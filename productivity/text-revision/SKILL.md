# Text Revision

Choose one primary mode by the requested deliverable. Read only that workflow; add another mode only for a distinct stage or artifact the task needs.

Resolve each link relative to the file containing it. Workflow links to `../artifacts/` refer to this package’s `references/artifacts/` directory.

| Mode | Use when | Workflow |
| --- | --- | --- |
| `revision-planning` | Turn an existing draft and revision goals into a sequenced, located plan that distinguishes structural work from later sentence polish. | [Revision Planning](references/workflows/revision-planning.md) |
| `structural-revision` | Apply substantial manuscript revisions to argument, scene sequence, chapter architecture, transitions, or emphasis while retaining the author’s required choices. | [Structural Revision](references/workflows/structural-revision.md) |
| `feedback-integration` | Reconcile comments from authors, editors, reviewers, or readers into traceable revision decisions and applied changes when requested. | [Feedback Integration](references/workflows/feedback-integration.md) |
| `rhetorical-revision` | Revise prose for cadence, emphasis, figurative force, register, and syntactic movement while preserving meaning and deliberate voice. | [Rhetorical Revision](references/workflows/rhetorical-revision.md) |
| `continuity-review` | Find evidenced contradictions in entities, time, space, knowledge, terminology, or repeated claims across a manuscript without treating every difference as an error. | [Manuscript Continuity Review](references/workflows/continuity-review.md) |
| `reader-response-review` | Evaluate likely reader orientation, comprehension, engagement, and access barriers through located evidence while separating predictions from observed reader feedback. | [Reader Response Review](references/workflows/reader-response-review.md) |
| `text-adaptation` | Produce complete adaptations of supplied text for a new audience, medium, length, or purpose while making consequential transformations inspectable. | [Text Adaptation](references/workflows/text-adaptation.md) |

Respect the authoritative draft and the user’s protected choices. Distinguish proposed edits, applied changes, textual evidence, and predicted reader responses. Preserve recoverable originals and report the actual extent reviewed or revised.
