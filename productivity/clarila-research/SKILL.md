# Answer the actual unknown

Read the [shared workflow contract](../clarila/references/contract.md) before substantive work. This skill is part of the locally installed Clarila suite. Its source is in `~/Developer/skills`; resolve sibling skills relative to this directory.

## Procedure

1. State the question, decision it informs, scope and stopping condition. Read existing relevant Obsidian knowledge first.
2. Read primary sources, using current official documentation for changing technical facts. Record actual read dates, applicability and source identity.
3. Separate source claims, local observations and your interpretation. Investigate disagreements rather than flattening them into a confident summary.
4. Produce the useful answer with citations, practical implications and remaining uncertainty. Do not copy whole copyrighted sources.
5. Use clarila-obsidian to retain a reusable source or synthesis when warranted. Research does not authorize implementation, provider changes or procedural activation.

For each decision-changing claim, record the owning primary source, its version/commit or effective date, and the local condition to which it applies. A current upstream guide can establish current upstream behavior while the installed version needs its matching evidence. When sources disagree, identify whether the difference is date, version, scope or an unresolved contradiction. Finish when the bounded question is answered at the required confidence, or when a named missing source is the remaining prerequisite.

This primary-source tracing method is informed by the public [research skill](https://github.com/mattpocock/skills/blob/4ae2317ddb22b046e26455e4f9c9b3aaaf62212d/skills/engineering/research/SKILL.md). Keep research outputs in the existing task knowledge/handoff locations.

## Synchronization and handoff

Resolve the same issue/workspace/session association before substantive work, including direct invocation. Read and update the private handoff described in the shared contract using available native file tools. Record the actual stage, source, findings, evidence, outcome and next action. If no native session identity is available, retain an unbound record. Use the current host’s native tools during the invoked workflow.

## Deliverable

Return a source-grounded answer, decision implications, checked dates and remaining unknowns.

Load only the relevant specialist from the [catalog](../clarila/references/catalog.md). Missing tools change the available evidence, never its meaning.
