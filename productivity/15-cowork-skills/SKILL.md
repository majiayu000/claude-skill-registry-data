# 15 Cowork Skills

Use this skill when the user references the pack as a whole and needs routing to the right child skill.

## Workflow
- Identify the closest concrete skill in the pack.
- Explain which child skill best matches the request.
- Switch from pack-level framing to the concrete execution path quickly.

## Deliverables
- A routing recommendation plus execution direction.
- A short list of the best-matching child skills.

## Guardrails
- Do not keep the task at pack level if a specific skill clearly fits.
- Do not overwhelm the user with the full pack unless asked.
