# Text Composition

Choose one primary mode by the requested deliverable. Read only that workflow; add another mode only for a distinct stage or artifact the task needs.

Resolve each link relative to the file containing it. Workflow links to `../artifacts/` refer to this package’s `references/artifacts/` directory.

| Mode | Use when | Workflow |
| --- | --- | --- |
| `composition-planning` | Turn an intention, commission, fragment, or open-ended idea into a usable writing brief and a route from exploration to finished text. | [Composition Planning](references/workflows/composition-planning.md) |
| `source-synthesis-and-outlining` | Convert supplied notes and sources into a traceable argument, narrative sequence, or working outline without laundering uncertain material into fact. | [Source Synthesis and Outlining](references/workflows/source-synthesis-and-outlining.md) |
| `fiction-drafting` | Write complete original fiction or requested scene/chapter revisions from a brief, including experimental and nonlinear forms. | [Fiction Drafting](references/workflows/fiction-drafting.md) |
| `nonfiction-drafting` | Write complete explanatory, argumentative, narrative, or practical nonfiction from an outline and an honest account of the available evidence. | [Nonfiction Drafting](references/workflows/nonfiction-drafting.md) |
| `essay-composition` | Compose complete reflective, personal, critical, lyric, or braided essays whose movement comes from inquiry as well as argument. | [Essay Composition](references/workflows/essay-composition.md) |
| `poetry-composition` | Compose and revise complete poems, sequences, or lyrics with deliberate relations among sound, syntax, image, line, stanza, and form. | [Poetry Composition](references/workflows/poetry-composition.md) |
| `dramatic-writing` | Write complete dramatic scenes or scripts in which playable action, speech, silence, and staging carry conflict or another chosen theatrical structure. | [Dramatic Writing](references/workflows/dramatic-writing.md) |
| `professional-writing` | Draft complete memos, letters, briefs, reports, speeches, proposals, and practical explanatory copy for a defined reader and decision. | [Professional Writing](references/workflows/professional-writing.md) |
| `academic-writing` | Compose complete scholarly manuscript sections or papers from supplied research, reasoning, results, and sources while preserving the evidential record. | [Academic Writing](references/workflows/academic-writing.md) |

Deliver the requested artifact, including complete drafts when assigned. Preserve source provenance, deliberate form and voice, and explicit limits on manuscript coverage. Planning or critique must not replace requested writing.
