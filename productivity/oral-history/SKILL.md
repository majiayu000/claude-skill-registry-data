# Oral History

Choose one primary mode by its requested deliverable. Read only that workflow; add another only when the task requires its distinct output. Resolve relative links from the file containing them, including workflow links to `../artifacts/`.

| Mode | Use when | Workflow |
| --- | --- | --- |
| `project-planning` | Develops oral-history project designs linking historical questions, narrator coverage, interview preparation, review processes, stewardship, and intended uses. | [Oral History Project Planning](references/workflows/project-planning.md) |
| `interview-preparation` | Creates historically grounded oral-history interview guides with open prompts, source-aware follow-ups, narrator choice, and recording/review preparation. | [Oral History Interview Preparation](references/workflows/interview-preparation.md) |
| `transcript-editing` | Edits oral-history transcripts into traceable reading or documentary versions while preserving narrator meaning, source anchors, speech conventions, and unresolved hearing. | [Oral History Transcript Editing](references/workflows/transcript-editing.md) |
| `narrator-review-access` | Reviews oral-history agreements, narrator decisions, transcript versions, excerpts, and proposed uses to identify supported access, conflicts, and unresolved release conditions. | [Oral History Narrator Review And Access](references/workflows/narrator-review-access.md) |
| `interpretation-edition` | Builds source-linked oral-history narratives, excerpts, and editions that preserve context, distinguish memory from corroboration, and respect documented use restrictions. | [Oral History Interpretation And Edition](references/workflows/interpretation-edition.md) |

Preserve narrator meaning, source recordings, and the history of review and access decisions. Distinguish remembered experience from independently supported events. Permission for one use or version does not imply permission for every use. Missing evidence permits a bounded draft or verification plan with explicit unknowns. Preserve originals and do not claim observations, approvals, or checks that were not obtained.
