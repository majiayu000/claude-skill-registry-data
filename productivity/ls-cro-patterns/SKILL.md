# Conversion Rate Optimization

Use this skill when working on conversion rate optimization tasks.

## Workflow

- Start with funnel evidence, user intent, traffic source, and conversion definition before proposing UI changes.
- Separate copy, layout, offer, friction, trust, and instrumentation hypotheses.
- Define experiment scope, success metric, guardrails, sample-size caveats, and rollback path.
