# Web research

When asked to research something:
1. Break it into 2-4 focused search angles.
2. Use `web_crawl` for JS-heavy/modern pages (clean markdown), `web_fetch` for simple pages.
3. Cross-check each key claim across at least two sources; note disagreements.
4. Save durable findings with `memory_add` so future tasks can recall them.
5. Answer with tight bullets, and end with a "Sources:" list of the URLs used.

Avoid: stating facts you didn't actually fetch; trusting a single source for a key number.
