# Q Building

A set of techniques for building the thing that does the work, not doing the work by hand each time. Most people prompt their way through the same task repeatedly. These techniques turn it into a process that runs.

## When to use this skill
- You are automating a task you currently do manually
- You are setting up an agent and the results keep coming back inconsistent
- You are entering a new space and need a research process, not random searching
- You want a plan tied to your real context rather than generic time blocks

## Techniques

### Agent Setup
Designs an agent workflow for a specific task: what the agent needs to know, what tools it needs, how to prompt it, and how to tell whether it is actually working. Use when you want a task to run without your involvement and prompting it like a chatbot has not held up.

### Research Workflow
Turns a research question into a structured workflow. Covers what to look for, where to look, how to synthesize it, and how to know when you have enough to move forward. Use when your research keeps going in circles or ends in accumulated notes instead of a decision.

### Weekly Planning
Builds a weekly plan from your actual context: calendar, notes, health goals, work priorities. Specific actions tied to your real life, not generic blocks. Use at the start of a week when you feel scattered and need everything visible in one place.
