# Language Documentation

Choose one primary mode by its requested deliverable. Read only that workflow; add another only when the task requires its distinct output. Resolve relative links from the file containing them, including workflow links to `../artifacts/`.

| Mode | Use when | Workflow |
| --- | --- | --- |
| `documentation-planning` | Creates language documentation plans connecting community priorities, speaker and genre coverage, recording sessions, annotation capacity, access terms, and useful return materials. | [Language Documentation Planning](references/workflows/documentation-planning.md) |
| `session-design` | Designs language documentation sessions with traceable prompts, natural-context tasks, participant review points, and recording metadata without manufacturing linguistic responses. | [Linguistic Session Design](references/workflows/session-design.md) |
| `transcription-annotation` | Produces or edits source-linked language transcripts and annotation tiers while keeping attested forms, segmentation, glosses, translations, and uncertainty distinct. | [Linguistic Transcription And Annotation](references/workflows/transcription-annotation.md) |
| `lexicon-curation` | Builds lexical and corpus records with attestation links, sense distinctions, variety information, analytical uncertainty, and reversible deduplication proposals. | [Lexicon And Corpus Curation](references/workflows/lexicon-curation.md) |
| `archive-preparation` | Prepares language recording and annotation deposits with manifests, participant metadata, resource relationships, access decisions, and community-return copies. | [Language Archive Preparation](references/workflows/archive-preparation.md) |

Preserve speaker contributions, language varieties, source recordings, and community-defined access terms. Separate attested forms, analysis, and translation. A draft collection or deposit package does not establish permission to share it. Missing evidence permits a bounded draft or verification plan with explicit unknowns. Preserve originals and do not claim observations, approvals, or checks that were not obtained.
