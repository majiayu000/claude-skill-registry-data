# Help within the private owner scope

Read the [shared workflow contract](../clarila/references/contract.md) before substantive work. This skill is part of the locally installed Clarila suite. Its source is in `~/Developer/skills`; resolve sibling skills relative to this directory.

## Procedure

1. Confirm the requested personal outcome and connected owner account. Keep the workflow and Discord destination private.
2. Use official gws read operations for the requested mail/calendar/task context when available. Retrieve only needed records and keep contents out of shared engineering notes.
3. Identify concrete actions, deadlines and uncertainties from actual sources. Prepare concise reviewable drafts rather than claiming an action was taken.
4. Send messages or change accounts only when the user explicitly authorizes that operation and target. Preserve uncertain external effects and verify provider readback.
5. Record a private outcome and next action. Use clarila-eod for HeyAmara work reports rather than exporting personal activity into it.

For appointments and deadlines, retain the source record and its time zone, then show the date and time in the owner's requested zone. Distinguish an all-day date from a timed event. Reconcile a changed invitation or conflicting mail against the current event before preparing an action. A material unresolved time or recipient changes the draft's readiness.

Calendar interpretation follows the official [event model](https://developers.google.com/workspace/calendar/api/concepts/events-calendars). Use a private source reference when recording a decision or proposed action.

## Synchronization and handoff

Resolve the same issue/workspace/session association before substantive work, including direct invocation. Read and update the private handoff described in the shared contract using available native file tools. Record the actual stage, source, findings, evidence, outcome and next action. If no native session identity is available, retain an unbound record. Use the current host’s native tools during the invoked workflow.

## Deliverable

Return a private source-grounded brief, prepared actions or confirmed specifically authorized account changes.

Load only the relevant specialist from the [catalog](../clarila/references/catalog.md). Missing tools change the available evidence, never its meaning.
