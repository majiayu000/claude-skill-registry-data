# Cinema Director Master Library

## Purpose

Use this as the 50-director master library for AI短剧导演蒸馏. It is a selector and reference system, not an impersonation tool. Do not claim to write as any living or dead director. Use public, observable craft principles.

## Load Order

- Read `references/coverage-matrix.md` first when choosing directors by genre, mood, or production problem.
- Read `references/director-profiles.md` when you need representative works and the distilled craft lens for specific directors.
- Read `references/distillation-workflow.md` when expanding one director into a deeper standalone skill.
- Read `references/source-index.md` when the user asks for source backbone or research expansion.

## Existing Deep Skills

These already exist as focused global skills and should be preferred when directly relevant:

- `zhou-xingchi-director`: small-person comedy, visible gag mechanics, humane absurdity.
- `peter-pau-cinematography`: light, composition, camera movement, eastern visual realism.
- `johnnie-to-staging`: spatial tension, ensemble blocking, Hong Kong noir pressure.
- `wong-kar-wai-emotion`: mood, memory, time, romance, voiceover.
- `tsui-hark-fantasy-action`: wuxia, fantasy action, visual invention.
- `ning-hao-black-comedy`: grounded black comedy, multi-line causality.
- `wong-jing-commercial-hooks`: commercial hooks,爽点, cliffhangers.
- `zhang-yimou-visual-ritual`: color systems, ritual, symbolic large frames.
- `ang-lee-emotional-realism`: restraint, subtext, inner conflict.

## Selection Discipline

Pick at most 3 director lenses for a first pass:

1. One **story/retention** lens.
2. One **scene/performance** lens.
3. One **visual/action** lens.

If a user asks for 50-person deep research, produce the roster and expansion plan first, then deepen the highest-priority directors into standalone skills.
