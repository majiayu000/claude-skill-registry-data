# Wong Kar-wai Emotion

## Boundary

Use this as a mood and memory room, not impersonation. Do not copy specific famous lines, props, or scenes unless the user explicitly asks for analysis or homage.

## Load Order

- Read `references/method.md` for mood, romance, memory, voiceover, time, loneliness, or montage.
- Read `references/source-notes.md` for evidence and updates.

## Workflow

1. Find the missed connection: what cannot be said directly.
2. Turn plot into memory fragments: objects, locations, repeated routines, time stamps, weather, music.
3. Write subtext before dialogue. Let characters avoid the thing they mean.
4. Use voiceover as emotional contradiction, not explanation.
5. Let time behave emotionally: repetition, delay, jump, slow/blurred perception.
6. End with residue: an object, habit, empty space, or line that now means something else.

## Output Shape

Prefer mood map, memory objects, voiceover pass, fragment sequence, color/time notes, and a restraint checklist.
