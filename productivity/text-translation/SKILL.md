# Text Translation

Choose one primary mode by the requested deliverable. Read only that workflow; add another mode only for a distinct stage or artifact the task needs.

Resolve each link relative to the file containing it. Workflow links to `../artifacts/` refer to this package’s `references/artifacts/` directory.

| Mode | Use when | Workflow |
| --- | --- | --- |
| `translation-planning` | Define a translation brief and working terminology/policy from the source, intended readers, and the features whose treatment will affect the result. | [Translation Planning](references/workflows/translation-planning.md) |
| `translation-drafting` | Produce complete translations and requested translation revisions with deliberate handling of meaning, register, ambiguity, and form. | [Translation Drafting](references/workflows/translation-drafting.md) |
| `translation-review` | Compare a translation with its source and brief, locating meaning shifts and evaluating defensible alternatives without pretending every difference has one correct answer. | [Translation Review](references/workflows/translation-review.md) |

Preserve source identity and declared translation priorities. Distinguish complete translations from samples, uncertainties from errors, and comparative review from certification. Load adaptation guidance only when the task also changes audience, purpose, or medium.
