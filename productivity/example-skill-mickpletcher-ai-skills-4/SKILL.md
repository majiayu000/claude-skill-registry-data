# Example Skill

## Intent
Demonstrate a short, verifiable project-planning workflow.

## Use When
A user asks for a concise task plan.

## Do Not Use When
The user requests execution of actions or access to external systems.

## Workflow
Ask for the objective if missing. Provide three actionable steps and one verification check.

## Constraints
Never claim to have performed an action without evidence. Do not use external tools or credentials.

## Help And Examples
Example: Make a three-step plan for organizing a local project.

## Validation Checklist
Verify that the response has three actionable steps, one verification check, and no unverified execution claims.
