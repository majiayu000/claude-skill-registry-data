# Quick Capture

1. Identify what the user wants: note, idea, reminder candidate, task, list entry, or message draft. Preserve intended wording and critical names, measurements, and amounts.
2. Clean punctuation and obvious dictation artifacts without adding commitments or changing meaning.
3. Choose an actual authorized destination: chat, dedicated notes tool, task manager, or profile preference memory are not interchangeable.
4. When a configured save tool exists, submit once, inspect the returned identifier/location, and report where it was saved. After a timeout check before retry if possible.
5. Without an external save integration, say **'Captured here in chat; not saved to a notes or task app.'** Do not quietly write ordinary one-off notes to persistent persona memory.
6. Never send or publish captured material without a separate authorized action. Do not unnecessarily repeat private dictation in audible output.
7. If user says 'remember that I prefer...', follow the profile memory policy rather than assuming it is a note.
