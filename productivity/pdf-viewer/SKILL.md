# Pdf Viewer

Use this skill when the task revolves around PDF content rather than generic document text.

## Workflow
- Clarify whether the job is extraction, comparison, or review.
- Keep page references explicit when useful.
- Use the installed Codex pdf skill where appropriate.

## Deliverables
- A PDF-derived summary, extraction, or comparison note.
- A short note on where to verify findings.

## Guardrails
- Do not rely on OCR alone when layout fidelity matters.
- Do not drop page-level traceability when the user may need it.
