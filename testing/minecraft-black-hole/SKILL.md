# 黑洞与吸积盘

将黑洞拆成核心、盘内空隙、发光气体盘、偏折射线、独立粒子与分层光晕。核心默认黑色，也可独立选色；与吸积盘内外配色分别设计。先做清楚轮廓和遮挡，再加细节。用户可以只描述颜色、形状与运动，无需填写 uniform。

制作白洞时读 [白洞外流分支](references/white-hole.md)：Forge 世界路径已有 `white-ring` 美术化白洞，包括强亮核心、核心专用 HDR 屏幕扩散与短星芒、独立体积冠层、向外盘纹、径向外散粒子、双极轴向输运喷流与重复扩张的球形光壳，使用 world/v2 配方。外喷体积独立沿直视射线按原场景深度截断，不继承主核/盘面的特殊地形深度策略。网页工作台与物品/面板仍为原黑洞路径；白洞模式不反转正质量透镜。

## 先选效果所在空间

- **物品内部**：模型/mask 是窗口，射线查询虚拟黑洞和内部星域。背景方向由材质内核提供，不依赖世界颜色复制。
- **世界实体/有限场景效果**：明确世界中心、范围、相机和场景遮挡；只有需要扭曲真实世界时才采样场景颜色/深度副本。
- **独立初稿或 skill 研究**：先使用随附预览。预览成功不表示 Minecraft 接入完成；创建 skill 不自动需要启动游戏。

用户未指定时沿用当前任务平台；本研究的接入说明以 Forge 1.20.1 / Java 17 为目标。不要把版本名称相近的包/API直接混用。

电影盘面已从内置预设、盘面选择和随机生成入口移除。不要再推荐或为新效果选择 cinematic；旧配方的解析与渲染仅用于兼容已有文件。

## 制作流程

1. 读 [设计与参数](references/design.md)，将描述转成焦点、暗核比例、盘内间隙、盘宽/厚度、倾角、色温/配色、旋转节奏和覆盖区域。用合理初稿补足非关键细节，不要求用户先理解算法。
2. 使用 `assets/preview/black-hole.glsl` 的原创美术化内核，或按目标另写求解器。原算法与局限见 [算法及来源](references/algorithm-sources.md)，选择参考实现时读 [六份来源对照](references/source-comparison.md)。角向旋转与径向内流分别控制；不能把纹理旋转冒充射线偏折，也不能将该内核描述为物理精确模拟。当前临界光圈使用有限步长的端点/中点积分与片元足迹重建。用户 `index.html` 的速度 Verlet 方案在工作台通过 `?solver=verlet` 作为可选研究路径保留，默认艺术积分与 Forge 接口不受影响。
3. 用 `python scripts/serve_preview.py --port 8771` 打开本地制作台；浏览器地址由脚本输出。v3.2 默认展示透镜尘埃，三个主配方分别对应连续尘埃、Unity 式层叠光带和颗粒组合；颗粒组合预设采用用户最新配方及其暂停时间/视角，旧配方仍可导入或用旧链接访问。工作台可用滚轮拉近/拉远，调节光圈半径、宽度、锐度，分别给核心、盘面、粒子、背景和三层光晕配色及渐变；粒子使用紧凑尘粒轮廓。可切换横向/方形画幅，单独检查盘面、背景和射线状态。先读 [v3.2 工作台与来源](references/v3-workbench.md)，区分背景星点与盘尘埃，检查长时间播放的剪切混叠；需要扩展风格或修改求解器时读 [OpenBenchHub 23 份参考研究](references/openbenchhub-patterns.md)。若用户提供单文件黑洞网页作为研究样本，先读 [用户 index.html 算法审读](references/user-index-study.md)：提炼有限步弯曲积分、薄盘交点/高斯薄层、温度与 Doppler 启发式、宽背景足迹过滤及 HDR 分层，但不要把无许可证源码、远景 bokeh 粒子或固定窄光子环直接复制。接口与复跑见 [预览与验收](references/preview-validation.md)。
4. 看原始大图、真实 16/32 px 重渲染以及目标轮廓。固定 seed/time 制作修改对照；分别改变时间、观察角度、偏折强度。随附剑刃只是示意窗口，实际设计使用目标模型的 mask。
5. 用户要求落地时读 [Forge 接入](references/forge-integration.md)，可从 `assets/forge-1.20.1` 示例工程起步，保留 Java→shader 参数、几何/相机契约、资源生命周期与验收。预览 JSON 不会被旧 Cosmic JAR 自动识别；不要输出不存在的 NBT 功能。
   用户要求旋转吸入、颗粒或光晕时读 [粒子与光晕](references/particles-and-halo.md)。Forge 世界示例已接入 v3.2 四种可选盘面、核心/盘面/分层光晕渐变、喷流、360°真实环境透镜、相机光学眼点与整实体保护。浏览器星域/HDR bloom、粒子中间色仍有宿主差异；物品路径保留旧内部材质。字段生效范围见接入文档，不能宣称网页与世界像素等价。
6. 交付视觉结果、配方/源码和已通过的环境。对新 shader 的 Forge 验收重新取证，不继承旧 baked-item Cosmic 实验的认证。

## 必须保留的契约

- 相机点、方向、暗核、盘面在同一材质空间；点与方向分别变换，非均匀缩放另处理距离单位。旋转盘面使用一个正交基，不旋转混合了不同空间的坐标。
- 先积累前景盘辐射，命中核心时先按剩余透射率加入核心源颜色，再截断后景；保留已积累的前景光。核心为黑色时退化为纯吸收。穿过盘的透射率与物品轮廓 alpha 是不同量。
- 步长决定每段吸收量。质量档改变时重新检查亮度、暗核轮廓、薄盘漏采与偏折路径；不能只凭平均亮度接近认定收敛。
- 稳定 seed 决定结构；time 只推进运动。环形纹理使用周期表达或真正无缝素材，避免 atan 经度接缝。
- 盘面角向旋转、盘纹径向内流、粒子轨迹是独立运动。变半径轨道要积分角速度；粒子重生和捕获时淡出。光晕保留核心与前景遮挡，不能覆盖成不透明亮环。
- 背景透镜围绕质量轴在 360° 方位连续；地面/天空同一完整角向映射，不能按地面前后分类裁掉半圈。玩家默认整模型保护，显式开启必须实际参与。用实体前环境副本恢复扭曲源并检查双线性四 tap，避免第三人称碎片/假重影。
- 真实世界固定中心不随视线重新计算。捕获地形实际 VP；inverseVP × (0,0,1,0) / w 得光学眼点，不能遗漏投影中的 bob/hurt 平移。
- 偏折方向用于查询背景场。真实世界的屏幕颜色不能从屏外或完全不可见内容中凭空恢复；需明确退化策略。
- Forge 世界合成须考虑云层等晚于粒子的 pass：原版 1.20.1 示例在 `AFTER_LEVEL` 取景并绘制，避免没有可靠深度的云层于黑洞之后盖住暗核；换用其他渲染管线需重查事件顺序与主 framebuffer。
- 显示转换放在指定阶段。预览自行转换颜色，Forge/光影可能另有显示管线，不机械叠加曝光或 gamma。
- 透明度、深度、framebuffer、viewport、shader、纹理绑定的所有权明确；flush 与参数保持一致，异常恢复相关状态。

- 白洞通过外喷运动与结构区分，不能只把黑核改白。双极喷流按盘法线两侧输运，球壳按半径扩张；各速度独立积累并支持 HOT 0 冻结/连续恢复。外喷材料用直视相机射线、原地形/实体深度和核心近面遮挡，薄壳解析区间与分段长度积分避免漏采。

## 与已有能力组合

普通物品接入可在已有 `minecraft-cosmic-material` 的 baked-item 路径上替换内部场；本 skill 自带接入说明，不要求该 skill 必须安装。Halo、外壳 rim 和 glint 是独立层，按用户设计选择，不能用于掩盖黑洞主体没有接入成功。

本 skill 附 WebGL 2 工作台和自包含 Forge 1.20.1 源码。黑洞预设倾角为 0°（水平）；白洞用户预设为 -1°，显式导入角度保留；世界预览沿命中表面放置后固定中心，玩家透镜参与可开关，黑洞默认关闭，白洞用户预设开启。2026-10-05 的黑洞迁移版本曾在独立开发客户端验证首次启动/真实 shader 加载/六视点地面核心定位；该结果不认证新增白洞。透镜和玩家策略的完整实机覆盖须按 [相机与透镜回归](references/world-regression.md) 重新取证，历史 ASTRA-TEST 结果不充当新路径认证。ArcaneVortex 及五份补充工程只作为研究来源，不随 skill 分发它们的源码、素材、JAR 或反编译文件。

白洞核心光团的 source 只记录经前景盘透射后的核心捕获，不选择天空或整屏亮像素；源继承原核心美术地形可见性，屏幕柔光可以覆盖前景像素。RGBA16F emission 与双尺度模糊独立于世界深度写入，coreGlow/Radius 同时驱动有限冠层及投影扩散；不能把 optical spill 称为动态地形照明或严格世界球形范围。

白洞当前用户默认共 75 字段，以 assets/presets/white-ring-default.json 为准；shellEnabled 独立控制外扩光圈，当前白洞默认 false，旧 world/v2 缺省 true 而显式强度不变。dust 风格的体积不依赖 particles，窄盘必须按实际盘宽渐隐并避免噪声八度乘积将密度消空。详见 references/white-hole.md 的用户默认与尘埃盘修复节。
