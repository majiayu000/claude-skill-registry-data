# Browser & E2E Audit Skill

## Scope of Inspection
1. **Routes & Pages:** Discover all navigable endpoints and links.
2. **User Journeys:** Verify primary flows (navigation, forms, submissions).
3. **Console & Network:** Assert zero unhandled JavaScript errors and zero failed 4xx/5xx network requests.
4. **Accessibility:** Run automated axe-core accessibility checks for WCAG 2.1 AA compliance.
5. **Responsive Matrix:** Validate layouts across mobile (390px), tablet (768px), and desktop (1280px+).
