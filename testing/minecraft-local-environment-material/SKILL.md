# 局部环境材质化渲染

把请求拆为 **影响场 → 可见表面与对象资格 → 材质函数 → 光照/雾/透明合成**。维持原方块、实体、建筑的位置和几何；视觉特效不修改方块数据、碰撞或服务器玩法。Cosmic 只是可替换的一个材质函数。

## 从用户意图选择路线

先确认工程版本、实际 renderer、目标对象和锚定语义。优先沿用已知目标；本研究目标是 **Forge 1.20.1 / Java 17**。1.21.1 Veil/Lodestone 是原理参考，不直接复制 API。

- “玩家周围 20 格”：默认球形半径 20 方块；说明跟随玩家还是释放点固定。玩家中心通常用脚底或明确偏移，不误用第三人称相机位置。
- “剑气经过地面变水墨”：记录世界空间路径与时间戳；胶囊链定义空间带，再用地形类别/朝上法线/指定高度层限制地面。它不是随相机刷过的屏幕笔触。
- “只影响方块，不影响实体”：早期地形阶段是最小路线；若包含方块实体、透明方块或排除某种方块，需要分类/绘制入口支持。不能从单深度或 RGB 猜对象。
- 涉及水/玻璃时先选择 **基础模式、材质化模式、完全异化模式**，读 [透明表面与流体](references/transparent-surfaces.md)。0.2.0 已在原透明区块绘制中实现可选材质函数；默认仍为基础模式。`water` 是精确 sprite 契约而非 Fluid ID，`layer` 明确包含整个透明区块层，不能冒充“只流体”。完全异化与 Shader Pack 折射需要独立适配，不用最终画面覆盖代替。
- “虚空球/命中点侵蚀”：锚定命中世界坐标，独立设置半径曲线、稳定噪声、边缘宽度和消退时间。不得把球壳网格或满屏星图当作区域材质替换。

按 [架构与对象分层](references/architecture.md) 选择：地形阶段重建、分类缓冲合成、原绘制材质注入，或混合方案。几何不变时，全屏三角也可作为计算载体，但材质必须取决于原表面世界位置，不能退化成屏幕 UV 贴图。

## 工作顺序

1. 研究、迁移或数据来源不明时读取 [源码证据](references/source-study.md)，核对版本与生产者、附件、时机、消费者和失效条件。已验证的同版后端可直接从对应资产开始，不必每次重读四个项目。
2. 先实现 [深度与世界空间 Mask](references/coordinates-regions.md)：固定时间显示坐标/棋盘和 Mask，验证转头、移动、FOV、视角晃动、大坐标。矩阵必须与深度生产者同帧同视图。
3. 用简单常量材质验证对象筛选与遮挡，再按 [材质与过渡](references/materials-transitions.md) 引入具体风格。正常与替代材质在一致颜色空间合成，原 alpha/几何不被意外改变。
4. 按 [区域管理与生命周期](references/runtime-performance.md) 建立适合当前请求的实例、时钟、资源代次和预算；需要时再增加重叠、多区域、路径或边缘发光，不为单球效果强制建设完整引擎。
5. 对 Forge 实施读 [1.20.1 接入](references/forge-1.20.1.md)。修改目标工程前确认核心 renderer 与 shader pack；不把加载器相同当作管线兼容。
6. 执行 [分级验收](references/validation.md)，记录每个已支持对象/后端。只有对应目标实例的画面证据才允许写“实机通过”。

## 不变量

- 深度提供最近的写深度表面，不提供实体类型、原材质、透明层列表或完整光照。缺少信息就增加生产入口，不能用命名或文件存在冒充能力。
- CPU 用 double 算区域中心相对实际相机的差；GPU 重建 camera-relative 位置再与之相减。Mask、材质和噪声的锚点分别明确，不能因相机平移而滚动图案。
- 未命中区域、无有效深度、类别未入选的像素保持原结果。区域后处理只写颜色，原深度保持给后续实体/透明物体使用。
- 输入颜色/深度是独立副本或经验证的只读资源；不从当前正在写入的同一附件采样。深度副本也检查反馈风险。
- 动画来自 tick+partialTick 或明确时钟，不按渲染回调次数推进。路径点容量与采样策略显式限制。
- 每次 draw 的参数与资源稳定；重载、切世界或异常不能让队列持有旧纹理/uniform。能力不足时明确回退，不静默把“只方块”扩大成“所有像素”。

## 随附资产与证据级别

- `assets/validation/`：原创 GLSL 区域/材质核，CPU 数值检查与 WebGL2 几何深度验证程序。GPU 示例含六种 Mask、Cosmic/水墨/熔岩三个原理样例、分类与重叠；需要 Python+NumPy 或 Node+Playwright 与可用浏览器。
- `assets/forge-1.20.1-lab/`：完整 0.2.0 工程，单个扩散/收缩球、三种材质、地形阶段及可选原透明几何注入、生命周期及未知 renderer 禁用。已 build/reobfJar，在 **Forge 47.4.10 / ASTRA-TEST / Fancy** 通过地形和新增水/染色玻璃测试；原生透明层对照见 [surface-validation.md](references/surface-validation.md)。
- 数值/GPU/Forge 编译与新后端实机证据于 2026-09-29 生成，详情见 validation.md。独立 GPU 合成场景与 Minecraft 实机截图分开记录；新后端实测不借用旧物品 Cosmic 的认证。

收到实施请求时可从资产扩展，不能把单区域演示宣称为已完成的多区域、网络同步、任意透明 renderer、折射或全部材质引擎。已有 Cosmic/黑洞/碎晶等 skill 可提供材质函数；此 skill 负责区域与环境接入契约。
