# 测试覆盖率统计Skill

## 适用场景
代码质量度量环节,量化单元测试覆盖情况,判定是否达标。

## 执行步骤
1. 选工具:优先运行现有工具(JaCoCo、pytest-cov、Jest --coverage、go test -cover)。
2. 统计口径:行覆盖率(默认)+ 分支覆盖率(关键模块必须)+ 变更覆盖率(增量场景)。
3. 生成覆盖率报告并解析:总覆盖率、模块分布、未覆盖 Top 清单。
4. 按阈值判定:达标 / 不达标,输出未覆盖清单。

## 判定阈值(默认,可按项目调整)
| 指标 | 门槛 |
|---|---|
| 行覆盖率 | ≥ 80% |
| 分支覆盖率(核心模块) | ≥ 70% |
| 新增/变更代码覆盖率 | ≥ 90% |

## 规范要点
- 覆盖率是底线不是目标:禁止为凑覆盖率写无断言空测试(视为违规)。
- 未覆盖清单按风险排序:核心业务/资金/安全相关代码的未覆盖项必须点名。
- 报告必须注明工具与版本,数据可复现。

## 输出模板
```
## 覆盖率报告
| 模块 | 行覆盖 | 分支覆盖 | 判定 |
## 未覆盖 Top(位置 + 风险 + 建议补测点)
## 达标判定
```

## 自检清单
- [ ] 工具与版本已注明
- [ ] 核心模块未覆盖项已点名
- [ ] 达标判定有依据
