# 接口自动化脚本开发Skill

## 适用场景
自动化测试环节,为 REST 接口编写可重复执行的自动化测试脚本。

## 执行步骤
1. 确定工具:与项目技术栈匹配(pytest+requests / Jest+supertest / RestAssured / JMeter)。
2. 搭脚本骨架:环境配置分离(base_url、环境变量)、公共请求封装、鉴权处理。
3. 用例设计:成功路径 / 参数校验 / 鉴权 / 幂等 / 错误码断言 / 边界值。
4. 数据策略:测试数据用夹具(fixture)构造,清理动作 tearDown 兜底,不污染环境。
5. 执行与断言:状态码 + 响应结构 + 业务字段 + 数据库副作用(必要时)。

## 规范要点
- 断言三件套:HTTP 状态码 + 业务 code + 关键字段值,禁止只断 200。
- 测试数据与生产隔离;涉及写操作的用例必须有清理或事务回滚。
- 密钥/token 从环境变量读取,禁止硬编码进脚本。
- 用例可独立执行、可重复执行(幂等设计:每次运行结果一致)。
- 失败输出必须含请求/响应摘要,可快速定位。

## 输出模板
```
[自动化脚本文件]
## 执行命令
## 环境准备(依赖服务/测试数据)
## 用例清单(编号/接口/场景/断言)
```

## 自检清单
- [ ] 断言三件套齐全
- [ ] 无硬编码密钥
- [ ] 用例可重复执行且结果一致
- [ ] 本地/CI 跑通
