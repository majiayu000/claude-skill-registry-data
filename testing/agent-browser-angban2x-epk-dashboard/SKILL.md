## What I do
- Automatización de navegador para AI agents
- Navegar páginas, llenar forms, hacer click, tomar screenshots
- Extraer datos, testear web apps, automatizar tareas del navegador
- Reemplaza Playwright manual con flujos automatizados

## When to use me
Use this when:
- Need to interact with websites
- Testing web applications
- Taking screenshots for visual regression
- Filling out forms programmatically
- Scraping data from pages
- Exploratory testing

## Project Context
- Playwright está configurado como MCP server
- Screenshots se guardan en `tests/screenshots/`
- Use `npx playwright screenshot` for quick screenshots
