# UI Testing Skill

Test the website provided in $ARGUMENTS.

Use Playwright MCP to:

1. Open the website.
2. Check page loading.
3. Inspect visible UI elements.
4. Test buttons and navigation.
5. Test form validation if forms exist.
6. Check browser console errors.
7. Take screenshots.
8. Report any bugs.

## Rules

- Do not modify application code.
- Do not submit real payments or delete data.
- Do not claim a test passed unless verified.

## Output

Provide:

- Tests performed
- Passed tests
- Failed tests
- Bugs discovered
- Recommendations
