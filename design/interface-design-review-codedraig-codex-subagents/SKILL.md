# Interface Design Review

Choose one primary mode and read only its workflow. Add modes only for interface concerns the request actually includes.

| Mode | Use when | Workflow |
| --- | --- | --- |
| `ux-flow-mapping` | Map actors, journeys, states, transitions, recovery, permissions, or destructive actions. | [UX flow mapping](references/workflows/ux-flow-mapping.md) |
| `design-system-audit` | Audit components, tokens, variants, visual consistency, adoption, or migration risk. | [Design-system audit](references/workflows/design-system-audit.md) |
| `accessibility-audit` | Review keyboard, focus, semantics, announcements, contrast, motion, or task completion barriers. | [Accessibility audit](references/workflows/accessibility-audit.md) |
| `localization-readiness` | Review translation readiness, locale formats, pluralization, expansion, or right-to-left behavior. | [Localization readiness](references/workflows/localization-readiness.md) |

Do not load sibling workflows or artifacts prospectively. Preserve user work, expose destructive consequences, and stop when required source, UI, or owner authority is unavailable.
