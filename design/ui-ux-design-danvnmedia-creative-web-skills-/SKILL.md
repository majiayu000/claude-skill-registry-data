# UI / UX Design

1. Name the actual audience, screen/job, primary action, and product vocabulary.
2. Ground visual decisions in the product domain and existing brand/system.
3. Define compact tokens: color, type, spacing, radius/elevation, motion.
4. Choose at most one memorable signature element; keep surrounding UI disciplined.
5. Design real content and long/empty/error/permission/loading/success/degraded states.
6. Preserve semantic controls, keyboard focus, contrast, reduced motion, and responsive reflow.
7. Avoid generic neon gradients, gratuitous glass/bento/stat cards, and decoration with no information value unless the brief justifies them.
8. If `ui-ux-pro-max` exists, query it for design intelligence, then reconcile with product context and accessibility.
9. After implementation, use `runtime-verification` and critique mobile + desktop screenshots. Fix visible hierarchy, overflow, density, copy, and interaction issues before completion.
