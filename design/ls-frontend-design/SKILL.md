# Frontend Visual Design

Use this skill when working on frontend visual design tasks.

## Workflow

- Start from the product domain and user workflow before choosing visual style.
- Prefer existing design-system conventions in established apps; avoid decorative novelty that hurts task flow.
- Check responsive typography, spacing, focus states, empty states, and dense operational screens for clarity.
