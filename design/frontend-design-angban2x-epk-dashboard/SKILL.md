## What I do
- Proporciona guía de diseño visual para construir interfaces distintivas
- Ayuda con dirección estética, tipografía, y decisiones de diseño que no parezcan templates genéricos
- Evita patrones de diseño default que se ven como "otro dashboard más"

## When to use me
Use this when:
- Creating new UI components
- Redesigning existing pages
- Need aesthetic direction
- Want to avoid templated defaults
- Working on landing pages, dashboards, or any user-facing UI

## Design Principles for PressPlay
- Brand: PressPlay — "Donde la música se presenta"
- Colors: Indigo (#4f46e5), Violet (#8b5cf6), Pink (#ec4899), Emerald (#10b981)
- Dark mode first, with light mode support
- Mobile-first responsive design
- Framer Motion for animations
- Tailwind CSS for styling
