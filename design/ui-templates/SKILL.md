## Usage

1. Choose a design template that matches your project needs
2. Read the design system documentation in the reference file
3. Implement using the provided color tokens, typography, and components
4. Follow the layout and animation guidelines for consistency

## Template Structure

Each template includes:

- **Design Philosophy**: Core principles and vibe
- **Design Tokens**: Colors, typography, spacing, borders, shadows
- **Components**: Buttons, cards, inputs, icons
- **Layout**: Grid systems, responsive breakpoints
- **Animation**: Transitions and micro-interactions
- **Accessibility**: Focus states, contrast requirements
