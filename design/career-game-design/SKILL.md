# career-game-design

## When to Use

当需要主动设计和构建个人职业生涯，而非被动接受传统就业时description

## Core Logic

# 执行步骤

1.  **识别核心痴迷与问题**
    *   **输入**：个人兴趣、长期关注点、感到不满或希望解决的社会/个人问题列表。
    *   **操作**：审视输入列表，筛选出能持续激发你好奇心与动力，且与外部需求（市场、社会问题）存在潜在交集的1-3个核心领域。
    *   **判断标准**：所选领域能清晰回答“我对什么充满热情？”和“我能解决什么具体问题？”。
    *   **输出**：1-3个明确的“痴迷-问题”交集领域。

2.  **规划技能获取路径**
    *   **输入**：上一步输出的“痴迷-问题”领域。
    *   **操作**：针对每个领域，拆解出实现价值创造所必需的“硬技能”（如编程、写作、设计）和“软技能”（如项目管理、沟通）。
        *   **IF** 技能树清晰（如开发一个App需要编程、UI设计），**THEN** 制定线性学习计划。
        *   **ELSE**（技能树模糊），**THEN** 通过快速尝试最小可行项目（MVP）来反向定义所需技能。
    *   **判断标准**：为每个核心领域生成一份具体、可开始行动（例如“学习Python基础语法”）的技能学习清单。
    *   **输出**：与核心领域绑定的个性化技能获取路线图。

3.  **构建最小可行产品（MVP）**
    *   **输入**：技能路线图、初步的想法或解决方案。
    *   **操作**：运用已获取或正在学习的技能，围绕核心问题，创建一个最简单的、能体现核心价值的产品原型（可以是一篇文章、一个简单程序、一个服务流程）。
    *   **判断标准**：MVP能在短时间内（如1-4周）完成，并能交付给目标用户/受众进行测试和反馈。
    *   **输出**：一个可展示、可测试的初始作品或服务原型。

4.  **建立个人分销渠道**
    *   **输入**：已完成的MVP、个人知识/经验积累。
    *   **操作**：选择一个主要平台（如个人博客、GitHub、社交媒体、邮件列表），开始持续公开分享与核心领域相关的内容（如创作过程、学习心得、行业见解、MVP迭代故事）。
    *   **判断标准**：建立了稳定的内容发布节奏（如每周更新），并开始吸引初始关注者或用户。
    *   **输出**：一个活跃的、与个人品牌和核心领域绑定的公开内容输出渠道。

5.  **启动价值交换循环**
    *   **输入**：通过分销渠道获得的反馈、关注度、潜在用户询问。
    *   **操作**：
        *   **IF** MVP获得积极反馈且有明确改进需求，**THEN** 迭代MVP，增加功能或深化服务。
        *   **IF** 收到明确的付费意愿或合作邀请，**THEN** 设计付费产品/服务（如咨询、高级功能、定制化）。
        *   **ELSE**（反馈平淡），**THEN** 回到步骤1或步骤2，重新调整领域或技能重点。
    *   **判断标准**：开启了“创造价值（产品/内容）→ 获取反馈/注意力 → 迭代/变现 → 再创造”的增强循环。
    *   **输出**：一个可持续的、能产生经济或社会回报的个人价值创造系统。

# 输出格式要求
以结构化报告形式呈现，包含以下部分：
1.  **核心定位**：陈述你的“痴迷-问题”交集领域。
2.  **技能蓝图**：列出对应的关键技能与学习/实践计划。
3.  **启动项目**：描述你的第一个MVP构想。
4.  **渠道策略**：明确你选择的内容分发平台与初步计划。
5.  **下一步行动**：指定未来7天内要完成的具体任务。
