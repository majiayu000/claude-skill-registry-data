# Open Design

Open-source AI design engine with 150+ composable skills for web, desktop, and mobile.

## When to Use

- Generating prototypes, landing pages, dashboards, and slide decks
- Building brand-grade DESIGN.md design systems for projects
- Creating images, videos, and motion graphics with AI
- Implementing frontend UI from design specifications
- Working with Figma plugins and design-to-code workflows
- Generating responsive HTML/CSS/React components from briefs
