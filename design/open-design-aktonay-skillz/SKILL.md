# Open Design Skill & Ecosystem

Open Design turns coding agents into full design partners for websites, prototypes, slide decks, and marketing visuals.

## Ecosystem Highlights

1. **Slide Decks & Presentations**:
   - `deck-open-slide-canvas`: Canvas-driven modern decks
   - `deck-swiss-international`: High-contrast Swiss typography slides
   - `pptx-generator`: Direct PowerPoint / Keynote production

2. **Brand & Visual Systems**:
   - `brand-extract`: Extract color tokens, logos, and fonts from live URLs
   - `brand-guidelines`: Formulate consistent design contracts
   - `color-expert`: Harmonious HSL/OKLCH color palette generator

3. **Motion & Media**:
   - `motion-design`: Choreographed UI sequences
   - `threejs` & `shader-dev`: 3D canvas and WebGL visualizers
   - `remotion`: Code-driven programmatic video rendering

4. **Component Guidelines**:
   - `shadcn-ui`: Tailwind and Radix UI primitives
   - `swiftui-design`: Apple native iOS/macOS layout patterns
   - `web-design-guidelines`: Responsive layout standards
