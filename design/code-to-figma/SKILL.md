# Code To Figma

Choose and load the complete original native skill for the requested output:

- Component-to-code mappings: `figma:figma-code-connect`.
- An editable screen or composed view from code:
  `figma:figma-generate-design`, with its required `figma:figma-use` prerequisite.

Follow that author's skill and its references. Preserve the native plugin's
ownership and update path; this adapter does not implement its author workflow.

If the selected original skill or Figma connection is missing, the route is
unavailable. Use the host's official Figma plugin setup to install or enable
it, then refresh session exposure. Do not substitute local summarized steps
or claim that an installed package proves a live connection.

## Owner Policy

- Keep the requested target file, nodes, mappings and allowed source scope
  explicit. Preserve unrelated components and repository changes.
- The requested output determines the provider; Code Connect mappings and
  editable screens are distinct deliverables.
- Do not inspect secret-bearing or unrelated private app state for artifacts.
- Report the actual provider, changed node IDs or mapping files, verification
  results and material evidence gaps.
