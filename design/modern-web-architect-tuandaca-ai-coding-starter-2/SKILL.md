# Modern Web Architect Skill

This skill provides guidance on modern web application architecture.

## Key Concepts

- Component-based architecture
- State management patterns (Context, Redux, Zustand, Signals)
- Server-side rendering vs static generation
- API layer design (REST, GraphQL, tRPC)
- Type-safe development with TypeScript
- Module federation and micro-frontends

## Best Practices

- Favor composition over inheritance
- Keep components small and focused
- Use proper error boundaries
- Implement proper loading/error states
- Follow platform conventions
