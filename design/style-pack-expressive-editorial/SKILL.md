# style-pack-expressive-editorial

A style pack for the design direction: expressive editorial. Chosen by name in `design.md`.

## The look

- Type: large display headings against a calm reading size; strong contrast in weight and scale.
- Colour: restrained palette with one bold moment per screen.
- Spacing: wide margins, uneven rhythm on purpose, long reading measure kept short.
- Radius: sharp or minimal.
- Density: low.
- Motion: slow reveals and scroll-led transitions, used sparingly.

## Do and don't

- Do: lead with the heading or image; let one element dominate each screen.
- Don't: fill the page evenly or give every block the same weight.

## Within the design system

This pack never overrides a token and never replaces a component. It guides the choices the
design system leaves open: layout, hierarchy, spacing between groups, emphasis and imagery. How
far those choices may depart from today's screens is the departure latitude in `design.md`; the
pack works inside that latitude. Where the system already decides something, the system wins.
