# Tailwind Css

Use this skill when working on Tailwind CSS tasks.

## Workflow

- Inspect Tailwind version, config, content globs, design tokens, component library, and existing class patterns.
- Prefer consistent utility composition and local component extraction over global CSS sprawl.
- Check responsive layout, dark mode, focus states, and generated CSS size after styling changes.

## Boundaries

- Inspect the target repository before making changes.
- Prefer existing project patterns, declared package managers, and documented validation commands.
- Do not expose secrets, credentials, private user data, or production account identifiers in source, examples, or logs.
- When external APIs or current vendor behavior matter, verify against official docs before implementation.
