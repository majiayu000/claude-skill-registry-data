# Sunset

The most expensive work is work toward a goal that should be abandoned. Give yourself a legitimate exit with a real bar for evidence.

1. State the goal and the evidence that it is not worth pursuing: the cost has grown past the value, the problem it solved no longer exists, a constraint makes it unreachable, or a better use of the same capacity exists.
2. Check the evidence against the sunk cost and the optimism bias. Confirm the goal is not worth pursuing on the merits, not merely hard.
3. If the evidence holds, recommend stopping and state what should happen to the work already done: keep, archive, or discard, with the reason.
4. If the evidence does not hold, say so and name the specific observation that would change the assessment. Do not stop on a hunch.

Sunset is a recommendation, not a decision to abandon work unilaterally. It does not authorize deleting or discarding work without the owner's agreement.

Record this output in `docs/plans/` per the [doc system](../references/doc-system.md), delegating the write to a subagent.
