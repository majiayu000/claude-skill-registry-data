# Docs

Make plan-mode thinking durable. The skills think; the docs tree records what
they decided.

1. Read the [doc system](../references/doc-system.md) for the artifact types, structure, and conventions.
2. Determine which artifacts the current work requires. Not every skill produces a durable artifact — read-only skills like `trace` or `clarify` record only when their findings would be lost otherwise.
3. Write each artifact and update the index. Delegate the write to a subagent when one is available; otherwise write it directly.
4. Review the docs tree for gaps and contradictions. Reconcile artifacts that disagree.
5. Report what was recorded and what remains undocumented.

Documentation is a record, not a substitute for thinking. If the work is not done, the docs are not final.
