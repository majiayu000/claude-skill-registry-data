# Ανάγνωση επιστημονικού άρθρου

Ο στόχος είναι ο φοιτητής να **καταλάβει** το άρθρο αρκετά καλά ώστε να το εξηγήσει, να το κρίνει και να αποφασίσει αν του χρησιμεύει. Μια περίληψη που δεν διαβάζει δεν αρκεί.

Γράφεις στα ελληνικά. Τους τεχνικούς όρους τους δίνεις και στα αγγλικά την πρώτη φορά. Ποτέ δεν επινοείς περιεχόμενο που δεν υπάρχει στο άρθρο: αν κάτι δεν φαίνεται στο κείμενο που έχεις, το λες.

Για PDF χρησιμοποίησε το skill ανάγνωσης PDF που υπάρχει στο περιβάλλον. Για εξαγωγή σε Markdown, το `markitdown`.

## Πέρασμα 1: Ο σκελετός (5–10 λεπτά)

Διάβασε τίτλο, περίληψη, εισαγωγή, επικεφαλίδες, σχήματα, συμπεράσματα. Απάντησε στα «5 C»:

| | Ερώτηση | Απάντηση |
|---|---|---|
| **Category** | Τι είδος paper; (νέα μέθοδος, σύστημα, εμπειρική μελέτη, θεωρία, survey, benchmark) | |
| **Context** | Με ποιες εργασίες συνδέεται; Ποιο πρόβλημα λύνει; | |
| **Correctness** | Φαίνονται λογικές οι υποθέσεις; | |
| **Contributions** | Ποιες είναι οι 2–4 συνεισφορές που δηλώνουν; | |
| **Clarity** | Είναι καλογραμμένο; | |

Απόφαση: αξίζει πέρασμα 2; Για βιβλιογραφική ανασκόπηση πολλών άρθρων, συχνά το πέρασμα 1 αρκεί.

## Πέρασμα 2: Το περιεχόμενο (~1 ώρα)

- **Η βασική ιδέα σε μία παράγραφο**, χωρίς ορολογία, σαν να την εξηγείς σε συμφοιτητή.
- **Μέθοδος**: τα βήματα του αλγορίθμου/συστήματος. Αν βοηθά, ψευδοκώδικας ή διάγραμμα Mermaid (`markdown-mermaid-writing`).
- **Πειράματα**: δεδομένα, baselines, μετρικές, κύρια αποτελέσματα **με αριθμούς από το άρθρο**.
- **Σχήματα**: τι δείχνει το σημαντικότερο σχήμα; Τι σημαίνουν οι άξονες;
- **Άγνωστοι όροι και αναφορές**: λίστα με όσα χρειάζεται να διαβάσει για να καταλάβει.

## Πέρασμα 3: Κριτική (για όσα άρθρα έχουν σημασία)

Σαν να ήσουν κριτής (δες `peer-review`, `scientific-critical-thinking`):
- Ποιες υποθέσεις κάνουν σιωπηρά; Τι γίνεται αν δεν ισχύουν;
- Είναι δίκαιη η σύγκριση με τα baselines; (ίδιο tuning, ίδια δεδομένα, ίδιο compute;)
- Υπάρχουν error bars / πολλαπλές εκτελέσεις / στατιστικά tests;
- Λείπουν ablations; Ποιο κομμάτι της μεθόδου κάνει πραγματικά τη διαφορά;
- **Αναπαραγωγιμότητα**: υπάρχει κώδικας; Δεδομένα; Αρκούν οι λεπτομέρειες για να το ξαναφτιάξεις;
- Τι **δεν** δείχνουν, ενώ το υπονοούν οι ισχυρισμοί τους;

## Μορφή σύνοψης (για σημειώσεις ή ανασκόπηση)

```markdown
# <Τίτλος> (<Συγγραφείς>, <Χώρος δημοσίευσης> <Έτος>)
**Σύνδεσμος/DOI:** ...
**Μία πρόταση:** ...

## Πρόβλημα
## Βασική ιδέα
## Μέθοδος
## Αποτελέσματα (με αριθμούς)
## Δυνατά σημεία
## Αδυναμίες / ανοιχτά ερωτήματα
## Σχέση με τη δική μου εργασία
## BibTeX
```

Το BibTeX το παίρνεις από επίσημη πηγή (DOI, DBLP, arXiv), όχι από μνήμης: `python3 <φάκελος elegxos-vivliografias>/scripts/bibcheck.py doi <DOI>` ή `find "τίτλος"` (δες `elegxos-vivliografias`).

## Παρουσίαση σε σεμινάριο / journal club

Δομή 15 λεπτών: Πρόβλημα & κίνητρο (2') → Βασική ιδέα με ένα σχήμα (3') → Μέθοδος (4') → Αποτελέσματα (3') → Κριτική & ερωτήματα για συζήτηση (3'). Για τις διαφάνειες, δες `scientific-slides` ή Slides στο Claude.

Ετοίμασε και 3 ερωτήσεις για να ξεκινήσει η συζήτηση.

## Πολλά άρθρα: πίνακας σύγκρισης

Για ανασκόπηση, φτιάξε πίνακα με στήλες: Άρθρο | Έτος | Πρόβλημα | Μέθοδος | Δεδομένα | Κύριο αποτέλεσμα | Περιορισμός. Ομαδοποίησε μετά ανά προσέγγιση, όχι χρονολογικά.
