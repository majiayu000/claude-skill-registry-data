# Park

Good ideas rejected for now are lost unless they are written down. Give "no" a home so it stops recurring.

1. State the idea or request and why it is not being done now: out of scope, lower priority, blocked by a dependency, or superseded by a better option.
2. Record it with enough context that it can be understood later: the goal it served, the reason it was set aside, and the trigger that would make it worth revisiting.
3. Place it where it will be seen when the trigger fires — a backlog, a someday list, or a note on the relevant work. An idea parked where no one will look is an idea lost.
4. Confirm to the requester that it was heard and recorded, not dropped.

Parking is not doing. It does not authorize starting the work, and it does not make the idea the parker's responsibility to remember.

Record this output in `docs/plans/` per the [doc system](../references/doc-system.md), delegating the write to a subagent.
