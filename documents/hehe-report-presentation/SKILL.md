# 商业报告呈现

让读者从页面结构中看清研究对象、论证关系和决策用途，同时保留正文的条件、依据和解释。服务研究计划书、行业与企业研究、用户研究及其他专业报告。

## 输入与分工

读取已确认正文或分页脚本、读者、用途、交付形态及品牌要求；上下文已明确的事项直接沿用。

- 文字尚不清楚：先完成专业编辑，可由 `hehe-report-writing` 承接；本 Skill 负责把完整论述安排成清晰的页面。
- 翻页 HTML 或 PPT：以完整主题编排页面，可由 `hehe-report-writing` 的分页模块承接；已有合格逐页脚本直接使用。主标题说明对象与角度，副标题必须用完整陈述说明本页主要意思。
- 下拉报告：直接接收 Markdown，按原标题层级、完整段落及图表组织自然阅读顺序，生成侧栏目录；无需 `hehe-report-writing` 或分页脚本。桌面显示侧栏，窄屏折叠，打印时隐藏导航并按 A4 自然分页。

本 Skill 可独立接收合格正文；上述 Skill 是协作接口，不是安装条件。

首次使用或运行环境变化时，按 [依赖清单.md](依赖清单.md) 检查本次交付所需的 Python、浏览器、字体及验收软件，再开始制作。

## 制作流程

1. **锁定内容。** 保留原稿，建立正文段落、表格单元、数据与来源的对应记录。确定每页或模块的主题、主副标题和读者用途；改版记录内容去向。
2. **先选图，再编排正文。** 读取 [商业报告视觉编排.md](references/商业报告视觉编排.md) 和 [版式与组件选用.md](references/版式与组件选用.md)，识别每个正文页或下拉模块的资金与数据流、阶段、条件分支、结构或数值关系，优先采用对应图式。按 [图形优先与生成检查.md](references/图形优先与生成检查.md) 在页面源记录 `visual_plan`：具体关系、图式、对应对象和完整解释的位置。精确查阅用表格，连续论证可保留正文，并说明选用理由；不能因原稿是长段落就直接选择双栏文字。
3. **确定交付形态。** 按 [多形态交付.md](references/多形态交付.md) 选择画布与阅读样式。16:9、9:16、A4 各自安排栏宽、表格和流程；同一形态在设备上等比显示。下拉版使用自然文档流。已确认风格直接实施；蓝白16:9的封面和章节页沿用 `assets/cover_chapter.json` 的样式。
4. **用真实内容制作代表页。** 先选实际存在的关系图、数量图和需要保留长解释的主题，连同必要的复杂表格制作样张；确认图形能解释关系、完整文字可读后再展开整稿。基础对象见 `assets/example.json`；主次阅读、分支汇合、推导、泳道、甘特、旅程、横向比较和利润构成的完整实例见 `assets/business_layouts.json`。实例为教学假设；逐页比较原文与新页，检查关系是否清楚、事实与解释是否完整。
5. **生成并检查。** 按 [HTML制作与核验.md](references/HTML制作与核验.md) 渲染 HTML/PDF；生成器先检查正文页的图形方案及其实际对象，缺少方案或用文字、表格冒充关系图时停止生成。需要 PPT 时读取 [可编辑PPT交付.md](references/可编辑PPT交付.md)。脚本不按字数、卡片数量或固定页数拆稿。容量不足先调整图文比例、列宽与装饰，再按完整子问题拆页；相邻同主题内容适合一起读时合并。
6. **看整稿及实际页面。** 缩略图检查章节节奏、版式重复与不合理空白，原尺寸检查阅读顺序、换行、图文对应与密度。修正应回到组件或页面源，再重新生成相关交付物。
7. **交付与记录。** 提供用户所需格式、相应 PDF 和可修改源文件。内部记录分别列出执行依据、内容核对、视觉发现与技术结果。注明实际检查范围；候选风格由用户验收后才作为后续风格依据。

## 交付验收

- 陌生读者单看一页能识别对象与意思；主标题、副标题、正文和图表共同支持同一主题。
- 图形的连线、比例、顺序和分组来自材料；图表交代单位、期间、口径、样本或来源，解释与相关数据靠近。
- 逐页对照图形方案与实际页面：图形直接表达关系，表格用于比较或查阅，正文解释理由与条件。加框、图标或把段落搬进表格不算完成关系图；不设每页必有图或全稿图形占比。
- 原稿文字、数字与来源能逐项找到；完整论述留在可见正文。公式的条件、图表注释和有效限制与相关内容相邻。
- 完整计划书保留封面、目录、章节引领和封底；报价独立，抽取后报告仍可阅读。成果报告按其结构配置目录和章节，不套计划书内容。
- PDF 颜色、尺寸、断页与文字正常，浏览器网址及日期页眉页脚关闭。下拉版打印允许自然分页，长表重复表头，完整图形与说明保持相邻。
- PPT 中实际修改文字、表格、图表数据及流程对象，保存后重开并查看渲染；独立插图的可编辑范围在交付说明中列明。
