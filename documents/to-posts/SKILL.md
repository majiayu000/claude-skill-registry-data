# To Posts

Write social posts that fit their channel and serve the campaign's key messages.

1. Read the campaign plan: the key messages, the voice brief, and the cadence. Every post must serve a key message.
2. For each channel, write posts in the native format. X is short and punchy with hashtags. LinkedIn is professional and narrative. Instagram is visual-first with a caption and hashtags.
3. Fit each channel's specs. Check the [platform specs](../references/platform-specs.md) for the character limit and, when the post carries an image, its dimensions. Write the hook inside the visible window — truncation cuts posts where readers decide. A post that exceeds its limit is not a post.
4. Vary the angle. Each post should approach the key message from a different angle — a benefit, a proof, a question, a story. Do not repeat the same post with different words.
5. End each post with a clear call to action that matches the campaign goal.

A post that could be posted on any channel is a post for none. If a post does not fit its channel, rewrite it.

Record this output in `docs/plans/` using the [doc system](../../plan-mode/references/doc-system.md).
