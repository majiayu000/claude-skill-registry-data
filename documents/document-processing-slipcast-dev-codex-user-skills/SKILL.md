# Document Processing

Порядок работы с офисными документами. Конкретные инструменты зависят от активной среды — проверь доступные функции перед началом.

## Общий порядок

1. **Определи формат** (PDF/DOCX/XLSX) и цель (чтение/изменение/создание).
2. **Проверь доступные инструменты** — вызови `list_functions` для поиска `pdf_*`, `docx_*`, `xlsx_*`, `document_*`.
3. **Работай по найденным инструментам** — адаптируй под те, что есть в среде.
4. **После изменения файла** — обязательно сохрани результат (экспорт/save).
5. **Сообщи пользователю путь** к результирующему файлу.

## Типовые операции

### PDF
- Извлечение текста и структуры
- Извлечение встроенных изображений в PNG

### DOCX
- Чтение текста, заголовков и оглавления
- Создание/обновление: добавление в конец, замена текста, структурированное добавление с уровнем заголовка, вставка изображений

### XLSX
- Список листов, чтение ячеек/диапазонов/столбцов
- Поиск текста по координатам
- Изменение ячеек с последующим сохранением

## Проверка
- [ ] После изменения docx/xlsx файл сохранён
- [ ] Структура и форматирование не пострадали
- [ ] Путь к результирующему файлу сообщён пользователю
