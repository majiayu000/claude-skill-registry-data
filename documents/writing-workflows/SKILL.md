# Writing Workflows

Choose the procedure matching the requested outcome below and read only its relevant resources. Paths within a procedure are relative to that procedure's folder. Run its scripts from that folder when a command assumes a working directory.

Current user instructions and repository conventions take precedence over defaults and historical project examples. Keep work proportional to the requested outcome. Reuse existing authorization; seek input only for a missing decision or permission. A procedure does not authorize publishing, spending, deployment or messages to others by itself.

All writing belongs here, including Ponti Studios scripts, social derivatives, podcast copy, and written scene development. Hand approved material to studio-workflows for recording, rendering and assembly.

- [Write Docs](references/write-docs/WORKFLOW.md) — use for repo docs, PRDs and product briefs (sole PRD owner), task plans, audit reports, runbooks.
- [Essay](references/essay/WORKFLOW.md) — use to take an essay from goal and sources to an approved draft.
- [Corpus pipeline](references/corpus-pipeline/WORKFLOW.md) — use to cluster a writing corpus into essay maps, theses, claims and topic maps.
- [Write Video Script](references/write-video-script/WORKFLOW.md) — use to turn a raw thought into a one-take short-form video script (sole owner of short-form scripts from an idea).
- [Write Brief](references/write-brief/WORKFLOW.md) — use to convert a transcript into a brief.
- [Write Incident Report](references/write-incident-report/WORKFLOW.md) — use to write a repo incident report with facts, inferences and fix separated.
- [Phrase Audit](references/phrase-audit/WORKFLOW.md) — use to find stock phrases and their rates across a Markdown corpus.
- [Plan to Tasks](references/plan-to-tasks/WORKFLOW.md) — use to split a plan, spec or PRD into dependency-ordered task files.
- [Workshop Design](references/workshop-design/WORKFLOW.md) — use to design a workshop agenda with deciders, outcomes and a playbook.
- [Master script](references/studio-script/WORKFLOW.md) — use to write the master script JSON that Studio derivatives consume.
- [Shot list](references/studio-scenes/WORKFLOW.md) — use to turn an approved master script into the scene array for video generation.
- [Social clips](references/studio-clips/WORKFLOW.md) — use to derive clip metadata (moment, visual, caption) from a master script.
- [Social posts](references/studio-social/WORKFLOW.md) — use to derive tweet, X and LinkedIn options from a master script.
- [Video scripts](references/studio-video/WORKFLOW.md) — use only to derive YouTube and short-video JSON from an approved master script; for a short-form script from a raw idea, use Write Video Script.
- [Physical production dossiers and certificates](references/kernel-ops-production/WORKFLOW.md) — use for print, archival, conservation and edition language.
- [Interface copy and UX writing](references/interface-copy/WORKFLOW.md) — use to write or critique UI copy.
- [Studio documentation, product emails and marketing](references/studio-documents/WORKFLOW.md) — use for Ponti Studios doc structure, product emails and marketing copy; PRDs go through Write Docs.
