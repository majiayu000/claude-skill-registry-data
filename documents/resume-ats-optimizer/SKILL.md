# 简历 ATS 优化器

## 何时使用此技能

当用户想要：
- 针对申请人跟踪系统（ATS）优化简历
- 检查简历能否通过机器自动筛选
- 弄清楚为什么投递总是石沉大海
- 提及诸如："ATS"、"没有面试"、"简历没效果"、"优化简历"、"关键词优化"等关键词时使用此技能。

当用户提供简历文件并提到正在投递工作时，也使用此技能。

## 核心能力

- 解析简历并测试 ATS 兼容性
- 提取关键词并对照职位描述进行分析
- 找出会破坏 ATS 解析器的排版问题
- 计算简历与职位发布的匹配得分
- 建议应补充的关键词及其位置
- 生成对 ATS 友好的排版建议

## ATS 问题

75% 的简历在没有任何人工查看之前就被 ATS（申请人跟踪系统）淘汰了。公司使用 ATS 来：
- 自动过滤不合格的候选人
- 按职位要求搜索特定关键词
- 把简历解析成结构化数据
- 按关键词匹配比例对候选人排序

简历被 ATS 拒掉的常见原因：
1. 排版糟糕（表格、多栏、页眉/页脚）
2. 缺少职位描述中的关键词
3. 板块标题不统一
4. 使用非标准字体或特殊字符
5. 文字嵌在图片里
6. 文件格式不正确

## ATS 兼容性清单

### 文件格式
- ✅ 使用 .docx 或 .pdf（不要用 .pages、.odt）
- ✅ PDF 必须是文字版，不能是扫描图片
- ✅ 文件命名："姓名_简历.pdf"（如"张伟_简历.pdf"或"Zhang_Wei_Resume.pdf"）

### 字体与排版
- ✅ 标准字体：Arial、Calibri、Georgia、Times New Roman、宋体、黑体等常见字体
- ✅ 字号：正文 10-12pt，标题 14-16pt
- ✅ 不用文本框、表格或多栏布局
- ✅ 不用页眉/页脚（把联系方式放在正文里）
- ✅ 不用图片、图形或图表
- ✅ 日期格式统一（YYYY/MM 或 MM/YYYY）
- ✅ 使用标准项目符号（•、-、*）

### 板块标题
使用 ATS 可识别的标准标题：
- ✅ "工作经历"或"职业经历"（而非"我的历程"）
- ✅ "教育背景"（而非"学业履历"）
- ✅ "技能"（而非"核心素养"）
- ✅ "个人简介"或"职业概述"

### 联系方式
```
张伟
zhangwei@email.com | 138-0000-1234 | LinkedIn：linkedin.com/in/zhangwei
上海
```

不要放在页眉/页脚，并避免：
- ❌ 用表格展示联系方式
- ❌ 邮箱里含特殊字符
- ❌ 写多个电话号码
- ❌ 写完整通信地址（写到城市即可）

## 关键词优化流程

### 第 1 步：提取职位描述关键词

识别三类关键词：

**硬技能（技术类）**
- 编程语言（Python、Java、SQL）
- 工具与平台（Salesforce、AWS、Excel）
- 证书（PMP、CPA、CFA）
- 方法论（Agile、Six Sigma、SDLC）

**软技能**
- 领导力、协作、沟通
- 问题解决、分析思维
- 项目管理、利益相关方管理

**行业术语**
- B2B、SaaS、电商
- 大型企业、中小企业、中端市场
- ARR（年度经常性收入）、MRR（月度经常性收入）、流失率

### 第 2 步：匹配分析

对职位描述里的每个关键词：
1. 检查简历中是否有完全一致的表述
2. 检查是否存在同义词或变体
3. 统计出现频次
4. 记录出现位置（简介、经历、技能）

### 第 3 步：计算匹配得分

```
匹配得分 = (命中的关键词数 / 必需关键词总数) × 100

示例：
职位共要求 20 个必需关键词
你的简历命中其中 15 个
匹配得分 = 75%

目标：80% 以上视为强匹配
```

### 第 4 步：关键词布局策略

**优先级 1：职业简介（简历顶部）**
- 纳入 5-8 个最重要的关键词
- 在 3-4 句的自然段落中使用
- 示例："拥有 5 年以上 Python、SQL 及机器学习经验的数据科学家，致力于用数据驱动业务洞察……"

**优先级 2：技能板块**
- 明确列出关键词
- 必要时按类别分组
- 使用与职位描述完全一致的措辞

**优先级 3：经历条目**
- 把关键词融入成果描述中
- 不要生硬堆砌关键词
- 全篇使用不同的变体表述

**关键词密度指南：**
- 关键关键词：全篇出现 2-4 次
- 重要关键词：出现 1-2 次
- 不要堆砌关键词——保持自然
- 变换措辞（如"带领团队"与"团队管理"交替使用）

## 分析结果格式

分析简历时，按以下结构化报告输出：

```markdown
# ATS 兼容性报告

## 总体得分：[X]/100

### 文件格式检查 ✅/❌
- 格式：[DOCX/PDF]
- 文本提取：[成功/失败]
- 文件大小：[X KB/MB]

### 排版问题
✅ 未检测到表格或多栏
❌ 联系方式在页眉中（应移至正文）
⚠️  技能板块出现了两种不同字号

### 关键词分析

职位要求 vs 你的简历：

**关键关键词（必须具备）：**
✅ 项目管理 - 出现 3 次
✅ Agile/Scrum - 出现 2 次
❌ 利益相关方管理 - 缺失（JD 中出现 5 次）
❌ 预算管理 - 缺失（JD 中出现 3 次）

**重要关键词：**
✅ 跨职能团队 - 出现 1 次
⚠️  "风险管理" - 你的简历写的是"风险缓释"（接近但不完全一致）
✅ 流程改进 - 出现 2 次

**匹配得分：65%**
建议目标：80% 以上

### 建议修改

**1. 补充缺失关键词：**

职业简介中，将：
"经验丰富的项目经理，具有过硬的交付记录……"

改为：
"经验丰富的项目经理，在利益相关方管理与预算统筹方面具有过硬的交付记录……"

在经历板块，新增条目：
"统筹 3 个部门及高管团队的利益相关方沟通"
"负责 250 万元人民币项目组合的预算管理"

**2. 修复排版：**
- 把联系方式从页眉移到简历正文
- 统一技能板块所有条目的字号（目前 10pt 与 11pt 混用）

**3. 强化已有关键词：**
将"风险缓释"改为"风险管理"以实现精确匹配

### 预计修改后匹配得分：85%
```

## 常见 ATS 失败模式

### 模式 1：过度创意的排版
```
❌ 问题：
[带图形的双栏布局]
[技能条与熟练度图表]
[放在彩色文本框里的文字]

✅ 解决方案：
- 单栏排版
- 纯文字形式的技能列表
- 简单的项目符号
```

### 模式 2：标新立异的板块名称
```
❌ 问题：
"我的旅程"（代替"工作经历"）
"我能带来什么"（代替"技能"）
"求学之路"（代替"教育背景"）

✅ 解决方案：
使用 ATS 可识别的标准标题
```

### 模式 3：关键词缺失
```
❌ 问题：
职位要求："Python、SQL、数据可视化"
简历写的是："编程、数据库、画图表"

✅ 解决方案：
直接使用职位描述中的准确术语
```

### 模式 4：关键词堆砌
```
❌ 问题：
技能：Python、Python 编程、Python 开发、Python 专家、Python 达人、资深 Python……

✅ 解决方案：
技能：Python、SQL、JavaScript、React、Node.js
（然后在经历条目中自然融入）
```

## 不同行业的注意事项

### 技术类简历
- 突出编程语言和框架
- 在技能板块中放 GitHub 和作品集链接（不要放页眉）
- 证书与课程非常重要

### 商业/金融
- 侧重软件熟练度（Excel、SAP、Salesforce）
- 证书至关重要（CPA、CFA、PMP）
- 行业关键词（损益、ROI、KPI）

### 医疗健康
- 需列出执照与证书
- 具体系统（Epic、Cerner、MEDITECH）
- 合规关键词（HIPAA、Joint Commission）

### 市场营销
- 平台专长（HubSpot、Salesforce、Google Analytics）
- 渠道关键词（SEO、PPC、邮件营销）
- 注重指标和数据导向的表达

## 边缘情况与特殊情形

### 转行者
- 聚焦可迁移技能
- 使用目标行业的关键词，而不仅是目前行业的
- 可能需要为 ATS 准备两个版本的简历

### 应届毕业生
- 教育背景板块成为关键词的重点来源
- 纳入相关课程和项目
- 实习经历也算工作经验——使用其中的关键词

### 高管层级
- 高级职位同样会经过 ATS
- 聚焦战略性关键词
- 纳入董事会经历、损益规模、团队规模

### 职业空窗期
- 如有帮助，只写年份（不写月份）
- 纳入自由职业/咨询经历及其关键词
- 志愿工作也可以体现相关关键词

## 执行清单

帮用户做 ATS 优化时：

1. ✅ 扫描当前简历的 ATS 兼容性问题
2. ✅ 分析职位描述，提取所需关键词
3. ✅ 计算当前匹配得分
4. ✅ 明确缺失的关键词
5. ✅ 给出新关键词的具体放置位置
6. ✅ 标记排版问题
7. ✅ 提供修改前/后的对比示例
8. ✅ 按建议修改后重新打分
9. ✅ 核对文件格式与命名
10. ✅ 尽可能用 ATS 模拟器测试

## 成效指标

优化完成后，简历应达到：
- 目标职位描述的匹配得分 80% 以上
- 通过 ATS 解析测试（所有板块均可识别）
- 排版零错误
- 每个关键关键词出现 2-4 次
- 读起来自然流畅（没有关键词堆砌感）
- 可立即投递
