# phxstack-interview

Record what the repository cannot reveal. This captures context; use
`phxstack-roast` to pressure-test an idea.

1. Inspect the README, agent instructions, docs, project metadata, and
   important application code.
2. Ask only the three to five questions that remain material.
3. Draft and show the section below.
4. Merge it into the appropriate agent instruction file after approval.

```markdown
## Product context

- **Product:** ...
- **Customer:** ...
- **Demand:** ...
- **Business model:** ...
- **Status quo:** ...
- **Distribution:** ...
- **Not doing:** ...
- **Open questions:** ...
```

Prefer `AGENTS.md` when multiple agent instruction files are suitable. Replace
only an existing Product context section; preserve unrelated instructions.
