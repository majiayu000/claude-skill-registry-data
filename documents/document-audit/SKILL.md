# Document Audit (Sovereign Intelligence)

Habilidade para processar e auditar documentos sensíveis com soberania total.

## Instruções de Uso
Ativar quando o usuário solicitar análise de contratos, relatórios financeiros ou fichas de alunos.

## Capacidades
- **Format Support**: PDF/Docx Parsing e Spreadsheet Intelligence (Excel/CSV).
- **PII Detection**: Identificação automática de dados sensíveis para anonimização.
- **Compliance Reporting**: Geração de relatórios com selo de conformidade LGPD.

## Regras Invioláveis (Zero-Bypass)
1. **No Cloud OCR**: Nunca enviar conteúdo de documentos para serviços de nuvem.
2. **Structure Integrity**: Validar a estrutura do documento antes do processamento em massa.
3. **Privacy Chain**: Acionar obrigatoriamente a skill `LGPD Compliance Guard` em dados extraídos.

## Exemplos
"Audite o contrato de prestação de serviços e extraia as cláusulas de rescisão."
