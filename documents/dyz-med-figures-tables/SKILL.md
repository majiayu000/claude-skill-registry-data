# 医学论文图表规划、生成与核对

## 核心原则

1. 每个图表都服务于一个研究问题；不要按研究类型机械生成整套图表。
2. 数值必须来自同一次成功执行且可追溯的分析输出，不从示例、占位符或稿件文字反向造表。
3. 先做图表计划，再生成代码或文件。源数据缺失时交付规格和缺项，不填入模拟数值。
4. 正文、图表与结构化结果不一致时追溯源脚本和运行日志，不自动选择“看起来正确”的一个。
5. 不自动安装包，也不运行仍含占位符或未经语法检查的脚本。
6. 期刊格式会变化；投稿级导出前核对期刊官网的当前作者指南并记录核对日期。

## 所需输入

- 研究设计、研究问题和预设结局；
- 已执行分析的结果文件、脚本、日志和数据字典；
- 当前稿件及已有图表；
- 目标期刊及其图表数量、尺寸、格式、分辨率和颜色要求；
- 需要交付的可编辑格式和最终提交格式。

## 工作流

### 1. 建立图表计划

为每个候选项目记录：

```text
编号 | 目的 | 数据/结果来源 | 关键字段 | 生成方式 | 输出格式
正文引用位置 | 状态 | 负责人 | 尚缺信息
```

删除不能回答研究问题、与正文重复或无法追溯的数据展示。把流程图列入计划，但交给 `dyz-med-flowchart` 生成。

### 2. 选择最小充分展示

以下只作选择提示，不是强制清单：

| 研究类型 | 常见核心展示 | 条件性展示 |
|---|---|---|
| 随机试验 | 基线描述、主要/次要结局、不良事件 | 生存曲线、预设亚组图 |
| 观察性研究 | 人群描述、调整前后效应估计 | 生存曲线、剂量反应、影响诊断 |
| 系统综述/Meta | 研究特征、风险偏倚、合并效应 | 小研究效应图、影响分析 |
| 诊断准确性 | 2×2 数据、敏感度/特异度及区间 | ROC 或分层森林图 |
| 预测模型 | 模型表现、校准图 | 决策曲线，仅在方法和数据支持时 |
| 定性/范围综述 | 参与者或证据来源特征、主题/证据地图 | 时间、地域或证据缺口图 |

漏斗图通常只在研究数量和方法条件足够时考虑；不对称检验一般至少需要 10 项研究，还要按效应量选择方法。
不把不对称直接标为发表偏倚。不要为美观生成 3D 图、双轴图或没有不确定性表达的装饰图。

### 3. 生成表格

- 明确分析人群、分母、缺失值、单位、参考类别、效应量和区间水平。
- RCT 基线表以描述为主，不做基线显著性检验，也不按基线 `P` 值决定调整变量。
- 观察性研究列出每个模型的调整集及选择依据。
- 回归表报告模型样本量、事件数、估计值、区间、单位和必要诊断。
- 系统综述区分研究、报告和结局行；Summary of Findings 只有在完成相应证据体评估后生成。
- 保留可编辑表格，并另存最终投稿格式。

### 4. 生成统计图

- 从实际输入模式生成最短可复现脚本；不要套用字段未核对的通用代码。
- 对比值型效应使用正确的对数轴和无效线，对差值型效应使用线性轴和零线。
- 展示区间、删失、风险集、样本量或其他理解图形所必需的信息。
- 亚组图优先展示交互检验，不用“某亚组显著、另一亚组不显著”推断组间差异。
- ROC、校准、决策曲线和阈值应对应独立验证或明确的数据集与时间点。
- 使用色盲友好配色、可读字号和清晰图例；颜色不作为唯一编码。

生成后必须：

1. 运行语法检查；
2. 在当前环境执行脚本；
3. 检查退出状态和警告；
4. 保存软件版本、脚本、日志和输出；
5. 目视检查裁切、字体、图例、轴、面板和分辨率。

若环境无法执行，交付标为 `not_rendered` 的脚本和依赖清单，不声称图已生成。

### 5. 核对图、表、正文

使用[图文一致性清单](templates/figure-text-consistency-checklist.md)，至少检查：

- 样本量、事件数、分母和分析人群；
- 估计值、区间、`P` 值、单位、方向和参考组；
- 允许的四舍五入差异；
- 图表编号、正文引用、补充材料引用和文件存在性；
- 同一结局的时间点、调整集和数据版本；
- 图注与图中实际内容是否一致。

状态使用：

- `MATCH`：来自同一结果且在允许的舍入范围内；
- `MISMATCH`：数值或定义冲突；
- `MISSING_SOURCE`：无法追溯到执行输出；
- `NOT_CITED`：图表存在但稿件未引用；
- `MISSING_FILE`：稿件引用但文件不存在。

### 6. 写标题、图注和脚注

标题说明展示对象与设计，不重复正文结论。图注/表注按需要写明：

- 人群、分析集、结局、时间点和单位；
- 效应量、区间、参考线和调整集；
- 缺失数据、删失、误差条或模型说明；
- 面板、颜色、线型和符号含义；
- 缩写全称及统计检验。

不要固定加入 `*P<0.05` 星号体系；仅在期刊要求且多重性和检验定义清楚时使用。

### 7. 按期刊要求导出

从期刊官网记录核对日期和要求，再决定 TIFF、EPS、PDF、PNG、DOCX 等格式、尺寸、DPI、颜色空间和字体嵌入。
矢量图优先保持矢量；线稿、照片和组合图按期刊各自要求处理，不套用一个固定 DPI。

## 输出

建议交付：

```text
paper/data/figures/figure-plan.yaml
paper/analysis/figures/
paper/data/figures/
paper/data/tables/
paper/evidence/display-items.md
paper/data/figures/consistency-report.md
```

目录可适配现有项目。每个最终文件都应指向来源结果、生成脚本、运行日志和期刊规格记录。

## 完成标准

- [ ] 每个图表有明确目的和可追溯来源
- [ ] 没有占位数据、未执行结果或无必要展示
- [ ] 生成脚本通过语法检查并真实执行，或明确标为未渲染
- [ ] 图表、正文和分析输出已核对
- [ ] 标题、图注、脚注和缩写完整
- [ ] 可访问性和目视检查通过
- [ ] 当前期刊规格及核对日期已记录
