# Template Creator

- Require a real source artifact and identify its file type before changing anything.
- Preserve layout, styles, formulas, masters, and reusable assets; replace instance-specific content with explicit placeholders.
- Store the template and a short UTF-8 usage guide in a dedicated workspace template folder.
- Verify that a fresh copy can be opened and that the original source remains unchanged.
