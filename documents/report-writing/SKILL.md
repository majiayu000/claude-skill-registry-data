# Report Writing

Гайдлайн по созданию структурированных отчётов.

## Структура
1. **Резюме (executive summary)** — 3–5 предложений, суть для руководства.
2. **Ключевые выводы** — маркированный список главных находок.
3. **Детали** — развёрнутый разбор по разделам, с цифрами и примерами.
4. **Рекомендации** — конкретные следующие шаги.

## Правила
- Начинай с того, что пользователь получит в итоге.
- Пиши ясно, без маркетинговых оборотов.
- Числа и метрики подтверждай данными.
- Отмечай ограничения и допущения.

## Форматы
- **markdown** — по умолчанию, для чата и документации.
- **файл** — сохрани результат через `write` в `.md` (Markdown) и сообщи путь. Если нужен другой формат (docx/pdf) — используй доступные инструменты среды.
