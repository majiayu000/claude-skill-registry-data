# 캠페인 브레인스토밍 에이전트

RFP 없이 캠페인 아이디어부터 시작하는 워크플로우.
3인 전문가 에이전트가 독립 브레인스토밍 → 크로스리뷰 토론 → 최적안 구조화.

---

## 워크플로우 (5-Step)

### Step 1: 캠페인 정보 수집
- 브랜드/제품명, 캠페인 목표, 타겟, 예산, 기간
- 기존 자료 (PDF, URL 등) 수집

### Step 2: 3인 에이전트 개별 브레인스토밍 (병렬)

**전략가 (Strategist)**:
- PEST + 3C 분석
- 타겟 페르소나 3개
- 전략 방향 3안 (포지셔닝 맵)
- Win Theme 3개 초안

**크리에이터 (Creator)**:
- 빅 아이디어 3안 (크리에이티브 컨셉)
- 메시지 체계 (핵심 메시지 + 서브 메시지)
- 채널별 콘텐츠 기획 (디지털/오프라인/PR)
- 바이럴 포인트 설계

**데이터 분석가 (Data Analyst)**:
- KPI 체계 수립 (인지도/전환/매출)
- 벤치마크 수치 (유사 캠페인 성과)
- 예산 배분 시뮬레이션 (채널별 ROI 추정)
- 3단계 성과 시나리오 (보수/기본/낙관)

### Step 3: Agent Teams 토론 (3라운드)

**Round 1**: 크로스리뷰 — 각 에이전트가 다른 2명의 아이디어에 피드백
**Round 2**: 의무적 반론 — 각 에이전트가 반드시 1개 이상 반론 제기
**Round 3**: 통합 — 최적안 도출 (사용자 선택 기반)

### Step 4: 기획안 구조화 → `campaign_brief.md`

```markdown
# Campaign Brief: [캠페인명]

## 1. 캠페인 개요
- 브랜드, 목표, 기간, 예산

## 2. 타겟 & 인사이트
- 핵심 타겟 페르소나
- 핵심 인사이트 (Pain Point)

## 3. 전략 방향
- 포지셔닝
- Win Theme 3개

## 4. 크리에이티브 컨셉
- 빅 아이디어
- 메시지 체계
- 채널별 콘텐츠 기획

## 5. 실행 계획
- 타임라인, 채널별 예산 배분

## 6. KPI & 성과 예측
- KPI 체계, 벤치마크, ROI 시나리오
```

### Step 5: 제안서 파이프라인 연계

- `campaign_brief.md`를 `output/테스트 XX/`에 저장
- `/p 테스트 XX` 실행 → 스마트 시작이 `campaign_brief.md` 감지 → **Step 3(스크립트)부터 시작**
- campaign_brief.md의 Win Theme, 타겟, KPI를 스크립트 입력으로 직접 활용
- 별도 RFP 분석 + 리서치 불필요 (이미 브레인스토밍에서 수행)

---

## 산출물

```
output/테스트 XX/
├── brainstorm_strategy.md      ← 전략가 산출물
├── brainstorm_creative.md      ← 크리에이터 산출물
├── brainstorm_data.md          ← 데이터 분석가 산출물
├── brainstorm_discussion.md    ← 토론 기록 (3라운드)
└── campaign_brief.md           ← 최종 브리프 (제안서 연계용)
```

---

## 핵심 원칙

- **의무적 반론**: Round 2에서 각 에이전트는 반드시 1개 이상 반론 필수
- **사용자 선택권**: 최종안 선택은 사용자가 결정
- **데이터 기반**: 모든 KPI/예산에 벤치마크 근거 필수
- **제안서 연계**: campaign_brief.md → proposal_script.md 자동 연결
