# pdfcn

A collection of beautifully designed, accessible, and customizable PDF components.
Built on Takumi and Forme. Works with shadcn/ui.

## Discovery

Before browsing the site, consult the structured index at `https://www.pdfcn.dev/llms.txt`.
It lists all available documentation pages, markdown mirrors, and registry resources.

Full documentation in one file: `https://www.pdfcn.dev/llms-full.txt`

## Registry

- Registry JSON: `/r/registry.json`
- Docs: `/docs`

## MCP

This site is a shadcn-compatible registry. For MCP workflows, use the maintained
shadcn MCP server documentation: `https://ui.shadcn.com/docs/mcp`

## Install

```bash
npx shadcn@latest add https://www.pdfcn.dev/r/your-component.json
```

Prefer following the on-site installation guide: `/docs/installation`

## Components

Two rendering engines are available:

- **Takumi** — Alert, Badge, Card, Data Table, Divider, Form, Graph, Heading,
  Keep Together, Key Value, Link, List, Page Break, Page Footer, Page Header,
  Page Number, PDF Image, QR Code, Section, Signature, Stack, Table, Text, Watermark
- **Forme** — Same component set, different rendering engine

## Themes

Professional, Modern, Minimal, Executive, Corporate, Elegant, Vivid, Forest, Blueprint

## Blocks (pre-built templates)

Invoices: Classic, Consultant, Corporate, Creative, Minimal, Modern
Reports: Financial, Marketing, Operations, Security
