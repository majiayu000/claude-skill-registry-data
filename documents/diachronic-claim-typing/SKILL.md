# 通時的主張の型付けスキル (Diachronic Claim Typing)

## 目的

時代をまたいで規範・実践・制度をつなぐ論文で、**主張の型を先に決めてから**文献を選び、断面を設計し、接続文を書く。型が証拠に見合わないときは主張を縮小する。通史の書き方講座ではない。

系譜学は通史ではなく**断面の選択的接続**である。禁止するのは、選択を通史として読ませることである。

## 発動タイミング

- 研究計画が概念史・系譜学・思想史・制度史・受容史、または成立／変容の経緯を含むと判明した時
- 古典・校訂本・法令・試験制度・紀要一次が、OpenAlex 等の論文APIの外にありそうな時
- 章・節で「〜から」「翻案」「連続」「現代に固有」など時代をまたぐ接続文を書く前
- チェリーピッキング・アナクロニズム・伝播の証拠不足を指摘された時

**非発動**: 単一年次の実証、時代接続を主張しない横断サーベイ。その場合は [`literature-search`](../literature-search/SKILL.md) と [`claim-evidence-gate`](../claim-evidence-gate/SKILL.md) で足りる。

## 主張の型

各通時的主張に次のいずれか**一つ**を付ける。複合なら文を分割する。

| 型 | 主張していること | 必要な証拠 | 失敗 | フォールバック |
| :--- | :--- | :--- | :--- | :--- |
| **T0 本文存在** | 史料 S に文または記録 X がある | 参照キー（校訂本・書き起こし ID・目録番号等）＋ `literature/papers/` の検証済み抜粋 | 頁の捏造、未読二次の外挿 | 引用しない |
| **T1 解釈** | 当該テクスト内部で X は Y と読める | T0 ＋代替読みの承認 | 一意の意味に固定 | 「読みうる断面」 |
| **T2 制度** | 実践が制度・教育の一部門だった | 規程・教科書・事例の一次 | 一事例の全国化 | 事例命題に限定 |
| **T3 伝播** | A が B として翻訳・導入・名指し受容された | 翻訳書誌、導入の一次、後続の名指し引用 | 類似＝因果 | T3b |
| **T3b 並置** | A と B の構造的類似を示す（因果は主張しない） | 双方の T0 ＋類似の写像 | 類似なき並置 | 節を書かないか主張を削る |
| **T4 連続** | 方法や規範が期間 P まで続いた | 連続を論じる一次、または複数時点の一次 | 古典二点で「〜まで」 | 断面のみ |
| **T5 新規性** | 時期 P の条件は種類として新しい | 敵対的還元（量／時間、程度差）に耐えること | 依拠する歴史家が先に連続・先例を書いている | 程度差、または規範と実践の矛盾の可視化 |

**受容**（「読まれてきた」「受容史として用いる」）は他者の解釈行為の主張である。証拠要件は **T3**。T1 はテクスト内部の読みに限る。受容の一次が無ければ T1 の「読みうる」に弱める。

### 禁則 N1（非同一視）

型ではない。全型に課す。過去の行為者が本稿の造語概念を保持していた、とは書かない。例外は、その行為者自身の明示的な自己同一視がある場合のみ。

## 処理手順

### Step 1: 論文型とインベントリ

`research-plan.md` の方法論を読む。通時的でなければ終了する。

通時的なら、文献検索の**前に** `docs/<paper-id>/design/sot/diachronic-claim-inventory.md` を作る（単一論文リポジトリでは `docs/design/sot/`）。章・節ごとに書きたい接続を仮の T 型で置く。

```markdown
| 節 | 主張（1文） | 型 | 証拠（papers/ と参照キー） | フォールバック |
```

`paper-outline.md` がある場合、節メモに型 ID を1行転写する（同期用。詳細はインベントリが正本）。

### Step 2: 選択基準と対抗系譜

検索を始める前にインベントリへ1段落で書く。

1. **選択基準**（正典性、制度への埋め込み、OA 一次が取れること等。使う基準を明示）
2. **対抗系譜**: 査読者が挙げそうな**最強**のものを1つ名指し、選ばない理由を書く（弱い代替の藁人形は不可）
3. **「成立」等の意味**: 網羅的起源ではなく、反復して観測できる起点の特定、など

### Step 3: 一次の層と検索チャネル

1. 通史・概説は Discovery に留め、引用根拠にしない。依拠する古典・法令・一次論文へ降りる。
2. 一次にアクセスできない場合は、当該 T 型の主張を縮小するか節を書かない。購入・購読の可否は**プロジェクト方針**に従う（本スキルは購入を命じない）。
3. 論文APIの対象外（古典デジタルライブラリ、J-STAGE、CiNii、機関リポジトリ等）は WebFetch と manual-stub で接地する。v1.0 で新APIは足さない。
4. その後（または並行して）[`literature-search`](../literature-search/SKILL.md) を使う。

### Step 4: 接続テスト（T3 / T3b / T4 / T5）

- **T3**: 翻訳・導入一次・名指し引用のどれかがあるか。無ければ T3b。
- **T3b**: 双方の T0 と、何が類似かの写像があるか。
- **T4 / T5**: 依拠する歴史家本人が連続や先例を書いていないか。敵対的還元（速度＝量／時間、必須性＝程度差、二点≠通時連続）に耐えるか。耐えないならフォールバックをインベントリに書き、それを章の執筆開始条件にする。

[`literature-gap-analysis`](../literature-gap-analysis/SKILL.md) の新規性が「系譜の接続」なら、T3 未通過時は「並置・比較」へ直す。

### Step 5: 起稿前チェック

- [ ] 屋台骨主張に T 型が付いている
- [ ] T0 は stub の抜粋範囲内
- [ ] T3/T4/T5 はテスト通過、またはフォールバック済み
- [ ] **N1**: 歴史的行為者＝造語概念を主張していない
- [ ] 同じ分析語（内部、記憶、能力等）が断面で指示対象を変えるなら、分析的構成物であると接続部で明示する
- [ ] 選択基準と最強の対抗系譜が、検索前の記録としてインベントリにある
- [ ] 通史化文体: 「その後」「こうして発展した」「受け継がれて」等が、選択を隠して空白を埋めていないか。章冒頭で選択性を明示しているか

通過後に [`counter-argument-tdd`](../counter-argument-tdd/SKILL.md) へ進む。

## 不変条件

- インベントリは文献検索の前に始める（選択基準の事後合理化を防ぐ）
- `literature-matrix.md` は索引。引用根拠は `literature/papers/`
- 類似は T3 を満たさない
- 本文（`docs/chapters/`）に T0・N1 等の内部記号を出さない

## やらないこと（v1.0）

通史講座、個別分野の史学教科書化、CiNii/J-STAGE の検索スクリプト、違法入手。将来の機械化候補（通史化接続詞の lint、「受容されてきた」＋引用なし、造語概念と過去行為者の共起）は手動チェックに留める。
