# 证据材料整理

## 概述

接收用户的案件文件后，自动完成两项工作：
1. **生成证据清单 Word 文档**：按固定模板格式编写，无需读取任何格式模板
2. **生成证据材料 PDF 合集**：将全部证据材料按顺序合并，A4 竖版，添加页码

**无需读取格式模板**——格式已固定为本技能内置标准模板。

---

## 工作流程

### 第一阶段：读取文件

读取用户提供两类文件：

| 文件类型 | 用途 | 读取方式 |
|---------|------|---------|
| **起诉状/案情材料**（.docx） | 了解案件背景、证据关系、当事人信息 | `python-docx` 读取文字 |
| **证据材料**（PDF/JPG） | 提取关键内容，确定证据名称、页数 | `pdfplumber` / `fitz` 提取文字 |
| **收条照片**（JPG） | 照片转 PDF 加入合集 | PIL 读取原文件，不做 OCR |

**注意：**
- `.doc` 文件用 LibreOffice 转换：`python scripts/office/soffice.py --headless --convert-to docx file.doc`
- JPG 照片直接用 PIL 读取，不做 OCR（照片内容在起诉状中应有文字引用）

### 第二阶段：分析证据材料

从每份 PDF 中提取关键内容：

1. **文件名** → 作为证据名称（注意文件名中的日期、案号）
2. **页数** → 计算在 PDF 合集中的起止页码
3. **关键页关键词** → 辅助编写"证据主要内容及证明对象"

### 第三阶段：生成证据清单 Word 文档

**直接按以下固定模板生成，无需参照任何外部模板文件。**

#### 文档结构

```
【标题】[原告]诉[被告][案由]纠纷案证据目录（原告提交）

【表格】四列
【落款】提交人（原告）：______________    日期：_____年_____月_____日
【页脚】第 1 页 共 2 页
```

#### 表格格式

| 列 | 内容要求 |
|----|---------|
| 编号 | 组标题行：整行合并单元格；证据行：`1.1`、`2.1` 格式 |
| 证据名称 | 法院文书：法院 / 案号 / 文书类型 三行排列；收条：写"收条" |
| 证据主要内容及证明对象 | 以"证明："开头，简洁概括证明内容 |
| 页码 | 证据在 PDF 合集中的起止范围；引用具体内容时加注（第X页） |

#### 组标题行（整行合并单元格）

```
第一组证据：证明 [一句话整体证明目的]
第二组证据：证明 [一句话整体证明目的]
```

#### 证据编号

```
1.1  收条（两张，分别标注两张收条各自的形成时间）
2.1  江苏省扬州市江都区人民法院（2022）苏1012民初2775号民事判决书
2.2  民事上诉状（郭长平，2022年10月31日）
2.3  江苏省扬州市中级人民法院（2023）苏10民终213号民事裁定书
2.4  江苏省扬州市江都区人民法院（2023）苏1012民初3667号开庭笔录（2023年7月17日）
2.5  江苏省扬州市江都区人民法院（2023）苏1012民初3667号民事判决书（发回重审后）
2.6  江苏省扬州市江都区人民法院（2025）苏1012民申3号民事裁定书
2.7  江苏省扬州市江都区人民法院（2025）苏1012民再4号开庭笔录（2025年10月15日）
2.8  江苏省扬州市江都区人民法院（2025）苏1012民再4号民事判决书（再审终局判决）
（以此类推，2.n 顺延）
```

#### 证明内容写作规范

- **以"证明："开头**，直接说明该证据能证明什么，不写"证据内容摘要"
- **引用原文关键语句**时，句末附`（见原判决书第X页）`
- **不堆砌原文**，以概括为主，精炼表达
- **证据推导要有边界**：收条只能证明"收款"，不能证明"未转交债权人"——证明内容不得超出证据本身所能证明的范围
- **判决类证据**：不只写"判决认定XXX"，要写"判决认定XXX，印证/证明YYY"

#### 页码列格式

```
第1-2页                      ← 收条（仅标注起止）
第3-7页                      ← PDF 文件（仅标注起止）
第3-7页（第6页）             ← 引用了第6页内容时，加注具体页
第25-36页（第33页、第34页）  ← 引用了多页时用顿号分隔
```

#### 落款

```
提交人（原告）：______________    日期：_____年_____月_____日
```

#### 页脚（自动添加）

```
第 1 页 共 2 页
```

### 第四阶段：生成 PDF 合集

#### PDF 合集格式规范

| 要求 | 实现方式 |
|-----|---------|
| 页面竖版 | 横向页面逆时针旋转90°，旋转后原顶部内容位于左侧 |
| A4 尺寸 | 所有页面统一 210×297mm |
| 不裁剪内容 | 大幅面扫描件（开庭笔录等）按比例缩放至 A4 内，留 5mm 窄边框 |
| 收条照片 | 旋转后填满页面（不缩放，保持原始字体大小） |
| 页码 | 每页底部居中，12pt，格式：`1`、`2`、`3` … |

#### PDF 合集顺序

按证据清单中的编号顺序排列。

## 格式速查

### 证据清单

```
【标题】[原告]诉[被告][案由]纠纷案证据目录（原告提交）

【表格】
编号 | 证据名称 | 证据主要内容及证明对象 | 页码
（组标题行整行合并，写明整体证明目的）
1.1 | 收条 | 证明：1. …；2. … | 第1-2页
2.1 | 法院名称 / 案号 / 文书类型 | 证明：… | 第3-7页（第6页）

【落款】提交人（原告）：______________    日期：_____年_____月_____日
【页脚】第 1 页 共 2 页
```

### PDF 合集

```
收条第1页 → 收条第2页 → 证据2.1 → 证据2.2 → ……
每页底部居中页码（12pt）
横向PDF旋转90°逆时针；大幅面扫描件等比缩放留窄边框
```

## 写作规范（从实务中总结）

1. **证据推导有边界**：收条只能证明"收款"，不能证明"未转交债权人"
2. **避免指代不明**："其"改为明确名词，必要时直接引用原文
3. **引用标注页码**：证明内容中引用原文时，句末附"（见原文第X页）"
4. **判决类证据写"证明什么"**：不只写判决内容，要写"判决认定/印证了XXX"
5. **工作提示不写入文书**：提示写在对话中，不写入提交法院的证据清单
6. **落款按文书类型匹配**：起诉状=具状人，证据清单=提交人，申请书=申请人
