# To Schedule

Map every asset to a channel and a date so the campaign publishes itself.

1. Read the campaign plan: the channels, the cadence, and the key messages. The schedule must respect the cadence.
2. For each asset, assign a channel and a date. A post without a date is a post that will not be published.
3. Space the posts according to the cadence. A launch is a burst; an ongoing campaign is a rhythm. Do not post everything on one day unless the plan says so.
4. Check for conflicts. Two posts on the same channel on the same day is a conflict unless the plan calls for it.
5. Write the schedule as a table: date, channel, asset, and a one-line description. Present it for approval before publishing.

A schedule that does not respect the cadence is not a schedule. If the spacing is wrong, fix it.

Record this output in `docs/plans/` using the [doc system](../../plan-mode/references/doc-system.md).
