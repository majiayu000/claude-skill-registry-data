# 医学论文方法部分撰写

## 核心原则

1. 方法部分描述“实际做了什么”，不能用标准模板替代真实研究记录。
2. 研究方案、注册记录、数据字典、统计分析计划和实际代码之间有冲突时，先列出冲突，不能擅自选一版。
3. 不编造研究日期、样本量依据、纳排标准、伦理信息、软件版本、模型设定或缺失数据处理。
4. 协变量应依据研究问题、因果结构、临床知识和预设方案选择；不能仅凭 Table 1 的 P 值筛选混杂因素。
5. 不把预测模型性能、统计显著性或方法名称写成研究质量的替代指标。

## 所需输入

尽量读取：

- 研究方案、注册记录及适用的报告规范；
- 研究设计、场所、时间、参与者来源和纳排标准；
- 暴露、干预、比较、结局、协变量及测量时间点；
- 数据来源、缺失值定义、偏倚控制和样本量依据；
- 统计分析计划、实际执行代码或输出、软件及版本；
- 伦理审批、知情同意、资助和数据可用性事实。

关键事实缺失时，先交付“方法信息缺口表”；可以起草已确认部分，但将未确认处留在内部待办中，不把占位符
混进可投稿正文。

## 工作流

### 1. 选择研究类型结构

依据实际稿件类型组织小节，例如观察性研究、随机试验、诊断准确性研究、预测模型、系统综述、定性研究、
病例报告或动物研究。核对当前适用的报告规范版本；模板只作提醒，不证明合规。

### 2. 写研究设计与参与者

说明设计、场所、时间范围、招募或抽样方式、纳排标准、分组或随机化过程，以及实际分析人群。不得把
回顾性研究写成前瞻性，也不得把便利样本写成随机样本。

### 3. 写变量与测量

明确主要和次要结局的定义、测量工具、时间点、单位和判定者；说明暴露或干预、协变量、数据来源及质量控制。
量表、阈值和分类切点需要来源或预设依据。

### 4. 写偏倚控制与统计方法

逐个主要模型说明：

- 分析对象、结局、效应量和模型；
- 未调整与调整分析及协变量集；
- 协变量选择依据；
- 缺失数据处理、模型假设和诊断；
- 聚类、重复测量、删失、竞争风险或加权等结构（如适用）；
- 多重比较、亚组和敏感性分析是否预设；
- 使用的软件、版本和关键包（以实际记录为准）。

不根据组间基线检验结果自动增删协变量。若作者的数据驱动选择可能带来偏倚，单独标注并建议方法学确认。

诊断描述引用实际计划与诊断记录，沿用[模型诊断证据记录](../dyz-med-analyze/templates/statistical-analysis-plan.md#4-统计方法选择及理由)：
按当前模型记录评估了什么、观察结果与输出/图定位、适用假设及局限、证据不足或发现问题时的获批处置。
只写实际完成的评估，不把未显著的诊断P值写成假设成立的证明；检验与图形不一致时保留冲突。缺资料标为
`unverified` 并列入信息缺口，不断言模型无效，也不代替统计人员自动换模型。

### 5. 写适用的声明

只写与研究类型和目标期刊相关、且已经确认的伦理审批、知情同意或豁免、注册、资助者角色和数据可用性信息。
数据受隐私、伦理或第三方协议限制时应如实描述；不强迫承诺公开，也不使用虚构仓库或登录号。

### 6. 一致性复核

核对方法与研究问题、主要结局、结果表格和实际分析一致。方法中预设的分析应能在结果中找到去向；新增或
事后分析必须有明确标记。

## 输出

默认写入 `paper/sections/02-methods.md`。非专业合作者需要时，可另用
[通俗解释模板](templates/plain-language-explanation.md)记录关键方法选择，不把内部解释混入正文。

## 验收标准

- 研究设计、对象、变量和统计方法可由现有材料复核；
- 每个主要模型有清晰效应量、协变量与处理规则；
- 缺失、冲突和未确认事实被显式记录；
- 伦理、注册、资助和数据声明均来自真实信息；
- 正文不含占位符、虚构内容或独立参考文献列表。
