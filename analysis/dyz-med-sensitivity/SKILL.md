# 医学研究敏感性与稳健性分析

## 核心原则

1. 从可能影响结论的具体假设或偏倚出发，不按研究类型机械执行一套固定分析。
2. 保留预设主分析，不为恢复统计显著性而选择替代模型、删样本或调整阈值。
3. 尽量在看主要结果前预设敏感性分析；事后新增的分析明确标为探索性。
4. 比较估计值、区间、方向、临床解释和样本量，不以 `P` 值是否跨过 `0.05` 单独定义“稳健”。
5. 每次分析保存实际输入、代码、参数、日志和输出；没有执行结果时只交付计划。
6. 无通用 E-value、缺失率或异质性阈值可自动判定 `PASS/FAIL`。

## 所需输入

- 主分析的研究问题、estimand、分析人群、模型和结果；
- 数据版本、脚本、诊断和缺失数据信息；
- 预设方案、注册或统计分析计划中的敏感性分析；
- 需要检验的具体担忧及其可辩护的替代假设；
- 临床重要阈值（若要判断结论是否发生临床层面的变化）。

无法取得可复现的主分析时，先列出缺项，不从稿件中的手工数值反推新分析。

## 工作流

### 1. 定义目标不确定性

对每项敏感性分析写清：

```text
担忧 → 为什么可能影响主结果 → 要改变的一个假设/选择
保持不变的部分 → 比较指标 → 预期输出 → 是否预设
```

一次只改变可解释的因素；同时改变多项时不能判断是哪项驱动差异。

### 2. 按问题选择分析

| 担忧 | 可考虑的分析 |
|---|---|
| 缺失结局或失访 | 完整病例与主要方法对照、合理的多重插补、delta 调整、tipping-point、极端情景 |
| 模型设定 | 预先合理的函数形式、链接函数、方差估计、聚类结构或影响点分析 |
| 协变量与混杂 | 基于临床/因果依据的替代调整集、定量偏倚分析；不要用单因素 `P` 值逐步筛选 |
| RCT 分析人群 | 按 estimand 比较 ITT、治疗策略、符合方案或安全性人群；说明每种人群回答的问题 |
| 观察性研究未测量混杂 | E-value（适用时）或带可辩护参数的定量偏倚分析 |
| Meta 分析 | leave-one-out、预设风险偏倚排除、替代异质性估计量、固定/随机效应对照、影响诊断 |
| 诊断准确性 | 阈值变化、验证偏倚、疾病谱变化和参考标准假设 |

只有在研究数和方法条件足够时才评估小研究效应。按当前 Cochrane Handbook 的经验规则，漏斗图不对称检验
通常至少需要 10 项研究，还要考虑研究规模是否相近及效应量适用的检验。漏斗图不对称或 Egger 检验不能
单独证明发表偏倚，trim-and-fill 也不能作为自动“纠偏”后的主结果。

### 3. 审批并执行

- 把敏感性分析计划和事后状态展示给用户。
- 涉及新代码、重跑数据或改变分析人群时，先获得明确批准。
- 复用主分析的已验证读取、清洗和结果导出路径；不要另建一套不一致的数据处理。
- 除被检验因素外，尽量保持结局、时间点、效应尺度和人群定义不变。
- 缺少软件或包时报告依赖，不自动安装。
- 运行失败或假设不适用时保留失败记录，不用另一个“能跑通”的方法静默替换。

### 4. 谨慎使用 E-value

- 先确认因果效应方向、无效值、区间和效应尺度。
- 只对可按风险比尺度解释的结果直接使用标准公式；OR、HR、连续结局等按原方法要求转换并记录假设。
- 优先使用经过验证的实现或原始方法说明，不手工套用不适用的近似。
- 对保护性效应使用倒数，并采用离无效值最近的区间界计算区间 E-value。
- 同时报告点估计和区间 E-value，并与本研究中已测混杂因素的合理强度比较。
- 不用 `1.3`、`1.5` 或 `2.0` 等通用切点自动标记脆弱或稳健。

E-value 只量化一种未测量混杂情景，不能处理选择偏倚、测量误差、模型错误或所有未测混杂结构。

### 5. 比较并解释

使用[敏感性分析记录表](templates/sensitivity-analysis-log.md)，对每次分析记录：

- 与主分析相比改变了什么、为什么；
- 样本量、事件数、估计值、区间和诊断；
- 效应方向、大小和临床解释是否实质改变；
- 结论是 `robust`、`not_robust` 还是 `uncertain`，以及判定依据；
- 是否预设、是否发生执行偏离。

“稳健”只表示在已检验的合理假设范围内结论相近，不表示研究没有其他偏倚。

### 6. 交付

建议生成：

```text
paper/analysis/sensitivity-plan.md
paper/analysis/sensitivity.<R|py>
paper/data/stats/sensitivity-results.<json|yaml>
paper/data/stats/sensitivity-report.md
paper/data/stats/sensitivity-run.log
```

若只收到汇总结果而没有数据/脚本，交付审阅表和待执行计划，不虚构复分析结果。把关键不稳健或仍不确定的部分
交给讨论/局限性写作；不要阻止用户继续工作，但要保留醒目标记。

## 完成标准

- [ ] 每项分析对应一个明确不确定性
- [ ] 主分析未被覆盖，预设与事后分析已区分
- [ ] 输入、代码、参数和输出可追溯
- [ ] 稳健性判断比较效应量、区间和临床解释
- [ ] E-value 的尺度、方向、区间界和假设已核对
- [ ] 没有把漏斗图不对称直接称为发表偏倚
- [ ] 未执行的分析没有被写成结果
