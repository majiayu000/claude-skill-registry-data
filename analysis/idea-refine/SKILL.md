# Idea Refinement

Take an existing idea document and improve it through critical analysis.

## Process

1. Read `docs/idea.md` (or the project's main idea document)
2. Analyze for:
   - **Gaps**: What's missing? What assumptions are unstated?
   - **Contradictions**: Do any parts conflict?
   - **Vagueness**: What needs to be more specific?
   - **Missing stakeholders**: Who else is affected?
   - **Risk**: What could go wrong?
   - **Scope**: Is this too big for an MVP? Too small to be useful?
3. Present findings to the user
4. For each gap, ask a targeted question
5. Update the idea document with the refined understanding

## Rules

- Don't remove the user's original intent
- Add, don't replace
- Mark uncertain items clearly
- Keep the document readable, not bloated
