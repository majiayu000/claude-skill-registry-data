# LeeWay 3D Facial Performance

Define neutral facial topology and deformation regions; create/validate expression shapes or joint/solver controls; coordinate jaw, lips, cheeks, brows, eyelids and eyes; support phoneme/viseme and performance capture workflows when required. Validate combinations/extremes, symmetry/asymmetry, interpenetration and runtime cost. Facial animation quality requires both geometry and rig/performance evidence.
