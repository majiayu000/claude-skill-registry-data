# Review 11 Evidence Matrix

## Purpose

Create the central evidence table that prevents unsupported manuscript claims.

## Required Inputs

- Deep-reading notes.
- Classification table.
- Quality/risk-of-bias tool appropriate for the review type.

## Output

Create `08_evidence_matrix/evidence_matrix.csv` with:

- Claim or theme.
- Supporting studies.
- Study type/evidence level.
- Direction of evidence.
- Consistency.
- Limitations.
- Suggested manuscript location.
- Citation keys.

## Completion Gate

Pass only when every planned major claim has supporting citations or is removed/deferred.

## Stop Rules

Do not rank evidence by journal impact alone. Separate evidence strength from publication prestige.
