# CAD乔木组串线与标注

先读当前项目唯一要求，再按`../cad-check-review/references/annotation-control.md`执行本批控制链。样式取本项目正式合格对象；TDbText、普通文字或其他类型是否可用，依项目实际标准，不能把乔木组一律改成灌草TDbSymbMultiLeader。

## 当前适用规则

- 一组真实成员、一套名称数量、一条完整串线；跨视口自然显示不重复计组。 `quantity`是独立源注或项目已核批准的期望数量，不能用待检`len(members)`反算后再证明数量一致；数量来源/冲突沿项目记录保存。原数量/身份与实际成员矛盾时，只挂该组，不能增删树去凑数。顶点数不是株数，末点重复也不是多一株。
- 旧注归属沿实际拓扑追溯：文字/引线可能先接中间连接线，再接树组串线。保留这条来源链及真实端点证据；不能因中间线位于置石层、0层或不是LEADER就排除，也不能把附近所有相交线当成同一组。近邻只能提示候选；有间隙或多义连接时结合本图精度、原图显示和独立源注核对，不套固定跨工程容差。原来源串线的归属与新标注的中心/头尾要求分别判断；不得复制不合格的旧连接形式。
- 串线对应树图例的**真实中心**。优先使用已核实的符号基点、变换后的原生圆冠中心等，处理嵌套块/转角/缩放；世界包围框中点、圆冠内任意点不等于中心。未知中心来源先挂局部，不能写个`center_verified=true`冒充实测。 同一块定义的符号中心核过后可按定义指纹缓存，每株只应用当前已核世界变换；不为每次排版重新展开或另开CAD取同一中心。
- 自由引线从完整组串线首端或末端实际连接引出；首末仍是本组真实端株中心。不从中段顶点/线段拉出，不加无用途尾巴或绕行伪造组端。单株指自身中心。实测旧引线仅作归属/位置参考，若与当前头尾/中心规则冲突，按当前规则重排。
- 内容及成员已核时优先只移动文字/自由外引。需修组线，只修当前错误中心与无用途绕行，不移动植物本体；不要用偏离中心的冠内搜索躲其他注。项目明确固定高程文字和测点时，将它们作为固定对象；若当前授权是调整坐标显示来避让，则只调整坐标的允许显示夹点，不把高程文字加入可移动邻注。
- 根据实际视口纸面方向优先短竖直外引加水平承托，或合格135°，从两端就近换侧/错层。组内连接不套自由外引90°规则。串线、外引分别查自交/互交/穿字和重要工程；普通GRASS、普通细地形不作为远抛理由。
- 同组乔木分布在路沿等分隔线两侧，成员归属已核且用户已允许这种跨越时，保持一组并允许组内串线跨过该类分隔线，不因此自动拆组、绕离真实树心或反复询问。跨路沿许可只作用于组内串线与该类分隔线，不放宽标注彼此交叉、穿字、自交或改变工程几何的要求；其他角色未知的线不能自动归为同类。
- 原生文字沿已定字高、字体、颜色与样式；要求白色串线时核实际ByLayer/对象色及视口显示。不能靠隐藏不合格对象、文字遮罩或截掉邻幅掩盖问题。

## 可执行前置检查

`scripts/preflight_tree_groups.py`用标准库检查树组的中心顶点、成员唯一性、首尾相接和三点外引角度。只需把现有机器计划或原生导出适配成`tree_groups`记录；保持在现有job/证据里，不另建要求清单。

每批提供本图`geometry_tolerance`、`angle_tolerance_degrees`和`allowed_elbow_degrees`，数值来自本次坐标单位、读回精度与标准，脚本不设跨工程米制容差。每组提供：

```json
{"id":"source-group-id","quantity":2,
 "members":[{"id":"tree-a","center":[0,0],"center_basis":"validated_block_basepoint"},
            {"id":"tree-b","center":[4,0],"center_basis":"transformed_native_crown_center"}],
 "chain":[[0,0],[4,0]],"external":[[4,0],[4,3],[7,3]]}
```

`center_basis`只允许有原生证明的`native_symbol_center`、`validated_block_basepoint`、`transformed_native_crown_center`；原生中心证明保存在现有快照。组内所有顶点应对应真实成员，禁止偏心/额外尾巴。不同拓扑或数量未定的组用`status: hold`及具体原因，不能强套三点模板。

规划器直接调用`audit_group`或`audit_batch`；原生生成前用最终目标再检，原生落图后从**实际导出**再检。同批`ready_ids`继续执行，`hold_ids/failed_ids`留本组修，不把一组未知锁住全专业。几何预检不核来源连接链/成员归属，也不检查字形、主要工程、全视口和真实树种，不能作为语义或完整图面通过。

## 来源与实际核验

定向读`../cad-check-review/library/knowledge/CAD_ANNOTATION_AESTHETIC_USER_REQUIREMENTS.md`的“正式种植整组串线”和N07/N15/N18/N19。来源成员映射、原生世界变换、当前可见集合与数量分开核；原生文字+串线完整可编辑，不能只凭同组或bbox归属通过。

批次结束核所有实际修改的组、被联动邻注、目标层全局/视口显示及跨幅；当前对象真图面看中心、头尾、方向和就近程度。检查与重开的频率沿[共用触发表](../cad-check-review/references/annotation-control.md#检查按触发条件执行不按每次微调重复)，常规复用已验原生区域截图，不为每组全图导出、固定多幅PDF或独立重开。用户反例先纳入此类型检查再回查同类，完整大项再统一项目验收。后续意见按共用控制链回写本小节，保留项目原话和覆盖关系。
