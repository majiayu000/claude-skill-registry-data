## Page Structure for chrisscho.uk Showcases

### 1. Above the Fold (Hero)
- **Tagline**: Categorize the product in 5 words or less ("Cloud Desktop Infrastructure for AI Agents").
- **Headline**: High-contrast benefit statement.
- **Visual**: Embedded interactive demo or video loop.
- **CTA**: `pip install open-desktop` or `View on GitHub`.

### 2. Architecture & How It Works
- Provide an ASCII or Mermaid architecture diagram showing the components (Client $\to$ Engine $\to$ Docker Sandboxes).
- 3 key technical highlights (e.g., Remote Docker SSH Manager, Multi-Agent Playbooks, Obsidian Vault Sync).

### 3. Quickstart & Code Examples
- Show realistic, runnable code snippets using standard conventions.

### 4. Open Source & Portfolio Footer
- Links to GitHub repo, documentation, and author profile (Chris Schofield / chrisscho.uk).
