## 功能能力
### 快速服务选型（Quick Service Picker）
按设备组合推荐优选云存储服务。选型原则：原生集成优先，避免跨平台兼容性损耗。详细定价与功能对比见 `services.md`.
| 你的设备 | 优选选择 | 原因 |
|:---:|:---:|:---:|
| iPhone + Mac | iCloud | 原生集成，无缝 |
| Android + Chrome | Google Drive | Gmail自带，自动照片备份 |
| Windows PC | OneDrive | Windows内置，Office集成 |
| 混合设备 | Dropbox | 各平台表现一致 |

### 常见困惑澄清（Common Confusions）
对照"What you think"与实际发生的差异，澄清同步机制、存储空间区别与重复备份问题.
| What you think | What's actually happening |
|:----------------|----------------:|
| "我从手机删除后笔记本上也没了" | 同步按设计工作——一个文件，处处一致 |
| "iCloud满了但手机还有空间" | 手机存储 ≠ iCloud存储 |
| "我的照片到处都是重复的" | 多个服务备份同一相机卷 |
| "我付了3个云服务的钱" | 选一个主服务，取消其余 |

### 存储满处理（Storage Full）
4步清理流程，详细的服务专属清理步骤见 `cleanup.md`：

1. **检查什么占用空间**——照片通常占大头
2. **清空回收站**——删除的文件在清空回收站前仍计入占用
3. **关闭重复备份**——只选一个照片备份服务
4. **归档旧文件**——将归档移至外置硬盘

### 备份策略（Backup Strategy）
- **3-2-1规则**：3份副本、2种不同介质、1份异地
- **云算异地**——但也要保留本地备份
- **每月检查备份状态**——不要假设它在工作

什么该备份、什么不该存云端：见 `backup.md`.

### 文件分享（Sharing Files）
| 需求 | 方法 |
|---:|:---|
| 快速分享给任何人 | 链接（设置过期时间） |
| 持续的家庭访问 | 共享文件夹 |
| 敏感文档 | 不要用云，或先加密 |

各服务详细步骤：见 `sharing.md`.

### 安全基础（Security Basics）
- 在所有云账户**启用2FA**
- **季度审查共享链接**——撤销旧的
- **不要未加密存储**：密码、证件、财务文档

## 错误处理指引
| 错误场景 | 原因 | 处理方式 |
|:------:|--------|:-------|
| "删除后笔记本上也没了" | 同步按设计工作，非错误 | 解释同步机制；若需保留，先复制到非同步目录再删除 |
| "iCloud满了但手机有空间" | 手机存储与iCloud存储是两个配额 | 引导到iCloud管理存储页面清理，而非删除手机本地文件 |
| 照片在多个服务重复 | 多个服务同时备份相机卷 | 选一个主备份服务，关闭其余的自动备份 |
| 同步长时间未完成 | 网络慢或文件过大 | 
| 共享链接被滥用 | 链接过期未撤销 | 季度审查共享链接，撤销旧的；新链接设过期时间 |
| 2FA未启用 | 账户安全基础缺失 | 立即在所有云账户启用2FA（短信/认证器/硬件密钥） |
| 备份"假成功" | 备份进程静默失败 | 每月检查备份状态，不要假设它在工作 |
| 跨平台同步冲突 | 混合设备用非原生服务 | 选Dropbox等跨平台一致的服务；或按主设备选原生服务 |
| 付费多个服务 | 重复付费 | 选一个主服务，取消其余；按设备组合决定主服务 |
| 敏感文档明文存储 | 安全习惯缺失 | 先加密再上传，或不用云；启用2FA |

## 常见问题FAQ

### Q1: 如何选择适合我的云存储服务？
A: 消费级云存储助手会根据您的设备组合推荐优选云存储服务，您可以根据推荐选择最适合自己的服务。

### Q2: 如果我在一个服务中删除了文件，其他服务中也会删除吗？
A: 不一定。同步机制会确保一个文件在所有设备上保持一致，但删除操作不会自动同步。

### Q3: 我的iCloud满了，但手机还有空间，这是为什么？
A: 手机存储和iCloud存储是不同的概念。iCloud存储是您在iCloud上购买的存储空间，而手机存储是您手机本身的存储空间。

### Q4: 如何备份我的重要文件？
A: 消费级云存储助手提供了备份策略，建议您遵循3-2-1规则进行备份，并定期检查备份状态。

### Q5: 如何安全地分享文件？
A: 您可以通过设置过期时间的方式分享链接，或者使用共享文件夹功能。对于敏感文档，建议不要使用云存储，或者先加密后再分享。

## 安全建议
1. 确保所有云账户都启用了2FA。
2. 定期审查共享链接，撤销旧的链接。
3. 不要在云存储中存储敏感信息，如密码、证件、财务文档。
4. 定期更新应用，以获取最新的安全补丁。
5. 避免使用公共Wi-Fi进行敏感操作。

## 错误恢复方案
针对消费级云存储助手使用中可能遇到的常见问题,提供以下排查方案:

| 错误类型 | 原因分析 | 解决方案 |
|---------|---------|---------|
| API认证失败(401) | API密钥错误或过期 | 检查密钥配置,重新生成token |
| 接口限流(429) | 请求频率超出限制 | 降低调用频率,启用重试退避策略 |
| 响应超时(504) | 网络延迟或服务端负载过高 | 增加超时阈值,检查网络连接 |
| 文件不存在 | 路径错误或文件未创建 | 检查路径拼写,确认文件已生成 |
| 文件格式不支持 | 扩展名不在支持列表中 | 转换为支持的格式后重试 |
| 权限不足 | 当前用户无读写权限 | 检查文件权限,以管理员身份运行 |
| 命令执行失败 | 参数错误或环境依赖缺失 | 检查命令语法,确认依赖已安装 |
| 进程超时 | 命令执行时间过长 | 增加超时设置,优化命令参数 |
| 网络连接失败 | DNS解析失败或防火墙拦截 | 检查网络配置,确认代理设置 |
