# Draw.io Diagram Engineering Skill

## Overview
Automates the creation, layout, and validation of architectural diagrams in `.drawio` XML/SVG format for cloud infrastructure, microservices, and workflows.

## Capabilities
- Multi-cloud stencils: AWS, Azure, GCP, Kubernetes, BPMN.
- Declarative node/edge layout with automated routing.
- Integration with `sparklabx/drawio-ai-kit`.
