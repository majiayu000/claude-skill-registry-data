# Infrastructure review
Use the relevant specialist agents. Evaluate architecture and complexity against the hardware, security and exposure (along the attacker's path), Ansible idempotency and self-verification, stateful data and replication, resources, observability, backup and recovery, deployment and rollback, and whether the docs still tell the truth. Report concrete findings by severity and domain and conclude merge/deploy readiness.
