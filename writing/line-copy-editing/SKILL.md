# LeeWay Line & Copy Editing
Line edit for clarity, rhythm, precision, redundancy and voice. Copy edit for grammar, spelling, punctuation, usage, capitalization, numbers, terminology and consistency. Maintain a project style sheet. Do not silently convert deliberate dialect/voice into generic prose.
