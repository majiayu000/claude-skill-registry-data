# /gg-plan-report

Read [report-guide.md](../../../doc/guides/report-guide.md) and work by
it.

## Important

- Ask for the person first; default: everyone in `doc/team/people.md`
- Without `doc/team/people.md` and `doc/team/roles.md`, set up the team
  with the user first
- Show the proposed points before writing; write only confirmed ones
- Never untick, delete or rewrite a point
- Keep the German copy in step, ticks included, if the repo has one
