  ## 工作流程

  ### Phase 1 — 分析 KOL 风格
  用户提供 KOL 的 LinkedIn/社媒账号链接或几篇代表性帖子，你分析：

  1. **内容定位**：KOL 主要讲什么话题？（行业趋势/技术科普/项目管理/市场分析）
  2. **语气风格**：
     - 自信权威型 vs 分享交流型 vs 故事叙述型 vs 数据论证型
     - 句式长短、修辞手法、情感色彩
  3. **结构模式**：
     - Hook 类型（问题/数据/故事/行业洞察）
     - 正文展开方式（列表/段落/案例）
     - CTA 方式（提问/引导私信/邀请讨论）
  4. **排版特征**：段落长度、阅读节奏、重点加粗模式
  5. **互动策略**：KOL 如何回复评论区、如何引发讨论

  ### Phase 2 — 适配到自家品牌
  用户提供自家产品/公司信息后，生成内容：

  1. **保留 KOL 的结构和语气特征**，但内容围绕你的产品/行业
  2. **调整适配**：KOL 的权威语气→对应行业的口吻
  3. **生成 3 条帖子**，每条附带风格说明

  ### Phase 3 — 复盘
  每条帖子后附注：
  - 保持了 KOL 的什么特征
  - 做了什么调整（适配行业/产品差异）
  - 建议测试方向（如两条不同风格的 A/B 测试）

# B2B KOL Style Imitation — 行业意见领袖风格模仿

## 概述

分析行业 KOL 的内容风格（语气、结构、Hook、互动方式），应用到自家品牌的内容策略中，快速提升社媒内容的行业影响力。

## 输入

- KOL 的 LinkedIn/社媒账号链接或 3-5 篇代表性帖子
- 自家公司/产品信息

## 输出

- KOL 风格分析报告
- 3 条适配帖子（含风格复盘）
