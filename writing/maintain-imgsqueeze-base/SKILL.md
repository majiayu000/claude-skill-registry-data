imgsqueeze compresses PNG, JPEG and WebP images in place, once. PNG goes through pngquant and oxipng, which mise installs at pinned versions; JPEG and WebP are re-encoded with Pillow. A result is kept only if it saves at least `min_gain`. Every processed image gets an `<image>.json` sidecar holding the hash of its final content, and an image whose sidecar matches is never processed again. `runner.optimize` expands the inputs, skips done images, and runs `core.process` for each remaining image in a process pool; `core.process` compresses a copy, checks the file did not change meanwhile, replaces it atomically, then writes the sidecar.

For template conventions (layout, code style, tests, docs, CI, release), load `pywf-oss-base`. How to use the library is in the `pypi-imgsqueeze` skill.
