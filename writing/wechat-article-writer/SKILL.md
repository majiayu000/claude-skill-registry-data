# 公众号文章创作

公众号是"订阅分发+社交转发+搜一搜搜索"三流量场：标题决定打开率，开头决定读完率，结构决定转发率；同时长尾搜索流量常被忽视。

## 输入

账号类型（订阅号/服务号）、定位与人设、本篇目的（涨粉/种草/转化/品牌/通知）、产品与卖点、目标人群、历史爆文风格（可选）。

## 创作 SOP

### 标题（给 5 个备选，≤64 字但建议 15–25 字）

- 打开率结构：利益承诺（"一文讲清 XX"）、悬念反差、身份代入、热点借势（须真实相关）、数字盘点。
- 搜一搜埋词：标题含用户会搜的品类/问题词（微信搜一搜有可观长尾流量）。
- 禁：夸大/惊悚标题党（"震惊体"伤账号）、极限词、与正文不符。

### 摘要（≤120 字）

- 补充标题未说完的利益点；转发卡片展示位，别浪费。

### 正文结构

- 开头 3 行定生死：场景共鸣/尖锐问题/反常识结论，不写"随着时代的发展"。
- 骨架按目的选：
  - 种草转化：痛点→方案→产品证据（真实案例/数据/资质）→优惠与行动入口（小程序卡片/阅读原文/企微二维码）；
  - 干货涨粉：问题→框架→分点展开（每点有小标题+案例）→总结清单→关注引导；
  - 品牌叙事：故事线（冲突→转折→价值观），少硬广。
- 排版：段落 ≤3 行；小标题分层；重点加粗；配图每 300–500 字一张（注明版权来源）；字号 15–16px、两端缩进、行距 1.75 为常见舒适区。
- 长度：干货 1500–2500 字，种草 800–1500 字，通知类 ≤800 字。

### 引导与转化组件

- 文末：关注引导（给关注理由而非"求关注"）、在看/转发引导（不得利诱强制，诱导分享违规）、转化入口（小程序/企微活码/阅读原文链接）。
- 服务号：模板消息/订阅通知需用户授权场景，不滥用。

## 合规红线

- 商业推广软文按《互联网广告管理办法》需可识别为广告（标注"广告"/合作声明）；医疗/药品/保健食品不得以养生知识形式变相发广告。
- 功效宣称、极限词、虚构案例/数据禁止；金融类不得承诺收益；转载须授权。
- 诱导分享/关注（"转发领红包""不转不是…"）违反微信平台规范。

## 输出格式

```
## 公众号文章方案（目的 / 人群 / 搜一搜关键词）
标题×5 + 摘要
正文（含小标题与排版标记）
配图建议 / 转化组件位置 / 文末引导
### 合规自查（广告标注/宣称/诱导）
### 发布建议：时段、合集、转发冷启动（社群/朋友圈话术）
```
