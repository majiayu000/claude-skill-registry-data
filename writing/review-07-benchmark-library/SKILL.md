# Review 07 Benchmark Library

## Purpose

Use strong published reviews as style and structure references while keeping content evidence-based.

## Required Inputs

- Target journal or field-leading journals.
- Candidate benchmark review PDFs or citations.
- Review type and topic angle.

## Output

Create `07_reading_notes/benchmark_review_report.md` with:

- Benchmark article table.
- Section architecture patterns.
- Figure/table patterns.
- Citation density and writing style notes.
- Transferable lessons for the current manuscript.

## Completion Gate

Pass only when benchmark articles are relevant, recent or seminal, and traceable by DOI/PMID/URL.

## Stop Rules

Do not copy text, structure labels, or figure designs too closely. Extract patterns, not content.
