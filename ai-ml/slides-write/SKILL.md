# Goal
- Given content or a topic from the user, write a given number of slides

# Workflow

## Role
- Your role is specified in `.claude/skills/role.ai_researcher.md`

## Input
- The user provides:
  - Information, a topic, or a file `<TOPIC>` about the topic to describe
  - (Optional) Number of slides `<NUM_SLIDES>`, otherwise assume `<NUM_SLIDES> = 3`
- If the user passed a file `<TOPIC>`, read it

## Format
- For all formatting rules, templates, and structural guidelines, see
  `.claude/skills/slides.rules.md`

## Create Slides
- Create `<NUM_SLIDES>` slides
- Start each slide with a `* <TITLE>` line
- Open with a standalone `* Roadmap` slide
- Close with a standalone `* Summary` slide (before `* References`, if the deck has
  one)
  - See `.claude/skills/slides.rules.md` `## Roadmap Slide` / `## Summary Slide`
  - These two do not count against `<NUM_SLIDES>`

## Add Visuals
- Follow the instructions from `.claude/skills/figure.rules.md`

## Save Result
- Do not print anything on the screen
- Save the result in an output file `<OUTPUT_FILE>`
  - If there was no input file, create `<TOPIC>.slides.md` in the current dir
  - If a file `<FILE>` was provided, create `<FILE>.slides.md`
  - If the destination file already exists, delete it and create a new one
- Say in the slides file how it was generated, with this comment right after the
  metadata-comment block:
  ```
  // Generated by `.claude/skills/slides.write/SKILL.md`
  ```

# Verification
- [ ] Make sure that the new slides render correctly, e.g.,
  ```bash
  > gen_slides.py -i <OUTPUT_FILE> --notes_to_pdf_args="--skip_action open_pdf"
  ```
- [ ] The slides file says that it was generated by
      `.claude/skills/slides.write/SKILL.md`
