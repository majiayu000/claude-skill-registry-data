# 統計検定 準 1 級

結論: **範囲が広いので「導出できる核」と「結果を覚える周辺」を分ける**。数値入力の問題があるため、式を立てて最後の数値まで出す練習が欠かせない。

## 試験の構造(統計検定の公式サイトで確認)

- CBT 方式。選択式に加えて数値入力式の問題がある。試験時間・問題数・合格点は級別案内を確認する(合格は 100 点満点の 60 点以上とされている)。
- 出題範囲表が正典。2 級の内容を前提に、大学で学ぶ統計の応用までを含む。

一次情報: 統計検定 https://www.toukei-kentei.jp/

## 範囲の芯

| 分野 | 核(導出できるようにする) | 周辺(結果と使いどころ) |
|---|---|---|
| 確率・分布 | 期待値・分散の計算、変数変換、積率母関数 | 多変量正規、順序統計量、各分布の関係 |
| 推定 | 最尤推定、フィッシャー情報量、不偏性・一致性 | ベイズ推定と事前分布、EM アルゴリズム |
| 検定 | 尤度比検定、検出力 | 多重比較、ノンパラメトリック検定 |
| 回帰・モデル | 最小二乗の正規方程式、ロジスティック回帰の解釈 | 一般化線形モデル、AIC、正則化(リッジ・ラッソ) |
| 多変量 | 主成分分析の固有値と寄与率 | 判別分析、クラスター分析、因子分析 |
| 時系列 | 自己相関、AR(1) の定常条件 | MA・ARMA、季節調整 |
| 調査・実験 | 層化抽出の分散 | 分散分析、直交表、欠測の扱い |
| その他 | | 生存時間解析(カプラン・マイヤー)、分割表、機械学習の基礎(交差検証・過学習) |

## 学び方

1. 2 級の判断表を前提に、尤度・情報量・漸近分布の考え方で全体をつなぐ。
2. 各分野の核を白紙で導出する(例: 正規分布の母平均・母分散の最尤推定量、AR(1) の自己相関)。
3. 周辺は「何のための手法か・前提・出力の読み方」を 3 行で書く。
4. 数値入力に備え、電卓レベルの計算を途中で丸めずに最後まで運ぶ練習をする。
5. 公式問題集を時間を計って解き、分野ごとの正答率を記録して弱い分野に戻る。

## 問題・解説を自作するとき

- 計算の問は、解説の式とは**別の道筋**(シミュレーション、ライブラリ関数)でも数値を出し、一致を確かめる。
- 導出の解説は前提(独立性、正則条件、大標本)を明記する。

## 落とし穴

- 不偏推定量と最尤推定量の違い(分散の n と n−1)。
- 尤度比検定の自由度の数え方。
- 主成分分析で変数の尺度をそろえるかどうか(相関行列か共分散行列か)。
- ロジスティック回帰の係数を確率の差として読む(正しくは対数オッズ)。
- 時系列で非定常な系列に定常モデルを当てはめる。
- 途中の丸めで数値入力の答えがずれる。

## 自己検証

- 公式問題集 1 回分を時間内に解き、60% を安定して超えるか。
- 核の導出を、教材を見ずに 1 本 10 分以内で書けるか。
- 分野別正答率の最低値が上がっているか。
