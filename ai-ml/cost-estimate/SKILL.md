# Cost estimate — retired method

The previous LOC-to-hours and commit-count-to-AI-ROI methodology is retired;
it did not provide calibrated evidence for those estimates. This manual
entrypoint remains only for compatibility.

For a requested estimate, clarify whether the subject is rebuild effort,
operating cost or business value. Use explicit scope, assumptions and relevant
measured or comparable evidence. Report ranges and unknowns without presenting
code volume, commit timestamps or subscription price as demonstrated ROI.
A replacement specialized estimation workflow requires an actual recurring need.
