# ai-local-pois 本地 POI 筛选助手

[快速开始](https://github.com/allinherog-star/ai-skills/tree/main#%E5%BF%AB%E9%80%9F%E5%BC%80%E5%A7%8B)

[更多技能](https://ai-skills.ai)

### 概述

本地 POI 筛选助手用于回答「周边 POI 怎么选」、资料整理、数据清理、行动项，适合运营、产品、销售、software在明确业务目标、内容材料或分析对象后调用。
它会结合地点需求或候选清单、粘贴地点需求、候选清单、预算、出行范围、偏好条件或评价摘录。等输入，整理关键上下文，并输出经营诊断、本地营销建议、执行清单，便于继续执行、复盘或交付。

### 什么时候使用

**适用场景**

- 用户提出“周边 POI 怎么选”这类问题，需要快速拆解目标、判断重点并形成可执行结果
- 运营、产品、销售、software需要围绕本地 POI 筛选助手生成经营诊断、本地营销建议、执行清单
- 用户已经准备了筛选目标（说明要完成的推荐、比较、路线、预算、风险核验或最终决策。）、出行或使用对象（说明人数、角色、偏好、场景、交通方式或活动类型。）、地点或地图链接（填写公开可访问的地图、门店、地点、评价或候选页面链接。），希望整理成可执行的分析或优化结果
- 用户需要把本地 POI 筛选助手相关材料转成清晰结论、优先级和下一步动作

### 命令示例

**基础调用**

```bash
python3 scripts/run.py --params '{}'
```

```bash
python3 scripts/run.py --params '{"goal":"筛选目标"}'
```

### 参数说明

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `goal` | string | 否 | - | 说明要完成的推荐、比较、路线、预算、风险核验或最终决策 |
| `audience` | string | 否 | - | 说明人数、角色、偏好、场景、交通方式或活动类型 |
| `materialUrl` | string | 否 | - | 填写公开可访问的地图、门店、地点、评价或候选页面链接；需要传可访问的完整 URL |
| `materialFile` | string | 否 | - | 上传地点清单、评价表、活动需求、预算表或调研资料 |
| `materialText` | string | 否 | - | 粘贴地点需求、候选清单、预算、出行范围、偏好条件或评价摘录 |
| `brandRequirements` | string | 否 | - | 补充时间范围、预算上限、距离限制、营业要求、避雷条件或人工核验重点 |

完整机器可读参数结构见 `references/form-schema.json`。

### 交付内容

- 经营诊断、本地营销建议、执行清单：围绕用户目标整理可直接阅读、复盘或交付的核心结果。
- 输入材料解读：结合筛选目标（说明要完成的推荐、比较、路线、预算、风险核验或最终决策。）、出行或使用对象（说明人数、角色、偏好、场景、交通方式或活动类型。）、地点或地图链接（填写公开可访问的地图、门店、地点、评价或候选页面链接。）提炼关键上下文和判断依据。
- 下一步动作：给出优先级、执行建议或可继续加工的内容框架。

### 结果使用建议

- 先判断输出是否回答了用户关于「本地 POI 筛选助手」的核心问题。
- 再检查结果是否覆盖经营诊断、本地营销建议、执行清单，以及是否给出明确下一步动作。
- 如果输入材料较少，建议让用户补充目标、受众、限制条件或原始材料后再运行。
