# Figure：参考风格驱动的学术数据图

先查看参考图，识别布局、图表类型、配色、字体、线型、标记、坐标尺度、双轴、误差带、图例和注释；根据真实数据关系复用视觉语言，而不是复制原论文的结果或结论。通用风格的辨识与参数见 [风格样例](references/styles.md)。其中也包括彩色外环雷达图、灰度纹理双面板柱状图。新参考图不必强行归入已有样式。

## 数据与范围

- 用户提供数据时使用原数据，并保存其来源、单位和必要的变换说明。缺少数值且任务是画真实实验结果时，不从曲线外观编造测量。
- 用户明确允许模拟时，用固定随机种子生成合理数据；在图中注明 `SYNTHETIC DATA`，在附带说明中记录种子、生成机制、误差带含义。不得沿用原方法名称使模拟结果看似原论文实验。
- 样例脚本 [render_examples.py](scripts/render_examples.py) 生成三套示范数据，也接受其自身导出的 JSON 以重放结果。它不是任意 CSV 的通用绘图入口；真实任务应根据字段映射调整绘图函数，明确实际数据来源，再修改模拟标注。
- 仅在用户要求时重命名输入图。用 `布局_图表类型_主要视觉特征` 的英文 snake_case 命名；记录旧名、新名与 SHA-256，不覆盖同名文件，不改图片内容。修改现有绘图项目时保留当前数据和用户调整的代码。

## 风格与可读性

- 默认使用 Matplotlib 等标准科学绘图库，交付真正的矢量 PDF/SVG；不把参考截图嵌入输出，不用 Excalidraw 重画数据轴。数据图不自动继承 method/motivation 的卡通字体、图标、斜线背景或高图标密度。
- 复用参考的长宽比、多面板排列、视觉层级和主要颜色。三联图可紧凑横排；六宫格按指标对齐；柱状图用同色系深浅和少量 hatch 区分系列。字体优先清楚的 serif/sans-serif，具体跟随参考；无需强制所有任务用 serif。
- 同一方法在各面板用同一颜色与标记，不能只靠颜色区分。图例数量随真实系列而定，不为贴近参考虚构基线。
- 根据最终论文栏宽调整字号、间距和画布。标题、轴标签、图例、数值标注必须完整显示；图例通常放空白角落或上方专用区域，避免压住曲线与柱顶数字。
- 百分数数据为 0–1 时用对应百分数格式，为 0–100 时按另一尺度处理；单位、刻度、坐标截断和对数变换须明确。柱状图默认从零起始。
- 双轴仅用于确有不同量纲的指标，各轴颜色对应系列；阈值绘制在所属轴上，不把像素高度相同当成数值相等。横轴相同不意味着两个纵轴可直接比较。
- 误差带必须由数据和定义计算，明确是 SD、SE、置信区间或范围；不根据视觉效果随意加带。单条测量曲线不自动产生统计置信区间。
- 直方图说明频率、概率质量或密度；归一化质量应求和为 1。线图与直方图共享横轴时区分统计量，避免暗示二者存在未定义的关系。

## 生成与检查

使用示例脚本需要 Python、NumPy 和 Matplotlib；运行环境缺依赖时按需安装，不依赖某个固定 `/tmp` 目录。

```bash
python /path/to/figure/scripts/render_examples.py --out /path/to/retry --seed 20260929
# 从已有模拟数据重放：
python /path/to/figure/scripts/render_examples.py --out /path/to/replay --data /path/to/retry/synthetic_data.json
```

每次输出 PNG（默认 300 dpi）、单页矢量 PDF、SVG、便于查看的预览，并保存绘图脚本及原始／派生数据。模拟示例额外导出 JSON 与 CSV。SVG 字体默认保留为文本；跨设备字体一致性要求较高时可改为路径，PDF 使用嵌入字体。不要只修改 dpi 元数据冒充提高分辨率。

检查数据长度、概率范围、图例—系列对应、阈值所属轴、PDF 页数和输出像素尺寸；实际查看整图与 PDF，修正图例遮挡、标签裁切、双轴拥挤和柱顶数字冲突。自动检查不能代替视觉检查。输出到用户指定目录，不把结果写回参考图；结束时提供结果和 skill 路径。

两种几何风格使用 [render_geometric_styles.py](scripts/render_geometric_styles.py) 生成，和其他样例同级管理。

需要更精致的彩色外环雷达图时，阅读 [雷达图设计变体](references/radar-design.md)，可用 [render_radar_gallery.py](scripts/render_radar_gallery.py) 基于同一份数据生成六种可比较的风格。保持所有系列、轴顺序和刻度一致，只调整视觉呈现。

绘制灰度纹理柱状图时，阅读 [多指标紧密柱状图](references/hatched-bars.md)：默认组内柱子相接；要求全无空隙时组间也相接。多指标按单位分面或明确归一化，支持共享图例和一行三列样例展示。
