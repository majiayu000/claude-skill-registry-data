# invest-asset：单品种资产分析

## 哲学锚点

- **达里奥「全天候」**：不同资产在不同经济环境下表现不同，配置比择时重要。
- **巴菲特「不碰不懂的」**：可转债条款、REITs 底层资产，看不懂就不买。

## 三关审查骨架（通用）

| 关 | 问题 | 判断标准 |
|---|---|---|
| 懂不懂 | 这类资产怎么赚钱？风险在哪？ | 能向外行说清 |
| 好不好 | 当前估值/收益率有吸引力吗？ | 历史分位 < 50% |
| 贵不贵 | 安全边际够吗？最坏情况能承受吗？ | 极端测试通过 |

## 资产类型专属细则

### 债券（利率债/信用债）

**关键指标**：到期收益率、久期、信用利差、评级、发行人资质

**分析要点**：
- 利率债：看收益率曲线位置、久期匹配
- 信用债：看发行人财务、区域财政（城投）、行业景气（产业债）
- 利差分析：品种利差、期限利差、评级利差、信用利差走势与分位

**数据获取**：
```bash
python3 ~/.agents/skills/mx-data/scripts/get_data.py --type bond --code <代码> --metrics ["yield","duration","spread"]
python3 ~/.agents/skills/mx-data/scripts/get_data.py --type spread --metrics ["credit_spread","term_spread","rating_spread"]
```

**输出模板**：`mx-templates/bond_onepager.md` 或 `mx-templates/credit_spread.md`

### 可转债

**关键指标**：转股价值、纯债价值、溢价率、到期收益率、下修/回售条款

**分析要点**：
- 债底保护：纯债到期收益率 > 0 有安全垫
- 股性弹性：转股溢价率 < 20% 跟随正股
- 条款博弈：下修条款、回售条款、强赎风险

### 大宗商品（黄金/白银/原油）

**关键指标**：实际利率（黄金）、供需平衡（原油）、美元指数、通胀预期

**分析要点**：
- 黄金：实际利率下行 + 避险需求 → 配置价值
- 原油：OPEC+ 供给 + 全球需求 + 库存周期
- 白银：工业属性 + 金银比

### 公募 REITs

**关键指标**：分派率、底层资产类型、运营管理能力、杠杆率

**分析要点**：
- 底层资产：高速公路/产业园/仓储/保租房/能源
- 现金流稳定性：租约结构、承租人集中度
- 估值：P/FFO、Cap Rate 对比

## 核心原则

1. **不替决策**：提供框架，决策交还用户
2. **不预测价格**：只评估估值与风险匹配度
3. **数据时效**：不用过期数据
