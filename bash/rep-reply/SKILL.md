# /rep-reply — отвечаем людям нашим опытом

## Зачем
Репутация не покупается постами в свои каналы — она складывается там, где живые инженеры
уже мучаются нашей болью. Один точный ответ с артефактом в чужом треде стоит больше десяти
постов в своём. Канон громкости: §1.5 (молчание требует причины) + ⛔ спам ≠ громкость
(одно точное сообщение в правильную дверь, никаких вееров одинакового текста).

## ⭐ Шаг 0-тер — ПОЛКА × ПРОСЬБА: сперва туда, где хозяин сам просит то, что у нас лежит (anton 21.09.2026, голосом)
Ещё до людного треда: `python3 ~/.claude/scripts/shelf_match.py --top 15` (0 LLM, ~5 мин API) — пересечение
НАШИХ публичных репо (полка, ниши из `domain.json` + фразы боли в `registry/github-universe/shelf_overrides.json`)
с живыми issue целевых репо, где внешних мержат. Печатаются только **точные** матчи: в тексте issue названа
боль конкретного нашего репо. Даём ТОЛЬКО то, что есть на полке; ниша без репо у нас = не наша экспертиза, мимо.
Первый ответ захода → лучший точный матч: ответ по существу + ссылка на репо как готовое решение, не «посмотрите
наш проект». ⛔ Обязательная обратная связь по КАЖДОМУ взятому или отброшенному матчу из топ-5:
`shelf_match.py --verdict <url> hit|miss "почему"` — miss исключается навсегда, точность печатается в следующем
прогоне; без вердиктов фильтр не ужесточится (замер 21.09: уровень «ниша» дал 929 матчей, уровень «боль» — 335,
из них настоящих на глаз ~⅓). Таблица для Антона: `--publish` → вкладка «Полка × просьбы» книги целей.
🪙 Тела топ-N issue для вердиктов НЕ читает дорогая модель: `Agent(model: "sonnet")` получает список url и возвращает по каждому ≤3 строки «что просят · что у нас · hit/miss с причиной»; дорогая модель только утверждает вердикты (замер 21.09: 70 тел прочитаны Fable, рельса Sonnet = 0 вызовов, причина «забыл»).
Пусто → строка «полка не спрошена» в журнал и Шаг 0-бис.
⚠️ **Прибора НЕТ на узле — это не «пусто», и чинить его в прогоне охоты не надо** (замер 23.09, хаб:
`shelf_match.py` не найден ни в `~/.claude`, ни в `_imports` на глубину 4, хотя Шаг 0-тер написан 21.09).
Пиши в лог `skip` со строкой «полка не спрошена: прибора нет на узле» и иди на Шаг 0-бис; развёртывание
прибора — работа посылки/деплоя, а не охоты, иначе прогон съедает себя на инфраструктуре.

## ⭐ Шаг 0-бис — САМЫЙ ЛЮДНЫЙ ЖИВОЙ ТРЕД ДОМЕНА ПЕРВЫМ (anton 15.09.2026, «делай правило, не жди реакции»)
Первый ответ захода идёт НЕ в гнёзда ниже, а туда, где прямо сейчас больше всего живых людей спорят
про нашу боль. Один веер, один bash-скрипт, слова домена по одному (длинная фраза даёт пусто):
`memory · fleet · consensus · "second brain" · supersede · handoff · CRM · watchdog · "exit 0"` →
`gh search issues "<слово> reactions:>10" --state open --updated ">$(date -v-14d +%F)" --sort comments --order desc --limit 10`.

⚠️ `reactions:>10` в САМОМ запросе — не украшение, а фильтр роевого спама (замер GIT-S5 17.09: без него
6 слов домена дали 36 кандидатов, из них **35 — репо-пустышки** с 2500💬 от 1–3 ботов, и живая дверь была
ровно одна; с ним верх выдачи = `anthropics/claude-code`, `openai/codex`, `microsoft/vscode`, пустышки ушли
полностью). Фильтр НЕ заменяет домен-суждение: реакции тянут вверх мега-треды мимо ниши (Proton, WSL, golang)
— их отсекаем словами ниши, как раньше.

Кандидат = **≥10 комментариев · ≥5 разных авторов · обновлён ≤14 дней · нашего голоса нет**
(`gh api .../comments --jq '[.[].user.login]|unique'`). Ботские «control board» треды (сотни 💬 от 1–3
авторов) — монолог, не дверь. Нашли → читаем тред целиком, ищем, чего в нём ещё НЕТ, и несём туда замер
с датой и артефакт (эталон: `gastownhall/beads#5877`, 14.09 — 77💬, 15 авторов, 25 дней без нас; коммент +
код в тот же день). Второй тред того же репо в тот же час — только с отдельной ценностью (§1.5).

⚠️ `github_targets.py --check` на несканированном репо отвечает «домен=off, вне круга» — это значит
«не сканировали», не «запрещено»; решение по описанию репо и словам домена (класс
`domain-gate-off-for-unscanned-repo`). Канон: `reglament-samyy-lyudnyy-zhivoy-tred-domena-pervym`,
память [[loudest-live-thread-first]]. Пусто по всем словам → строка «людного треда нет» и дальше Шаг 1.
