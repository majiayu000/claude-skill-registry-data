# invest-analyst：全能分析师工作台

## 定位

机构级内容交付。invest-stock/fund 做「买不买」的判断，invest-analyst 做「怎么写/怎么产出」的报告。

## 六大场景

| 场景 | 触发词 | 输出模板 |
|---|---|---|
| IC 研报 | 「IC报告」「投资备忘录」 | `mx-templates/ic_report.md` |
| 行业深度 | 「行业深度」「行业研究报告」 | `mx-templates/industry_report.md` |
| 首次覆盖 | 「首次覆盖」「深度报告」 | `mx-templates/ic_report.md` |
| 业绩点评 | 「业绩点评」「财报分析」 | `mx-templates/earnings_review.md` |
| 事件驱动 | 「怎么看待XX政策/并购」 | 结构化分析 + 影响评估 |
| 市场日报 | 「日报」「晨报」「今天市场怎么样」 | 市场快照 + 异动解读 |

## 数据获取

**统一走 mx-data 数据层**：

```bash
# 行业数据
python3 ~/.agents/skills/mx-data/scripts/get_data.py --type industry --name "半导体" --metrics ["size","growth","pe"]

# 企业深度数据
python3 ~/.agents/skills/mx-data/scripts/get_data.py --type enterprise --code <代码> --metrics ["revenue","profit","debt_ratio"]
```

## 估值方法论

### 方法选择矩阵

| 方法 | 适用场景 | 核心输入 | 局限 |
|------|---------|---------|------|
| DCF | 现金流稳定企业 | WACC / 永续增长率 / FCF 预测 | 对假设敏感 |
| PE | 盈利稳定企业 | EPS / 可比公司 PE | 不适用亏损企业 |
| PB | 重资产/金融企业 | BVPS / 可比公司 PB | 不适用轻资产企业 |
| EV/EBITDA | 资本密集企业 | EBITDA / 可比公司 EV/EBITDA | 不考虑资本结构差异 |
| DDM | 高分红企业 | 股息 / 要求回报率 / 增长率 | 不适用不分红企业 |
| PS | 亏损/高增长企业 | 营收 / 可比公司 PS | 不考虑盈利能力 |
| NAV | 重资产/REITs | 资产价值 - 负债 | 不适用轻资产企业 |

### 估值交叉验证规则

- 至少用 2 种方法交叉验证
- 估值差异 > 30% 时，需说明原因
- 安全边际 = 估值 - 市价 > 20%

## 产业链分析框架

### 产业链结构

| 层级 | 分析内容 | 核心问题 |
|------|---------|---------|
| 上游 | 原材料/设备/技术 | 集中度？议价能力？ |
| 中游 | 制造/加工 | 产能利用率？竞争格局？ |
| 下游 | 品牌/渠道/终端 | 需求稳定性？议价能力？ |

### 利润池分析

- 产业链利润分布：哪个环节利润率最高？
- 利润转移趋势：利润在上下游间如何流动？
- 价值驱动因素：技术/品牌/规模/渠道哪个是核心价值来源？

### 产业链投资逻辑

| 逻辑 | 核心问题 | 判断标准 |
|------|---------|---------|
| 上游垄断 | 上游是否高度集中？ | CR3 > 70% → 上游优先 |
| 下游品牌 | 下游是否有定价权？ | 毛利率 > 40% → 下游优先 |
| 中游制造 | 中游是否有规模效应？ | 成本领先 > 15% → 中游可投 |
| 产业链整合 | 是否有企业向上下游延伸？ | 整合成功 → 竞争优势提升 |

## 报告写作原则

1. **数据驱动**：每个结论有数据支撑，不编造
2. **逻辑清晰**：投资要点 → 分析 → 结论 → 风险
3. **专业术语**：用机构语言，不用口语
4. **风险提示**：必须包含，不构成投资建议

## 核心原则

1. **不替决策**：提供分析，决策交还用户
2. **不预测股价**：只评估基本面与逻辑
3. **数据时效**：不用过期数据
