# Liveboard

Запускать встроенный dependency-free сервер:

```bash
node "<skill-root>/scripts/server.mjs" --root "<project-root>"
```

Оставлять процесс в foreground и передавать пользователю URL из события `liveboard-ready`. Порт `0` означает автоматический выбор свободного порта; bind по умолчанию — только `127.0.0.1`.

## Настройка

```bash
node "<skill-root>/scripts/server.mjs" \
  --root "/path/to/project" \
  --host "127.0.0.1" \
  --port 0 \
  --interval 300000
```

| Параметр | По умолчанию | Назначение |
|---|---:|---|
| `--root` | текущий каталог | Git-проект, чьи worktree и задачи показывать |
| `--host` | `127.0.0.1` | интерфейс прослушивания; внешний bind только по явному запросу |
| `--port` | `0` | порт; `0` автоматически выбирает свободный |
| `--interval` | `300000` | полный перескан в миллисекундах; минимум `1000` |

Endpoints: `/` — HTML, `/health` — liveness, `/api/snapshot` — текущий снимок, `/api/events` — SSE, `POST /api/refresh` — ручной перескан.

UI автоматически выбирает язык браузера и позволяет переключаться между 43 локалями. В набор входят English, Русский, Українська и ещё 40 языков Европы и Азии. Arabic, Hebrew, Persian и Urdu включают RTL. Выбор языка живёт только в памяти вкладки.

Для Task Master настроить ключи в окружении (`ANTHROPIC_API_KEY` или `OPENAI_API_KEY`) и выбрать main-модель через `/task-master:provider <anthropic|openai|codex-cli> <model-id>`. `PERPLEXITY_API_KEY` нужен только для опциональной research-модели.

## Источники

- Получать worktree через `git worktree list --porcelain`.
- Читать задачи из `.taskmaster/tasks/tasks.json` каждого worktree.
- Определять активные Claude/Codex/Cursor процессы best-effort через локальный список процессов и cwd.
- Если процесс нельзя связать с ролью, показывать честную inference-запись для каждой задачи `in-progress`.

Сервер следит за файлами Task Master, доставляет изменения через SSE и делает полный reconciliation каждые 5 минут. `POST /api/refresh` запускает ручной перескан.

## Ограничения

- Не писать snapshot, PID, логи или пользовательские данные на диск.
- Не открывать bind на `0.0.0.0`, если пользователь явно этого не запросил и не подтвердил риск.
- Не обещать точную идентификацию агента, если ОС не раскрывает cwd процесса; UI помечает источник как `process` или `task`.
- Останавливать сервер по `Ctrl+C`/SIGTERM; после остановки runtime-состояния не остаётся.

Проверять `GET /health` и `GET /api/snapshot`, если запуск требуется подтвердить.
