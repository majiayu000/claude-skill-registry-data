# ai-hr-pro HR 专业助手

[快速开始](https://github.com/allinherog-star/ai-skills/tree/main#%E5%BF%AB%E9%80%9F%E5%BC%80%E5%A7%8B)

[更多技能](https://ai-skills.ai)

### 概述

HR 专业助手用于回答「HR 文档怎么更稳」、HR 文档、绩效反馈、求职材料，适合人力资源、manager、运营、software在明确业务目标、内容材料或分析对象后调用。
它会结合岗位、绩效或求职材料、粘贴岗位描述、简历、绩效素材、人事沟通草稿、评估标准或反馈目标。等输入，整理关键上下文，并输出转化问题诊断、文案和结构建议、实验清单，便于继续执行、复盘或交付。

### 什么时候使用

**适用场景**

- 用户提出“HR 文档怎么更稳”这类问题，需要快速拆解目标、判断重点并形成可执行结果
- 人力资源、manager、运营、software需要围绕HR 专业助手生成转化问题诊断、文案和结构建议、实验清单
- 用户已经准备了处理目标（说明要完成的匹配分析、绩效反馈、表达优化、面试准备或风险检查。）、相关角色（说明候选人、员工、管理者、HRBP、面试官或沟通对象。）、岗位或资料链接（填写公开可访问的岗位、公司、政策或参考资料链接。），希望整理成可执行的分析或优化结果
- 用户需要把HR 专业助手相关材料转成清晰结论、优先级和下一步动作

### 调用方式

通过导出的 Python runner 直接调用 AI Skills API：

### 命令示例

**基础调用**

```bash
python3 scripts/run.py --params '{}'
```

**带常用参数调用**

```bash
python3 scripts/run.py --params '{"goal":"处理目标"}'
```

### 参数说明

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `goal` | string | 否 | - | 说明要完成的匹配分析、绩效反馈、表达优化、面试准备或风险检查 |
| `audience` | string | 否 | - | 说明候选人、员工、管理者、HRBP、面试官或沟通对象 |
| `materialUrl` | string | 否 | - | 填写公开可访问的岗位、公司、政策或参考资料链接；需要传可访问的完整 URL |
| `materialFile` | string | 否 | - | 上传简历、岗位说明、绩效记录、人事政策、面试材料或沟通草稿 |
| `materialText` | string | 否 | - | 粘贴岗位描述、简历、绩效素材、人事沟通草稿、评估标准或反馈目标 |
| `brandRequirements` | string | 否 | - | 补充事实依据、敏感信息处理、语气要求、不可承诺内容、法律边界或人工复核重点 |

完整机器可读参数结构见 `references/form-schema.json`。

### 交付内容

- 转化问题诊断、文案和结构建议、实验清单：围绕用户目标整理可直接阅读、复盘或交付的核心结果。
- 输入材料解读：结合处理目标（说明要完成的匹配分析、绩效反馈、表达优化、面试准备或风险检查。）、相关角色（说明候选人、员工、管理者、HRBP、面试官或沟通对象。）、岗位或资料链接（填写公开可访问的岗位、公司、政策或参考资料链接。）提炼关键上下文和判断依据。
- 下一步动作：给出优先级、执行建议或可继续加工的内容框架。

### 结果使用建议

- 先判断输出是否回答了用户关于「HR 专业助手」的核心问题。
- 再检查结果是否覆盖转化问题诊断、文案和结构建议、实验清单，以及是否给出明确下一步动作。
- 如果输入材料较少，建议让用户补充目标、受众、限制条件或原始材料后再运行。
