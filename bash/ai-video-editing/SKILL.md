# ai-video-editing AI 视频剪辑诊断助手

[快速开始](https://github.com/allinherog-star/ai-skills/tree/main#%E5%BF%AB%E9%80%9F%E5%BC%80%E5%A7%8B)

[更多技能](https://ai-skills.ai)

### 概述

AI 视频剪辑诊断助手用于回答「这段素材怎么剪」、视频剪辑、素材整理、短视频改编，适合市场营销、运营、software、内容媒体在明确业务目标、内容材料或分析对象后调用。
它会结合剪辑需求或素材说明、粘贴本次要交给「AI 视频剪辑诊断助手」处理的素材说明、转写稿、时…等输入，整理关键上下文，并输出剪辑结构诊断、片段取舍和时间点建议、字幕配音与平台重构清单，便于继续执行、复盘或交付。

### 什么时候使用

**适用场景**

- 用户提出“这段素材怎么剪”这类问题，需要快速拆解目标、判断重点并形成可执行结果
- 市场营销、运营、software、内容媒体需要围绕AI 视频剪辑诊断助手生成剪辑结构诊断、片段取舍和时间点建议、字幕配音与平台重构清单
- 用户已经准备了成片目标与时长（说明本次希望解决的剪辑问题、目标时长、成片用途或需要产出的版本。）、目标平台与受众（说明「AI 视频剪辑诊断助手」输出要服务的平台、观看人群、角色、市场或使用场景。）、素材或参考链接（填写公开可访问的视频、素材或参考成片链接；如果链接需要登录、权限或 Cookie，…），希望整理成可执行的分析或优化结果
- 用户需要把AI 视频剪辑诊断助手相关材料转成清晰结论、优先级和下一步动作

### 命令示例

**基础调用**

```bash
python3 scripts/run.py --params '{}'
```

**带常用参数调用**

```bash
python3 scripts/run.py --params '{"goal":"成片目标与时长"}'
```

### 参数说明

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `goal` | string | 否 | - | 说明本次希望解决的剪辑问题、目标时长、成片用途或需要产出的版本 |
| `audience` | string | 否 | - | 说明「AI 视频剪辑诊断助手」输出要服务的平台、观看人群、角色、市场或使用场景 |
| `materialUrl` | string | 否 | - | 填写公开可访问的视频、素材或参考成片链接；如果链接需要登录、权限或 Cookie，请改为上传文件或粘贴内容；需要传可访问的完整 URL |
| `materialFile` | string | 否 | - | 上传 raw footage、录屏、访谈、直播片段、转写稿或脚本文件，便于生成剪辑决策表 |
| `materialText` | string | 否 | - | 粘贴本次要交给「AI 视频剪辑诊断助手」处理的素材说明、转写稿、时间点、剪辑目标或当前成片问题 |
| `brandRequirements` | string | 否 | - | 补充品牌语气、平台规格、剪辑风格、必须保留内容、不可改动事实、合规限制或人工复核重点 |

完整机器可读参数结构见 `references/form-schema.json`。

### 交付内容

- 剪辑结构诊断、片段取舍和时间点建议、字幕配音与平台重构清单：围绕用户目标整理可直接阅读、复盘或交付的核心结果。
- 输入材料解读：结合成片目标与时长（说明本次希望解决的剪辑问题、目标时长、成片用途或需要产出的版本。）、目标平台与受众（说明「AI 视频剪辑诊断助手」输出要服务的平台、观看人群、角色、市场或使用场景。）、素材或参考链接（填写公开可访问的视频、素材或参考成片链接；如果链接需要登录、权限或 Cookie，…）提炼关键上下文和判断依据。
- 下一步动作：给出优先级、执行建议或可继续加工的内容框架。

### 结果使用建议

- 先判断输出是否回答了用户关于「AI 视频剪辑诊断助手」的核心问题。
- 再检查结果是否覆盖剪辑结构诊断、片段取舍和时间点建议、字幕配音与平台重构清单，以及是否给出明确下一步动作。
- 如果输入材料较少，建议让用户补充目标、受众、限制条件或原始材料后再运行。
