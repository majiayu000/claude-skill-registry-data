# invest-stock：统一个股分析

买一股股票就是买一家企业的一部分。A股/港股/美股，三个市场，四种分析模式，一个入口。

## 模式自动选择

| 触发条件 | 模式 | 适用市场 |
|---|---|---|
| 默认（分析个股） | **三关审查**：懂不懂→好不好→贵不贵 | A股/港股 |
| 美股标的 或 用户要求量化 | **四维评分**：ROE/负债/FCF/护城河 → A-D评级 | 美股 |
| 用户说"深度分析"/"DCF"/"IC Memo" | **机构深度**：DCF估值/同行比较/财报透视/投资备忘录 | 全部（初筛通过后） |

**港A增强**：分析A股/港股时自动附加政策敏感度、AH溢价、南北资金流检查。

## 快速识别

收到标的名称/代码后：

1. 识别市场：A股（6位数字）→ 三关+港A增强 / 港股（5位数字）→ 三关+港A增强 / 美股（字母代码）→ 四维评分
2. 识别深度：用户是否说「深度」「DCF」「IC Memo」「机构」→ 机构深度模式
3. 开始分析

## 数据获取

**统一走 mx-data 数据层**，不直接调用 API：

```bash
# 取股票数据
python3 ~/.agents/skills/mx-data/scripts/get_data.py --type stock --code <代码> --metrics ["ROE","PE","revenue","net_profit"]
```

取数后按下方方法论分析，不暴露数据源细节给用户。

## 模式 1：三关审查（默认，A股/港股）

### 哲学锚点

- **巴菲特「能力圈」**：不懂的生意，涨跌都拿不住。
- **巴菲特「护城河」**：好生意才能持续赚钱。
- **巴菲特「安全边际」**：好公司也要好价格。

### 第一关：懂不懂（能力圈）

能向一个外行说清楚这家公司怎么赚钱吗？收入从哪来？客户为什么选它？5年后它还在吗？

**数据需求**：主营业务构成（分产品/分地区）、上下游位置、行业生命周期。

**未通过** → 停止，不买。

### 第二关：好不好（护城河 + 管理层 + 行业地位）

有定价权吗？竞争对手多久能复制？需要持续烧钱维持吗？

**行业生命周期判断**：

| 阶段 | 特征 | 增速 | 竞争格局 | 投资策略 |
|------|------|------|---------|---------|
| 成长期 | 需求爆发，渗透率快速提升 | > 15% | 分散，龙头未现 | 高估值可容忍，选龙头 |
| 成熟期 | 增速放缓，格局稳定 | 5-15% | 集中，CR3 > 50% | 选龙头，看分红 |
| 衰退期 | 需求下降，产能过剩 | < 5% | 分散，价格战 | 回避，除非转型 |

**竞争格局（波特五力）**：

| 力量 | 核心问题 | 强/弱信号 |
|------|---------|----------|
| 供应商议价 | 上游集中度？转换成本？ | 集中/高转换成本 → 强 |
| 买方议价 | 下游集中度？产品差异化？ | 集中/无差异化 → 强 |
| 替代品威胁 | 替代成本？性能差距？ | 低成本/高性能 → 威胁大 |
| 新进入者威胁 | 进入壁垒？规模经济？ | 低壁垒/无规模经济 → 威胁大 |
| 行业内竞争 | 竞争者数量？行业增速？ | 多/增速慢 → 竞争激烈 |

**管理层与治理**：

| 维度 | 核心问题 | 判断标准 |
|------|---------|---------|
| 诚信 | 有无财务造假/违规记录 | 无 → 通过 |
| 能力 | 战略执行力、行业认知 | 过往业绩验证 |
| 激励 | 股权激励、薪酬与业绩挂钩 | 有 → 加分 |
| 股权结构 | 控股股东、机构投资者占比 | 合理 → 通过 |
| 董事会 | 独立性、专业背景 | 独立董事 > 1/3 → 通过 |

**5年趋势表**（N-4至N年）：

| 指标 | N-4 | N-3 | N-2 | N-1 | N | 判断标准 |
|------|-----|-----|-----|-----|---|----------|
| 毛利率 | __% | __% | __% | __% | __% | 稳定或上升 |
| ROE | __% | __% | __% | __% | __% | 持续>12% |
| 经营现金流/净利润 | __% | __% | __% | __% | __% | >70% |
| 有息负债率 | __% | __% | __% | __% | __% | <50% |
| 研发投入占比 | __% | __% | __% | __% | __% | 科技/医药 > 5% |

**一票否决**：财务造假历史 / 竞争优势消失 / ROE依赖高杠杆（权益乘数>3且负债率高）/ 管理层重大诚信问题。

**未通过** → 停止，不买。

### 第三关：贵不贵（安全边际 + 估值方法）

当前价格包含了多少乐观预期？如果买错能承受多大损失？

**多方法估值交叉验证**：

| 方法 | 适用场景 | 核心指标 | 判断标准 |
|------|---------|---------|---------|
| PE | 盈利稳定企业 | PE_TTM / PE历史分位 | < 40% 分位为低估 |
| PB | 重资产/金融企业 | PB / PB历史分位 | < 40% 分位为低估 |
| DCF | 现金流稳定企业 | WACC / 永续增长率 | 现值 > 市价 20%+ |
| EV/EBITDA | 资本密集企业 | EV/EBITDA / 历史分位 | < 40% 分位为低估 |
| DDM | 高分红企业 | 股息率 / 要求回报率 | 股息率 > 要求回报率 |
| PS | 亏损/高增长企业 | PS / 历史分位 | < 40% 分位为低估 |

**估值安全边际**：

| 指标 | 当前值 | 历史均值 | 历史分位 | 判断 |
|------|--------|----------|----------|------|
| PE_TTM | __ | __ | __% | __ |
| PB | __ | __ | __% | __ |
| 股息率 | __% | __% | __% | __ |
| DCF 现值/市价 | __ | - | - | __ |

**极端测试**：假设盈利下滑30%，PE变成多少？DCF 现值下降多少？能承受吗？

**未通过** → 价格透支未来3-5年增长且无安全边际 → 等待或放弃。

## 模式 2：四维评分（美股）

| 维度 | 评分标准 | 分值 |
|------|----------|------|
| ROE持续性 | 连续3年+ > 20% → 3分 | /3 |
| 负债安全性 | 有息负债率 < 30% → 3分 | /3 |
| FCF质量 | 连续3年+ FCF > 0 → 3分 | /3 |
| 护城河 | 定价权+品牌+网络效应 → 3分 | /3 |

总分 10-12 → A（买入）/ 7-9 → B（观察）/ 4-6 → C（回避）/ 0-3 → D（远离）

## 核心原则

1. **不替决策**：提供框架，决策交还用户
2. **不预测股价**：只评估基本面与价格匹配度
3. **不保证收益**：任何分析都可能错误
4. **数据时效**：不用过期数据
