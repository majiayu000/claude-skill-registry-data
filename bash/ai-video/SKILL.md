# ai-video AI 视频生成策划助手

[快速开始](https://github.com/allinherog-star/ai-skills/tree/main#%E5%BF%AB%E9%80%9F%E5%BC%80%E5%A7%8B)

[更多技能](https://ai-skills.ai)

### 概述

AI 视频生成策划助手用于回答「想生成什么视频」、视频生成、分镜策划、提示词优化，适合市场营销、software、内容媒体、电商在明确业务目标、内容材料或分析对象后调用。
它会结合视频创意或生成需求、粘贴本次要交给「AI 视频生成策划助手」规划的视频创意 brief…等输入，整理关键上下文，并输出视觉/创意诊断、提示词或分镜方案、发布规格检查，便于继续执行、复盘或交付。
能力定位补充：skills.sh all-time/trending 信号显示 video 有用户需求；平台展示为 media_generation 业务助手目录，输出可复核的视频分镜、生成提示词和生产准备包。

### 什么时候使用

**适用场景**

- 用户提出“想生成什么视频”这类问题，需要快速拆解目标、判断重点并形成可执行结果
- 市场营销、software、内容媒体、电商需要围绕AI 视频生成策划助手生成视觉/创意诊断、提示词或分镜方案、发布规格检查
- 用户已经准备了视频目标（说明本次希望解决的具体问题、判断目标或交付用途。）、目标观众（说明「AI 视频生成策划助手」输出要服务的人群、角色、市场或观看场景。）、参考链接（填写公开可访问的链接；如果链接需要登录、权限或 Cookie，请改为上传文件或粘贴…），希望整理成可执行的分析或优化结果
- 用户需要把AI 视频生成策划助手相关材料转成清晰结论、优先级和下一步动作

### 参数说明

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `goal` | string | 否 | - | 说明本次希望解决的具体问题、判断目标或交付用途 |
| `audience` | string | 否 | - | 说明「AI 视频生成策划助手」输出要服务的人群、角色、市场或观看场景 |
| `materialUrl` | string | 否 | - | 填写公开可访问的链接；如果链接需要登录、权限或 Cookie，请改为上传文件或粘贴内容；需要传可访问的完整 URL |
| `materialFile` | string | 否 | - | 上传与「AI 视频生成策划助手」相关的参考图、产品资料、脚本、录屏或音视频素材 |
| `materialText` | string | 否 | - | 粘贴本次要交给「AI 视频生成策划助手」规划的视频创意 brief、产品信息、脚本草稿、镜头想法或生成目标 |
| `brandRequirements` | string | 否 | - | 补充品牌语气、平台规则、格式偏好、不可改动事实、合规限制或人工复核重点 |

完整机器可读参数结构见 `references/form-schema.json`。

### 交付内容

- 视觉/创意诊断、提示词或分镜方案、发布规格检查：围绕用户目标整理可直接阅读、复盘或交付的核心结果。
- 输入材料解读：结合视频目标（说明本次希望解决的具体问题、判断目标或交付用途。）、目标观众（说明「AI 视频生成策划助手」输出要服务的人群、角色、市场或观看场景。）、参考链接（填写公开可访问的链接；如果链接需要登录、权限或 Cookie，请改为上传文件或粘贴…）提炼关键上下文和判断依据。
- 下一步动作：给出优先级、执行建议或可继续加工的内容框架。

### 结果使用建议

- 先判断输出是否回答了用户关于「AI 视频生成策划助手」的核心问题。
- 再检查结果是否覆盖视觉/创意诊断、提示词或分镜方案、发布规格检查，以及是否给出明确下一步动作。
- 如果输入材料较少，建议让用户补充目标、受众、限制条件或原始材料后再运行。
