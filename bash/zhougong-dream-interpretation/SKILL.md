# 周公解梦 · 阴阳五行 · 现代心理学 多层解梦

当用户描述梦境时，本技能给出**三层解读**：①《周公解梦》原文吉凶断语 → ②阴阳五行/周易/洪范/
天人感应 推演（结合本命、天时，可选并入近期事件合参）→ ③现代心理学（弗洛伊德/荣格/睡眠科学/
意识科学/文化批判）；最后再给一段**联合三层的交叉解析**（汇聚点与分歧点），而非各说各话。

## 定位声明（务必贯彻）

- **文化参照 + 心理洞察，不是字面预言。** 周公解梦的「主吉/主凶」是传统占断的语汇，
  应作为文化素材呈现，并与心理学解读并置，让用户自行取舍。
- **主动呈现分歧**：占断（向前预言）、精神分析（向后溯源）、睡眠科学（神经加工）、
  Crary 的批判（反对把梦物化为可解码信息）之间常相矛盾——**呈现张力，不要调和成一种声音**。
- 语气温和、尊重，避免制造焦虑；涉及健康/情绪困扰时，鼓励现实中寻求支持。

## 阶段一：收集信息（逐步询问，不要一次全问）

按顺序收集。自由文本项直接用文字询问；`地点`可用 AskUserQuestion 也可自由文本。

1. **梦境描述（必答，自由文本）** —— 请用户尽量具体：梦见了什么物象、场景、情绪、结局。
2. **做梦日期与时间（必答）** —— 用于查当天当地天气。若只记得大概日期也可；完全不记得则
   取最近一次做该梦的估计日期，并说明是估计。
3. **所在地点（必答，城市级）** —— 做梦时人在哪个**城市/地区**（天气是城市尺度，
   不必精确到街道或景点；如「北京」「杭州」「London」）。
4. **生日（可选）** —— 询问用户是否愿意提供**公历**生日（可含出生时刻）以叠加
   「本命五行」视角；不提供则跳过该维度，仅做前两层 + 心理层。
5. **近期特殊事件（可选）** —— 询问用户近来是否发生过印象深刻的事（喜事/变故/压力/
   转折/失落等）。愿意提供则纳入「梦事合参」（层2 会把事件与梦境用天人感应合并推演）；
   不提供则跳过，不影响其余各层。

收齐后，简短复述确认再进入解读。

## 阶段二：运行脚本（确定性计算，勿手算）

脚本在本技能 `scripts/` 目录下。设 `SKILL_DIR=~/.claude/skills/zhougong-dream-interpretation`。

**A. 地点+天气（地点必答 → 总是运行）：**
```bash
python3 "$SKILL_DIR/scripts/geoweather.py" "<城市>" <做梦日期YYYY-MM-DD> [HH:MM]
```
- 返回经纬度、当天天气、**天气五行 + 庶征**（雨=水、晴热=火、风=木…）。
- **核对返回的 `display_name` 是否与用户所述地点相符**；若国家/省份明显不符，
  换更规范的城市名重试（见其 `alternatives`）。
- `requests` 缺失时：`conda activate skill` 后重试，或 `pip install requests`。

**B. 生日→农历/属相/纳音（仅当用户提供生日）：**
```bash
python3 "$SKILL_DIR/scripts/birthinfo.py" <公历生日YYYY-MM-DD> [HH:MM]
```
- 纯标准库、无需联网。返回农历日期、**属相**、年柱干支、**本命纳音五行**（如乙亥→山头火→火）、
  可选时辰五行。

把两脚本的 JSON 结果留作层2 推演的输入。

## 阶段三：多层解读

### 层1 ·《周公解梦》原文断语
1. 从梦境提取核心**梦象**（物象/动作/场景），如「蛇」「水」「飞」「牙齿脱落」。
2. 打开 `references/zhougong/index.md`，按 27 类目定位到相关类目文件（一个梦象可能跨多类，
   如「水里的蛇」→ `23-shuihuo-...` 与 `25-longshe-...`，应合并查）。
3. 在类目文件中检索匹配断语，**原文引用**并标注类目出处（原文为繁体，按字义匹配简体输入）。
4. 若无恰好对应条目，选取**意象最相近**者，并说明是近似类比，不牵强附会。

### 层2 · 阴阳五行 / 周易 / 洪范 / 天人感应
底表见 `references/wuxing-yinyang.md`（生克、干支、纳音、生肖、天气五行）、
`references/zhouyi.md`（阴阳、八卦取象）、`references/shangshu-hongfan.md`（五行本义、庶征、稽疑）、
`references/baihu-tongyi.md`（五行/性情/日月/灾变/蓍龟）、
`references/chunqiu-fanlu.md`（董仲舒天人感应、同类相动、五行生克、阴阳）。
1. **梦象归五行/落卦**：把核心梦象归入五行或八卦（水/坎、火/离、木/震巽…），辨其阴阳动静。
2. **排生克**：将「梦象五行 · 本命纳音五行（若有生日）· 当天天气五行」并排，看相生（顺/助）、
   相克（逆/耗/警示）、比和（稳）。举例说明其气机倾向，而非断死祸福。
   （生克机理可引 `chunqiu-fanlu.md` 五行相生/相胜、`baihu-tongyi.md` 相害。）
3. **天时（庶征）**：天气得时和顺偏「休征」（吉背景），反常极端偏「咎征」（宜警惕）。
4. **梦事合参（仅当用户提供了近期特殊事件）** —— 用**天人感应/同类相动**把事件与梦境合并推演：
   - 事件与梦象各自**归五行 / 取象**；用「同者相益、异者相损」排「事件五行 · 梦象五行 · 本命 · 天时」。
   - 判「梦-事」关系类型：**同类呼应**（美事召美类/恶事召恶类）、**预兆先见**（其将兴亡，
     美祥/妖孽先见）、**阴阳相求/补偿**（忧则欲卧、喜则不卧；梦与事相反作补偿）、或**无显著感应**。
   - 出处引 `chunqiu-fanlu.md`（同类相动/天地阴阳/灾异说）、`baihu-tongyi.md`（灾变谴告）、
     `shangshu-hongfan.md`（庶征）、`zhouyi.md`（观象）。保持描述性（感应/回响/补偿），**不作硬预言**。
5. 用「阴阳消长」总括这个梦是偏阳升还是阴降的气象。

### 层3 · 现代心理学
用 `references/psychology-crossref.md` 把梦的主题路由到 `references/psychology/<书>/` 内的具体章节
（先读该书 `overview.md` 再进 `chapters/chNN-*.md`）：
- 欲望/冲突/童年 → Freud；原型/阴影/自性/预兆感 → Jung；
- 机制/REM/情绪调节/创造力/噩梦 → Walker；意识与无意识加工 → Dehaene；
- 学派比较、「梦有无意义」之争 → Bulkeley（枢纽）；现代性/失眠/对解梦的反思 → Crary。
给 1–2 个最贴切的解读并**标注出处章节**，再点明它与层1、层2 的异同。

## 阶段四：综合 → 三层交叉解析 → 建议

除阶段三的各层独立解析外，**必须**再给一段联合三层的**交叉解析**（这是本技能的落点）。

**1. 交叉对照表** —— 就该梦的 2–4 个核心意象逐行对照：

| 核心意象 | 层1 周公断语 | 层2 五行·天时·（事件） | 层3 心理学 | 交叉结论 |
|---------|------------|----------------------|-----------|---------|
| 例：鱼 | 群鱼游水主有财 | 鱼属水×雨天(水)旺 | 荣格：无意识浮现之物 | 三层同指「财/生机自水下浮现」→ 信号强 |

**2. 汇聚点 vs 分歧点**：
- **汇聚点**：三层（或两层）**同指**同一含义时，标为「信号最强」，是解读的重心。
- **分歧点**：各层**相悖**时（如周公主吉 vs 五行相克示警 vs 科学说只是 REM 加工），
  **呈现张力、不要调和**——如实说「传统这样看、五行那样提示、科学则未必有隐意」。

**3. 梦事感应结论（若有事件合参）**：综合层2 第4步，给出「梦-事」关系的整合判断
（同类呼应 / 预兆先见 / 阴阳补偿 / 无显著感应），仍保持描述性、非硬预言。

**4. 整合收束 + 建议**：用 3–5 句把交叉解析收成一个整体读解，落到对用户处境的温和体察；
可给一两条现实层面的小建议（关注睡眠、记录梦、留意近期情绪），不下命令、不预言灾祸。
邀请用户补充梦的细节或自身联想以深化（Freud/Jung 都强调**做梦者自己的联想**）。
