# invest-enterprise：企业深度分析

## 哲学锚点

- **巴菲特「买股票就是买企业」**：企业分析是投资决策的基石。
- **格雷厄姆「安全边际」**：企业财务健康是安全边际的前提。

## 分析框架（15 板块）

| # | 板块 | 核心问题 |
|---|---|---|
| 1 | 基本情况 | 企业是做什么的？注册地、成立时间、上市地？ |
| 2 | 股东与治理 | 控股股东、股权结构、董事会、管理层 |
| 3 | 所处行业 | 行业生命周期、竞争格局、政策环境 |
| 4 | 经营状况 | 营收增速、盈利能力、现金流质量 |
| 5 | ESG 分析 | 环境、社会、治理表现 |
| 6 | 财务状况（一） | 资产负债结构、流动性 |
| 7 | 财务状况（二） | 盈利能力、运营效率、现金流 |
| 8 | 发行概述 | 债券/股票发行历史、规模 |
| 9 | 发行定价 | 估值水平、市场定价分析 |
| 10 | 偿债分析 | 债务结构、偿债能力、违约风险 |
| 11 | 信用分析 | 评级、信用利差、市场评价 |
| 12 | 司法风险 | 诉讼、仲裁、行政处罚 |
| 13 | 科创能力 | 专利、研发投入、科技称号（如适用） |
| 14 | 重点关注 | 核心风险点与亮点 |
| 15 | 综合结论 | 整体评估与投资建议 |

## 数据获取

**统一走 mx-data 数据层**：

```bash
python3 ~/.agents/skills/mx-data/scripts/get_data.py --type enterprise --code <代码> --metrics ["revenue","profit","debt_ratio","rating"]
```

## 核心原则

1. **不替决策**：提供框架，决策交还用户
2. **不预测股价**：只评估企业信用与财务健康
3. **数据时效**：不用过期数据
