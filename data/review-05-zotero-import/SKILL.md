# Review 05 Zotero Import

## Purpose

Create a traceable reference library without losing database provenance.

## Required Inputs

- Search exports and `search_log.csv`.
- Zotero collection name or desired folder convention.
- Deduplication rules if already defined.

## Output

Create `04_zotero_library/zotero_import_plan.md` with:

- Collection/folder structure.
- Import order.
- Tags for database, screening status, theme, full text, and priority.
- Deduplication plan.
- Export-back format for Codex analysis.

## Completion Gate

Pass only when references can be traced back to database source and screening status.

## Stop Rules

Do not delete ambiguous duplicates without keeping a duplicate audit note.
