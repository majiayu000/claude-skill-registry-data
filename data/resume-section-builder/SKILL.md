# 简历版块构建器（Resume Section Builder）

## 何时使用本技能

当用户出现以下情况时使用本技能：
- 需要帮助处理特定的简历版块
- 想优化简历的某一部分
- 不确定某个版块该写什么
- 需要针对具体版块的指导
- 提到："简历版块""技能栏""个人小结""工作经历栏""该写什么内容"

## 核心能力

- 构建有针对性的专业小结
- 高效组织技能栏结构
- 优化工作经历版块
- 恰当撰写教育背景版块
- 有策略地补充附加版块
- 针对不同职业阶段定制各版块

## 专业小结版块

### 何时需要写

**适合写小结的情况：**
- 转行者（需要解释职业转变）
- 资深从业者（提炼漫长的职业生涯）
- 重返职场（需要回应职业空窗期）
- 高度专业化的岗位（强调匹配度）

**可以省略小结的情况：**
- 经验有限的应届/初级求职者
- 职业路径一目了然的线性发展
- 版面空间非常紧张

### 小结写作框架

**公式：** [头衔/身份] + [年限/经验] + [核心技能] + [价值主张]

### 按职业阶段细分

**初级/应届：**
```
加州大学伯克利分校计算机科学专业应届毕业生，拥有全栈开发实习经验。熟练掌握 Python、React 和 AWS。希望在软件工程师岗位上发挥机器学习学术项目和面向用户应用开发方面的积累。
```

**中期职业：**
```
拥有 6 年经验的产品经理，推动 B2B SaaS 产品从概念走向规模化。通过数据驱动的路线图优先级排序和跨职能领导力，成功发布累计创造 1000 万元以上 ARR 的产品。深耕 API 产品、开发者工具和企业级销售打法。
```

**资深/高管：**
```
拥有 15+ 年经验的技术高管，在全球市场将工程组织从 50 人规模化发展到 500+ 人。在主导数字化转型项目、并购整合和平台现代化方面拥有出色的成功记录。管理超过 1 亿元损益（P&L），实现 40%+ 的效率提升。
```

**转行者：**
```
从销售转型至客户成功（Customer Success）的从业者，带来 5 年顾问式销售经验，擅长建立持久的客户关系。精通需求挖掘、方案设计和利益相关方管理。希望将关系经营专长应用于推动客户留存与增购。
```

### 小结写作禁忌

- ❌ 「寻求一份有挑战性的岗位……」
- ❌ 「勤奋刻苦的团队合作者……」
- ❌ 「以结果为导向的专业人士……」
- ❌ 用第三人称（「张伟是一名……」）
- ❌ 写求职目标（你想要什么，而不是你能提供什么）

## 技能栏版块

### 组织方式选项

**选项 1：简单罗列**
```
技能
Python、JavaScript、SQL、React、Node.js、AWS、Docker、Git、敏捷、JIRA
```
最适合：优化 ATS（申请人跟踪系统）、空间受限

**选项 2：分类归纳**
```
技术技能
编程语言：Python、JavaScript、TypeScript、SQL
框架：React、Node.js、Django、FastAPI
云平台：AWS（EC2、S3、Lambda）、GCP、Docker、Kubernetes
工具：Git、JIRA、Confluence、Datadog
```
最适合：技术岗位、技能储备丰富

**选项 3：熟练度分级**（谨慎使用）
```
技能
精通：Python、SQL、产品管理
熟练：AWS、数据分析、利益相关方管理
掌握：机器学习、Figma、财务建模
```
最适合：对熟练度有明确要求的岗位、真实呈现水平

### 应该包含的内容

**技术/硬技能：**
- 编程语言
- 软件和工具
- 方法论（敏捷、精益）
- 平台（Salesforce、SAP）
- 专业认证（Certifications）

**职能技能：**
- 项目管理
- 财务分析
- 数据分析
- 市场调研

**行业知识：**
- 领域专长
- 监管合规知识
- 行业认证

### 不应该包含的内容

- ❌ Microsoft Office（默认人人都会）
- ❌ 标注"基础水平"的技能
- ❌ 面试中无法深入讨论的技能
- ❌ 软技能（要用事实证明，而不是罗列）
- ❌ 过时的技术

## 工作经历版块

### 标准格式

```
公司名称 | 城市，省份
职位名称 | 起止时间

• 带指标和影响说明的成果经历条目
• 带指标和影响说明的成果经历条目
• 带指标和影响说明的成果经历条目
```

### 按职业阶段的经历条目数量指南

**初级/应届（0-2 年）：**
- 每段经历 3-5 条
- 写入相关项目
- 尽可能量化
- 展现主动性和学习能力

**中期职业（3-10 年）：**
- 近期岗位 4-6 条
- 较早岗位 2-3 条
- 聚焦成果而非职责
- 全程使用有力度的指标

**资深（10+ 年）：**
- 近期岗位 5-6 条
- 较早岗位 2-3 条
- 强调领导力和战略
- 展示职责范围不断扩大

### 特殊情况处理

**同一家公司的多次晋升：**
```
公司名称 | 城市，省份
高级经理 | 2021 至今
• [当前岗位的经历条目]

经理 | 2019 - 2021
• [此前岗位的经历条目]

分析师 | 2017 - 2019
• [最早岗位的经历条目]
```

**任职时间较短：**
- 如果经验相关就写上
- 围绕项目或成果来组织表述
- 不要在简历里道歉或解释

**合同工/自由职业：**
```
自由职业产品顾问 | 2022 至今
客户包括：A 公司、B 公司、C 公司
• [为 A 公司取得的成果]
• [为 B 公司取得的成果]
```

## 教育背景版块

### 标准格式

```
教育背景

计算机科学 理学学士
加州大学伯克利分校 | 2020 年
GPA：3.8/4.0 | 荣誉：优等生（Magna Cum Laude）
```

### 按职业阶段决定包含内容

**初级/应届：**
- 学位、专业、学校、年份
- GPA（3.5 以上才写）
- 荣誉和奖项
- 相关课程
- 学术项目
- 交换/海外学习经历

**中期职业：**
- 学位、专业、学校、年份
- 仅在 GPA 特别出色时才写
- 省略课程（已被工作经历取代）

**资深：**
- 学位、学校
- 可以省略年份（避免年龄歧视）
- 职业发展培训更有相关性

### 更高学位

```
MBA，金融与战略
哈佛商学院 | 2022 年
• 领导力学者（Leadership Fellow）
• 相关课程：公司金融、并购战略

计算机科学 理学硕士
斯坦福大学 | 2018 年
• 专业方向：人工智能
• 毕业论文：《论文题目》
```

### 专业认证

```
专业认证
AWS Solutions Architect Associate | Amazon Web Services | 2023 年
PMP（项目管理专业人士）| PMI | 2022 年
Google Analytics 认证 | Google | 2023 年
```

## 附加版块

### 各版块的适用场景

**项目版块：**
- 工作经验有限的初级/应届求职者
- 展示新技能的转行者
- 拥有个人项目的技术岗位求职者

**志愿活动版块：**
- 相关的志愿服务经历
- 担任过领导角色
- 能有意义地填补职业空窗期

**语言能力：**
- 仅在与岗位/公司相关时
- 如实标注熟练程度
- 仅在超出基本日常会话水平时才写

**出版物/专利：**
- 学术类职位
- 研究类岗位
- 技术领域思想领导力

**奖项/荣誉：**
- 重要的行业奖项
- 全公司范围的表彰
- 相关的荣誉称号

### 格式示例

**项目：**
```
项目经历
电商平台 | React、Node.js、PostgreSQL | github.com/user/project
• 构建全栈交易市场应用，拥有 500+ 活跃用户
• 基于 Stripe 集成实现支付处理
```

**志愿活动：**
```
志愿经历
理事会成员 | 本地公益组织 | 2021 至今
• 领导募捐委员会，使年度捐赠额提升 40%
```

**语言能力：**
```
语言能力
中文（母语）| 英语（专业级）| 日语（日常会话）
```

## 按岗位类型排列版块顺序

### 标准顺序
1. 联系方式
2. 小结（可选）
3. 技能
4. 工作经历
5. 教育背景
6. 附加内容

### 技术岗位
1. 联系方式
2. 技能（前置）
3. 工作经历
4. 项目经历
5. 教育背景
6. 专业认证

### 应届毕业生
1. 联系方式
2. 教育背景（前置）
3. 技能
4. 实习经历
5. 项目经历
6. 校园/社团活动

### 高管
1. 联系方式
2. 高管小结
3. 职业亮点
4. 工作经历
5. 董事会职务
6. 教育背景

### 转行者
1. 联系方式
2. 小结（解释职业转变）
3. 技能（可迁移技能）
4. 工作经历（重新组织表述）
5. 桥接型经历（与新领域接轨的经历）
6. 教育背景

## 输出格式

构建简历版块时：

```markdown
# 简历版块建议

## 针对：[用户的情况/目标岗位]

### 推荐版块顺序
1. [版块] - [理由]
2. [版块] - [理由]
...

### 各版块详情

#### 专业小结
**建议：** [写/不写]
**草稿：**
[如果建议写，给出撰写好的小结]

#### 技能栏
**格式：** [简单罗列/分类归纳/熟练度分级]
**内容：**
[组织好的技能清单]

#### 工作经历版块
**格式：** [标准/职能型/混合型]
**每段经历的条目数：**
- 近期岗位：[X] 条
- 较早岗位：[X] 条

#### 教育背景版块
**应包含：**
- [要包含的内容]
**应排除：**
- [要排除的内容]

#### 附加版块
**建议添加：** [版块名称]，因为 [理由]
**建议省略：** [版块名称]，因为 [理由]
```

## 版块构建检查清单

- ✅ 版块顺序针对目标岗位优化
- ✅ 小结（如有）简洁且有针对性
- ✅ 技能相关且组织有序
- ✅ 经历条目以成果为导向
- ✅ 教育背景符合职业阶段
- ✅ 附加版块有实际价值（不是凑数）
- ✅ 全文格式统一
- ✅ 所有版块都服务于目标岗位
- ✅ 没有无关或过时的内容
- ✅ 总篇幅合适（1-2 页）
