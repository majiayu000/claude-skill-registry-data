# Data Visualization

Правила выбора визуализации под задачу.

## Выбор типа
| Задача | Тип |
|--------|-----|
| Сравнение категорий | `bar` |
| Динамика во времени | `line` |
| Распределение/доли | `donut` / `pie` |
| Связи/потоки между сущностями | `sankey` / `chord` |
| Иерархия и пропорции | `treemap` |
| Многомерное сравнение | `radar` |
| Корреляция точек | `scatter` |
| Геоданные | `map` |
| Схемы процессов | `mermaid` |

## Правила
- Подписывай оси и добавляй заголовок.
- Не перегружай график: максимум 5–7 категорий для donut.
- Для sankey избегай циклов (A→B и B→A) — перестрой поток в одном направлении.
- Агрегируй данные в коде перед передачей в визуализацию.
- Проверяй доступные инструменты: `autovisualiser__*`, `show_chart`, `render_*`.

## Проверка
- [ ] Данные корректны (типы, суммы, отсутствие NaN)
- [ ] Заголовок и подписи осей на месте
