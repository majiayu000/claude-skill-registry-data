# Навык: Database

Моделирование данных и выбор хранилищ.

- Реляционные vs документные vs key-value — по природе данных и запросов
- Нормализация, индексы, транзакции, уровни изоляции
- Партиционирование, шардирование и репликация
- Миграции без простоя и обратная совместимость схемы

## Углублённо
- Реляционная БД → навык **postgresql** (индексы, EXPLAIN, транзакции, партиционирование).
- Документная БД → навык **mongodb** (моделирование, aggregation, sharding).
