# 求职信生成器（Cover Letter Generator）

## 何时使用此技能

当用户想要以下操作时使用此技能：
- 为求职申请撰写求职信
- 创建个性化的申请信
- 以信件形式回应具体的职位要求
- 提到：「求职信」「cover letter」「写求职信」「申请信」等

请在分析职位描述（JD）之后使用此技能，以获得清晰的论述要点。

## 核心能力

- 根据简历 + 职位描述生成个性化的求职信
- 使语气匹配公司文化
- 战略性地处理资质缺口
- 创作有吸引力的开头钩子
- 构建有说服力的求职论证结构
- 在有效推销的同时保持真实

## 求职信理念

**问题所在：** 大多数求职信千篇一律、枯燥乏味，除了简历之外没有增加任何价值。

**解决方案：** 一封出色的求职信应该：
1. 表明你研究过这家公司
2. 将「你」的具体经验与「他们」的具体需求联系起来
3. 回答「为什么是你、为什么是现在、为什么是这里」这三个问题
4. 增添简历无法传达的个性与背景

## 完美求职信的结构

### 长度与格式
- **长度：** 250-400 词（3-4 段）
- **格式：** 专业商务信函风格
- **语气：** 自信而不傲慢，个性化而专业

### 结构概览
```
[你的联系方式]
[日期]
[收件人信息]

开头段落：钩子 + 职位 + 为什么选择这家公司（2-3 句）

正文第一段：你最匹配的核心资质（3-4 句）

正文第二段：其他资质 + 处理短板（3-4 句）

结尾段落：行动号召 + 表达热情（2-3 句）

[专业落款]
```

## 开头段落策略

开头至关重要——你只有 5 秒钟时间抓住注意力。

### 钩子类型（任选其一）

**1. 具体的公司认知**
```
「看到智谱最近推出了你们的 API 开放平台，我非常激动——作为一名深耕开发者工具领域 3 年的产品经理，我立即意识到我的经验可以如何加速你们平台的增长。」
```

**2. 共同的联系人**
```
「你们工程团队的 Sarah Chen 提到你们正在寻找一位产品经理来主导支付业务。我曾在[上一家公司]与 Sarah 共事，并在[现在所在的公司]负责过支付集成工作，我很乐意进一步讨论我能做出的贡献。」
```

**3. 解决问题者**
```
「你们的职位描述中提到，让技术与业务相关方达成一致的挑战——我恰好应对过这一挑战，通过让工程、销售和高管团队共享路线图透明度，成功发布了 8 个产品。」
```

**4. 令人印象深刻的成就**
```
「去年，我主导的一款产品在 6 个月内用户从 0 增长到 10 万。我很期待将这种增长思维带入[公司]不断扩张的产品线。」
```

**5. 行业洞察**
```
「B2B 支付领域正处于拐点，[公司]在嵌入式金融方面的布局让你完美站位在下一波浪潮之上。作为一名在金融科技领域深耕 5 年的从业者，我很乐意为这一增长贡献力量。」
```

### 开头禁忌
- ❌ 「我写此信是为了应聘……」（乏味、显而易见）
- ❌ 「我是最完美的候选人……」（让他们自己判断）
- ❌ 「我在 LinkedIn 上看到你们的招聘信息……」（千篇一律）
- ❌ 以「我」开头（先谈他们，或用一个钩子开头）

## 正文段落框架

### 正文第一段：直接匹配

将你最核心的经验与他们的首要要求联系起来。

**公式：** [他们的需求] + [你的确切经验] + [具体成果]

```
你们对数据驱动产品决策的重视与我的工作方式高度契合。在[公司]，我搭建了一套产品分析体系，通过 A/B 测试和用户行为分析识别并优先处理高价值机会，使功能采用率提升了 40%。
```

### 正文第二段：更多价值 + 缺口处理

展示额外价值并主动回应疑虑。

**如果存在缺口，主动提及：**
```
虽然我的 SQL 能力仍在提升中（目前正在学习DataCamp 的 SQL 课程），但我通过搭建 Tableau 数据仪表盘，为涉及 200 万美元的战略决策提供了支持，展现了扎实的分析能力。我一直以来都能与数据团队高效协作，并有快速上手新工具的良好记录。
```

**如果没有缺口，补充更多价值：**
```
除了产品管理，我还能带来[相关补充技能]。在[公司]，这使我得以[具体成就]。我尤其向往[公司]，因为[体现做过调研的具体原因]。
```

## 结尾段落

以自信和明确的行动号召收尾。

**有力的结尾示例：**
```
我很期待将我在[具体技能]方面的经验带到[公司]的[具体业务或产品]中。我非常乐意与你们进一步探讨，说明我在[关键领域]的背景如何能为团队目标做出贡献。感谢你考虑我的申请。
```

**好的结尾要素：**
- 表达真诚的热情（针对某个具体的事物）
- 提及你能做出的一个具体贡献
- 明确的行动号召（面谈、会面等）
- 向对方致谢

**结尾禁忌：**
- ❌ 「期待你的回复」（被动）
- ❌ 「请查收随附的简历」（显而易见）
- ❌ 「我随时可以参加面试」（显得急切）

## 行业差异注意事项

### 科技/工程类
- 提及具体的技术栈
- 引用 GitHub、作品集或技术项目
- 表明你理解他们的技术栈

### 市场/创意类
- 在求职信本身中展现创意（适度即可）
- 引用他们的营销活动或品牌调性
- 包含相关指标（互动率、转化率等）

### 金融/咨询类
- 语气更正式
- 以资质/证书开头
- 强调分析的严谨性与成果

### 创业公司 vs. 大型企业
**创业公司：** 语气更轻松，展现拼劲，强调增长思维
**大型企业：** 更正式，强调流程经验与规模化经验

## 常见场景的处理

### 当你不知道招聘负责人是谁时
```
尊敬的招聘负责人，
或
尊敬的[部门名称]团队，
或
尊敬的[公司名称]招聘团队，
```
避免使用「敬启者 / To Whom It May Concern」（过于冷漠）

### 当你有人内推时
把内推放在最前面：
```
「你[团队]的[姓名]建议我就[职位名称]岗位与你联系。我曾与[内推人有交集的经历]，得知[公司]在[领域]的工作后非常期待。」
```

### 当你资历不足时
不要道歉。相反，着重强调：
- 可迁移技能
- 快速学习能力
- 真诚的热情
- 能够弥补短板的相关经验

### 当你资历过高时
解释你的动机：
```
「在带领大型团队 10 年之后，我很期待重返一线[职能]工作，回到一家能让我在[具体领域]直接创造影响的公司。」
```

### 处理职业转型时
```
「虽然我的背景是[原领域]，但我一直在通过[课程、项目等]积极积累[新领域]的技能。我在[可迁移技能]上的经验可以通过[具体关联]直接应用到[新岗位]上。」
```

## 质量核对清单

在交付任何求职信之前，请确认：

1. ✅ 以钩子开头（而不是「我写此信是为了应聘」）
2. ✅ 提及了具体的公司认知
3. ✅ 将经验直接关联到职位要求
4. ✅ 至少包含一个具体的量化指标/成就
5. ✅ 处理了任何明显的缺口（如适用）
6. ✅ 语气自信而不傲慢
7. ✅ 以明确的行动号召收尾
8. ✅ 篇幅为 250-400 词（3-4 段）
9. ✅ 没有错别字或语法错误
10. ✅ 能让读者想邀请这个人来面试
