# Visualize

- Create a self-contained or clearly structured local HTML visualization in the workspace.
- Use real supplied data, label assumptions, and include accessible text alternatives for important visuals.
- Verify the page in browser preview at desktop and narrow widths and check for console errors.
- Do not fabricate measurements or imply that an illustrative simulation is observed data.
