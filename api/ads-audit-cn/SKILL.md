# 国内投放账户审计

对非电商类投放账户做系统体检：结构、跑量、成本、素材、定向、落地页、合规，输出带优先级的整改清单。

## 数据契约

先确认平台与投放目标（线索/APP/短剧/小程序/电商引流/品牌），再要数据。接受 CSV/Excel 上传或粘贴，最低要求：

| 层级 | 必需字段（各平台导出名略有差异，按语义对齐） |
|---|---|
| 账户/计划层日报（近 14–30 天） | 日期、消耗、展示、点击、转化数、转化成本、深度转化数/成本 |
| 计划/单元层汇总 | 计划名、出价方式（oCPM/oCPC/手动）、目标出价、预算、状态、定向摘要 |
| 素材层汇总 | 素材名/ID、消耗、点击率、转化率、首次投放日期 |
| 可选 | 落地页 URL、转化回传方式（监测链接/SDK/API）、搜索词报告（搜索类） |

数据不齐时：明确列出缺什么、影响哪个判断，先做可做的部分，不要虚构数字。

## 流程

1. 判定平台与目标 → 读 `references/platform-checklists.md` 中对应平台清单（只读需要的那节）。
2. 算大盘：总消耗、转化量、加权转化成本 vs 目标成本；按天看趋势（起量/衰退/波动）。
3. 结构检查：在投计划数、预算集中度（Top3 计划消耗占比）、同质化计划内耗、学习期失败占比。
4. 成本分层：按计划把"消耗×成本"分四象限（高消耗高成本=优先整改；高消耗低成本=加预算；低消耗高成本=关停观察；低消耗低成本=提价/扩量测试）。
5. 素材检查：素材数量、上新频率、头部素材依赖度、衰退素材（详见 creative-fatigue-cn 的判据）。
6. 定向与出价：过窄/过宽、重叠内耗、出价方式与转化量是否匹配（oCPM 需要稳定转化回传）。
7. 转化链路：回传是否准确/延迟、落地页与素材承诺是否一致（详见 landing-page-audit-cn）。
8. 合规抽查：素材文案极限词、行业资质（详见 ad-compliance-cn）。
9. 输出报告：问题按"影响×整改成本"排序，每条给具体动作与预期影响。

## 通用红旗（跨平台经验值，需用账户自身历史校准）

- 单计划连续 3 天成本超目标 30%+ 且仍在消耗 → 优先处理
- Top1 素材消耗占比 >50% → 素材断档风险
- 近 7 天 0 上新素材 → 跑量衰退前兆
- 转化回传数与后台业务数差异 >10% → 先修数据再谈优化
- 同定向同素材多计划互抢 → 合并/分层，避免抬价内耗
- 学习期内频繁改价改定向（每天 >2 次）→ 模型反复重置

## 输出格式

```
## 投放账户审计报告（平台 / 目标 / 数据区间）
**健康分**：X/100　**总消耗**：¥X　**加权转化成本**：¥X（目标 ¥X）
### 🔴 立即处理（本周）
1. 问题 — 预估影响 ¥X/月 — 具体动作
### 🟡 优化机会（两周内）
### 🟢 做得好的
### 行动清单
| 优先级 | 动作 | 影响 | 工作量 | 预期效果 |
### 置信度：高/中/低 + 原因（缺哪些数据）
```

## 约束

- 所有阈值是行业经验起点，不是平台官方标准；与账户历史基线冲突时以基线为准。
- 不臆造转化价值；金额一律人民币；区分"平台口径转化"与"业务口径成交"。
- 只读分析，不代替用户执行改价/关停；给出的操作建议注明风险（如改价触发学习期重置）。
