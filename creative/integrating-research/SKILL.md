# Integrating Research

Map real scientific findings onto fictional universe formalism.

## Process

1. Read the research material fully
2. Read the target canon section(s) the research extends
3. Build the mapping chain:
   Real principle → what it says about reality → creative analogy → which canon section it fills
4. Draft the integration as status: draft
5. Present for author review

## Out of Scope

Does NOT search for papers (use /researching-papers).
Does NOT write final science files (use /writing-science).
