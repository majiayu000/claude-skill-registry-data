# Dobby 跨平台 Inline Hook 框架 技能卡

## 基本信息

- **中文名称**：Dobby 跨平台 Inline Hook 框架
- **来源仓库**：[jmpews/Dobby](https://github.com/jmpews/Dobby)
- **上游参考分支**：`master`
- **参考提交（使用前核对）**：`5dfc8546954ce3b3198132ab13fddb89ee92cdd7`
- **许可证线索**：Apache-2.0；文件：`源码\LICENSE`

## 功能概览

1. 在支持的平台上安装 inline hook 并生成 trampoline
2. 提供符号解析、指令重定位和原函数调用路径
3. 通过 C/C++ API 承载运行时拦截、观测和替换逻辑

## 适用范围

- 用于 native 函数观测/替换的底层 Hook 适配层，适合与 ABI 检查、线程调度和崩溃证据组合。

## 不能替代的边界

- 不负责目标函数定位、IL2CPP 元数据、ABI 推断、线程切换、反检测、网络协议或生命周期恢复；Hook 安装成功不等于业务成功。

## 输入与输出合同

```text
输入：模块基址、函数地址/符号、架构、替换函数签名、安装时机和卸载句柄。
输出：Hook 句柄、trampoline 地址、安装/卸载状态、调用日志和异常记录。
失败：指令不可重定位、地址未映射、签名不匹配、权限不足或并发卸载时必须失败闭合。
后置：输出必须绑定项目、目标版本、平台/ABI（如适用）、时间戳和证据路径。
```
