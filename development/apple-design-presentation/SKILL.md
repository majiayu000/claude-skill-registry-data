# Apple Presentation and Windows

## Apply the skill

Classify the need before selecting a presentation: urgent actionable information, a choice after an intentional action, a bounded task, supplementary controls, or independent content. Choose the least disruptive container that supports that need.

Specify the presenting context, initial focus, dismissal routes, commit and cancel semantics, unsaved work, and the destination after closing. Prefer recovery through undo when it is sufficient; reserve confirmation for consequences that justify interruption.

Check adaptation across the requested size classes and windowing environments. Presentations should preserve the originating task and remain usable with a keyboard and assistive technology. Avoid building a second application inside nested sheets.
