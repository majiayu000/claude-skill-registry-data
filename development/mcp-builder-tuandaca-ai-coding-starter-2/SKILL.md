# MCP Builder Skill

This skill provides Model Context Protocol development guidance.

- Protocol specification (JSON-RPC 2.0)
- Server capabilities (tools, resources, prompts)

- Transport mechanisms (stdio, SSE, WebSocket)

- Authentication and authorization

## Integration Patterns

- Remote MCP services
- Proxy and gateway patterns
- Capability negotiation
- Session management

## Ecosystem
