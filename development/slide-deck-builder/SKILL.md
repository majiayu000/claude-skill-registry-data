# Slide Deck Builder

Use this skill when the user has a topic but not a usable presentation structure yet.

## Workflow
- Define audience and deck objective first.
- Build the narrative arc before deciding slide count.
- Keep one clear point per slide.

## Deliverables
- A slide-by-slide outline.
- Optional speaker-note guidance.

## Guardrails
- Do not paste paragraphs onto slides.
- Do not let style outrun the argument.
