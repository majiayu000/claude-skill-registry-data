# Goal
- Given a target `<SRC>` (function, file, or directory), remove it cleanly, with no
  dangling references or dead code
- Identify what `<SRC>` is before proceeding

# If `<SRC>` Is a Function
- **Remove the function definition** from its source file
- **Find all callers** across the codebase and remove or refactor them
- **Remove orphaned helpers**: recursively remove functions now called only by
  `<SRC>` (or each other)
- **Remove tests** that exclusively test `<SRC>` or its orphaned helpers
- **Clean up imports** that were only needed by the deleted code

# If `<SRC>` Is a File or Directory
- **Remove the file/directory** from the repo
- **Find all references**: any `import`, `from ... import`, `require`, or path
  string pointing to `<SRC>`
- **Remove or refactor each reference**: delete the import and any dependent code,
  or replace it with a substitute if one exists
- **Remove related tests** that exclusively test the removed file/directory
- **Update configs** (e.g. `pyproject.toml`, `setup.py`, `__init__.py`,
  `MANIFEST.in`) that reference `<SRC>`

# After Removal (all Cases)
- Summarize the changes
- Do not commit any change

# Verification
- [ ] Run the test suite to confirm nothing is broken
- [ ] Run a final grep for the removed name to catch remaining references
