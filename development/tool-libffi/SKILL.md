# libffi 跨 ABI 动态函数调用 技能卡

## 基本信息

- **中文名称**：libffi 跨 ABI 动态函数调用
- **来源仓库**：[libffi/libffi](https://github.com/libffi/libffi)
- **上游参考分支**：`master`
- **参考提交（使用前核对）**：`71ce128d7acf4ef4c2c675c0751e2e37661dd868`
- **许可证线索**：MIT 风格（以 LICENSE 及源文件声明为准）；文件：`源码\LICENSE; 源码\LICENSE-BUILDTOOLS`

## 功能概览

1. 按运行时类型描述准备参数、调用 native 函数并读取返回值
2. 覆盖多种平台/架构的调用约定、结构体和闭包场景
3. 可嵌入脚本、插件或桥接层，减少手写汇编封送

## 适用范围

- 用于动态调用签名已确认的 native/IL2CPP 函数，补齐 ABI 与参数封送层。

## 不能替代的边界

- 不会定位函数地址、校验对象/线程、修复错误签名或保证业务结果；错误的类型布局、生命周期和线程会导致崩溃。

## 输入与输出合同

```text
输入：函数地址、ffi_cif、参数类型/值、返回类型、目标 ABI 和调用线程。
输出：函数返回值、errno/异常状态（若适用）、调用耗时和封送诊断。
失败：ABI 不支持、参数尺寸/对齐错误、空地址、异常返回或线程不允许时必须拒绝调用。
后置：输出必须绑定项目、目标版本、平台/ABI（如适用）、时间戳和证据路径。
```
