# Навык: React 19

Современный React (по react.dev).

## Компоненты и состояние
- Только функциональные компоненты + хуки; чистый рендер, побочки — в эффектах/обработчиках.
- Состояние минимально и локально; производное — вычисляй при рендере.
- Списки — стабильный `key`.

## Хуки
- Правила хуков: только на верхнем уровне.
- `useEffect` — синхронизация с внешним миром, корректные зависимости и cleanup.
- Логика — в кастомные хуки.
- React 19: `use()`, Actions, `useActionState`/`useOptimistic`.

## Мемоизация (по необходимости)
- `useMemo`/`useCallback`/`memo` — после замера, не заранее. React Compiler снимает часть ручной мемоизации.

## Server / Client Components
- Server по умолчанию; `"use client"` — интерактивность/браузерные API.
- Секреты сервера не тащить в клиент.

## Интернационализация (i18n)
- Пользовательский текст — через `useTranslation`/`t()` (или серверный аналог), не литералами в JSX; ключи типизированы; мн. число/род — ICU, форматы — `Intl`. В мультиязычном проекте — строгий запрет хардкода строк. Детали — `$i18n`.

## Надёжность
- Error Boundaries + понятный fallback; Suspense; состояния loading/empty/error.
