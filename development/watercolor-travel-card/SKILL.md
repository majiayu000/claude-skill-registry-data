# Watercolor Travel Card

## Delivery

- Use the source photo only as a reference for subject, structure, space, direction, and color. Stylize the entire final canvas; do not show the original photo or create split-screen or before-and-after layouts.
- Generate one standalone 3:4 vertical poster per source image. Process multiple images separately and never combine them in a single generation.
- If the user asks only for a prompt, return a ready-to-use image-generation prompt. Otherwise, use the available image generation or editing capability directly. Ask for an upload only when no reference image is available.
- Before generation, lock the subject's identity, count, pose, proportions, direction, architectural or terrain structure, spatial relationships, and viewpoint. Do not invent a location, date, coordinates, or attribution.

## Fixed visual specification

The entire canvas is a perforated watercolor travel memory card on warm ivory cotton cold-pressed paper, divided vertically:

- The left 68%–75% reconstructs the scene with transparent watercolor and a few fine pen lines. Preserve the most recognizable contours, pose, direction, colors, and spatial relationships. Remove clutter, repeated objects, micro-texture, and irrelevant detail without changing defining features.
- Keep the watercolor transparent and airy, with cold-pressed grain, pigment bloom and settling, broken linework, controlled washes, natural water marks, slight overrun, reserved paper highlights, and lightly unfinished edges. Let the environment fade naturally into the page.
- The right 25%–32% is a restrained travel archive column. Separate it with one evenly spaced row of uniform circular perforations so the composition feels like a collectible tear-off card.

Build a soft, limited watercolor palette entirely from the source image. Preserve its signature subject colors, overall temperature, and warm-cool relationships.

Derive a verifiable 2–3-word English title and a `NO. XX` identifier before rendering the text. Use an editorial serif or humanist sans serif. An ultra-thin rule and a tiny low-contrast decorative travel stamp are optional, but the stamp must not contain invented information.

## Quality boundaries

The result should feel like a quiet, transparent, gentle, restrained independent travel journal, vintage watercolor notebook, and collectible ticket card. Avoid visible source photography, collages, altered subjects, sticker borders, cartoons, children's-book styling, heavy gouache, oil paint, plastic 3D, slick digital illustration, hyper-real watercolor, dense typography, excessive text, invented facts, names, handles, logos, QR codes, real barcodes, watermarks, and garbled text.
