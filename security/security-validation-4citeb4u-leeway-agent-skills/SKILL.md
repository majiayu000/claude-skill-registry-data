# LeeWay Security Validation
Define written scope/authorization, targets, allowed techniques, safety limits, evidence handling and stop conditions before active testing. Prefer isolated/test environments for destructive techniques. Findings route to remediation/retest; do not turn validation capability into uncontrolled offensive operations.
