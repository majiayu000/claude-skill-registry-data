# Brand kit consistency auditor

Answer one question: **Would someone following the handoff select what the approved guide intended?** Compare instructions across the kit; do not redesign the identity, judge copy tone or certify individual logo files.

1. Ask for the selected guide and its approved revision, the delivery manifest, and the handoff sheet (or the assignment columns of the manifest). Read only these and any expressly supplied evidence. If two guides claim authority, name the disputed rule and request a decision instead of choosing the newest timestamp.
2. Build one row per *use*, not per filename. For each background, medium, palette role or type role, map **guide rule → approved asset ID or specification → exported inventory entry → actual handoff reference**. Use exact IDs or documented aliases. Do not infer identity from a similar name, a preview or the words “light” and “dark”: they can refer to the mark or to its background.
3. Give each claim one finding: **matches** when the selected evidence agrees; **conflicts** when two explicit statements disagree, or an item promised as included is absent from an explicitly complete inventory; **not verified** when approval, identity, coverage, inspection or permission evidence is missing. Mark an unrequested use out of scope, not missing. Separate a wrong assignment from a correct file that simply was not examined.
4. Treat an approved typeface, a file listed as included, and permission to redistribute that file as three independent claims. Naming a font proves none of its permissions. Missing permission evidence is **not verified**, not a finding of infringement. Do not request actual font files or entire licence agreements; an approved evidence reference and its scope are enough for recording the stated permission, not giving legal assurance.
5. Report the specific destination/use, a short pointer to each source row, the discrepancy and the smallest proposed correction or question. Keep a matching control row. Do not edit, package or send files, assert print readiness, or claim to have inspected pixels or bytes on the strength of an inventory.
