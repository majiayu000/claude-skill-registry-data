---
name: maintain-documentation
description: Revise owner READMEs, coordinate Manual updates or audit guidance.
---

1. Locate the canonical owner using [Responsibilities](../../context/contracts-and-instructions.md). Read its implementation and current guidance.
2. Check behavior, vocabulary, links and task routing for consistency. Remove stale duplication; link the authoritative source. Keep technical contracts in owner READMEs and context, and human controls and recovery in the Manual.
3. For Manual changes use the enabled documentation module's write-manual skill. For context authoring use maintain-context.
4. Verify each changed link and example. Run sync when routes or skills change. Report the coverage of the audit and remaining inconsistencies with concrete locations.
