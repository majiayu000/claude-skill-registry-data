# Decision Synthesis

Use when this capability directly owns the requested outcome.

## Procedure
1. Separate agreement, disagreement, and domain-specific constraints.
2. Do not average incompatible advice; explain the tradeoff.
3. Prioritize safety, user values, and reversible experiments when uncertainty is high.
4. End with a clear choice set or next action while preserving the user's agency.

## Output standard
Give a concrete result, decision aid, or next action. Keep assumptions visible and hand off work outside this skill's domain.
