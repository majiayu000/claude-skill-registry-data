# Vibe knowledge films

Read [the pinned upstream instructions](references/upstream-skill.md) for the requested task. Resolve its script, engine and reference paths from this package root. Referenced scripts, engine files and research references retain their original paths in this package. Work in an authorized task directory; preserve source attribution, uncertainty and the user's chosen scope. Package availability is not evidence that dependencies are installed or a task is complete. Keep user-specified language, duration, narration and music choices. Use original topics and artwork; the upstream example films are study references and are not redistributed here. Prepare ordinary Python/browser/FFmpeg dependencies locally, then render a real MP4 and inspect frames and audio. For Three.js spatial filmmaking use remotion-video; for HTML/GSAP motion use hyperframes-video.
