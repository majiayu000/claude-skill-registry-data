# 一稿多发（国内平台矩阵）

同一素材在不同平台必须"换文体、换钩子、换长度、换转化路径"。直接搬运=各平台都跑不动。

## 输入

源内容（文章/资料/脚本/视频文字稿）、核心卖点与不可改的事实（价格/资质/数据）、目标平台清单、各账号人设（可选）、转化目标。

## 平台改编规则

| 平台 | 文体与长度 | 钩子 | 转化路径 | 注意 |
|---|---|---|---|---|
| 公众号 | 长文 800–2500 字，结构化 | 标题+开头 3 行 | 小程序/企微/阅读原文 | 搜一搜埋词；广告标注 |
| 小红书 | 300–800 字笔记体，emoji 分段 | 标题≤20 字+封面大字 | 评论区/私信/店铺组件 | 真人感、优缺点都说、商业报备 |
| 抖音 | 15–60s 口播/分镜脚本 | 前 3 秒 | 小黄车/POI/私信 | 完播结构；每 5–8 秒一个信息点 |
| 视频号 | 30–90s，偏稳重/知识感 | 前 3 秒+字幕 | 微信小店/企微/公众号挂载 | 用户年龄偏大，信任背书优先；社交推荐权重高 |
| 知乎 | 800–2000 字回答体 | 首段直接给结论 | 好物推荐/知+组件/签名区 | 问题匹配（选已有高流量问题）；论证+来源，硬广感会被踩 |
| 微博 | ≤140 字核心+长文可选 | 热点话题词+情绪 | 链接/评论区 | 话题标签 1–2 个；抽奖/互动合规 |
| B站 | 3–8 分钟视频脚本或专栏 | 标题+封面+前 30 秒 | 评论区/悬赏/工房 | 信息密度与真实感；"恰饭"要坦诚，社区反感暗广 |

## 流程

1. 提炼源内容的"事实核"（卖点/数据/案例）与"可变壳"（语气/结构/长度）。
2. 按目标平台逐一重写：先定该平台钩子，再重组结构，最后换语气；每版标注埋的搜索词/话题词。
3. 一致性校验：价格/优惠/功效表述/资质全平台一致（一处违规全链路风险）；各平台转化入口与追踪参数（见 tracking-setup-cn）。
4. 排期建议：首发平台（通常公众号或抖音）→24–72h 内分发其余平台；热点内容当天发完。
5. 合规统一过一遍（极限词/功效/广告标注），输出各平台差异化风险提示。

## 输出格式

```
## 一稿多发方案（源内容 / 目标平台）
### 事实核（不可改）
### 各平台版本（按平台分节，含标题/钩子/正文或脚本/标签/转化入口）
### 发布排期表
### 合规与一致性校验结果
```

## 约束

- 不虚构源内容没有的体验/数据；改编只改表达不改事实。
- 平台规则冲突时（如知乎可留链接、小红书禁站外导流）按各平台规则分别处理，不统一硬塞链接。
