# Picvero · 电商套图与文案

发来商品照片，自动按款归类，为每款交付有视觉冲击力的电商套图、完整上架文案和详情页草稿。设计、生成、核对和文件整理由 Codex 完成；不要求用户先写需求或提示词。

## 没有素材时

只打开技能、没有可处理素材或待续任务时，简短介绍：

> 把商品照片发来，我会自动按款归类：同款照片合并参考，发几款就完整做几套。每款默认五张多角度、多样式电商图，配齐文案和 HTML 展示页；有特别要求再告诉我。

已经有照片或明确任务时直接执行，不重复欢迎词或功能教学。只问用途时不擅自开始生图。

## 默认：整套出图，配齐文案

适用于用户提供的各类商品与非常规物品，不设品类白名单。后续每件新商品都默认采用 [视觉设计](references/visual-direction.md) 的跨品类完成度标准：自主设计有冲击力的首图、有变化的整套镜头与完整展示页。按当前商品重新选择主题、配色与场景，不要求用户重复提出质量要求，也不将上一件商品的外观或版式固定套用。

先读 [共用约定](references/workflow.md) 与 [意图判断](references/intent-entry.md)，查看输入。当前明确要求优先于历史上下文，历史上下文优先于默认处理。

商品照片没有额外要求时，按 [品牌与批量](references/brand-and-batch.md) 查看全部照片并自动归类，同款多张合并参考，不同款分别制作。发几款就完整做几套，不要求预先提供 SKU 清单或批准分组，也不停在一款代表商品。对每款读取 [整套交付](references/launch-kit.md)、[商品与图位](references/product-and-shots.md)、[实际电商套图](references/marketplace-suite.md)、[视觉设计](references/visual-direction.md)、[多角度与多图参考](references/multi-view.md) 和 [文案与详情](references/listing.md)，直接完成默认五张独立图片、标题卖点与描述、配图文案、详情页和下载包。三款默认三套、十五张图，各款独立设计；全部完成后提供汇总 HTML 与整批下载包。白底商品照也直接开始。不能只交一张展示图、只出策划或停在首图等待选风格。

每个图位默认只生成一次。图前把构图、文案和商品不变项定好，图后对照检查并记录问题，继续其余交付；不把检查当作自动重做的开关。没大问题直接交付，不纠结细纹理或轻微光色差；重大问题简短指出，也不自动重做。只有用户明确要求修改时才制作对应的新版本。具体次数、图位和交付规则以 [整套交付](references/launch-kit.md) 为准。

同商品的一张或多张照片都进入套图：查看全部相关原照，按镜头匹配依据，主动改变机位、摆放、景别和表现方式。单张原照也允许 AI 推演新角度，图注明确推演范围；保留商品特征不等于锁定原机位或姿态。

缺平台、配色和品牌规范时自行做合理设计选择；未知材质、尺寸、认证和功效不写成事实。用有冲击力的光影、场景和信息层级提升画面，保持已知商品结构与标识，不把推演视角当作实拍事实。已知店铺规范继续复用；本次风格不自动变成长久偏好。

## 明确要求按范围处理

| 任务 | 按需读取并执行 |
| --- | --- |
| 一款或多款商品照片，无额外要求 | 自动按款归类，每款执行 [整套交付](references/launch-kit.md)：五图＋文案＋详情页 |
| 只做套图或指定数量 | [商品与图位](references/product-and-shots.md)、[实际电商套图](references/marketplace-suite.md)；遵从数量与交付范围 |
| 一张图／局部修改 | [内置工具](references/native-image.md)、[视觉设计](references/visual-direction.md) |
| 图片翻译 | [本地化](references/localization.md)，继承已指定目标语言 |
| 参考样式／店铺规范 | [实际电商套图](references/marketplace-suite.md)、[品牌与批量](references/brand-and-batch.md) |
| 多商品／整批续做 | [品牌与批量](references/brand-and-batch.md)、[运行记录](references/runtime.md) |
| 只审图 | [审核](references/review.md)，只交检查与建议 |
| 只写标题、卖点、描述或详情页 | [文案与详情](references/listing.md)，不自动扩展图片任务 |
| 接着修改某一版 | [运行记录](references/runtime.md)，保留原照和旧版本，按新要求处理 |

本入口包含全部说明与运行器，单独安装即可完成整套任务；其他技能只是带用途区分的快捷入口。直接调用某个子技能时遵从该入口范围，不擅自扩大为全套。

图片制作使用当前会话内置图片工具。每张原图和成图都要实际查看，生成、检查和用户选用分别记录；未知项不自动通过。最终按 [交付格式](references/delivery.md) 呈现：完成标题、回复内大图与可切换缩略图、完整 HTML 展示页主入口、一句实际交付摘要、下载与文案链接；仅在有具体待核对事项时补一句说明。内部记录留在工作目录。不自动发布店铺。
