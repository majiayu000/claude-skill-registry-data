# search-wechat

## 目标
在用户需要微信公众号文章或公众号资料时，通过只读抓取、搜索和浏览器读取获取文章正文、发布时间、作者、公众号名称与来源链接。

## 适用请求
- 读取用户提供的微信文章 URL。
- 搜索某公众号、某主题或某时间段的公众号文章。
- 查找微信文章的转载、引用、摘要或公开备份。

## 首选通道
- skill-only：优先用文章 URL、WebSearch/WebFetch、当前 Firefox 可见页面或用户复制文本只读获取文章正文，否则走兜底。
- 搜索时如果搜狗微信、`last30days API` 或浏览器可用，则可尝试只读搜索公开索引。
- 对给定 URL，优先使用可用抓取工具；失败时使用浏览器读取可见内容。

## 兜底通道
- 请用户提供具体微信文章 URL 后再进行只读抓取或浏览器读取。
- 使用普通 WebSearch 查找文章标题、转载、引用、镜像或公众号公开资料。

## 操作流程
1. 确认用户需要的是文章正文、公众号资料、历史文章列表还是引用来源。
2. 优先用文章 URL、WebSearch/WebFetch、当前 Firefox 可见页面或用户复制文本只读读取；不可用时走 URL + 浏览器或 WebSearch 兜底。
3. 搜索公众号文章时只读取公开索引和可访问页面；全程只读搜索/读取，不发起新的登录流程、不下单、不私信、不发帖、不写入平台，也不扫码、关注公众号、留言或转发。
4. 输出文章标题、公众号、作者、发布时间、原始 URL、转载 URL 和可读性限制。
5. 对转载来源进行标注，避免把转载页误认为原始发布页。

## 只读安全边界
- 只搜索和读取公开或用户提供 URL 可见的微信文章内容。
- 不发起新的微信登录/扫码流程；优先复用当前 Firefox 可见会话，不关注公众号、不留言、不点赞、不转发、不收藏。
- 不绕过付费、权限、删除、登录或地域限制。
- 不写入平台，不保存 Cookie、Token、二维码或会话信息。

## 验证方式
- 后续可运行：`dir C:\Users\Zhang\.config\opencode\skills\search-wechat\SKILL.md`
- 人工检查：确认流程为 skill-only + URL/WebSearch/当前 Firefox 可见页面，且明确只读。

## 已知限制
- 微信文章搜索索引不稳定，历史文章列表可能需要登录或公众号后台权限。
- 已删除、仅粉丝可见、付费或受限文章无法保证读取。
- 转载页面可能缺失原文图片、评论或阅读量。
