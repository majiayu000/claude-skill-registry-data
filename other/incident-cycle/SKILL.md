# Incident Cycle

Chain: ops-incident → feature-plan (fix) → feature-implement → feature-test → ops-deploy → pm-retrospective

## Process

1. Diagnose the incident: root cause analysis
2. Plan the fix
3. Implement the fix
4. Test thoroughly
5. Deploy the fix
6. Retrospective: what went wrong, how to prevent
