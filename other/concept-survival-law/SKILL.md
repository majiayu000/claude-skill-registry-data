# concept-survival-law

## When to Use

当试图建立或改变一个习惯、例行程序，但遇到阻力或难以坚持时description

## Core Logic

# 执行步骤

1.  **概念化目标行为**
    *   **输入**：希望建立的具体习惯（如“每日深度工作2小时”）。
    *   **操作**：将该行为提炼为一个简洁、有力的“概念”或身份标签（如“我是一个深度工作者”）。
    *   **判断标准**：这个概念能清晰定义行为，并可与个人身份产生联结。
    *   **输出**：行为对应的核心概念。

2.  **识别生存威胁**
    *   **输入**：核心概念、当前环境与日常流程。
    *   **操作**：分析哪些现有习惯、环境线索、社交规范或即时诱惑会对该概念的“生存”（即持续实践）构成最大威胁（如：随时查看手机的习惯、开放的办公室环境）。
    *   **判断标准**：准确找出1-3个最主要的、导致旧行为复发的“威胁源”。
    *   **输出**：概念生存的主要威胁列表。

3.  **设计防御机制**
    *   **输入**：概念生存威胁列表。
    *   **操作**：为每个威胁设计具体的、预先的行动方案来消除或减弱其影响（如：工作期间将手机放入锁柜；使用降噪耳机；告知同事勿扰时段）。
    *   **判断标准**：防御机制是主动的、可执行的，并能直接抵消特定威胁。
    *   **输出**：针对每个威胁的防御策略。

4.  **融入系统与身份**
    *   **输入**：核心概念、防御策略。
    *   **操作**：将防御策略固化为日常系统的一部分（如设定固定的勿扰时间），并内化核心概念为自我认知的一部分（通过自我对话、成果庆祝等方式）。
    *   **判断标准**：防御动作变成自动反应，且个人在心理上认同概念所代表的身份。
    *   **输出**：强化后的行为系统和身份认同。

# 输出格式要求
提供一个针对目标习惯的“概念生存”分析报告：
1.  **目标行为**：[具体描述]
2.  **核心概念**：[对应的身份或概念标签]
3.  **主要生存威胁**：
    *   威胁1：[描述]
    *   威胁2：[描述]
4.  **针对性防御机制**：
    *   针对威胁1：[具体策略]
    *   针对威胁2：[具体策略]
