# 库存优化技能

## 适用场景
用户询问“哪些物资要补货”“库存够不够”“在途还有多少”等。

## 数据获取
1. `inventory_risk`：低于安全库存的物资、缺口、在途、净缺口；
2. `inventory_page` / `inventory_check`：余额与盘点概览；
3. `issue_page`：近期领用记录，用于估算日均消耗；
4. `order_page` / `receipt_page`：在途订单与收货进度；
5. `warehouse_list`：仓库与库位；
6. `spend_analysis`：按分类的年度花费，辅助 ABC 分类。

## 计算口径
- 净缺口 = `max(安全库存 - 现存 - 在途未收, 0)`；
- 覆盖天数 = `现存 / 日均领用`（无领用数据时说明无法估算）；
- 补货优先级：净缺口 > 0 且覆盖天数 < 7 → 高；< 14 → 中；其余低。

## 输出格式
| 物资 | 仓库 | 现存 | 在途 | 净缺口 | 覆盖天数 | 优先级 |
|---|---|---|---|---|---|---|
| ... | 主原料仓 | 19 | 0 | 1 | 2.3 | 高 |

## 边界
- 只给建议，不自动创建申请或领用；
- 领用/收货必须走平台人工流程与权限校验；
- 无领用历史时不得臆造日均消耗。
