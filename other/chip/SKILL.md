# /chip — чипы, которые нажмёшь ТЫ

## Зачем это существует

Антон 31.07: «я хочу сам выбирать, когда мне нужны НОВЫЕ сессии с ЧИПАМИ, а когда чтобы ты
САМ ЗАПУСТИЛ… мне нужен КОНТРОЛЬ сессии в моих руках, особенно супер важных».

Автостарт видимых сессий заработал только 31.07 — механизм молодой. Пока доверие не
набрано, на важном Антон держит палец на кнопке. Чип здесь — **его выбор**, а не моя
отговорка «делегировал и забыл» (за неё гейт `chip_guard` бьёт по-прежнему).

Парная команда: **`/nsr`** — там сессию поднимаю я сам.

## ⭐ ДЕФОЛТ-МАРШРУТИЗАЦИЯ (anton 14.08, supersedes таблицу 31.07)

**Дефолт для ЛЮБОГО типа задачи = автозапуск** (`/nsr`, видимая сессия): anton 06.08
«все ставь на автозапуск, у меня нет времени нажимать ЧИПЫ». Замер, закрепивший это:
04.08–13.08 заведено +8 чипов, нажато 0; всего висело 118 из 359 (33%).

**Чип разрешён ровно в двух случаях** (anton 14.08 «важнО! мы оставляем ЧИПЫ как
функционал и используем ТОЛЬКО ЕСЛИ ЮЗЕР САМ ПОПРОСИЛ НОВУЮ СЕССИЮ ЧИПОМ»):
1. юзер сам, словами, попросил чип в ЭТОМ запросе («в чип», «сделай чипом», `/chip`);
2. задаче нужны физические руки человека (2FA/UAC/QR) — маркер `ТРЕБУЕТ РУК АНТОНА:`.

Сомнение → автозапуск, НЕ чип. По своей инициативе чип не завожу никогда.
Если долг висяков растёт (строка «🧷 чипы» на старте сессии) — называю цифру вслух
ДО создания чипа; решает юзер. Канон: Библия `reglament-chipy-tolko-po-pryamomu-zaprosu-yuzera`.

## Как выполнять

**Шаг 1. Понять, сколько чипов.** Одна задача — один чип. Не дроби мелочь ([[ak47-simplicity]]):
если кусок ≤2 минут и обратим — сделай его здесь, чип не нужен.

**Шаг 2. Собрать сид по контракту.** Чип стартует ПУСТУЮ сессию: контекста этого разговора
она не увидит. В `prompt` обязаны быть:
`Outcome` · `Контекст` (из RECALL, не «см. выше») · `Scope` (шаги) · `Deliverable` · `DoD`
(чем доказано) · `не-цели` · `куда эскалировать` · **срок годности**: строка
«сид актуален до <дата создания +7 дн>; если нажат позже — сперва RECALL, что уже
сделано/изменилось, вслепую не исполнять» (ретро 13.08: оба чипа 04.08 несли инструкции,
неверные уже назавтра — несуществующий дефект, снятое окно 24ч, несуществующую команду).
Плюс граница Tier-2 одной строкой: деньги / необратимое удаление / исходящее 3-м лицам /
секреты — НЕ исполнять, стоп + `approval.py ask`.
⛳ Плюс строка-рефлекс (anton hub:5090; текст и формат ответа — в `/skill-gap` §⛳):
`⛳ ВХОД: что из этой задачи уже должно быть скиллом — а если скилл есть, чего ему не хватило? Ответь ОДНОЙ строкой до начала работы (/skill-gap).`

📛 **И блок STOP-DUP в КАЖДЫЙ сид** (сводный вердикт 07.08, «+» Антона 14.08): `cat $OBSIDIAN_VAULT/08-Templates/seed-stop-dup-block.md` → вставь блок ЦЕЛИКОМ и ДОСЛОВНО (на 30.08 там 6 строк: 📛 ON AIR · 👤 консолидатор · 🔁 RECALL ЛЕТЯЩЕЙ · 🪫 бак · 🔍 улика · ⏳ премисса с ранним выходом; число строк смотри В ФАЙЛЕ, не здесь — счётчик в пяти местах расходится). Один источник — правится только тот файл, копий здесь нет.

**Шаг 3. Поставить маркер.** Первой строкой `prompt`:
```
ВЫБОР АНТОНА: /chip — эту сессию он запускает сам, когда решит.
```
Без маркера гейт `chip_guard` отобьёт вызов (и правильно сделает: он не умеет отличать
осознанный чип от брошенного).

**Шаг 4. Создать чип** инструментом `spawn_task`: `title` — императив ≤60 симв,
`tldr` — 1–2 предложения без путей, `prompt` — сид из шага 2, `cwd` — рабочая папка.

**Шаг 5. Сказать вслух.** Чип — не почтовый ящик: назови Антону, сколько чипов сделал и
что в каждом, ОДНОЙ строкой на чип. Молчаливый чип = невыполненная задача.

**Шаг 6. Записать в реестр** `10-Tasks/task-*.md` — сессия И запись, никогда одно вместо
другого (иначе через неделю никто не вспомнит, зачем чип).

## Границы

- ⛔ Не выдавай чип за результат: «сделал чипы» ≠ «работа сделана». Замер 28.07: 107 из 346
  чипов не нажаты никогда → долг видно в `python ~/.claude/scripts/chip_debt.py`.
- ⛔ Маркер `ВЫБОР АНТОНА: /chip` ставит ТОЛЬКО этот скилл по прямой команде. Ставить его
  самому, чтобы обойти гейт, — подлог.
- Tier-2 внутри порождённой сессии не ослабляется.
- Хочешь наоборот, чтобы я запускал сам всегда → `python3 ~/.claude/scripts/session_mode.py --set auto`
  (это дефолт), а глобально на чипы → `--set chip`.

## Как понять, что работает

```
python3 ~/.claude/scripts/_test_session_mode.py
```
Ждём «ВСЁ ЗЕЛЕНО»: гейт пропускает чип с маркером и отбивает без него.
Каждая попытка пишется в `~/.claude/hooks/_chip_guard.log` — иначе не отличить «гейт
молчал» от «гейт ни разу не сработал».
