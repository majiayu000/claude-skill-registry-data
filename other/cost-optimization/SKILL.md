# 成本优化方案Skill

## 适用场景
云资源成本持续上升或需要完成降本目标,基于用量评估数据(Skill:资源用量评估)制定可落地的降本方案。

## 执行步骤
1. 先出账单归因:按资源类型/环境/项目/标签拆解账单,找出成本大头与增长来源。
2. 规格匹配:比对实例规格与实际水位,长期低水位(<30%)降配,峰谷差异大走弹性。
3. 闲置回收:识别长期无流量实例、未挂载存储、过期快照/镜像、闲置公网 IP 与负载均衡,逐项确认后回收。
4. 存储分层:按访问频率将数据迁入冷/归档层,生命周期策略自动沉降。
5. 算力降本:训练/推理任务按需调度、闲时抢占、按量计费与包年结合、模型推理降级/批处理合并。
6. 输出降本方案:每项措施附收益预估、实施窗口、风险与回滚方式、责任人。

## 规范要点
- 先评估后动手:任何回收/降配必须基于用量数据,禁止拍脑袋缩减。
- 降本不降可靠性:资源水位不得低于安全余量,可用性指标不允许因降本劣化。
- 变更可回滚:每项措施执行前确认回滚方式(快照/备份/镜像留存),高风险项分批执行。
- 效果要量化:每月核算实际节省金额,与预估对比,偏差大的复盘原因。
- 安全红线:生产实例降配、数据删除/迁移、存储降层等敏感操作需「总控 + 安全合规」双签名审批;所有变更操作留痕,数据销毁需二次确认并记录。

## 输出模板
```
## 降本方案
成本归因分析 / 措施清单(方向|措施|预估节省|风险|回滚方式|责任人) / 实施排期 / 效果核算口径
```

## 自检清单
- [ ] 措施均基于用量数据
- [ ] 每项措施有风险与回滚方式
- [ ] 未牺牲可用性与安全余量
- [ ] 生产敏感操作具备双签名审批与留痕
