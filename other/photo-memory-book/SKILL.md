# 照片记忆册

交付一张像真实摄影小册子摊开时拍下的画面。默认 3:4 竖幅画布，横向打开的双页书居中，书本周围少量桌面留白。它是书册效果图，不宣称可翻页、印刷 PDF 或照片无损。

查看所有输入。单图时用一个主要照片版面和最多两个来自同图的细节裁切，不虚构第二天或另一地点。多图时按用户顺序或可确认的内容关系分组；不把未提供的拍摄日期、地点、人物经历写成事实。

选择一个主视觉页：照片应占该页大半面积，有摄影原貌和可辨认主体；另一页用较小的细节照片、简短文字和宽留白建立节奏。跨页装订缝自然、书页轻微弯曲、厚度真实，文字顺随页平面。采用乳白无涂布纸、细腻印刷颗粒，配色由来源照片决定。避免贴纸、胶带、撕边、花朵等无关道具堆叠，也不让每个版面都是等尺寸照片格子。

默认一行中文标题（约 4–8 字），小字用简短英文；可按用户要求改变语言或完全不加字。把所有可见文字逐字列入生成提示词，不生成密集假文案。标题表达情绪而非编造个人履历。

把原照片作为参考调用图像编辑工具。生成时尽量保持照片主体和核心环境，但说明图像模型会重绘，不能保证精确保留原图；若用户要求原图像素不变，应改用确定性排版工具并据实说明能力。

检查标题拼写、来源辨识、照片裁切、装订线、页面透视和文字可读性；最多一轮针对性修订。保存图片和实际提示词。独立使用本目录规则，不读其他 Skill 的排版规范；不自动发布。无生成工具时只交付提示词并明确状态。

## 复杂输入的取舍

输入是拥挤多主体时，主图保留用户关心的组合；细节裁切只能来自本图，不重复生成新的主体。字句长时先缩短文案再调整字号。单页小图不能大过主视觉。用户提供两张以上照片时先确认顺序或用上传顺序，本轮单图测试不代表多图编排已验证。
