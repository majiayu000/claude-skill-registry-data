# ai-pptx PPT 诊断助手

[快速开始](https://github.com/allinherog-star/ai-skills/tree/main#%E5%BF%AB%E9%80%9F%E5%BC%80%E5%A7%8B)

[更多技能](https://ai-skills.ai)

### 概述

PPT 诊断助手用于回答「PPT 讲清了吗」、文档处理、资料审阅、摘要，适合运营、产品、市场营销、technical在明确业务目标、内容材料或分析对象后调用。
它会结合幻灯片文字或讲稿、可粘贴逐页标题、正文、备注、讲稿、目录或平台解析出的幻灯片文本。等输入，整理关键上下文，并输出摘要、诊断结论、行动建议和可复用交付物，便于继续执行、复盘或交付。

### 什么时候使用

**适用场景**

- 用户提出“PPT 讲清了吗”这类问题，需要快速拆解目标、判断重点并形成可执行结果
- 运营、产品、市场营销、technical需要围绕PPT 诊断助手生成摘要、诊断结论、行动建议和可复用交付物
- 用户已经准备了演示目标（例如融资、销售、汇报、培训、路演、复盘、说服决策或争取资源。）、听众对象（说明这套演示面向谁，例如投资人、客户、管理层、培训学员或评审委员会。）、公开演示链接（填写无需登录即可访问的演示文稿链接；受权限保护的 deck 请改为上传或粘贴逐页文…），希望整理成可执行的分析或优化结果
- 用户需要把PPT 诊断助手相关材料转成清晰结论、优先级和下一步动作


### 参数说明

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `goal` | string | 否 | - | 例如融资、销售、汇报、培训、路演、复盘、说服决策或争取资源 |
| `audience` | string | 否 | - | 说明这套演示面向谁，例如投资人、客户、管理层、培训学员或评审委员会 |
| `materialUrl` | string | 否 | - | 填写无需登录即可访问的演示文稿链接；受权限保护的 deck 请改为上传或粘贴逐页文字；需要传可访问的完整 URL |
| `materialFile` | string | 否 | - | 上传需要审阅、重排、优化讲述或生成简报的 pptx/ppt/pdf 文件 |
| `materialText` | string | 否 | - | 可粘贴逐页标题、正文、备注、讲稿、目录或平台解析出的幻灯片文本 |
| `brandRequirements` | string | 否 | - | 补充品牌调性、术语、视觉限制、必须保留页面、合规要求和不可公开信息 |

完整机器可读参数结构见 `references/form-schema.json`。

### 交付内容

- 摘要、诊断结论、行动建议和可复用交付物：围绕用户目标整理可直接阅读、复盘或交付的核心结果。
- 输入材料解读：结合演示目标（例如融资、销售、汇报、培训、路演、复盘、说服决策或争取资源。）、听众对象（说明这套演示面向谁，例如投资人、客户、管理层、培训学员或评审委员会。）、公开演示链接（填写无需登录即可访问的演示文稿链接；受权限保护的 deck 请改为上传或粘贴逐页文…）提炼关键上下文和判断依据。
- 下一步动作：给出优先级、执行建议或可继续加工的内容框架。

### 结果使用建议

- 先判断输出是否回答了用户关于「PPT 诊断助手」的核心问题。
- 再检查结果是否覆盖摘要、诊断结论、行动建议和可复用交付物，以及是否给出明确下一步动作。
- 如果输入材料较少，建议让用户补充目标、受众、限制条件或原始材料后再运行。
