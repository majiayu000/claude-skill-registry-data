# 代码审计

## 何时使用

对指定代码路径检查正确性、权限、数据处理与实际缺陷。

## 执行要点

- 沿输入、信任边界、状态变化和敏感操作定位目标调用链。
- 核对校验发生的层级和顺序，检查错误分支与并发条件。
- 给每个发现明确触发输入、影响与证据，避免把未复核的扫描命中当缺陷。
- 提供最小修改和会因原问题失败的回归检查，保留原接口语义。

## 交付与验收

可复现发现、调用链、修复差异和回归结果。每个结论注明对应输入、版本与证据；运行条件不满足时说明已确认范围与未验证部分。
