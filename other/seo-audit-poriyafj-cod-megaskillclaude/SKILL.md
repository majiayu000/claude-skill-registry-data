# SEO Audit

Structured SEO audit with an actionable fix backlog.

## Areas
1. **Technical** — crawlability (robots, sitemap), indexation, canonicalization, redirects/chains, status codes, pagination, hreflang.
2. **Performance** — Core Web Vitals (LCP/INP/CLS), image weight, JS bloat, caching.
3. **On-page** — titles/metas (unique, intent-matched), heading structure, thin/duplicate content, media alts.
4. **Content & intent** — top pages vs target queries, content gaps, cannibalization, freshness.
5. **Schema** — org, article, product, FAQ — valid and rich-result eligible.
6. **Links** — internal-link depth (<=3 clicks), orphan pages, anchor distribution.

## Method
- Findings format: issue → evidence (URLs) → impact (H/M/L) → effort → exact fix.
- Prioritize: indexation blockers P0; CWV/critical on-page P1; links/schema P2.

## Output
Audit report (scorecard per area + fix backlog table + 30/60/90 plan).
