# Проверить результат

1. Назови исходные данные и критерий результата.
2. Сверь каждое утверждение или пункт результата с входом. Пометь добавленное без основания.
3. Проверь пропуски, повторения, выдуманные числа и противоречия.
4. Для исполняемого результата покажи реально выполненную команду и её exit-код,
   если запуск был разрешён. Для текста покажи конкретную сверку; кодовый тест не нужен.
5. Дай статус: проверено по названному критерию / нужны исправления / не проверено.

Выход: критерий → что проверено → расхождения → статус.
Рассуждение не выдавай за выполненный тест. Деньги, отправка или удаление не служат проверкой.

## Квитанция первого запуска

Квитанция одна на установку: `~/Second-Brain-Lite/My-Work/receipts/lite-<дата>.md`. Все пути ниже
от `~/Second-Brain-Lite/`. Поля всегда одни и те же, по одному на строку, `поле: значение`.
Время пиши в UTC в виде `2026-11-03T20:15:00Z`. Неизвестное пиши `UNKNOWN`, не угадывай.

Заполняют двое. Первый чат (тот, что ставил) после первой задачи пишет всё, кроме `first_recall`,
`owner_accept` и `elapsed`, и ставит там `UNKNOWN`. Новый чат после самостоятельного поиска по
FIRST-TASK.md открывает тот же файл и дописывает эти три поля. Квитанции нет: создай её с `UNKNOWN`.

| Поле | Что писать | Откуда брать |
|---|---|---|
| `release` | номер версии и первые 12 знаков суммы архива | `lite/VERSION`, строка `archive_verified` в `lite-install.log` |
| `os_shell` | система и оболочка, например `Windows 11 / PowerShell 5.1` | вывод команды, не догадка |
| `agent` | приложение и его версия, например `Codex 0.141` | то, что приложение сообщает о себе |
| `start` | время начала | первая строка `started` этой версии в `lite-install.log` |
| `archive_verified` | время проверки архива | строка `archive_verified` |
| `installed` | время установки | строка `installed` |
| `first_recall` | время, когда новый чат сам нашёл заметку, и `PASS`/`FAIL`/`UNKNOWN` | часы в момент проверки по FIRST-TASK.md |
| `owner_accept` | время, когда владелец сказал «полезно», или `UNKNOWN` | его ответ |
| `elapsed` | минуты от `start` до `first_recall`, если оба известны | вычислить, иначе `UNKNOWN` |
| `assistance` | `сам` или `с помощью` (кто помогал, без имён: `друг`, `Антон`) | владелец |
| `retries` | сколько раз повторяли шаг 1 для этой версии | строки `archive_verified` с этой версией в `lite-install.log` минус одна; журнала нет: `UNKNOWN` |
| `status` | `done` / `blocked` / `abandoned` / `unknown` и до какого шага дошли | итог |
| `friction` | где застряли: шаг, что случилось, сколько минут потеряли; пусто, если нигде | наблюдение, коротко |

В квитанцию **не** пиши содержание задачи и заметок, личные пути, имена людей, пароли и ключи.
Квитанция лежит только у владельца. Отправлять её кому-либо можно только по его отдельной просьбе;
сам ничего не отправляй.
