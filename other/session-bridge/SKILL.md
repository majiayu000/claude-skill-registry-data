# Session Bridge

Read `../../references/SESSION_BRIDGE.md`.

Use the existing `00_project/HANDOFF.md` as the canonical human-readable handoff.

1. Read pipeline progress, active work unit/decision map, current resource-handoff state, and authoritative artifacts.
2. Summarize only what the next session needs.
3. Reference existing artifacts instead of copying them.
4. Name suggested Story-Film skills for the next task.
5. Redact API keys, passwords, bearer tokens, private credentials, and unrelated personal data.
6. Never claim a blocked or running ComfyUI batch is complete.
