## 安全指导原则
1. 确保输入的地理位置信息准确，避免泄露个人隐私。
2. 不要在公共场合大声朗读天气信息，以防信息泄露。
3. 注意天气变化，及时调整出行计划，确保人身安全。
4. 不要依赖天气信息进行重要决策，如股票投资等。

针对天气使用中可能遇到的常见问题,提供以下排查方案:

| 错误类型 | 原因分析 | 解决方案 |

| 文件格式不支持 | 扩展名不在支持列表中 | 转换为支持的格式后重试 |
| 权限不足 | 当前用户无读写权限 | 检查文件权限,以管理员身份运行 |
| 命令执行失败 | 参数错误或环境依赖缺失 | 检查命令语法,确认依赖已安装 |
| 进程超时 | 命令执行时间过长 | 增加超时设置,优化命令参数 |
