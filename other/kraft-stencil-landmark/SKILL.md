# Kraft Stencil Landmark

## Applicability, delivery, and mode selection

- Use only for a clearly isolated landmark or object with a strong single silhouette, such as a lighthouse, tower, gateway, monument, windmill, pavilion, bridge tower, or lone boat. If no single subject is recognizable, do not impose a stock landmark.
- Produce one standalone 3:4 vertical poster per source image. Never combine photos.
- Offer two modes when the user has not already chosen:
  1. **Split comparison** — true source photo above, kraft stencil print below.
  2. **Full canvas** — the whole poster becomes a kraft stencil print.
- Use one mode for all uploaded photos unless the user maps modes per image.
- Read only the selected guide: [split-comparison.md](references/split-comparison.md) or [full-canvas.md](references/full-canvas.md).
- Return a ready-to-use prompt only when explicitly requested; otherwise use the available image generation or editing capability.

## Shared visual rules

Use the source as the only content reference. Preserve subject identity, count, orientation, height-width ratio, viewpoint, top, base, and 2–6 defining internal openings. Keep only the minimum ground, shoreline, rock, or water connection needed for recognition. Never add people, birds, boats, trees, decoration, or regional symbols absent from the source.

Use one continuous dark natural-fiber paper color derived from the source shadows and one opaque light stencil ink derived from the subject. The print is strictly two-color or near-two-color. Recognition must come from one large continuous light negative shape plus a few dark internal openings, not detailed lines or photo shading.

Keep the upper structure and defining silhouette firm. Toward the lower edge, reduce ink coverage through natural stencil gaps and exposed paper fibers until the paper ground becomes dominant. Use local, irregular printing variation only; never use digital blur, transparency, fog, regular screens, or pixel effects.

Before rendering, choose and lock exactly one truthful uppercase English scene word. Render only that word in the same light ink, as small readable stencil type in edge space. If a place is uncertain, use a subject or mood word rather than guessing a name.

## Avoid

Ordinary silhouettes, vector icons, travel logos, automatic tracing, threshold photo filters, detailed etching, dense hatching, regular halftones, multicolor printing, realistic shadows, dimensional paper craft, complete scenic backgrounds, stock landmarks, added scenery, extra text, misspellings, random characters, signatures, logos, QR codes, URLs, and watermarks.
