# 健康管理方案生成 Skill

本 Skill 指导健管智能体基于用户健康数据，生成结构化、可执行的个性化健康管理方案。

## 适用场景

当用户明确要求"制定""生成""规划"健康管理方案时加载本 Skill。仅用于查询解读的场景不加载。

## 加载前置条件

生成任何方案前，**必须**先通过工具查询必要的健康数据，禁止凭空生成：

| 方案类型 | 必查工具 | 可选工具 |
|---------|---------|---------|
| 饮食方案 | `query_health_metrics`、`query_disease_profile` | `query_medication_record`、`query_examination_report` |
| 运动方案 | `query_health_metrics`、`query_disease_profile`、`query_medication_record` | `query_examination_report` |
| 用药管理方案 | `query_medication_record`、`query_health_metrics` | `query_disease_profile`、`query_examination_report` |
| 综合方案 | 以上全部 | — |

查询完成后，基于真实数据生成方案，禁止编造用户指标。

## 方案类型识别

根据用户表述判定方案类型，可同时生成多个：

- **饮食方案**：饮食、食谱、吃什么、热量、营养、忌口
- **运动方案**：运动、锻炼、活动、健身、运动处方
- **用药管理方案**：用药、服药、吃药、药物、用药提醒、用药调整
- **综合方案**：健康管理方案、整体方案、全面方案（同时输出饮食+运动+用药）

## 一、饮食方案生成规范

### 必填字段（缺一不可）

1. **每日总热量目标**：明确数值（kcal/天），基于 BMI、活动量、疾病状态计算
2. **三大营养素配比**：碳水/蛋白质/脂肪的百分比和克数
3. **食物推荐清单**：分类列出推荐食物
4. **食物禁忌清单**：明确列出需避免或限制的食物
5. **一日三餐参考食谱**：早/中/晚的具体食物和分量
6. **饮食注意事项**：进餐顺序、烹饪方式、特殊疾病约束

### 热量计算依据

- 标准体重 = 身高(cm) - 105
- 轻体力劳动：25-30 kcal/kg/天
- 中体力劳动：30-35 kcal/kg/天
- 超重/肥胖：在计算值基础上下调 500 kcal/天
- 糖尿病：碳水占比 50-60%，蛋白质 15-20%，脂肪 25-30%

### 疾病特异性约束

- **糖尿病**：低 GI 食物为主，禁单糖/双糖，定时定量，少食多餐
- **高血压**：低盐（<5g/天），增钾，限酒，DASH 饮食模式
- **高脂血症**：低脂（<总热量 30%），降 LDL（饱和脂肪 <7%），增膳食纤维
- **糖尿病肾病**：限蛋白（0.8g/kg/天），低钾低磷
- **高尿酸**：低嘌呤，禁动物内脏/海鲜/浓汤，戒酒，多饮水

### 输出模板

```
【饮食管理方案】

一、热量目标
- 每日总热量：XXXX kcal
- 标准体重：XX kg（计算依据：身高 XXX - 105）
- 计算说明：[活动量等级] × [每公斤热量] × 标准体重 [±调整]

二、营养素配比
| 营养素 | 占比 | 每日摄入量 |
|--------|------|-----------|
| 碳水化合物 | XX% | XXX g |
| 蛋白质 | XX% | XX g |
| 脂肪 | XX% | XX g |
| 膳食纤维 | — | ≥25 g |

三、推荐食物
- 主食类：[具体食物]
- 蛋白质类：[具体食物]
- 蔬菜类：[具体食物]
- 水果类：[具体食物，注明限量]
- 油脂类：[具体食物]

四、禁忌/限制食物
- [食物1]：[原因]
- [食物2]：[原因]

五、参考食谱
早餐（XX kcal）：[具体食物和分量]
午餐（XX kcal）：[具体食物和分量]
晚餐（XX kcal）：[具体食物和分量]
加餐（可选，XX kcal）：[具体食物]

六、注意事项
1. [进餐顺序建议]
2. [烹饪方式建议]
3. [疾病特异性约束]
4. [其他]
```

## 二、运动方案生成规范

### 必填字段（缺一不可）

1. **运动风险评估**：基于疾病和并发症判定运动风险等级
2. **运动类型推荐**：有氧 + 抗阻 + 柔韧性，分项列出
3. **运动参数**：频率、时长、强度（明确量化）
4. **分阶段目标**：初始期 → 进阶期 → 维持期
5. **注意事项**：疾病特异性禁忌和监测要求

### 运动风险评估

根据疾病情况判定风险等级：

- **低风险**：单纯超重、轻度高血压（控制良好），可中等强度运动
- **中风险**：糖尿病（血糖控制一般）、2级高血压，需运动前评估，中低强度起始
- **高风险**：糖尿病并发症（肾病/视网膜病变/神经病变）、3级高血压、心血管疾病，需医生评估后方可运动，仅低强度

### 运动强度量化

- **有氧运动**：目标心率 = (220 - 年龄) × 50%-70%（中低强度）或 60%-80%（中等强度）
- **RPE 量表**：主观疲劳感 4-6/10（中等强度）
- **抗阻训练**：每组 8-15 次，2-3 组，组间休息 60-90 秒

### 疾病特异性约束

- **糖尿病**：运动前后测血糖，血糖 >13.9 或 <5.6 mmol/L 时不宜运动，携带糖块
- **高血压**：避免屏气动作（如大重量抗阻）、头低位动作，运动前血压应 <160/100
- **糖尿病视网膜病变**：避免剧烈跳跃、头低位、Valsalva 动作
- **糖尿病肾病**：避免高强度运动，以中低强度有氧为主

### 输出模板

```
【运动管理方案】

一、运动风险评估
- 风险等级：低/中/高
- 评估依据：[疾病情况、并发症、当前指标]
- 医生评估要求：[是/否]

二、运动目标
- 短期目标（4周）：[具体目标]
- 中期目标（12周）：[具体目标]
- 长期目标（6个月）：[具体目标]

三、运动处方
| 项目 | 有氧运动 | 抗阻训练 | 柔韧性训练 |
|------|---------|---------|-----------|
| 类型 | [快走/游泳/骑车] | [弹力带/自重] | [拉伸/瑜伽] |
| 频率 | X 次/周 | X 次/周 | X 次/周 |
| 时长 | XX 分钟/次 | XX 分钟/次 | XX 分钟/次 |
| 强度 | 心率 XX-XX 次/分 | 8-15次/组，X组 | 拉伸至有牵拉感 |

四、分阶段计划
初始期（第1-2周）：[具体安排]
进阶期（第3-8周）：[具体安排]
维持期（第9周起）：[具体安排]

五、注意事项
1. [疾病特异性监测要求]
2. [运动禁忌]
3. [热身和放松要求]
4. [异常情况处理]
5. [装备和环境建议]
```

## 三、用药管理方案生成规范

### 必填字段（缺一不可）

1. **当前用药清单**：基于查询结果列出，不增删
2. **用药依从性评估**：基于查询数据的依从性分析
3. **用药提醒方案**：时间、剂量、注意事项
4. **用药监测建议**：需定期复查的指标和频率
5. **风险提示**：需医生确认的调整建议（不直接给出换药/停药指令）

### 重要约束

- **本方案仅提供用药管理建议，不替代医生处方**
- 禁止建议用户自行换药、停药、加量、减量
- 发现用药问题（如药物相互作用、剂量异常）时，提示"建议咨询主治医生"
- 用药提醒方案基于现有处方，不修改处方内容

### 输出模板

```
【用药管理方案】

一、当前用药清单
| 药品名称 | 剂量 | 频次 | 类别 | 开药医生 | 状态 |
|---------|------|------|------|---------|------|
| [基于查询结果填写] |

二、用药依从性评估
- 依从性评分：XX%
- 存在问题：[基于查询数据]
- 改善建议：[具体措施]

三、用药提醒方案
| 时间 | 药品 | 剂量 | 注意事项 |
|------|------|------|---------|
| 早餐前 30 分钟 | [药品] | [剂量] | [空腹服用] |
| 早餐后 | [药品] | [剂量] | [餐后服用] |
| ... | ... | ... | ... |

四、用药监测建议
| 监测指标 | 频率 | 目标值 | 当前值 |
|---------|------|--------|--------|
| [基于疾病和用药] | [X次/周或月] | [目标范围] | [当前值] |

五、风险提示
1. [需医生确认的问题]
2. [药物相互作用风险]
3. [副作用监测要点]
⚠️ 任何用药调整须由主治医生确认，请勿自行更改。
```

## 四、综合方案输出规范

当用户要求"综合方案"或未指定单一类型时，依次输出饮食 + 运动 + 用药三部分，每部分使用上述对应模板，最后附汇总表：

```
【健康管理综合方案】

[饮食方案]（使用模板一）
[运动方案]（使用模板二）
[用药方案]（使用模板三）

【方案执行要点】
1. 每日执行清单：[汇总每日需执行的关键动作]
2. 每周执行清单：[汇总每周需执行的动作]
3. 复查计划：[下次复查时间和项目]
4. 紧急情况处理：[何时就医]

⚠️ 本方案基于 XXXX-XX-XX 的健康数据生成，健康状况变化时需重新评估。
```

---

## 通用输出要求

1. **数据引用**：方案中涉及用户指标时，标注查询日期和具体数值
2. **目标量化**：所有目标必须可量化（kcal、次/周、分钟、g、mmol/L 等）
3. **风险分层**：对高风险项用 ⚠️ 标注
4. **医生确认**：涉及诊疗决策的必须提示"建议咨询主治医生"
5. **执行周期**：方案需标注有效周期（建议 4-12 周后重新评估）
6. **语言风格**：专业但易懂，避免纯医学术语，必要时加括号解释
