# 🌡️ Livestock Fever & Hypothermia Detection | 畜禽体温异常检测

> 通过热成像或视觉特征识别畜禽体温异常，预警发热。
>
> **群体体温预警中枢** · 热成像/可见光智能分析 · 个体体温异常识别 · 早期发热预警 · 历史报告云端查询

|---|---|
| 🏷️ 技能名称 | **畜禽体温异常检测** |

## 🎯 任务目标 | Goals

### 1. 🧩 技能用途

通过畜禽热成像或可见光图像，识别个体体表温度分布并判定是否出现异常升高或降低，输出结构化的体温异常预警结果，为群体健康筛查与重大疫病早期识别提供客观依据。

### 2. 🛠️ 能力范围

| 序号 | 具体能力 |
|---:|---|
| 1 | 畜禽个体检测与定位（头部/耳根/眼周等关键测温区域） |
| 2 | 热成像图像温度色带解析 |
| 3 | 个体体表温度区间估算 |
| 4 | 可见光辅助判读（面部潮红、呼吸急促等视觉温度线索） |
| 5 | 与畜种正常体温参考范围对比 |
| 6 | 体温异常识别（发热 / 低温 / 边界） |
| 7 | 异常个体清单与位置标注 |
| 8 | 群体体温异常比例统计与预警等级输出 |

### 3. ⚡ 触发条件

| 触发类型 | 触发规则 |
|---|---|
| ✅ 默认触发 | 当用户提供畜禽热成像或可见光图像/视频 URL 或文件需要体温筛查时，默认触发本技能进行体温异常检测 |
| 🔎 明确分析意图 | 当用户明确提及畜禽体温、发热预警、低温预警、热成像检测、群体体温筛查、疫病早期筛查等关键词，并且上传了图片或视频文件 |
| 📚 历史报告查询 | 当用户提及以下关键词时，**自动触发历史报告查询功能**：查看历史体温异常报告、历史发热预警报告、体温异常检测清单、查询畜禽体温记录、显示所有体温预警报告 |

| 自动行为 | 执行要求 |
|---|---|

## 📷 采集要求 | Capture Requirements

| 序号 | 说明 |
|---:|---|
| 1 | 优先使用热成像相机拍摄，保留温度色带和刻度信息，便于温度估算 |
| 2 | 拍摄距离建议 0.5m～3m，能清晰看到目标个体的头部、耳根、眼周等关键测温区域 |
| 3 | 避免强逆光、镜头结露和大面积热源干扰（如暖灯、加热器直射画面） |
| 4 | 采集前尽量让目标个体处于相对静止状态，减少高强度运动带来的表面温度波动 |
| 5 | 支持单张图或短视频（≤10MB），视频建议 5~15 秒平稳巡舍拍摄 |
| 6 | 支持格式：jpg/png/jpeg 图片，及 mp4/avi/mov 视频；单文件不超过 10MB |
| 7 | 若仅提供可见光图像，建议包含面部/耳部特写，便于辅助判读体温相关视觉线索 |
