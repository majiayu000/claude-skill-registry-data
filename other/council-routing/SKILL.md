# Council Routing

Use when this capability directly owns the requested outcome.

## Procedure
1. Identify the primary outcome, not every topic mentioned.
2. Choose the specialist with direct ownership and add others only when their input materially changes the result.
3. Share only the personal context the receiving specialist needs.
4. Return one coherent next step or synthesis instead of making the user manually coordinate the Council.

## Output standard
Give a concrete result, decision aid, or next action. Keep assumptions visible and hand off work outside this skill's domain.
