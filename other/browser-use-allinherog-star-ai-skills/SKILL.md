# browser-use 业务诊断助手

[快速开始](https://github.com/allinherog-star/ai-skills/tree/main#%E5%BF%AB%E9%80%9F%E5%BC%80%E5%A7%8B)

[更多技能](https://ai-skills.ai)

### 概述

业务诊断助手用于回答「这件事该怎么做」、网页研究、公开信息、竞品分析，适合市场营销、运营、产品、销售在明确业务目标、内容材料或分析对象后调用。
它会结合页面状态记录、粘贴页面可见文本、步骤记录、错误提示、表单标签、截图转写或浏览观察…等输入，整理关键上下文，并输出摘要、诊断结论、行动建议和可复用交付物，便于继续执行、复盘或交付。

### 什么时候使用

**适用场景**

- 用户提出“这件事该怎么做”这类问题，需要快速拆解目标、判断重点并形成可执行结果
- 市场营销、运营、产品、销售需要围绕业务诊断助手生成摘要、诊断结论、行动建议和可复用交付物
- 用户已经准备了浏览任务目标（例如页面理解、流程复核、问题定位、内容检查或人工验收清单。）、任务执行者（填写 QA、运营、产品经理、研究员、内容编辑、客服团队等使用者。）、页面公开链接（填写无需登录即可访问的页面 URL、页面标题、链接 metadata 或页面路径说…），希望整理成可执行的分析或优化结果
- 用户需要把业务诊断助手相关材料转成清晰结论、优先级和下一步动作

### 命令示例

**基础调用**

```bash
python3 scripts/run.py --params '{}'
```

```bash
python3 scripts/run.py --params '{"goal":"浏览任务目标"}'
```

### 参数说明

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `goal` | string | 否 | - | 例如页面理解、流程复核、问题定位、内容检查或人工验收清单 |
| `audience` | string | 否 | - | 填写 QA、运营、产品经理、研究员、内容编辑、客服团队等使用者 |
| `materialUrl` | string | 否 | - | 填写无需登录即可访问的页面 URL、页面标题、链接 metadata 或页面路径说明；需要传可访问的完整 URL |
| `reviewDepth` | string | 否 | `标准诊断` | 选择快速观察卡、标准任务计划或深度验收清单；可选值：`快速体检`、`标准诊断`、`深度改稿` |
| `materialFile` | string | 否 | - | 上传截图转写、页面记录、QA 笔记、PDF、Markdown、TXT 或流程资料 |
| `materialText` | string | 否 | - | 粘贴页面可见文本、步骤记录、错误提示、表单标签、截图转写或浏览观察笔记 |
| `targetPlatform` | string | 否 | - | 说明任务计划面向官网、SaaS 控制台公开页、帮助中心、落地页、移动 Web 等 |
| `brandRequirements` | string | 否 | - | 补充品牌口径、合规边界、禁止操作、截图/引用规范或输出格式要求 |

完整机器可读参数结构见 `references/form-schema.json`。

### 交付内容

- 摘要、诊断结论、行动建议和可复用交付物：围绕用户目标整理可直接阅读、复盘或交付的核心结果。
- 输入材料解读：结合浏览任务目标（例如页面理解、流程复核、问题定位、内容检查或人工验收清单。）、任务执行者（填写 QA、运营、产品经理、研究员、内容编辑、客服团队等使用者。）、页面公开链接（填写无需登录即可访问的页面 URL、页面标题、链接 metadata 或页面路径说…）提炼关键上下文和判断依据。
- 下一步动作：给出优先级、执行建议或可继续加工的内容框架。

### 结果使用建议

- 先判断输出是否回答了用户关于「业务诊断助手」的核心问题。
- 再检查结果是否覆盖摘要、诊断结论、行动建议和可复用交付物，以及是否给出明确下一步动作。
- 如果输入材料较少，建议让用户补充目标、受众、限制条件或原始材料后再运行。
