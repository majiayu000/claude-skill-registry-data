# 投放周报/客户报告

报告的价值 = 结论 + 归因 + 下一步，不是表格搬运。面向甲方/老板时：先说钱花得值不值，再说为什么，最后说接下来怎么办。

## 数据契约

本周+上周（或本月+上月）分渠道：消耗、转化、成本、后端质量（有效线索/成交/ROI）；本周操作记录（上新/调价/活动）；下周已知节点（大促/上新/预算变化）。缺后端数据时明说"本周报仅前端口径"。

## 流程

1. 算环比：消耗/转化/成本/ROI 四件套，标注口径（平台转化 vs 业务成交）。
2. 提炼 1–3 个核心结论（好/坏/风险），每个结论配数据证据。
3. 归因：成本变化对应到具体动作或环境（素材上新见效/节点竞争/回传修复），不写"优化了账户"这类空话。
4. 分渠道一句话点评 + 关键表格。
5. 下周计划：动作、负责人占位、预期目标（可量化）、需要的支持（预算/素材/资质）。
6. 风险预告：素材断档、节点成本抬升、政策/审核风险。

## 输出格式

```
# 投放周报（M.D–M.D）
## 一句话总结
本周消耗 ¥X（环比±X%），转化 N（±X%），成本 ¥X（±X%），[核心结论]。
## 关键指标
| 渠道 | 消耗 | 转化 | 成本 | 后端质量 | 环比点评 |
## 本周动作与效果（动作→数据变化）
## 问题与归因
## 下周计划（动作/目标/所需支持）
## 风险提示
```

## 风格约束

- 结论先行，单段不超过 3 行；金额人民币、保留合理位数。
- 对甲方：坏消息不隐瞒，但配"已采取/将采取的动作"；不甩锅平台，也不揽不属于投放的责任（如产品转化力）。
- 对老板：少术语（oCPM/学习期等首次出现给一句白话解释）。
- 数据缺失处写"待补"，不用估算值冒充实测值。
