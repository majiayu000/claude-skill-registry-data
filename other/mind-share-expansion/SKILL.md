# mind-share-expansion

## When to Use

当规划长期内容策略或评估个人/品牌影响力时description

## Core Logic

# 执行步骤

1.  **定义“颠覆性观点”**
    *   **输入**：自身专业领域知识及对受众现有认知的理解。
    *   **操作**：构思并提炼那些与领域内常见观点不同、能提供新颖视角、或能简化复杂问题的核心观点。
    *   **判断标准**：观点需具备独特性、争议性或极高的澄清价值。
    *   **输出**：一个或多个“颠覆性观点”的清晰表述。

2.  **内容矩阵规划**
    *   **输入**：步骤1定义的“颠覆性观点”。
    *   **操作**：围绕每个核心观点，规划多种内容形式（如文章、视频、播客、图解）和多种阐述角度（如为什么、怎么做、案例、反驳异议），形成内容矩阵。
    *   **判断标准**：单个观点能衍生出覆盖不同渠道和用户学习阶段的内容组合。
    *   **输出**：一个以核心观点为中心的内容主题规划图。

3.  **持续输出与迭代**
    *   **输入**：步骤2的内容主题规划图。
    *   **操作**：按计划持续创作并发布内容。同时，监测受众反馈（评论、分享、私信），了解哪些观点引起了共鸣或讨论。
    *   **判断标准**：发布节奏稳定，并能根据反馈优化后续内容。
    *   **IF** 某个观点获得显著正向反馈 → 进入步骤4。
    *   **ELSE** 反馈平淡 → 返回步骤1，重新审视或提炼观点，或检查步骤2的内容表达方式。

4.  **强化与巩固**
    *   **输入**：在步骤3中验证成功的核心观点。
    *   **操作**：围绕该成功观点，创作更深度的内容（如电子书、课程、系列直播），将其打造为个人或品牌的标志性理论，并在不同场合反复引用和强化。
    *   **判断标准**：该观点与你的名字/品牌在受众心智中形成强关联。
    *   **输出**：一个已占据特定心智空间的“签名式思想”。

# 输出格式要求
输出当前心智空间占据情况评估，包括：已确立的核心观点、对应的内容资产矩阵、受众反馈摘要，以及下一步的强化计划。
