# search-linuxdo

## 目标
在用户需要 linux.do 论坛帖子或佬友讨论时，通过只读搜索和读取整理主题、回复、发布时间、作者公开信息和链接。

## 适用请求
- 搜索 linux.do 论坛帖子、教程、资源讨论或争议话题。
- 读取给定 linux.do 主题 URL 的楼主内容和可见回复。
- 汇总多个相关帖子中的观点、时间线或解决方案。

## 首选通道
- skill-only：优先使用 WebSearch/WebFetch 与 `site:linux.do` 查询，再用当前 Firefox 或普通浏览器只读打开页面核验。
- 如果本机已有 `linuxdo` npm CLI，可作为只读辅助；不要新增或依赖 MCP 服务器。

## 兜底通道
- 使用 WebSearch，查询词包含 `site:linux.do` 与用户关键词。
- 使用浏览器只读打开结果页和帖子；遇到权限、登录或验证码限制时请求用户人工处理。

## 操作流程
1. 提取主题关键词、分类、时间范围和是否需要只看主楼/全部回复。
2. 优先使用 WebSearch/WebFetch + 浏览器只读查询；如已有 `linuxdo` CLI，可用其只读命令辅助。
3. 读取帖子时只查看公开内容和可见回复；全程只读搜索/读取，不发起新的登录流程、不下单、不私信、不发帖、不写入平台，也不点赞、收藏或回复。
4. 汇总时按 URL、标题、楼层/回复、发布时间和作者公开名标注来源。
5. 对可能需要登录才能查看的内容，说明无法访问范围并请用户提供可访问内容。

## 只读安全边界
- 只进行搜索、页面打开、读取和摘要。
- 不发起新的 linux.do 登录流程；如当前 Firefox 已登录则只读复用，不绕过权限、验证码或风控。
- 不点赞、收藏、回复、发帖、私信、编辑资料或执行任何写入动作。
- 不保存账户 Cookie、Token 或会话数据。

## 验证方式
- 后续可运行：`dir C:\Users\Zhang\.config\opencode\skills\search-linuxdo\SKILL.md`
- 人工检查：确认兜底包含 `site:linux.do`，且不依赖 MCP，安全边界禁止发帖和私信。

## 已知限制
- 部分帖子、附件、图片或隐藏内容可能需要登录或权限。
- 站内搜索能力取决于可用工具和当前登录态。
- WebSearch 可能无法索引最新或受限讨论。
