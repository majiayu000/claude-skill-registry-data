# Trailer Plan

## Workflow

1. Read `../../references/TRAILER_SYSTEM.md`, approved screenplay, edit plan, selected media, canon, and verified release facts.
2. Write `06_release/trailers/trailer_manifest.json`.
3. Assign stable `TRL-###` IDs.
4. State trailer type, target duration, tolerance, aspect ratio, audience promise, spoiler policy, and dramatic structure.
5. Map intended beats to available source scenes/shots where possible.
6. Identify pickup needs instead of forcing unsuitable movie material.
7. Keep release-date, platform, award, quote, and availability claims unresolved unless verified.
8. Validate with `scripts/promo_validate.py`.

## Done

Every requested trailer has a distinct marketing job and enough structured information to build assets, edit, mix, and master it.
