# Mobile App

Гайд по разработке мобильных приложений.

## Выбор фреймворка

| Фреймворк | Язык | Когда |
|-----------|------|-------|
| React Native (Expo) | JS/TS | Веб-разработчикам, быстрый старт |
| Flutter | Dart | Единый UI, производительность |
| Нативный (Swift/Kotlin) | Swift/Kotlin | Полный доступ к платформе |

## Чек-лист

### Инициализация
- [ ] `npx create-expo-app` / `flutter create`
- [ ] Запуск в эмуляторе/на устройстве (`expo start`, `flutter run`)
- [ ] Настройка конфигов (App name, bundle id, иконки)

### UI
- [ ] Адаптивность под разные экраны
- [ ] Навигация (React Navigation / GoRouter)
- [ ] Темы, офлайн-режим, состояния загрузки/ошибки

### Данные и сеть
- [ ] HTTP-клиент + обработка ошибок/таймаутов
- [ ] Offline-first при необходимости (SQLite/AsyncStorage)
- [ ] Защита секретов API (не хардкодить; серверная прокси)

### Нативные модули
- [ ] Уведомления (push)
- [ ] Камера, гео, файловая система через плагины
- [ ] Биометрия/хранилище ключей для чувствительных данных

### Сборка и публикация
- [ ] EAS Build (Expo) / Fastlane для автоматизации
- [ ] Подпись, версии (semver), разные окружения (dev/stage/prod)
- [ ] Тестирование на реальных устройствах
- [ ] Публикация: App Store / Google Play, метаданные

## Правила
1. Секреты — не в APK/IPA, используй серверных посредников.
2. Тестируй на реальных устройствах (железо, сеть, разрешения).
3. Автоматизируй сборку и публикацию (CI/CD).
4. Учитывай гайдлайны платформ (Android/iOS дизайн).
