# Picvero · 批量商品做图

读取 [共用约定](references/workflow.md)、[品牌与批量](references/brand-and-batch.md) 与 [运行记录](references/runtime.md)。

查看直接发送的全部照片，或读取文件夹／CSV，按品牌与批量中的自动归类规则整理 request.json；无需用户先做 SKU 清单。同款多照合并参考，不同款式、颜色变体分别分组，没有 SKU 时建立本地编号。每个商品保留自己的事实与图片计划，共用店铺品牌规范；相似文件名不能自动视为同一商品。

默认对本次全部款各做一套，连续完成所有商品，不先试做代表商品等确认。未指定数量时每款采用 [整套交付](references/launch-kit.md) 的五个图位，每张一次；本快捷入口默认交图片和图中文字，主入口路由来的默认整批任务或用户明确要求完整交付时，还须逐款配齐上架文案、HTML 与整批汇总。明确限制商品或数量时遵从。每个图位由 Codex 调用 [内置图片工具](references/native-image.md)，立即记录真实输出，并按 [审核](references/review.md) 完成原图对照。

中断恢复先运行 status。已生成而未审核的先审核；已完成的不要无理由重生成；失败或未知不得用其他 SKU 图片顶替。输入改变时建立新版本任务，保留旧结果。

最终导出带 SKU、图位、版本和问题状态的预览与文件清单。不要启动厂商 CLI、额外服务或账户池来提高并发，不把当前会话的可用额度描述为无限。
