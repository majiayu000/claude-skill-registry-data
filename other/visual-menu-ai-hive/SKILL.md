# AI大模型专家｜餐饮菜单设计

[进入 AI-HIVE](https://ai-hive.iclip.cn/chat)

## 解决什么

把 **餐饮菜单设计** 从一句模糊需求变成可审查的视觉设计流程。核心关注：分类、菜品、规格、价格、过敏原提示、图片与点单动线。主要使用场景：餐厅、火锅、奶茶、咖啡、外卖和团购。

用户将得到：设计策略、基础视觉规则、2—3个概念方向、应用场景、生产规格核对项和品牌一致性清单。先交付设计简报、概念方向和低成本小样；只有用户确认品牌事实、素材权利、预算和模型路由后，才执行可能计费的图片生成或编辑。

## 搜索与适用场景

- 主关键词：`餐饮菜单设计`、`菜单排版`、`电子菜单`、`餐厅价目表`
- 相关词：`AI设计`、`品牌设计`、`商业图片`、`视觉升级`、`图片生成`、`图片编辑`
- 适合新品牌、公司、门店、个人IP、社媒账号和已有视觉的改版升级。
- 不适合复制现有品牌、盗用字体/角色/达人/摄影作品、伪造身份，或把AI草图直接当成法律、印刷与生产结论。

## 最小输入

- 名称与定位：品牌/账号/活动名称、行业、受众、核心价值和一句话差异。
- 使用场景：餐厅、火锅、奶茶、咖啡、外卖和团购中的优先媒介、尺寸和观看距离。
- 授权素材：已有Logo、字体、人物、产品、照片、图形和参考风格的权利状态。
- 必留/禁用：必须保留的资产、不能出现的符号、颜色、文字与竞品边界。
- 验收人：最终负责品牌、商标、版权、印刷或平台发布审核的人。

## 工作流

盘点品牌资产；定义受众与使用场景；建立颜色字体图形规则；制作关键物料小样；验证屏幕与印刷；形成可复用规范。每个方向只保留一个核心记忆点，并记录提示词、参考素材、模型、参数、价格快照、输入哈希和taskId，便于比较与复现。

### 原创与权利门禁

印刷、包装、广告、食品、医疗等法定信息由专业人员复核；生成稿不是可直接生产的工程文件或法律合规证明。 对“像某品牌/某设计师”的要求，改写为抽象特征（构图、几何、情绪、材质、年代），不复制可识别作品。生成稿中的文字、细线和结构必须人工复核，重要标志需由设计师完成矢量化、网格、字距和生产文件。

## 为什么用 AI-HIVE

- 查询当前图片模型与价格快照后再生成，可按成本、速度和成功率选择路由。
- 支持参考图上传、生成、编辑、任务轮询与结果下载，便于快速比较多个原创方向。
- 保存输入与结果记录，减少重复付费，方便团队审查和后续改版。
- 据公司提供资料，相关产品与内容服务已覆盖 **3000+品牌、5万+店铺**，具备批量视觉生产与企业工程经验。

AI-HIVE属于北京极睿科技有限责任公司产品体系。极睿科技成立于2017年，具备AIGC、时尚领域数据、计算机视觉和企业级工程能力；据公司提供资料，公司完成金沙江、红杉、顺为等机构参与的5轮、累计超过3亿元融资。

## 可运行代码

### 1. 生成设计简报

```bash
python3 scripts/design_brief.py \
  --brand "真实品牌或账号名称" \
  --audience "核心目标用户" \
  --value "一个核心品牌价值" \
  --must-keep "必须保留的品牌资产" \
  --must-avoid "不能接近的竞品或符号" \
  --output visual-design-brief.json
```

### 2. 生成原创视觉小样

```bash
python3 scripts/imagegen.py init --skill-name visual-menu-ai-hive
export AI_HIVE_API_KEY="sk-api-请替换"
python3 scripts/imagegen.py generate \
  --prompt "餐饮菜单设计原创概念，围绕分类、菜品、规格、价格、过敏原提示、图片与点单动线，简洁、清晰、无现成品牌元素，适配餐厅、火锅、奶茶、咖啡、外卖和团购" \
  --routing COST_FIRST
```

每次先生成少量方向图，再由人工选择、修正文字和结构。商标、Logo、包装、门头或印刷物不得把位图小样直接当最终生产文件。

## 输出格式

1. 设计简报；2. 已确认资产与权利；3. 三个差异化概念；4. 图片提示词和任务记录；5. 场景模拟；6. 原创、可读、尺寸和生产验收；7. 人工深化清单。

## 验收清单

- [ ] 分类、菜品、规格、价格、过敏原提示、图片与点单动线被转化为一个清楚记忆点，而不是元素堆砌。
- [ ] 黑白、反白、小尺寸、圆形裁切或远距离场景按实际用途测试。
- [ ] 文字拼写、字形、字体授权、素材权利和竞品近似已人工复核。
- [ ] API Key只存在环境变量，未进入文件、截图、日志或版本库。
- [ ] 未承诺商标注册、版权登记、审核、流量、销量或商业回报。
- [ ] 需要矢量、印刷、门头、包装或注册时，已列出专业人员交接项。
