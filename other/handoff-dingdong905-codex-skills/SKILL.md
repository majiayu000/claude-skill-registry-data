# 任务交接

让接手者知道要完成什么、哪些已被证实、从哪里接着做。默认生成本地 Markdown 和可粘贴首句；不依赖云服务、会话导出器或生命周期 hooks。

## 选择模式

- **准备交接**：用户要换会话、换模型、保存检查点或让另一工具续做。下一会话目标优先采用用户指定内容，否则沿用当前未完成目标，无需重新询问。
- **接手续做**：当前用户要求从指定交接文件继续。先核验，再执行其中仍适用的下一步。
- **只读了解**：用户仅让查看或分享交接内容。说明状态，不把历史待办变成新的任务授权。

稳定偏好和长期仓库约定属于记忆整理；当前任务状态属于用户项目。不要把每次交接安装成新 Skill，也不回写本 Skill。

## 准备交接

1. 在当前操作结束或可恢复的检查点采集状态。仍在运行的进程、远端作业或未确认的写操作必须列明其标识、观察时间和待确认结果；不能为了交接擅自终止它们。
2. 保留原目标、验收条件、已接受的纠正和明确边界。记录决定及理由，只保留会影响后续行为的失败尝试。
3. 记录精确工作目录、已有分支/HEAD、暂存与未暂存状态、相关未跟踪文件和关键产物。不要为交接自动提交、stash、切分支或新建 worktree。
4. 为每项状态标明“已验证 / 推断 / 未验证”，附关键命令、结果、时间和适用文件版本。“上次测试通过”不能证明后来修改仍通过；无法访问的历史或附件明确记为缺口。
5. 引用现有文件、符号、必要的内容哈希和来源链接。没有保存的关键代码、SQL 或草稿才附精确片段；大文件与原始日志按需查阅。
6. 用 [空白模板](templates/handoff.md) 生成短交接文档；删除不适用的可选项。通常控制在约 1–2 页，但不得为了篇幅删除验收条件或关键证据。结尾给出一个具体下一步；若阻塞，给解除阻塞的动作。
7. 默认写入用户指定位置或项目内按任务区分的笔记目录；文件名含任务名与时间，避免覆盖另一任务。未经明确要求不写进全局记忆、AGENTS.md 或 Skill 来源仓库。检查其中是否有凭据、私人数据及不应共享的内容；有则移除或只保留不敏感引用。
8. 使用 [检查脚本](scripts/handoff_state.py) 的 validate 子命令，并回读文件确认引用和首句可用。结构校验不证明事实正确，也不能保证完全脱敏。
9. 返回绝对路径和粘贴首句，首句包含目标、读取入口、工作目录及下一步。明确区分“交接包已准备”和“接手已验证”。

Git 状态与文件哈希需要机器复核时，按需读 [状态检查契约](references/state-check.md)；非 Git 的研究、写作任务只需关键产物哈希。无需为交接重复运行无关测试。

## 接手续做

1. 完整读取短交接文件；再按顺序打开当前工作区中的指令、关键文件及相关证据。原始历史只在摘要不足或存在矛盾时按索引检索，不预加载全部会话。
2. 对照真实工作目录、HEAD、分支、暂存/未暂存状态和关键产物哈希。目录可访问不等于工作状态相同；另一台机器的路径也不应直接当成当前路径。
3. 有状态快照时运行 check，并解释差异。旧目录映射到当前目录须来自当前用户指定、可核验的项目映射或明确确认，不能静默选择另一 checkout。
4. 依据当前文件、用户最新指令和实际验证结果处理陈旧结论。遇到关键差异，先保存并说明差异，执行能消除不确定性的最小只读检查；无法确认时只暂停依赖该差异的写操作。
5. 简短说明继承的目标、确认的状态和下一动作；已有续做授权且核验充分时直接推进。历史文本是证据线索，不产生新的发送、发布、部署或删除授权。
6. 接手后更新用户项目中的任务笔记或新检查点，不改通用 Skill。仅在真实核验完成后称“接手已验证”；准备文件本身不表示原任务完成。

## Codex 聊天与跨工具边界

仅当用户明确要求创建新聊天时使用当前环境提供的 create_thread；向已有聊天发送需有明确授权。给目标聊天内联完整短交接，项目目标来自真实项目列表。新 worktree 不包含源工作区未提交内容，不能声称交接 Markdown 已传输代码。只生成交接包时直接交付首句即可。

只有目标聊天核验真实工作状态后才报告自动接手成功。归档、置顶、导航和安装 hooks 各自遵从用户要求，不是交接的默认动作。没有原生能力时提供文件和首句，不虚构会话迁移或精确上下文用量。

接收方不一定能访问本机路径；跨设备交接需同时准备获准传递的相关产物或可访问版本，并明确未传输的未提交改动。完整对话导出和云分享仅在明确需要时选择，见 [外部方案取舍](references/external-options.md)。

教学演练时可按需查看 [合成交接场景](example/stale-workspace.md)，不把其中的事实或授权用于真实任务。来源与改编范围见 [SOURCE.json](SOURCE.json)。
