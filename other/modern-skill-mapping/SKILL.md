# modern-skill-mapping

## When to Use

当需要将抽象的核心能力（如逻辑、修辞、心理学）转化为具体、可实践、可学习的现代技能时调用此模型description

## Core Logic

# 执行步骤

1.  **识别核心能力**：明确需要转化的抽象核心能力或原则（例如：逻辑、修辞、心理学、代理、统计学）。
    *   **判断标准**：能够用1-3个关键词清晰描述目标核心能力。
    *   **常见误区**：将具体技能（如“写代码”）误认为核心能力，或核心能力过于模糊（如“变聪明”）。

2.  **映射到现代技能领域**：将核心能力与当前时代的具体技能领域进行关联。
    *   **输入**：步骤1识别的核心能力。
    *   **操作**：思考“在当今世界，哪些具体的活动或职业领域最能体现和实践这项核心能力？”例如：
        *   IF 核心能力是“修辞学”和“实用心理学”，THEN 映射到“营销与销售”。
        *   IF 核心能力是“逻辑”和“研究”，THEN 映射到“写作与思考”。
        *   IF 核心能力是“代理”、“投资”和“统计学”，THEN 映射到“创业”。
    *   **判断标准**：映射出的技能领域是公认的、有明确实践路径的现代活动。
    *   **常见误区**：映射到过时或过于狭窄的领域；映射关系牵强，缺乏实践支撑。

3.  **应用技能学习框架**：对映射出的具体技能，采用结构化的学习路径进行掌握。
    *   **输入**：步骤2映射出的具体技能名称。
    *   **操作**：执行以下循环框架：
        1.  **研究成功者的流程**：寻找该技能领域的顶尖实践者，分析他们的工作方法、决策流程和产出标准。
        2.  **尝试各种技术**：基于研究，亲自实践多种相关技术、工具或方法。
        3.  **识别模式与原则**：从实践中总结出通用的模式、底层原则和关键变量。
        4.  **创建个人流程**：结合总结的原则和个人特点，构建适合自己的标准化操作流程。
        5.  **分享与贡献**：通过写作、教学或项目输出，验证并迭代个人流程，为领域贡献新知。
    *   **判断标准**：完成了从研究到内化再到输出的完整循环；形成了可重复的个人工作流。
    *   **常见误区**：停留在步骤1（只研究不实践）或步骤2（盲目实践不总结）；跳过步骤5（缺乏反馈和迭代）。

# 输出格式要求

输出一个清晰的技能映射与学习计划，包含：
1.  **核心能力**：[列出识别的抽象能力]
2.  **映射技能领域**：[列出对应的现代实践领域]
3.  **学习行动计划**：按照“研究→尝试→总结→内化→分享”的框架，为每个技能领域列出下一步具体行动。
