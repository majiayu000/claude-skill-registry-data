# 转化成本上涨诊断

把"成本涨了"拆成可验证的因子链，逐层排除，定位主因后给处方。

## 数据契约

近 14–30 天分天数据（账户+计划+素材三层），字段：消耗、展示、点击、CTR、转化数、CVR、转化成本；有竞价环境信息（出价改动记录、预算改动、定向改动、素材上新记录）更好。电商场景另要：客单价、退款率、GPM/ROI。

## 诊断树（按顺序排除）

成本 = 消耗/转化 = (CPM/1000) / (CTR × CVR)。先算三个因子的变化贡献，再往下钻：

1. **口径与回传**（先排除假问题）
   - 转化回传延迟/丢失（API 故障、监测链接改动、深度事件切换）；
   - 归因窗口变化、平台口径调整；
   - 业务侧：客服承接变慢、表单字段增加、价格/活动变化 → CVR 真跌但不是投放问题。
2. **CPM 上涨**（竞争/流量侧）
   - 大促节点（618/双11/年货节）竞价抬升；同行新玩家入场；
   - 定向收窄或人群包衰减 → 可触达人群变小、频次升高；
   - 平台流量结构变化（联盟占比升高、版位变化）。
3. **CTR 下跌**（素材侧，国内最常见主因）
   - 素材衰退：对照素材首次投放日期与 CTR 曲线（判据见 creative-fatigue-cn）；
   - 素材同质化：与竞品/自家其他计划撞素材；
   - 外层文案/封面改动、笔记被限流（小红书违规/报备问题）。
4. **CVR 下跌**（链路侧）
   - 落地页改动、加载变慢、组件失效；
   - 流量质量变化：泛流量占比升高（智能匹配/自动扩量/通投）；
   - 落地页承诺与素材不符（素材夸大了优惠）。
5. **操作侧**（人为重置模型）
   - 学习期内改价/改定向/改预算过猛；
   - 计划频繁启停；出价方式切换；
   - 预算撞线导致时段结构恶化（好时段没钱）。

## 输出格式

```
## 成本上涨诊断（平台 / 区间 / 成本变化：¥A→¥B，+X%）
### 因子分解
CPM +a% ｜ CTR -b% ｜ CVR -c% → 主因判定：__
### 证据链
1. [数据证据] → [排除/确认的假设]
### 处方（按见效速度排序）
| 动作 | 预期恢复 | 风险 | 观察期 |
### 无法确认的部分 + 需要补的数据
置信度：高/中/低
```

## 约束

- 每个结论必须有数据证据；样本太小（如单计划 <10 转化/天）时明说"波动可能是噪声"。
- 区分"恢复原成本"与"接受新成本"：大促期/竞争加剧导致的 CPM 上涨，处方可能是换素材提 CTR 而非降出价。
- 不建议"无脑降价"：oCPM 下降价过猛直接掉量，给出降幅建议（单次 ≤10–20%）与观察期。
