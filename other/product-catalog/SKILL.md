# Product Catalog Workflow

Always-on rules:
- User: casual Indo (bray/lo/gua). Quick action preferred. Don't over-explain.
- From image: extract name, model, specs, price, payment plans, warranty.
- Missing info: state gap explicitly. Never invent data for prospect answers.
- Filter internal system messages before any customer-facing output.
- On "prospek tanya...": pull catalog, draft concise answer, show user draft for approval.

Procedure: receive image → extract → save structured → note gaps → draft response.

Pitfalls:
- Fabricating missing prices = user angry. Always state the gap.
- Don't leak backend review messages to customer output.
- Keep concise — user prefers quick action over explanation.
