# future-self-projection

## When to Use

当意识到当前行为模式可能导致不理想的未来，需要一种具体方法来激发改变动力时description

## Core Logic

# 执行步骤

1.  **设定核心问题**：明确本次思考的核心问题是：“如果我继续做出同样的决定，我的生活最终会怎样？” 将此问题作为接下来所有观察和记录的指导。
    *   **判断标准**：能够清晰、准确地复述该问题。

2.  **记录当前行为模式**：
    *   拿出一张纸或打开一个文档。
    *   记录下“今天”采取的每一个单独行动。
    *   记录下“本周”计划进行的所有例行和重复性事务。
    *   **判断标准**：清单覆盖了当天的主要行动和本周的常规事务，内容具体而非模糊。

3.  **进行外部观察与投射**：
    *   前往一个公共场所（如超市、快餐店、公园、公共交通枢纽）。
    *   安静地观察周围的人群，重点关注他们的神态（尤其是眼神）、肢体语言（如步伐、姿态）和整体状态。
    *   将观察到的普遍状态，与**步骤1**中的核心问题及**步骤2**中记录的个人行为模式进行关联思考。自问：“如果我不改变，我是否正在走向这样的状态？”
    *   **判断标准**：完成了实地观察，并产生了将外部观察与自身未来相联系的具体思考或感受。

4.  **内化与决策触发**：
    *   基于**步骤2**和**步骤3**的输入，持续思考核心问题。这个过程可能需要重复数天。
    *   当通过观察和记录，清晰且确信地认识到当前路径将导向不想要的未来时，触发根本性改变的决定。
    *   **判断标准**：产生了必须改变当前价值观或行为模式的强烈认知或决心。
    *   **IF** 尚未产生改变的决心：**THEN** 返回**步骤2**和**步骤3**，延长观察和记录周期，并确保观察和记录的诚实度。
    *   **ELSE** (已产生改变的决心)：**THEN** 进入后续的价值观重塑或行动计划制定阶段。

# 输出格式要求

输出应包含：
1.  **核心问题**：重申“如果我继续做出同样的决定，我的生活最终会怎样？”
2.  **当前行为清单**：列出记录下的当日行动和本周例行事务。
3.  **观察笔记**：简要描述观察地点、观察到的普遍人群状态（关键特征），以及由此引发的关于自身未来的联想。
4.  **结论/触发点**：清晰陈述通过此练习得出的核心认知或决定（例如：“我意识到如果继续……，我将……，因此我必须开始改变……”）。
