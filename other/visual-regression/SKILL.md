# LeeWay 3D Visual Regression

## Baseline

Preserve approved baseline renders and measurable scene state before repair.

## Controlled comparison

Use stable cameras, lens, resolution, lighting/environment, color management and render settings. Compare geometry/material/performance changes; uncontrolled beauty renders are weak regression evidence.

## Gate

Expected changes are distinguished from unintended drift. Couple image comparison with structural metrics; pixels alone cannot prove dimensions/topology.
