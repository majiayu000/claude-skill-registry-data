# search-telegram

## 目标
在用户需要 Telegram 频道、群组或历史消息时，通过 MTProto/User API 类工具或缓存索引做只读搜索、读取和来源整理。

## 适用请求
- 搜索公开 Telegram 频道、群组或历史消息。
- 读取用户提供的频道链接、消息链接或可访问聊天记录。
- 对频道历史进行关键词、时间范围或主题归档检索。

## 首选通道
- skill-only：优先使用当前 Firefox 已登录的 Telegram Web、用户提供的公开频道/消息链接、导出记录或本地只读索引。
- 如用户已有 MTProto/User API 脚本或导出数据，可只读查询；不要新增或依赖 MCP。
- 明确不要用 Bot API 做历史搜索；Bot API 通常无法读取加入前历史消息或非授权范围。

## 兜底通道
- 如果 `telecrawl` 已安装/可用，可用于深度缓存和后续只读检索，否则请求用户提供导出记录或消息链接。
- 使用 WebSearch 搜索公开频道页面、转发引用或网页缓存，并用浏览器只读读取。

## 操作流程
1. 确认目标是频道、群组、公开链接、消息链接还是用户提供的导出数据。
2. 优先使用当前 Firefox Telegram Web、用户提供的导出记录或本地只读索引；深度历史可在 `telecrawl` 可用时建立或查询缓存。
3. 只读取可访问消息和元数据；全程只读搜索/读取，不发起新的登录流程、不下单、不私信、不发帖、不写入平台，也不加入群组/频道或发送消息。
4. 不使用 Bot API 做历史搜索，除非用户明确说明只查询 Bot 已授权且可见的有限范围。
5. 输出消息链接、频道/群组名、发布时间、消息 ID、上下文限制和可验证来源。

## 只读安全边界
- 只搜索和读取公开或用户授权可见的 Telegram 内容。
- 不发起新的 Telegram 登录/扫码流程；如当前 Firefox Telegram Web 已登录则只读复用，不加入频道/群组、不发送消息、不私信、不转发、不举报。
- 不绕过私有群、删除消息、权限、地区或平台限制。
- 不保存手机号、验证码、Session、API ID、API Hash、Token 或 Cookie。

## 验证方式
- 后续可运行：`dir C:\Users\Zhang\.config\opencode\skills\search-telegram\SKILL.md`
- 人工检查：确认文档明确“不要用 Bot API 做历史搜索”，并包含 `telecrawl` 深度缓存路径。

## 已知限制
- Telegram 历史访问强依赖账户授权、频道权限和消息是否仍存在。
- 私有群组、已删除消息和受限频道无法保证读取。
- 大规模历史检索需要缓存和速率控制，且不能写入平台。
