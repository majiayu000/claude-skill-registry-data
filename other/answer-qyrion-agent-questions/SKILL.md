# answer-qyrion-agent-questions

On first use, follow the bundled qyrus-setup skill to check the connector, credentials, and Qyrion availability. Continue with the capabilities needed for this request.

Read the pending question for the supplied session ID. Answer from authorized task or ticket facts. Ask the user when a fact is missing. Send the answer to that same session and resume monitoring.
