# CAD工程量、苗木表与图例对账

按项目最后有效平面和原始要求读取当前对象，沿`../cad-check-review/references/construction-drawing-workflow.md`接续。CAD表格、原生属性、文字表和普通缓存图形不是同一数据源；源实测表也可能沿用旧统计，不能以源表相同当正确。

## 对账顺序

1. 为每类量明确计量对象和单位：唯一植物实物/真实逻辑组，当前有效种植分区全部分片，实际道路/构件。图块实例数、顶点数、复制标签数和视口出现次数都不是当然工程量。
2. 数量/名称/规格期望来自独立源注、设计依据或已核批准记录，不能从待检成员`len()`反算再自证。来源矛盾只挂该条并保留现有实物，不增删植物/工程实体凑表。
3. 原生有效面积按闭环及bulge计算/读Area，先扣本项目明确硬质/农田等控制。分片的源身份准确后求和，底层精确值与标签整数显示分别保留；不累加重复分幅的总量。
4. 读取表格真实单元格、样式和单位；更新后回读单元格与实际图面。原生表的图形缓存可能未刷新，数值读回正确而图面仍旧也算未完成，不以炸开表格解决。
5. 平面名称数量面积→图例→规格/数量表→说明逐项闭合；规范说明、图名、现状保留范围与旧方案文字按角色辨认，不按关键字整层批删。

保护未变单元格、表样式、有效几何及其它专业数据。完整表项/有效分区全集独立于本次修改列表建立，局部只验一个单元格不能覆盖整表。未知统计先列清来源缺口并继续已明确项，不能照抄旧表或用指数、包围框、近邻代替。

调用来源为`../cad-check-review/library/knowledge/CAD_ANNOTATION_AESTHETIC_USER_REQUIREMENTS.md`的N15—N19及当前项目原生表/分区验收。不同工程的株数、定额和规格不移入；新增意见若是计量口径留项目，若是跨幅去重、分片求和或缓存读回机制则更新本Skill及相应实际检查入口。
