## Nova Ai-Studio 集成（优先于下文）

- 所有成果写入 **`<task-artifact-dir>/`**；勿写工作区根、`output/` 或其它 `artifacts/task-*`。
- **禁止**首 turn `ask_user_question`；**禁止**正文末「请选择一个风格」——推荐模式直接开写最高分 full。

- **须交付四文件（同 turn 写完即停，basename 固定）**：
  1. `article-brief.md` — 六维 + TOP3（标 full/stub）+ 主风格/理由 + 结构说明要点 + **2 条变体方向**（各 1 句）
  2. `article.md` — 3–5 标题候选 + 正文（主槽；可选副写「爆款母稿.md」）
  3. `quotes.md` — 可截图金句（5–12 条）
  4. `channel-plan.md` — 按 `channel-matrix` 短模板，**≤800 字**
- `data-sources.md` 由引擎同步时勿抢权威槽；未要求配图时禁 `generate_image`。
- 研究：`web_search` 1–3 次；选定风格后最多再读 **1** 份 `style-t1-1.md` 或 `style-t1-2.md`（勿连环读 3–5 份）。
- **停写铁律**：四文件落盘并通过自检后停止；禁止为润色 channel-plan / 补运营手册 / 再搜图空转至 max_turns。

### 选风铁律

1. 打分可含 stub；brief TOP3 必须标 `full` / `stub`；冲突对勿并列推送。
2. **自动主风格** = 得分最高的 **full**（仅 T1-1 / T1-2）；stub 永不自动主写。
3. 点名 stub：**软拒绝**——改用最近 full 仍交四文件，brief 首段说明。
4. 点名 full 但总分＜30 或落入禁区维=0：**软切换**最高分 full，brief 说明（本批不硬中断）。
5. 两种及以上风格同篇：**硬拒绝混搭**——不写伪混搭正文；brief 解释框架撕裂并建议拆两篇。
6. 系列模式本批不做：brief 一句说明可拆多 turn。

### brief 必含骨架（推荐模式）

```
选题分析：领域|性质|证据|情绪|深度|时效
TOP3：1..3（风格名 + full/stub + 分/60 + 2–3 句理由）
选中主风格：… + 叠加公式 F?
结构说明：钩子→…→收尾（各 1 句设计意图）
变体方向：①… ②…
（若软切换：首段说明点名风格未入库/低配原因）
```

### T1-1 / T1-2 迷你红线

**T1-1**：短段 1–3 句；≥5 出格类比；硬数据≤2；必算一笔账；情绪「哈哈哈说得对」；**禁**「这意味着什么」/行动清单/框架命名/报告腔。  
**T1-2**：第三人称；**蓝字=Markdown 加粗**（每 400–600 字）；禁感叹号/模糊信源/结尾道德升华；公开信息拼图。  
虚构数据标【示例数据】。用户提供数据必须作核心论据。

# 爆款长文生成（风格路由 · 参数级）

为正确的选题匹配可写气质，在合适渠道交付母稿。当前 **full** 仅 T1-1、T1-2；其余见 `references/stub-styles.md`。  
索引见 `references/style-registry.md`（可选读）。

## 适用 / 不适用

**适用**：公众号/垂类长文、热点解构、调查讽刺向商业稿；需风格路由 + 渠道建议。  
**不适用**：短视频口播主交付；只要选题清单（内容飞轮）；深度蒸馏写作 OS；未要求时的批量配图。

## 工作流（推荐模式默认）

1. 推断选题/渠道/字数（缺省：公众号 + 该风格标准字数）。
2. 六维特征 + 打分（`routing-matrix.md` 刻度）。
3. 写 `article-brief.md`（含 TOP3、结构说明、2 变体）；**不询问用户选风**。
4. 按迷你红线生成 `article.md`；可选再读 1 份 `style-t1-*.md`；可叠 F1–F8。
5. 抽 `quotes.md`；写短 `channel-plan.md`。
6. 自检通过 → **停止**。

### 硬拒绝混搭（示例口径）

用户「半佛+刘润」：说明二者认知框架/节奏/情绪出口不同，混搭导致风格撕裂；建议各写一篇；本 turn 只交 brief（或单一风格正文）。

## 全流程质检（强制）

**通用**：风格唯一；公式模块可辨；数据来源/【示例数据】；用户数据已用；移动端短段；值得转发；去 AI 套话。  
**专项**：对照该风格红线；标题适配首选平台。  
**交付**：四 basename 齐全且未膨胀为第七八个运营附件。

## 绝对禁止

- 一篇混搭多风格  
- 禁区硬写却不说明软切换  
- 编造数据不标【示例数据】  
- 忽略用户原始资料  
- 跳过自检直接收口  
- 推荐生态位冲突风格对并列第一  
- stub 自动主写，或点名 stub 后硬中断不交稿  
- 未验证宣称「已发布」  
- 连环读盘 / channel-plan 运营长文空转
