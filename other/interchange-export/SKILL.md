# LeeWay 3D Interchange & Export

## Preflight

Freeze only required transforms, resolve units/axis conventions, external dependencies, material compatibility, texture paths/embedding, animation ranges, LOD/collision naming and unsupported features.

## Export

Select format from consumer capability, not habit. Preserve native source separately when destructive conversion is required.

## Round trip

Re-import or validate with a second consumer/parser where practical. Export success != semantic equivalence.
