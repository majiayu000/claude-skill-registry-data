# 数学验证（math-verification）

验证论文中的数学内容：推导是否正确、假设是否被使用、量纲是否一致、边界是否成立、复杂度是否如实。**辅助工具，不是定理证明器**：深层证明仍需人类数学家复核。

## 协议

1. **形式化**：把推导/命题写成可检查的形式：已知条件、假设、命题、推导步骤、结论。标注每一步用到了哪些假设。
2. **符号验证**：用 sympy 做符号计算：展开/化简、求导/积分、极限、特征值、方程求解、恒等式验证。脚本与输出存档到 `.research/experiments/<id>-math.md`。
3. **一致性检查**：
   - 量纲/单位：等式两边量纲一致（可借助 uncertainty-and-units 的思路）；
   - 边界条件：退化情形（参数=0、∞、极端值）下结论是否仍成立；
   - 假设检查：推导中是否用了未声明假设；声明假设是否真的必要；
   - 复杂度：算法复杂度声明与实际实现是否一致（big-O 复核）。
4. **优雅性评审**：结论是否最小（无多余假设/步骤）、是否一般（能否推广）、记号是否清晰。给出"数学是否优美"的主观评价与理由（注明是审美判断）。
5. **报告**：输出验证报告：通过项、问题项（严重度 P1/P2/P3）、修改建议；P1 问题必须解决后才能进入写作阶段。报告写入 `.research/`。

## 边界

- 对统计内容：统计正确性交给 nature-statistics / statistical-analysis，本技能只做推导层；
- 对实验数值：不做结果复现（那是 S6 的职责），只验证推导与实现的一致性；
- 无法形式化的哲学式论点：标记"不可形式化验证"，不做强行检查。
