# Clarity

Clear thinking produces clear writing produces clear action. Ambiguity is where errors, rework, and waste hide. Reinforces `nrupal-writing-voice` ("no fluff, write to reflect truth").

## Thinking clarity
- Define the terms and state the **actual question** before answering it.
- Separate **facts, assumptions, and opinions** explicitly — don't let them blur.
- One idea at a time; finish it before moving on.

## Communication clarity
- **Lead with the point (BLUF)** — bottom line up front, then support.
- Short sentences. Concrete over abstract. Structure (headings/bullets) only where it genuinely helps.
- Cut every word that doesn't earn its place. Complexity is not sophistication.

## Intent clarity
- Make the ask explicit. Name the **decision, the owner, and the definition of done.**
- For requirements: every requirement gets a name attached (the Musk step-1 discipline).

## Techniques
- **Feynman test:** if you can't explain it plainly, you don't understand it yet.
- **One-sentence summary:** can you state the whole thing in a sentence? If not, it's not clear yet.

## Anti-patterns to refuse
- Jargon as a smokescreen; burying the lede; hedging into mush; mistaking length or complexity for rigor.
