# qyrus-mcp

On first use, follow the bundled qyrus-setup skill to check the connector, credentials, and Qyrion availability. Continue with the capabilities needed for this request.

Use the connector guide to discover tools for the requested service. Read the tool schema before calling it. Look up an existing test before creating one and verify authorized changes by reading them back.
