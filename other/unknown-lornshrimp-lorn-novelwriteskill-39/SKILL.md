# 通用-审阅人物传记
> **题材路由**：若 .github\题材专用Skills\ 目录存在对应的 <题材>-审阅人物传记 Skill，则：
> - 将题材特性骨架路由到 <题材>-审阅人物传记，该 Skill 位于 .github\题材专用Skills\ 目录。
> - 命中本技能时，必须优先强制加载当前 Skill 与 <题材>-审阅人物传记。


> **头号要求：禁止吹捧，客观分析。** 审阅中不得出现无依据的称赞、吹嘘性描述或主观美化。所有判断必须基于文本事实、可验证标准与明确扣分依据，优先指出问题与改进方向。

人物传记要当作作者的裁判源来审，而不是当角色介绍页来夸。

- 未标注必读的文件：必须读取，但读取后可仅提取与当前任务直接相关的段落，不要求逐字通读。

## 默认执行顺序

人物传记审阅按以下步骤执行，每一步标注了应读取的参考文件：

### 步骤 1：审阅前准备
1.1 确认目标人物传记文件，收集关联的总纲、分卷、事件文档中与人物相关的内容。
1.2 若项目根存在 `Agents.md`，执行 `## 风格/蓝本/写作研究模板自动发现规则` 并加载对应的蒸馏模板对标维度。
1.3 加载 `references/人物传记审阅检查清单.md`，作为逐项核对的底表。

### 步骤 2：通读与多维审计
2.1 完整通读传记正文一次，不做中断判断。逐项核对身份归属、动机—代价闭环、能力边界与工具箱、关系网与镜像对手。
2.2 加载 `../通用-设计人物传记/references/nuwa-深度人物心智模型注入.md`，执行 Nuwa 深度审阅：心智模型提炼、表达 DNA 识别、矛盾张力检查、诚实边界判断、决策启发式评估。
2.3 执行起点爆款人物快筛与共情度评估（10 秒快筛 + 付费价值评估 + 读者群体代入感定位审查）。

### 步骤 3：专项审阅
3.1 执行配角工具性 / 独立性双轨复核、人物传播讨论点复核。
3.2 加载 `references/腾讯专栏人物审阅可演出性与辨识度增补.md`，检查人物在起点读者面前的可演出性与辨识度是否达标。
3.3 若加载了蒸馏模板对标维度，按蒸馏对标审阅规则执行对标审计。
3.4 **执行人物五维互咬合审计**（新增——吸收自知乎网文老刀·五维立人设体系）：
   - 检查人物的五个核心维度（身份设定、处境设定、性格设计、能力定位、欲望方向）是否服务于**同一个人物内核**，是否存在互相矛盾的组合。
   - 矛盾判定标准：身份原型与欲望方向冲突（如"冷血杀手身份+佛系种田欲望"）、能力定位与性格设计冲突（如"设定为天下无敌+性格却极度胆小"）、处境设定与能力定位矛盾（如"底层长期受压+开局就是隐藏大佬"而无合理解释）。
   - **一句话验证**：能否用一句话说清"这是一个怎样的人"？如果不能，说明五维要素尚未收敛到统一内核。
   - 若存在≥1项明显矛盾，标记"五维割裂"为 Critical 问题，对应来源层：`[五维人设]`。
3.5 **执行能力影响范围审阅**（吸收自知乎《最近弃了七本书》关于"天才独善其身"的教训）：
   - 检查主角的定位与其能力产生的叙事影响是否匹配——如果主角被定位为"天才/拥有非凡能力"，其能力对世界产生的影响范围是否与其定位一致。
   - 若已完成数万字以上正文，检查主角能力的影响是否只限于自身和周围极少数人，而对更大范围（社会/组织/局势）近乎无影响——这是"天才独善其身"的典型症状。
   - 能力影响范围审阅的判定标准：写正文20万字时，主角天赋对世界的可感知影响至少应达到"改变了自己所在的小生态（班级/科室/营地/公司）"，50万字前至少应达到"引起了中等范围的格局变化（城市/宗门/行业/战场区域）"。
   - 若主角能力与其叙事影响范围严重不匹配，判定为"能力浪费"风险，标注来源层：`[能力影响度]`。
### 步骤 4：构建审阅报告
4.1 加载 `references/人物传记审阅报告骨架.md` 作为报告主骨架。
4.2 交叉对照 `references/人物传记审阅报告增补.md`，补写 Nuwa 深度审阅板块、蒸馏对标审计（若已执行）、起点潜力分档。
4.3 确保报告完整覆盖七维审计结论 + 可复用写作素材（至少 4 类，每类 3–7 条）+ 可直接贴回正文的登场镜头（至少 1 段）+ 可直接复用的台词（至少 3 句）。
4.4 给出 Green / Yellow / Red 入库判定。

### 步骤 5：评分
5.1 加载 `references/审阅维度说明.md`，按七维（身份/动机/边界/关系/抓手/弧线/索引）逐项评分。
5.2 综合评分低于 9.20 的需附具体优化路径。

### 步骤 6：问题分级与回写建议
6.1 加载 `references/人物传记问题分级与回写建议.md`，将每个问题归入 Critical / Warning / Suggestion 三级。
6.2 输出最小返工处方（优先补首秀动作、动机具体度、代价显影、关系网事件功能）。

## 作者风格画像嵌入与审阅回流（自动）

- 若项目根注册了"作者风格进化"数据源（见 `Agents.md`）：
  - **执行中（只读）**：读取 `作者风格画像.md` 的 人物声口库 + 作者语言库 作为传记审阅作者约束（优先级：作者画像 > 作者风格模板 > 通用默认基线）——角色"表达DNA"与声口库交叉核对，声口差分是否成立
  - **审阅回流（S5 触点）**：审阅结论交付后，作者取舍的原话 → 按 L2 模板归档样本库 + 立场回填显影层 / 母题层
- 未注册数据源或作者明确跳过：跳过回流，不报错，不阻断

## 风格/蓝本/写作研究模板自动发现规则

若当前服务的项目根目录存在 `Agents.md`，审阅人物传记前必须：

1. 读取项目根目录的 `Agents.md`；若其中声明了 `主输出平台`，检索三类模板时优先匹配"适用平台"与主输出平台一致的模板，无匹配时回退到"适用平台：默认"的同类模板
2. 若 `Agents.md` 中注册了"写作研究模板"——读取对应路径的模板文件，将其作为人物设计约束、题材典型人物原型与平台人物禁忌的审阅基线
3. 若 `Agents.md` 中注册了"作者风格模板"——读取对应路径的模板文件，将其作为人物声口、对话风格、情绪表达方式与禁忌清单的审阅对照源
4. 若 `Agents.md` 中注册了"作品蓝本模板"——读取对应路径的模板文件，将人物出场节拍、人物弧线模式、套路指纹中的人物关系类作为传记结构审计参照
5. 本 Skill 只消费与人物审阅相关的字段；若模板字段与人物传记本体设定的动机/代价/边界冲突，以人物传记本体为准
6. 若项目根目录不存在 `Agents.md`，或其中未注册对应模板——回退通用默认模式，不报错，不阻断

本 Skill 默认消费字段：

- 写作研究模板：人物设计要求、配角功能性/独立性约束、反派动机合理化要求、人物类禁忌约束
- 作者风格模板：对话风格配置、人物声口、情绪表达方式、叙事距离、禁忌清单
- 作品蓝本模板：人物出场节拍、新人物引入速率、人物弧线（L3）与关系线（L4）模式、套路指纹中的人物关系类

| 配角功能性/独立性 | §三 人物类约束 | 重要配角是否同时具备功能性（制造冲突/提供信息/引发翻面）与独立性（独立诉求/隐藏目标/立场代价）；是否规避了"工具人风险"与"资料饱满不供血风险" | 25% |
| 反派动机合理化 | §三 人物类约束 | 反派的动机是否合理、是否有独立的行为逻辑（而非"纯恶"）；是否符合研究模板对反派的设计要求 | 20% |
| 禁忌类约束 | §四 禁忌类约束 | 人物设计是否触碰了研究模板的硬性禁忌（如"禁止万能主角""禁止频繁切视角"等） | 15% |
| 原则层归因 | §五 原则层 | 该人物的共情/代偿/追随价值是否满足读者心理学归因原则 | 10% |

### 对标审阅执行规则

1. **对标优先度**：作品蓝本模板（人物结构对标） > 作者风格模板（声口/表达审计） > 写作研究模板（人物设计约束对标）。
2. **评分影响**：蒸馏产物对标维度在人物审阅综合评分中默认按 **20%** 计权；若缺少蒸馏模板导致关键对标维度缺失，需标注"蒸馏对标盲区"。
3. **缺模板回退**：若缺少某类蒸馏模板，该对标维度自动跳过，不扣分，不阻断。
4. **冲突处理**：与人物传记本体设定的动机/代价/边界冲突时，以人物传记本体为准。蒸馏产物约束之间冲突时，写作研究模板的硬门禁 > 作品蓝本模板的强约束 > 作者风格模板的软建议。

## 完整模板执行要求（强制）

- 产出人物传记审阅报告时，必须以 `references/人物传记审阅报告骨架.md` 作为主骨架，不得退化成“几段人物点评 + 少量建议”的简版报告。
- 审阅人物传记模板时，必须先核查其在原有细分结构基础上是否显式覆盖 **背景、性格、外貌、其它** 四大基础栏位；若缺栏、混栏或任一类无法快速定位，必须记为结构缺口。
- 报告至少要完整覆盖：阅读链路确认、基本信息检查、人物一句话定义、角色功能位、首次出场与前三章留存验证、人物—情境—观点合拍度、可演出性与可写性评估、网文留存与角色辨识度复核、身份与组织归属、动机—代价闭环、能力边界与工具箱、关系网与镜像对手、新颖性与趋势适配、人物标签与成长弧核查、可复用写作素材库、秘密与爆点、心理弧线与索引映射、大纲完整性检验、冷热点与回归压力、问题分级、评分、具体修改方案、冲击 9.2+ 综合评分的优化思路与总体评价 / 审阅结论。
- 若当前任务还加载了题材 Skill，则必须在通用骨架的占位章节中继续补写题材专项段、题材专项评分项与题材化结论重点。
- 报告中必须至少产出 `4` 类可复用写作素材，每类 `3–7` 条；并至少给出 `1` 段可直接贴回正文的登场镜头与 `3` 句可直接复用的台词。

## 网文留存与角色回归压力（强制）

- 审人物传记时，必须把人物视为“读者为什么持续追、为什么记得住、为什么愿意等他/她回归”的连载资产，而不是静态设定页。
- 必须显式判断：一句话记忆点、读者继续跟随理由、冷线回归压力、重要对手镜像关系、关系网事件生成能力是否成立。
- 若核心人物缺乏可识别钉子、离线后没有回归压力，或缺陷始终不进入关键选择，不得轻描淡写判为可后补小问题。

## 网文首秀与追读供血（强制）

- 审人物时必须判断：他 / 她第一次出场是否落在最能体现价值与压力的熟悉情境里，且前三章内已经完成一次有效回报、误读、反击或关系拉扯。
- 必须显式判断：这个人物主要靠什么持续供血（专业碾压、情绪回报、关系张力、危险推进、反差幽默、反击爽点、价值站队）。
- 若人物首秀只有履历说明、没有情境动作，或三章内没有可截图 / 可站队 / 可催更的钩子，不得判为网文高完成度人物。

## 起点爆款人物快筛与共情评估（新增）

人物审阅时，默认不只看“资料齐不齐”，还要判断**这个人物在起点读者那里是否有持续付费价值与记忆留存价值**。

### 10 秒快筛（人物版）

把当前人物当作读者在首秀阶段快速感知到的角色资产，默认先做一次 `10` 秒快筛；命中以下 `3` 项及以上弱信号时，人物默认不得判高档：

1. **一句话记忆点是否成立**：是否能在一句话内说清这人最值得记住的特质、处境或矛盾。
2. **主角四要素是否成立**：若为主角，是否具备“低起点 + 强动机 + 反套路 + 立体弧光”；缺两项以上直接下调评价。
3. **缺陷是否真实可用**：是否存在能在关键选择里反复反噬的短板，而不是“设定上有缺点，正文里从不出事”。
4. **关系拉扯是否可演出**：这个人物与至少一名关键角色之间，是否存在足以生成事件的关系张力。
5. **首秀是否有抓手**：前三章内是否能靠动作、判断、反击、误解、站队、反差中的至少一项让读者记住他/她。

### 共情度与付费价值评估

起点爆款人物能持续拉住读者，通常不是因为“设定很满”，而是因为同时满足以下三项中的至少两项：

1. **可共情**：读者能在他/她身上看到现实处境中的自己，如被低估、被误解、职场受压、关系受伤、生活不如意。
2. **可代偿**：读者能在他/她身上看到理想中的自己，如关键时刻敢反击、能破局、能扛事、能聪明地赢。
3. **可追随**：这个人物会持续制造“我想知道他下一步怎么做”的跟随感，而不是只在设定表里厉害。
### 读者群体代入感定位审查（新增）

在上述共情度评估基础上，追加一轮群体定位审查——从市场定位型大纲角度，判断人物设计是否真正瞄准了特定读者群体，而不是"设定完整但读者无感"的自嗨式人物：

1. **群体指向性**：这个人物能否在 10 秒内让目标群体产生"这不就是我吗"的代入感？若人物设计可以在不提目标读者群体的情况下"也成立"，说明代入感定位缺位。
2. **人群具体度**：目标读者群体是否具体到可指导创作决策（学生党 / 打工人 / 社畜翻身 / 创业逆袭 / 被低估的专业者等），而不是"面向大众读者"这类空泛表述。
3. **首秀代入触发器**：人物第一次出场时，是否用目标读者最熟悉的情境、痛点或欲望作为代入钩子，而不是从履历、世界观背景或抽象设定开始介绍人物。
4. **自嗨判定**：若人物传记中"角色有多厉害/多特别"的篇幅明显超过"读者凭什么觉得这人是自己"的篇幅，判为自嗨倾向——这是人物设计最常见的市场定位失误。
审阅报告里默认要回答：

- 这个人物更偏“共情型、代偿型，还是追随型”；
- 其主要付费价值来自主角抓手、关系张力、反派压迫、反差魅力，还是语言/行动风格；
- 若当前版本付费价值偏弱，最该先补的是首秀动作、动机具体度、代价显影，还是关系网事件功能。

### 配角工具性 / 独立性双轨复核

对重要配角与反派，默认补做一轮双轨判断：

- **工具性是否成立**：他/她是否明确承担剧情功能（制造冲突、提供信息、引发翻面、支撑回报）。
- **独立性是否成立**：他/她是否拥有独立诉求、隐藏目标、个人旧账或立场代价，而不是只围着主角转。

若配角只有工具性、没有独立性，判“工具人风险”；若只有独立性、没有剧情功能，判“资料饱满但不供血风险”。

### 起点潜力分档（人物审阅辅助口径）

除 `Green / Yellow / Red` 入库判定外，按起点口径审人物时，默认允许再给一层“人物爆款助推档位”判断：

| 档位 | 判断标准 | 审阅含义 |
| --- | --- | --- |
| S | 记忆点强、动机硬、缺陷真能反噬、关系张力足、首秀三章抓人 | 这是能直接拉动追读与讨论的人物 |
| A | 人物主干稳定，存在鲜明抓手，局部缺口可通过补首秀/补代价快速修复 | 这是可持续供血的人物 |
| B | 资料基本成立，但首秀、关系网或代价显影偏弱 | 这是能用但不够亮的人物 |
| C | 记忆点弱、动机空、缺陷假、关系不生事命中两项以上 | 这是会拖累整书代入与追读的人物 |

该分档只用于辅助判断“这个人物对整书爆款链路的拉升强度”，不得替代完整审阅结论与问题分级。

### 10 万字中期验证（人物版）

人物审阅若服务起点口径，默认补查该人物在前 `10` 万字的持续供血能力，而不仅是首秀是否抓人。报告至少应回答：

1. 这个人物在前 `15` 章里是否有持续功能，而非首秀后隐身。
2. 该人物是否至少触发一次关系位移（结盟、裂变、反咬、误解升级、站队变化）。
3. 该人物的缺陷是否在关键选择里造成过真实代价。
4. 若这是核心人物，是否能在中期继续制造追读问题，而不是“任务完成后功能归零”。

若以上四项中有两项以上缺失，默认判为“中期人物供血风险”。

### 人物传播讨论点复核

人物审阅时，默认再判断其是否具备稳定的传播讨论点：

- **可站队点**：读者是否会在关键选择上分裂立场；
- **可截图点**：是否有高识别动作、台词、反差瞬间；
- **可二创点**：是否存在关系张力、身份秘密、旧账冲突、价值矛盾；
- **可回归点**：人物离线后是否仍有“读者等他/她回来”的压力。

若人物“设定完整但无讨论点”，默认在报告中标记为“商业传播弱人物”，并建议优先补首秀动作、关系拉扯与缺陷反噬场景。

## 题材竞对分析接入要求（强制）

- 若当前任务服务某个题材，且该题材目录下的 `竞对分析/` 已存在与当前项目、当前平台或当前赛道相关的竞对分析报告，审阅前必须先读取并纳入对照。
- 若目标平台为起点中文网，或未注明平台但默认按起点口径处理，且当前题材目录下尚无可用竞对主报告，审阅前应优先调用 `通用-分析竞对作品`，至少补齐 **Top10 候选池、`3–5` 本主样本与四层深拆速览**；若任务限制导致本轮无法补齐，必须显眼记录盲区，并下调本轮审阅上限与置信度。
- 审阅报告不得只给内部自洽结论；必须显式判断当前人物相对竞对在哪些维度已领先、持平或落后，以及最先该补哪条超越路径。
- 若当前人物在竞对已验证的关键强点上明显更弱，必须直判为竞争风险；人物审阅默认按“严酷找差距”口径执行，不得为了安抚作者而把首秀发空、代价缺席或关系网无事件功能轻描淡写带过。
- 竞对维度在人物审阅综合评分中默认按 `25%` 计权；若未完成量化差距卡，或关键维度仍显著落后且没有 `72` 小时补丁，综合评分默认不得给高档。

## 起点化竞对吸收口径（新增）

当人物审阅服务起点中文网，或未标平台而默认按起点基线处理时，默认把竞对对照拆成以下四层，并翻译成审阅判断与补丁建议：

- **市场数据层**：用榜单位次、均订 / 首订 / 收订比代理信号、推荐资源位等，反推这个人物是否真的支撑题材归类、持续付费价值与长线商业竞争位，而不是只在作者视角里“资料很全”。
- **内容创作层**：重点对照主样本在人物抓手、欲望与代价、关系拉扯、身份反差、能力边界、语言指纹、成长弧线与反派动机包装上的成熟度，把差距翻成条目级传记补丁与正文级首秀补丁。
- **运营策略层**：重点对照主样本如何通过角色制造追读工程、本章说讨论点、站队点、关系张力与持续回报，把差距翻成触发器、底线 / 开关、留痕偏好、可复盘细节库与回归压力补丁。
- **受众反馈层**：重点对照本章说 / 书友圈 / 书评区里高频被夸的人物魅力点、被骂的脸谱化病灶、老白读者对降智 / 空心 / 无代价主角的敏感点，把差距翻成避坑与加码建议。

起点语境下，默认尽量使用以下术语，而不是写成空泛的“人物竞争力不足”：`均订`、`高订`、`首订`、`追订`、`收订比`、`分类月票榜`、`畅销榜`、`新书榜`、`三江`、`本章说 / 段评`、`书友圈`、`老白读者`。拿不到精确值时必须写成代理信号，不得伪造具体数字。

## 可演出性与作者交付（强制）

- 审人物传记时，必须把它当作“作者的角色操作手册”来审，不是给读者看的漂亮简介。
- 必须显式判断：三秒立人、行动驱动、缺陷可复用、关系网络可用、与题材机制绑定是否成立，以及人物—情境—观点是否合拍。
- 禁止只给概念评价；必须同时产出条目级补丁、登场镜头示例、可复用台词 / 动作 / 雷点 / 把柄素材。

## 来源层、判定门禁与模板化工件镜像（新增）

- 审人物传记时，默认继续检查它是否已长成“可维护的作者工件”，而不是只有静态人设说明：完整 / 精简模板判断、当前状态、章节行为记录、语言指纹情绪变体、关系总览、可复用素材库，都应纳入审阅范围。
- 问题默认标记来源层：`[人物结构层] / [动态状态层] / [正文抓手层]`。人物结构层负责背景、动机、边界、关系主轴；动态状态层负责当前状态、章节行为记录、阶段变化；正文抓手层负责登场镜头、语言指纹、素材库、可贴回正文的动作与台词。
- 默认补 `Green / Yellow / Red` 入库判定：`Green`=四大基础栏位、动机代价、关系事件、动态状态与素材库齐备；`Yellow`=主干成立但动态字段 / 素材库 / 首秀补丁仍弱；`Red`=栏位缺失、能力万能、代价缺位、关系网无事件功能、首秀无抓力或离线无回归压力。
- 若人物传记无法直接支持“首秀三章怎么写、回归时靠什么重新拉热、缺陷怎样反噬关键选择”，默认不得判为成熟裁判源。

## 报告落盘位置与命名规则（强制）

- 人物传记审阅报告必须落在项目根下的 `审阅意见/人物传记审阅报告/` 子目录中，不得散落在 `人物传记/` 目录或 `审阅意见/` 根目录。
- 人物传记审阅报告文件名必须带日期，日期格式固定为 `YYYY-MM-DD`。
- 推荐完整相对路径写法为 `审阅意见/人物传记审阅报告/人物传记审阅报告_[人物名]_2026-04-15.md`。
- 人物传记本体文件默认不带日期；日期只用于对应审阅报告。

## 默认执行顺序

0. 若按起点口径执行且当前题材目录下缺少可用竞对主报告，先调用 `通用-分析竞对作品`，补齐 `Top10 候选池 → 3–5 本主样本 → 四层深拆` 的最小结论集。
1. 先确认目标传记文件与输出策略。
2. 若按起点口径执行，先吸收竞对主样本四层结论，并写清本轮审阅重点比对的关键项。
3. 按检查清单做结构审计，先确认背景、性格、外貌、其它四大基础栏位是否齐备。
4. 判断动机代价、能力边界、关系网、读者联结、镜像对手与冷线回归压力是否成立。
5. 输出问题分级与最小回写建议。
6. 生成可落库、可回写的审阅报告。

## 默认输出口径

- 默认输出一份带问题分级、证据依据与最小回写建议的人物传记审阅报告。
- 默认不改传记本体，除非用户明确要求边审边回写。
- 报告必须同时回答“哪里不成立”“最小怎么补”“补完后如何更能写、能追、能记住、首秀更抓人”，不能停留在抽象审美判断。
- 默认同时输出：来源层标记、入库判定、最先要回写的层级与 `72` 小时最小补丁链。
- 若按起点口径执行，报告还必须显式覆盖：`Top10 候选池`、`3–5` 本主样本四层速览、竞对差距量化卡，以及当前人物最先该补的超越路径。

## 固定输出骨架（强制）

人物审阅报告默认按以下固定顺序输出，除非用户明确要求改版式，否则不得跳步或乱序：

1. **快筛结论**（10 秒）：先给人物是否“能记住、能跟随、能供血”的快速判断与阻断项。
2. **深评结论**（3 分钟）：再给动机代价、能力边界、关系事件、首秀回报、回归压力、竞对差距判断。
3. **分档结论**：给 `Green/Yellow/Red` + 起点口径潜力档（如 `S/A/B/C`）并写明依据。
4. **最小补丁链**：给“先改哪 `3` 处（条目/镜头/台词）、每处改什么动作词”。
5. **72 小时动作**：给人物级回炉顺序、预计抬升项与复审触发条件。

若任务非起点口径，仍按同一骨架输出；其中竞对或平台字段可标注“本轮不适用”，但不得删掉骨架步骤。

## 最低交付

- 能指出背景、性格、外貌、其它四大基础栏位是否齐全、清楚、可回写，哪些地方属于结构缺口。
- 能指出身份、动机、边界、关系、抓手、弧线与索引中最关键的问题位。
- 能说明哪些问题属于高风险，哪些问题可后续优化。
- 能给出最小可回写补丁，而不是只给抽象评价。
- 能给出至少 `1–3` 处可直接写回传记的条目级补丁、至少 `1` 段可直接贴回正文的登场镜头、至少 `3` 句可直接复用的台词，以及至少 `1` 条首秀 / 前三章回报补丁。

## 复审独立性规则（强制）

- 每一轮人物传记审阅都必须针对当前版本重新独立、从严、全面审一遍，不得因为上一轮指出的问题已修复，就直接按“进步明显”给出高分。
- 上一轮问题修复情况必须核查，但这只是基础项；仍需重新审查身份归属、动机代价、能力边界、关系网、写作抓手、心理弧线与索引映射是否成立。
- 若本轮发现新的 OOC 风险、新的代价缺口、新的关系网失效点或新的索引断裂，必须如实写入本轮报告，不得为了保持“评分持续上涨”而省略。
- 本轮评分只能根据当前版本在本轮完整审阅下的实际质量给出，不得按上一轮分数、已修复问题数量或修改幅度自动抬分。

## 硬规则

- 禁止只评价“人物有没有魅力”
- 若按起点口径执行，禁止跳过 `Top10 候选池 → 3–5 本主样本 → 四层对照` 就直接给高分或高档判断。
- 必须落到证据、结构与回写动作
- 必须说明这个人物为什么值得读者继续跟、为什么在长线连载里不会被忘掉
- 发现核心人物缺代价、能力万能、关系网无事件功能时，至少记为高风险
- 禁止把人物问题写成空泛形容词；必须落成可验证证据、具体条目、可直接回写的动作
- 禁止把人物写成“履历很满但首秀很空”的设定板；若前三章里没有真正让读者想继续跟的动作或回报，必须明确记为失血点
## 风格/蓝本模板自动发现规则

若当前服务的项目根目录存在 `Agents.md`，审阅人物传记前必须：

1. 读取项目根目录的 `Agents.md`；若其中声明了 `主输出平台`，检索三类模板时优先匹配"适用平台"与主输出平台一致的模板，无匹配时回退到"适用平台：默认"的同类模板
2. 若 `Agents.md` 中注册了"写作研究模板"——读取对应路径的模板文件，将其人物类约束作为人物设计的题材×平台默认审阅基线
3. 若 `Agents.md` 中注册了"作者风格模板"——读取对应路径的模板文件，追加"风格适配审阅"（见下方）
4. 若 `Agents.md` 中注册了"作品蓝本模板"——读取对应路径的模板文件，将 POV 切换规律和对话密度分布作为人物出场节奏的参照约束
5. 若项目根目录不存在 `Agents.md`，或其中未注册对应模板——跳过风格适配审阅，不报错，不阻断

### 风格适配审阅（当作者风格模板存在时生效）

**检查项**：

- **句长匹配**：人物的表达DNA中的"句长偏好"是否符合作者风格模板的句长基线？如果人物是短句急速型但作者模板是长句徐缓型，标注"人物-作者风格摩擦"——作者可能写不出这个人物的节奏感。
- **禁忌词重叠**：人物的"禁忌词/绝不说的句式"是否与作者风格模板的"句式禁忌/词汇禁忌"重叠？如果重叠，说明人物声口与作者默认声口一致——这可能是好事（人物不会撞作者禁忌墙），也可能是坏事（所有人物听起来都像作者本人）。
- **对话标签适配**：人物的对话方式是否符合作者模板的对话风格配置（标签偏好、打断密度）？如果作者模板是"动作标签派 70%"，但人物需要大量纯对话无标签推进，标注"人物对话方式可能与作者默认方式有摩擦"。
- **情绪表达方式匹配**：人物的情绪表达方式（躯体化/动作外化/直述）是否符合作者模板的情绪表达分布？如果人物是直述情绪型但作者模板直述 < 5%，标注"人物情绪表达方式超出作者舒适区"。

**审阅输出**：在报告的"人物深度"段中追加"风格适配评估"子段，列出摩擦点和适配建议。
## Nuwa 级深度审阅（新增）

> 详细方法论见 `通用-设计人物传记/references/nuwa-深度人物心智模型注入.md`。人物审阅时，在完成结构审计与起点口径评估后，默认追加以下 Nuwa 深度维度。人物若止步于"设定完整"而缺乏可运行的认知操作系统，不得判为高完成度。

### 心智模型审阅

审阅人物传记时，默认检查以下心智模型维度：

- **心智模型是否存在且可识别**：核心/重要人物是否有 2–5 个明确的心智模型（不只是"性格标签"或"背景设定"）？传记中是否能找到类似"信任是需要挣的，不是给的"这种可运行认知规则？
- **跨场景一致性**：每个心智模型是否在 ≥2 个不同场景类型中有证据？如果传记中只在一个场景中体现了某个"信念"，则它只是场景台词，不是心智模型。
- **生成力**：用传记中提供的心智模型，是否能推断这个人物在未写场景中的可能反应？如果不能，说明模型太虚。
- **排他性**：这个人物的心智模型是否能把他与故事中其他人物区分开？如果所有人物的"世界观"都写成了"善良/正义/想变强"，说明缺乏排他性 → 人物同质化风险。
- **误解型模型缺失**：核心人物是否至少有一个"误解型"心智模型（会在弧线中被修正的误信）？如果没有，成长弧线可能缺发动机。
- **模型间碰撞**：不同核心人物的心智模型之间是否有可碰撞的差异性？如果两个对立的角色有着相同的深层假设，冲突就只是表面热闹。

**审阅输出**：报告"人物深度"段中显式判断心智模型成立度，标注缺失项与补丁建议。

### 表达DNA审阅

审阅人物传记时，默认检查以下语言指纹维度：

- **语言身份证是否可测量**：传记中的"口头禅/句式习惯"是否停留在"说话很冷""爱怼人"这类模糊标签？是否提供了句长偏好、疑问句用法、确定性语气、禁忌词等可测量维度？
- **声口分众**：核心人物是否有对不同对象的声口变化？如果对上位者/同级/下属/亲密对象/敌对对象说话方式完全一样 → 声口单一风险。
- **情绪变体**：传记是否描述了同一人物在愤怒/恐惧/伪装/亲密时的语言变化？
- **遮名测试**：遮住名字读传记中提供的对话样本或口头禅，是否能认出是谁？如果不能 → 语言指纹不成立。
- **禁忌词检查**：传记是否写清了这个人物绝不说的话？如果没有 → 语言指纹不完整。

**审阅输出**：报告"可复用写作素材库"段中显式评估表达DNA成熟度，标注缺失维度与最小补丁。

### 矛盾与张力审阅

- **本质性张力**：核心人物是否至少有 1 对内在价值观冲突？如果传记中的人物"表里如一、信念坚定、从不犹豫" → 纸板人风险，直接标记为深度不足。
- **领域性矛盾**：人物是否在不同领域/关系中表现出一致的行为准则？如果所有场景中的反应都可以被一个标签概括 → 扁平化风险。
- **矛盾与弧线的对接**：本质性张力是否已写入心理弧线的关键步骤？张力是否在弧线高潮中有"正面相撞"的节点？
- **错误矛盾处理检测**：传记中是否存在"编一个调和解释抹平矛盾"的痕迹？是否存在"选一边忽略另一边"的简化？如果存在 → 矛盾被浪费了。

**审阅输出**：报告"心理弧线"段中显式判断矛盾深度，若本质性张力缺失或矛盾被调和抹平，记为高风险。

### 诚实边界审阅

- **盲区存在性**：核心人物是否有 ≥3 条诚实边界？传记中是否写清了人物看不到什么、理解不了什么、做不到什么？
- **情节关联**：至少 1 条诚实边界是否与主线情节直接挂钩？如果所有盲区都不在正文中造成后果 → 盲区只是装饰。
- **万能主角检测**：传记中是否存在"什么都能看透、什么都能做到"的痕迹？如果能力边界写得含糊、所有弱点都可以"克服" → 万能人风险，直接标记。

**审阅输出**：报告"能力边界"段中显式评估诚实边界，若核心人物诚实边界 <2 条或全部与主线无关，记为结构缺口。

### 决策启发式审阅

- **规则存在性**：核心人物是否有 ≥5 条"如果X则Y"式决策规则？传记中的"底线/开关"是否可操作？
- **错误规则检查**：是否至少 1 条决策启发式是"错误规则"，会在关键时刻导致人物误判？如果所有规则都是"正确选择" → 人物过于聪明，缺乏真实感。
- **案例支撑**：每条决策启发式是否有具体情节节点支撑？

**审阅输出**：报告"动机/边界"段中显式评估决策启发式完整度。

### Nuwa 深度汇总评分（新增评分维度）

除现有综合评分外，默认追加 Nuwa 深度分（满分 10 分，权重占综合评分的 15%）：

| 子维度 | 满分 | 评估标准 |
| --- | --- | --- |
| 心智模型 | 3 | 存在、可识别、跨场景、有排他性、有误解型 |
| 表达DNA | 2 | 可测量、有声口分众、有情绪变体、可遮名识别 |
| 矛盾张力 | 2 | 有本质性张力、有领域性矛盾、已对接弧线 |
| 诚实边界 | 2 | 存在、与主线相关、有触发计划、非装饰 |
| 决策启发式 | 1 | 存在、有错误规则、有案例支撑 |

Nuwa 深度分 <5 分 → 人物虽有设定但缺乏认知操作系统，报告必须标注"Nuwa 深度不足"并给出最优先补的 2 个维度。
## 与其他 Skill / Prompt 的边界

- 本 Skill 负责人物传记的结构审阅与回写建议，不直接代替人物传记重写。
- 若用户要直接重写或补强人物传记，应优先使用 `通用-设计人物传记`。
