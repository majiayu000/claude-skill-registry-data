# 基层中国的运行逻辑

> **可执行 AI Skill** · 安装 ID：`nie-grassroots-logic`  
> 来源：聂辉华《基层中国的运行逻辑》（组织经济学 + 政治经济学 + 实地调研）  
> 本 skill **提纯结构、不写摘要**；忠于原著命名与因果，不编造原书没有的框架/数字/案例。  
> **开源包不含原书全文**；请购买正版。一页索引见 `INDEX.md`。

## 哲学（先记住）

1. **中国的问题，归根结底都是政治经济学问题。** 先找权力与激励，再谈道德与情怀。
2. **公说公有理，婆说婆有理；究竟谁有理，关键看逻辑；逻辑要自洽，关键看框架。**
3. **人跟资源走，资源跟权力走，权力本质是等级体系。** 市场与等级并存；基层很多事不是价格配置的。
4. **理解基层，才能理解中国。** 基层是底色与基本盘；国家治理与基层治理必须**上下同治**。
5. **有限权力 + 无限责任（政治承包制）** 是基层主官的结构性张力；别把县委书记简单画成「土皇帝」或「包青天」。

## 调用本 skill 时必须做的

1. **先判断用户问题落在哪一层**（见下方「三层地图」），再打开对应 `references/`。
2. **优先用原书命名框架**分析，不要改写成泛化政治学口号。
3. **输出结构默认**：
   - 这是什么问题（条/块？级？激励？财权？）

   - 因果链（谁激励谁、权责是否对称）
   - 可执行判断/选项（选岗、读新闻、写分析时）
   - 反模式提醒（见 `anti-patterns-voice.md`）
4. **不确定的制度细节**标「[原书有述·具体现行规定请核最新文件]」；不假装掌握最新人事口径。

## 框架速查（一句话）

| 框架 | 一句话 | 何时用 |
|---|---|---|
| **内外冲突的双均衡** | 内稳↔外稳冲突 → 集权/分权两套兼容体系；制度僵化=兴亡之谜 | 宏观国策、巡视/考核转向、数字技术与集权 |
| **条块结合，以块为主** | 矩阵治理；属地责任落在块；条管与属地要分清 | 权责不对等、「上面千条线」、条管单位 |
| **央地 = 委托—代理** | 非兄弟、非父子；下级服从+地方有自利博弈 | 政策变形、差序信任、试点与推广 |
| **等级制配置资源** | 城市/官员金字塔；财政漏斗；行政级别抬 TFP 也抬错配 | 城市差距、撤县设区/市、资源为何向上集中 |
| **职务含权量三因子** | 级别 + 管什么人 + 管多少钱 | 同级职位比权、隐性台阶、晋升非线性 |
| **县委书记三座大山** | 维稳、招商、借债 | 县域主官行为、地方新闻动机 |
| **压力型体制 + 注意力分配** | 指标膨胀、一票否决、棘轮；部门抢考核权 | 形式主义、迎检、指标越来越多 |
| **激励→监督转向** | 数字技术降信息不对称 → 过程监督+多元一票否决 | 十八大后新常态、指尖形式主义 |
| **政企四象限** | 合作/分治/伤害/合谋（干预×合法） | 招商、营商环境、亲清+平 |
| **土地财政闭环** | 低价工业地换税源 + 高价商住地抽血 + 基建交叉补贴 | 房价、债务、园区、卖地依赖 |
| **活力—秩序** | 城市化大城/小城之争的权衡框架；主张第三条道路 | 区域政策、收缩城市、统一大市场 |
| **上下同治** | 顶层设计 + 摸着石头过河；两个积极性 | 改革试点、地方创新如何上位 |
| **昆山三板斧** | 先做不说 → 做了再说 → 先上车再买票 | 基层创新、企业/地方推政策 |
| **西气东输九步** | 想法→汇报→视察→批示→论证→审批→领导小组→实施 | 国家级/跨省重大项目 |
| **政商亲清指数** | 亲近（服务）+ 清白（可预期）；不完全契约 | 选城、投资、区域黑话校准 |
| **容错创新三色边界** | 红线/灰区/绿区；问责时代创新补丁 | 敢不敢干、躺平与乱作为 |
| **重大工程争夺五幕** | 进规划→抢站→注意力→配套→实施虹吸 | 高铁站、枢纽、国家级项目 |

## 决策树（先问这三句）

1. **这是权力结构问题还是激励/考核问题？**  
   - 结构（谁管谁、条还是块）→ 层 I/II  
   - 激励（为什么拼命干/不干/搞形式）→ 层 III 考核与晋升  
2. **主角是哪一级？** 中央/省/市/县/乡/村/街道 → 权界与天花板不同  
3. **用户要解释还是要选？**  
   - 解释现象 → 框架因果  
   - 个人选择（求学/考公/投资/养老/创业）→ **先读** `life-decisions.md`，再补对应框架 reference  


## 关键原则（调用时守住）

1. **分清属地 vs 垂直、领导 vs 指导、分管 vs 联系。**  
2. **权力边界 ≠ 辖区边界。** 条管单位在地理上在县里，行政上未必归县委书记。  
3. **有权必有责，但基层常是权小责大。** 分析时写清「无限责任政治承包」是否在起作用。  
4. **集权/分权要素不要混搭。** 集权配：监督、忠诚、一刀切、犬牙交错；分权配：激励、能力、多样化、山川形便。  
5. **十八大前后规律不同。** 勿用唯 GDP 锦标赛一套讲今天；要用政绩→问责、激励→监督。  
6. **物证纪律。** 框架名、命题、案例来自原书；数字与人事以原书/用户补充为准。
