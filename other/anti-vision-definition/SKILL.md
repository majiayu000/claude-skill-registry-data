# anti-vision-definition

## When to Use

当需要明确个人或组织想要避免的未来状态，以激发行动力时description

## Core Logic

# 执行步骤

1.  **识别负面经历**：回顾近期或过往经历，列出所有让你感到不满、痛苦、厌倦或想要避免重复的具体事件、任务或情境。
    *   **判断标准**：列表包含至少3个具体、可描述的负面条目。
    *   **常见误区**：停留在模糊的情绪描述（如“不开心”），而非具体事件（如“每周重复的数据录入工作”）。
2.  **分类记录**：将识别出的负面条目，按照“不愿学习的材料”、“不愿完成的工作”、“不希望发生的争论”或其他自定义类别进行分类记录。
    *   **判断标准**：每个条目都归入至少一个类别，记录格式清晰。
    *   **常见误区**：不进行分类，导致条目杂乱，难以分析共性。
3.  **定义问题**：针对每个记录下的负面条目，用“如何避免/解决 [具体负面条目]？”的句式，将其转化为一个待解决的问题。
    *   **判断标准**：每个负面条目都对应一个明确的问题陈述。
    *   **常见误区**：仅停留在抱怨阶段，没有将情绪转化为可行动的问题。

# 输出格式要求

输出一个结构化的“反愿景”文档，包含以下部分：
1.  **负面经历列表**：按类别排列的具体条目。
2.  **待解决问题**：由负面条目转化而来的问题陈述列表。
