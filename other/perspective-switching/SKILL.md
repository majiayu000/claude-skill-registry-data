# perspective-switching

## When to Use

当遇到令人情绪激动或陷入僵局的情境，需要跳出固有反应模式以做出更优决策时description

## Core Logic

# 执行步骤

1.  **识别触发点与当前视角**
    *   **输入**：外部事件（如他人的言论、冲突、挑战）或内部状态（如愤怒、沮丧、困惑）。
    *   **操作**：暂停当前自动化的反应。明确意识到：“我当前正通过一个特定的视角（如‘被冒犯者’、‘受害者’、‘竞争者’）看待此事，这引发了我的情绪X。”
    *   **判断标准**：能够清晰描述触发事件和自身当下的主导情绪及隐含的视角标签。
    *   **输出**：对当前情境和自身初始视角的明确认知。

2.  **主动选择并切换到目标视角**
    *   **输入**：步骤1的输出（当前视角认知）。
    *   **操作**：有意识地提出一个旨在激发好奇心或寻求理解的问题框架，例如：“如果我从[目标视角，如‘好奇的学习者’、‘中立的观察者’、‘对方的盟友’]来看，会有什么不同？” 具体问题可包括：“对方为何有此观点/行为？”“其背后的目标、经历或限制是什么？”“这个情境中可能隐藏着什么我未看到的机会或信息？”
    *   **判断标准**：能够明确陈述意图切换到的目标视角名称，并基于此视角提出至少一个具体的探索性问题。
    *   **输出**：一个或多个基于新视角的探索性问题。

3.  **基于新视角收集信息与重构认知**
    *   **输入**：步骤2输出的探索性问题。
    *   **操作**：根据问题，收集信息。这可能包括：回忆已知的对方背景、观察非语言信号、查找相关资料，或纯粹进行思想实验，推测多种可能性。
    *   **判断标准**：能够基于新视角，列举出至少一条之前未考虑到的信息、动机或情境解释。
    *   **输出**：一组基于新视角的、对情境的更新后的解释或假设。

4.  **评估与选择反应行动**
    *   **输入**：步骤3输出的更新后的情境解释。
    *   **操作**：比较“基于初始视角的默认反应”与“基于新视角的潜在反应”的预期后果。评估哪种反应更符合你的长期目标（如学习、合作、解决问题、维护关系）。
    *   **判断标准**：能够说明为何选择（或放弃）某种行动方案，并将其与视角转换后获得的新认知联系起来。
    *   **输出**：一个经过深思熟虑的、选择性的行为决策（可能是行动，也可能是暂不行动）。

# 输出格式要求
以结构化方式呈现视角转换的过程与结果：
1.  **初始状态**：简述触发事件及识别出的初始视角与情绪。
2.  **视角切换**：说明主动选择的目标视角及核心探索问题。
3.  **新认知**：列出基于新视角获得的关键发现或不同解释。
4.  **决策与行动**：陈述最终选择的行动方案及其理由。
