# mvp-proposal-creation

## When to Use

当需要将个人技能或兴趣快速转化为可收费的咨询服务或自由职业服务时description

## Core Logic

# 执行步骤

1.  **确定核心交付物类型**
    *   **输入**：一项明确的技能（如邮件营销、网页设计）或一个明确的兴趣领域（如健康健身、个人发展）。
    *   **操作**：根据输入，判断服务形式。
        *   **IF** 输入是“技能”类（如网页设计、文案写作）**THEN** 交付物为“自由职业服务”（为客户执行任务）。
        *   **IF** 输入是“兴趣”或“知识”类（如健身、生产力）**THEN** 交付物为“辅导/咨询服务”（教授客户技能或知识）。
    *   **判断标准**：明确了服务是基于“执行”还是基于“教学/指导”。
    *   **输出**：服务类型（自由职业 / 辅导咨询）。

2.  **构建提案框架（针对辅导/咨询服务）**
    *   **输入**：服务类型为“辅导/咨询”；一个具体的客户问题或目标领域。
    *   **操作**：按照“目标-路径-问题”模型构建提案核心。
        1.  定义**目标 (B点)**：客户希望达成的具体状态或结果。
        2.  定义**起点 (A点)**：客户当前所处的状态或面临的具体问题。
        3.  设计**路径**：从A点到B点，你提供的独特步骤、方法或教学大纲。
    *   **判断标准**：A点、B点和路径清晰、具体，且路径能逻辑上连接A与B。
    *   **输出**：一个清晰的转变蓝图（从A到B的路径）。

3.  **设计服务包结构与定价**
    *   **输入**：服务类型；构建好的提案框架（针对辅导/咨询）。
    *   **操作**：
        *   **IF** 服务类型为“自由职业” **THEN** 将技能打包为明确的项目（如“设计一个5页官网”），初始定价为$500-$1000。
        *   **IF** 服务类型为“辅导/咨询” **THEN** 设计为包含以下要素的服务包：
            1.  **教学结构**：基于步骤2的路径，细化为每周教学重点。
            2.  **互动形式**：设定为“4次每周通话”，用于教学和答疑。
            3.  **支持材料**：每次通话后提供明确的“每周行动项目”，并提供通话外的沟通渠道（如短信/邮件支持）。
            4.  **初始定价**：该服务包初始定价为$500-$1000。
    *   **判断标准**：服务包内容具体、有边界（如次数、时长）、交付物明确，并附有初始价格区间。
    *   **输出**：一个结构化的、有定价的服务方案。

4.  **获取初始客户与建立信用**
    *   **输入**：结构化的服务方案。
    *   **操作**：选择获取最初几个客户的策略。
        *   **IF** 目标是快速验证和积累案例 **THEN** 可以免费或以极低价格为少数精准客户（如同领域的创作者）提供服务。
        *   **IF** 目标是立即产生收入 **THEN** 以$500的价格寻找付费客户。
        *   **ELSE** （默认路径）以$500-$1000的价格开始寻找付费客户。
    *   **判断标准**：成功获得1-3个初始客户，并完成服务交付。
    *   **输出**：初步的客户成果和/或推荐信。

5.  **迭代与扩展路径决策**
    *   **输入**：已完成初始客户交付，拥有初步成果和反馈。
    *   **操作**：评估后续发展方向。
        1.  **路径A（深化服务）**：基于经验优化提案，提高客单价。
        2.  **路径B（产品化杠杆）**：将一对一服务标准化为“基于班级的课程”，利用已有受众进行推广。成功后，可进一步产品化为“自学课程”。
        *   **建议**：优先考虑路径B，以实现时间杠杆和规模扩张。
    *   **判断标准**：根据自身品牌受众规模、时间投入意愿和规模化目标，做出明确的路径选择。
    *   **输出**：清晰的业务进化方向决策。
---

# 输出格式要求
输出一个结构化的服务提案，需包含：
1.  **服务名称与类型**：（自由职业 或 辅导/咨询）
2.  **核心转变描述**：用“从A点（当前问题）到B点（理想目标）”格式阐述。
3.  **服务包详情**：列出包含的具体项目、会议次数、支持内容等。
4.  **初始定价**：注明起步价格（$500-$1000区间）。
5.  **下一步行动**：简述获取初始客户的策略（如“寻找3位潜在客户提供限时优惠”）。
