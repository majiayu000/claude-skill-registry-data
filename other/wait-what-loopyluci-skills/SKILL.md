# Wait What

> **Adapted for the LoopyLuci Skills collection** from [mattpocock/skills](https://github.com/mattpocock/skills). The guidance below is rewritten and condensed for this repo; commands, paths, and reference tables are preserved.

## Trigger

- Stop. That last message did not land: re-pitch it

## When NOT to Use

- Outside the trigger above; keep the task in the skill that owns it.

## Overview

Use when the previous explanation clearly missed: the user signals confusion, or a message did not land. The task is to re-pitch the same content in a clearer register, not to introduce new material.

## Re-pitch protocol

- Open by naming the gap: say plainly that the last explanation did not land.
- Restate the core point in a few short sentences before adding any detail.
- Write in ASD-STE100 Simplified Technical English: short sentences, one idea per sentence, active voice, no jargon unless it is ubiquitous language.
- Use the project's ubiquitous language from `GLOSSARY.md`. If the repository contains more than one glossary, follow `GLOSSARY-MAP.md` to the correct one.
- Keep the facts and the decision identical — never quietly change the recommendation while rephrasing it.

## Verification

- [ ] The restatement is shorter than the message it replaces.
- [ ] Every sentence carries one idea and uses the active voice.
- [ ] Domain terms match `GLOSSARY.md` exactly.
- [ ] The conclusion and the next step are unchanged.
