# Paper to HTML v2.3

Turn research papers into interactive, explained HTML reading guides.
把研究论文变成可交互、带讲解的 HTML 阅读指南。

## 当前定位与讲解决策
当前版本定位为：**以生物医学实验论文为主、适应当前用户的中文共读工具**。先用用户实际阅读与反馈改善理解体验，再考虑其他读者和领域；不以全领域覆盖、图数、卡数或篇幅作为优化目标。沿用用户已认可的具体对象、实验设计与证据链讲法，依据本篇反馈调整，不能从用户的研究方向推定其已掌握所有技术。

**先识别论文的论证结构，再决定讲解单位；允许省讲、合讲和跨图比较。** 新文章在写作前按[讲解单位与详略](references/reading-units.md)作选择。完整性针对核心问题与证据，不要求每张图独立、等量讲解。省讲省的是无增益注释，仍保留来源与必要原图/图注，不能省掉关键反例、条件或推理。复杂关键图保持详细带读。

知识卡按[知识点拆分与深度](references/adaptive-concepts.md)另行判断：不同关键概念默认独立、自足讲解；适合比较的近邻概念可合讲，但须先分别讲清，再说明共同点与差异。只需辨认身份的成批名称可集中简述。多图合讲不授权把多个知识点压成一句话。

图例先识别文章领域。生物学默认“基因与蛋白、实验方法、调控元件、细胞与亚型、生物学概念”，固定颜色且只显示实际使用类别；非生物学或混合领域按本文内容自动选择少量直白类别，不硬套生物学术语。具体分类和清单接口以adaptive-concepts.md为准。

## 交付范围
默认一次交付完整首次阅读核心：实际原文全题与按需译题、摘要及连续核心论证、主图/面板的原始查阅入口与按论证需要组织的讲解、作者总结与局限、必要知识卡、全文论证链、文末读者总结与评议，以及阅读控件与随手记。内部可分批制作，按选定讲解单位保持质量；不要让用户逐图追加请求才补齐核心。
核心范围内的原文及图注提供完整中文翻译，保留条件、数量、统计、限定语和图号/补充材料引用。所有阅读内容移除纯参考文献编号及引用上标角标，不改为其他编号形式；真实单位、公式上标等保留，详见reading-and-teaching.md。核心范围按主贡献决定，不按章节名决定：方法/算法/证明是贡献主体时完整带读；复现级操作细节、附图详解、补充支线和复习检测不默认生成，关键补充依据就地解释。进阶请求先列本文相关候选模块，按用户选择生成；明确全包/局部范围时按其请求。
不生成共读记录/阅读日志网页章节或独立日志文件。随手记及其处理回复仍保留。已有进阶内容保留，按下述归属整理。

## 带读交付门槛
先决定讲解单位，再按[详细讲解要求](references/panel-teaching-contract.md)写作。关键复杂单元保留“当前问题与数据构造 → 局部图例 → 实际例子到判断 → 剩余问题”；简单图可以只保留身份/必要条件与图注，多图共享一个详细比较单元。不能用一个空泛 `explain` 段替代关键推理，也不能为通过检查给简单图凑四块文字。详略选择、科学复述与浏览器交互分别验收。

读图时优先采用作者在上下文中明确写出的目的和结论，再用图中观察解释其依据。先查对应正文前后段、图注与相关讨论；没有明确表述时才作带读归纳并标明归属。设计图不冒充结果图，跨图总结不冒充单面板证明。具体执行与来源字段见[来源与证据核对](references/source-and-evidence.md#先找作者明确写出的读图目的与结论)。

用类别概括多项读图结果时，按[具体标签到分类总结](references/panel-teaching-contract.md#从概括类别落回可见证据再做组合总结)给出可定位的对象、位置和比较方向，再解释哪些结果共同支持该特征及有哪些例外；不能只说“早期／混合／某通路活跃”。

## 论文结构与解释方式
先识别实际语言、主贡献、核心结构和证据依赖。默认中文共读，同语种无需重复翻译。遇到非生物医学实验论文，按[范围边界与必要适配](references/cross-domain-reading.md)处理；不将一次外领域测试扩展成全领域优化任务，也不套用生物实验路线。保留认可的阅读控件与布局。

## 操作流程
资料定位、版本核对及主张审查按[来源与证据核对](references/source-and-evidence.md)执行；需要补足工具能力时再读[外部能力选用](references/optional-capabilities.md)，不把检索或安装外部Skill设为每篇必做前置。
术语与知识卡先执行[术语选择与知识卡说明](references/adaptive-concepts.md)：从当前文章发现理解所需概念，再选择、消歧、建立必要前置关系并解释；词库只辅助核对，未命中不意味着忽略。每篇生成可审查清单，原文/译文/图注均有适当查阅入口，按领域选择直白分类。卡片先建立认识，再有依据地连接本文用途与相关概念；不把用户举例固化为通用词表或校准材料。匹配器、结构验收与理解/科学核查分开。

1. **读入与续改定位**：新论文核对正文、图注、方法/推导及证据材料和已取得补充资料，从原论文建立本文核心内容清单，含正文单元、主图/面板，以及承载主贡献的表格、公式、算法与证明；不能只从已生成HTML反推清单。维护已有项目先读AGENTS、实时pending随手记及附件、已有方法草稿；保留原文、译文、锚点和用户数据。只要求对话解释或审查时不改网页。
2. **核对证据再写作**：读[讲解范式](references/conversational-teaching-playbook.md)与[拆解手册](references/article-decomposition-manual.md)，先建来源证据台账和问题网络，再写自然解释；台账关联具体主张、源位置与最终页面锚点，核对作者原述、通用背景和教学归纳的边界。自然解释是写作方法，不要求先在聊天中重复交付全文。只有表达失真且案例适用时才读[校准例子](references/teaching-calibration-examples.md)，只借鉴表达，不迁移旧论文事实。
3. **按问题讲解**：按[阅读与教学](references/reading-and-teaching.md)保留连续原文、完整翻译与明确结论，围绕所选单元解释。详细单元讲清输入、比较、测量与元素、真实观察、推理和界限；共享比较先核对样本/条件/尺度是否可比，再讲共同方法与独有变化，不在每个面板重复整套模板。简单图按其角色简述。全文链保留真实依赖、并行及否定结果；核心表格、公式与方法按贡献需要讲解。
4. **图像与装配**：按[图像规范](references/figure-quality.md)检查原生矢量/位图和裁区，保留所有轴/图例，不生成式补细节。复用[组件使用说明](references/components.md)，用scripts/build_reader.py装配工作稿；不为新论文重新设计已经确定的交互。
5. **验收与发布**：执行[验收](references/acceptance.md)，逐单元核对内容、逐视口验证交互。按[维护与版本](references/maintenance.md)发布，桌面只保留固定同名最新版，项目内保留最新版与用户选定历史数量。报告缺失资料及未实测项，不以结构检查证明理解效果。

## 页面归属与顺序
| 区域 | 内容 | 默认生成 |
|---|---|---|
| 基础文章内容 | 摘要、按原结构连续组织的核心论证与主图、作者总结/局限 | 是 |
| 知识区 | 超出读者起点且必要的概念、术语卡、全文论证链与简洁流程图 | 是 |
| 进阶内容 | 用户选定的复现细节、附图、论文支线 | 按选择 |
| 进阶知识区 | 读者总结与评议；选定后加入复习等 | 读者评议必需，复习按选择 |
四区按表顺序排列，空区不显示；读者评议始终全文最后。“进阶知识区”是归属名称，不决定生成权限。知识区不冒充作者正文；首次用到陌生对象时随正文简短定义，读前基础只解释摘要后真正需要的对象和问题，不提前堆实验品系与细节。导航、DOM顺序、编号及笔记选项一致。

## 保留的阅读体验
具体状态与HTML属性见[版式与导航](references/page-and-navigation.md)。
- 目录常规导航不记录返回。名词→知识卡及明确的临时查阅才显示底部固定返回按钮，恢复外层位置、当前面板与独立文字滚动；返回栈用尽隐藏。
- 知识卡单列，标题右侧一个按钮切换整组展开/收起；卡片跳转居中，段落起始对齐。
- 左下笔与图例按钮同一行，图例展开为两列三行、与侧栏对齐、每项单行。笔展开不启用标黄；状态默认关闭，按钮显示“开启”，启用后显示“关闭”；另有“撤销”。术语颜色开关独立，文章不使用类别角标。
- 随手记为右边缘竖排书签，可沿边上下拖动并记住相对位置。面板无收起按钮，点外部或Escape收起，保留草稿。写当前项目、下轮助手处理，不即时调用GPT。
- 大图预览居中留边，右上圆形×，点遮罩/Escape关闭；支持缩放和平移。禁用图片原生拖拽，保留右键保存。手机/iPad可切换全部面板，原图与对应文字同时切换。

## 文件、设置与边界
每篇唯一稳定paper-id，项目路径/端口取当前环境。核心入口paper-reading.html，队列reading-notes.json，项目备份策略reader-settings.json，版本清单reader-versions.json；工作稿与正式历史快照分开。来源页/段/裁区保存于内部台账，阅读区不重复展示制作定位提示或正文截图；保留原论文PDF总入口及科学上必要的图号引用。
备份策略以项目文件为唯一依据：0/1/2历史备份，最新版另计。首次本地服务页面询问，可稍后选择；桌面离线版仅显示策略及本地服务入口，不另建离线策略。未选择时仍交付带时间标签的工作版，不清理历史。正式发布命名简称_vN.0_北京时间.html，桌面文件名固定；细则见maintenance.md。
静态全文可离线；项目笔记保存依赖独立本地服务，浏览器草稿/个人标黄不等于项目笔记。断线自动补存/移动端安全网络/即时GPT不在当前组件能力内，不虚称已实现。学习完成、理解效果和重启实测与内容/功能交付分别报告。新论文不携带本来源项目私有笔记、图片或机器路径。
将[项目维护模板](assets/AGENTS-reading.md)合并入新项目，保留适用的既有规则。仅按用户明确请求上传GitHub或安装Skill。
