# search-cn-ecommerce

## 目标
在用户需要中国电商跨平台商品搜索、比价或资料收集时，通过零认证统一搜索和只读页面读取整理商品、价格、店铺、评价线索和链接。

## 适用请求
- 跨淘宝、天猫、京东、拼多多、1688、速卖通、抖音商品、小红书商品进行比价。
- 搜索商品关键词、型号、图片线索或同款替代。
- 汇总不同平台当前价、优惠信息、店铺和评价摘要。

## 首选通道
- skill-only：先按平台专项 skill 分流，再用当前已登录 Firefox 新标签页打开平台搜索/详情页核验。
- 公开可索引信息用 WebSearch/WebFetch；登录后可见信息只从当前 Firefox 可见页面、用户复制文本或截图/OCR 取证。
- 不新增或依赖 MCP；外部项目只能作为资料线索，不作为本 skill 的执行前提。

## 兜底通道
- 转入平台专项 skill，如 `search-taobao-tmall`、`search-jd`、`search-xianyu` 或 `search-xiaohongshu`。
- 使用当前 Firefox 已登录会话只读访问平台搜索页和商品详情页；遇到验证码或风控时请求用户人工处理。

## 操作流程
1. 确认商品关键词、品牌型号、规格、地区、预算、是否需要含券价/到手价。
2. 优先按平台专项 skill 分流：淘宝/天猫、京东、闲鱼、小红书、Amazon、价格历史；用当前 Firefox 或 WebSearch 取证。
3. 读取商品页时只记录公开或当前 Firefox 已授权可见的标题、价格、店铺、销量、评价摘要、规格和 URL；全程只读搜索/读取，不发起新的登录流程、不下单、不私信、不发帖、不写入平台，也不加购、领券或咨询客服。
4. 对价格标注时间、平台、优惠条件和是否需登录可见，避免把促销价当作稳定价格。
5. 输出可比较表格，并标注无法访问或需要人工验证的项目。

## 只读安全边界
- 只搜索、打开、读取、摘录和汇总商品公开信息。
- 不发起新的电商平台登录流程；优先复用当前 Firefox 已登录会话，不绕过验证码、风控或地区限制。
- 不加购物车、不下单、不付款、不领券、不关注店铺、不咨询客服、不私信、不评价、不发布内容。
- 不写入密钥、Cookie、Token、收货地址或支付信息。

## 验证方式
- 后续可运行：`dir C:\Users\Zhang\.config\opencode\skills\search-cn-ecommerce\SKILL.md`
- 人工检查：确认首选通道为平台专项 skill + 当前 Firefox/WebSearch，且不依赖 MCP，安全边界禁止下单和私信。

## 已知限制
- 电商价格、库存和优惠实时变化，结果需标注检索时间。
- 部分平台搜索和评价需要登录或 App 环境。
- 零认证工具覆盖范围、排序和字段完整性可能有限。
