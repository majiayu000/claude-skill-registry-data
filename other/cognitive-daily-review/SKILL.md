# 每日与每周反思

## 目标

围绕真正触动或重复发生的事件提炼改变，不追求流水账、篇幅、连续天数或形式完整。没有触动时允许短写或不写。

## 工作流

1. 收集素材：最重要进展、最大消耗、最强情绪、最意外结果、最值得保留的行为。
2. 只选 1—3 个触动点。优先选择改变认识、暴露模式或影响行动的事件，不平均记录所有事情。
3. 对每个触动点执行“每日反思三步”：
   - 描述经过：只写关键事实和行为；
   - 分析原因：区分事实、解释、情绪、环境、能力和选择节点；用户没有提供的原因标为“待核实”，不要为了完整擅自补全；
   - 改进措施：形成下次可以执行和检查的认知点或行动点。
4. 建立关联：这件事还说明什么？与哪条旧经验、知识或长期目标有关？以后在哪个场景可能再次出现？
5. 检查反模式：把日记当反思、只宣泄不提炼、只自责不找机制、列太多改进、为了连续打卡而写。
6. 提炼一条“保留”，一条“停止”，一条“尝试”。必要时把复杂行动交给 `cognitive-action-system` 继续拆解。
7. 确定明日唯一重点、最小开始动作和检查时间。

## 输出格式

按“事实摘要 → 触动点 → 原因分析 → 认知点 → 行动点 → 明日唯一重点”输出。周复盘再补充“本周重复模式、有效策略、下周一个实验”。

## 质量门槛

- 复盘必须指向下一次改变，但每次最多修正一个关键问题。
- 不把一次失误上升为人格缺陷；用机制解释后仍要落实责任与选择。
- 明日行动必须小到可以开始，并有明确检查点。
- 用户未提供次日日程时，给可平移的默认时段并说明可调整，不把假定时间写成既定事实。
- 不用“今天很充实、继续加油”代替因果分析。
- 复盘不是正在发生的危机处理；强烈情绪先转交事实情绪工作流。
