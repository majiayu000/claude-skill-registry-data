# deep-work-flow-setup

## When to Use

当需要进入并维持高度专注的深度工作状态时description

## Core Logic

# 执行步骤

1.  **意图确认**
    *   **输入**：个人愿景、目标、优先事项。
    *   **操作**：明确当前深度工作时段要服务的具体目标，确保行动与个人意图一致。
    *   **判断标准**：能否用一句话说清“这次专注是为了实现XX”。
    *   **输出**：清晰的深度工作意图陈述。

2.  **任务与时间框定**
    *   **输入**：待办任务池。
    *   **操作**：
        a. **筛选**：选出1-3项能最大程度推动目标的关键任务。
        b. **安排**：在日历上为这些任务预定一个连续的、不可打扰的时间段（建议45分钟至2小时）。
    *   **判断标准**：任务是否关键；时间段是否已被正式预约并保护。
    *   **输出**：写入日程的深度工作时段及对应的关键任务列表。

3.  **环境与干扰隔离**
    *   **输入**：预定的工作时间段和任务列表。
    *   **操作**：
        a. **选择地点**：前往一个与休息/睡眠区分开的独立物理空间。
        b. **屏蔽数字干扰**：使用工具（如应用拦截器）屏蔽手机、电脑上的非必要通知和网站。
        c. **设置氛围**：根据需要，播放无歌词的音乐或环境音。
    *   **判断标准**：物理和数字环境是否已最大程度减少分心可能。
    *   **输出**：准备就绪的深度工作环境。

4.  **执行与单任务聚焦**
    *   **输入**：关键任务、准备好的环境。
    *   **操作**：启动计时器，在预定时间段内，只处理选定的单一关键任务，拒绝任务切换。
    *   **判断标准**：是否在整段时间内保持了对单一任务的专注。
    *   **输出**：任务完成或取得实质性进展。

5.  **强制性休息与衔接**
    *   **输入**：刚结束的深度工作时段。
    *   **操作**：计时结束后立即离开工作位置，进行10分钟左右的散步或非屏幕活动。期间可复盘进展并思考下一任务。
    *   **判断标准**：是否实现了身心状态的切换，并为后续工作做好了准备。
    *   **输出**： refreshed 状态及对后续工作的简要规划。

# 输出格式要求
提供深度工作会话报告：
- **时段**：[开始时间] - [结束时间]
- **意图目标**：[步骤1的输出]
- **完成的关键任务**：[步骤4的输出]
- **干扰处理情况**：遇到的主要干扰及应对方式。
- **休息后状态**：简要描述（如：清醒/疲惫/有新的想法）。
