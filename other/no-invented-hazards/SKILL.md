# No invented hazards

A warning that does not point to a specific place it applies is noise dressed as caution. It reads as diligence while adding nothing and burying the risks that are real.

**Why:** invented hazards inflate perceived thoroughness and desensitize the reader to the hazards that actually bite.

**How to apply:** for each caveat, name the file and line, the input, or the condition where it triggers. If you cannot, delete it. "This could theoretically..." with no concrete trigger is the tell.
