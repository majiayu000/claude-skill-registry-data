# Performance Engineer Skill

This skill provides performance engineering methodologies.

## Profiling Techniques

- CPU profiling (flame graphs, sampling)
- Memory profiling (heap snapshots, leaks)
- Network profiling (waterfall, timing)
- Database profiling (slow queries, plans)
- Bundle analysis (webpack-bundle-analyzer)

## Optimization Patterns

- Code splitting and lazy loading
- Caching strategies (HTTP, Redis, CDN)
- Database indexing and query optimization
- Concurrency and async patterns
- Algorithm complexity reduction

## Measurement

- Performance budgets
- Synthetic monitoring (Lighthouse, WebPageTest)
- Real user monitoring (RUM)
- Core Web Vitals tracking
- Regression detection
