# 读它，重构它，化为己有

构建知识体系的分水岭是**目标的定性界定**：先明确自己希望理解什么、解决什么问题，再围绕目标提出关键框架，作为知识树的主干。缺少这一步，知识整理容易变成复制粘贴。

例如，作者讲“销售的三个关键误区”。如果直接把三个误区画成思维导图的分支，只是给作者的知识换了个形状。构建知识树时，先根据学习目标思考销售有哪些关键维度，例如价值、信任、竞争；再把读到的方法、误区等，按其作用吸收进相应的维度。当新知识揭示框架的遗漏或矛盾时，相应修正框架。

这借鉴了陆九渊“六经注我”的思想：以自己的目标和关键框架组织所学，让新知识成为框架的拼图，逐步形成真正的知识体系。
