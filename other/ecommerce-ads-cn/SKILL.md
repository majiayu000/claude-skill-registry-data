# 电商站内投放

先分清平台与经营场景（直播/短视频/货架/商品卡），再按 `references/platforms.md` 对应小节诊断。电商投放的铁律：**投放是放大器，货品力与内容力是本体**；ROI 差先排除品与内容的问题，再谈投放技巧。

## 数据契约

平台与店铺类型、推广目标（直播间成交/商品成交/拉新）、近 7–30 天分计划：消耗、成交金额、ROI、转化成本、点击率、转化率；商品维度：客单价、毛利率、退款率；直播场景另要：场观、GPM、停留、转粉、流量结构（付费/自然/短视频引流）。

## 通用诊断顺序

1. **算保本线**：保本 ROI = 1/毛利率（含退款与平台扣点修正）。先判断"ROI 低"是低于保本还是低于预期。
2. **货品力**：点击率与转化率对标类目（用户历史/生意参谋/罗盘数据）；品不行换品，不硬投。
3. **内容力**（抖音/快手）：素材/直播间承接能力——GPM、停留、互动决定付费流量能否撬动自然流量。
4. **投放结构**：计划数与预算分布、出价方式（控成本 vs 放量/最大化）、定向宽窄、素材上新。
5. **全域/托管产品评估**：是否适合开全域推广/货品全站推（前提：货品转化稳定、素材供给足、接受系统接管定向与出价）；开了之后看"整体 ROI（付费+自然）"而非单计划 ROI。
6. **人群资产**：拉新 vs 收割比例；老客复购触达是否过度（频次/退款）。

## 输出格式

```
## 电商投放诊断（平台 / 场景 / 区间）
**保本 ROI**：__　**实际 ROI**：__　**结论**：__
### 货品/内容/投放三层归因
### 行动清单（优先级/动作/预期/风险）
### 是否调整托管产品（全域/全站推）的建议与前提
置信度 + 数据缺口
```

## 约束

- 平台产品名以用户后台实际为准（迭代快）；参考文件中的名称为 2025–2026 现行口径。
- 不建议刷单/补单/虚假交易来"做权重"——违法且平台严打。
- 托管产品不是万能药：给开启前提与退出条件，不盲目推荐。
