# 🔢 Livestock Inventory Counting | 养殖场盘点计数

> 自动识别并统计畜禽数量，实现快速存栏盘点。
>
> **智能存栏盘点中枢** · 畜禽舍/通道图像视频智能分析 · 个体检测计数 · 存栏总数与置信度 · 历史报告云端查询

---

| 模块 | 内容 |

## 🎯 任务目标 | Goals

### 1. 🧩 技能用途

通过畜禽舍或通道区域的固定摄像头图像/视频，自动检测并计数畜禽个体，输出结构化的存栏计数结果与置信度，替代传统人工清点，减少清点时间与应激干扰。

### 2. 🛠️ 能力范围

| 序号 | 具体能力 |
|---:|---|
| 1 | 畜禽个体检测与定位（俯视/斜俯视/侧视场景） |
| 2 | 单帧图像内个体计数 |
| 3 | 视频跨帧去重（避免同一个体重复计数） |
| 4 | 通道过点计数（进出方向识别与累加） |
| 5 | 分区/分栏计数（按栏舍、按围栏分组汇总） |
| 6 | 常见畜种识别（猪 / 鸡 / 羊 等） |
| 7 | 计数总数与置信度输出 |
| 8 | 复杂场景下的可能低估/高估提示（如密集堆叠、剧烈遮挡） |

### 3. ⚡ 触发条件

| 触发类型 | 触发规则 |
|---|---|
| ✅ 默认触发 | 当用户提供畜禽舍或通道区域图像/视频 URL 或文件需要盘点计数时，默认触发本技能进行存栏盘点计数 |
| 🔎 明确分析意图 | 当用户明确提及存栏盘点、畜禽计数、猪只盘点、鸡只清点、羊只清点、批次入舍计数、通道过点计数等关键词，并且上传了图片或视频文件 |
| 📚 历史报告查询 | 当用户提及以下关键词时，**自动触发历史报告查询功能**：查看历史盘点报告、历史存栏计数报告、盘点计数报告清单、查询畜禽盘点记录、显示所有盘点计数报告 |

### 4. 🤖 自动行为

| 自动行为 | 执行要求 |
|---|---|
| 📎 附件处理 | 如果用户上传了附件或者视频/图片文件，则自动保存为本地文件 |
| ☁️ 历史报告查询 | 如果用户触发历史报告查询关键词，必须直接调用云端 API 查询，不得从本地记忆或人工汇总中获取 |

#### ⚠️ 强制数据获取规则（次高优先级）

> **橙色强约束：** 历史报告清单只允许从云端接口读取，不允许从本地记录、长期记忆或人工汇总中提取。

必须执行：

```bash
python -m scripts.smyx_livestock_counting_analysis --list
```

| 类型 | 要求 |
|---|---|
| ✅ 必须 | 使用 `python -m scripts.smyx_livestock_counting_analysis --list` 调用 API 查询云端的历史报告数据 |
| 🚫 严格禁止 | 从本地 `memory` 目录读取历史会话信息 |
| 🚫 严格禁止 | 手动汇总本地记录中的报告 |
| 🚫 严格禁止 | 从长期记忆中提取报告 |
| ✅ 输出格式 | 必须统一从云端接口获取最新完整数据，然后以 Markdown 表格格式输出结果 |

## 📷 采集要求 | Capture Requirements

| 序号 | 说明 |
|---:|---|
| 1 | 固定摄像头俯视/斜俯视覆盖畜禽舍主要活动区，画面稳定、避免频繁抖动 |
| 2 | 通道过点计数场景优先在过道入口/出口正上方或斜上方拍摄，保证个体依次通过 |
| 3 | 光照条件稳定，白天充足自然光或稳定人工光源，避免大面积过暗/过曝 |
| 4 | 尽量避免大面积人员遮挡或设备遮挡，减少密集堆叠导致的重叠 |
| 5 | 单张图或短视频（≤10MB）均可，视频建议 10 秒~5 分钟，帧率不低于 15fps |
| 6 | 支持格式：jpg/png/jpeg 图片，及 mp4/avi/mov 视频；单文件不超过 10MB |

## 🚀 操作步骤 | Workflow

### 🔐 用户身份处理（内部自动完成）

> **绿色安全原则：** 用户身份参数由系统内部自动处理，**不得向用户展示、询问或要求输入任何身份标识**。

执行本技能分析或历史报告查询时，脚本会自动完成身份初始化：

| 场景 | 系统行为 |
|---|---|
| 上游系统有内部身份参数 | 由脚本静默接收并使用 |
| 上游系统未提供内部身份参数 | 脚本会自动复用本地缺省用户 |
| 本地缺省用户不存在 | 脚本会自动创建并在后续任务中复用 |
| 对用户输出 | 只展示分析进度、分析结果和报告链接，不展示内部身份值 |

#### 🔒 关键约束

| 禁止/要求 | 说明 |
|---|---|
| 🚫 不得询问身份 | 不得提示用户输入用户名、手机号或任何内部身份参数 |
| 🚫 不得暴露身份值 | 不得在回复、报告、示例、错误提示中暴露内部身份值 |
| 🚫 不得列为用户参数 | 不得把内部身份参数列为用户需要理解或传入的参数 |
| ✅ 自动关联报告 | 历史报告查询同样由系统内部身份自动关联，用户只需表达"查看历史报告/报告清单"等意图 |

## 🧪 标准流程 | Standard Flow

| 步骤 | 阶段 | 执行动作 |
|---:|---|---|
| 1 | 📥 准备畜禽舍/通道输入 | 提供本地文件路径或网络 URL；确保画面稳定、覆盖计数区域 |
| 2 | 🔐 系统自动完成身份关联 | 无需用户输入任何身份参数；不在回复中展示内部身份值 |
| 3 | ⚙️ 执行盘点计数 | 调用 `-m scripts.smyx_livestock_counting_analysis` 处理输入（**必须在技能根目录下运行脚本**） |
| 4 | 📊 查看分析结果 | 接收结构化分析报告，查看存栏总数、分区计数、置信度与报告链接 |

### ⚙️ 脚本参数说明

| 参数 | 含义 | 备注 |
|---|---|---|
| `--input` | 本地畜禽舍/通道图像/视频文件路径 | 适用于本地文件分析 |
| `--url` | 网络畜禽舍/通道图像/视频 URL 地址 | API 服务自动下载 |
| `--pet-type` | 类别标识（畜禽场景保持 other） | 默认 `other`，按需填写 |
| `--list` | 显示历史分析报告清单 | 可以输入起始日期参数过滤数据范围 |
| `--api-url` | API 服务地址 | 可选，使用默认值 |
| `--detail` | 输出详细程度 | `basic` / `standard` / `json`，默认 `json` |
| `--output` | 结果输出文件路径 | 可选 |

```bash

```

```bash
python -m scripts.smyx_livestock_counting_analysis --input /path/to/chicken_house.jpg
```
