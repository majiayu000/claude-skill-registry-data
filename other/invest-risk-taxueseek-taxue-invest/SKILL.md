# invest-risk：风险认知与管理系统

> 风险不是波动，是本金的永久损失。管理的关键不是意志力，是系统。

---

## 哲学锚点

- **巴菲特「保住本金」**：规则一——永远不要亏钱；规则二——永远不要忘记规则一。
- **达里奥「全天候」**：不预测天气，但为每种天气准备衣服。永不离场。
- **塔勒布「反脆弱」**：真正的风险是你认知以外的风险——你根本看不见。

## 第一层：风险认知四层递进

风险不是单一概念，而是四层递进——从最致命到最隐蔽：

| 层 | 风险类型 | 核心判断 | 典型表现 |
|---|---------|---------|---------|
| 1 | **杠杆风险**（最致命） | 杠杆放大亏损，爆仓=永久出局 | 配资、高杠杆期货、借钱炒股 |
| 2 | **本金风险** | 亏损侵蚀本金，复利基础被破坏 | 追热点、满仓单一品种、不止损 |
| 3 | **认知风险** | 你认知以外的风险，你根本看不见 | 看不懂的衍生品、不了解的底层资产 |
| 4 | **心态风险**（最隐蔽） | 心态失衡 → 一步错步步错 | 亏损后加仓赌一把、赚了就飘 |

**诊断顺序**：先排杠杆 → 再控本金 → 再拓认知 → 最后管心态。前一层不解决，后一层白搭。

### 杠杆风险判断

| 信号 | 判断 |
|------|------|
| 使用配资/两融/期货杠杆 | **红线**——普通人不应使用 |
| 借钱投资（消费贷/信用卡） | **红线**——绝对禁止 |
| 杠杆率 > 1.5X | 危险区 |
| 杠杆率 < 1.2X 且有安全垫 | 可接受（如优先股/认股权证结构） |

**核心原则**：杠杆本身不是罪，无安全垫的杠杆才是。巴菲特的 1.5X 杠杆建立在保险浮存金（零成本、无追保）之上，普通人复制不了这个结构。

### 本金风险判断

| 信号 | 判断 |
|------|------|
| 单一品种 > 20% | 集中度过高 |
| 单一行业 > 30% | 行业风险暴露过大 |
| 无应急现金（< 6 个月支出） | 抗风险能力弱 |
| 投资组合相关性 > 0.8 | 名义分散，实际同涨同跌 |

### 认知风险判断

| 信号 | 判断 |
|------|------|
| 说不清底层资产是什么 | 认知盲区——不买 |
| 说不清怎么赚钱 | 认知盲区——不买 |
| 说不清最坏情况亏多少 | 认知盲区——不买 |
| 靠运气赚过钱 | 最危险的体验——会误以为有判断力 |

### 心态风险判断

| 信号 | 判断 |
|------|------|
| 盯盘时间 > 研究时间 | 信噪比过低 |
| 亏损后频繁操作 | 损失厌恶驱动 |
| 盈利后加大仓位 | 过度自信 |
| 只关注支持性信息 | 确认偏误 |

## 第二层：风险管理四层框架

四层从基础到高级，层层递进。**行为约束最重要**——没有它，前三层都是纸糊的。

| 层 | 内容 | 性质 | 核心规则 |
|---|------|------|---------|
| 1 | **仓位管理** | 最基础 | 永不满仓；6 个月应急现金；不碰杠杆；单一品种 ≤ 20%；单一行业 ≤ 30% |
| 2 | **分散配置** | 降系统性风险 | 跨资产类别、跨市场、跨货币；全天候策略主要在这一层工作 |
| 3 | **估值约束** | 辅助判断 | 不在高估值时买核心仓位；用 PE/PB 历史分位、股债性价比辅助 |
| 4 | **行为约束** | **最重要** | 预设规则、降低决策频率、自动化执行——处理最大风险源：你自己 |

### 仓位管理规则

```
永不满仓 → 永远留有余地
应急现金 → 至少 6 个月支出
不碰杠杆 → 无安全垫的杠杆 = 赌博
单一品种 → ≤ 20%
单一行业 → ≤ 30%
```

### 分散配置原则

- **跨资产类别**：股票 + 债券 + 商品 + 现金
- **跨市场**：A股 + 港股 + 美股 + 其他
- **跨货币**：人民币 + 美元 + 其他
- **关键指标**：资产间相关性 < 0.5 才有效

### 相关性矩阵分析

| 资产对 | 正常时期 | 危机时期 | 判断 |
|--------|---------|---------|------|
| 股-债 | -0.3 ~ 0.2 | 0.3 ~ 0.6 | 危机时正相关，分散失效 |
| 股-黄金 | -0.1 ~ 0.1 | -0.3 ~ 0.0 | 黄金是有效对冲 |
| A股-美股 | 0.4 ~ 0.6 | 0.7 ~ 0.9 | 危机时高度相关 |
| A股-港股 | 0.6 ~ 0.8 | 0.8 ~ 0.9 | 高度相关，分散效果有限 |

**相关性陷阱**：2008/2015/2022 期间，多数资产相关性趋近 1，名义分散失效。真正的分散需要加入负相关资产（如黄金、国债、CTA 策略）。

## 第三层：不依赖意志力的投资系统

意志力是消耗品，市场专挑你最累的时候出题。设计一套系统，让它在关键时刻替你做决定。

### 四条规则

**规则一：预设并写下来**
- 什么时候买、什么时候卖、什么时候调仓
- 在市场平静的时候写好规则
- 等市场疯狂时，不需要判断，只需要执行

**规则二：降低决策频率**
- 主动调仓每年不超过 2 次
- 定投自动扣款
- 不看日线、不看周线
- 每周甚至每月看一次账户就够
- 「盯盘越久，亏得越多」不是玩笑，是统计事实

**规则三：自动化执行**
- 定投自动扣款
- 再平衡日写进日历
- 需要「手动操作」的事越多，被情绪干扰的机会就越多

**规则四：定期复盘，按规则不按情绪**
- 三个问题：
  1. 我按规则执行了吗？
  2. 规则本身需要调整吗？
  3. 我有没有在规则之外做决策？
- 复盘的目的是检验系统，不是表扬或谴责自己

### 核心洞察

> 系统不要求你完美。系统只要求你在关键的那几个时刻，让它替你做决定。

## 第四层：现金管理与安全垫

### 现金原则

- **现金像氧气**：平时不感觉存在，没有时立刻窒息
- **永远留有余地**：不预测市场，但为所有可能的情况准备好衣服
- **抄底需要安全垫**：没有现金的抄底 = 接飞刀

### 安全垫设计

| 层级 | 内容 | 作用 |
|------|------|------|
| 第一层 | 6 个月生活支出（货币基金/存款） | 应急，不动用投资资金 |
| 第二层 | 投资组合中的现金/短债仓位（5-10%） | 再平衡弹药 |
| 第三层 | 类现金资产（国债/金融债） | 抄底专用，市场暴跌时启用 |

### 杠杆认知

| 类型 | 特征 | 判断 |
|------|------|------|
| 安全杠杆 | 低成本、无追保、有安全垫（如保险浮存金） | 可接受 |
| 危险杠杆 | 高成本、有追保、无安全垫（如配资/两融） | **红线** |

## 核心原则

1. **不替决策**：提供框架，决策交还用户
2. **不预测风险**：只评估当前状态与设计系统
3. **行为约束优先**：没有行为约束，其他三层都是纸糊的
4. **数据时效**：不用过期数据
