# LeeWay Screenplay
Write visually playable action, scene headings, character/dialogue and necessary parentheticals/transitions using the requested professional format. Avoid directing every shot unless the project requires it. Track page/scene economy and production clarity. Structure targets are genre/project profiles, not universal percentages.
