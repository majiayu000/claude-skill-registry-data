# holonic-alignment

## When to Use

当寻求个人行动或项目在更宏大系统中的意义，或需要将日常工作与长远价值连接时description

## Core Logic

# 执行步骤

1.  **识别所在全息体**
    *   **输入**：你正在从事的具体活动、项目或角色。
    *   **操作**：
        *   将你的活动视为一个“整体/部分”（全息体）。
        *   向上追溯：识别该活动是哪个更大系统（更大的“整体”）的组成部分。例如：你写的代码是某个软件的一部分，该软件是某个公司业务的一部分，该公司服务于某个社会需求。
        *   向下分解：识别构成该活动的更小组件（更小的“部分”）。例如：完成这个项目需要沟通、设计、执行等子环节。
    *   **判断标准**：能清晰描述出活动在至少两个层级（上一层和下一层）系统中的位置。
    *   **输出**：一个简要的层级关系描述（如：我的[活动A]是[更大系统B]的一部分，并由[组件C1, C2...]构成）。

2.  **区分秩序类型**
    *   **输入**：步骤1输出的层级关系。
    *   **操作**：分析你所处层级结构中的秩序是如何产生的：
        *   **IF** 秩序主要由外部权力、规则强加，且抑制下层部分的自主性与成长 → 这可能是“支配型分层”。
        *   **ELSE IF** 秩序是在解决冲突、问题或满足内在成长需求中自然“涌现”的，并且整合（包含）了下层部分的特性 → 这接近“自然/成长型分层”。
    *   **判断标准**：能判断当前系统秩序的主要产生机制是强加的（支配）还是涌现的（成长）。
    *   **输出**：对当前系统秩序类型的判断（支配型 / 成长型）。

3.  **与最高秩序对齐**
    *   **输入**：步骤1和步骤2的输出（全息体位置及秩序类型）。
    *   **操作**：
        *   秉持“超越并包含”的进化观，思考你的活动如何能促进自然涌现的、更具包容性的秩序。
        *   自问：我的工作如何能**解决一个真实问题**，从而为所在系统（及更大系统）创造价值？
        *   自问：我的**技能获取与个人成长**，如何能使我更好地服务于更广阔的整体（从群体到世界乃至宇宙）？
        *   将日常任务视为向更大整体贡献价值的“涟漪效应”的起点。
    *   **判断标准**：能将具体活动与解决更广泛问题、促进系统健康或个人超越性成长联系起来。
    *   **输出**：一段关于个人行动如何与更宏大、涌现的秩序（最高秩序）保持一致的清晰陈述。

# 输出格式要求
以反思陈述形式输出：
1.  **系统定位**：我当前的 [活动] 是 [更大整体] 的一部分，它由 [子部分] 构成。
2.  **秩序诊断**：我所在的系统秩序更偏向 **[支配型/成长型]**。
3.  **意义对齐**：通过这项活动，我旨在解决 **[具体问题]**，这有助于 **[描述对更大整体的贡献]**，同时推动我个人在 **[技能/认知]** 上的成长，这与更宏大的涌现秩序是一致的。
