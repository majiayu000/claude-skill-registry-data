# 4-hour-work-system

## When to Use

当需要系统性地提升工作专注度和生产力，实现高质量成果时description

## Core Logic

# 执行步骤

1.  **确立身份与愿景**
    *   **输入**：对当前状态的不满或对未来的模糊期望。
    *   **操作**：明确一个你希望成为的、反对平庸的“身份”（例如：“我是一个能深度思考并交付卓越成果的人”），并基于此身份，构想一个清晰的长期愿景。
    *   **判断标准**：身份陈述具体、有激励性；愿景描述清晰，能激发行动。
    *   **输出**：一个明确的身份声明和一个清晰的长期愿景。

2.  **定义具体项目**
    *   **输入**：上一步输出的长期愿景。
    *   **操作**：将愿景分解为具体的、可执行的项目。每个项目应是一个有明确产出和边界的任务集合，作为实现愿景的“指针”。
    *   **判断标准**：项目与愿景直接相关，有明确的完成标准和边界。
    *   **输出**：一个或多个具体项目列表。

3.  **设置截止日期**
    *   **输入**：上一步输出的具体项目列表。
    *   **操作**：为每个项目设定一个具有挑战性但合理的截止日期，以制造必要的紧迫感。
    *   **判断标准**：截止日期能激发行动力，而非导致焦虑或不可实现。
    *   **输出**：带有明确截止日期的项目计划。

4.  **规划时间块与休息**
    *   **输入**：带有截止日期的项目计划。
    *   **操作**：在日历中为高专注工作预留固定的、受保护的时间块（如每日2-4小时）。在时间块之间及之后，规划明确的休息时段。
    *   **判断标准**：时间块长度符合个人专注力极限；休息时段被正式纳入日程。
    *   **输出**：包含受保护工作块和休息时段的日程表。

5.  **筛选高杠杆工作**
    *   **输入**：项目计划与日程表。
    *   **操作**：在每个工作块开始前，识别并优先选择能对项目进展产生最大推动作用的“高杠杆”任务（即投入产出比最高的任务）。
    *   **判断标准**：所选任务直接关联项目核心目标，能显著推进项目进度。
    *   **输出**：当前工作块内要执行的具体高价值任务。

6.  **执行并固化为日常**
    *   **输入**：当前工作块的具体任务。
    *   **操作**：在规划的时间块内，执行选定的高杠杆任务。通过每日重复此流程（步骤4-6），将整个系统固化为无需消耗意志力的日常习惯。
    *   **判断标准**：能在规划时间内专注完成任务；系统执行起来越来越自动化。
    *   **输出**：完成的任务项和强化的习惯系统。

7.  **执行战略性休息**
    *   **输入**：完成工作块后的状态。
    *   **操作**：严格履行规划的休息，进行与工作完全无关的活动（如散步、冥想、社交）。理解休息是系统的一部分，用于恢复认知资源、激发创造力。
    *   **判断标准**：休息期间真正脱离工作；休息后感到精力恢复，而非更疲惫。
    *   **输出**：恢复的专注力和创造力，为下一个周期做好准备。

# 输出格式要求
输出一个结构化的当日或当周生产力计划，包含：
1.  **核心身份/愿景提醒**：一句话重申。
2.  **核心项目与截止日**：列出1-3个关键项目及其截止日期。
3.  **今日/本周时间块规划**：以日历形式展示受保护的工作块和休息时段。
4.  **当前工作块高杠杆任务**：列出即将开始的时间块内要做的具体任务。
5.  **休息活动安排**：注明计划中的休息活动。
