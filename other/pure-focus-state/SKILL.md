# pure-focus-state

## When to Use

当需要进入高效学习、创作或问题解决的心流状态时，调用此模型作为环境与心理准备框架。description

## Core Logic

# 执行步骤

1.  **任务单一化**
    *   **输入**：多项待办事项或一个复杂的多线程任务。
    *   **操作**：从中剥离或定义出一个在当前时段（如接下来的2-3小时内）唯一需要全力投入的、最小的完整子任务。
    *   **判断标准**：能否用一句话清晰描述这个子任务，且该任务完成后能产生明确的进展感。
    *   **输出**：一个单一的、明确的当前焦点任务。

2.  **干扰源清除**
    *   **输入**：物理工作环境和数字设备。
    *   **操作**：
        *   **物理环境**：整理桌面，移除与当前任务无关的物品。
        *   **数字环境**：关闭所有非必要的软件通知，将手机设为勿扰模式并置于视线之外，关闭无关的浏览器标签页。
        *   **心理环境**：如果头脑中有杂念，用1分钟时间快速写在纸上，清空工作记忆。
    *   **判断标准**：是否创造了一个外部信号无法轻易闯入的“封闭”环境。
    *   **输出**：一个洁净的、低干扰的启动环境。

3.  **状态锚定启动**
    *   **输入**：洁净的环境和单一任务。
    *   **操作**：通过一个简单的、重复性的仪式动作（如深呼吸三次、喝一口水、启动一个计时器）向大脑发出“开始深度工作”的信号。然后立即开始执行焦点任务中最简单、最机械的第一小步（如写下第一个标题、打开第一个必需的文件）。
    *   **判断标准**：是否通过一个动作完成了从“准备”到“执行”的无缝切换，避免了在任务起点犹豫。
    *   **输出**：进入任务执行流程的初始动量。

4.  **维持与回收注意力**
    *   **输入**：执行任务过程中的内部（如走神）或外部（如意外干扰）注意力分散信号。
    *   **操作**：
        *   **IF** 意识到注意力分散：**THEN** 不评判，立即将注意力轻柔地拉回到当前任务的**下一个最小动作**上。
        *   **ELSE** (持续专注中)：**THEN** 继续推进，享受心流状态。
    *   **判断标准**：注意力分散后，能否在短时间内（如1分钟内）重新聚焦。
    *   **输出**：被维持或成功回收的专注力，以及持续的任务进展。

# 输出格式要求
输出一个针对当前任务的“纯粹专注”启动清单：
1.  **焦点任务**：[步骤1定义的单一任务]
2.  **清除项**：[步骤2中需要处理的物理、数字、心理干扰列表]
3.  **启动仪式**：[步骤3选定的具体锚定动作]
4.  **回收暗语**：[步骤4中用于提醒自己回归专注的内心提示词，如“下一个动作”]
