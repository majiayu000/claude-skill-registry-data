# CAD尺寸与圆弧标注

先读项目唯一要求及`../cad-check-review/references/annotation-control.md`。真实源几何和测量语义先于排版；普通植物/索引引线的90°规则不能套用尺寸线。图种、尺寸必要性和源轮廓均按当前项目。

## 类型路由

| 实际任务 | 方法 |
|---|---|
| LINE或线性路宽/长宽 | 当前合格原生线性尺寸；核实际端点及真实垂直断面 |
| ARC/多段线子弧圆心角 | `TDbDimension2`等当前已证原生角度；表达度数，不用弧长冒充 |
| 半径/直径 | `TDbRadiusDim`等实际类型；保圆心、源弧箭头及R/直径语义 |
| 运行/修改“自动批量多段线尺寸”命令 | 读取`../tianzheng-batch-polyline-dimension/SKILL.md`及其当前能力注册入口；不重写业务算法或默认重放历史命令 |

定向读`../cad-check-review/library/knowledge/CAD_ANNOTATION_AESTHETIC_USER_REQUIREMENTS.md`的N05—N12/N19，以及同根`TIANZHENG_NATIVE_ANNOTATION_ADJUSTMENT_AND_COLLISION.md`的“园建原生控制”和“半径标注”节。通用标注修改沿本项目当前执行者，不能因为读取批量命令研发Skill便向旧项目派业务。

## 生成与调整

按共用控制先筛尺寸的有效源资格，再排版：旧构件取消的清其失效尺寸，原构件变位的按当前对应源更新；两测量端点/源弧缺同一有效措施支持的直接列“待删除／待改”，不因附近任意边线或显示数字未变而继续美化。不把尺寸线或其延伸线本身当作被标实体，也不将匹配失败的尺寸自动改指最近另一构件。

1. 资格按实际物理构件判定：中线/偏移边线、主轮廓/压边、内外构件、同宽不同断面分别辨认。源句柄+子段+真实拾取位置完整，不能仅凭同数值去重或把侧边线当中线。
2. 先主要轮廓与必要非R尺寸，再按本图已验H归一外带排角度，最后排同侧半径。优先近带连续性，不为零交点把所有尺寸推远；有效细线相交与文字受压分别判断。
3. LINE核长度及单位；路宽取真实垂直断面，不能斜切后盖数字。ARC核圆心角度数、顺逆与bulge符号，不能文字覆盖把反角假改正确；角度异常按同源端点/原生测量修，不交换夹点猜测。
4. 已验证样例已证半径样本g0圆心、g2源弧标记、g1尺寸线端、g3文字；先按源弧径向调g2让原生联动，再必要时微调文字，实际版本/拓扑先核。不得用曾致崩溃的Reset/猜测ABI恢复样式。模板顺逆、文字在线/线外取当前合格样例，不套另一图常数。
5. 优先原生默认文字关系，只对真实特殊冲突局部调整；不修改真实设计弧/端点或覆盖测量文字。尺寸异常救援只作用异常子集，其它已经合格对象保持。

## 核验

实际原生测量值、源端点、单位/角度符号、RXCLASS和夹点联动逐项核。按当前视口看外带连续、文字与弧线、R/角度成对关系及邻注；尺寸线允许的单点交叉不能全当失败，文字穿线/剪半仍须修。程序端点正确不代表原生显示值正确。

同类数据化批量，修改完成保存并在当前文档继续，大项核本次要求的实际图面；重开仅沿共用触发表按具体异常或明确任务触发；不要继承研发命令的默认不保存策略覆盖用户已授权的正式出图要求。新意见区分源资格、测量语义、排版公式和本图取舍，更新对应条款及已验证消费者；不能为一个特殊角落重造整图算法。
