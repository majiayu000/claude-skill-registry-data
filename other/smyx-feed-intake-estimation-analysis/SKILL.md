# 🥣 Livestock Feed Intake Estimation | 畜禽采食量估算

> 通过食槽视频估算每日采食量变化，异常时预警。
>
> **精准饲喂计量中枢** · 食槽区域连续视频智能分析 · 剩余料量变化估算 · 每日采食量趋势 · 异常预警 · 历史报告云端查询

## 🎯 任务目标 | Goals

### 1. 🧩 技能用途

通过食槽区域固定摄像头的连续视频，量化食槽内饲料剩余量随时间的变化，估算畜禽的每日采食量，输出结构化的采食量趋势与异常提醒，为精准饲喂管理和饲料成本控制提供客观的视觉计量数据。

### 2. 🛠️ 能力范围

| 序号 | 具体能力 |
|---:|---|
| 1 | 食槽区域检测与关键测量位定位 |
| 2 | 食槽内饲料剩余量视觉估算（面积/高度/体积比） |
| 3 | 相邻时段剩余量变化差分计算 |
| 4 | 单餐/单时段消耗量估算 |
| 5 | 每日总采食量估算 |
| 6 | 采食量时序趋势与节律输出 |
| 7 | 与历史基线对比及偏差等级判定 |
| 8 | 采食量异常提醒（骤降 / 骤升 / 长期偏低） |

### 3. ⚡ 触发条件

| 触发类型 | 触发规则 |
|---|---|
| ✅ 默认触发 | 当用户提供食槽区域固定摄像头视频 URL 或文件需要采食量估算时，默认触发本技能进行采食量估算 |
| 🔎 明确分析意图 | 当用户明确提及采食量、日采食量、饲料剩余量、精准饲喂、饲料成本、采食异常、采食趋势等关键词，并且上传了图片或视频文件 |
| 📚 历史报告查询 | 当用户提及以下关键词时，**自动触发历史报告查询功能**：查看历史采食量报告、历史采食量估算报告、采食量报告清单、查询畜禽采食量记录、显示所有采食量估算报告 |

### 4. 🤖 自动行为

| 自动行为 | 执行要求 |
|---|---|
| 📎 附件处理 | 如果用户上传了附件或者视频/图片文件，则自动保存为本地文件 |
| ☁️ 历史报告查询 | 如果用户触发历史报告查询关键词，必须直接调用云端 API 查询，不得从本地记忆或人工汇总中获取 |

#### ⚠️ 强制数据获取规则（次高优先级）

> **橙色强约束：** 历史报告清单只允许从云端接口读取，不允许从本地记录、长期记忆或人工汇总中提取。

必须执行：

```bash

```

## 📷 采集要求 | Capture Requirements

| 序号 | 说明 |
|---:|---|
| 1 | 固定摄像头正对食槽（俯视或斜俯视），拍摄角度稳定，避免大幅位移或频繁调整 |
| 2 | 画面中食槽全景可见，槽底与料面之间高度差清晰可辨，便于估算剩余量 |
| 3 | 光照条件稳定，白天充足自然光或稳定人工光源，避免强逆光和大面积过曝/欠曝 |
| 4 | 视频建议 30 秒~10 分钟连续拍摄，覆盖典型饲喂时段，帧率不低于 10fps |
| 5 | 支持格式：jpg/png/jpeg 图片，及 mp4/avi/mov 视频；单文件不超过 10MB |
| 6 | 尽量减少人员补料、清扫等大面积遮挡时段，或将其从关键分析片段中剔除 |
| 7 | 建议保持食槽形状/规格与历史采集一致，以获得更稳定的采食量趋势对比 |

| 场景 | 系统行为 |
|---|---|
| 上游系统有内部身份参数 | 由脚本静默接收并使用 |

| 对用户输出 | 只展示分析进度、分析结果和报告链接，不展示内部身份值 |
