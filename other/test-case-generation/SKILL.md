# 测试用例自动生成Skill

## 适用场景
功能测试环节,基于 PRD/AC 生成全量用例,保证验收标准全覆盖。

## 执行步骤
1. 解析 AC:每条验收标准展开为用例雏形。
2. 补四类场景:正常路径 / 边界值 / 异常与错误 / 权限与状态。
3. 建覆盖矩阵:AC ↔ 用例双向映射,确保每条 AC 至少一条用例。
4. 定优先级:P0 核心链路必测 / P1 常规功能 / P2 边缘场景。
5. 输出用例集(可转自动化脚本时附脚本建议)。

## 用例编写规范
- 字段:编号 / 关联 AC / 前置条件 / 步骤 / 输入数据 / 预期结果 / 优先级。
- 步骤可执行:精确到操作与输入,禁止「正常操作一下」。
- 预期结果可判定:具体到文案/状态/数据,禁止「表现正常」。
- 边界值:最小值/最大值/临界±1/空值/超长/特殊字符。
- 用例间独立:不依赖执行顺序。

```
|---|---|---|
```

```

## 覆盖矩阵(AC 全覆盖确认)
```

- [ ] AC 覆盖率 100%(矩阵核对)
- [ ] 四类场景齐备

- [ ] 用例相互独立
