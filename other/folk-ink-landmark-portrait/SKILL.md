# Folk Ink Landmark Portrait

## Delivery and mode selection

- Use only for photos with clear architecture or a human-made landmark. If none is recognizable, do not invent one; explain that the image is unsuitable.
- Produce one standalone 3:4 vertical poster per source image. Never combine photos.
- Offer two modes when the user has not already chosen:
  1. **Split comparison** — real source photo above, folk ink portrait below.
  2. **Full canvas** — the whole poster becomes the folk ink portrait.
- Use one mode for all uploaded photos unless the user maps modes per image.
- Read only the selected mode guide: [split-comparison.md](references/split-comparison.md) or [full-canvas.md](references/full-canvas.md).
- Return a ready-to-use prompt only when explicitly requested; otherwise use the available image generation or editing capability.

## Shared visual rules

Preserve landmark identity, count, viewpoint, height-width proportion, perspective, and defining relationships among roof, dome, tower, opening, steps, columns, sculpture, entrance, base, bridge, wall, or shoreline. Reduce nonessential tourists, vehicles, signage, repeated windows, masonry seams, ornament, dense plants, and photo noise only in the illustrated region. Never remove defining structure or add regional symbols absent from the source.

On matte warm-white paper, use heavy slightly hesitant black brush or marker lines: variable weight, local retracing, occasional breaks, small ink blocks, and a few open contours. Structure may feel handmade but must remain accurate. Add only 2–3 signature colors extracted from the source as matte gouache blocks with visible brush marks, slight overrun, misregistration, gaps, and exposed paper.

Keep generous continuous paper white. Before rendering, lock readable text from source facts only: a 1–3-word English title, STUDY NO. XX or LANDMARK NOTE, and a 5–10-word observation. If the place is unknown, use a truthful scene theme; never guess a name, date, or coordinates.

## Avoid

Fixed regional templates, invented local symbols, calligraphy or fake characters, copied architecture, detailed technical pen drawing, automatic photo outlines, vectors, closed digital fills, transparent watercolor, halftones, full backgrounds, excessive detail, unreadable text, signatures, handles, logos, QR codes, URLs, and watermarks.
