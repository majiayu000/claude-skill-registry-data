# Picvero · 商品上架文案

读取 [共用约定](references/workflow.md) 和 [文案与详情](references/listing.md)。

该能力可以只有文字或参数资料，不把图片或生图工具设为前置条件。用户要标题时直接给标题，做详情页时才安排模块。

先梳理事实来源与未知项，再写目标语言的内容。商品名、参数、包含物在文字与图片中保持一致；不补造材质、认证、销量、用户评价、折扣或功效。

详情 HTML 仅引用用户提供或已完成的本地图片，按商品全貌、使用、特点、细节与规格等实际需要编排。输出预览文件和可复制文案，说明它是供编辑和适配的草稿。

需要新的商品位图时使用 picvero-image 或 picvero-suite；未安装子技能时使用本技能内附的 [原生图片说明](references/native-image.md)。不自动发布或修改店铺。
