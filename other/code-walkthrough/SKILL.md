# Code Walkthrough

Use the business scenario specified by the user, draw how it moves from the entry point through key modules to where the data ends up, and use one set of example values to show the API request, response, and data before and after. Follow the actual call order, plug those same values into key expressions and branch conditions, explain in plain language what each calculates or why the code takes that branch, and point to the variable, log entry, or field that helps verify the result and locate problems.
