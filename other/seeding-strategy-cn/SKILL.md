# 种草策略（人群资产视角）

国内种草已从"铺量曝光"进化为"人群资产经营"：可度量（A3/TI 人群增量）、可反漏斗（先核心后泛化）、可联动（种草→搜索→转化）。

## 输入

产品与价格带、品类竞争格局、目标人群假设、预算与周期、现有阵地（店铺/账号/私域）、目标（新品冷启动/老品破圈/大促蓄水/品牌心智）。

## 核心模型（按平台选用）

- **小红书 AIPS**：A 认知→I 兴趣→TI 深度兴趣（种草核心层）→P 购买→S 分享；灵犀平台可看人群资产与流转。TI 人群规模与增速是种草有效性的关键中间指标。
- **人群反漏斗**：先打透核心人群（高相关高转化），验证内容模型后逐层扩到兴趣人群、泛人群；冷启动就通投=烧钱。
- **KFS**：K（达人/原生内容）→F（信息流放大已验证内容）→S（搜索广告+搜索卡位承接主动需求）。三者预算联动，不是三件事。
- **巨量云图 O-5A**：A1 了解→A2 吸引→A3 种草→A4 行动→A5 复购；A3 是种草蓄水核心，大促前看 A3 规模与流转率。
- **腾讯如翼 5R / 快手磁力方舟 5R**：R1–R5 人群分层，品牌客户看流转；GTR 等工具做预算分配参考。

## 策略设计流程

1. **定人群**：核心人群画像（场景×痛点×身份），用 icp-research-cn 深化；给出反漏斗三层人群定义。
2. **定内容模型**：核心人群的 3–5 个内容角度（痛点/场景/测评/对比/情绪），每个角度先小预算测（KOC+薯条/聚光小额），跑出互动与搜索信号再放大。
3. **定链路**：种草内容→搜索承接（笔记/商品卡/关键词买词）→转化阵地（店铺/小程序/私域）；每一跳有追踪（见 tracking-setup-cn）。
4. **定节奏与预算**：
   - 冷启动期（2–4 周）：KOC 铺量+内容测试，70% 内容/30% 投流；
   - 放大期：验证内容加信息流+搜索，达人腰部进场；
   - 收割期（大促/上新）：效果广告+达人带货+私域触达，种草预算降、收割预算升；
   - 大促蓄水提前 30–45 天（双11 从 9 月底开始蓄水）。
5. **定度量**：过程指标（TI/A3 人群增量、搜索指数、爆文率、CPE）+ 结果指标（成交/ROI/新客占比）；种草不背即时 ROI，但要背人群资产与搜索增量。

## 输出格式

```
## 种草策略（产品 / 周期 / 预算）
### 人群反漏斗三层定义
### 内容模型（角度×形式×平台×数量）
### KFS/平台联动方案与预算表（分阶段）
### 链路图与追踪方案
### 度量体系（过程/结果指标与目标值）
### 风险（合规/竞品/内容模型跑不出的止损线）
```

## 约束

- 人群模型名称与平台工具以当期官方为准（灵犀/云图/如翼功能迭代快）；不确定的功能注明"以平台后台为准"。
- 不承诺"种草必爆"；给内容模型失败的止损线与转向方案。
- 医疗/功效类目先过合规（ad-compliance-cn）再谈打法。
