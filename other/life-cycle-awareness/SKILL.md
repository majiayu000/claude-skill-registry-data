# life-cycle-awareness

## When to Use

当意识到自己处于迷茫、例行公事或心流等不同生活状态，并希望主动管理而非被动承受时description

## Core Logic

# 执行步骤

1.  **识别当前阶段**
    *   **输入**：对自身当前情绪、能量水平和注意力的主观感知。
    *   **操作**：将当前状态与以下三个典型阶段进行匹配：
        *   **迷茫期**：感到方向不清、动力不足、注意力分散，常伴有焦虑或不安。
        *   **例行期**：按部就班地处理日常事务，情绪平稳但缺乏激情，处于“自动驾驶”状态。
        *   **心流期**：高度专注、充满能量和创造力，沉浸于有挑战性的构建性任务中。
    *   **判断标准**：能明确地将当前主要状态归入上述某一阶段。
    *   **输出**：当前所处阶段的标签（迷茫期/例行期/心流期）。

2.  **接纳与定性**
    *   **输入**：步骤1输出的阶段标签。
    *   **操作**：
        *   **IF** 当前为“迷茫期”：承认其破坏性，但将其重新定义为“积蓄能量和寻求启发的必要过程”，而非纯粹的失败或停滞。采取“观察而不对抗”的态度。
        *   **IF** 当前为“例行期”：承认其稳定价值，但警惕可能导致的思维僵化或机会错失。
        *   **IF** 当前为“心流期”：充分投入并享受，同时记录促成此状态的条件（如任务类型、环境等）。
    *   **判断标准**：对当前阶段产生中性或积极的认知重构，减少因抗拒该阶段而产生的内耗。
    *   **输出**：对当前阶段的接纳态度及定性认知。

3.  **执行阶段适配行动**
    *   **输入**：步骤2输出的接纳态度及定性认知。
    *   **操作**：
        *   **IF** 处于“迷茫期”：
            1.  降低对“高效产出”的期望。
            2.  进行低压力探索：广泛阅读、与人交谈、尝试新体验，目标是“寻找蜡烛”（即灵感、兴趣点或新方向线索），而非立即找到出路。
            3.  记录任何微小的启发或兴趣点。
        *   **IF** 处于“例行期”：
            1.  利用稳定的节奏完成必要的维护性任务（如行政、健康管理）。
            2.  安排小剂量的新刺激或学习，以防止思维固化（如学习一项新技能的基础知识）。
            3.  复盘“心流期”的成果，进行优化和系统化。
        *   **IF** 处于“心流期”：
            1.  优先保护大块不间断的时间，专注于核心的构建性任务。
            2.  明确任务边界，避免过度扩张导致精力分散。
            3.  在能量高峰处理最具挑战性的部分。
    *   **判断标准**：所采取的行动与当前阶段特性相匹配，且执行时心理阻力较小。
    *   **输出**：一套正在执行的、与阶段适配的具体行动。

4.  **监测转换信号**
    *   **输入**：日常的自我觉察和步骤3的行动反馈。
    *   **操作**：持续关注情绪、动力和注意力的变化，识别阶段转换的早期信号：
        *   **迷茫期 → 其他期**：出现明确的好奇点、恢复少量行动能量、偶然发现一个想深入探索的方向。
        *   **例行期 → 心流期**：对某项任务产生强烈兴趣，愿意主动投入更多时间，进入专注状态。
        *   **心流期 → 例行/迷茫期**：感到倦怠、任务挑战性下降变为重复、或项目告一段落后的空虚感。
    *   **判断标准**：能够感知到自身状态正在发生变化的趋势。
    *   **输出**：对潜在阶段转换的预警。

# 输出格式要求
以结构化摘要形式向用户反馈：
1.  **当前阶段判定**：[迷茫期/例行期/心流期]
2.  **阶段解读**：（基于模型对当前阶段的定性描述）
3.  **建议行动焦点**：（列出2-3条适配当前阶段的核心行动建议）
4.  **转换信号提示**：（提醒用户关注哪些迹象可能预示阶段变化）
