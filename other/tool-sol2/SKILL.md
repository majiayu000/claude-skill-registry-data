# sol2 C++/Lua 绑定库 技能卡

## 基本信息

- **中文名称**：sol2 C++/Lua 绑定库
- **来源仓库**：[ThePhD/sol2](https://github.com/ThePhD/sol2)
- **上游参考分支**：`develop`
- **参考提交（使用前核对）**：`c1f95a773c6f8f4fde8ca3efe872e7286afe4444`
- **许可证线索**：MIT；文件：`源码\LICENSE.txt`

## 功能概览

1. 将 C++ 函数、类、属性、容器和回调暴露给 Lua
2. 管理 Lua state、栈、错误和生命周期，支持单头文件集成
3. 适合把策略脚本与 C++ 宿主 API 连接起来

## 适用范围

- 用于 C++ 游戏工具/宿主的 Lua 策略、配置和热更新脚本桥接。

## 不能替代的边界

- 不包含 Lua VM 本体、不提供 Unity/C# 绑定、IL2CPP、内存读写、Hook、设备控制或业务成功证明；线程与 state 归属需由宿主负责。

## 输入与输出合同

```text
输入：Lua/LuaJIT 运行时、C++ 类型/函数注册、脚本文件、state 线程和异常策略。
输出：Lua 返回值、C++ 回调事件、绑定错误、异常和脚本日志。
失败：Lua ABI/版本不兼容、类型转换失败、state 跨线程或异常未捕获时隔离脚本并回滚。
后置：输出必须绑定项目、目标版本、平台/ABI（如适用）、时间戳和证据路径。
```

## 接入原则

1. 核对实际源码版本与说明中的参考提交后，先做最小、可撤销、可回放的接入。
2. 任何地址、线程、设备、模型、资源或协议输入都必须记录来源、版本和后置状态。
3. 工具输出是候选或观测，必须与项目专项规则、状态机和真实成功证据交叉验证。
4. 失败时保留原始错误和现场证据，不把命令退出码、识别命中或 Hook 安装当作业务成功。
5. 与 Luau/xLua 是不同脚本路线；sol2 不等于 Unity/C# Lua 接入。

## 与 Codex 项目路由的边界

- `l-gameassist`：负责游戏目标、进程/设备连接和现场任务编排；本技能只提供本卡标注的工具能力，不能扩展为未登记的内存、Hook、协议或输入能力。
- `l-reverse`：负责逆向/静态或运行时证据路由；本技能的输出必须按目标版本、模块、ABI 和现场回读复核，不能把候选分析直接当作成功结论。
- `l-dev`：负责构建、依赖、配置、部署、回滚和服务维护；本技能不替代发布门禁，未完成依赖、许可证、异常恢复和回滚检查时不得发布。
