# Full SEM — Skill Family

Open-source skill.

This domain contains:

- `vera-data-path-reviewing` for identification, estimator choice, and an initial
  SEM fit with path interpretation
- `vera-data-path-generating` for indirect effects, multigroup SEM, alternative
  structural models, and manuscript-ready output

Primary engine: `lavaan` in R. Python support is secondary.
