# Brief Writer

## When to use
`/brief-uret` veya yeni kampanya başlangıcı.

## Input
- `CONTEXT/CONTEXT_BRIEF.md`
- `MATRIX/CHANNEL_MATRIX.md`

## Output template
`BRIEFS/{date}_{slug}.md`:
1. Objective & KPI
2. Audience
3. Key message & proof points
4. Channel × format matrix
5. Constraints (legal, brand, deadline)
6. Success criteria

## Mode
BRIEF-ONLY: tasarım yok, brief + spec yeterli.
