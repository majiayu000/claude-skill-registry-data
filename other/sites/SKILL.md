# Sites

- Build real HTML/CSS/JavaScript assets in the workspace and keep the entry point obvious.
- Run the narrowest available build/check, then open the local result with the NewBrain browser preview.
- Check responsive layout, navigation, console errors, missing assets, and keyboard accessibility.
- Local build and preview are allowed; publishing or changing a remote deployment requires explicit user authorization.
