# life-as-game-design

## When to Use

当需要将个人目标或生活挑战转化为结构化、可执行的游戏化系统时description

## Core Logic

# 执行步骤

1.  **定义游戏视角**
    *   **输入**：当前面临的特定情境或挑战（例如：公开演讲、社交焦虑、技能学习）。
    *   **操作**：识别并写下对该情境的默认、消极的内心叙事（如“我会被嘲笑”、“我做不到”）。然后，主动将视角切换到“游戏设计师”或“玩家”视角，问自己：“在这个‘游戏’中，最坏的结果是什么？这个结果在更大的时间尺度或空间尺度上（如一周后、在陌生人群中）真的重要吗？”
    *   **判断标准**：能够清晰陈述默认叙事，并能提出一个更宏观、更具建设性的替代视角，将挑战视为“游戏关卡”而非“个人威胁”。
    *   **输出**：一个经过重构的、游戏化的情境定义（例如：“这是一个提升‘社交勇气’技能的游戏关卡，失败只是损失一点‘面子’金币，但能获得‘经验值’”）。

2.  **创建玩家角色**
    *   **输入**：步骤1中定义的游戏化情境。
    *   **操作**：在纸上或数字文档中，描述你希望在这个“游戏”中扮演的“满级角色”。具体定义：
        *   **角色特质**：该角色具备哪些核心技能和性格特质？（例如：冷静、表达清晰、学习速度快）
        *   **游戏内资源**：该角色能积累多少“金币”（可象征财富、影响力、资源）？
        *   **终极形态**：这个角色在游戏结束时（达成目标后）是什么状态？
    *   **判断标准**：角色描述具体、正面，且与步骤1中的游戏情境直接相关。特质和资源是可想象和可追求的。
    *   **输出**：一份清晰的“玩家角色档案”，包含目标特质、技能和终极状态。

3.  **编写游戏剧本**
    *   **输入**：步骤2创建的“玩家角色档案”。
    *   **操作**：将达成“满级角色”的过程故事化。问自己：
        *   **当前章节**：我现在处于这个角色成长故事的哪个阶段？（例如：“新手教程期”、“第一个Boss战前”）
        *   **核心冲突**：我当前需要克服的主要“阻力”或“反派”是什么？（可能是内在的恐惧、外部的技能短板）
        *   **故事主题**：我是为了“自己获胜”而玩，还是为了“帮助团队/他人获胜”而玩？这决定了游戏的深层意义。
    *   **判断标准**：能够用故事章节、冲突、主题来框架化当前的成长过程，使努力具有叙事性和意义感。
    *   **输出**：一个简明的个人成长故事大纲，包含阶段、挑战和意义。

4.  **设定并执行游戏规则**
    *   **输入**：步骤3编写的“游戏剧本”。
    *   **操作**：将故事转化为可操作的游戏机制：
        *   **学习规则**：明确要掌握的核心规则、机制或原则是什么？（例如：演讲的框架、社交的开场白公式）
        *   **设定目标层级**：建立清晰的短期目标（小任务）、中期目标（关卡Boss）、长期目标（故事线结局）。
        *   **定义经验值（XP）**：明确什么行为可以积累“经验值”（例如：每次练习、每次尝试）。
        *   **执行与迭代**：开始行动，专注于内在目标层级，通过行动获取“XP”，并强化步骤2中定义的角色特质。
    *   **判断标准**：目标被分解为可执行、可度量的任务。“经验值”系统与核心行动挂钩。行动过程有意识地指向角色成长。
    *   **输出**：一个正在运行的游戏化行动循环，包含明确的目标、规则和成长反馈。

# 输出格式要求
向用户呈现一个为其特定情境（由用户提供或步骤1识别）量身定制的“游戏化方案”，包含：
1.  **游戏名称**：[用户情境]挑战赛
2.  **玩家视角**：用一句话陈述重构后的游戏视角。
3.  **我的角色**：列出2-3个要培养的核心特质和终极形态。
4.  **当前章节**：描述当前所处的故事阶段和要击败的“Boss”。
5.  **本关卡任务**：列出接下来1-3个可执行的短期目标（任务）及对应的“经验值”。
