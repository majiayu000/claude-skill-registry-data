# 医学论文语言自然化

## 伦理与职责边界

语言特征不能可靠证明文本由 AI 或人类创作。本 Skill 只处理可观察的写作问题，不承诺降低任何检测分数，
不帮助隐瞒工具使用，也不把“看起来像 AI”写进学术诚信结论。

如用户要求规避检测、删除披露或伪装作者身份，拒绝该部分；仍可提供普通的清晰度与风格编辑。

## 适用范围

主要处理医学论文正文、摘要、投稿信和审稿回复。普通非医学内容可使用通用写作编辑能力；不要把随意口语、
故意瑕疵或个人观点强行注入医学论文。

## 受保护内容

编辑前锁定：

- 所有数字、单位、样本量、事件数和统计量；
- 引用编号、citekey、图表编号与来源关系；
- 医学术语、药物名、剂量、基因/蛋白和量表；
- 研究设计、时间、纳排标准和结局定义；
- 伦理、注册、利益冲突、资助、作者贡献和 AI 使用披露；
- 因果、否定、条件和不确定性边界。

任何受保护内容需要改变时，暂停该处语言编辑，先取得相应来源并请求作者确认，实质修改转为 `dyz-med-revision`。
用户明确要求科学修订也不等于已有证据或已确认具体改法；缺来源或确认时，只列出稿外问题，不自行改变科学判断。

## 工作流

### 1. 识别具体文风问题

只标记实际出现的问题，例如：

- 连续使用空泛连接词；
- 多次重复“结果表明”“值得注意的是”等包装句；
- 句式和段落节奏过度一致；
- 机械堆叠三点式列表；
- 过度宣传、空洞强调或泛泛结论；
- 同一句叠加多重模糊限定；
- 术语不一致、主语不清或图表作主语反复出现；
- 观察性结果出现因果或优效语言（列为稿外科学问题，不在语言编辑中自行修正推断类型）。

不要因为单个常用词、破折号、被动语态或格式整齐就判定文本“像 AI”。

### 2. 确认作者语气

若用户提供其既有写作样本，提取可复用的句长、用词和段落习惯；没有样本时采用清晰、克制的医学学术语气，
不虚构个人经历或观点。

### 3. 做最小必要改写

- 删除不承载信息的包装；
- 把抽象评价换成原文已有的具体事实；
- 合并重复句，拆分过长句；
- 调整连接词和句式，但保留逻辑关系；
- 保留原文的科学强度、推断类型和不确定性边界；只删除不改变这些含义的重复限定；
- 原文同时出现强断言与可能性措辞等科学强度冲突时，保留未决主张并在稿外作者提示中明确标记，取得来源和确认前
  不擅自升级、降级或改为关联性结论；
- 输入片段未写效应量、时间或不确定性，只能说明片段未提供；提示放在稿外，不写成研究本身的局限，也不新增研究建议；
- 不故意制造语法错误、随机标点或“自然瑕疵”。

### 4. 逐项回归检查

比较原文与修订稿：

- 受保护内容是否完全一致；
- 每个原始论点是否仍存在；
- 是否新增数据、机制、限制、作者态度或来源；
- 是否误把语言编辑变成科学内容修订；
- 披露和声明是否保留。

## 可选机械对照

有编辑前后文件时，可按[保护内容检查接口](references/protected-content-cli.md)运行本技能携带的 compare_protected.py。
语言未变化时保护短语的 source/target 可相同；计数通过不证明科学含义未变，仍需语义复核。

## 输出

默认交付：

1. 修订稿；
2. 精简变更说明；
3. 受保护内容核对结果；
4. 需要作者决定的实质性问题，独立标为“稿外作者提示”，不得混入修订稿或作为新研究事实。

用户只要求成稿时可省略逐句分析，但仍需完成内部核对；未解决的科学强度冲突仍须在稿外明确提示，不能把语言
自然化结果当作科学核查已通过。

## 验收标准

- 文本更具体、紧凑且保持原作者语气；
- 所有事实、数字、引用和声明保持；
- 没有新增“更像人类”的虚构细节；
- 没有声称通过 AI 检测或判断作者身份；
- 实质性问题与语言问题被清楚分开。
