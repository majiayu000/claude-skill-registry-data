# Investment Style Router Skill

## Purpose

Map target to Graham, Buffett/Munger, Fisher, Klarman, Greenblatt, Marks, Greenwald, Mauboussin, or Damodaran frameworks.

## Inputs

- Target
- Market
- Industry
- Available data
- User requested depth
- Prior assumptions, if any

## Outputs

- Structured analysis
- Assumptions
- Missing data
- Confidence level
- Next required action

## Rules

- State assumptions explicitly.
- Flag missing or low-confidence data.
- Prefer conservative assumptions.
- Keep output auditable.
