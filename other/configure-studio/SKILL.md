---
name: configure-studio
description: Configure studio settings or recover Admin access.
---

1. Run `yarn studio status --json` and `yarn studio whoami --json`. If unregistered, use [setup-contributor](../setup-contributor/SKILL.md) in registration-only mode.
2. Read the contributors module README and [Configuration](../../context/config.md). Inspect `yarn studio` for current configure options. Preview the requested settings, then apply with --yes within the person's authorized scope. Preserve existing roles and unrelated settings.
3. For missing Admin access use the documented recovery mode. For a new Vue system reach the enabled systems module's setup-design-system skill. For team context or skills use [maintain-context](../maintain-context/SKILL.md).
4. Sync guidance and restart through the recorded dev-server command when required. Verify status and an affected prototype, leaving the app available. Report changed settings and checks.
