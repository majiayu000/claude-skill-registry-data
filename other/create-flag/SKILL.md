## What this skill does

- Translates place, organization or fictional faction values into simple flag geometry and colors.
- Separates the flat flag design from optional fabric presentation and tests reversibility and distance.

## How to use

Provide entity, meaning, symbolism, color constraints, proportions and flat or fabric presentation.

#### Example

```text
Design one 2:3 flag for fictional Port Meridian using navy, white and coral; a simple lighthouse-path symbol; flat front view.
```

## Workflow

1. Define symbolism, field ratio, color meanings and prohibited symbols.
2. Limit geometry and palette; decide reverse behavior.
3. Generate one flat orthographic result directly with GPT Image 2 Medium/2K; never treat `ai-flag-generator` as a model.
4. Verify distance readability, contrast, edge simplicity, originality and no accidental national-symbol copying.

## User-facing output

- Media type: One flag design
- Default quantity: 1
- Content per image: One original flag in a clearly reviewable presentation
- Default layout: User-requested or source-preserving format
- Model policy: GPT Image 2 Medium/2K for controlled flat geometry and one selected output
- Downstream use: Organizations, fictional worlds and civic concepts
