# business-feedback-loop

## When to Use

当在线业务的一个环节（如产品、内容）运行后，需要系统性地收集反馈并驱动整体优化时。description

## Core Logic

# 执行步骤

1.  **定义反馈指标**
    *   **输入**：业务当前阶段的核心目标（如验证需求、提升转化、增加复购）。
    *   **操作**：为“三点模型”的每个环节选择1-2个关键量化指标（如社交媒体互动率、邮件列表增长率、产品转化率、用户满意度评分）。
    *   **判断标准**：指标明确、可测量、且与核心目标直接相关。

2.  **收集环节数据**
    *   **输入**：定义好的反馈指标。
    *   **操作**：使用分析工具（平台后台、邮件营销软件、支付网关、调查问卷）收集步骤1中定义指标的实际数据。
    *   **判断标准**：获得了反映各环节表现的真实、原始数据集。

3.  **分析与归因**
    *   **输入**：各环节的原始数据。
    *   **操作**：对比数据与预期目标，分析表现优劣。尝试建立环节间的关联（如：某类社交媒体内容是否带来了更高的邮件订阅转化？首次购买用户主要来自哪类邮件主题？）。
    *   **判断标准**：识别出至少一个表现超出预期或低于预期的关键环节，并对其原因有初步假设。

4.  **执行优化实验**
    *   **输入**：分析得出的关键环节及优化假设。
    *   **操作**：在表现不佳或希望提升的环节，设计一个微小的、可逆的变更（A/B测试），例如更改社交媒体内容形式、调整邮件标题、优化产品着陆页描述。
    *   **判断标准**：优化实验被明确设计并启动，有清晰的对比组和测量方法。

5.  **闭环与迭代**
    *   **输入**：优化实验的结果数据。
    *   **操作**：根据实验数据，决定是否将优化方案固化到业务流程中。无论成功与否，将本次循环的洞察更新到对业务和受众的理解中。
    *   **判断标准**：业务操作流程或策略文档根据反馈得到了更新，并计划启动下一个反馈循环。
    *   **IF** 实验成功，指标提升。
        *   **THEN** 将变更标准化，并回到步骤1，为下一阶段目标定义新指标。
    *   **ELSE** (实验未达预期)
        *   **THEN** 记录学习，放弃或调整假设，回到步骤3或步骤4，设计新的实验。

# 输出格式要求

以实验报告摘要形式呈现本次反馈循环的洞察与决策：
1.  **循环目标**：[本次反馈循环旨在解决的核心问题或验证的假设]。
2.  **关键数据**：
    *   社交媒体：[指标] 从 [旧值] 变为 [新值]。
    *   邮件列表：[指标] 从 [旧值] 变为 [新值]。
    *   产品：[指标] 从 [旧值] 变为 [新值]。
3.  **核心洞察**：数据表明，[环节A] 对 [环节B] 的影响最为显著/薄弱，原因是 [假设]。
4.  **执行决策**：基于上述洞察，决定 [采纳/放弃] 在 [具体环节] 进行的 [具体变更]。
5.  **下一循环重点**：下一个反馈循环将重点关注 [下一阶段待优化的环节或指标]。
