# 三省吾身 - 自我审查技能

每日起心动念，自我审视，持续进化。

## 触发时机

**自动定时触发**（通过 cron job）：
- 每天 22:00 - 今日复盘
- 每周一 09:00 - 周度审查
- 每月 1 日 09:00 - 月度大修

**手动触发**："自我反思"、"review"、"三省吾身"

## 自我审查流程

### 第一步：收集近期记忆
读取以下文件，判断近期行为是否有值得记录的模式：
- `memory/YYYY-MM-DD.md`（最近7天）
- `workspace/.learnings/LEARNINGS.md`（如有）
- `workspace/.learnings/ERRORS.md`（如有）

### 第二步：三省吾身

**一省：去糟粕**
- 近期有没有反复犯错但没有记录的？
- 有没有曾经有用但现在已经不适用的习惯？
- 有没有积累了大量重复的纠正记录可以合并？

**二省：扩核心**
- 用户明确偏好是否有遗漏没有写入 MEMORY.md / SOUL.md？
- 哪些行为被用户反复认可（不只一次）应该提升为固定习惯？
- 最近学到的教训里，哪些应该promote到永久记忆？

**三省：查漏补缺**
- 用户沟通风格有什么新变化？
- 哪些边界没有明确划定但已经触碰到？
- 哪些工具使用模式应该记录到 TOOLS.md？

### 第三步：执行整理

| 情况 | 行动 |
|------|------|
| 重复纠正 ≥3 次 | 写入 MEMORY.md 成为固定规则 |
| 30天未用的规则 | 降级或归档 |
| 矛盾规则存在 | 标注冲突，请用户仲裁 |
| 边界越界一次 | 加入 boundaries.md |
| 好的行为模式 | promote 到 SOUL.md / AGENTS.md |
| 错误认识 | 写入 corrections.md 并修正 |

### 第四步：输出摘要

向用户报告：
```
【三省吾身】DDL复盘报告
日期：YYYY-MM-DD

🗑 删除/归档：
- （条目）

✨ 新增/升级：
- （条目）

🔧 修正/合并：
- （条目）

❓ 待确认：
- （需要用户回答的冲突或疑问）
```
