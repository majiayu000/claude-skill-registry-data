# Picvero · 商品单图修改

需要更漂亮、更高级或更有品牌感时，读取 [电商视觉设计](references/visual-direction.md)，明确布景、光线、配色与排版后执行。

读取 [共用约定](references/workflow.md) 和 [内置图片工具](references/native-image.md)。

1. 查看目标图和商品原图，辨明哪些是商品、场景或风格参考。原图缺失时不把风格图里的商品当作本商品。
2. 按用户指定范围改变背景、留白、光线、文字或拍摄视角；要求换角度、重新摆放时读取 [多角度与多图参考](references/multi-view.md)，只换底或翻译时不改变机位。将标签、部件、图案、数量等具体不变项写入制作要求。
3. 用户要求透明底时使用内置工具，并实际检查透明像素；输出不符合时如实反馈。
4. 调用内置工具生成独立图片，取得真实输出，保留原图和旧版。
5. 按 [审核](references/review.md) 同时查看原图与结果。默认只生成一次，快速看一遍；没大问题直接交付，有大问题简短指出，不自动再生成。只有用户明确要求修改时才按范围处理。无参考依据造成的问题不要靠重复生成猜出来。
6. 保存文件的任务用 [运行记录](references/runtime.md) 建任务、记录图位与版本。临时预览可直接展示工具结果。

不能用变形、补造纹理、重画品牌等方式换取“高级感”。设计概念与真实上架图的事实边界分开说明。
