# A/B 测试设计与分析

国内投放 A/B 的特殊性：平台分发不均（赢家通吃）、oCPM 模型干扰、素材对比常被"不同计划不同模型"污染。先判断数据能不能比，再算显著性。

## 数据契约

两组（或多组）的：展示/点击/转化数、消耗、测试起止时间、是否同计划同定向同时段。落地页测试另要：UV、转化事件口径。笔记标题测试：阅读/互动/点击率。

## 可比性检查（先于统计）

- 同时段同定向同预算？不同计划各自跑模型 → 差异可能来自模型而非素材，结论降级为"方向性参考"。
- 平台自动优选（程序化创意/自动素材优选）会主动偏心 → 曝光量悬殊时不能直接比 CTR 以外的指标。
- 测试期是否覆盖完整周期（至少含周末；国内节点流量结构差异大）。
- 转化数太少：单组转化 <20 时任何结论都不稳，先延长或放大流量。

## 统计方法

1. 比率指标（CTR/CVR）：双比例 z 检验；给出 p 值与 95% 置信区间。样本小（任一组期望频数 <5）用 Fisher 精确检验思路说明"无法下结论"。
2. 样本量预估：给定基线率 p、最小可检测提升（相对 10–20%）、α=0.05、power=0.8，反推每组所需展示/点击/转化数，并换算成"按当前日流量要跑几天"。
3. 成本/ROI 类：方差大，优先看转化量是否达标，再比成本；提醒"成本差异 <15% 且样本小"多为噪声。
4. 多重比较：同时比 N 条素材/N 个标题时，提高显著门槛或声明" exploratory"，避免挑出来的赢家是运气。
5. 禁止偷看即停：达到预定样本量前不因"暂时领先"提前宣布；说明提前停止的假阳性风险。

## 输出格式

```
## A/B 测试分析
**可比性**：通过/受限（原因）
| 组 | 展示 | 点击 | CTR | 转化 | CVR | 成本 |
**检验**：CTR 差异 X pp，p=__，95% CI [__]；CVR 同
**结论**：显著胜出 / 方向性参考 / 样本不足
**下一步**：放量验证 / 延长 N 天 / 重新设计（控制变量建议）
```

## 约束

- 计算过程可复现（给出公式与代入值）；能用 Python 就算，不手算近似。
- "不显著"≠"没差异"；明确说检测力不足时的含义。
- 不鼓励用统计显著性包装本来就可比性不足的数据。
