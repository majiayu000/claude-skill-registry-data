# query — 위키 기반 질의·분석 워크플로우

`wiki/` 전체를 종합해 질문에 답하거나 분석을 만든다.
세부 규칙은 항상 `wiki/CLAUDE.md`(위키 스키마)를 따른다.

## 단계

1. **index.md 읽기**: 먼저 `wiki/index.md`를 읽어 관련 페이지와 **각 소스의 정본/대체 표기**를 파악한다.
2. **관련 페이지 읽기**: `wiki/CLAUDE.md`의 **근거 우선순위**를 따른다 — `concepts/`·`entities/`(맥락 분리·상충 해명이 여기 있음) → `open-questions.md`(**필수**) → 필요 시 `sources/`.
   - 근거를 `sources/`로 한정하거나 `sources/`를 `concepts/`보다 우선하지 않는다.
   - `🔁` 표기된 폐기본은 현행 근거로 쓰지 않는다.
   - open-questions 상태는 **부정 매칭** — `해소됨`이 아닌 모든 항목은 미결.
3. **출력 형식 선택**: 질문 성격에 맞게 고른다.
   - 일반 분석 → 마크다운 본문
   - 항목 비교 → 비교표 (마크다운 테이블)
   - 발표용 → Marp 슬라이드 (frontmatter에 `marp: true`)
   - 데이터 시각화 → matplotlib 코드 블록
4. **답변 작성**: 종합해 출처 링크(`[[페이지명]]`)를 포함한 답변을 제공한다.
5. **저장 여부 판단**: 재사용 가치가 있는 분석·비교 결과는 `wiki/synthesis/[주제].md`에 저장하고, `overview.md` 갱신 필요 여부를 판단한다.
6. **log.md 추가**: 파일 끝에 `## [YYYY-MM-DD] query | [질문 요약]` 한 줄 기록.
7. **검사** (synthesis 페이지를 저장했을 때): `python3 wiki/script/lint.py` → 위반 0건 확인.
