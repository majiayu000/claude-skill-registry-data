# 국문 학술 문체 규범 (v2)

이 스킬은 사용자가 자신의 논문을 여러 차례 직접 교정하며 확립한 문체 규범이다. 목표는 사람이 쓴, 한 번 읽고 바로 이해되는, 담백한 국문 학술 문어다. 독자는 컴퓨터공학이나 소프트웨어공학을 전공한 국내 학회 논문지의 심사자와 대학원생이다. 이 독자가 사전 없이, 한자를 떠올리지 않고, 되읽지 않고 읽어 내려갈 수 있어야 한다.

규칙은 두 종류다. AI가 즐겨 쓰지만 사람은 잘 쓰지 않는 문장 패턴(1절, 3절, 4절)과, 국내 학회 논문에서 흔히 보는 어휘의 범위를 벗어난 말(2절)이다. 2절은 이 스킬의 이전 판이 놓쳤던 부분이다. 이전 판은 "한자어보다 우리말"을 기준으로 삼았는데, 그 결과 잘 쓰지 않는 한자어와 문학적인 고유어 동사가 한 글에 섞여 오히려 읽기 어려워졌다. 기준은 어원이 아니라 익숙함이다.

v2는 humanize-korean(im-not-ai 플러그인, 10대 분류 85개 AI 티 패턴) 가운데 학술 글에 맞는 규칙을 흡수했다. 흡수한 규칙에는 대괄호로 원래 패턴 ID를 붙였다(예: [C-11]). 학술 규범과 부딪치는 humanize-korean 규칙은 6절에서 끈다. 이 스킬이 기준이고, humanize-korean은 글을 고친 뒤의 점검과 수치 점검으로만 쓴다(적용 절차 7단계).

## 1. 문장의 결

클립 단정문을 쓰지 않는다. 주어를 뚝 잘라 단정하는 문장은 AI의 대표적 지문이다. 조사와 어미로 문장을 완결한다.

- 나쁨: "기여는 문제의 정리 그 자체다." 좋음: "본 논문의 기여는 다음과 같다."
- 나쁨: "실무는 두 문제 모두 고정 규칙으로 처리한다." 좋음: "업계에서는 두 문제를 모두 고정 규칙으로 다룬다."
- 나쁨: "문제 정리는 세 원칙을 따른다." 좋음: "문제를 정식화하는 과정에서는 다음 세 원칙을 따른다."

의문문을 명사화해 서술어로 쓰지 않는다. "X은 ~는가이다", "~는가 하는 문제" 꼴을 피하고 동사 서술로 푼다.

- 나쁨: "포함 기준은 그 값이 최적 행동을 바꾸는가이다." 좋음: "그 값이 최적 행동을 바꾸는지 여부에 따라 포함할지를 정한다."
- 나쁨: "어느 행동이 최적인가 하는 계산 문제가 된다." 좋음: "어느 행동이 최적인지를 계산하는 문제로 바뀐다."

산문체와 기사체를 쓰지 않는다. 수필이나 기사에서 쓰는 리듬은 논문에 어울리지 않는다. 짧은 단정을 던지고 부연하는 리듬(punch-then-elaborate), 문단을 경구로 닫는 마무리, "~뿐이다", "~일 뿐이다", "~하면 된다", "~는 셈이다" 같은 종결을 피한다. 대구로 문단을 닫는 것("B1은 채우고 G는 미룬다", "미루는 것은 지어내는 것의 반대편에 있는 선택이다")도 같은 부류다.

- 나쁨: "실행 시점에 남는 일은 조회뿐이다." 좋음: "실행 시점에는 조회만 남는다."
- 나쁨: "위험은 실측되어 있다. 결제 인가 하나가…" 좋음: "이 위험은 실측 사례로도 확인된다. 결제 인가 하나가…"
- 나쁨: "~시대가 열리면서", "되살린", "치솟는다" 좋음: "~사례가 늘고 있다", "활용하는", "급증한다"

"A가 아니라 B" 대조를 경구처럼 거듭 쓰지 않는다 [C-8]. "A가 아니라 B다", "~이지 ~이 아니다", "~것은 아니다"가 한 절에 두 번 넘게 나오면 한 번만 살리고 나머지는 직접 단언으로 바꾼다. 다만 측정 범위를 한정하는 방법론 문장("이 수는 차단 성능이 아니다", "실제 운영 거래의 발생률이 아니다")은 한정이 곧 내용이므로 그대로 둔다. 풀 때 한정의 강도를 낮추지 않는다("~이 아니다"를 "~로 읽을 수 없다"로 약하게 바꾸지 않는다).

번역투 피동을 쓰지 않는다 [A-8, A-9]. "~되었다", "~어지다", "~게 되다", "~쓰였다", 이중 피동("~되어진다"), "~에 의해" 피동은 행위 주체를 찾아 능동으로 바꾼다. 주체가 문장에 이미 있거나 복원할 수 있으면 반드시 능동으로 쓴다.

- 나쁨: "위협은 여러 연구에서 보고되었다." 좋음: "위협은 여러 연구가 이미 보고했다."
- 나쁨: "초기 정보는 관측 커널을 거쳐 신념으로 압축된다." 좋음: "관측 커널은 초기 정보를 신념으로 압축한다."
- 나쁨: "이 가정은 증명에 본질적으로 쓰였다." 좋음: "증명은 이 가정에 본질적으로 의존한다."
- 예외: 우리말 고유의 자동사(얽히다, 갈라지다, 뒤집히다)와 정착된 기술 표기("체인에 포함된 결제")는 그대로 둔다.

헤지의 강도를 바꾸지 않는다 [G-1, G-2, A-10]. 유보("~로 보인다", "~할 수 있다", "확인되지 않았다")를 단정으로 올리지 않는다. 같은 추측 종결이 되풀이되면 강도는 그대로 두고 종결 형태만 바꾼다. 이중 완곡("~할 가능성이 있을 수 있다")은 완곡 하나만 남긴다. 헤지가 걸린 피동을 능동으로 바꿀 때도 주장 강도를 높이지 않는다("찾지 못했다"는 되지만 "없다"는 안 된다). 부정이 낀 문장은 극성을 확인하고, 애매하면 원문을 둔다.

AI 강조 공식을 쓰지 않는다 [D-2, D-8, I-2, I-3]. "핵심은 ~다", "요점은 ~에 있다", "관건은 ~다", "문제는 ~다", "주목할 점은 ~는 것이다", "~하는 것은 X다" 같은 분열문과 리드 문장 공식, "시사하는 바가 크다", "매우 중요하다" 같은 의의 과장, 문장 끝의 "~다는 것이다", "~다는 뜻이다", 동사 3연 병렬 의인화("실수하고 지치며 응답하지 않는"), 메타 서술("주장하지 않는 것도 밝혀 둔다", "결과를 미리 말하면")을 피한다. 강조가 필요하면 내용 자체가 앞에 오게 문장을 재배치하고, 분열문은 주어와 서술어를 바로 잇는다.

- 나쁨: "핵심은 개선 폭이 체제에 의존하지 않는다는 점이다." 좋음: "특히 개선 폭은 체제에 거의 의존하지 않았다."
- 나쁨: "제약을 집행하는 지점은 검증자다." 좋음: "제약은 검증자가 집행한다."

결산어와 문두 접속어를 몰아 쓰지 않는다 [D-1, D-9, D-10, H-1]. "따라서", "이를 통해", "그러므로", "결국", "요약하면"이 한 글에 세 번 넘게 나오면 한두 번만 남긴다. 짧게 끊은 문장을 "그래서", "곧", "따라서"로 다시 잇는 구조가 되풀이되면 앞 문장과 연결어미("-므로", "-어서", "-고")로 합친다. 문장 끝의 "~하는 이유다" 도치는 순방향 서술로 바꾼다. 접속어를 전부 없애지는 않는다. 사람 글에도 있는 말이다.

연결어미 뒤에 쉼표를 찍지 않는다 [C-11]. "-고,", "-며,", "-지만,", "-면서,", "-어서," 뒤 쉼표는 뺀다. 고쳐 쓴 문장에서 이런 쉼표가 원문보다 늘면 실패로 본다. 3항 이상 명사 나열의 쉼표는 이 규칙과 무관하다(3절).

번역투 조사와 접미사를 남발하지 않는다 [A-1, A-3, A-5, A-6, A-11, A-19, F-4, F-5]. "~에 있어서"는 "~에서"로, "~에 대해"가 한 문단에 몰리면 목적격 조사로, "~와 관련하여"는 "~에"나 "~의"로 바꾼다. "~를 통해", "~에 기반하여", "~을 위해"가 한 문단에 거듭 나오면 "~로", "~해서", "~려고"로 나눈다. 이중 조사("~에서의", "~으로의", "~으로부터의")는 절로 푼다. "~적", "~성", "~화" 접미사가 사슬을 이루면("전략적 함의의 실천적 기반") 명사 병치나 풀어쓰기로 바꾼다.

명사 앞 수식을 세 겹 넘게 쌓지 않는다 [A-18]. 명사 앞에 관형절이나 관형구가 세 어절 넘게 쌓이면 문장을 나누거나 수식을 뒤로 뺀다. 정의된 용어가 얽혀 있어 풀면 뜻이 바뀌는 경우에는 어순만 조정한다.

같은 종결어미를 네 문장 넘게 잇지 않는다 [E-2]. "~이다. ~이다. ~이다. ~이다."가 이어지면 일부를 연결어미로 합치거나 서술어를 바꾼다. "~고 있다"는 단순 시제로 바꿀 수 있으면 바꾼다.

## 2. 어휘의 결

### 2.1 기준은 어원이 아니라 익숙함이다

한자어냐 고유어냐를 묻지 않는다. 국내 학회 논문지와 전공 교과서에서 그 뜻으로 흔히 쓰는 말인지를 묻는다. 두 방향 모두 실패한다.

- 잘 쓰지 않는 한자어와 조어: 한자를 떠올려야 뜻이 잡히거나(사영, 다종, 병리, 귀속, 관용, 거동), 외국어를 글자 그대로 옮겨 만든 말(열린 결, 결손 기록, 방출된 명세)은 독자를 멈추게 한다.
- 문학적인 고유어: 기술 명사에 일상 동사를 붙이면(값을 잰다, 조건과 견준다, 실패를 층에 돌린다, 대조군을 접었다) 산문처럼 읽히고 뜻이 넓어진다.

균형점은 구어도 기사체도 아닌, 국내 학회 논문의 통용 어휘로 쓴 담백한 학술 문어다.

### 2.2 잘 쓰지 않는 한자어와 조어를 통용어로

판정법은 다음과 같다. 그 말의 한자를 떠올려야 뜻이 잡히면 바꾼다. 정착된 수학과 전산 용어(유계, 포섭, 정식화, 건전성, 보존적 확장, 단조)는 예외이며, 첫 등장에서 원어를 병기한다.

| 쓰지 않는다 | 쓴다 |
|---|---|
| 사영 규칙 | 대응 규칙, 투영 규칙 |
| 다종 서명(many-sorted signature) | 첫 등장에 원어 병기 후 유지. 설명이 필요하면 "여러 종류의 값을 가지는 서명" |
| 부분 사상 | 부분 함수(partial function) |
| 정준화 | 정규화(canonicalization). 다른 정규화와 겹치면 "표준형 변환" |
| 속박된 생성, 속박 디코딩 | 제약 생성, 제약 디코딩(constrained decoding) |
| 방출된 명세, 미방출 | 생성된 명세, 출력된 명세, 미출력 |
| 결손, 결손 기록 | 누락, 누락 기록. 모델 밖 발화를 뜻하면 "모델 범위 밖 발화" |
| 잔여, 잔여 목록 | 미확정 항목, 미확정 목록 |
| 계기(instrument) | 진단 지표 |
| 병리 | 문제 유형, 결함 유형 |
| 귀속하다, 귀속된 실패 사유 | 원인을 분류하다, 분류된 실패 원인 |
| 형식의 관용 | 형식 차이의 허용 |
| 무질의 | 질의 없음, 질의 없이 |
| 거동 | 동작 |
| 열린 결(open texture) | 개방적 구조(open texture). 국내 법철학 문헌의 표기를 따른다 |
| 되묻기 | 확인 질의, 재질의 |
| 명료화 질문 | 명확화 질문(clarification question) |
| 동행하다, 나르다(명세가 거래와) | 함께 전달되다 |
| 선조(직접적인 선조) | 선행 연구 |
| 재료(방법의 재료) | 구성 요소 |
| 승부처 | 차이가 드러나는 지점 |
| 상기·하기·여히, 익일, 요망 | 위·아래·다음과 같이, 다음 날, 요청한다 |

기술 용어가 저자의 핵심 개념이라 바꿀 수 없으면(예: 접지 grounding) 첫 등장에서 정의하고 원어를 병기한 뒤 논문 전체에서 하나로 통일한다. 두 번째 등장부터는 병기하지 않는다 [B-1].

### 2.3 문학적인 고유어 동사를 통용 학술 동사로

판정법 둘을 함께 쓴다.

- 목적어 교체 판정. 그 동사에 서로 다른 종류의 목적어를 끼워 모두 자연스러우면 뜻이 넓은 동사다("넘긴다": 데이터를/업무를/권한을). 좁은 동사(전달한다/이관한다/위임한다)로 가른다.
- 주어 교체 판정. 주어를 사람이나 물건으로 바꿔 자연스러우면 전용된 비유다("점수가 흔들린다", "발화가 모델 밖으로 떨어진다", "선택이 유한한 공간 안에 갇힌다"). 비유가 아닌 서술로 바꾼다 [D-5, D-14].

| 쓰지 않는다 | 쓴다 |
|---|---|
| 잰다, 쟀다, 재고 | 측정한다, 측정했다 |
| 견준다 | 비교한다 |
| (실패를 층에) 돌린다 | (층별로) 분류한다 |
| (대조군을 하나로) 접었다 | 줄였다, 한정했다 |
| 잡아낸다(선호를) | 포착한다 |
| 흔들림, 흔들린다 | 변동, 불안정하다 |
| 표류 | 변동, 불일치 |
| 몫(결손의 몫, 관측 층의 몫) | 비율, 담당 범위 |
| 자리(빈자리, 그 자리) | 항목, 위치 |
| 짓는다(모델을), 지어낸다(값을) | 구축한다, 생성한다. 단 "지어낸 값"이 hallucination을 뜻하는 정의된 용어면 유지 |
| 낸다(점수를, 출력을) | 산출한다, 출력한다 |
| 내린다(속성으로) | 구체화한다 |
| 떨어진다(모델 밖으로) | 벗어난다 |
| 갇힌다 | 한정된다 |
| 바닥이다 | 매우 낮다 |
| 치르는 값 | 비용, 대가 |
| 쓰게 한다(명세를) | 작성하게 한다 |
| 적는다(값을, 절을) | 기록한다, 생성한다 |
| 이긴 상대 | 이미 우위를 확인한 조건 |
| 통한다(도메인에서) | 적용된다, 유효하다 |
| 무너진다(정확도가) | 크게 떨어진다 |

반대 방향도 유지한다. 뻣뻣한 격식체("직면한다", "수신자인", "~로 축소된다")는 통용어("겪는다", "받는", "~만 남는다")로, 구어("잰다", "내주는", "~짜리", "값을 하는지", "아깝지 않은지")는 문어("측정한다", "제공하는", "50달러", "타당한지", "이득인지")로 바꾼다. 광고성 영어 유행어(seamless, robust, leverage)는 우리말로 풀되, 표준 기술 용어(API, prompt, token)는 원어로 둔다 [B-2].

### 2.4 전문 용어의 표기 순서

외래 개념을 적을 때는 다음 순서로 고른다. 위 단계가 있으면 아래 단계로 내려가지 않는다.

1. 국내 학회, 교과서, TTA 용어사전에 정착한 번역어. 첫 등장에서 "번역어(원어)"로 병기한다.
2. 정착 번역어가 없으면 원어 음차("그라운딩") 또는 영문 그대로 쓴다. 음차와 영문 가운데 그 분야 국내 논문이 더 많이 쓰는 쪽을 고른다.
3. 조어는 마지막 수단이며, 반드시 첫 등장에서 정의와 원어를 함께 적는다.

식별자, 필드명, enum 값, API 이름은 번역하지 않고 영문 그대로 쓴다(`unit_price`, `Pending`). 같은 개념은 논문 전체에서 한 표기로 통일하고, 같은 단어가 두 뜻으로 쓰이면 갈라 쓴다(formulation의 "정리"는 "정식화"로, theorem의 "정리"만 남긴다).

### 2.5 국내 학회 관례

자기지칭은 "본 논문"으로 쓰고 "본 고"는 쓰지 않는다. 1인칭은 쓰지 않는다("우리의" 대신 "본 연구의"). 소제목은 명사형으로 쓰고 질문형과 대구형은 쓰지 않는다("분석이 성립하는가" 대신 "이론적 타당성", "무엇을 비교하는가" 대신 "비교 조건"). 외래 용어는 첫 등장에서 "국문(원어)"로 병기한 뒤 국문으로 통일한다.

## 3. 기호와 수치

산문 속 기호를 쓰지 않는다 [J-3]. 가운뎃점(·), em dash(—), en dash(–), 화살표(→), ≈, ≠를 본문 문장에 넣지 않는다. 3항 이상 나열은 쉼표로, 2항은 조사("과/와", "이나")로 잇는다. em dash 삽입구는 문장 분리나 쉼표로 푼다. 예외는 수식, 표 내부, 참고문헌 쪽수 범위, 고유한 기술 표기(예: unsafe→safe→finalized)다. 본문 볼드 강조와 따옴표 강조도 거의 쓰지 않는다 [J-1, J-2].

과잉 수치를 쓰지 않는다. 판단 기준은 그 숫자가 빠지면 주장이 약해지거나 검증할 수 없게 되는지다. 그렇지 않으면 정성화하거나 뺀다. 정성화할 때는 원 수치와 부합하는지 검산한다(25.8~29.9%를 "사분의 일 이상"으로 쓰면 참이고, "삼분의 일 가까이"로 쓰면 거짓이다). 표본 수, p값, 파라미터 기본값 나열은 대체로 뺀다. 한 번 쓰고 버리는 그리스 기호와 수식은 우리말로 푼다. 이후 문장이 계속 참조하는 기호(상태 변수 등)만 남긴다. 이 판단은 글을 쓰거나 구성할 때 한다. 문체만 고치는 단계에서는 숫자를 한 개도 바꾸거나 빼지 않는다(5절).

## 4. 흐름과 구조

- 문단은 두괄식으로 쓴다. 첫 문장이 그 문단의 주장이고, 나머지가 뒷받침한다. 문단 끝에 결론이 매달려 있으면 문두로 끌어올린다. 첫 문장들만 이어 읽어도 글 전체의 논증이 따라와야 한다.
  - 나쁨: "행동은 A, B, C의 다섯 가지다. … (문단 중간) 이 다섯 가지면 기존 규칙을 전부 담을 수 있다." 좋음: "행동 공간은 기존 규칙을 전부 담을 수 있도록 다섯 가지로 구성했다. A, B, C이며 …"
  - 나쁨: "X는 오래전부터 연구된 문제다. (열거)" 좋음: "X는 오래전부터 연구됐지만, Y를 함께 다룬 모형은 없다. (열거가 이를 뒷받침)"
- 문단과 절의 첫 문장은 바로 앞 내용을 받아서 시작한다. 전환어를 붙이는 것이 아니라 내용으로 잇는다. 문단 첫머리의 "먼저", "반면", "결국" 3단 공식은 쓰지 않는다 [C-7].
- 한 문단에는 하나의 생각만 담는다. 괄호가 두 번 이상 겹치거나 가정 여러 개가 한 문장에 눌려 있으면 쪼갠다("가정은 네 가지다. 첫째, …").
- 사족을 지운다. 자기 해명, 반복되는 한계 자백(한 곳에 모은다), 앞 절 내용의 재탕, 없어도 논지가 서는 수식어가 여기에 든다. "한계도 분명하다" 같은 문패 문장은 지우고 실제 한계를 첫 문장으로 쓴다 [D-12].
- 한 번 읽고 바로 이해되지 않아 되읽어야 하는 문장은 실패한 문장이다. 다시 쓴다.

## 5. 고치되 사실은 지킨다

문체를 고칠 때 기술적 주장, 수치의 의미, 인용 번호와 귀속, 가정과 한계의 범위는 한 글자도 달라져서는 안 된다. 특히 다음을 조심한다.

- 문장을 재배치하거나 두 문장을 합치다 보면 인접한 주장과 결합해 원문에 없던 새 주장이 생기거나 수식 범위가 흐려질 수 있다. 예를 들어 "그림은 예시일 뿐이다"를 앞 문장에 붙이면 그림이 그 사례를 보여준다는 주장이 된다. "A의 X, Y와 B의 Z는 P3이었다"처럼 묶으면 무엇이 무엇에 걸리는지 흐려진다. 고친 뒤 원문과 대조한다.
- 한정문을 풀다가 능력을 단정하는 문장으로 바꾸지 않는다("~을 거르는 층은 아니다"를 "~을 거르지 못한다"로 바꾸면 결과와 충돌할 수 있다).
- 엄격 부등호가 표현에서 무너질 수 있다. "절반 미만"과 "절반을 넘지 않게"는 다르다. 수학적 조건의 강도를 보존한다.
- 일괄 치환은 조사 오류를 만든다("본 고는"을 일괄 치환하면 "본 논문는"이 된다). 치환 후 조사를 점검한다.
- 어휘를 바꿀 때 뜻이 넓어지거나 좁아지지 않는지 확인한다. "결손"을 "누락"으로 바꿀 때 원문이 "모델에 없는 것"과 "모델에 있으나 연결되지 않은 것"을 구분했다면 그 구분을 유지한다.
- 저자가 정의한 용어를 통용어로 바꿀 때는 정의문과 표, 그림 캡션, 영문 초록의 대응어를 함께 고쳐 한 논문 안에서 한 개념에 한 이름만 남게 한다. 반대로, 정의된 용어를 일부러 반복한 것은 AI 티가 아니다. 어휘 다양성을 높이려고 동의어로 바꾸지 않는다.
- LaTeX 원고에서는 명령과 인자(\cite, \ref, \label, \emph, 수식, 표와 그림 환경, 캡션 명령)를 건드리지 않는다.

## 6. humanize-korean과 함께 쓸 때

humanize-korean은 일반 글(칼럼, 리포트, 에세이) 기준이라 학술 글에서는 다음 규칙이 이 스킬과 부딪친다. 학술 글에서는 이 규칙들을 적용하지 않는다.

| humanize-korean 규칙 | 학술 글에서 | 이유 |
|---|---|---|
| D-3 열거 도입("다음과 같다", "세 가지로") 삭제 | 적용하지 않는다 | "본 논문의 기여는 다음과 같다"는 학회 관례다(1절) |
| C-9, E-4, C-1 "첫째, 둘째" 나열 해체 | 기여, 가정, 조건, 연구 질문 목록에는 적용하지 않는다 | 번호 목록이 심사자의 대조를 돕는다(4절). 목록이 아닌 곳의 "하나는/다른 하나는" 반복만 푼다 |
| C-4 문단 첫머리 요약문 | 적용하지 않는다 | 두괄식이 이 스킬의 중심 규칙이다(4절) |
| E-1 문단마다 100자 넘는 장문 만들기 | 적용하지 않는다 | 되읽어야 하는 문장은 실패다(4절) |
| H-4 "즉"을 "곧"으로 바꾸기 | "곧"으로 바꾸지 않는다 | "곧"이 되풀이되면 그 자체가 AI 티다. 풀어 쓰거나 뺀다 |
| lexical diversity 점수가 낮다는 진단 | 정의된 용어 반복이면 무시한다 | 한 개념에 한 이름(5절) |
| 방법론 한정문의 "~이 아니다"를 C-8로 풀기 | 풀지 않는다 | 한정이 곧 내용이다(1절) |

## 적용 절차

1. 대상 글을 통독하며 위 규칙 위반을 수집한다(1~4절 순서로).
2. 어휘 전수 검사를 따로 한다. 2.2와 2.3의 표에 있는 말과, 표에 없어도 두 판정법(한자 연상, 목적어와 주어 교체)에 걸리는 말을 전부 표시한다. 표시된 말마다 국내 학회 논문에서 이 뜻으로 흔히 보는지를 묻고, 아니면 바꾼다. 저자의 핵심 용어라 바꿀 수 없는 것은 첫 등장의 정의와 병기를 확인한다.
3. 문장 단위로 고치되, 각 수정이 5절(사실 불변)을 지키는지 확인한다.
4. 분량 제한이 있는 문서(학회 쪽수 상한 등)는 수정 후 반드시 분량을 다시 확인한다. 풀어쓰기는 길이를 늘리므로 사족 삭제와 중복 제거로 상쇄한다.
5. 금지 기호(·, —, –, →, ≈, ≠)와 금지 패턴("~는가이다", "~뿐이다", "본 고", 1인칭, "핵심은", "관건은", "결과를 미리 말하면", "~하는 이유다", 연결어미 뒤 쉼표)과 2.2와 2.3 표의 "쓰지 않는다" 열을 스크립트로 전수 검색해 남은 위반을 찾는다. "따라서", "그래서", "곧", "결국"의 문두 출현 수도 센다.
6. 고친 글에서 문단 첫 문장만 이어 읽어 논증이 따라오는지 확인하고, 임의의 세 문단을 골라 한 번에 읽히는지 소리 내어 읽듯 점검한다.
7. AI 티 점검과 수치 점검(선택, 논문 원고는 권장). humanize-korean 플러그인이 설치돼 있으면, 1~6단계를 마친 글에 humanize-korean을 학술 모드로 부른다. 인자에 다음을 적는다: "장르: 국문 학술 논문(한다체). 6절 표의 규칙은 적용하지 않는다. LaTeX 명령과 인자, 숫자, 구간, 백분율, 인용 키, 영문 고유명사와 식별자, 정의된 용어, 방법론 한정문은 한 글자도 바꾸지 않는다." 진단과 윤문 에이전트 지시문에도 같은 조건을 넣는다. 결과는 그대로 채택하지 않는다. 다음을 직접 확인한 뒤 채택한다.
   - 파일(절)별로 숫자 토큰과 LaTeX 명령의 다중집합이 원문과 같은가(차이 0). 이 대조는 fact-check로 한다.
   - 합친 문장에서 수식 범위가 흐려지거나 한정이 단정으로 바뀐 곳이 없는가(5절). 있으면 그 문장만 원문으로 되돌린다.
   - 점검 도구의 각주 경고가 "x402)" 같은 표기를 각주로 오인한 것인지 확인한다.
   - 빌드 오류 0, 쪽수 한도 이내.
   - 바뀐 문단의 전후 대조표를 기록 파일로 남긴다.
