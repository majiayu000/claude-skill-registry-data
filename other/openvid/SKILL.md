# OpenVid

Read [ORG-WIRING.md](ORG-WIRING.md) first for seat ownership and export paths.

Then read the upstream [README.md](README.md) for editor features and local run.

## When to use

- Product demo from a screen recording or uploaded clip
- Device mockup + zoom + 3D camera on existing footage or a still
- Phase 15 / 19 when OpenMontage is the wrong tool (nothing to generate)

## When not to use

- Prompt-to-video hero or ad film → `skills/community/openmontage/`
- Brand stills with no footage → brand-designer / photoreal-stills
- Scroll-driven marketing pages → `skills/community/scroll-craft/`

## Seat rule

Only `video-producer` runs the editor. `brand-designer` may export still mockups. Everyone else reviews or requests via `ask_manager`.
