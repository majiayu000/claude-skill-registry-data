## 适用场景

在闲鱼上架 AI Agent 部署、AI 工具安装配置、办公自动化脚本等虚拟技术服务。

## 市场调研方法

1. **先搜竞品**：闲鱼搜索 "AI agent" / "AI 部署" / "远程帮装" 看现有商品定价和描述
2. **参考外部案例**：知乎、X/Twitter 搜 "闲鱼 AI 副业" 看实战经验
3. **判断差异化**：如果只会装 Coze/Dify（零代码拖拽），跟低价卷没优势。私有化部署 + Docker + GPU 调优才是壁垒

## 商品文案撰写规则

### 核心原则

- **买家视角，不是简历**：买家关心"花多少钱得到什么"，不是"你会哪些技术"
- **信任挂钩放最前面**：第一句消除最大的顾虑（"装不上不收费" / "装不上全额退"）
- **价格必标**：没有价格的商品闲鱼曝光低，系统算法不喜欢
- **闭环行动指引**："拍前先聊" — 防止没确认需求就下单的纠纷
- **交付边界要死**：闲鱼纠纷重灾区。每个套餐写死包含项、修改次数、售后天数

### 必须写入的说明

```
⏱️ 交付时间：基础款通常1小时内，进阶/定制1-3天
📋 你需要准备：一台电脑 + AI模型API Key
🚫 不代购API Key，不做灰色业务
⚠️ 不包含AI模型API/Token费用，需自行购买
```

### 大忌

- ❌ **"不限次修改，满意为止"** — 闲鱼第一大纠纷来源。改成 "含 N 轮需求修改，超出另议"
- ❌ **自我卑微** — 不说 "我会的东西你用得上"，直接用事实背书
- ❌ **"不卖账号、不卖API Key" 放最后** — 要放前面显眼位置，减少无效咨询

### Agent列表排序

按自己最熟悉、跑得最稳的顺序排列，不是按知名度。

## 定价策略

| 层级 | 内容 | 建议价 | 定位 |
|------|------|--------|------|
| 引流款 | 标准安装+跑通 | ¥99-199 | 口碑积累、评价积累 |
| 利润款 | +工具链+平台对接 | ¥499-699 | 主力收入 |
| 高端款 | 私有化+GPU调优 | ¥999起 | 利润天花板、展示技术上限 |

- 前 3-5 单可以适当低价冲好评，评分上来之后逐步涨价
- 闲鱼接单核心资产是 5 星好评，比多写 1000 行代码值钱

## 封面图制作

### 方案：HTML → 浏览器截图（推荐）

AI 生图中文文字模糊，**HTML + 浏览器截图**是最佳方案。

设计要点：
- **1:1 正方形**（800×800），适配闲鱼缩略图
- **深蓝科技背景** + 青色点缀，符合 AI 主题
- **不把价格写在封面上** — 留到详情页
- **字体要巨大**：标题 72px+，才能在缩略图里看清
- **辅助文字对比度要够**：深蓝背景上用 `#cbd5e1` 以上，不能用 `#64748b` 以下的暗色

参考模板见 `templates/xianyu-cover.html`。完整商品文案模板见 `references/listing-copy-template.md`。

### 备选：mmx image generate

文字可能糊，但速度快。适合没有特殊文字要求的场景。

## 避坑清单

### 绝对不接

- 论文代写 / 考试代考
- 账号代注册 / API Key 代购
- 爬虫/养号/灰产脚本
- 闲鱼平台本身的自动化机器人（有封号风险）

### 交付避坑

- 远程工具备选：SSH / TeamViewer / ToDesk / RustDesk，别只留一个
- 客户用自己 API Key，永远不要代买代充
- 交付时录屏或截图留存，防止"你没装"纠纷
- 基础安装前先确认客户电脑环境（系统版本、有无 Docker、网络状况）

## 信任背书写法

用"我跑过的真实东西"而不是"我会这些技术"：

```
🏷️ 关于我
· 自建4卡A10 GPU服务器，Hermes跑了半年
· QQ群机器人7×24在线，没断过
· 不卖课、不卖账号，只做交付
```
