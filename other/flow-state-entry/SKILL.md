# flow-state-entry

## When to Use

当需要进入高度专注、高效且愉悦的心流状态以完成创造性或学习性任务时description

## Core Logic

# 执行步骤

1.  **建立目标层次结构**
    *   **输入**：对个人长期愿景的模糊想法。
    *   **操作**：从宏观到微观，依次定义：
        *   **愿景与反愿景**：清晰描述你理想的生活状态（愿景）和你绝对要避免的生活状态（反愿景）。
        *   **长期目标**：设定一个10年期的方向性目标。
        *   **中期目标**：将长期目标分解为1年期的具体目标。
        *   **短期目标**：将中期目标分解为月、周、日的优先事项。
    *   **判断标准**：目标层次清晰，从愿景到每日任务逻辑连贯，且所有目标均可根据新信息调整。
    *   **输出**：一份结构化的目标清单（从10年到每日）。

2.  **锚定深入兴趣**
    *   **输入**：步骤1输出的目标清单。
    *   **操作**：
        *   审视目标清单，识别出为实现这些目标，需要深入掌握哪些核心兴趣、主题或技能。
        *   从中选择**一个**当前最相关或最吸引你的领域作为起点。
        *   为该领域分配固定的学习/实践时间。
        *   获取该领域的基础资料（如经典书籍、权威课程）并开始系统学习。
    *   **判断标准**：所选兴趣与目标高度相关，并已制定出可执行的学习计划和时间投入。
    *   **输出**：一个明确的深度学习领域及对应的初步学习计划。

3.  **匹配挑战与技能**
    *   **输入**：步骤2输出的深度学习领域。
    *   **操作**：
        *   评估你在此领域的**当前技能水平**。
        *   设计或选择一个**项目**，该项目的难度（挑战）略高于你当前的技能水平。
        *   **IF** 项目挑战远高于技能 → 你会感到焦虑，**则** 应降低项目复杂度或先提升基础技能。
        *   **ELSE IF** 项目挑战远低于技能 → 你会感到无聊，**则** 应增加项目难度或寻找更具创新性的应用。
        *   **ELSE** (挑战与技能大致平衡或略高) → 进入执行阶段。
    *   **判断标准**：启动的项目能带来轻微的压力感（非焦虑）和兴奋感，促使你专注投入。
    *   **输出**：一个与当前技能水平相匹配的、具体的实践项目。

# 输出格式要求
以结构化清单形式输出：
1.  **目标框架**：[列出你的愿景、反愿景及核心长期目标]
2.  **聚焦领域**：[明确你选择深入学习的兴趣/技能领域]
3.  **启动项目**：[描述与技能匹配的具体项目及其预期挑战]
