# LeeWay 3D QA Automation

Automate deterministic checks where possible: units/scale, unapplied transforms when prohibited, naming, missing textures, non-manifold/degenerate geometry, normals, UV overlap rules, texture dimensions/formats, material counts, polygon budgets, LOD/collision presence, unsupported export features and dependency resolution. Automated PASS supplements visual/engineering Veritas; it does not replace it.
