# value-driver-analysis

## When to Use

当分析个人或他人成就差异的根本原因，并寻求提升路径时description

## Core Logic

# 执行步骤

1.  **确定比较对象与维度**：明确要分析的对象（如不同职业阶段的自己、同行佼佼者）和关键成果维度（如收入、影响力、作品质量）。
    *   **判断标准**：比较对象和成果维度清晰、具体。
    *   **常见误区**：进行模糊、笼统的比较，导致无法得出 actionable 的洞见。

2.  **解构成果差异的驱动因素**：摒弃“努力程度”或“工作时间”作为首要解释，系统性地从以下三个层面分析：
    *   **技能**：评估在特定领域所具备的专业知识、技术和能力的水平与稀缺性。
    *   **杠杆**：评估所使用的工具、资本、协作网络或产品/内容是否具备可扩展性，能否将一份时间/努力重复售卖。
    *   **认知**：评估对行业、市场、用户需求的洞察深度，决策判断力，以及思维模型的有效性。
    *   **判断标准**：能够清晰指出差异主要来源于哪个或哪几个因素。
    *   **常见误区**：将结果差异简单归因于运气或天赋，忽略了可习得和可构建的因素（技能、杠杆、认知）。

3.  **识别最高优先级改进点**：基于步骤2的分析，判断在“技能”、“杠杆”、“认知”三者中，哪一项的边际提升对缩小成果差距或实现下一阶段目标作用最大。
    *   **IF** 技能是瓶颈 → 制定专项深度学习与实践计划。
    *   **ELSE IF** 杠杆是瓶颈 → 探索如何应用新技术、构建资产、扩大影响范围。
    *   **ELSE IF** 认知是瓶颈 → 寻求高阶思维模型、深入市场研究、与顶尖认知者交流。
    *   **判断标准**：得出一个明确的、具体的改进方向。
    *   **常见误区**：试图同时提升所有方面，导致资源分散，进展缓慢。

# 输出格式要求
输出一份结构化分析报告，包含：
1.  比较对象与成果差异描述。
2.  从“技能”、“杠杆”、“认知”三个维度进行的差异分析。
3.  结论：当前最应优先投资的改进领域及初步行动思路。
