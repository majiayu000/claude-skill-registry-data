# 統計検定 3 級

結論: **グラフと要約統計量を「読む」問題が中心**。公式を覚えるより、表やグラフから値を正しく読み取り、計算で確かめる練習を積む。

## 試験の構造(統計検定の公式サイトで確認)

- CBT 方式、多肢選択。試験時間・問題数・合格点は公式サイトの級別案内を確認する(3 級は 60 分、合格は 100 点満点の 65 点以上とされている)。
- 出題範囲は公式の「出題範囲表」が正典。高校の「データの分析」と数学 A・B の確率・統計の入口に相当する。

一次情報: 統計検定 https://www.toukei-kentei.jp/ (級別の試験内容、出題範囲表、公式問題集の案内)。

## 範囲の芯

| 分野 | 押さえること |
|---|---|
| データの種類と収集 | 量的・質的、標本調査と全数調査、無作為抽出の意味 |
| グラフ | 棒・折れ線・円・帯・ヒストグラム・幹葉図・箱ひげ図・散布図。目的に合うグラフの選択 |
| 要約 | 平均・中央値・最頻値、範囲・四分位範囲・分散・標準偏差、外れ値 |
| 2 変数 | 散布図と相関係数、相関と因果の違い、クロス集計 |
| 確率 | 場合の数、独立、条件付き確率の入口 |
| 推測の入口 | 標本平均のばらつき、母集団と標本の区別 |

## 学び方

1. 箱ひげ図とヒストグラムの対応(同じデータがどう見えるか)を、自分で作った数値で何度も描く。
2. 四分位数の求め方は**定義が複数ある**ことを知り、試験の定義(出題範囲・公式教材の方法)に合わせる。
3. 平均・分散・標準偏差は手計算と表計算(またはプログラム)の両方で求め、一致を確かめる。
4. 公式問題集で時間を計って解き、誤答は「読み取りの誤り」か「計算の誤り」かを分けて記録する。

## 問題を自作するとき

- 数値は自分で作り、答えを**プログラムで検算**する(中央値・四分位数の定義も明記)。
- 誤答の選択肢は典型的な誤り(中央値と平均の取り違え、度数と相対度数の混同)から作る。
- 公式問題の文章・図を転載しない。

## 落とし穴

- ヒストグラムの階級幅が不揃いのとき、高さは度数でなく**密度**で読む。
- 箱ひげ図から平均は読めない(中央値と四分位数だけ)。
- 相関係数が 0 に近くても関係がないとは限らない(曲線的な関係、外れ値の影響)。
- 「割合の割合」(全体に対する比率か、グループ内の比率か)の取り違え。

## 自己検証

- 公式問題集 1 回分を時間内に解き、65% を安定して超えるか。
- 与えられたデータから箱ひげ図を白紙で描けるか。
- 誤答の原因を 1 行で説明できるか。
