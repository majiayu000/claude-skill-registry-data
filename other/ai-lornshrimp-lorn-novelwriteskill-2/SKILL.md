# AI科幻-撰写书评

这是题材包装层、兼容入口与路由层。


<!-- ===== Layer 3: 场景缓存 ===== -->

## 对应通用 Skill

- `通用-撰写书评`

## 本层职责

- 保留“AI科幻-撰写书评”这一题材入口名。
- 将书评写作的共性骨架路由到 `通用-撰写书评`。
- 补充AI科幻题材下的日常裂缝、数据痕迹真、系统摩擦、人物体面与技术代价抓手。

## 常见触发词 / 用户说法速查

- 帮我写AI科幻书评
- 给这本书写一篇不剧透安利文
- 这篇书评太像剧情简介了
- 把数字压迫感和后怕写进书评
- 给我一篇偏平台推荐口径的AI科幻书评

## 推荐组合调用

- 默认基础链：`AI科幻-设计题材定位框架`、`AI科幻-设计故事面`
- 若目标是分卷 / 单章书评，且需要强化连载抓点，可再补充调用：`AI科幻-强化章节开头`、`AI科幻-强化章末钩子`
- 若书评面向具体平台传播，再按需叠加对应 `AI科幻-输出*版` Skill 的平台口径

## 强制要求

- 命中本技能时，必须优先强制加载当前题材 Skill 与 `通用-撰写书评`。
- 书评不能只写神秘感，必须写出它如何把熟悉城市生活变得危险且可信。
- 不得绕过 `通用-撰写书评` 在题材层平行维护一整套通用书评规则。
- 若用户只说“推荐型书评 / 普通读者书评 / 安利文”，默认优先从异常细节、代入感、后怕与余味切入。
- 若目标平台已明确，默认在题材切口不丢的前提下，按对应平台模板调整标题、开头问题感与结尾安利动作。
