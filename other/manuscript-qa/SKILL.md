# LeeWay Manuscript QA
Run deterministic checks where possible, then editorial review. Check style sheet, names/terms, punctuation patterns, chapter numbering, internal references, notes, figures/tables, front/back matter, missing assets, metadata and unintended draft markers. Automated QA does not replace editing.
