# 3D Isometric Healing Blocks

## Delivery

- Use the source photo only as a reference for subject, structure, pose, spatial relationships, and color. Stylize the entire final canvas; do not show the original photo or create split-screen or before-and-after layouts.
- Generate one standalone 3:4 vertical poster per source image. Process multiple images separately; never create a collage.
- If the user asks only for a prompt, return a ready-to-use generation prompt. Otherwise, use the available image generation or editing capability directly. Ask for an upload only when no reference image is available.
- Preserve subject identity, count, mass proportions, axes, curves, interlocks, layers, occlusions, and negative spaces. Simplify secondary detail without changing defining features.

## Fixed visual specification

Use a deconstruct → select → distill → reconstruct process to translate the subject into a healing-style 3D/isometric block sculpture. Reorganize it with rounded, simple, tactile modular volumes while keeping it immediately recognizable.

- Adapt the composition to the subject's center of gravity, pose direction, and spatial relationships.
- Build rhythm through volume scale, stepped heights, front-back interlocking, selective suspension, density changes, and generous negative space.
- Modules may join, stack, nest, pass through one another, or shift naturally. Aim for contemporary sculpture and relaxed imagination, not mechanical disassembly or pixelation.

Derive every color from the current source image. Identify its most recognizable and lively dominant colors, overall temperature, value hierarchy, warm-cool relationships, and key accents, then translate them into a soft, clear, bright, airy healing palette. You may lift brightness, reduce harsh contrast, and clean muddy mixtures. Use dominant color area, supporting layers, related tints and shades, and a few lively accents. Each photo must generate its own palette; never use a fixed color card or introduce colors absent from the source.

Use finely matte, softly diffused materials with subtle pulp, wood, powder-wax, or flexible-material tactility. Keep corners rounded and shadows gentle.

Add restrained editorial micro-typography. Derive a 2–5-word title from the source image's light, action, space, mood, or symbolism. Optional micro-copy may include only verifiable location, numbering, direction words, or annotations; do not use years. Align text with block edges, seams, visual axes, or negative space, allowing subtle overlap or occlusion without competing with the subject.

## Quality boundaries

The result should feel gentle, airy, quiet, refined, playful but not childish. Avoid visible source photography, collages, fixed palettes, LEGO replication, mechanical disassembly, simple pixelation, children's cartoons, plastic highlights, metallic surfaces, heavy CGI, cheap toys, e-commerce displays, and template styling.
