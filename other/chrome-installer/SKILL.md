# Chrome 安装与升级 Skill

本技能专门用于帮助用户检测、安装或升级本地 Google Chrome 浏览器。
Google Chrome 是私有助理平台正常运行所必须的底层依赖（建议版本为 **120 或以上**，推荐最新稳定版），如果用户的系统未安装 Chrome，或者 Chrome 版本过低，可能导致页面控制、数据采集、账号登录等功能无法正常使用。

## 核心功能

1. **状态检查**：自动检测当前操作系统（Windows / macOS）下 Chrome 是否已安装、物理路径以及具体版本号，并判断是否满足运行条件（>= 120）。
2. **极简自动安装**：
   - **Windows**：自动从国内镜像下载 64位独立安装包，并以静默模式在后台自动完成安装（无需用户手动点击下一步）。
   - **macOS**：自动下载 Mac 通用 DMG 镜像文件，在后台挂载并将其拷贝至 `/Applications/` 目录下完成安装。
3. **友好容错引导**：如果自动安装中因系统权限不足（如 UAC 弹窗被拒绝、`/Applications/` 目录写保护）或网络异常导致失败，本技能会自动捕获异常，并清晰引导用户打开国内官方地址 [https://www.google.cn/chrome/](https://www.google.cn/chrome/) 手动下载和安装，让用户操作成本降到最低。

## 可用命令行

该技能可以通过本地命令行直接执行：
*   **状态检查**：
    ```bash
    python run.py check
    ```
*   **安装/升级**：
    ```bash
    python run.py install
    ```

## 不可违反的原则

1. **访问国内镜像**：下载地址必须使用国内可访问的 Google 官方 CDN 路径，确保在国内网络环境下也能以最快速度完成下载。
2. **用户最小干预**：默认采用静默或全自动拷贝安装，减少弹窗，只在万不得已（如权限报错）时才引导用户手动处理。
3. **临时文件清理**：下载的安装包属于临时文件，必须放在项目根目录下的 `./temp/` 文件夹内，并在安装完成或安装失败后**立即彻底删除**，严禁残留无用文件。
