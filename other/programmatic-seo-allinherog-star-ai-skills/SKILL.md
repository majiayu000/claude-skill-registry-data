# programmatic-seo 程序化 SEO 助手

[快速开始](https://github.com/allinherog-star/ai-skills/tree/main#%E5%BF%AB%E9%80%9F%E5%BC%80%E5%A7%8B)

[更多技能](https://ai-skills.ai)

### 概述

程序化 SEO 助手用于回答「页面能批量获客吗」、SEO、GEO、内容增长，适合市场营销、运营、产品、software在明确业务目标、内容材料或分析对象后调用。
它会结合程序化页面样本、可粘贴页面模板、字段样本、关键词/实体列表、目录结构、页面规则或业…等输入，整理关键上下文，并输出摘要、诊断结论、行动建议和可复用交付物，便于继续执行、复盘或交付。

### 什么时候使用

**适用场景**

- 用户提出“页面能批量获客吗”这类问题，需要快速拆解目标、判断重点并形成可执行结果
- 市场营销、运营、产品、software需要围绕程序化 SEO 助手生成摘要、诊断结论、行动建议和可复用交付物
- 用户已经准备了规模化 SEO 目标（例如覆盖长尾关键词、扩展地区/行业页面、提升 AI 引用或获取线索。）、长尾搜索人群（说明目标查询场景、地域/行业细分、采购角色或内容消费阶段。）、样本页面或目录链接（填写无需登录即可访问的样本页、目录页、竞品页或页面模板链接。），希望整理成可执行的分析或优化结果
- 用户需要把程序化 SEO 助手相关材料转成清晰结论、优先级和下一步动作

### 调用方式

通过导出的 Python runner 直接调用 AI Skills API：

### 命令示例

**基础调用**

```bash
python3 scripts/run.py --params '{}'
```

**带常用参数调用**

```bash
python3 scripts/run.py --params '{"goal":"规模化 SEO 目标"}'
```

### 参数说明

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `goal` | string | 否 | - | 例如覆盖长尾关键词、扩展地区/行业页面、提升 AI 引用或获取线索 |
| `audience` | string | 否 | - | 说明目标查询场景、地域/行业细分、采购角色或内容消费阶段 |
| `materialUrl` | string | 否 | - | 填写无需登录即可访问的样本页、目录页、竞品页或页面模板链接；需要传可访问的完整 URL |
| `materialFile` | string | 否 | - | 支持 CSV、表格、关键词清单、实体数据样本、页面模板、站点结构或需求文档 |
| `materialText` | string | 否 | - | 可粘贴页面模板、字段样本、关键词/实体列表、目录结构、页面规则或业务说明 |
| `brandRequirements` | string | 否 | - | 补充品牌语气、禁用生成方式、合规限制、必须保留字段和人工复核要求 |

完整机器可读参数结构见 `references/form-schema.json`。

### 交付内容

- 摘要、诊断结论、行动建议和可复用交付物：围绕用户目标整理可直接阅读、复盘或交付的核心结果。
- 输入材料解读：结合规模化 SEO 目标（例如覆盖长尾关键词、扩展地区/行业页面、提升 AI 引用或获取线索。）、长尾搜索人群（说明目标查询场景、地域/行业细分、采购角色或内容消费阶段。）、样本页面或目录链接（填写无需登录即可访问的样本页、目录页、竞品页或页面模板链接。）提炼关键上下文和判断依据。
- 下一步动作：给出优先级、执行建议或可继续加工的内容框架。

### 结果使用建议

- 先判断输出是否回答了用户关于「程序化 SEO 助手」的核心问题。
- 再检查结果是否覆盖摘要、诊断结论、行动建议和可复用交付物，以及是否给出明确下一步动作。
- 如果输入材料较少，建议让用户补充目标、受众、限制条件或原始材料后再运行。
