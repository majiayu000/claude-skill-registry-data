# 物理表示侦察兵 / Problem Representation Scout

卡住通常不是因为不会算，而是因为**在错误的表示里算**。这个 skill 做两件事：
把过程切成阶段，为每个阶段配一个表示。

顺序不能反。**先分阶段，再选表示**——一个横跨"接触前 / 接触中 / 接触后"的受力图，
画得再漂亮也没用，因为那三段的约束根本不是同一套。

## 何时使用 / When to use

- 方程都列出来了，就是解不动
- 能量怎么算都对不上
- 不知道该沿哪个方向、对哪个系统列方程
- 过程里有碰撞、绳突然绷直、打滑、脱离接触，不知道怎么接
- 画了图但不知道图能回答什么问题

**不适用于** / Not for：

- 还不知道该用哪条定律 —— 先用 `problem-formalization-coach`
- 只是想换个参考系 —— 用 `reference-frame-choice-guide`（本 skill 会指过去）
- 想要有人把方程解出来 —— 本 skill 不解

## 需要的输入 / Inputs

| 输入 | 必填 | 说明 |
|---|---|---|
| 问题与要求的量 | 是 | 要求什么、在哪个时刻 |
| 已经做到哪一步 | 是 | 列了哪些方程、卡在哪一行；这是诊断的主要依据 |
| 定律台账 | 否 | 有 `problem-formalization-coach` 的产物最好 |

## 第一步：分阶段 / Stage decomposition

### 阶段边界只有五种

| 边界 | 判据 | 例子 |
|---|---|---|
| **约束改变** | 一条约束方程开始或停止成立 | 绳由松变紧、滑块进入轨道 |
| **接触建立或断开** | 正压力 `N` 由正变零 | 小球离开球面（`N = 0` 的那一刻） |
| **摩擦状态切换**（静 → 滑） | 维持无相对滑动所需的静摩擦，其大小 `f_req` 达到 `μ_s N` | 静止的物块开始滑动；滚动的轮子开始打滑 |
| **摩擦状态切换**（滑 → 滚、滑 → 停） | 接触点相对滑动速度 `v_slip` 降到 0（如 `v_cm − ωR = 0`）；之后再验所需静摩擦的大小 `f_req ≤ μ_s N`，成立才进入无滑阶段。滑动时摩擦是动摩擦 `μ_k N`，等不到"摩擦达到 `μ_s N`"那一刻 | 打滑的保龄球转为纯滚动；传送带上的物块滑到与带共速 |
| **冲量作用** | 有限冲量在趋于零的时间内完成 | 碰撞、绳绷直、锤击 |
| **相变或介质改变** | 材料状态或传播介质变了 | 熔化、进入另一种介质 |

**判据本身往往就是一个待解的方程**（"`N = 0` 发生在什么时候"）。
把它单独列出来当作一个子问题，不要混在主线里。

### 冲量阶段的严格处理

在冲量时间 `Δt → 0`、冲量 `J = ∫F dt` 保持有限的极限下：

| 量 | 能不能突变 | 理由 |
|---|---|---|
| 位置 | **不能** | `Δr ≤ v_max·Δt → 0` |
| 速度 / 动量 | 能 | `Δp = J` |
| 角动量 | 能 | `ΔL = r × J`，`r` 因位置连续而取碰撞点的值 |
| 动能 | 只能**减少**（或由内部储能释放而增加） | 恢复系数 `e ∈ [0, 1]`；爆炸、压缩弹簧释放属于后者 |
| 有限力（重力、常规弹簧力）的冲量 | 趋于零 | **所以冲量阶段可以忽略重力**——这才是"碰撞瞬间动量守恒"的严格版本 |

两个常用推论：

- **绳突然绷直**（不可伸长、不回弹）：冲量沿绳，沿绳方向的速度分量被抹掉，
  垂直分量不变；损失的动能是 `½m v_∥²`。
- **刚体受冲量 `J`，作用点相对质心的位置是 `r`**：`Δv_cm = J/M`，`Δω = I_cm⁻¹(r × J)`。
  质心速度和角速度必须分别处理，不能只写一条。

### 衔接条件

相邻阶段之间，逐个状态量对上：

| 量 | 跨冲量边界 | 跨非冲量边界 |
|---|---|---|
| 位置 | 连续 | 连续 |
| 速度 | **可突变** | 连续 |
| 加速度 | 可突变 | 可突变（约束换了） |
| 能量 | 可减少 | 无耗散时连续 |

**能量算不平，十有八九是漏了一个冲量边界。** 先回来查阶段划分，不要去改系数。

## 第二步：选表示 / Choosing a representation

### 选择判据：看问题里出现哪些量、不出现哪些量

| 要求的量里**不含** | 就找不含它的关系 |
|---|---|
| 时间 | 功–动能定理、能量守恒、`v²` 型关系 |
| 内力 | 把两个物体取成一个系统 |
| 具体路径 | 保守力的势能差 |
| 力的大小，只要方向 | 对称性 |
| 瞬时值，只要总量 | 冲量–动量、收支方程 |

### 表示清单

| 表示 | 直接给出 | 前提 | 什么时候不该用 |
|---|---|---|---|
| 受力图 | 瞬时加速度、约束力 | 系统边界画清；每个力有施力物体 | 内力多、约束复杂时改用广义坐标 |
| 冲量–动量表 | 突变前后的速度 | 冲量主导（见上） | 有限时长的过程 |
| 势能曲线 `U(x)` | 转折点、能不能越过、平衡点稳定性 | 保守力，且可约化为单自由度 | 有耗散或强耦合 |
| 有效势 `U_eff = U(r) + L²/(2mr²)` | 中心力问题的径向运动 | 角动量守恒 | 有非中心力或力矩 |
| 相图 `(x, ẋ)` | 周期性、分离线、稳定性 | 自治系统（不显含 `t`） | 受迫振动要扩展相空间或用庞加莱截面 |
| `v–t` / `a–t` 图 | 位移 = 面积，加速度 = 斜率 | 一维，或已分解到某个分量 | 二维耦合运动 |
| 质心系 + 相对坐标 | 两体降为单体（约化质量 `μ = m₁m₂/(m₁+m₂)`） | 内力只依赖相对位置 | 三体以上 |
| 电路重画（等势点合并） | 串并联结构 | 无互感、准静态 | 有互感、分布参数、高频 |
| 相量 / 复阻抗 | 正弦稳态的幅值与相位 | 线性、单一频率、已达稳态 | 暂态、非线性、多频 |
| 无量纲化 | 哪些参数只以组合形式出现 | — | 定不了无量纲系数 |
| 对称性 → 守恒量 | 一个首次积分 | 拉格朗日量在该变换下不变 | 有耗散 |
| 镜像法 / 叠加 | 简单边界下的场 | 线性介质、规则边界 | 非线性或复杂几何 |
| 参考系变换 | 消掉一个运动 | 见 `reference-frame-choice-guide` | — |

## 诊断表 / Symptom to missing representation

| 症状 | 缺的通常是 | 先做什么 |
|---|---|---|
| 受力都画了，方程解不动 | 一个首次积分 | 找对称性；检查是否有守恒量没用上 |
| 不知道沿哪个方向、对哪个系统列方程 | 约束分析 | 数自由度，改用广义坐标；把"系统"边界画出来 |
| 能量怎么都对不平 | 阶段划分 | 找漏掉的冲量边界或耗散项 |
| 结果依赖一个我以为无关的量 | 无量纲化 | 把方程无量纲化，看该量是否只出现在某个组合里 |
| 多个物体，方程一大堆 | 质心 / 相对坐标分解 | 先写整体动量方程，再写相对运动 |
| 电路看不出串并联 | 等势点重画 | 标出等势点并合并，再重画 |
| 结果随时间振荡，看不出规律 | 相图或频域 | 画 `(x, ẋ)`；或做频谱 |
| 画了 `v–t` 图但答不了问题 | 图的类型不对 | 问"什么时候"用 `v–t`，问"能不能到"用 `U(x)` |
| 每一步都对，最后结果荒谬 | 不是表示问题 | 交给 `dimensional-analysis-checker` 查量纲、`limiting-case-validator` 查极限 |

## 输出格式 / Output

```markdown
## 阶段划分
| 阶段 | 起点事件 | 终点事件（判据） | 该段守恒什么 | 该段的表示 |

## 阶段边界
| 边界 | 类型（约束/接触/摩擦/冲量/相变） | 判据方程 | 位置 | 速度 | 能量 |

## 诊断
- 症状：<使用者的原话>
- 缺的表示：<哪一个>
- 理由：<为什么这个表示能直接回答本段的问题>

## 每段该问的问题
1. 阶段一：<在这个表示里，该问的第一个问题是什么>
2. ...

## 交接
- 需要先解决的子问题（通常是某个边界判据）
- 需要换参考系时 → reference-frame-choice-guide
- 解出后用什么检查
```

交出前闭环检查：每个阶段边界都有判据方程；相邻阶段的位置、速度、能量三行都填了；
诊断给的表示与"要求的量里不含什么"对得上。

## 边界 / Boundaries

- **不解题**：不列完整方程组、不化简、不求解、不给数值。
- **不替使用者画图**：说明该画什么图、图上该标哪些量，图由本人画。
- **不把"多试几个表示"当建议**：给出的表示必须附一句它为什么能回答本段问题。
- **不跳过阶段划分直接推荐表示**：这是本 skill 最容易被抄近路的地方。
- **不越过诚信闸**：作业与竞赛进行中只给角度，不给结果。

## Token 控制 / Token discipline

- 只复述使用者卡住的那几行，不重抄整份推导
- 表示清单按需引用相关行，不整表展开
- 交接只带阶段表与诊断结论
