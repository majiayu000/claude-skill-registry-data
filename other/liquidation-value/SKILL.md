# Liquidation Value Skill

## Purpose

Estimate downside value under conservative liquidation assumptions.

## Inputs

- Target
- Market
- Industry
- Available data
- User requested depth
- Prior assumptions, if any

## Outputs

- Structured analysis
- Assumptions
- Missing data
- Confidence level
- Next required action

## Rules

- State assumptions explicitly.
- Flag missing or low-confidence data.
- Prefer conservative assumptions.
- Keep output auditable.
