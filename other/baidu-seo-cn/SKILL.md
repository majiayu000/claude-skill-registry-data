# 百度 SEO

百度与 Google 的核心差异：移动落地页体验权重高、算法对采集/作弊打击严、百度系产品占位重要、新站收录慢需主动提交。

## 输入

站点类型（企业站/内容站/B2B/商城）、域名年龄与备案、当前收录/排名数据（搜索资源平台）、目标关键词、技术栈（可否改 TDK/结构）。

## 审计与优化清单

### 1. 收录基础

- 百度搜索资源平台（ziyuan.baidu.com）：站点验证、sitemap 提交、普通收录/API 推送、抓取诊断、抓取频次；
- 备案与服务器：国内服务器+ICP 备案是百度信任基础；海外主机收录与排名明显吃亏；
- robots/死链/抓取异常：死链提交、404 规范、JS 渲染内容百度抓取弱（重要内容服务端渲染）。

### 2. 移动落地页体验（百度特色，重点）

- 《百度移动搜索落地页体验白皮书》：首屏广告面积限制、弹窗/悬浮/强制跳转 APP 限制、主体内容占比；违规触发冰桶类算法，广告与收录双杀；
- 打开速度（移动 1.5s 内为佳）、MIP 已淘汰不再推荐、自适应或独立移动站+适配声明。

### 3. 算法红线（不碰）

- 飓风（采集拼接）、惊雷（点击快排作弊）、清风（标题堆砌作弊）、细雨（B2B 标题堆词）、烽火（劫持跳转）、石榴（低质广告页）；
- 明确拒绝"快排/万词霸屏/点击器"需求并说明风险（惊雷打击下站点被 K 概率高）。

### 4. 内容与关键词

- TDK：标题含核心词且不堆砌（≤30 字）、描述有点击欲、一词一页避免内部竞争；
- 内容：原创/深度/更新频率；问答型内容匹配百度搜索意图；聚合页要有真实信息增量（空聚合=低质）；
- 内链结构：扁平（3 层内可达）、面包屑、相关推荐；外链：友情链接+行业目录，不买链接群发。

### 5. 百度系占位（SERP 现实）

- 百度百科（品牌词门面，创建需参考资料）、百度知道/经验（问答占位）、百家号（内容分发+搜索加权）、百度地图（本地业务）、智能小程序（搜索直达）；
- 品牌词 SERP 首页构成审计：官网/百科/百家号/新闻源/负面，缺位补位。

## 输出格式

```
## 百度 SEO 审计（站点 / 数据区间）
### 收录与技术问题清单（优先级）
### 落地页体验违规项
### 关键词布局表（词/页面/TDK 建议）
### 百度系占位方案
### 90 天执行排期与度量（收录量/索引/排名/点击）
```

## 约束

- 不承诺"7 天上首页"；百度新站考察期数周至数月是常态，给合理预期。
- 算法名称与规则以百度搜索资源平台当期公告为准。
- 医疗/金融等资质行业先确认资质，百度对这类站点审核更严。
