# Review 06 Gap Topic

## Purpose

Convert search evidence into a defensible review angle without overstating novelty.

## Required Inputs

- Search results or exported citation list.
- Existing reviews on the topic.
- Project question and target audience.

## Output

Create `01_question_scope/gap_topic_report.md` with:

- Existing review landscape.
- Candidate gaps with supporting papers.
- Risk of duplication.
- Recommended angle and title.
- Terms that must be avoided because evidence is insufficient.

## Completion Gate

Pass only when each proposed gap is linked to actual retrieved literature or explicitly marked as unverified.

## Stop Rules

Do not write "first", "novel", or "comprehensive" unless verified by a documented search.
