# 天正索引、剖切与多落点说明

先读项目唯一要求及`../cad-check-review/references/annotation-control.md`。索引源构件、正文、详图号/图号、范围框和实际承接详图分别核；不凭文字附近或最近曲线改指向。

## 已证类型与入口

- `TDbSymbIndexPointer`：读`../cad-check-review/library/knowledge/TIANZHENG_NATIVE_ANNOTATION_ADJUSTMENT_AND_COLLISION.md`的“园建原生控制”“总图双圈索引”“纸面符号与剖切”。限定样本g2指向、g1折点、g0承托端；先真实点→折点→承托并每次重读。双分支7夹点不能套普通3点。
- `TDbSymbComposing`：同文档“多落点说明”。将最高g0越过其它落点曾删除已存在控制点；正确样本按实际纸面排序先从低到高调整其它点，最后最高点，并逐项配原文字与源句柄。夹点序可能变，不能固化g5以后永远代表同一行。
- 双圈：已验证样例直径10模板有g4移动5生成第二圈的限定实测；圈径、版本、第三圈风险须重新核，不能把数字5当通用公式。

具体原生方法见包内原生控制文档的“总图双圈索引”“多落点说明”“纸面符号与剖切”。固定工程的索引/剖切试验脚本不随包；已有数组式属性/夹点执行源码在 `../tianzheng-batch-polyline-dimension/runtime/src/NativeAnnotationJob.cs`，适用字段和当前原生拓扑须分别核实。

## 操作与检查

引出允许纸面90°竖引、0°水平直引和45°斜引；90°优先，后两种按当地空间选择。斜引外观规则后置，不反过来要求所有索引都斜引。0°按同向水平直线核，不强造折点或套180°退化拒绝；完整判定沿共用控制，不改变原生分支及构件指向。

1. 先按当前图种和已确认新底板核应索引的有效构件，再建立实际源构件→完整索引对象→文字/详图引用→当前承接页的对应。不能只遍历旧索引并调整外观：构件取消则清失效注，同一构件移位则迁移或在新处重建清旧，新构件需索引而缺注则补；仍有效且正确的沿用。同句柄或最近邻只支持追源，不能独立证明措施仍有效，未知只停该对象。原DWG、PDF或手改号冲突时按本次明确来源处理，不能自行择旧号。
   - 全册变更时，按全部受影响图幅核原索引及当前需索引的有效构件，不能只处理已点名对象或只核新增注。构件仍保留且移位/改形的，索引随同一实物更新落点和必要引用；实际取消的清失效注；做法变更的同步承接详图与图名。删除旧注不能代替保留构件在新位置的必要表达，也不凭最近对象或图案种子认定新材料。未知只挂该项，已核且未受影响的索引沿用。
2. 读取真实RXCLASS、所有原生属性与夹点、模型/布局归属、视口变换。保持整体可编辑语义，不炸成文本/圆圈/线冒充。
3. 固定源指向，在对应同一构件有效位置内按授权调整；单源＋水平承托的索引按共用“90°优先”，先纸面竖直向上引出、圈/文字在横线上左右展开。文字被坡顶线/粗虚线切过，先调长度并适当加长脱开，仍无位再向下，最后才斜引；圈、文字、横线整体按原生拓扑联动。不能长距离贴边线走或换指另一构件只为消交叉。坡顶线等说明须对同一现行真实线位；移动说明及其指向，不移动工程线腾位置。已验且未受影响的索引不为统一方向重排。
4. 原生拓扑每步重读。先源点再折点/承托适用于已证类型；复合索引按自己的顺序与源文字逐项验证。任何点数变少、文字丢失或源关系改变立即停该对象并保护，不能继续写下一批掩盖。
   - 原生读回后，所有本批新建/调整的水平承托索引均须经过共用`check_leader_joint`真实接头判定；不能只给坐标计算角度，而索引仅返回正文/图号。六夹点等对象先由真实引线邻段与朝圈/文字的承托邻段确定角色；不按点数硬套三点坐标模板。角色未知或缺该对象/分支结果保留待核，不当作合格。原图未改且已有有效验收的范围不重扫。
5. 同一纸面统一投影模型和纸空间当前可见文字、索引圈、引线及主要工程；排除系统纸空间总览缓存，不只检同类或只检新对象。另一已验证样例的跨空间审计可复用方法，不能套其页号与视口。
6. 图号、详图号、剖切线/范围框和承接内容逐项完整；只画索引点不画范围框或引用错误均不算完成。按构件去重而非整层/同文字批删。
   - 同一区域在网格定位、主节点与局部放大页可有不同承接图号；按源构件＋当前视图用途＋实际目标页配对。用户纠正某一引用只更新该关系及直接目录/标题，不全图替换相同字符串，也不将另一个构件的同页号详图混用。保留本次手调的视口后再定位索引，旧标题或历史过程文件名不作为当前图号依据。

完整大项核原生拓扑/数值/所有文字、源关系、受影响图幅和保护对象，保存后直接在当前文档继续，不例行重开。新意见关于本项目图号/详图归属留在项目；关于原生点数丢失、先后顺序、跨空间碰撞的可复用控制更新本Skill对应类型，不覆盖已经验证有效的另一拓扑。
