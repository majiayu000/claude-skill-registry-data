# CAD实际图面与整体审美

沿`../cad-check-review/references/construction-drawing-workflow.md`和项目原ID验收；读`../cad-check-review/library/knowledge/CAD_ANNOTATION_AESTHETIC_USER_REQUIREMENTS.md`的A1—A7及当前相关N条款。审美建立在语义正确和可读施工表达上，不能替代真实源对象/数值检查。

## 检查层次

1. **范围和用途**：本专业是否完整覆盖当前施工范围、首末节点和必要接口；旧要求是否有漏项；图种内容是否合理。保留/取消/农田/硬质和新旧底板从原意见核，不从脚本改过哪些对象反推。
2. **信息层级**：设计线、背景地形、填充、符号、网格、文字按本套已定层级显示。普通GRASS/细地形是低优先级；重要工程、有效文字/符号是真障碍。不同专业可以有不同填充表达，不能强行做完全相同。
3. **就近与秩序**：文字和对象归属清楚；短而舒展、侧别一致、间距适当。检查远抛、无用途绕行、边界贴走和密集挤压，不能靠极端搜索取得零交点。具体H系数、字高和最小距离取当前已核公式，不跨项目套常数。
4. **类型后态**：乔木中心/首尾，灌草有效核心，坐标真点与值，标高文字符号贴合，索引构件与详图，尺寸源弧/角度/R分别按专项Skill核。统一“引线无交叉”不能替代这些条件。
5. **整页与跨幅**：实际纸面比例、图框图签、标题/图例/表格、指北针和长索引余量；检查文字剪半、孤立碎线、重复注及首末漏幅。局部好看不证明整幅好，整幅缩略图也看不清细字和端点。

## 证据与返修

准确绑定当前候选和文档，复用已验证的无前台原生CAD区域图/完整帧，保留可定位全图与必要放大；同帧细节直接裁取，不重新捕获未变范围。捕获方式沿`../cad-check-review/references/drawing-change-workflow.md`，频率统一按[共用检查触发表](../cad-check-review/references/annotation-control.md#检查按触发条件执行不按每次微调重复)。黑图、旧图、天正文字未渲染、仅普通几何显隐变化均不能验收。

常规图审用CAD实际区域捕获，不打印PDF再转图片。重叠、压字、串线和邻注排布必须在对应布局视口检查，先核真实可见集合；模型空间多图种叠加的画面不能证明这些后态。包围框/圆冠范围碰撞只筛候选，实际字形与重要工程关系才用于判定。布局捕获接口缺失或模型与布局显示不同，不能自动触发打印；只修相应截图入口，不因此反复扩展位置搜索。PDF只用于明确输出或具体打印属性问题，限定图幅并在诊断结束后退出，不能把临时例外延续到日常引线检查。实际调用按[截图与正式出图](../cad-check-review/references/drawing-change-workflow.md#截图与正式出图)；同一实际画面复用，完整大项统一核本次修改与受影响接缝，未变范围不重查。

程序候选筛选、必要原生后态、保存结果和实际图面各说明所证明的内容；在当前文档完成常规检查，只有具体异常或明确重开效果验证才重开。局部反例只修失败机制/对象及受影响同类，已核其余保护；整项完成后集中返修，不逐小段索批准。审美意见回写对应专业/类型Skill，跨类型层级与检查顺序更新本Skill，不将一次美观候选称为全图通用自动排版。
