# focus-framework

## When to Use

当需要将分散的注意力系统性地引导至个人成长方向，并为好奇心提供明确指引时description

## Core Logic

# 执行步骤

1.  **准备规划工具**
    *   **输入**：空白文档或规划工具（如笔记本、数字应用）。
    *   **操作**：选择一个用于记录和规划的物理或数字载体。
    *   **判断标准**：工具已就绪，可以开始清晰、结构化的书写。
    *   **输出**：就绪的规划界面。

2.  **结构化书写个人规划**
    *   **输入**：就绪的规划界面。
    *   **操作**：按照以下四个层级，依次写下清晰、具体的描述：
        1.  **愿景**：描述长远的、理想的生活状态或身份。
        2.  **惯例**：列出支撑愿景的日常习惯或固定行为模式。
        3.  **目标**：设定中期（如季度/年度）可衡量的具体成果。
        4.  **优先事项**：明确当前周期（如本周/本月）需要完成的最重要任务。
    *   **判断标准**：四个层级均已填写，内容具体、可理解，且从愿景到优先事项存在逻辑支撑关系。
    *   **输出**：一份包含四个层级的完整书面规划。

3.  **启动注意力训练与迭代**
    *   **输入**：完整的书面规划。
    *   **操作**：
        a. **定期回顾**：将书面规划置于日常可见处，并定期（如每日/每周）快速浏览。
        b. **捕捉机会**：在日常生活和工作中，主动留意与书面规划中愿景、目标相符的信息和机会。
        c. **迭代更新**：根据新的认知或环境变化，对规划（尤其是目标、优先事项）进行修订和优化。
    *   **判断标准**：规划内容开始影响日常注意力的分配，并能识别出与规划相关的机会；规划文档根据实际情况进行了更新。
    *   **输出**：一个持续运行、引导注意力的动态规划系统。
    *   **IF/ELSE**：
        *   **IF** 发现注意力持续被无关事务分散：**THEN** 返回步骤2，检查并重写优先事项，确保其足够清晰且与愿景强相关。
        *   **ELSE**（注意力能有效聚焦）：**THEN** 持续执行步骤3的迭代循环。

# 输出格式要求

向用户呈现一个结构化的个人聚焦框架，包含以下部分：
1.  **你的聚焦框架**：以清晰的分点或表格形式，展示用户填写的愿景、惯例、目标、优先事项。
2.  **行动指令**：明确告知用户下一步行动，即如何放置、回顾及迭代该框架。
3.  **预期效果**：简要说明持续使用此框架将如何训练注意力并引导好奇心。
