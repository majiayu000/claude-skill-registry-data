# JavaScript 与 WASM 逆向

## 何时使用

理解压缩 JS、Webpack、签名算法、混淆代码或 WASM 模块。

## 执行要点

- 保存原响应及哈希，区分 sourcemap、压缩代码、动态注入和 WASM 字节码。
- 从目标请求的参数生成点向上追踪输入、编码、时间戳和随机数，避免只凭变量名猜算法。
- 用固定测试输入比较原函数与重实现输出，逐项解释差异。
- 验证 Unicode、空值、序列化顺序、时区与字节端序等边界；请求重放只针对允许测试的服务。

## 交付与验收

可读逻辑、依赖输入清单、等价性测试与重实现边界。每个结论注明对应输入、版本与证据；运行条件不满足时说明已确认范围与未验证部分。
