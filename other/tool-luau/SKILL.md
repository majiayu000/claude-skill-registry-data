# Luau 嵌入式脚本运行时 技能卡

## 基本信息

- **中文名称**：Luau 嵌入式脚本运行时
- **来源仓库**：[luau-lang/luau](https://github.com/luau-lang/luau)
- **上游参考分支**：`master`
- **参考提交（使用前核对）**：`bb15c717405696bf9fc47f5566a07e2c3e467cb2`
- **许可证线索**：MIT（含 Lua.org 版权声明）；文件：`源码\LICENSE.txt`

## 功能概览

1. 在宿主进程中运行沙箱脚本、模块和自定义 API
2. 提供字节码编译、类型分析、lint 和 REPL 工具
3. 可通过 C++ API 暴露项目状态查询与动作接口

## 适用范围

- 用于把策略、规则和可热更新编排逻辑放入受控脚本层，减少宿主重编译。

## 不能替代的边界

- 不提供 Lua 与 C#/IL2CPP 的绑定、不读取游戏内存、不执行 native Hook、协议发送或 AI 训练；脚本能运行不代表动作有效。

## 输入与输出合同

```text
输入：脚本源码/字节码、宿主注册 API、沙箱权限、输入状态快照和资源限制。
输出：脚本返回值、宿主调用事件、类型/lint 报告、运行日志和错误堆栈。
失败：语法/类型错误、超时、资源超限、未注册 API 或脚本异常时必须隔离脚本并保留输入版本。
后置：输出必须绑定项目、目标版本、平台/ABI（如适用）、时间戳和证据路径。
```

## 接入原则

1. 核对实际源码版本与说明中的参考提交后，先做最小、可撤销、可回放的接入。
2. 任何地址、线程、设备、模型、资源或协议输入都必须记录来源、版本和后置状态。
3. 工具输出是候选或观测，必须与项目专项规则、状态机和真实成功证据交叉验证。
4. 失败时保留原始错误和现场证据，不把命令退出码、识别命中或 Hook 安装当作业务成功。
5. 可与 sol2 或 xLua 作为不同 Lua 接入方案；Luau 本身不含 Unity/C# 绑定。

## 与 Codex 项目路由的边界

- `l-gameassist`：负责游戏目标、进程/设备连接和现场任务编排；本技能只提供本卡标注的工具能力，不能扩展为未登记的内存、Hook、协议或输入能力。
- `l-reverse`：负责逆向/静态或运行时证据路由；本技能的输出必须按目标版本、模块、ABI 和现场回读复核，不能把候选分析直接当作成功结论。
- `l-dev`：负责构建、依赖、配置、部署、回滚和服务维护；本技能不替代发布门禁，未完成依赖、许可证、异常恢复和回滚检查时不得发布。
