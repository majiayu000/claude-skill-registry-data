# tactical-pressure

## When to Use

当个人或团队因拖延、分心或动力不足，导致重要目标长期停滞不前，需要一种强制机制来激发高度专注和行动力时。description

## Core Logic

# 执行步骤

1.  **识别停滞目标与风险承受边界**
    *   **输入**：当前面临的核心问题或长期停滞的目标清单。
    *   **操作**：评估并选择一个对你至关重要、但一直缺乏进展的目标。同时，评估你愿意且能够承受的风险类型（如财务损失、公开承诺的压力、时间机会成本）和上限。
    *   **判断标准**：目标明确具体（如“学会技能X并接单”而非“提升自己”），风险边界清晰（如“可承受最多Y元的损失”）。
    *   **输出**：一个具体的目标陈述和个人风险承受边界定义。

2.  **设计“不成功便成仁”的约束条件**
    *   **输入**：步骤1输出的具体目标和风险承受边界。
    *   **操作**：设计一个或多个行动，这些行动将你与目标深度绑定，并移除轻松退出的选项。行动必须满足：a) 涉及你珍视的资源（金钱、时间、声誉）；b) 制造一个无法轻易撤销或忽略的“真实截止日期”或“失败成本”。
    *   **IF** 目标是技能获取或项目启动：**THEN** 可设计为“投入一笔对你而言可观、且无法轻松承担损失的金钱”（如购买昂贵工具/课程、预付项目定金）。
    *   **IF** 目标是习惯养成或输出承诺：**THEN** 可设计为“做出一个公开的、有后果的承诺”（如向客户承诺交付日期、在社交媒体公布进度、与朋友设立惩罚机制）。
    *   **判断标准**：设计的约束条件能引发明显的“生存危机感”（紧迫感、焦虑感），且失败后果是你真实希望避免的。
    *   **输出**：一个具体的、高风险的启动行动方案。

3.  **执行高风险启动行动，切断退路**
    *   **输入**：步骤2输出的高风险启动行动方案。
    *   **操作**：毫不犹豫地执行该方案。完成支付、公开承诺或签署协议。关键是在心理和事实上接受“退路已断”的状态。
    *   **判断标准**：行动已完成，相关资源已投入或承诺已不可撤销地做出。
    *   **输出**：“退路已断”的既成事实状态。

4.  **将压力转化为聚焦行动**
    *   **输入**：“退路已断”的状态和最初的目标。
    *   **操作**：利用步骤3产生的危机感和紧迫感，将全部注意力收缩到实现目标所需的具体、下一步行动上。忽略所有非核心任务与干扰。
    *   **判断标准**：注意力是否从“要不要做”转移到“如何完成”，并开始持续、专注的执行动作。
    *   **输出**：进入针对核心目标的高度专注工作流。

# 输出格式要求
向用户清晰阐述“战术压力”模型，包括其核心逻辑、适用场景、关键步骤与风险提示。格式应为结构化要点，避免冗长叙述。
