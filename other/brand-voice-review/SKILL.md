# brand-voice-review 业务诊断助手

[快速开始](https://github.com/allinherog-star/ai-skills/tree/main#%E5%BF%AB%E9%80%9F%E5%BC%80%E5%A7%8B)

[更多技能](https://ai-skills.ai)

### 概述

业务诊断助手用于回答「这件事该怎么做」、品牌调性、风格一致、PR，适合市场营销、运营、service、销售在明确业务目标、内容材料或分析对象后调用。
它会结合品牌表达样稿、可粘贴官网段落、社媒文案、品牌介绍、客服话术或活动文案；建议附上希…等输入，整理关键上下文，并输出摘要、诊断结论、行动建议和可复用交付物，便于继续执行、复盘或交付。

### 什么时候使用

**适用场景**

- 用户提出“这件事该怎么做”这类问题，需要快速拆解目标、判断重点并形成可执行结果
- 市场营销、运营、service、销售需要围绕业务诊断助手生成摘要、诊断结论、行动建议和可复用交付物
- 用户已经准备了转化目标（例如统一品牌语气、提升信任感、降低冒犯风险、强化专业感或促进咨询。）、目标人群（说明品牌表达面向的对象，例如潜在客户、合作伙伴、招聘候选人、媒体或老用户。）、品牌内容链接（填写无需登录即可访问的官网页面、品牌介绍、公开文档或社媒内容链接。），希望整理成可执行的分析或优化结果
- 用户需要把业务诊断助手相关材料转成清晰结论、优先级和下一步动作

### 参数说明

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `goal` | string | 否 | - | 例如统一品牌语气、提升信任感、降低冒犯风险、强化专业感或促进咨询 |
| `audience` | string | 否 | - | 说明品牌表达面向的对象，例如潜在客户、合作伙伴、招聘候选人、媒体或老用户 |
| `materialUrl` | string | 否 | - | 填写无需登录即可访问的官网页面、品牌介绍、公开文档或社媒内容链接；需要传可访问的完整 URL |
| `reviewDepth` | string | 否 | `标准诊断` | 诊断深度；可选值：`快速体检`、`标准诊断`、`深度改稿` |
| `brandPersona` | string | 否 | - | 例如专业可信、年轻活泼、温和克制、效率优先 |
| `materialFile` | string | 否 | - | 支持 docx、pdf、md、txt 等品牌文档，适合提交品牌手册节选、文案稿或对外话术 |
| `materialText` | string | 否 | - | 可粘贴官网段落、社媒文案、品牌介绍、客服话术或活动文案；建议附上希望保留的品牌语气 |
| `targetPlatform` | string | 否 | `通用` | 目标平台；可选值：`通用`、`社媒`、`客服`、`PR` |
| `referenceSamples` | string | 否 | - | 粘贴 1-3 段符合品牌调性的参考文案 |
| `brandRequirements` | string | 否 | - | 补充品牌性格、口吻边界、禁用表达、竞品差异和必须保留的关键词 |

完整机器可读参数结构见 `references/form-schema.json`。

### 交付内容

- 摘要、诊断结论、行动建议和可复用交付物：围绕用户目标整理可直接阅读、复盘或交付的核心结果。
- 输入材料解读：结合转化目标（例如统一品牌语气、提升信任感、降低冒犯风险、强化专业感或促进咨询。）、目标人群（说明品牌表达面向的对象，例如潜在客户、合作伙伴、招聘候选人、媒体或老用户。）、品牌内容链接（填写无需登录即可访问的官网页面、品牌介绍、公开文档或社媒内容链接。）提炼关键上下文和判断依据。
- 下一步动作：给出优先级、执行建议或可继续加工的内容框架。

### 结果使用建议

- 先判断输出是否回答了用户关于「业务诊断助手」的核心问题。
- 再检查结果是否覆盖摘要、诊断结论、行动建议和可复用交付物，以及是否给出明确下一步动作。
- 如果输入材料较少，建议让用户补充目标、受众、限制条件或原始材料后再运行。
