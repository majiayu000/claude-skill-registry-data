# Preview Landscape

- Display name: Preview Landscape

## What this skill does

- Adds a coherent planting, material and outdoor-use concept to a real site.
- Protects property geometry, paths, doors, grades and must-keep elements.

## How to use

Provide site photo, climate or location, target style, uses, maintenance level and must-keep elements.

#### Example

```text
Redesign this courtyard for a dry Mediterranean climate; keep paving and olive tree; add drought-tolerant planting and seating.
```

## Workflow

1. Map hardscape, entries, grade, sun cues, must-keep plants and usable zones.
2. Choose climate-plausible species groups, materials and circulation.
3. Edit the supplied site directly with GPT Image 2 Medium/2K, one source and one result. Never treat `ai-landscape-design-free` as a model.
4. Inspect site geometry, access, plant plausibility, scale, water implications and requested functions.

## User-facing output

- Media type: One landscape preview
- Default quantity: 1
- Content per image: The same outdoor site with one viable design direction
- Default layout: Source-preserving or dimension-defined format
- Model policy: GPT Image 2 Medium/2K for consistency-sensitive source-site editing
- Downstream use: Landscape concept planning
