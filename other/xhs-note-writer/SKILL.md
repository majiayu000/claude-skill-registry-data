# 小红书笔记创作

小红书是"生活决策搜索场+种草社区"：笔记要像真人分享，不像广告；同时为搜索流量埋词。

## 输入

产品/服务、目标人群、卖点与真实差异点、投放目的（种草/搜索卡位/商销引流/留资）、是否商业合作（蒲公英报备）、账号人设与历史风格（可选）。缺关键信息先问 1–2 个最影响方向的，其余做合理假设并标注。

## 创作 SOP

### 标题（≤20 字，给 5 个备选）

- 公式：人群/场景 + 痛点或利益 + 情绪钩子；口语化，可用 emoji（1–2 个）。
- 高点击结构：数字盘点（"5 个…"）、反差（"月薪 5k 也能…"）、避坑（"千万别…"/"后悔没早…"）、身份代入（"油皮打工人…"）、问句（"XX 到底值不值？"）。
- 埋搜索词：标题含 1 个核心品类词/场景词（用户会搜的原话，不是品牌内部术语）。
- 禁：极限词、夸大功效、标题党与正文不符（限流）。

### 正文（300–800 字为宜）

- 结构：真实场景开头（我为什么遇到这个问题）→ 体验过程（具体细节：质地/价格/使用场景/对比）→ 优缺点都说（只夸=广告感）→ 适合谁不适合谁 → 软性引导（"有问题评论区聊"）。
- 分段短、多 emoji 分隔、口语化；关键信息加【】或换行突出。
- 搜索埋词：正文自然覆盖 2–4 个相关搜索词（品类+场景+人群+平替/测评类词）。
- 种草软度：商业笔记也要有真实信息量；纯硬广直接投流不如走聚光广告组件。

### 标签（5–10 个）

- 组合：1–2 品类大词 + 2–3 场景/人群词 + 1–2 长尾词 + 品牌词（报备笔记按规范带合作标识）。

### 封面文案

- 大字报式主文案（≤12 字）+ 小字补充；与标题互补不重复；真实感图片优于精修海报（类目差异：美妆家居重审美，攻略类重信息密度）。

### 评论区

- 预埋 1–2 条自问自答（价格/链接/适合人群）；置顶补充信息；引导私信注意平台导流规则（站外导流违规）。

## 合规红线（内嵌，系统检查用 ad-compliance-cn）

- 医疗/药品/医疗器械/保健食品：普通账号不得发布功效宣称类商业内容；化妆品功效（美白/祛斑/防脱等）需特殊化妆品注册与功效评价，不得超范围宣称。
- 不得虚构使用体验、伪造对比图；商业合作须蒲公英报备（未报备商业笔记有限流/处罚风险，平台虚假种草治理常态化）。
- 极限词（最/第一/国家级/100% 有效等）、医疗用语（治疗/根治/消炎）、诱导站外交易。

## 输出格式

```
## 小红书笔记方案（目的 / 人群 / 核心搜索词）
标题×5（标注各自钩子类型）
正文（含分段与 emoji）
标签 / 封面文案 / 评论区预埋
### 合规自查：通过项 / 需用户确认项（资质/报备/功效依据）
### 发布建议：时段、合集归属、后续投流（薯条/聚光）提示
```
