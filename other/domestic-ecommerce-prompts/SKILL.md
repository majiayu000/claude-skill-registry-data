# 国内电商提示词

## Overview

把国内微信卖货和国内电商商品展示需求，整理成可直接复制到豆包的中文提示词、朋友圈文案或带货短视频脚本。优先按用户选择的单个素材类型输出，不默认生成长素材包。

## Core Workflow

1. 收集输入：商品名称、品类、目标客户、使用场景、卖点、上传图或参考图、想要风格、输出平台。
2. 先判断素材用途：商品主图、商品宣传图、商品功能细节图、朋友圈营销文案、带货短视频脚本。
3. 把商品事实和营销表达分开：能从图片或用户描述确认的内容才写进功能卖点；不能确认的功能标为待补充或弱化表达。
4. 只生成用户选择的那一类内容；用户没有要求整套时，不输出九宫格规划、群聊话术或私聊话术。
5. 输出时保持短、可复制、能直接投喂豆包或发布朋友圈。

## Image Prompt Rules

图片提示词默认使用中文，直接给豆包看。所有图片 prompt 必须包含：

- 明确说明“根据我上传的产品图/同一件产品”
- 产品还原：颜色、版型、长度、纹理、结构、图案、logo、可见细节不能乱改
- 画面用途：商品主图、商品宣传图、商品功能细节图
- 场景与构图：国内电商大牌商品展示感，干净棚拍、生活方式场景或细节近景
- 光线与比例：柔和商业布光，4:5、3:4、1:1 或 9:16
- 负面限制：不加不存在的口袋、纽扣、拉链、图案、logo、文字、水印；不生成夸张功效证明

默认图片结构：

- `商品主图`：产品第一视觉层级，干净高质感，适合微信/国内电商浏览。
- `商品宣传图`：有生活方式场景和购买理由，适合朋友圈或视频号封面。
- `商品功能细节图`：只展示可见细节和已确认功能，不编造结构、材质或功效。

通用负面限制固定使用中文：

```text
必须严格保留上传产品图里的颜色、版型、长度、纹理、结构、图案、可见细节和商品轮廓。不要改款，不要新增不存在的口袋、纽扣、拉链、图案、吊牌、logo、文字、水印或包装。不要让商品变形，不要出现多余肢体、畸形手指、错误中文、廉价广告字和虚假品牌元素。
```

## Video Prompt Rules

需要带货短视频脚本时，输出中文脚本，不使用灵途字段格式，不写英文段落。

默认脚本方向：

- 9:16 竖屏，适合微信视频号和朋友圈。
- 前 2 秒出现商品或上身效果。
- 15-25 秒短视频优先。
- 按开头、中段、转化三段写，给镜头和口播。
- 默认禁止自动字幕、屏幕文字、价格、折扣、虚假 logo、夸张特效。
- 口播中文，语气像微信私域推荐：清楚、可信、不过度喊卖。

## Copywriting Rules

朋友圈营销文案要像微信私域内容营销，不像平台详情页，也不写私聊话术。

默认输出四种文案：

- `品牌种草版`：像商品内容营销，强调质感、场景和审美理由。
- `场景痛点版`：从用户日常使用/穿搭问题切入，再连接产品卖点。
- `卖点转化版`：直接突出核心卖点、适合人群和咨询动作。
- `短句朋友圈版`：适合朋友圈快速发布，短句、有节奏、不吆喝。

文案必须：

- 用中文。
- 突出产品特点和适合人群。
- 有营销结构，但不要土味吆喝、不要“姐妹冲”“闭眼入”“老板娘推荐”这类廉价口吻。
- 说人话，避免空泛词和平台详情页腔调。
- 不编造销量、评价、库存、折扣、认证、材质比例或无法确认的功能。
- 有明确行动：留言或联系看细节图、颜色、上身效果、视频。
