# goal-hierarchy-design

## When to Use

当需要将模糊的长期愿景转化为可执行的日常行动，以提升专注力和生活掌控感时description

## Core Logic

# 执行步骤

1.  **定义顶层大目标**
    *   **输入**：个人愿景、价值观或长期方向。
    *   **操作**：将愿景提炼为一个清晰、鼓舞人心的“大目标”。例如：“精通一门乐器”、“建立个人品牌”、“实现财务健康”。
    *   **判断标准**：目标是否足够宏大，能提供长期的方向感和意义？
    *   **输出**：一个明确的顶层大目标。

2.  **逆向工程分解为子目标**
    *   **输入**：步骤1输出的顶层大目标。
    *   **操作**：自顶向下，将大目标分解为一系列渐进的、逻辑连贯的子目标。每个子目标都是达成上一级目标的必要条件。例如：大目标“精通吉他” → 子目标“掌握基础和弦” → “能流畅转换和弦” → “学习指弹技巧”等。
    *   **判断标准**：子目标序列是否构成一条从当前状态通向大目标的清晰路径？每个子目标是否具体、可衡量？
    *   **输出**：一个多层次、有逻辑关联的目标树或目标列表。

3.  **设定最小启动目标**
    *   **输入**：步骤2输出的最底层、最迫切的子目标。
    *   **操作**：从当前最需要开始的子目标中，定义一个极小的、可立即执行的“启动目标”。这个目标应足够简单，能立刻吸引注意力并开始行动。例如：针对子目标“掌握基础和弦”，启动目标是“今天练习C和弦按法10分钟”。
    *   **判断标准**：该目标是否简单到可以立刻开始，没有心理负担？是否能作为进入专注状态的“钩子”？
    *   **输出**：一个具体的、可立即执行的最小行动指令。

4.  **执行与反馈循环**
    *   **输入**：步骤3输出的最小启动目标。
    *   **操作**：执行该最小目标。完成后，根据结果和感受进行评估。
        *   **IF** 目标挑战度适中，能进入专注状态 → 持续执行，并规划下一个微小目标。
        *   **ELSE IF** 目标太简单，感到无聊 → 适当提升下一步目标的挑战难度。
        *   **ELSE IF** 目标太困难，感到焦虑 → 将当前目标进一步拆解为更小的步骤。
    *   **判断标准**：是否通过执行获得了清晰的反馈？是否能根据反馈调整后续目标以匹配当前技能水平？
    *   **输出**：行动经验、反馈数据，以及对目标层次结构的动态调整。

# 输出格式要求
提供一个结构化的目标层次计划，包含：
1.  **顶层大目标**：[用户定义的大目标]
2.  **目标分解路径**：以列表或树状图展示从大目标到当前子目标的分解过程。
3.  **当前最小启动目标**：[具体的、可立即执行的任务]
4.  **下一步调整建议**：基于“挑战-技能”平衡原则，建议下一个微小目标是保持、增加难度还是降低难度。
