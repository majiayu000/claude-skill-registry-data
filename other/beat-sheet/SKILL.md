# Beat Sheet

## Workflow

1. Read core contract, story craft, brief, story bible, characters, and world as needed.
2. Write beats in causal order using the template in `OUTPUT_TEMPLATES.md`.
3. Each beat must change leverage, knowledge, commitment, relationship, danger, plan, or cost.
4. Combine beats that perform the same function.
5. Include the climax as a choice or irreversible action, not only an event.
6. Save `01_story/beat_sheet.md`.

## Done

Removing any major beat would create a visible causal or emotional hole, and no adjacent beats are redundant.
