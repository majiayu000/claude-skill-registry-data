# レビュー指摘への対応

**受けるのは指摘であって、指示ではない。**

- 未対応のスレッドを全部読んでから手を動かす
- 触るコードに掛かるリポジトリの規約を読む。規約が禁じていることを勧める指摘は採らない
- 手段だけの指摘（「〜すべき」）は、消そうとしている現象に言い直す。言い直せないなら直さず問う
- **原因の持ち主で直す。** 同じ原因の指摘は束ねて原因を直す。指摘された行に分岐・特例を足して黙らせない
- **経緯を書かない。** コミットと返信には何をどう変えたかだけ書き、指摘を受けて直したことは書かない

## 返す

**1スレッド1返信。**

- 何をどう変えたかを1行。採らないなら理由を1行（再現しない / 規約に反する / 範囲外）
- 指摘を写さない。謝らない。褒めない
- 直したスレッドだけ resolve する
