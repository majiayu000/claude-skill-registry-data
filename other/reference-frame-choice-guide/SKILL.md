# 参考系选择向导 / Reference Frame Choice Guide

换参考系不改变物理，只改变**哪些东西看起来简单**。这个 skill 帮你把这句话变成
一张可以逐项对照的表：换了之后要付什么代价，换了之后什么仍然成立。

强制产物是那张**不变量清单**。看清"换系后哪些量根本没动"，就是在看这个问题的本质
有多少是坐标选择带来的假象。

## 何时使用 / When to use

- 在地面系里方程很长，怀疑换个系会短很多
- 题目里有加速的车厢、转动的圆盘、下滑的斜面
- 两体碰撞、散射，想知道质心系值不值得
- 换过系但结果不对，怀疑漏了惯性力或忘了换初条件
- 想说清"这个结论是物理的还是坐标造成的"

**不适用于** / Not for：

- 还没分清过程有几个阶段 —— 先用 `problem-representation-scout`
- 还没确定该用哪条定律 —— 用 `problem-formalization-coach`
- 想要有人把换系后的方程解出来 —— 本 skill 不解

## 需要的输入 / Inputs

| 输入 | 必填 | 说明 |
|---|---|---|
| 问题与要求的量 | 是 | 要求的量**在哪个参考系里**——这一条最常被忘，必须写明 |
| 现有的写法 | 否 | 已经在哪个系里列了什么方程 |
| 速度量级 | 否 | 用来判断是否需要相对论；不确定就问 |

## 一、三种"换系"要分开 / Three different changes

它们的后果完全不同，混起来是最常见的错误来源。

| 操作 | 变的是 | 牛顿定律 |
|---|---|---|
| **坐标轴旋转 / 平移** | 只是分量。矢量本身、所有标量（质量、能量、`|v|`）都不变 | 不变 |
| **伽利略变换**（惯性系 → 另一个惯性系，相对速度 `V` 恒定） | 位置、速度、动量、动能、角动量、功都变 | 形式不变，无惯性力 |
| **换到非惯性系**（加速平移或转动） | 加速度也变 | **形式改变**，必须补惯性力 |

## 二、非惯性系里的惯性力 / Pseudo-forces

设参考系原点以 `A` 加速、并以角速度 `ω` 转动（`ω` 可随时间变）：

```
m a' = F − mA − 2m ω×v' − m ω×(ω×r') − m (dω/dt)×r'
              平动惯性力    科里奥利力      离心力            欧拉力
```

`v'`、`r'` 都是**在转动系里量的**。把地面系的速度代进科里奥利项是高频错误。

三条必须记住的性质：

1. **科里奥利力不做功**：`F_cor·v' = −2m(ω×v')·v' = 0`。它改变方向，不改变速率。
2. **离心力是保守的**（`ω` 恒定时），势能 `U_cf = −½ m ω² r_⊥²`，`r_⊥` 是到转轴的距离。
   所以在匀速转动系里可以写能量守恒，但**必须把这一项算进势能**。
   完整的守恒量是雅可比积分 `E' = ½mv'² + U(r') − ½mω²r_⊥²`（要求约束不显含时间）。
3. **欧拉力做功**，`ω` 变化时不能用上面的能量写法。

## 三、换系后什么不变 / The invariance checklist

**这是本 skill 的强制产物。** 每次给建议都要填这张表。

### 伽利略变换（惯性系之间）

| 不变 | 改变 |
|---|---|
| 质量、时间间隔、同时事件的空间距离 | 位置、速度、动量、角动量 |
| 加速度、力 | 动能、功、功率 |
| 相对位置、相对速度 | — |
| **每条守恒律成立与否** | 守恒量本身的数值 |

一条容易被忽略但很有用的推论：

> **总动量守恒的封闭系统，其动能的变化量 `ΔT` 是伽利略不变的。**
> 由 `T' = T − V·P + ½MV²`，`P` 与 `M` 不变时两个系里的 `ΔT` 相同。

这正是"弹性碰撞在一个惯性系里成立就在所有惯性系里成立"的原因。
反过来说：**单个物体受外力时，功和 `ΔT` 都是依赖参考系的**——
"在地面系里摩擦生热 `Q`，在车厢系里怎么变了"这类困惑，
根源是把开放子系统当成了封闭系统，把另一半物体漏掉了。

### 坐标轴旋转（同一参考系内）

标量全不变，矢量本身不变，**只有分量变**。如果一个"结论"在换个坐标轴之后就没了，
那它本来就不是物理结论。

### 换到非惯性系

| 仍然成立 | 不再自动成立 |
|---|---|
| 质量、时间间隔 | 动量守恒（惯性力是外力） |
| 加了惯性力之后的 `F = ma'` | 机械能守恒（除非用雅可比积分那种写法） |
| — | 角动量守恒 |

**"在非惯性系里动量还是守恒的"是错的。** 惯性力对系统而言是外力。

### 角动量的两个下标

角动量同时依赖**参考点**和**参考系**，两者必须分别写明。一条有用的事实：

> 总动量为零的参考系（质心系）里，角动量与参考点的选取无关
> （因为换点相差 `Δr × P = 0`）。

## 四、候选参考系对照 / Candidate frames

| 参考系 | 消掉了什么 | 付出的代价 | 适合 |
|---|---|---|---|
| **地面系** | — | 无惯性力 | 大多数题；先默认它，除非有理由换 |
| **随某物体平动的系** | 该物体的速度（它静止） | 若该物体加速，全体加 `−mA` | 追及、相对运动、车厢内的实验 |
| **质心系** | 总动量（`P = 0`） | 若质心加速，是非惯性系 | 两体碰撞与散射：柯尼希 `T = ½MV_cm² + T_rel`；两体问题用约化质量 `μ = m₁m₂/(m₁+m₂)` 降成单体；弹性碰撞在质心系里只是速度方向转了个角 |
| **转动系** | 旋转本身 | 三个惯性力；速度必须换成 `v'` | 圆盘上的运动、旋转机械、大尺度地球流动 |
| **斜面系 / 沿约束方向的坐标** | 一个约束方向（运动只沿一个坐标） | 斜面加速时是非惯性系 | 滑块–斜面、约束面运动 |
| **随波传播的系** | 波的传播 | 只对无色散、单一波速有效 | 波包、激波 |

选系的判据按优先级：

1. **约束能不能变简单**——把"沿斜面运动"变成"某个坐标恒为零"，收益通常最大。
2. **能不能消掉一个未知速度**——随某物体平动的系直接消一个。
3. **有没有守恒量因此出现**——质心系里 `P = 0` 是白拿的一条方程。
4. **要付几个惯性力**——转动系要付三个，且科里奥利项引入耦合。

代数复杂度可以粗估：**项数 ≈ 原方程项数 − 消掉的项 + 惯性力项数 + 因耦合新增的交叉项**。
转动系常常"看起来简洁、算起来更长"，因为科里奥利项把两个方向耦合起来了。

## 五、什么时候伽利略变换本身就不能用

| 判据 | 门槛 | 换成什么 |
|---|---|---|
| `β = v/c` | `β = 0.1` 时 `γ − 1 ≈ 0.5 %`，`β = 0.5` 时 `≈ 15 %` | 洛伦兹变换；速度不再相加，用 `u' = (u−v)/(1−uv/c²)` |
| 涉及光在真空中的传播 | 任何速度 | **真空中没有介质提供优先参考系**，声学多普勒公式不能照搬 |
| 需要判断"同时" | `β` 不可忽略 | 同时性依赖参考系 |

相对论下的不变量换成：时空间隔 `s² = c²t² − r²`、静质量（`E² − p²c² = m²c⁴`）、
固有时、电荷、波的相位；电磁场则是 `E² − c²B²` 与 `E·B`。
**长度、时间间隔、能量、动量都不是不变量。**

## 六、六个高频翻车 / Common failures

1. **非惯性系里写机械能守恒却漏了惯性力做的功。** 离心力那一项必须写成势能，
   欧拉力存在时干脆不能这么写。
2. **换了系没换初条件。** 初速度、初位置都要在新系里重新写一遍。
3. **把参考点和参考系混为一谈。** 角动量需要两个下标。
4. **默认地面系是惯性系。** 判据是罗斯贝数 `Ro = U/(fL)`，`f = 2Ω sinφ`。
   实验室尺度 `Ro ≫ 1`，可以忽略；大尺度长时间（气旋、洋流、远程弹道、傅科摆）不行。
5. **在转动系的科里奥利项里代入了地面系的速度。**
6. **"惯性力是虚构的，所以可以不管。"** 在该参考系里它的效应是真实可测的
   （傅科摆、离心分离、地转偏向）。虚构指的是它没有反作用力对，不是它没效果。

## 边界 / Boundaries

- **不解题**：不写出换系后的完整方程组，不求解。
- **不替使用者选系**：给对照表和推荐理由，选择由本人做。选择本身是要被评分的能力。
- **不省略不变量清单**：这是本 skill 的强制产物，不能因为"显然"而跳过。
- **不含糊处理相对论门槛**：`β` 未知时问清楚，不默认非相对论。
- **不越过诚信闸**：作业与竞赛进行中只给判断依据，不给结果。

## Token 控制 / Token discipline

- 只对照真正有意义的两三个候选系，不穷举
- 不变量清单只列与本题结论相关的量
- 交接只带推荐、代价与不变量清单
