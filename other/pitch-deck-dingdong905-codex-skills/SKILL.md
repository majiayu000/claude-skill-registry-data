# 融资路演

与 `Presentations` 组合使用。根据阶段和投资人类型调整权重，常用故事线为：问题 → 解决方案/产品 → 为何现在 → 市场 → 采用或验证 → 商业模式 → 竞争与护城河 → 增长计划 → 团队 → 融资需求与里程碑。

- 开头迅速说清服务谁、解决什么高价值问题，以及已有何种验证。
- TAM、SAM、SOM 不得只给大数；写明口径、假设和可触达路径。
- 牵引指标保留时间范围、分母、是否累计和数据来源。
- 竞争页以客户选择标准比较，不用没有证据的二维象限制造唯一优势。
- 团队页只强调与执行风险相关的经历。
- 融资需求关联 runway、用途和可验证里程碑。
- 没有数据时明确写验证计划，不虚构客户、收入、合作或增长。

交付前使用 `deck-review`，重点检查可证实性、指标口径、视觉可信度和问答风险。


需要组织问题、价值、证明与融资页面时，按需读取 [叙事与布局参考](references/persuasion-and-layout.md)，继续使用现有构建与验证流程。
