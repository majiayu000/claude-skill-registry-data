# search-jd

## 目标
在用户需要京东商品、价格、评价或店铺信息时，通过只读搜索和页面读取整理商品详情、当前价、评价摘要、链接和可验证来源。

## 适用请求
- 搜索京东商品、品牌型号、店铺或同款商品。
- 读取京东商品详情、京东价格、评价摘要和规格参数。
- 对比京东与其他平台当前价和促销条件。

## 首选通道
- skill-only：默认复用用户当前已打开且已登录的 Firefox 会话，用 `firefox.exe -new-tab <京东 URL>` 打开搜索页或商品页。
- 公开线索使用 WebSearch/WebFetch；登录后内容只从当前 Firefox 可见页面、用户复制文本或截图/OCR 取证。
- 不新增或依赖 MCP；可选京东联盟 API 只有在用户已配置且明确要求时才只读使用。

## 兜底通道
- 使用 WebSearch 查询商品标题、型号和 `site:jd.com` 结果。
- 使用浏览器只读打开京东页面；遇到登录、验证码、地区或风控限制时请求用户人工处理。

## 操作流程
1. 明确商品关键词、型号、规格、地区、是否需要自营/旗舰店和价格范围。
2. 优先用 WebSearch/WebFetch + 当前 Firefox 已登录会话做只读检索和详情读取。
3. 浏览器读取详情时，全程只读搜索/读取，不下单、不私信、不发帖、不写入平台，也不加购、领券、关注店铺、咨询客服或评价。
4. 记录标题、SKU/商品 ID、当前价、促销条件、店铺、评价摘要、参数、URL 和检索时间。
5. 对价格和优惠标注条件，必要时提示用户人工确认到手价。

## 只读安全边界
- 只搜索、打开、读取和总结京东公开或授权可见页面。
- 不发起新的京东登录流程；用户确认已登录时直接复用当前 Firefox 会话，不绕过验证码、风控、地区或会员限制。
- 不加购、不下单、不付款、不领券、不关注、不咨询客服、不评价、不发布内容。
- 不写入 Cookie、Token、收货地址、支付信息或联盟密钥。

## 验证方式
- 后续可运行：`dir C:\Users\Zhang\.config\opencode\skills\search-jd\SKILL.md`
- 人工检查：确认流程为 skill-only + 当前 Firefox 会话复用，不依赖 MCP。

## 已知限制
- 京东价格、库存、优惠和配送地区强相关，结果可能随时间和地址变化。
- 评价详情可能需要登录或分页加载。
- 京东联盟 API 需要用户已有配置；本 skill 不写入密钥。
