# life-chapter-cycle

## When to Use

当感到生活迷茫、停滞不前，需要理解当前所处阶段并规划下一步行动时description

## Core Logic

# 执行步骤

1.  **识别当前阶段**：回顾近期（如过去1-3个月）的主要感受、动力水平和目标进展。
    *   **输入**：个人近期状态描述。
    *   **输出**：判断当前处于“停滞”、“愿景”、“流动”、“阻力”四阶段中的哪一个。
    *   **判断标准**：能清晰地将主要特征（如迷茫/无方向、有想法/有动力、专注/高效、进步放缓/抗拒改变）与某一阶段对应。
    *   **常见误区**：将正常的“阻力”阶段误判为“停滞”，或将短暂的疲惫误判为长期“停滞”。

2.  **执行阶段应对策略**：
    *   **IF** 当前阶段为“停滞”：
        1.  **接受状态**：承认“感到迷茫”是开启新篇章的正常起点，而非失败信号。
        2.  **拒绝不作为**：明确意识到“什么都不做”是维持停滞的最差选择，必须启动探索。
        3.  **输出**：一个“必须启动探索”的明确决定。
    *   **IF** 当前阶段为“愿景”：
        1.  **保护与培育**：记录并细化新出现的想法和图景，避免因不确定性而否定它。
        2.  **积累动力**：采取小行动验证愿景，积累正向反馈。
        3.  **输出**：一个更清晰的愿景描述和一组初步的验证行动。
    *   **IF** 当前阶段为“流动”：
        1.  **沉浸与维护**：保持当前的工作节奏和环境，最大化产出和心流体验。
        2.  **输出**：维持“流动”状态的计划。
    *   **IF** 当前阶段为“阻力”：
        1.  **识别阻力来源**：分析是外部条件限制，还是内心对阶段结束的抗拒。
        2.  **决策**：决定是寻找新方法突破瓶颈，还是接受本章节尾声，准备开启新循环。
        3.  **输出**：关于“突破”或“过渡”的决策。

3.  **规划下一阶段过渡**：基于当前阶段和应对策略的输出，预见并准备进入下一阶段。
    *   **输入**：步骤2的输出（决定、计划或决策）。
    *   **输出**：一个针对预期下一阶段的初步准备思路（例如，若从“停滞”启动探索，则准备进入“愿景”阶段的素材收集方法）。
    *   **判断标准**：输出能体现对生活章节循环动态演进的理解，而非静态计划。

# 输出格式要求

向用户清晰说明：
1.  根据其描述，判断其当前所处的“生活章节”阶段（停滞/愿景/流动/阻力）。
2.  给出针对该阶段的核心行动建议。
3.  提醒下一阶段可能是什么，以及可以提前做何准备。
