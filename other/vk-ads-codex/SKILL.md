# VK Ads: техническая работа

Сначала установите тип задачи и кабинет: рекламодатель, агентство/клиент, менеджер или партнёр монетизации. Не подменяйте VK Рекламу старым рекламным API социальной сети. Интерфейс `/hq` и `sudo` описывают контекст браузера, но не являются OAuth-правом API.

1. Зафиксируйте цель, сущности, период, единицы метрик и разрешённые действия. Прочитайте доступный проектный контекст.
2. Найдите официальный источник через [карту документации](references/documentation-map.md) и `scripts/find_sources.py QUERY`; открывайте только необходимые страницы.
3. Для API прочитайте [контракт API](references/api-contract.md); для кампаний — [операции](references/account-and-campaigns.md); для оценки результатов — [измерение](references/measurement.md).
4. Для конкретного объекта используйте [маршрутизацию объектов](references/object-routing.md). Лид-формы рассмотрены отдельно в [интеграциях](references/lead-integrations.md).
5. Подготовьте конкретный план изменения с текущими и целевыми значениями. Если разрешена запись, сохраните исходное состояние, проверьте зависимости, выполните минимальную операцию и перечитайте результат. При неопределённом ответе сначала ищите созданный объект; не повторяйте POST автоматически.
6. Отдайте результат с URL/ID в приватном отчёте, датой, источниками, проверками и нерешёнными расхождениями. Публикация проекта не означает запуск рекламы.

Реестр источников перечисляет охват официального индекса, а не гарантирует неизменность каждой страницы. Наличие URL в реестре не заменяет чтение текущего контракта. [Журнал расхождений](references/conflicts.md) имеет приоритет перед упрощёнными примерами.

## Источники и границы

Проверено 2026-09-09. Числа в справке и интерфейсе могут меняться. Перед записью в кабинет заново откройте нужную официальную страницу и сравните с текущим полем. Метки: **DOC** — официальная документация; **UI** — наблюдение редактора на дату проверки; **RECOMMENDATION** — авторская методика; **UNKNOWN** — не подтверждено. Наблюдение UI не доказывает прохождение серверной валидации или модерации.

Работайте в рамках текущего запроса. Аудит и подготовка текста не разрешают сохранение формы, отправку тестового лида, настройку получателей, запуск кампании или изменение бюджета. Если такая операция уже явно разрешена, не спрашивайте повторно. Не отправляйте заявки ради проверки без разрешённого теста. Форма может использоваться несколькими кампаниями: перед изменением проверяйте связи. Не публикуйте данные кабинета, лиды, скриншоты аккаунта, реальные контакты и секреты в общий пакет.
