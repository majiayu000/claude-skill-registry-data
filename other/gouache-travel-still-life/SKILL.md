# Gouache Travel Still Life

## Delivery and mode selection

- Produce one standalone 3:4 vertical poster per source image. Never combine photos.
- Offer three modes when the user has not already chosen:
  1. **Split still life** — real source photo above, extracted gouache still life below.
  2. **Full-canvas still life** — the entire poster becomes a recomposed object archive.
  3. **Full-scene painting** — preserve the source composition and repaint the complete scene in opaque gouache.
- Use one mode for all uploaded photos unless the user maps modes per image.
- Read only the selected guide: [split-still-life.md](references/split-still-life.md), [full-canvas-still-life.md](references/full-canvas-still-life.md), or [full-scene-painting.md](references/full-scene-painting.md).
- Return a ready-to-use prompt only when explicitly requested; otherwise use the available image generation or editing capability.

## Shared visual rules

Use truly opaque, matte, high-coverage gouache with restrained acrylic and dry-brush texture. Derive the palette entirely from the current source image; never impose a fixed color card or add unrelated bright hues. Preserve visible bristles, paint-thickness variation, modest dry gaps, rough handmade edges, a few searching lines, exposed paper, and paper-white highlights without becoming dirty or chaotic.

Keep subjects immediately recognizable and never invent objects, places, brands, signs, people, animals, or scenery. Text, when the selected mode includes it, must be locked before rendering from visible facts only: a short English title, a simple study identifier, and a brief observation. Never guess a location, date, brand, relationship, or attribution.

## Avoid

Transparent watercolor, photo filters, same-crop low-resolution redraws, photoreal painting, smooth gradients, airbrush, vectors, oil impasto, plastic 3D, cartoons, children's coloring-book styling, copied signs, fake labels, unreadable type, polished floating digital text, excessive decoration, logos, QR codes, watermarks, and garbled text.
