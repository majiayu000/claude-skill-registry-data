# anti-niche-validation

## When to Use

当需要评估一个商业想法或服务方向是否适合自己时，特别是面临“选择一个利基市场”的传统建议压力时description

## Core Logic

# 执行步骤

1.  **评估内在兴趣与契合度**
    - **输入**：潜在的商业想法或服务方向列表。
    - **操作**：针对每个方向，自问：“我是否对这个方向本身（其问题、客户、工作内容）有真正的兴趣和热情？我是否愿意长期沉浸其中？”
    - **判断标准**：能够明确区分出“感兴趣/有热情”和“不感兴趣/仅为赚钱”的方向。成功标准是识别出至少一个能激发你内在动力的方向。
    - **IF** 对所有方向都缺乏兴趣 → **THEN** 返回步骤1，重新构思或寻找新的方向，直到找到至少一个感兴趣的方向。
    - **ELSE** (至少对一个方向有兴趣) → **THEN** 进入步骤2。

2.  **评估经验与问题理解深度**
    - **输入**：从上一步筛选出的、你感兴趣的方向。
    - **操作**：针对每个感兴趣的方向，自问：“我是否亲身经历过这个方向试图解决的核心问题？我对其痛点、背景和细节有多深的理解？”
    - **判断标准**：能够清晰陈述该方向的核心问题，并基于个人经历或深度观察描述其具体表现。成功标准是确认你对该问题有第一手或深刻的二手理解。
    - **IF** 对感兴趣的方向缺乏相关经验或问题理解 → **THEN** 考虑暂停将其作为商业启动方向，转而通过工作、研究或项目积累相关经验，或返回步骤1。
    - **ELSE** (对某个方向既有兴趣又有相关经验/理解) → **THEN** 进入步骤3。

3.  **评估策略重心：从“寻找”转向“吸引/成为”**
    - **输入**：通过前两步验证的、兼具兴趣与经验的方向。
    - **操作**：审视你为该方向设想的客户获取策略。判断其重心是放在主动“寻找”客户（如冷推销、广撒网），还是放在通过分享专业知识、构建作品或解决特定问题来“吸引”客户，或“成为”该领域的公认专家。
    - **判断标准**：能够制定一个初步计划，其中超过50%的精力将投入于创造价值内容、构建解决方案原型或深化专业能力，而非单纯的客户搜寻。成功标准是策略重心明显偏向价值创造与专业建立。
    - **IF** 策略仍以“寻找客户”为核心 → **THEN** 重新设计策略，将重点调整为如何展示你的专业知识和解决方案价值，以吸引客户主动咨询。
    - **ELSE** (策略重心已调整至“吸引/成为”) → **THEN** 该方向通过验证，可作为优先启动选项。

# 输出格式要求
向用户清晰呈现评估结果，结构化输出：
1.  **评估结论**：明确说明哪个（或哪些）方向通过了三步验证，哪个方向在哪个环节被否决及原因。
2.  **通过验证的方向详情**：对于通过的方向，总结其兴趣点、经验依据以及初步的“吸引/成为”策略要点。
3.  **后续行动建议**：建议用户立即对通过验证的方向开始执行“吸引/成为”策略中的第一项具体行动。
