# GitHub etiquette

Before filing, check whether a PR for this issue exists.

Review the diff locally against origin/main to make sure
its contents match the goal.

PR titles usually become commit messages, so make the title
concise, human-readable, and explain why the change matters.

Open the description with a simple explanation of the problem
then briefly explain the solution. Don't lead with an implementation
inventory.
