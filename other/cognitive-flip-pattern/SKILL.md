# cognitive-flip-pattern

## When to Use

当观察到或经历某种极端转化现象，或试图主动促成根本性观念转变时description

## Core Logic

# 执行步骤

1.  **识别对立两极**：明确当前认知或状态光谱的两个极端端点。
    *   **输入**：一个具体的观念、情感状态、行为模式或社会评价。
    *   **判断标准**：能定义出该光谱上截然相反的两个端点（如“完全相信”与“完全不信”、“极度喜爱”与“极度厌恶”）。
    *   **输出**：清晰定义的A极与B极。

2.  **定位当前状态**：判断个体或事物在当前光谱上的大致位置。
    *   **输入**：步骤1定义的对立两极（A极和B极）。
    *   **判断标准**：能基于证据（言论、行为、感受）将当前状态归类为更接近A极、更接近B极，或处于中间渐变地带。
    *   **输出**：当前状态在光谱上的定性位置。

3.  **观察或施加极端张力**：分析或主动创造使当前状态趋向某一极端的条件，直至达到承受极限。
    *   **输入**：步骤2的当前状态定位。
    *   **判断标准**：能识别出导致状态向某一端持续发展的压力源（如持续的失败、极度的厌倦、反复的质疑），或能设计施加此类压力。
    *   **输出**：识别出“张力源”及其所推动的方向（推向A极或B极）。
    *   **IF** 当前状态更接近A极，且张力将其进一步推向A极的极致 → 进入“推向极致”状态。
    *   **ELSE IF** 当前状态更接近B极，且张力将其进一步推向B极的极致 → 进入“推向极致”状态。
    *   **ELSE** 张力不足或方向不明 → 无法触发翻转，返回步骤2或调整张力源。

4.  **判断翻转临界点**：监测“厌倦”或“无法忍受”的极点信号。
    *   **输入**：“推向极致”状态。
    *   **判断标准**：出现情感或认知上的彻底疲惫、排斥，认为当前极致状态荒谬、不可持续。
    *   **输出**：是否达到“临界点”的判断。
    *   **IF** 检测到明确的“极致性厌倦”或“认知超载”信号 → 达到临界点，可能触发翻转。
    *   **ELSE** → 未达临界点，继续步骤3的过程。

5.  **促成或识别翻转**：在临界点后，观察或引导认知向对立极的跳跃式转变。
    *   **输入**：达到临界点的判断。
    *   **判断标准**：观察到观点、态度或行为发生突然的、根本性的逆转，从一极跳转至另一极。
    *   **输出**：确认“认知翻转”是否发生，并描述新状态（位于原对立极）。
    *   **IF** 发生根本性转变，新状态稳定 → 翻转完成。
    *   **ELSE IF** 发生摇摆或部分转变 → 翻转未完全，可能需经历多个周期。

# 输出格式要求
以过程报告形式输出：
1.  识别出的对立两极。
2.  初始状态定位。
3.  施加的张力或观察到的压力源。
4.  临界点判断依据。
5.  翻转结果描述（是否发生及新状态）。
