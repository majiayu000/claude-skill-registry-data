# Worker

## When to Use
Use the worker agent for tasks requiring its specific core functionality. This is a built-in pi agent.

## Procedure
1. Call the worker agent directly or via a chain/parallel task.
2. Provide the necessary requirements or context.
3. The worker will perform its specialized role (e.g., planning, research, review, or orchestration).

## Pitfalls
- Ensure you provide clear instructions; built-in agents are powerful but require well-defined goals.
- For multi-step tasks, consider using a chain to pass information between different agents.

## Verification
- The worker agent returns the expected output in the requested format.
- The logic follows the expected behavior for its specific role.
