# Notion Template Processor

Use this skill when the end state should be reusable inside Notion rather than only free-form markdown.

## Workflow
- Identify the recurring structure in the raw content.
- Map it into a stable template shape.
- Return Notion-friendly markdown or block structure.

## Deliverables
- A reusable Notion template or processed page layout.
- Suggested database properties if relevant.

## Guardrails
- Do not over-template one-off content.
- Do not hide important nuance in generic placeholders.
