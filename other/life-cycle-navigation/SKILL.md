# life-cycle-navigation

## When to Use

当意识到自己处于长期迷茫、缺乏动力阶段，需要系统性方法走出困境时description

## Core Logic

# 执行步骤

1.  **状态诊断与实验类型选择**
    *   **输入**：对自身当前情绪、能量水平和社交偏好的觉察（如：是否感到空虚、是否渴望与人交流）。
    *   **操作**：判断当前更适合“内向实验”还是“外向实验”。
        *   **内向实验**：偏向独处、内省、自学、创作。
        *   **外向实验**：偏向与他人交流、合作、参与社群、寻求反馈。
    *   **判断标准**：能够根据自身状态明确选择一种初始实验类型。
    *   **输出**：选定的实验类型（内向/外向）。

2.  **设计并执行针对性实验**
    *   **输入**：步骤1选定的实验类型。
    *   **操作**：
        *   **IF** 选择“内向实验”，**THEN** 设计一个可独立完成的项目，如：学习一门新知识并整理笔记、创作一件作品（文章、视频、代码）、解决一个个人效率问题。
        *   **IF** 选择“外向实验”，**THEN** 设计一个需要外部互动的行动，如：加入一个相关的线上社群并参与讨论、向一位该领域的人士请教、发起或参与一次线下活动。
    *   **判断标准**：实验设计具体，且已按计划启动执行。
    *   **输出**：实验过程的记录、产生的作品或获得的社交反馈。

3.  **评估反馈与周期过渡**
    *   **输入**：步骤2的实验记录和反馈。
    *   **操作**：分析实验是否激发了持续的好奇心或带来了成就感。
        *   **IF** 实验激发了强烈兴趣，**THEN** 判定为从“迷茫期”进入“好奇期”，后续应围绕该兴趣点深化（可衔接 `natural-compass-navigation` 模型的步骤3）。
        *   **IF** 实验未激发兴趣，**ELSE** 判定仍处于“迷茫期”，返回步骤1，考虑切换实验类型或更换实验主题，重新开始。
    *   **判断标准**：明确判断个人状态是否发生了从“迷茫”到“好奇”的周期转换。
    *   **输出**：对个人所处生活周期的更新判断（迷茫期/好奇期）及相应建议。

# 输出格式要求
以周期视角进行总结：
- **诊断结论**：当前所处宏观周期（迷茫期/好奇期/着迷期）。
- **实验回顾**：上一轮实验的类型与关键发现。
- **周期建议**：
    - 若处“迷茫期”：建议下一轮实验的类型与潜在主题。
    - 若处“好奇期”：建议如何聚焦并深化探索。
