# idea-filter-framework

## When to Use

当面临信息过载或想法过多，需要筛选出值得投入资源（时间、精力）去执行的高价值想法时description

## Core Logic

# 执行步骤

1.  **定义个人筛选框架（“哲学”）**
    *   **输入**：个人对价值观、长期目标、生活准则的思考。
    *   **操作**：用书面形式明确回答以下问题（至少各一个）：
        *   **价值观**：我最看重什么？（如：创造、自由、影响力、家庭）
        *   **愿景**：我3-5年后想成为什么样的人/达到什么状态？
        *   **核心目标**：我当前阶段（如未来12个月）最重要的1-3个目标是什么？
    *   **判断标准**：答案具体、清晰，能够作为判断依据。
    *   **输出**：一份书面的个人筛选框架声明。

2.  **收集与初步评估想法**
    *   **输入**：待筛选的想法列表（来自灵感、机会、任务等）。
    *   **操作**：为每个想法填写一个简单的评估表，包含：
        *   想法描述。
        *   预估所需资源（时间、精力、金钱）。
        *   与步骤1中定义的“价值观”、“愿景”、“核心目标”的关联度评分（1-5分）。
    *   **判断标准**：所有待评估想法均完成了基础信息填写和关联度评分。
    *   **输出**：一份带有初步评分想法的评估列表。

3.  **应用过滤器进行决策**
    *   **输入**：步骤2生成的评估列表；步骤1定义的筛选框架。
    *   **操作**：
        *   **IF** 一个想法与“核心目标”的关联度评分 >=4，**THEN** 将其标记为“高优先级”，进入详细规划。
        *   **ELSE IF** 一个想法与“长期愿景”关联度 >=4 且与“价值观”高度契合，但偏离当前核心目标，**THEN** 将其放入“孵化池”或分配极少资源进行探索。
        *   **ELSE IF** 一个想法与上述框架关联度均低（<3），**THEN** 明确拒绝或搁置。
        *   **ELSE** (关联度中等)，**THEN** 进一步分析：能否调整该想法，使其更符合框架？如果能，调整后重新评估；如果不能，搁置。
    *   **判断标准**：每个想法都有明确的决策结果（执行/探索/拒绝/搁置）。
    *   **输出**：一份分类清晰（高优先级、孵化、拒绝）的想法决策清单。

# 输出格式要求
向用户呈现一个结构化的决策看板，包含：
1.  用户的个人筛选框架摘要。
2.  所有评估想法的分类列表（表格形式），并附上关键决策理由。
3.  明确的下一步行动建议（针对高优先级想法）。
