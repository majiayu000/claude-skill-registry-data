# 达人筛选与投放评估

达人投放的本质：买"信任关系+内容能力+人群匹配"，不是买粉丝数。腰尾部 KOC 矩阵常比头部单点 ROI 更稳。

## 数据契约

平台与预算、产品/人群/目标（种草/带货/搜索卡位）、候选达人清单或导出数据（粉丝数、报价、近期笔记/视频的阅读/互动/播放中位数、粉丝画像、历史商单表现）；三方工具数据（小红书：千瓜/新红；抖音：蝉妈妈/飞瓜；B站：火烧云；公众号：新榜）可直接粘贴。

## 评估框架

### 1. 匹配度（先于数据）

- 内容垂直度：近 20 条内容与品类的相关占比；跨类目接单多的号信任稀释。
- 粉丝画像 vs 目标人群：性别/年龄/城市/兴趣重合度；看评论区真实用户语气而非仅看后台标签。
- 人设与产品调性：测评型/生活方式型/专业型各有适配品类。

### 2. 数据健康度（假数据识别）

- 互动率基准（经验值，按类目校准）：小红书赞藏评/阅读 3–8% 常见，>15% 或 <1% 都要查；抖音点赞/播放 2–5% 常见。
- 造假信号：阅读高评论少且评论模板化（"已种草""求链接"刷屏）、点赞收藏比异常、粉丝增长脉冲式（买粉）、商单数据显著差于日常数据（日常刷量）、评论区无水军但转发异常。
- 稳定性：看近 10–20 条**中位数**而非平均数（一条爆款拉高平均是陷阱）；爆文率（超日常 3 倍的条数占比）。
- 商单频率：商单占比 >50% 的号粉丝信任透支；连续接同类竞品的号慎选。

### 3. 报价评估

- 小红书：CPE（报价/预期互动）与 CPM（报价/预期阅读）双口径；图文 vs 视频报价差；报备费（蒲公英平台服务费）计入。
- 抖音：星图报价 vs 预期播放 CPM；带货另看历史 GPM/转化率与佣金结构（纯佣/坑位+佣金）。
- B站：花火报价 vs 播放中位数；长尾流量（视频半年后仍有播放）计入价值。
- 议价空间：刊例价普遍可谈；打包多条/年框/置换（产品抵扣）常见。

### 4. 组合策略

- 金字塔：1–2 头部定调（可选）+ 腰部 10–30% 预算做深度内容 + KOC 铺量做搜索卡位与真实感；
- 小红书 KFS：达人内容（K）→信息流放大（F）→搜索承接（S），达人笔记要预留投流授权；
- 带货：纯佣 KOC 矩阵测品→跑出的品加腰部专场/头部混场。

## 输出格式

```
## 达人评估（平台 / 预算 / 目标）
| 达人 | 粉丝 | 报价 | 阅读/播放中位数 | 互动率 | CPE/CPM | 匹配度 | 风险信号 | 结论 |
### 推荐组合与预算分配（含投流预留）
### 淘汰名单 + 原因
### 合作条款提醒：报备/授权投流/改稿次数/排期/竞品排他/数据保底（谨慎接受保底承诺）
### 复盘口径：按 CPE/搜索增量/A3/TI 人群增量/带货 GMV 分目标设定
```

## 约束

- 无数据时不编造达人数据；给"去哪里拉哪些字段"的清单。
- 假数据判断给证据与置信度，不一票否决（新号/小众类目可能误判）。
- 不推荐刷量补数据；保底销量承诺多为骗局，提示风险。
