# Review 18 Journal Match

## Purpose

Choose a realistic target journal before final polishing and submission packaging.

## Required Inputs

- Manuscript draft or abstract.
- Review type.
- User constraints: IF/JCR quartile, OA/APC, speed, publisher, field.
- Candidate journals if any.

## Output

Create `14_journal_target/journal_match_report.md` with:

- Candidate journal table.
- Scope fit.
- Recent similar reviews.
- Article type eligibility.
- APC and open access note.
- Formatting requirements.
- Submission risk and recommendation.

## Completion Gate

Pass only when the selected journal accepts the article type and has clear scope fit.

## Stop Rules

Verify current journal information online when making target-journal recommendations.
