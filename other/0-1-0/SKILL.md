# 会话交接（session-handoff）

把当前对话收成**一份**记忆 markdown。下一场会话只读这一份就能接着干，不必翻聊天记录。

## 工作区

打开用户正在做的那个项目目录。记忆文件写到用户指定的路径；未指定时按 `references/01-write-memory.md` 询问，并给出系统建议路径。

## 路由

| 用户信号 | 加载 |
|---|---|
| 帮我记录一下上下文 / 会话交接 / 生成记忆 md | `references/01-write-memory.md`（整份交接） |
| 帮我记住下面的话 | `references/01-write-memory.md`（追加原话） |
| 技能做不到 / 记成升级需求 / 这是 skill 的问题 / 技能缺口 | `references/gap-capture.md` |

## 硬闸

1. 对话和已读文件里没有的事实，不要写进记忆。
2. 口令、密钥、云方人员手机等秘密不要写入。用户在「帮我记住下面的话」里原文要求记住的除外，仍只记原文。
3. 保存路径未定时先问，同时给出建议路径。用户已经给出路径则不再问。
4. 目标路径已有记忆文件：先读再合并，不要空白覆盖。
5. 只维护一份记忆 markdown，不要另存过程版本。

写完后告诉用户文件路径，并说明下一场会话应先读这份文件。细则只在 `references/01-write-memory.md`。
