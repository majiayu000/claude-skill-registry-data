# Minecraft 原画线稿渲染

把真实场景的几何、实体、水和建筑先渲染出来，再从可见结果提取**选择性的结构线与少量明暗**，在接近白色的纸面上用一条可调的屏幕空间渐变为线条着色。参考图只用于分析留白、线条密度和色彩分布；不要复制人物或图像像素作为游戏素材。

## 判断是否适用

- 用户要求“整个游戏像动画原画/白底彩色线稿”、镜头移动时持续生效：使用本 Skill。渐变通常锚定屏幕；同一物体可横跨暖色与冷色。
- 用户要求“玩家周围 20 格世界变成星空/水墨、区域固定在世界中”：使用 `minecraft-local-environment-material`，其世界位置 Mask 与本预设不同。
- 用户要求只给单个物品或装备赋予内部 Cosmic：使用 `minecraft-cosmic-material`。不把普通 Sobel、全屏颜色覆盖或纹理降饱和称为原画线稿。

## 实施关键

1. 明确哪些对象在风格化之前完成绘制、哪些 UI 在之后绘制。首选场景颜色、世界深度、手部深度的明确生产阶段；单张最终深度不能同时表示已被清除的世界深度和第一人称手部深度。读 [渲染管线](references/pipeline.md)。
2. 从亮度的两个空间尺度获取稳定暗线，再以可见深度变化的转折补足方块轮廓与转角。草方块也属于 cutout，不能按渲染阶段把它当树叶；以方向连续性保留地形长边，对稀疏候选降低碎线。低分辨率覆盖只能辅助判断，不能直接描等值线，否则角部会圆化。短缺口与锯齿修正见 [管线与断边诊断](references/pipeline.md)；水面、树叶的真实类别方案见 [专用线条方案](references/water-leaf-lines.md)。
3. 以线条强度在白纸与渐变色之间插值；渐变的色标、位置、角度、跨度和偏移独立于原方块颜色。调节线稿密度时仍须检查草叶、纹理砖、玻璃、云和远景是否过密或过空。
4. 资源重载、尺寸变化、离开世界、关闭预设时释放独立 FBO；禁止同时读写一个附件。未知 renderer/光影包、Fabulous 等更改目标顺序的管线必须有适配或显式回退，不能把 Java 能启动当作画面正确。
5. Forge 1.20.1 可从 [已构建实验](references/forge-1.20.1.md) 和 `assets/forge-1.20.1-lab/` 开始。修改滤镜时同一 `sketch.fsh` 供游戏和 WebGL 工作台使用；预览缺真实深度及镂空分类，不代替实机验收。若某些坡面内边界仍缺失，先检查是否有法线/材质类别输入，避免无区别地增加全屏色彩边缘敏感度。

## 彩色原画线稿预设与工作台

`assets/forge-1.20.1-lab/workbench/one-last-kiss.json` 是五色默认配方，灵感来自用户给出的暖橙—红—粉紫—蓝紫—青蓝色彩关系。它是风格预设，不包含参考插画。工作台允许拖动五个色标的位置、改颜色、改渐变方向/跨度/偏移，并调整线条敏感度、纹理抑制、深度轮廓、明暗留痕和线条尺度。浏览器导出 `olk-sketch/v1` JSON；游戏 `/localmaterial sketch reload` 读取同一结构。

从工程根目录运行 `python workbench/serve.py`，打开它打印的 `http://127.0.0.1:<port>/workbench/`。服务仅绑定本机回环地址，端口由系统分配。若没有 Python 的 PATH，使用已安装解释器的绝对路径。可上传自己的 Minecraft 截图，工作台自带一张已获本地实测的场景示例。完整限制和验收见 [Forge 与工作台](references/forge-1.20.1.md)。

不要把浏览器中的截图风格化称为游戏内深度/实体支持；以目标 Forge 实例的开关对照、实体/手部、水/玻璃、移动/FOV、重载和日志作为最终判断。
