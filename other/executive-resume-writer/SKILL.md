# 高管简历撰写（Executive Resume Writer）

## 何时使用此技能

当用户符合以下情况时使用此技能：
- 正在申请 C-suite 高管、VP 或总监级别岗位
- 拥有 15 年以上高级管理层经验
- 需要突出战略领导力而非具体操作技能
- 提到：「高管简历」「executive resume」「C-suite」「VP 简历」「高级管理层」「董事会」「高管寻聘」等

## 核心能力

- 为 C-suite 和 VP 级岗位撰写简历
- 强调战略领导力与业务转型
- 展示损益（P&L）责任与组织影响力
- 平衡成就与领导理念
- 面向高管寻聘顾问（executive recruiter）和董事会展示进行排版
- 包含董事会经验和行业认可

## 高管简历理念

**与普通简历的关键区别：**

| 普通简历 | 高管简历 |
|-----------------|------------------|
| 罗列技能 | 展示领导力品牌 |
| 描述任务 | 展现战略影响 |
| 聚焦「做了什么」 | 聚焦「带来了什么」 |
| 1-2 页 | 2-3 页可接受 |
| 面向 ATS 的关键词 | 面向决策者的故事 |
| 个人贡献 | 组织变革 |

## 高管简历结构

### 推荐章节

```
1. 高管简介/概要（Executive Profile/Summary）
2. 核心胜任力（领导力主题）
3. 职业亮点 / 关键成就
4. 职业经历
5. 董事会与顾问职务
6. 教育背景与高管进修
7. 行业认可（可选）
```

### 篇幅指南
- VP/SVP：2 页
- C-suite：2-3 页
- 董事会 CV：可以更长

## 高管简介章节

这一节取代普通简历中的职业概要（professional summary），应传达你的**领导力品牌**。

### 格式
```
[头衔/职能] 高管

[领导力品牌陈述——作为领导者你是谁]

[2-3 句话概述你的业绩记录及其范围/规模]

[你以什么著称 / 独特价值主张]
```

### 示例

```
首席运营官 | 损益管理（P&L）| 运营转型

以增长为导向的运营高管，拥有 20 余年推动 B2B 科技公司从 5 千万美元营收增长到 5 亿美元以上的经验。以打造高绩效团队、追求卓越运营以及构建支撑快速增长的可扩展基础设施而著称。

业绩记录包括 3 次成功退出、2 次 IPO 筹备，以及管理横跨 6 个国家、人数超过 500 人的组织。擅长运营战略、并购（M&A）整合，以及在 SaaS 和企业软件环境中的数字化转型。

核心理念：建立可复制的规模化流程，同时保持驱动创新的敏捷性。
```

## 核心胜任力章节

以领导力主题的方式呈现，而不是技能清单。

### 示例
```
领导力胜任力

战略增长                | 并购（M&A）整合           | 数字化转型
损益管理（5 亿美元以上） | 全球团队领导力            | 董事会关系
卓越运营                | 变革管理                  | 投资者关系
```

## 职业亮点章节

将你最重大的成就放在时间线式职业经历之前。

### 格式
```
职业亮点

• [成就 1，附量化指标]
• [成就 2，附量化指标]
• [成就 3，附量化指标]
• [成就 4，附量化指标]
```

### 示例
```
职业亮点

• 主导智谱的运营转型，将 EBITDA 利润率从 12% 提升至 28%，同时将营收从 1.5 亿美元增长到 4 亿美元
• 执行总金额超 2 亿美元的 5 起收购，成功整合 3 家公司，员工保留率达 95%
• 将全球运营团队从 50 人扩至 500 人以上，覆盖美国、EMEA 和 APAC 区域
• 为公司成功 IPO 做准备，落实 SOX 合规并建立投资者级报告体系
```

## 高管的职业经历章节

### 高管经历条目公式

**[领导动作] + [战略举措] + [规模化业务成果]**

### 示例岗位

```
首席运营官
智谱科技 | 旧金山，加州 | 2019 - 至今
4 亿美元营收的 B2B SaaS 公司 | 1200 名员工 | D 轮 - IPO 轨道

受 CEO 邀请加入，负责运营转型并为公司筹备 IPO。直接下属包括工程 VP、客户成功 VP、运营 VP 和 CIO。全面负责服务业务的损益（1.5 亿美元）。

战略举措与成果：

• 运营转型：重构端到端运营体系，将毛利率从 62% 提升至 78%，并将客户上手周期从 90 天缩短至 30 天

• 规模与增长：搭建支撑营收从 1.5 亿美元增长至 4 亿美元的基础设施，包括 ERP 落地、拓展 3 个新市场区域，以及建立 7x24 小时全球支持体系

• 并购领导：担任总金额 7500 万美元的 3 起收购的运营负责人，在 6 个月内完成全面整合，人才保留率 95%

• 团队发展：将运营组织从 200 人扩展到 600 人，建立领导力发展项目，已将 15 名内部人才晋升至 VP/总监岗位

• IPO 筹备：主导 SOX 合规落地，建立审计委员会汇报机制，并构建投资者级的运营指标与预测能力
```

### 高管职业经历的关键要素

**务必包含：**
- 公司背景（营收、员工数、发展阶段）
- 汇报关系 / 管理跨度
- 损益或预算责任
- 战略范围

**应突出的指标：**
- 营收增长（金额与百分比）
- 盈利能力提升（利润率、EBITDA）
- 成本降低
- 团队规模与发展
- 地域扩张
- 并购动作
- 退出（exit）结果

## 高管简历的特定注意事项

### 着重体现转型

企业聘用高管是为了**转型**，而不是维持现状。要展示：
- 因为你的加入，哪些发生了改变
- 前后对比状态
- 影响的规模

**转型叙事公式：**
「接手[状况]。实施[战略变革]。取得[成果]。」

### 展示领导理念

与个人贡献者简历不同，高管简历应当暗示你「如何」领导。

**示例：**
- 「以在多元利益相关方群体中凝聚共识著称」
- 「坚持数据驱动决策，同时保持战略灵活性」
- 「倡导创新，同时坚守运营纪律」

### 谨慎处理任期

**短期任职：** 围绕特定使命来解释
- 「受邀加入以主导并购后整合」
- 「受邀负责业务扭转，18 个月内完成」
- 「加入公司以为被收购做准备」

**长期任职：** 展现晋升轨迹与自我革新
- 「12 年间历经 4 个岗位逐级晋升」
- 「在公司从 5 千万美元增长至 5 亿美元的过程中，主导了多轮转型」

### 保密信息

**应该：**
- 绝对数值涉密时，使用百分比改进幅度
- 营收/人数使用区间
- 以相对影响来表述

**不应该：**
- 泄露专有战略
- 透露保密的收购标的名称
- 揭露未公开的财务信息

## 高管简历的语气

### 高管专用的有力语言

**战略性行动动词：**
- 牵头（Spearheaded）、统筹（Orchestrated）、力推（Championed）、掌舵（Steered）
- 转型（Transformed）、革新（Revolutionized）、开创（Pioneered）
- 架构（Architected）、构建（Engineered，指战略层面）
- 驱动（Drove）、加速（Accelerated）、催化（Catalyzed）

**领导力语言：**
- 「带领组织走过……」
- 「搭建并规模化……」
- 「为……确立愿景」
- 「谈判并达成……」
- 「推动……转型」

### 应避免的内容

- ❌ 战术/操作性语言（管理了、处理了、协助了）
- ❌ 第一人称代词（我、我的）
- ❌ 没有上下文的行话
- ❌ 没有论据的空泛陈述
- ❌ 过度谦逊（该归功时要恰当归功）

## 高管寻聘的注意事项

**你的简历可能被以下人群看到：**
- 高管寻聘顾问
- 董事会成员
- PE/VC 合伙人
- CEO 和 CHRO

**优化方向：**
- 便于忙碌的高管快速扫读
- 清晰的职业发展叙事
- 鲜明的领导力品牌
- 可信、可验证的成就

**请谨记：**
- 高管寻聘往往在面试之前就进行背调
- 你的简历会被逐项核实
- 人脉与口碑至关重要
- 简历为你打开大门；人脉为你促成交易
