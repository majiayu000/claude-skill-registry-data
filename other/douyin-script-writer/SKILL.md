# 抖音短视频脚本

抖音是"兴趣推荐+完播驱动"：前 3 秒决定生死，结构服务于完播与互动；投流素材与原生内容逻辑不同，先问用途。

## 输入

用途（涨粉内容/带货短视频/千川投流素材/本地生活团购）、产品与卖点、目标人群、时长（15/30/60s）、形式（口播/剧情/测评/混剪/图文）、账号人设。投流素材另要：转化目标与落地页承诺（价格/优惠必须一致）。

## 结构模板

### 前 3 秒钩子（给 3–5 个备选，标注类型）

- 痛点直击："XX 的人千万别再…"; 利益前置："9.9 就能…"; 反差悬念："我把 XX 拆了，发现…"; 身份点名："当妈的都看过来"; 视觉冲击（动作/道具/对比画面）+ 一句话。
- 钩子必须与正片强相关，骗完播的假钩子伤转化与账号标签。

### 正片结构（按时长）

- 15s：钩子→1 个卖点演示→行动引导（小黄车/评论区/关注）。
- 30s：钩子→痛点放大→产品演示（眼见为实：质地/效果/对比）→信任背书（成分/资质/销量，须真实）→引导。
- 60s 剧情：冲突开场→转折→产品自然介入→结局梗→引导；产品出现不早于剧情钩子之后。
- 口播：每 5–8 秒一个信息点或画面变化，防划走；字幕关键词放大。

### 结尾引导

- 带货：明确指令（"点下方小黄车"/"评论区扣 1"）+ 限时限量理由（必须真实）；
- 涨粉：下集预告/系列钩子；本地生活：POI 定位+团购组件。

## 千川投流素材特别规则

- 素材即定向：脚本里的人群点名/场景就是定向信号；
- 开头 3 秒可更"广告"（利益直给），但原生感素材通常更长寿；
- 一个脚本出 3–5 个变体（换钩子/换场景/换演员/换 BGM），供跑量测试与疲劳轮换（见 creative-fatigue-cn）；
- 价格/优惠/赠品与落地页完全一致；不得用"最/第一/根治"等违规表述（详见 ad-compliance-cn）。

## 输出格式

```
## 抖音脚本（用途 / 时长 / 形式）
钩子×3–5（类型标注）
分镜脚本表：时间 | 画面 | 台词/字幕 | 音效/道具
结尾引导 / 标题+话题标签（埋搜索词）
### 投流变体建议（如适用）
### 合规自查 + 拍摄执行提示（设备/场景最低要求）
```

## 约束

- 不写虚假测评/伪造实验效果；医疗功效、绝对化用语直接拒绝并给合规替代表述。
- 剧情脚本给可执行的低成本拍法，不默认专业团队。
