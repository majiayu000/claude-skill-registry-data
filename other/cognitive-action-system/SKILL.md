# 行动落地与习惯设计

## 目标

把“想改变”压缩成今天某个时刻可以开始、完成后能得到反馈的动作。用理智设计环境、意义和反馈，不要求用户长期靠意志力硬扛。

## 工作流

1. 把愿望改写为可观察结果。追问“什么变化能证明它发生了？”
2. 诊断主要阻力，只选最关键的一项：
   - 目标或过程模糊；
   - 一次想做太多、马上见效；
   - 动作过大或难度不匹配；
   - 诱惑出现在开始、结束或转场节点；
   - 打卡形式接管了内在动机；
   - 只有输入和思考，没有真实行动与反馈。
3. 选用对应技法：
   - 模糊：用“行动单行通道”明确唯一优先项、时间、地点、动作和完成标准。
   - 过大：把任务调到“舒适区边缘”，设置下限、标准、拉伸三级。
   - 转场诱惑：在“元时间”暂停几秒，预先写下“如果……那么……”动作。
   - 打卡陷阱：用私下记录代替展示，设下限、不设上限，中断后从下限恢复。
   - 无反馈：选一个作品、自测、使用或外界回应，形成“行动—反馈—修正”。
4. 生成 5—30 分钟的唯一下一步。若仍无法开始，继续缩小动作，不增加动机口号。
5. 设计环境：移走高刺激诱因，把材料、入口和提醒放到触发点附近。
6. 设计恢复：明确漏做后的重启动作，禁止用“下周一重新开始”替代今天恢复。
7. 设复盘点：检查是否开始、卡在哪里、得到什么反馈、下一轮怎样调整。

## 今日行动卡

必须包含：目标证据、唯一下一步、时间、地点、完成标准、最低动作、环境调整、反馈方式、中断恢复、复盘时间。

## 质量门槛

- 主行动最多 1 个；可另加 1 个最低动作和 1 个恢复动作。
- 不输出“自律一点、坚持下去、克服懒惰”等不可执行评价。
- 动作必须同时写清时间、地点、行为和完成标准。
- 计划强度应略高于当前能力但仍可完成；高风险任务不以试错拉伸为先。
- 验收现实改变，不以连续打卡、看完内容或计划写得完整为成功。
