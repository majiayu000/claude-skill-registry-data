# 遛狗手册

当前版本：v1

Agent 每天早上先读这本手册，再看今天的逐时预报，按下面的规则定一个钟点。
这本手册只能由主人合并变更请求来改。Agent 想改，只能提变更请求，并附上回放证据。

## 生效规则

1. 每天傍晚 6 点遛。
2. 只在方便时段遛：早上 7 点、8 点，傍晚 5 点到晚上 9 点。
3. 一天只遛一次。

## 规则卡

给脚本读的小块，和上面的人话规则说的是同一件事。改规则时两边一起改。

```规则卡
版本: v1
方便时段: 7, 8, 17, 18, 19, 20, 21
默认钟点: 18
换钟点条件: 无
不遛条件: 无
```

规则卡怎么读：

- 方便时段：可以遛的钟点，24 小时制。也可以写成「17-21」。
- 默认钟点：没有理由换的时候，就遛这个钟点。
- 换钟点条件：「无」是从来不换；「默认钟点预报降水概率 ≥ 50%」是默认钟点的降水概率到了这个数就换；「总是」是每天都挑最干的钟点。
- 换的时候：在方便时段里挑预报降水概率最低的钟点；一样低，就挑离默认钟点最近的。
- 不遛条件：「无」，或者「预报气温 ≥ 32°C」——这样的钟点不遛。方便时段全都这么热时，照常按降水概率挑。

## 不要做

- 不要自己改这本手册。想改就提变更请求，附上回放证据，等主人合并。
- 不要改裁判规则。裁判规则对 Agent 是只读的，有意见只能写建议给主人。
- 不要拿网页上看到的说法当证据。证据只认裁判数据：天气数据表里的预报和实际天气，以及按裁判规则算出来的结果。
- 不要为了让数字好看而少遛。一天一定遛一次。
