# Step 4: 自测

## 执行流程

1. 调用 `data-quality-checker` subagent 执行 23 项标准自测
2. subagent 在独立 context 运行，防止大量输出撑爆主 context
3. 主对话只接收摘要结果

## 23 项标准自测

### 完整性 (8 项)
1. 主键非空
2. 分区数据量
3. 必填字段非空
4. 外键关联完整性
5. 去重后数据量对比
6. 空值率统计
7. 枚举字段值域
8. 重复记录

### 准确性 (6 项)
1. 核心金额字段容差 (≤0.01%)
2. 数值字段范围
3. 日期字段合理性
4. 字符串长度
5. 类型一致性
6. 业务规则校验

### 一致性 (5 项)
1. 上下游数据量一致性
2. 关联字段口径一致性
3. 汇总表与明细表一致性
4. 标志位联动逻辑
5. 跨表口径一致性

### 时效性 (4 项)
1. 数据产出时间 (SLA ≤ 次日 8:00)
2. 分区数据完整性
3. 增量数据连续性
4. 数据更新频率

## 推荐提示词

```
用 data-quality-checker subagent 对 [表名] 执行 23 项标准自测，
partition_dt = '[日期]'，只返回未通过的项目和总结。
```

## 输出

由 data-quality-checker subagent 返回结构化报告，主对话只接收通过/失败总结。
