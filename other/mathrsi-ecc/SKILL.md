# ECC 领域插件

本技能面向二元线性码研究，把生成矩阵、距离、无损归约、分类和共同扩张的实际判断交给 agent。
它与 [MathRSI base](../../../../base/skills/mathrsi-research/SKILL.md) 配合；base 管目标、路线、预算和交接，本插件提供领域方法与验证接缝。
插件随仓提供原证明、论文、两个Lean归约工程、实际矩阵、检查器及一个完整母码证书；全172大pair流的精简范围见 [archive说明](../../archive/README.md)。它不把旧题的母码目录或参数当作当前任务。

首次使用读原目标与两种完成路径，再按当前义务选择方法。
定位历史工具与案例时读 [来源与检查器地图](references/source-map.md)，准备具体工作包可参考 [固定母码的联合判定示例](examples/fixed-parent.md)。
执行矩阵、保存集、pair或Lean具体核验时调用 [ecc-certificate](../ecc-certificate/SKILL.md)，传原规格与scope，消费其真实结果回当前义务。无需为一个显式小矩阵的验距先建立全域分类或整套研究流程。

数学公式、适用条件及完整成功链在 [结构归约](references/reductions.md)；真实失败输入、修法与重试条件在 [失败机制](references/failures.md)。这两层是实质方法，source-map负责按需定位原件，不能替代它们。

## 每次推进先确定节点归属

新推进、恢复、换方法或派子任务前，执行[按节点研究协议](references/node-research.md)：读取当前分枝与相关原证据，按实际对象、目标和覆盖关系确定 node_id，再登记 task_id。先回答“是否属于已有分枝；若不属于，它挂在哪个父域/未覆盖补集，或是否是多枝共用依赖”。关系未知时先做归属核对，不能直接启动依赖该归属的大扫描。

已有同域闭合则复用，未完则接原断点；换基、换名或换算法不产生新数学节点。分枝必须保留未覆盖余类，共用计算只执行一次。完成后按精确范围回写节点并将核验交给 ecc-certificate；局部完成不关闭整枝。使用[最小工作包](examples/node-work-package.md)或当前任务等价字段；[72/36结构示例](examples/node-research.md)说明A/B/C与母码扩张如何挂接，示例不宣称原题已解。原规格、用户暂停和 base 全局进展重评仍优先。

## 原对象、量词与完成路径

二元线性 [n,k,≥d] 码是 F₂ⁿ 的 k 维子空间，可由 GF(2) 满行秩的 k×n 矩阵 G 表示。
距离条件是对每个非零消息 u∈F₂ᵏ，都有 wt(uG)≥d。
先读当前规格的 n、k、d、域、长度含义、允许的等价表示与完成方式。
若任务实际研究非二元、非线性或其他距离，重新核对对象和检查器，本技能的 GF(2) 公式不能直接套用。

一个满足原规格的实际矩阵即可证明存在；发现该矩阵的搜索不需要完备。
若规格只要求证明存在而不要求交出矩阵，严格的非构造性存在证明也可以完成肯定路线。下文的直接矩阵核验适用于显式构造路线，不替所有肯定证明指定方法。
若合同要求否定，则必须覆盖全部原始对象，不只覆盖某种自同构、准循环结构、固定母码或搜索生成器。
结构子族可用于构造探索；没有无损覆盖证明时，只能排除这个子族。
若任务接受构造与否定任一方式，保留两条路线的机会，不要求先完成全部否定分支再验收构造。

一个输出合法但距离不足的矩阵仍可作为种子，不能写成目标已解。
所有尝试都失败或求解器返回 UNKNOWN，不构成不存在性证明。
中间码验距通过、一个固定母码扩张排除和原题全域排除属于不同结论。
公开纪录或新颖性的声称还需核对当时原始来源，验距程序只验证矩阵性质。

## 构造路线：尽早直接验证原矩阵

先找已有种子、构造定理、邻近参数和搜索后端；按当前数学判断选择改基、局部修改、拼接、子码或其他构造。
这些都是候选产生手段，验收读取最终显式矩阵。
如果内部表示是偶扩展、系统形、压缩列或某种中间码，先完成导回原长度和原维数的操作。
不要让最终检查只看到内部摘要参数或搜索器缓存。

检查矩阵形状、元素属于 F₂、位序约定及 GF(2) 实际秩。
满行秩时，所有非零消息必须生成互异非零码字；对可承接的 k，完整枚举 2^k−1 个非零消息求距离。
保存实际最小权消息、码字和重量谱，使失败能反馈到下一候选。
大维数若需其他充分验距证据，先明确该方法证明的完整性与合同是否接受，不能把抽样标成精确距离。

既有 generic verifier 需要调用者核对期望 n/k/field、rank、target_distance 与 proof_level 的实际含义。
精确枚举上限必须覆盖当前 k；程序退出零有时仅表示合法运行。
有的报告序列化不导出重量谱，查看真实接口并单独保存需要的结果。
要求独立复算时，至少一个实现直接读取实际矩阵，不共享搜索器展开后的码字缓存。

变换后旧的最小权消息通常不是新基下的同一个消息；保留基变换或重新从原矩阵计算。
构造已满足原合同且所需核验完成时，及时结束此完成路径，不继续为构造搜索补不存在性完备证明。
若仅改进了距离未达标，记录实际结果与失败见证，再判断继续局部构造是否仍值得。

## 否定路线：明确覆盖链，允许多种证明组合

从任意假定目标开始，给出完整的数学归约，直到可处理的分类、共同表示或有限约束域。
逐步写清是等价、必要覆盖、充分构造，还是只探索某个子族。
穿孔、缩短、奇偶扩展、对偶支撑和 residual 操作都须重算长度、维数与距离方向。
删掉若干坐标不等于维数下降同样多；穿孔不降维可能依赖原最小距离。

引用 Griesmer、MacWilliams、分类或不存在性定理时，检查域、满支撑、偶性、projective 等精确前提。
二元生成矩阵的 projective 在相应语境下要求无零列且无重复列，不能无理由附加给原母码。
文献“至多 N 类”和实际 N 个合格、两两不等价代表可以共同证明覆盖。
两边的对象域与等价关系须一致，或另有足够的类数转移论证；用更细等价关系数出的 N 个代表不能直接配更粗等价下的类数上限。
代表发现可以启发式；覆盖来自明确的数学和实际验证，不必追求发现器也穷尽。

若只有一个已知库、没有覆盖上界或其他完整性论证，直接报告“已知代表库”。
重量谱相同不意味着坐标等价；等价与不等价需使用足以区分码的证据。
用图规范化等工具时，查编码为何对应码的坐标等价，并保留实际矩阵与所需置换。
不把代表数量或新类增长换算成原题完成百分比。

否定证明可由有限证书、解析论证、完整扫描或其组合完成。
先选足够支撑当前结论且成本相称的组合，不把历史项目的双完整扫描设为所有任务必做规则。
局部排除只在其输入范围内收回；全部母码计算完成仍须把覆盖链和原目标连接装配起来。

## 合法陪集：成员正确和无遗漏是两项义务

固定母码后，系统形、主元、商空间基和奇偶限制可以提供陪集的规范截面。
证明每个相关陪集有代表、规范代表唯一、距离条件不被规范化改变，再确定完整参数区间。
保存 F 中每个成员确实合法，只证明没有误接纳，未证明没有把合法成员错误删掉。
完整扫描、另一套全域实现、可重放覆盖证书或充分的形式证明可以解决相应无遗漏义务。

第二实现若要承担独立无遗漏核验，不应直接用旧 F 决定接受／拒绝。
不同商基得到的集合先运输到共同实际坐标或证明共同表示相等，再比较。
成员重验、集合比较、全域再生成和配对拒绝重放分别报告，不能把它们累计为多次完整扫描。
依据输入范围记录中断区块、完整终态和未执行域，避免只从汇总最大值推断全覆盖。

同一程序可以有搜索与检查模式；调用时选择当前义务需要的模式和参数。
不要为了统一插件接口重写成熟扫描器，优先复用当前任务的实际入口与说明。
对非常大的域先用真实实例测准备、执行、保存与读回成本，再决定正式批次。

## 联合扩张：每行合法还不够

新增行的所有非零线性组合都要达到相应距离；多个合法单行未必能同时扩张。
先从目标尾空间、头部与母码的关系推导共同必要条件，而非直接展开最高阶组合。
例如某路线可推出 a、b、a+b 都属于同一个 F；若完整相容 pair 图为空，就无需继续枚举三行。
这个条件只用于已经推导出该必要性的尾型，不能当所有扩张的一般等价式。

较高维结构有时能复用 P_a=F∩(F+a)、Q_(a,b)=P_a∩(P_a+b) 等共同交集。
先证明它们与实际仿射 cube 或目标关系的方向，再考虑缓存和分桶。
小单行表不保证联合域小；计算实际配对、子空间、共同头和后续恢复规模。
反过来，完整联合域经过证明压缩且已经可承接时，直接做完，不无限等待更强解析归约。

必要条件判定若失败，返回实际低权消息、码字或其他拒绝见证，可独立重放。
若必要条件仍可行，说明它未排除此输入；不要声称存在目标，除非已恢复原矩阵并通过原规格。
输出中间矩阵时区分记录数、不同实际矩阵数和坐标不等价类数。
后续扩张尚未执行的成本单列，不能用当前阶段的快查询时间估计整题。

## 共同坐标、群作用与多个规范化

多行、母码、尾基和线性关系属于同一个实际对象；变换必须共同作用。
先规范第一行后，第二行通常只能使用保持第一行的稳定子继续规范；未来行也要同时运输。
各行独立取全群代表可能删掉合法联合对象。
只给类编号或谱，不能保证两次扩张处于同一坐标嵌入。

在代表图上每条边存在某种相容嵌入，不保证三条边的嵌入能共享同一坐标系。
需要共同嵌入、实际运输或保留足够联合变量，再作联合判定。
运输还须保留目标所需的奇偶、距离、尾空间和后续作用，不只让当前矩阵看起来等价。

多个单独无损的规范化叠加前检查是否使用了同一份变换自由度。
固定若干零锚点与后续边际规范化可能分别成立却不能同时成立。
若发生冲突，撤掉一项、证明同时可满足，或完整覆盖剩余轨道；不能以分别正确的论证替代联合保真。
这项数学义务应显式交给 base，不藏在优化代码的一行条件里。

## CP／SAT 与有限证书

有限模型可用于找候选、证明某域不可行或发现松弛过宽。
先证明每个待排除的实际码都映入约束模型；如果模型只是必要条件，UNSAT 可以排除该实际范围，SAT 未必给实际码。
完整求解的状态、超时和 UNKNOWN 如实保留，不能把没有找到解写成 UNSAT。
小型 RUP 或其他确定性证书可降低对大型求解器的依赖，但 checker 只验证相应形式系统的结论。

CNF 不可满足不自动证明原码不存在；仍需母码、补空间、子码／穿孔等编码的无损连接。
固定父码内的全子码排除，只关闭该父码及已证明覆盖的操作路线。
没有必要把每个有限模型全部转为 Lean；合同要求或关键接缝值得形式化时，使用本仓当前宿主的 `lean-formalize`。

## 根据成本与信息改变行动

比较完整流程：归约、输入准备、F 生成、联合检查、输出、独核、证明装配及交接。
CPU、墙钟、存储、文件数和读取代价分别说明；内部查询计时不能代表外部进程，更不能代表研究总时长。
一个重复坐标很多的实例可能有巨大群作用收益，不代表其余母码也如此。
代表较少但共同自由度极大时，先估联合域，不按母码数估剩余时间。

有界探针要说明哪种观察会改变下一步：完整关闭输入、产生原规格候选、找出新公共约束或证明现有松弛无效。
若完整局部域全非空、没有减少任何原题义务，停止自然追加同类层，返回共同关系与整体路线。
新增母码仍可能带来构造机会，可在明确预算内继续，但别冒称它推进了完整分类。
同一卡点两轮无实质增量时重新判断表示和投入，不机械放弃，也不无限续刷。

固定域已完成则复用；新约束、新表示或新成本样本可以说明重试理由。
资源不足停止与数学无信息停止分别记录；预算允许后，前者可沿原法续跑。
已有见证或完整局部产物交回后及时核验并接到下一义务，不等待无关批次全部结束。

## 验证与交接

每个检查器绑定具体义务，注明实际输入、完整域和未解决连接；不给整个 ECC 领域一个统一 verifier 布尔值。
矩阵验距、分类互异、陪集无遗漏、pair 拒绝和 CNF 重放各自支撑不同结论。
独立实现共享了循环、数据或规范化时如实报告；静态跨模型审阅不能写成 reviewer 实际运行。

使用 `research-wiki` 复用已读文献、失败对象与重试条件；熟悉路线用 `research-lit` 定向补原文，新领域或旧路线失效时可广搜引用链、反例与替代方法，再收敛到可推进的数学义务。
使用 `formula-derivation`／`proof-writer` 组织归约与缺失数学；`proof-checker` 或定点 `research-review` 检查新增关键连接。
现成搜索 harness 可作为候选后端，先读其实际接口；本插件未分发旧发现harness，不虚构可运行入口。其中 ECC 专用的评价或 team/portfolio 逻辑不改名冒充通用 base。
按需使用 `render-html` 做交付，展示保真、计算复现与原题证明分别报告。

最终从原规格回看实际矩阵，或串起完整归约、覆盖、联合拒绝与输入绑定。
保留接受的外部数学进口、软件信任及本次真实复算范围；没有 Lean 就不写内核形式化。
任务参数、当前母码列表、覆盖区块和状态留在工作区；可迁移的数学与策略才进入插件维护候选。
本技能没有恢复旧 ECC Goal、执行历史扫描或迁移其研究数据。


## 当前阶段怎样实际调用并回交

prepare/survey接收初步参数、允许操作和当前疑问，先用本入口定义及references的E1/E2/E3条件定位已有知识；需要新文献时与base共享一次survey，输出准确来源/版本/范围、当前参数能否满足、缺哪条运输引理。历史目录无完整上界时直接写已知库，不让后续prove误作分类。新任务不把旧172母码当通用默认。

route-loop收到卡点后读取失败机制及相关原件，提出会改变原结论的数学探针。选择结构漏斗、构造、共同pair、商空间/稳定子、文献短运输之一；先写实际必要/充分关系和联合域成本，再执行有界推导或程序。输出实际新引理、反例、可继续输入与下一项具体任务，不交一个未消费的工具表。已有base管理审阅循环，本入口不另启一套总控。

prove用已选路线推进实际数学。比如43/10从任意码证明≤3列独立、强迫对偶重量4、满支撑缩短、目录覆盖和共同尾型；42/16先补恰距离归一化再调用E3。这些是有公式与条件的可复用实例，具体新参数须重算。收回条件定理后检查本题实际输入满足，不让作者自证某个抽象Certificate可推出结论后就结束。

verify调用ecc-certificate时给原定义、正文、实际矩阵/母码/F/流、期望完整域、基/坐标运输、需证明的范围与写入位置。返回后逐项装配：矩阵结果只用于该构造，单母码pair只用于该母码，F读回不补完整扫描，Lean类型带参数就保留对应进口。普通检查器失败回相关prove义务；结构归约失效才返回路线。父调用者持有最终验收，不重复启动另一个verify。

handoff消费已核数学和执行记录，提供原规格、完整证明、参数关系、复现命令、缺失流和显式进口。旧archive只读，新研究wiki写当前任务；遇到通用流程改进给外层meta-evolve，不在求解中改base。本轮真实运行见 [IMPLEMENTATION](../../evidence/IMPLEMENTATION.md)。
