# LeeWay Formula Factory

## Mission
Turn candidate equations/models/profiles into qualified Formula artifacts through evidence. The Factory does not directly mutate canonical Formula or production Fabric catalogs.

## Inputs
Research equations; LeeWay-derived candidates; empirical models; standards-bound formulas; House-specific Suns; discovered repeated reasoning suitable for mathematical formalization.

## Pipeline
INGEST → PROVENANCE → NORMALIZE → CLASSIFY(LFEA) → DOMAIN/UNITS → SYMBOLIC → BOUNDARY/SINGULARITY → PROPERTY → RANDOMIZED → ADVERSARIAL → NUMERICAL STABILITY → EMPIRICAL/STANDARD VALIDATION → REPAIR/RETEST → CANONICAL COMPARE → PROMOTION PROPOSAL.

## Outputs
QUALIFIED_CANDIDATE; ADAPT_REQUIRED; HOLD; REJECT. Only authorized promotion can create a production Formula Fabric catalog entry/canonical binding.

## Learning
PASS and FAIL remain evidence. Counterexamples and repair history are first-class Formula knowledge.
