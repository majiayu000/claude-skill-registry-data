# daily-practice-stack

## When to Use

当需要建立结构化的每日例行程序，以支持不同阶段的个人成长目标时description

## Core Logic

# 执行步骤

1.  **确定发展阶段与选择模板**
    *   **输入**：对自身当前发展阶段的评估（例如：解决基本稳定性问题、发展个人能动性、专注于创造性输出）。
    *   **操作**：根据阶段选择对应的每日练习模板：
        *   **IF** 阶段目标是**基础巩固与清晰度**：**THEN** 选择“写作练习”（30分钟，含反观、问题识别、价值思考、分享）。
        *   **IF** 阶段目标是**从依赖到自主（1.0到2.0）**：**THEN** 选择“代理发展堆栈”（60分钟，含感恩、体能活动、学习、项目准备、真诚联系、反思）。
        *   **IF** 阶段目标是**从自主到创造（2.0到3.0）**：**THEN** 选择“创作者堆栈”（90分钟，含深度工作、内在动机训练、公开创意工作、系统优化）。
    *   **判断标准**：选择了一个与当前主要发展目标相匹配的练习模板。
    *   **输出**：一个选定的每日练习模板名称及其时间预算。

2.  **拆解与日程安排**
    *   **输入**：一个选定的每日练习模板名称及其时间预算。
    *   **操作**：将模板中的抽象活动（如“深度工作”、“真诚联系”）转化为明天可执行的、具体的行动（如“写文章初稿30分钟”、“给X发一条真诚的问候信息”）。并将其安排到每日日程的固定时间段。
    *   **判断标准**：模板中的每个模块都有了对应的、明天可执行的明确任务，并分配了具体时间。
    *   **输出**：一份明日的具体化、时间化的每日练习日程表。

3.  **执行与记录**
    *   **输入**：一份明日的具体化、时间化的每日练习日程表。
    *   **操作**：在计划的时间执行每项任务。简要记录完成情况、专注度、收获或阻力。
    *   **判断标准**：完成了日程表中大部分（如80%）的练习内容，并留下了简单的执行记录。
    *   **输出**：当日的练习完成记录与简要反思。

4.  **每周回顾与模板调整**
    *   **输入**：连续多日（如一周）的练习完成记录与简要反思。
    *   **操作**：回顾一周实践。评估该模板是否有效支持了阶段目标？哪些活动收益最大？哪些难以坚持？根据反馈微调模板中的活动比例或内容，或考虑是否切换到更适合下一阶段的模板。
    *   **判断标准**：完成了基于数据的模板效用分析，并做出了继续、调整或更换模板的决定。
    *   **输出**：优化后的下周每日练习计划。

# 输出格式要求
以“每日练习卡”形式呈现，包含：1) 当前阶段与选用模板，2) 明日具体日程安排（时间+具体任务），3) 今日完成打卡与一句话感悟，4) (每周)模板调整建议。
