# Picvero · 店铺图片风格

用户要求参考电商平台套图或提供商品页样式时，读取 [实际电商套图](references/marketplace-suite.md)，提炼信息顺序、构图和视觉体系，按本商品事实适配。

需要更漂亮、更高级或更有品牌感时，读取 [电商视觉设计](references/visual-direction.md)，明确布景、光线、配色与排版后执行。

读取 [共用约定](references/workflow.md) 与 [品牌与批量](references/brand-and-batch.md)。

识别当前店铺已有规范，优先复用。没有时从用户提供的参考提取背景、光线、机位、留白、色调和文字语气，不提取参考商品的事实、销量或评价。

在项目中保存可读的 brand.json：店铺名称、视觉要求、参考文件、适用范围、版本说明。字段缺省就省略，不编造色号和精确色温。记清哪些是用户确认、哪些是当前建议。

用户已经要求整店采用时推进；用户只说这一张喜欢，不擅自写成全局偏好。多店铺分别保存。后续修改当前图片不覆盖品牌源文件。

应用到示例商品时按 [原生图片工具](references/native-image.md) 和 [审核](references/review.md) 检查实际效果。规范提升复用性，但不承诺每张生成图完全相同。
