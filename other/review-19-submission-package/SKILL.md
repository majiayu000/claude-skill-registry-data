# Review 19 Submission Package

## Purpose

Turn a polished manuscript into a journal-ready submission bundle.

## Required Inputs

- Target journal instructions.
- Final manuscript.
- Author list and affiliations.
- Funding, ethics, conflicts, data availability, and contribution statements.

## Output

Create files under `15_submission_package/`:

- `cover_letter.md`.
- `title_page.md`.
- `submission_checklist.md`.
- `declarations.md`.
- `upload_order.md`.
- `highlights.md` if required.

## Completion Gate

Pass only when all journal-required components are present or marked not applicable with reason.

## Stop Rules

Do not invent author contributions, funding, ethics approval, conflicts, or data availability statements.
