# 竞品与市场分析Skill

## 适用场景
新产品立项、重大功能规划、商业化决策前,需要摸清市场格局、竞品能力边界与自身差异化机会点。

## 执行步骤
1. 圈定竞品范围:直接竞品(同场景同用户)、间接竞品(同场景不同方案)、标杆竞品(跨行业参考)。
2. 确定对标维度:目标用户、核心功能、定价模式、技术壁垒、市场数据(份额/增速/口碑)。
3. 采集信息:官方文档、产品实测、用户评价、公开财报/行业报告,标注每个信息的时间与来源。
4. 建功能对标矩阵:逐功能逐竞品打「有/无/部分有/差异化实现」,附截图或录屏证据。
5. 归纳差距与机会:我方缺失的核心功能、竞品普遍未覆盖的空白点、可超越的体验短板。
6. 输出结论:市场定位建议、功能优先级建议(哪些必须做/哪些可以差异化/哪些不做)。

## 规范要点
- 信息必须标注来源与时间:竞品迭代快,过期结论会误导决策,超过 3 个月的信息标注"待复核"。
- 对标结论落在「策略层」而非只罗列功能:每个差距点写明「对我方意味着什么」。
- 不做主观贬损:对比只陈述事实与可验证数据,不写"竞品体验差"这类无依据判断。
- 空白点不等于机会点:标注每个空白点未被满足的原因(技术难度/需求小众/政策限制),避免误判。

## 输出模板
```
# [产品名] 竞品与市场分析报告
1. 市场概览(规模/增速/格局/趋势)
2. 竞品圈定与基本信息
3. 功能对标矩阵(维度 × 竞品,附证据)
4. 核心功能深度对比(选 3-5 个关键功能拆解流程)
5. 差距与机会点分析(每条附"对我方意味着什么")
6. 结论:定位建议 + 功能优先级建议
```

## 自检清单
- [ ] 每条信息有来源与时间,超期信息已标注
- [ ] 对标矩阵覆盖直接/间接/标杆三类竞品
- [ ] 差距点均附策略层结论
- [ ] 机会点已分析未被满足的原因
- [ ] 无主观贬损性表述
