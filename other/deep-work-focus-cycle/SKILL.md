# deep-work-focus-cycle

## When to Use

当需要进入并维持一段高度专注、无干扰的工作状态以处理复杂任务时description

## Core Logic

# 执行步骤

1.  **定义专注任务与目标**
    *   **输入**：待办事项列表或项目规划。
    *   **操作**：从中筛选出一个需要深度认知参与、具有高价值的单一、明确任务。为其设定一个具体的、可衡量的专注时段目标（例如：“完成XX报告大纲起草”，而非“写报告”）。
    *   **判断标准**：任务定义清晰，目标结果可验证，预计需要连续不间断的专注时间（如60-120分钟）。
    *   **输出**：一个明确的“深度专注任务目标”。

2.  **准备专注环境**
    *   **输入**：上一步定义的专注任务目标。
    *   **操作**：
        *   **物理环境**：消除外部干扰（如：选择安静空间、佩戴降噪耳机、清理桌面）。
        *   **数字环境**：消除数字干扰（如：关闭非必要通讯软件通知、将手机设为勿扰模式、退出社交媒体网页）。
        *   **材料准备**：确保所需资料、工具触手可及，避免中途寻找。
    *   **判断标准**：环境中已无已知的、可预见的干扰源；所需工作材料已就绪。
    *   **输出**：一个优化后的、支持深度工作的物理与数字环境。

3.  **执行专注时段**
    *   **输入**：准备好的环境和专注任务目标。
    *   **操作**：
        *   启动计时器（推荐使用番茄钟，如25-50分钟为一个单元）。
        *   将全部注意力集中于任务目标上。
        *   **IF** 出现分心想法或外部干扰：迅速记录在旁（如便签上），然后立即将注意力拉回任务。
        *   **IF** 遇到任务内无法解决的阻塞：先记录问题点，尝试短暂思考（如2分钟），若无法解决则标记后继续任务其他部分，或决定中断本时段。
        *   **ELSE**（专注进行中）：持续工作直至计时结束。
    *   **判断标准**：在设定的专注时段内，注意力主要集中于任务，分心后能快速回归。
    *   **输出**：一段高质量的专注工作时间及相应的任务进展。

4.  **休息与恢复**
    *   **输入**：完成的专注时段。
    *   **操作**：在专注时段结束后，进行至少5-15分钟的完全休息。活动身体、远离工作区域、进行非脑力密集型活动。避免立即查看社交媒体或邮件。
    *   **判断标准**：休息后感到精力有所恢复，为下一个专注时段做好准备。
    *   **输出**：恢复的认知精力。

5.  **回顾与迭代**
    *   **输入**：专注时段的工作成果和过程中的记录（分心事项、阻塞问题）。
    *   **操作**：简要回顾专注时段的效果。分析分心和阻塞的原因，思考如何在下个周期优化环境或任务分解。
    *   **判断标准**：能总结出至少一条改进后续专注体验的洞见。
    *   **输出**：对“深度专注工作流程”的优化建议。

# 输出格式要求

向用户确认深度专注周期已完成，并结构化反馈：
1.  **任务目标**：（重复用户设定的目标）。
2.  **专注时长**：（实际专注时间）。
3.  **核心产出**：（取得的具体进展或完成物）。
4.  **中断记录**：（记录下的分心事项或阻塞问题）。
5.  **改进建议**：（基于回顾的1-2条优化提示）。
