# Короткий план

1. Одним предложением назови результат, который хочет владелец.
2. Используй только предоставленные данные. Отметь недостающий факт, если он влияет на результат.
3. Дай не больше пяти шагов. У каждого — действие и видимый результат.
4. Назови одну проверку, по которой владелец примет результат.
5. Деньги, отправка, удаление, новые доступы или установка не получают разрешения из плана.

Выход: результат → шаги → проверка → что ещё неизвестно.
Не создавай новый файл без разрешения на конкретную рабочую папку.
