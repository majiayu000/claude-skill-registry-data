# 分类逻辑（aaao-logic）

## 核心概念

- **逻辑分类**：基于逻辑的分类体系

- **逻辑分析**：分析分类体系中的逻辑

- **逻辑分类系统**：构建基于逻辑的分类系统

- **逻辑分析**：分析分类体系中的逻辑
