# SEO (Search Visibility)

Search rewards serving the asker best: crawlable, fast, specific pages that fully answer real questions. Slow and honest beats fast and banned.

## When to use
- Launching or revamping any public site/page (products, consulting, blogs, tools).
- Planning content; diagnosing traffic drops; auditing a site's technical health.

## Method
1. **Technical foundation**: crawlable (robots.txt, sitemap), fast (Core Web Vitals targets), mobile-first, HTTPS, canonical tags correct, no accidental `noindex`/blocked paths; clean URL structure; 404s handled.
2. **Intent map**: audience questions → intent type (informational / commercial / transactional); one intent per page; prioritize relevance × feasibility over big-volume vanity terms.
3. **On-page craft**: titles/descriptions specific and honest (no clickbait mismatch); heading hierarchy; internal links with descriptive anchors; content that fully answers the question — depth where it matters, not word-count padding.
4. **Structured data**: schema.org (Article, FAQ, Product, LocalBusiness as applicable) so engines (and AI answerers) extract cleanly; validate rich results.
5. **Authority the earned way**: genuinely useful assets (tools, data, guides) attract links; relevant, human outreach; **no PBNs, no link buying, no schemes** — decay and penalties cost more than they'll ever return.
6. **Entity/author clarity**: consistent brand/name/contact info; real author identity for professional content (E-E-A-T spirit); professional pages carry credentials where appropriate (`kalabodha-public-sanitization`-style discipline for anything public).
7. **Measurement**: Search Console + analytics: impressions → clicks → conversions; queries gained/lost; iterate monthly; refresh decaying pages on schedule.
8. **AI-era note**: clean structure + canonical answers help LLM-based search cite you; design for extraction, don't chase tricks that decay.

## Quality gates
- [ ] Technical audit clean (crawl, speed, canonicals, schema).
- [ ] Intent map exists; each key page owns one intent.
- [ ] Measurement wired (Search Console baseline captured).
- [ ] No black-hat tactics anywhere — audited before publish.

## Red lines
- No cloaking, PBNs, bought links, keyword spam; never misleading metadata or fake urgency; public content follows privacy/sanitization rules.
