# 上海交通大学电院 MEM 毕业论文写作技能（v2.0）

## ⚠️ 重要声明

本技能生成的全部内容**仅供参考**，不可作为毕业论文直接提交。
实证分析与数据章节的数据需要用户自行补充真实研究数据。
提交人必须对最终论文内容承担学术诚信责任。

---

## 一、MEM 学位论文的内核

> 通过特定形式与篇幅的文章，证明获得该学位的毕业生具备使用本专业的
> 知识体系（管理科学）解决应用场景中的问题（技术驱动的工程项目管理）
> 的能力。

**三条逻辑线必须并行**（出自浅见社 0914 研究框架 p.6）：

1. **工程项目线**：提出问题 → 分析问题 → 解决问题
2. **研究方法线**：选取方法 → 使用方法 → 论证成果
3. **数据分析线**：采集数据 → 分析数据 → 应用数据

---

## 二、论文类型（教指委 3 分类）

| 类型 | 字数目标 | 侧重点 |
|---|---|---|
| **工程管理专题研究类** | **3 万字 / 60 页** | 对所从事领域中的工程管理特定问题进行分析、研究、改进、实现，综合应用基础理论、专业知识和管理知识 |
| **工程管理设计类** | 2 万字 / 40 页 | 对产品 / 系统 / 设施 / 流程 / 方案进行创新性设计；重点阐述设计背景、需求分析、设计依据、设计过程及验证结论 |
| **工程管理案例研究类** | 2 万字 / 40 页 | 以成功或失败的工程管理实践为研究对象，调研与数据收集、分析、归纳，提出建议或解决方案 |

LLM 应基于用户主题 + 岗位职责 + 数据可获得性自动判定类型。

## 三、正文 6 章 canonical 结构（SJTU 电院 MEM）

| 章 | 标题前缀 | 核心内容 |
|---|---|---|
| 第一章 | **绪论** | 研究背景 / 研究意义 / 国内外研究现状 / 研究方法 / 研究内容 / 研究创新点 / 论文结构安排 |
| 第二章 | **理论基础与文献综述** | 管理学理论 + 行业现状 + 国内文献综述 + 国外文献综述 + 现有研究评述 + 概念说明 |
| 第三章 | **项目介绍与现状分析** | 所研究的工程项目背景 / 目标 / 特征 / 过程 / 资源；问题识别与剖析 |
| 第四章 | **研究成果与数学建模** | 研究方法应用 / 数学建模 / 计算公式 / 数据结论 / 权重 / 排序 / 方案 / 计划 |
| 第五章 | **实施验证与价值评估** | 采取措施 / 采纳方案 / 形成计划 / 实施规划 / 应用效果评估与验证 |
| 第六章 | **总结与展望** | 全文总结 / 主要结论 / 研究不足 / 研究创新点 / 后续工作展望 |

**章节命名规则**：每章标题以上述规范前缀开头，可在冒号 / 破折号后追加针对具体研究对象的副标题（例如 "第三章 N 公司 A 客服系统研发项目质量管理现状分析"）。

**每章必须以「本章小结」段落收尾**（200-300 字）。

**前置部分**（不计入 6 章，由装配层渲染）：
- 中英文封面
- 独创性声明 + 学位论文版权使用授权书
- 中文摘要 + 英文摘要
- 中英文关键词
- 论文目录

**后置部分**（不计入 6 章，由装配层渲染）：
- 参考文献（GB/T 7714 顺序编码，[1]…[N]）
- 攻读学位期间发表的论文目录
- 致谢
- 附录（可选）

| 进度管理 | 19.39% | 实施数据/历史记录/节点日期 → 阶段/趋势/偏差/风险 → 监控/响应/干预/调整 → 按时按量完成 |
| 流程管理 | 12.85% | 方案/步骤/输入输出/依赖 → 资源配置/信息流动/状态映射 → 优化/设计/策略 → 优化实施方案 |
| 运营管理 | 10.86% | 库存/供应链/精益生产数据 → 产品分类/稳定性/预测 → 库存策略 / 上下游设计 → 提高资源利用率 |
| 成本管理 | 6.89% | 投入成本/产出效益/资源结构 → 趋势/效益/回报/分配/差异/权重 → 控制/驱动/优化 → 降本增效 |
| 需求管理 | 2.92% | 客户满意度/需求实现/投入资源 → 优先级/关联/冲突/满足度 → 动态/决策 → 更合理产品方案 |
| 绩效管理 | 1.64% | 项目目标/组织个人行为/资源投入 → 绩效有效性/激励性/动态变化 → 效果/合理性/影响 → 提高积极性 |

## 五、5 类研究方法（教指委 + 浅见社）

| 方法 | 适用场景 | 数据获取门槛 |
|---|---|---|
| **实验数据研究** | 主动操控自变量 | 高，但因果推断能力强 |
| **准实验数据研究** | 自然环境/仿真 | 中，对数据处理能力要求高 |
| **问卷调查研究** | 选取被调查者 + 针对性问卷 | 中等 |
| **案例研究** | 同类案例经验性实证 | 低-中 |
| **二手数据研究** | 公开/半公开数据集 | 低，需评估真实性与有效性 |

## 六、5 类分析方法 + 工具库（浅见社 0914 p.26-34）

### 1. 因果分析
- 分析原理：在相关基础上系统性、逻辑性的因果关系验证
- 工具：5W1H / 鱼骨图 / 根因分析法（RCA）

### 2. 价值分析
- 分析原理：衡量不同特性的价值差别与产生价值的能力
- 工具：价值流（VSM）/ 价值工程（VE）

### 3. 权重分析
- 分析原理：通过系统性比较得出相对重要性的量化值
- 工具：**层次分析法（AHP）** / 敏感性分析 / 熵权法 / **TOPSIS**

### 4. 竞争分析
- 分析原理：基于历史数据与市场现状的趋势推测
- 工具：**SWOT** / 波特五力模型 / 质量屋（QFD）

### 5. 预测分析
- 分析原理：基于历史规律延续性与事件相关性
- 工具：**蒙特卡洛模拟** / 决策树 / 时间序列预测

> 第四章「研究成果与数学建模」必须显式选定上述任意一种分析框架并完整应用，不仅是点名工具，要把分析逻辑展开。

## 七、教指委 6 评价维度 + 权重

LLM 复核与 review agent 必须按此 6 维度 + 权重打分：

| 维度 | 权重 | 评分要点 |
|---|---|---|
| 论文选题 | **15%** | 问题导向、来源于工程管理实践、代表性、难度、足够工作量 |
| 文献综述 | **10%** | 文献资料的质与量、国内外动态跟踪、引用标注分析水平、≥30 篇 |
| **内容与方法** | **30%** | 研究目标明确、思路清晰、方法正确、详实调研与数据分析 |
| 成果与应用性 | **20%** | 可验证性、应用性、新颖性、潜在效益 |
| 基础知识与理论应用 | **15%** | 基础知识扎实、技术先进性、严谨科学作风 |
| 写作规范性 | **10%** | 结构合理、表达准确、图表公式引文规范 |

## 八、GB/T 7714 引用格式

参考文献顺序编号 `[1]…[N]`，正文内联引用 `[N]` 格式严格对齐：

- 期刊：`[N] 作者. 题名[J]. 期刊名, 年份, 卷(期): 起止页码.`
- 专著：`[N] 作者. 书名[M]. 版次. 出版地: 出版社, 年份: 起止页码.`
- 学位论文：`[N] 作者. 题名[D]. 学位授予地: 学位授予单位, 年份.`
- 网络文献：`[N] 作者. 题名[EB/OL]. 发表年-月-日 [引用年-月-日]. URL.`
- 缺字段时降级到最近上级模板，不抛错（参 PLAN-030 Slice 3）。

## 九、写作约束（学术不端红线）

1. **绝不为「项目介绍 / 研究成果」等章节生成具体数值、问卷统计、访谈节录、案例数据**。空缺处统一以 `[用户补充：xxx]` 标记。
2. **绝不杜撰参考文献**。所有引用条目必须来自 literature 工人输出的 `citation_pack.entries`。
3. **披露 AI 使用**：提示用户在论文「致谢」或「研究方法」章节按学校要求披露 AI 辅助。
4. **避免**「首次」「领先」「填补空白」「创造性地」等绝对化词语（教指委标准明文禁止）。
5. **不要生成元注释**：LLM 输出必须直接是章节正文 Markdown，禁止「好的，以下是修订版本」「作为您的助手」等回应性开场白。
