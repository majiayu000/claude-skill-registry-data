# asymmetric-betting

## When to Use

当需要在众多机会中筛选出投入产出比最高的选项，以最小化风险并最大化潜在回报时description

## Core Logic

# 执行步骤

1.  **识别非对称机会**
    *   **输入**：对市场、技术、个人技能或社会趋势的观察。
    *   **操作**：寻找符合“前期投入（时间/金钱/精力）相对较小，但成功后可能带来巨大回报”特征的机会。评估其启动门槛和潜在天花板。
    *   **判断标准**：能清晰描述该机会的“低投入”特性和“高回报”潜力。
    *   **IF** 未找到符合标准的机会 **THEN** 返回步骤1，扩大观察范围或调整评估标准。
    *   **ELSE** 进入步骤2。

2.  **评估与选择**
    *   **输入**：步骤1识别出的一个或多个非对称机会。
    *   **操作**：对比不同机会，评估其与个人技能、兴趣、资源的匹配度，以及市场时机的成熟度。选择1-2个最可行、最匹配的机会作为行动目标。
    *   **判断标准**：选定一个具体、可启动的行动方向。
    *   **常见误区**：试图同时开始多个项目，导致精力分散，无法在任何一项上取得进展。

3.  **执行“公式”**
    *   **输入**：选定的非对称机会。
    *   **操作**：按照“前期小额投资 + 持之以恒 + 迭代”的公式执行。
        *   **3.1 小额启动**：以最低可行成本（如利用免费资源学习、使用基础工具）开始行动，产出最小可行产品（MVP）或服务。
        *   **3.2 持续投入**：在较长时间周期内（如数月或数年），定期、专注地投入时间进行创作、交付或优化。
        *   **3.3 收集反馈并迭代**：基于市场或用户的反馈，不断调整和优化你的产品、服务或内容。
    *   **判断标准**：行动已启动并进入“投入-反馈-优化”的循环。
    *   **常见误区**：初期追求完美而迟迟不开始；遇到初期挫折就放弃，未能“持之以恒”；不根据反馈进行调整，固守最初想法。

# 输出格式要求
输出应清晰陈述所选的非对称机会，并概述按照“公式”执行的初步行动计划，包括启动方式、持续投入的频率以及计划如何获取反馈。
