# 竞品营销拆解

目的不是罗列竞品动作，而是回答：它为什么有效/无效？我方能复用什么、差异化打哪里？

## 数据契约

竞品名单（1–3 个直接竞品+1 个跨界标杆）、我方定位与资源；可用数据：竞品公开账号内容（笔记/视频/文章列表与互动数）、三方工具导出（蝉妈妈/飞瓜：抖音销量与达人；千瓜/新红：小红书投放；新榜：公众号）、电商页面（价格/SKU/评价/问大家）、落地页与广告素材（公开可见）、用户评价语料。

## 拆解框架

### 1. 定位与信息屋

- 一句话定位（对谁/什么场景/什么差异/什么信任状）；主张层级：品牌主张→品类卖点→产品证据；
- 价格带与人群象限；与我方的正面冲突区与空白区。

### 2. 内容矩阵

- 各平台账号布局（官号/矩阵号/达人分发）、内容栏目与比例（种草/测评/剧情/干货）、爆文规律（标题钩子/封面/评论区运营）；
- 搜索卡位：竞品占了哪些词（小红书/抖音/百度），哪些词它没占。

### 3. 达人与投放

- 达人结构（头腰尾比例/类目/报备标识）、投放节奏（脉冲式大促 vs 常态铺量）；
- 信息流素材（公开广告库/刷到的广告）：钩子类型/卖点角度/落地页链路；
- 估算投放量级（三方工具投放笔记数/预估消耗，标注是估算）。

### 4. 电商与直播

- 货盘结构/价格机制/赠品策略、直播频次与货盘节奏、销量与评价（差评=我方机会点）、问大家高频顾虑。

### 5. 用户语料

- 竞品评论区/差评/问大家：未被满足的需求、信任缺口、服务槽点 → 我方内容与产品差异化弹药。

## 输出格式

```
## 竞品拆解（竞品 / 数据区间 / 数据来源）
### 定位对比表（竞品 vs 我方）
### 各维度拆解（内容/达人/投放/电商/语料）+ 证据
### 有效性判断：哪些动作值得复用（为什么有效）、哪些是无效内卷
### 差异化机会清单（空白词/空白人群/未满足需求/信任缺口）
### 我方行动建议（优先级/资源需求）
### 数据局限与估算标注
```

## 约束

- 只用公开信息与合法三方工具数据；不爬取需登录的数据、不获取竞品内部资料。
- 销量/投放金额多为三方估算，标注口径与误差可能。
- "抄作业"要过合规与知识产权（素材/文案抄袭有侵权风险），复用逻辑而非照搬素材。
