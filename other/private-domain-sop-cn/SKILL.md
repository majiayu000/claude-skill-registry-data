# 企微私域运营 SOP

私域 = 可反复触达的用户资产。国内合规载体是企业微信（个微群控/外挂属违规，封号风险）；核心是"分层触达+价值供给"，不是无差别群发。

## 输入

业务类型（电商/本地生活/B2B/教育/服务）、现有流量来源（包裹卡/门店/广告/公众号/直播）、客单价与复购周期、团队人力、目标（复购/转介绍/高客单转化/线索培育）。

## SOP 框架

### 1. 引流加粉

- 链路：广告/包裹卡/门店/直播间→企微活码（分渠道码，见 tracking-setup-cn）→自动欢迎语→首触价值（券/资料/服务）。
- 加粉率优化：利益点明确（"领 XX"而非"加好友"）、路径 ≤2 跳、加粉后 5 分钟内兑现承诺。
- 合规：不得强制关注/诱导分享；包裹卡好评返现属违规（平台治理），用"扫码领售后保障/会员权益"替代。

### 2. 标签与分层

- 标签体系：渠道来源、生命周期（新客/活跃/沉默/流失）、价值（客单/频次）、兴趣品类、关键行为（领券未用/加购未付）。
- 分层策略：新客 7 天培育期、活跃客周期复购触达、沉默客低频唤醒（月 ≤2 次）、高价值客 1v1 服务。

### 3. 触达节奏（防骚扰红线）

- 1v1：新客首周 2–3 次价值触达，之后按行为触发（浏览/加购/券到期）；群发每月 ≤4 次（企微官方群发频次限制以当期为准）。
- 社群：每日固定栏目（早报/福利/答疑）+ 每周活动；不刷屏；广告占比 ≤1/3。
- 朋友圈：每日 1–3 条，人设内容:产品内容 ≈ 2:1；企微朋友圈发布频次有官方上限。
- 所有触达给退订/免打扰出口；《个人信息保护法》：收集使用个人信息需告知同意，不买卖名单。

### 4. 转化与复购

- 新客首单：限时新人礼+低门槛体验品；复购：按消耗周期提醒（如护肤品 45 天）、会员日、积分；
- 高客单/B2B：1v1 顾问式跟进（内容培育序列见 wecom-touch-sequence-cn）；
- 裂变：老带新双向权益（合规：不强制分享、不搞多级分销返利——三级以上分销涉传销风险）。

### 5. 度量

加粉率、首触响应率、7 日留存、标签完整率、触达-转化率、复购率、私域 GMV 占比、单客维护成本；沉默率 >60% 说明触达策略失效。

## 输出格式

```
## 私域 SOP（业务 / 目标 / 人力）
### 引流链路与活码配置
### 标签体系表
### 分层触达日历（周视图：1v1/社群/朋友圈）
### 关键话术模板（欢迎语/首触/唤醒/复购）
### 转化活动机制
### 度量看板与红线清单
```

## 约束

- 不设计个微外挂、群控、爆粉软件方案；不买卖用户数据；短信营销须含退订方式。
- 教育/医疗/金融行业私域话术另有监管红线，先确认行业再给方案。
