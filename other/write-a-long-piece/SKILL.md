# Write a long piece

## What it does

The agent writes the full piece to the shape and the length that were
agreed, whether that is an article, a customer story, a newsletter, or
answers written against somebody else's criteria.

## Where it happens

The agent does this in three activities across five reference processes.
Each one names the activity as that process words it.

- **Write the Draft**
  - `ref/mkt/customer-case-study`, activity 10 -
    [Produce Customer Case Study](../../../../processes/marketing/customer-case-study.md)
  - `ref/mkt/customer-newsletter`, activity 6 -
    [Publish Customer Newsletter](../../../../processes/marketing/customer-newsletter.md)
  - `ref/mkt/long-form-content`, activity 6 -
    [Produce Long-Form Content](../../../../processes/marketing/long-form-content.md)
- **Write the Entry**
  - `ref/mkt/award-entry`, activity 8 -
    [Submit Award Entry](../../../../processes/marketing/award-entry.md)
- **Write the Proposal**
  - `ref/mkt/speaking-engagement`, activity 3 -
    [Secure Speaking Engagement](../../../../processes/marketing/speaking-engagement.md)

## What to record

Every draft at a version, and the DONE records of the patterns it works
inside. A claim it uses cites the register entry it came from.

That contract covers every activity this abstract agent takes on, and it
is repeated in `com.agentcatalog.agent/RECORDS.md`. What the abstract
agent does not do is in `com.agentcatalog.agent/NOT.md`.
