# CAD分幅、视口与图册布局

先读项目已确认图幅和图纸分类，沿`../cad-check-review/references/construction-drawing-workflow.md`调用当前布局方法。已有分幅可用则保留；用户未要求重分时只修真实遗漏/裁边/冲突，不拿全局重排替代局部调整。

## 已有方法

读取`../cad-check-review/library/knowledge/CAD_ANNOTATION_VIEWPORT_SCALE_CONTRACT_V1.md`及同目录`CAD_ANNOTATION_AESTHETIC_USER_REQUIREMENTS.md`的N02—N05/N13/N14/N18/N19。所需比例和字高公式已随前一文档给出，按当前实际视口与单位使用，不依赖作者本机机器合同或另一工程固定字高。

实际浮动视口读取Target/ViewCenter/CustomScale/Twist/Clip/冻结层，系统纸空间总览不当打印分幅。模型单位到纸面单位换算有物理证据时，`C=U/N`、`H=h/C`；N为1:N分母，U为每模型单位对应纸面单位数。不能只凭INSUNITS或题签猜比例，也不能取全图最常见C替代实际覆盖目标的视口。

## 操作顺序

1. 先核完整工程范围、首末桥/入口、专业覆盖及必要详图承接，再核分幅搭接和标注余量；局部无措施不等于可漏掉施工范围。
2. 读取实际布局和图框所在空间，按左至右/上至下等本套已定次序整理。保持WCS设计坐标，旋转视图而非旋转实物；辅助网格纸面摆正并保持真实坐标。
   - 用户已手调当前视口时，先准确绑定当前文档/图框/视口并取得其内存中的范围、转角、比例、裁剪和显示状态，保护未存修改；文件名最新或旧保存参数不能替代手调当前态。获准套用到另一图时只迁移所需窗口参数，依目标纸面框核范围和比例，不盲复制图签、图号及全部冻结状态。
   - 同一部位的总览、定位与局部放大页分别确定标注职责。只在大比例页表达的小标高/级数可按授权在总览条件隐藏，数据/原生关联仍保留；先稳定实际视口再核字高、方向和网格。图号与对应索引/目录按承接关系改，禁止跨角色全文替换。
3. 每幅对真实比例/单位/纸张和图签比例，尺寸/符号依实际覆盖C和原生样本换算；同一非注释性模型对象出现在不同C时需明确主设计幅或已验证方案，不能宣称自动同纸面字高。
4. 图名、图号、日期、图框/图签、指北针、详图索引及图纸目录按实际内容同步。字号、长索引和图例会占用版面，放入后再核图名/边框净距，不沿用空版固定位置。
5. 显示问题先核对象Visible、层off/freeze、VP冻结、裁剪和外参，不以隐藏一套标注当去重；乔木/地被/尺寸/网格各图种应显示哪些内容由项目要求决定。
6. 新视口仅采用当前条件已验原生建立方法。另一已验证样例Clone共用视图状态有反例，MVIEW独立建立后设置与核实际图面的方法可参考；不能直接推广旧视口句柄或Number。

同一布局排多张图时，先按实际图框/图签配对，每个图号再对应一个或多个浮动视口（例如一张内上下双幅）。仅按纸面最近距离匹配，可能把视口配到上一排图签。比较原施工图与改稿时，即使句柄相同，也看视口中心是否仍在本图框、窗宽/高、视向及覆盖位置是否相符；若本图窗变成全布局总览，先恢复该幅实际观察范围，再核它的内容。不要为一个异常图窗重建其余图幅。

## 后态

实际覆盖范围、比例、转角、冻结集合、图框图签、首末和跨幅标注逐幅核。模型排版、布局纸张、最终缩印是三个量；A2缩A3不能通过改设计模型冒充。PDF只在本次需要正式出图/打印验证时生成，普通区域检查沿原生实际图面。

保存后在当前文档复核受影响真实视口和纸面，不因排版完成例行重开；运行时Number=-1或冻结列表顺序变化不能单独判设计变化。新意见的本套分幅/纸张/密度留项目；比例换算、裁边、显示失效反例更新本Skill并核实际消费者。
