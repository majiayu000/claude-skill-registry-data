# 大促与节点营销策划

国内大促是"蓄水-预热-爆发-返场"的确定性节奏战；平台机制（满减/券/预售/现货）每年微调，方案以当年平台规则为准。

## 输入

节点与平台（天猫/京东/抖音/拼多多/线下/全渠道）、品类与货盘、预算、目标（GMV/新客/清库存/品牌）、历史大促数据（可选）、团队与供应链约束（库存/发货时效）。

## 全案框架

### 1. 节奏（以双11为例，具体日期按当年平台日历）

- 蓄水期（T-45~T-20）：种草内容+达人铺量+人群资产积累（A3/TI），收藏加购成本考核；
- 预热期（T-20~T-3）：预售/加购引导、会员提前购、直播预约、搜索卡位；
- 爆发期（开卖~T+3）：效果广告放量+直播大场+私域集中触达+客服承接；
- 返场期（T+3~T+10）：未付款催付、返场优惠、复购引导、复盘。
- 618（京东主场）/年货节（食品礼盒主场）/38节（女性品类）按品类调整权重。

### 2. 货盘与机制

- 主推款/引流款/利润款/清仓款分层；大促机制：跨店满减+店铺券+赠品+会员权益的组合（算清叠加后到手价与毛利）；
- 价盘合规：先涨后降属价格欺诈（监管重点）；预售定金规则、价保承诺要兑现；
- 库存与发货：爆款备货深度、超卖预案、发货时效承诺（平台考核）。

### 3. 渠道排期

- 种草（小红书/抖音/B站）→搜索承接（站内关键词+社交搜索）→效果广告（千川/万相台/京准通）→直播大场→私域触达（序列见 wecom-touch-sequence-cn）；
- 每渠道给：起止时间、预算、目标、负责人占位、依赖项。

### 4. 预算与目标拆解

- GMV 目标 = 流量 × 转化率 × 客单价，按渠道拆解；付费/自然/私域占比假设；保本 ROI 与分阶段考核口径（蓄水期看加购成本不看 ROI）。

### 5. 风险预案

素材断档、爆款断货、价格穿底（达人破价）、平台规则突变、客服爆量、舆情（虚假促销投诉）。

## 输出格式

```
## 大促全案（节点 / 平台 / 目标）
### 节奏甘特表（阶段×渠道×动作×预算×目标）
### 货盘与机制表（到手价/毛利测算）
### 目标拆解与分阶段考核口径
### 私域/直播/达人专项要点
### 风险预案与止损线
### 复盘模板
```

## 约束

- 平台当年规则（满减档位/预售/价保）未确认时标注"以当年招商规则为准"，不编造具体日期档位。
- 不设计先涨后降、虚假原价、刷单冲榜等违规机制。
- 预算方案给"保底/标准/冲刺"三档，不孤注一掷。
