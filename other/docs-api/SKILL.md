# Задача: docs/API.md из OpenAPI-спеки

Сгенерируй `docs/API.md` из OpenAPI-спеки (см. `$api-design`, `$swagger-coverage`).

1. Найди спеку: статическая `openapi.{yaml,json}`, рантайм-эндпоинт (`/documentation/json` · `/api-json` · `/openapi.json` · `/v3/api-docs`) или генератор.
2. **Спеки нет — не выдумывай API по коду**: остановись и предложи сначала `$swagger-audit` → `$swagger-cover`; документировать нечего, пока контракта нет.
3. Сводная таблица эндпоинтов (метод, путь, `summary`, auth, теги), группировка по тегам. По каждой операции: параметры, `requestBody`, `responses` по кодам — **только из спеки**.
4. curl-примеры на ключевые операции: реальные поля из схем, плейсхолдеры `<TOKEN>`, базовый URL из `servers`; синтаксис проверь (`bash -n`).
5. Версия — из `info.version`; в шапке файла — источник спеки и дата генерации.

Отдай путь к `docs/API.md` + источник спеки + число задокументированных операций (сверь со спекой). Опирайся на `$technical-writing`.
