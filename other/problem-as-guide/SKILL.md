# problem-as-guide

## When to Use

当在行动或追求目标过程中遇到挫折、痛苦或不满等负面体验时，调用此模型将负面体验转化为指引方向的积极信号。description

## Core Logic

# 执行步骤

1.  **捕捉负面信号**
    - **输入**：在行动过程中产生的任何负面体验（如挫败感、厌倦、焦虑、不满）。
    - **操作**：立即记录该体验的具体情境和感受，而不是忽略或强行克服它。
    - **判断标准**：是否清晰描述了“在什么情况下，我感到什么样的负面情绪”。
    - **输出**：一个具体的负面体验记录。

2.  **转换问题视角**
    - **输入**：步骤1记录的负面体验。
    - **操作**：将“这是一个需要消除的麻烦”的视角，转变为“这是一个揭示我思维或能力盲区的线索”。提问：“这个痛苦/困难，试图告诉我什么需要被解决或学习？”
    - **判断标准**：是否将情绪反应转化为一个待探究的、关于自身或方法的问题。
    - **输出**：一个初步的问题化表述。

3.  **确认问题的指引价值**
    - **输入**：步骤2得出的初步问题。
    - **操作**：判断该问题是否指向：
        - **IF** 问题指向外部不可控因素或偶然事件 → 则归类为“噪音”，可记录但暂不深究，返回主要行动。
        - **ELSE IF** 问题反复出现，或指向自身认知、技能、价值观的冲突 → 则确认为“指引性信号”，进入步骤4。
    - **判断标准**：能明确区分“偶然麻烦”与“重复出现的、指向内在限制的模式”。
    - **输出**：一个被确认为具有指引价值的核心问题，或决定忽略当前信号。

4.  **将问题作为下一阶段输入**
    - **输入**：被确认为“指引性信号”的核心问题。
    - **操作**：将此问题正式作为“自然指南针”模型步骤3（定义核心问题）的输入，启动后续的“研究-扩展-解决”流程。
    - **判断标准**：是否将该问题纳入了系统性的分析解决流程，而非停留在抱怨层面。
    - **输出**：一个待深入分析和解决的关键议题，整合到个人成长循环中。

# 输出格式要求
输出对当前负面信号的诊断结论：
- **信号类型**：[“指引性信号”或“噪音”]
- **核心问题**：[如果是指引性信号，则陈述问题]
- **后续动作**：[“启动深入分析”或“记录并继续观察”或“忽略，继续原计划”]
