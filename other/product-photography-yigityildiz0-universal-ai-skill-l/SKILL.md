# Product Photography

Create a coherent product image set using the active host’s image capability. Do not choose a provider or model automatically.

## Intake

Establish the product, non-negotiable identity details, audience, channel, brand constraints, target ratio, and whether a reference image is authoritative. When the product must remain exact, treat every visible label, logo, geometry, color, material, and included accessory as a preservation requirement.

## Plan the image set

Choose only shots that serve the channel:

| Need | Reliable shot |
|---|---|
| Listing lead | clean packshot or hero |
| Product understanding | alternate angle and detail |
| Size | scale or in-hand view |
| Use case | lifestyle scene |
| Range | collection or variants |
| Conversion support | feature/included-items frame |

For a full e-commerce set, use 5–9 complementary images rather than repeating the same angle.

## Direction

1. Match lighting to the material: diffuse for catalog clarity, rim/controlled reflection for premium tech or glass, natural light for believable lifestyle scenes.
2. Use a centered, uncluttered composition for packshots; reserve negative space and contextual props for campaign/lifestyle images.
3. Specify camera angle, background, shadow, surface, material behavior, and exclusions in the prompt or edit brief.
4. Keep one visual system across the set: consistent white balance, perspective, texture treatment, background family, and crop logic.
5. Generate or edit one representative frame first; inspect identity before scaling the set.

## Verify

- Compare every output with the authoritative product/reference.
- Check text, logo, quantity, ports, seams, labels, geometry, and unwanted invented accessories.
- Check crop, resolution, color space, and marketplace requirements against the channel’s current official rules when relevant.
- Do not state a marketplace requirement from memory when the asset will be published.

## Guardrails

- Do not fabricate certification marks, claims, packaging text, reviews, or people using the product without authorization.
- Do not silently alter the product to make it more attractive.
- Keep source assets and generated variants clearly named; do not overwrite the original.
