# skill-market-alignment

## When to Use

当个人技能与市场需求不匹配，需要调整技能组合以实现职业或商业目标时description

## Core Logic

# 执行步骤

1.  **评估现状**
    *   **输入**：个人当前的核心技能列表、过往的变现尝试结果（成功/失败）。
    *   **操作**：分析当前核心技能在目标市场中的需求强度、变现潜力和竞争情况。识别过往尝试未能成功变现的主要原因。
    *   **判断标准**：能够明确指出当前技能组合的“市场价值缺口”或“变现瓶颈”。
    *   **输出**：一份现状分析报告，包含优势技能、市场短板及初步问题诊断（如“有创造力但缺乏变现渠道”）。

2.  **识别辅助技能**
    *   **输入**：步骤1的现状分析报告、目标行业/岗位的技能要求调研。
    *   **操作**：研究目标市场更重视且能与你核心技能形成互补的“辅助技能”。评估学习这些辅助技能的可行性（资源、时间、成本）。
    *   **判断标准**：找到至少一个能将核心技能“产品化”或“市场化”的具体辅助技能方向。
    *   **输出**：一个或多个候选的辅助技能列表，并说明其与核心技能的互补关系。

3.  **制定学习与整合计划**
    *   **输入**：步骤2输出的辅助技能列表。
    *   **操作**：为选定的辅助技能制定具体的学习路径（如课程、项目实践）。规划如何将新学的辅助技能与原有核心技能进行整合，形成新的、更具市场竞争力的复合技能组合。
    *   **判断标准**：计划包含明确的学习资源、时间节点和预期的整合产出（如“学习编程，将设计能力转化为可交互的网页”）。
    *   **输出**：一份包含时间线的学习与技能整合计划。

4.  **验证与迭代**
    *   **输入**：步骤3计划执行后的初步成果（如完成课程、做出项目作品）。
    *   **操作**：将新的复合技能组合投入市场进行小规模验证（如求职、接小型项目、发布最小可行产品）。收集市场反馈（薪资、客户反应、产品销量）。
    *   **判断标准**：新的技能组合是否带来了比之前更高的市场认可度或变现效率。
    *   **IF** 验证成功（获得正面反馈或初步变现）**THEN** 进入“放大与深化”阶段，持续投入。
    *   **ELSE**（验证失败或反馈不佳）**THEN** 返回步骤2，重新评估辅助技能的选择或调整整合方式。

# 输出格式要求

向用户呈现一个清晰的技能调整路径图，包括：
1.  当前技能与市场的错位分析。
2.  建议学习的辅助技能及其理由。
3.  一个分阶段的学习与实践计划。
4.  明确的下一步验证行动建议。
