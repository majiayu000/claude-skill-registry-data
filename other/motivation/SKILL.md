# Motivation：精致、紧凑的学术 Excalidraw 图

用户提供一张参考图时，保留其科学含义与关系，按本 skill 的视觉风格重新组织版面，交付真正可编辑的 `.excalidraw`、高清 `.png` 和 `.pdf`，同时提供预览与 SVG。以当前用户要求覆盖这里的默认偏好。不能把整张参考图作为唯一图片贴进 Excalidraw。

## 开始工作

- 先查看输入参考图和 [GRPO 风格样例](assets/grpo/motivation.png) 与 [Transformer 风格样例](assets/transformer/motivation.png)。示例是视觉基准，不是科学内容模板：不要自动复制样例文案、阶段数或反馈关系。
- 从参考图提取模块、实体、文字、比较关系、流程方向、成功/失败等语义。文字确实看不清且会改变科学含义时，向用户询问；可先完成独立的布局工作。不要编造论文结论。
- 修改已有图时，先找到**当前实际路径**及最新 `.excalidraw`，备份后编辑。文件可能被用户移动；旧的生成脚本、scene-source.json 和上次预览不能覆盖用户手动改过的文件。
- 输出目录用用户指定位置；未指定时就近创建结果目录。不要改动 skill 自带样例或把本次内容写回 skill。

## 默认视觉语言

- 白底、黑/深灰色手绘圆角边框，少量浅色底与原生 hachure 填充；流程箭头采用适量红色。用对齐、层级和分组产生空间感，避免大面积装饰阴影。
- 实体（机器人、雪花、锁、奖杯、书本等）用风格统一的**原色彩色卡通图标**，优先 Flaticon 彩色描边系列。不能把“组件偏黑白灰”理解为把图标灰度化；不要用线条手绘实体。图标清晰可辨，书本/清单不得缩成难以识别的角标。
- 正文、容器、箭头、分隔线、token、标签使用 Excalidraw 原生元素；复杂公式优先按用户偏好通过 LaTeX Live 渲染为 SVG，再作为图片内嵌，保留对应 LaTeX 源码。默认 Comic Shanns（fontFamily 8），卡通感适度、整齐可读；中文使用支持中文字形的字体并实际验证。
- 高信息密度优先：先改布局，再压缩间距，最后才考虑小幅调整字号。不要靠缩小所有内容或添无意义图标来“消灭空白”。
- Motivation 图可优先尝试紧凑的纵向模块；Method 图按用户偏好优先采用横向主流程，长宽比可参考约 2.0–2.4:1，保留丰富的机制细节、反馈关系与语义图标，并加强原生手绘轮廓和填充。根据具体内容调整，不强行让每个子模块横排，也不添加无语义依据的循环或重复总结。

详细尺寸、图标规则与布局方法见 [references/style-and-layout.md](references/style-and-layout.md)。选图标时读 [references/icon-sources.md](references/icon-sources.md)。

## 制作与迭代

1. 建立语义清单与简洁的布局草案，标明每个组的边界和阅读顺序。流程箭头表达真实关系，比较项不强行画成因果链。
2. 新图可使用 [scripts/scene_builder.py](scripts/scene_builder.py) 输出 skeleton JSON，再由实际 Excalidraw 库生成规范元素；已有文件直接编辑其元素，保留 ID、图标数据、用户的局部调整。
3. 遇到含上下标、期望、分式等数学公式时，按 [references/rendering.md](references/rendering.md) 的公式流程，优先进入 https://www.latexlive.com/ 编辑并取得渲染 SVG。公式图片是原生文字要求的明确例外，不要将整张图栅格化。
4. 先完成一版可查看的图，再针对**具体问题**迭代：长句断行、说明栏过宽、标签占整行、模块内部大块空白、图标比例不一、连线绕远、文字被遮挡。可以改内容表达，但不能改变事实与论证。
5. 渲染后同时查看全图和最密集局部。碰撞检查须覆盖**整个文本矩形**与图片边界，而不是只看锚点。书本可以部分叠在机器人身前表达组合实体，但不能覆盖 模型名称等文字。
6. 修改尺寸或位置后重新导出与检查。完成标准：语义完整、关键字体与图标在目标尺寸下可读、无意外遮挡和裁切、空白有分组作用、导出与最新源文件一致。不要承诺期刊接受或无限迭代；没有明显未解决问题即可交付。

## 导出与交付

使用 [references/rendering.md](references/rendering.md) 和 [scripts/export_scene.mjs](scripts/export_scene.mjs)。脚本使用真实 Excalidraw SVG 导出及浏览器 PDF，支持自动画布尺寸、内嵌图标和 3 倍 PNG。

- **新建模式**：skeleton JSON → `.excalidraw` + SVG + PNG + PDF + preview。
- **已有源文件模式**：直接读 `.excalidraw`，不经过 skeleton 转换、不重新量字或重排，仅导出。输入与输出源文件同路径时不写回源文件；不同路径时保存字节一致的副本。
- PNG 默认 3× 像素尺寸、300 dpi 元数据；PDF 保留文本/线条的矢量性质，图标仍是其原始位图。不能通过修改 dpi 标签代替增加像素。
- 验证输出尺寸、PDF 页数、图标完整性和源文件完整性，并实际看图。只做适当的技术检查，不把“通过脚本检查”当成审美验证。
- 最终给出预览、可编辑源文件、PDF 的简洁链接；所有结果放到用户指定位置。图标来源与已知授权状态记录到结果目录，不宣称未核实的出版授权。

调用示例：`使用 $motivation，根据这张参考图生成同风格的紧凑学术图，保存到 <输出目录>，交付 Excalidraw、PNG 和 PDF。`
