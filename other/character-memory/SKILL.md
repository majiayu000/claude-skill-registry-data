# Character Memory Skill (角色记忆与连续性状态)

`skills/character-memory.md` 负责维护角色在多场次、多镜头、跨剧集之间的动态记忆与状态继承，杜绝长篇 AI 剧集中角色“每场戏重新做人”的脱节现象。

---

## 1. 核心职能

在真实影视表演中，演员进入新的一场戏时，必然携带着上一场戏的**生理残留**与**心理余波**。

本模块跟踪记录：
1. **Emotional Residue (情绪余波与衰减)**：刚经历激烈争吵、惊吓或欢愉后，生理肾上腺素不会瞬间归零，面部张力、呼吸深浅、视线警惕度会有残留。
2. **Physical Continuity (身体与物理状态)**：体能消耗、是否有外伤、受冻/出汗、衣物整洁度、发型凌乱度、左右手持物。
3. **Information & Secrets (信息差与信任动态)**：本场戏角色新获悉了什么事实？开始怀疑谁？隐藏了什么新秘密？
4. **Unfinished Actions (未完成动作意志)**：上一场戏被打断的动作（例如正欲倒水、正欲点烟、正欲开门）。

## 3. 跨场景状态转移规则

### 规则 1：无重大事件触发，情绪绝不发生跳变
- 错误案例：第 12 场结尾大哭分手崩溃，第 13 场开头无过渡直接若无其事地和同事开怀大笑。
- 正确修正：第 13 场开头即便是在面对同事，角色的笑容也是晚半秒挤出来的“社交面具”，同事转身后眼神立刻跌落回空洞，嘴角肌肉垮塌。

### 规则 2：追踪“道具与物理锚点”
角色上一镜头拿在手里的手机、钥匙、水杯，进入下一镜头必须有交代（仍在手中、随手放在玄关桌上、塞进风衣口袋），避免出现 AI 生成常见的“道具凭空消失或瞬间换手”。

### 规则 3：信息沉淀改变台词节奏
当角色获悉某个秘密后，即使台词不变，其反应时间、视线聚焦方式也会发生剧变：从原本的“即时回应”变为“先凝视对方眼角半秒，再给出简短回答”。
