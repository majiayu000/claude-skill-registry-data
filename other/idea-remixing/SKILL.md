# idea-remixing

## When to Use

当需要基于外部信息源创作具有个人特色的原创内容时description

## Core Logic

# 执行步骤

1.  **输入外部想法**：收集并理解至少一个来自外部（非你原创）的想法、观点或信息片段。
    *   **判断标准**：能够清晰复述该想法的核心主张或关键信息。
    *   **常见误区**：仅收集信息，未进行深度理解；或收集过多信息导致焦点分散。

2.  **识别个人滤镜**：明确你个人独特的“世界观”滤镜，即你基于个人目标、面临的问题或独特经历而形成的核心视角。
    *   **判断标准**：能够用一句话描述你的核心视角（例如：“从初创企业效率提升的角度看...”或“从解决社交焦虑的实践出发...”）。
    *   **常见误区**：滤镜过于宽泛（如“从积极的角度看”），缺乏独特性；或未能将个人经验抽象为可复用的视角。

3.  ##### IF 分支：是否能够将外部想法与个人滤镜建立连接？
    *   **IF (是)**：进入步骤4。
    *   **IF (否)**：返回步骤1，寻找更相关或更易激发连接的外部想法；或返回步骤2，重新审视和提炼你的个人滤镜。

4.  **进行混音创作**：将外部想法通过你的个人滤镜进行加工、阐释或重构。具体操作包括：用你的视角重新解读该想法、将该想法与你关注的问题结合、或用你的经历为例证来阐述该想法。
    *   **判断标准**：产出的内容既包含原始想法的核心元素，又明显带有你的视角、语言风格或问题关切，形成新的综合表述。
    *   **常见误区**：简单复述或转述外部想法，未添加个人视角；或完全脱离原始想法，变成了另一个不相关的话题。

5.  **输出原创内容**：将“混音”后的综合表述，组织成完整的、可发布的内容（如一段文字、一个视频脚本、一篇帖子）。
    *   **判断标准**：内容完整、逻辑自洽，并且读者能够感知到其中既有外部信息的借鉴，又有创作者独特的个人声音。
    *   **常见误区**：未注明灵感来源（虽非直接抄袭，但提及来源更佳）；或内容组织混乱，未能清晰呈现新旧想法的融合。

# 输出格式要求
输出应为一段完整的、具有个人视角的原创内容。内容应明确体现：
1.  所借鉴的外部想法的核心。
2.  创作者个人独特的滤镜或视角。
3.  两者融合后产生的新观点或新表述。
