# 素材疲劳监测与轮换

国内信息流素材是快消品：抖音爆量素材常见生命周期 3–14 天（远短于 Meta 的数周），小红书笔记衰退更慢但受限于社区分发。目标：在成本崩掉之前排好替换。

## 数据契约

素材层分天数据（近 14–30 天）：素材 ID/名、首投日期、消耗、展示、CTR、转化成本、CVR；账户总消耗（算依赖度）。小红书另要：笔记阅读/互动/搜索来源占比。

## 判据（经验值，用账户历史校准）

对每条素材看 3–7 天滑动趋势：

| 状态 | 信号 | 动作 |
|---|---|---|
| 🔴 立即替换 | CTR 较峰值跌 ≥30–40%，或成本连续 3 天超目标 20%+，且消耗仍在高位 | 停投或压预算，上新承接 |
| 🟡 预备替换（约 3–7 天寿命） | CTR 每天阴跌 5–10%；成本缓慢爬升；频次/重复触达升高 | 立即安排翻拍/混剪变体 |
| 🟢 健康 | CTR 平稳或上升，成本达标 | 不动，可小幅加量 |
| ⚫ 已死 | 连续多日几乎无消耗（平台不再分发） | 归档；分析死因供上新参考 |

辅助信号：

- 素材上线天数：抖音 >14 天仍做主力=高风险；>30 天基本进入长尾。
- 账户 Top1 素材消耗占比 >50% → 断档风险，无论它现在多健康。
- 同脚本/同模板变体集体衰退 → 是"创意方向"疲劳而非单素材疲劳，需要新方向而非混剪。
- 小红书笔记：互动率下滑+搜索流量占比升高=进入长尾搜索期，可停投流但保留笔记吃搜索。

## 国内特有的续命手段（按成本排序）

1. 混剪变体：换前 3 秒钩子/换 BGM/换封面/换结尾引导（成本最低，续命有限）；
2. 翻拍：同脚本换演员/场景/口播人（信任感重置）；
3. 新方向：换卖点角度/人群场景/剧情结构（真正解决方向疲劳）；
4. 达人原生素材授权投放（星图/蒲公英报备素材，原生感强，常比自制素材长寿）。

## 输出格式

```
## 素材健康盘点（区间 / 在投素材 N 条）
🔴 立即替换：[素材+证据+建议承接]
🟡 预备替换：[素材+剩余寿命估计+变体建议]
🟢 健康 / ⚫ 已死
**依赖度**：Top1 占比 X%；**上新建议**：本周至少 N 条（方向：__）
### 轮换排期表（日期 × 动作）
置信度 + 数据缺口
```

## 约束

- 不臆断"频次"数值：国内多数平台不开放素材级频次，用 CTR 衰减+上线天数+消耗趋势推断，并注明是推断。
- 区分素材疲劳与大盘竞争（全素材同跌→查 CPM/节点，转 cpa-diagnostics-cn 思路）。
- 上新数量建议匹配团队产能，不给不切实际的"每天 10 条"。
