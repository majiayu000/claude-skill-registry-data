# 写作与图表

先读[入口路由约定](../_shared/references/入口路由约定.md)，再按用户意图读取下面**一个相关流程**，直接承接用户已经提供的材料和要求。表中是内部选择依据，不是让用户逐项选择的菜单；明确意图不再问“要用哪个命令”。

覆盖：写作与图表。数据采集、实验与原创研究判断仍由研究者负责。其他阶段按[公开清单](../_shared/commands.yaml)转入对应入口。

| --- | --- |
| 大纲 | [outline](../paper-outline/WORKFLOW.md) |
| 分段写作 | [draft](../paper-draft/WORKFLOW.md) |

| 风格校准 | [style](../paper-style/WORKFLOW.md) |
| 图表建议 | [figure](../paper-figure/WORKFLOW.md) |
| 绘图代码 | [plot](../paper-plot/WORKFLOW.md) |
