# 公司风险速查

## 为什么必须做

> 实例：九方智投（9636.HK）表面是"港股上市金融科技名企"，实际刚被上海证监局责令改正+暂停新增客户 3 个月，2026 上半年溢利同比 **-96.3%**。
> **如果只 JD 匹配就投，会踩进一个正在塌方的公司。**

## 四类必查（每类一次搜索，搜索词模板在下面）

### 1. 监管处罚 / 合规
```
<公司名> + 处罚 / 被罚 / 责令改正 / 暂停新增客户 / 整改 / 监管
```
**高危行业重点查**：金融（证券投顾、支付、借贷）、教育（K12、教培）、医美、币圈/区块链、P2P 遗留、保健品、直播带货。

### 2. 业绩塌方
```
<公司名> + 业绩 / 财报 / 营收 / 利润 + 下滑 / 亏损 / 同比
```
看三个数：营收同比、利润同比、利润率变化。**利润同比 -50% 以上是红灯**。上市公式还要看股价是否腰斩。

### 3. 用户/员工投诉
```
<公司名> + 投诉 / 黑猫 / 虚假宣传 / 退款 / 裁员 / 欠薪
```
员工侧看：脉脉、看准网；用户侧看：黑猫投诉。

### 4. 业务模式本质（最重要，决定你进去干什么）
```
<公司名> + 商业模式 / 怎么赚钱 / 获客 / 转化
```
要能一句话说清"这家公司靠什么赚钱、我这个岗在链条的哪一环"。
- 例（九方）：`公域引流 → 0.1元低价破冰 → 私域卖 29800 元/半年投顾产品 → 存量复购`
- 落到岗位：**你要投的运营/内容岗，本质是获客转化（带销售 KPI），不是内容创作**

## 红线（命中任意一条 → 直接建议不投或极低优先）

- 🔴 近 12 个月内被**责令暂停新增客户 / 停业整顿**
- 🔴 利润同比下滑 **>50%**
- 🔴 核心业务（你要去的那个部门）正被新规收紧
- 🔴 大量投诉集中在**虚假宣传 / 诱导消费 / 退款难**（说明岗位在做擦边事）
- 🔴 上市公式股价较年内高点**腰斩**

## 黄线（要提示，但不一定不投）

- 🟡 行业整体在被整顿（不是它一家的问题）
- 🟡 依赖单一渠道/单一产品
- 🟡 刚完成整改、恢复经营（观察期）

## 输出格式

```
## 风险核查：<公司名>
| 维度 | 结论 | 证据 |
|---|---|---|
| 监管处罚 | 🟢/🟡/🔴 | ... |
| 业绩 | ... | 营收 X 同比 Y；利润 X 同比 Y |
| 投诉 | ... | ... |
| 业务模式 | 一句话：靠什么赚钱 | 你要投的岗在链条第几环 |

**综合：可投 / 谨慎投（只投 X 岗）/ 不投**
**如果可投，岗位选择上怎么规避风险**（例：避开直接做营销转化的岗，选后台/中台岗）
```

## 平衡原则

不要一味劝退。**持牌、有真实营收、行业地位明确的公司仍然是正经公司**。
要说清的是：
1. 它靠什么赚钱
2. 你的岗位在这条链的哪一段
3. 这段现在是被鼓励还是被打击
4. 结论交给用户自己选（"如果你要的是高薪+锻炼，可以投；如果你要的是 XX 主线，这里会稀释标签"）
