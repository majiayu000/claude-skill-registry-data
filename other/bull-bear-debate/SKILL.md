# Bull Bear Debate Skill

## Purpose

Generate bull case, bear case, and risk committee review.

## Inputs

- Target
- Market
- Industry
- Available data
- User requested depth
- Prior assumptions, if any

## Outputs

- Structured analysis
- Assumptions
- Missing data
- Confidence level
- Next required action

## Rules

- State assumptions explicitly.
- Flag missing or low-confidence data.
- Prefer conservative assumptions.
- Keep output auditable.
