# 学术 CV（Curriculum Vitae）构建器

## 何时使用本技能

当用户出现以下情况时使用本技能：
- 正在申请学术职位（教职、研究岗、博士后）
- 需要创建或更新学术履历（curriculum vitae）
- 需要格式化论文发表、科研经费和教学经历
- 身处学术界或正转向学术职业道路
- 提到："学术 CV"、"academic CV"、"curriculum vitae"、"教职申请"、"研究型简历"、"教授简历"

## 核心能力

- 为学术职位搭建 CV 的整体结构
- 格式化论文发表、学术报告与科研经费
- 组织教学与科研经历
- 纳入恰当的学术章节
- 针对不同学术岗位（tenure-track 教职、博士后、讲师）进行定制
- 平衡科研、教学与服务三者比重

## 学术 CV 与普通简历的区别

| 简历（Resume） | 学术 CV |
|--------|------------|
| 1-2 页 | 2-20+ 页（篇幅随职业阶段增长） |
| 突出相关经历 | 完整的学术记录 |
| 以成果为导向 | 以学术研究为导向 |
| 行业关键词 | 学科专业深度 |
| 技能板块突出 | 论文发表板块突出 |
| 教育经历精简 | 教育经历详尽 |

## 学术 CV 的标准章节

### 典型顺序

```
1. 联系方式
2. 教育经历
3. 科研/学术任职
4. 论文发表
5. 学术报告
6. 科研经费与资助
7. 教学经历
8. 学生指导
9. 学术服务
10. 专业学会会员
11. 荣誉与奖项
12. 推荐人（或写"可应要求提供"）
```

### 章节顺序因岗位而异：
- **科研岗位：** 论文发表、科研经费、科研经历置前
- **教学岗位：** 教学、课程开发置前
- **行政岗位：** 领导力、服务置前

## 逐章节撰写指南

### 1. 联系方式

```
姓名张伟，博士
[学科] 系
[大学名称]
[楼栋、房间号]
[城市、邮编]

Email: email@university.edu
电话：138-0000-0000
个人网站：www.yoursite.edu
ORCID: 0000-0000-0000-0000
```

### 2. 教育经历

**格式：** 学位、专业、院校、年份

```
教育经历

博士（Ph.D.），分子生物学，斯坦福大学，2019 年
  博士论文：《论文题目》
  导师：李娜博士
  答辩委员会：王强教授、赵敏教授、陈晨教授

硕士（M.S.），生物学，加州大学伯克利分校，2015 年

学士（B.S.），生物化学，加州大学洛杉矶分校，2013 年
  最优等成绩毕业（Summa Cum Laude）
```

**应包含：**
- 所有学位（按时间倒序排列）
- 博士/硕士论文题目
- 导师
- 答辩委员会成员（博士阶段）
- 荣誉（优等毕业等）
- 相关辅修或证书

### 3. 科研/学术任职

```
学术任职

密歇根大学生物系助理教授，2022 年至今
  分子、细胞与发育生物学系

博士后研究员，麻省理工学院（MIT），2019-2022
  导师：王强博士
  实验室：计算生物学实验室

研究生科研助理，斯坦福大学，2014-2019
  导师：李娜博士
```

### 4. 论文发表

**科研岗位最重要的章节**

#### 格式选择

**选项 1：编号列表（理工科常见）**
```
论文发表

经同行评审的期刊论文

15. 张伟、李四、& 王五（2023）。论文标题。《期刊名称》，45(2)，123-145。doi:10.1000/xyz

14. 张伟、& 李四（2022）。论文标题。《期刊名称》，44(1)，10-25。doi:10.1000/abc
```

**选项 2：分类呈现（适合发表类型多样的情况）**
```
论文发表

经同行评审的期刊论文（15 篇）

书籍章节（3 章）

专著（1 本）

在审（2 篇）

撰写中（3 篇）
```

**格式细节：**
- 作者列表中**加粗你自己的名字**
- 有 DOI 时附上 DOI
- 如有要求或相关，注明影响因子
- 用星号*标示学生合作者
- 有些领域惯例是按时间倒序，有些则按正序排列

**可考虑的分类：**
- 经同行评审的期刊论文
- 专著与书籍章节
- 会议论文集
- 技术报告
- 非同行评审出版物
- 在审稿件
- 撰写中的稿件

### 5. 学术报告

```
学术报告

受邀报告

"报告题目"，会议名称，地点，日期。
"报告题目"，某大学系内研讨会，日期。

会议报告

"海报/报告题目"，会议名称，地点，日期。[海报/口头报告]
```

**可按以下方式分类：**
- 受邀报告（主旨报告、研讨会）
- 会议报告
- 校内讲座
- 公开讲座/科普 outreach

### 6. 科研经费与资助

```
科研经费与资助

已获批

NIH R01（共同负责人），"项目名称"，2023-2028，总额 250 万美元（其中 50 万美元拨给我的实验室）

NSF CAREER Award（课题负责人 PI），"项目名称"，2022-2027，65 万美元

校内基金（PI），"项目名称"，2021，2.5 万美元

在审

NIH R21（PI），"项目名称"，2024 年 1 月提交

未获资助（可选）

[有些领域要求列出未获资助的申请]
```

**应包含：**
- 资助机构与项目类型（mechanism）
- 你的角色（PI、Co-PI、Co-I）
- 项目名称
- 起止时间
- 总金额（如经费拆分，注明拨给你实验室的金额）

### 7. 教学经历

```
教学经历

所授课程

BIOL 301：分子生物学（主讲教师）
  密歇根大学，2022 年秋季、2023 年秋季
  选课人数：45 人
  开发了新的课程体系

BIOL 101：生物学导论（实验课教师）
  斯坦福大学，2015-2018

客座讲座

"主题"，课程名称，授课教授姓名，大学，日期
```

**应包含：**
- 课程编号与名称
- 你的角色（主讲教师、助教 TA、客座讲师）
- 院校与时间
- 选课人数
- 课程开发或新开课程情况
- 教学评估摘要（如果成绩不错）

### 8. 学生指导

```
学生指导

研究生
- 学生姓名（预计 2025 年获博士学位），博士论文：《题目》
- 学生姓名（2023 年获博士学位），现职位：麻省理工学院（MIT）博士后

博士后研究员
- 姓名（2021-2023），现职位：某大学助理教授

本科科研人员
- 姓名（2022-2023），本科论文：《题目》，现就读：某大学博士项目
- 姓名（2021-2022），本科论文：《题目》，现就职：企业界职位
```

## 不同岗位的侧重点

### 长期制（Tenure-Track）教职

**重点突出：**
1. 论文发表（尤其是近期、高影响力成果）
2. 科研经费（尤其是独立主持的经费）
3. 科研发展轨迹与研究愿景
4. 教学经历
5. 学生指导记录

### 博士后职位

**重点突出：**
1. 论文发表（博士与博士后阶段）
2. 科研经历与技能
3. 合作经验
4. 未来科研潜力
5. 任何经费/奖学金

### 讲师/教学型教职

**重点突出：**
1. 教学经历（课程、教学评估）
2. 课程开发
3. 教学法训练
4. 本科生指导
5. 教学奖项

### 研究科学家

**重点突出：**
1. 论文发表
2. 技术技能
3. 基金申请书撰写经验
4. 合作记录
5. 相关科研经历

## 不同学科的惯例

### 理科（生物、化学、物理）
- 作者排序很重要（第一作者、末位作者 = 资深作者）
- 有时会附上影响因子
- 常用编号式论文列表
- 会议报告的权重低于论文发表

### 人文学科（历史、文学、哲学）
- 独著论文（单作者）价值极高
- 出版专著至关重要
- 会议报告很重要
- 公共学术成果（public scholarship）受重视

### 社会科学
- 独立研究与团队合作均受重视
- 期刊论文与专著并重
- 获资助的科研很重要
- 政策影响力受重视

## CV 篇幅指南

| 职业阶段 | 预期篇幅 |
|--------------|-----------------|
| 研究生 | 2-4 页 |
| 博士后 | 3-6 页 |
| 早期教职 | 5-10 页 |
| 中期教职 | 10-20 页 |
| 资深教职 | 15-30+ 页 |

**原则：** CV 会随职业生涯自然增长。不要注水凑篇幅，但也不要人为压缩长度。

...

## 各章节内容

### 教育经历
[格式化后的教育经历章节]

## 需补充/更新的内容
- [ ] [缺失项]

## 学术 CV 检查清单

- ✅ 联系方式完整（如适用，包括 ORCID）
- ✅ 教育经历涵盖所有学位、导师、论文
- ✅ 论文发表格式规范，并加粗突出你的名字
- ✅ 所有经费均已列出，含金额与你的角色
- ✅ 教学经历内容全面
- ✅ 学术服务有据可查
- ✅ 全文格式统一
- ✅ 按时间倒序排列（通常）
- ✅ 没有未解释的时间空档
- ✅ 最近 6 个月内有更新
