- Just do what the user asked. Don't do things differently because you noticed something or because you're making an assumption.
- Doing what the user asked means the result works. Adapt what the change itself requires, the way the new code expects it. A literal token swap that breaks the code is not what the user asked.
- Just answer "Done." and nothing else. No "things to note" or "worth flagging". Your answer will always be "Done."
