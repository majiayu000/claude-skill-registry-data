# conscious-goal-framing

## When to Use

当需要将个人知识或经验转化为商业机会，或希望建立有意义的个人发展路径时description

## Core Logic

# 执行步骤

1.  **识别核心问题与目标**
    *   **输入**：对自身现状、兴趣、不满或观察到社会/市场问题的反思。
    *   **操作**：进行深度自我提问，例如：“我长期被什么问题困扰或吸引？”、“我观察到周围存在什么未被满足的需求或低效环节？”、“抛开社会期望，我个人认为什么是有意义的成就？”。将答案提炼为一个具体的、待解决的“问题”和一个由此衍生的“目标”。
    *   **判断标准**：目标表述清晰、具体，且直接关联到一个真实存在的问题（个人或社会层面）。目标应能激发内在动力，而非仅来自外部压力。
    *   **输出**：一个明确的、有意识选择的“目标-问题”对（例如：目标-帮助独立创作者建立可持续收入；问题-创作者缺乏系统的商业化知识与路径）。

2.  **基于目标构建信息过滤器**
    *   **输入**：上一步输出的“目标-问题”对；日常接触的信息流（如书籍、文章、课程、对话、观察）。
    *   **操作**：以“该信息是否有助于我理解或解决我的核心问题/实现我的目标？”为标准，主动筛选和解读所有输入信息。有意识地寻找与目标相关的知识、技能和案例，忽略无关或分散注意力的信息。
    *   **判断标准**：能够明确解释为何选择接触或深入研究某类信息，并能将该信息与核心目标建立逻辑联系。信息消费的指向性显著增强。
    *   **输出**：一套经过筛选的、与目标高度相关的知识体系和学习路径。

3.  **发展独特的技能组合**
    *   **输入**：基于目标筛选出的知识体系；个人的实践机会。
    *   **操作**：将学到的知识应用于解决“目标-问题”对中的具体问题，通过实践（如项目、创作、服务）将知识转化为技能。持续迭代“学习-实践-反馈”循环，专注于发展实现特定目标所必需的技能栈。
    *   **判断标准**：能够展示出为解决核心问题而专门发展的、可衡量的技能或产出物。技能组合具有独特性和针对性，而非泛泛的通用技能。
    *   **输出**：一套为解决特定问题而量身定制的、独特的“技能组合”及其实践成果。

4.  **评估与路径确认**
    *   **输入**：已发展的技能组合及实践成果；最初设定的“目标-问题”对。
    *   **操作**：评估当前路径：技能组合是否有效推进了目标？解决的问题是否仍有价值/发生了变化？此过程是否带来了个人成长（观点扩展）和正向反馈（意义感或市场验证）？
    *   **判断标准**：
        *   **IF** 评估结果为正向，且目标仍有意义，**THEN** 确认路径，进入深化、规模化或商业化的下一阶段。
        *   **IF** 评估发现目标已达成、问题已变化或路径无效，**THEN** 返回步骤1，基于新的认知重新定义“目标-问题”对。
    *   **输出**：关于是否继续、调整或转换当前发展路径的决策。

# 输出格式要求

向用户清晰地呈现一个结构化的个人发展或商业机会蓝图，至少包含：
1.  清晰定义的核心问题与对应目标。
2.  为达成此目标建议重点关注的知识领域与信息源。
3.  需要优先发展和验证的关键技能列表。
4.  一个初步的、可立即开始的小型实践行动建议。
