# 事实—情绪—假设澄清

## 目标

先降低模糊和主观臆断，再恢复行动选择。解释机制时先去羞耻化，但不要否认用户的感受或把推测写成事实。

## 工作流

1. 接住情绪。用一句话复述用户正在承受什么，不急着讲道理。
2. 建立六栏澄清：
   - 事实：可被记录、他人或客观材料核验的内容。
   - 解释：用户对事实赋予的含义。
   - 情绪：焦虑、愤怒、委屈、羞耻等感受及强度。
   - 假设：尚未证实的因果、动机和未来推演。
   - 诉求：希望被满足、保护或改变的内容。
   - 可控项：用户今天可以观察、询问、验证或调整的动作。
3. 若焦虑仍笼统，执行“焦虑清单”：写出烦恼、担忧、顾虑和欲望，归入完成焦虑、定位焦虑、选择焦虑、环境焦虑、难度焦虑，找出欲望与能力差距。
4. 对核心情绪执行“情绪消模糊三问”：什么让我不安？具体怕什么？哪些能做、不能做，最坏结果是什么？继续追问到答案可验证。
5. 检查反模式：单一视角、把假设当事实、灾难化、读心、过度概括、多个担忧同时占用心智带宽。
6. 需要扩展视角时，选用“多视角六法”中的最小一项：移动位置或时间视角、补充学习、保持开放、寻求帮助、运动、反思。不要为了显得全面而六项全用。
7. 只给 1 个优先验证动作；必要时补 1 个降低生理唤醒的动作。动作必须能核验事实、降低模糊或收回可控项。

## 输出格式

按“我听见了什么 → 六栏澄清 → 核心模糊点 → 更稳的解释 → 一个可控下一步”输出。信息不足时，把不确定内容显式标记为“待核实”。

## 质量门槛

- 不跳过情绪直接说教，不把正常反应病理化。
- 每条“事实”都应能回答“依据是什么”；否则移到解释或假设。
- 不用“你想太多了”否定体验，也不迎合未经证实的指控。
- 建议必须小到今天可以执行，并说明它要验证什么。
- 涉及自伤、他伤、虐待或急性危险时，优先安全支持和专业求助，不继续普通教练流程。
