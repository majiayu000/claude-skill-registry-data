# autotelic-goal-setting

## When to Use

当设定个人或工作目标，希望目标本身能带来持续的内在动力和满足感时description

## Core Logic

# 执行步骤

1.  **识别内在兴趣点**
    *   **输入**：一个宽泛的生活或工作领域（如“职业发展”、“健康”）。
    *   **操作**：在该领域内，追问：“抛开所有外部奖励（金钱、名誉、认可），这个过程中有哪些环节或方面是我单纯觉得有趣、享受或好奇的？”列出这些内在兴趣点。
    *   **判断标准**：是否找到了至少一个纯粹因为过程本身而吸引你的活动？
    *   **IF** 找不到任何内在兴趣点 → 考虑更换目标领域。
    *   **ELSE** → 进入步骤2。

2.  **围绕内在兴趣构建目标**
    *   **输入**：步骤1识别的内在兴趣点列表。
    *   **操作**：选择一个兴趣点，将其转化为一个具体、可执行的目标。确保这个目标的达成过程主要依赖于你享受的那个环节。
    *   **判断标准**：想象自己正在执行目标，是否超过50%的动机来自于活动过程本身带来的愉悦，而非最终结果？
    *   **IF** 目标仍然主要依赖外部结果驱动 → 返回步骤2，调整目标描述，使其更聚焦于过程。
    *   **ELSE** → 进入步骤3。

3.  **剥离外部奖励依赖**
    *   **输入**：步骤2构建的初步目标。
    *   **操作**：进行思想实验：“如果完成这个目标后，绝对没有任何人知道，也带不来任何物质或社会回报，我是否仍然愿意去做？”审视目标，移除或弱化那些纯粹为了外部认可而设定的部分。
    *   **判断标准**：对上述思想实验的回答是否为“是”或“很大程度上是”？
    *   **IF** 答案为“否” → 返回步骤1或2，重新寻找或构建目标。
    *   **ELSE** → “自足目标”设定完成。

4.  **与行动系统绑定**
    *   **输入**：已设定的自足目标。
    *   **操作**：将该目标与具体的、可重复的行动系统（如每日习惯、项目里程碑）相结合。重点设计行动过程的结构，而非只盯着最终终点。
    *   **判断标准**：是否能够描述出一个不依赖最终结果评价的、可持续的日常或周期性行动模式？

# 输出格式要求
输出应包含：1）最终确定的自足目标描述；2）该目标的核心内在驱动力（即享受的过程是什么）；3）建议与之绑定的初始行动系统。
