# Judgment Chain — router

> *Break the rule you agreed to, and the chain does not negotiate.*

Judgment never builds. It rules. The agent names DONE; `scripts/done.sh` tests it.

## Selection — read exactly one

| Situation | Aspect |
|---|---|
| Phase claims done — gate criteria | `gatekeeping.md` |
| G4 claim sweep | `claim-audit.md` |
| Critique own work | `self-critique.md` |
| Other context available to prosecute | `hetero-critique.md` (mechanical: `scripts/emperor review-pack --check-isolation`) |
| Ruling / breach | `verdicts-and-breaches.md` |
| About to edit or G1 moved | `scope-guard.md` |
| About to write a hunk | `change-rationale.md` |
| Non-trivial decision, before DONE | `self-calibration.md` |

## Laws

1. Evidence opens gates; confidence does not.
2. Examiner stance — argue against admission.
3. Findings are claims.
4. Breach register is append-only.
5. Easy path is a breach. Scope drain and creep are breaches.
