# 人群洞察与画像（国内版）

好画像的标准：能直接推导出"在哪触达、说什么话、给什么钩子"。人口标签只是起点，场景与决策链路才是核心。

## 数据契约（有什么用什么）

业务信息（产品/价格/购买渠道）、现有客户数据（电商后台人群画像/生意参谋/罗盘、企微标签、CRM）、平台工具数据（巨量云图/灵犀/如翼/百度观星盘）、客服聊天记录与评价（差评/问大家是金矿）、竞品评论区。无数据时基于品类常识给假设画像并明确标注待验证。

## 画像框架（每层人群一份）

1. **身份与场景**：人口特征 + 生活/工作场景（"什么时候什么情境下需要这个产品"）；
2. **痛点与任务**：功能任务/情绪任务/社交任务（Jobs-to-be-done）；现有替代方案与不满；
3. **决策链路**：需求触发→信息搜索（搜什么词/在哪个平台）→比较维度（价格/成分/品牌/口碑）→购买渠道→购后行为（评价/复购/分享）；
4. **顾虑与异议**：不买的理由（价格/信任/效果怀疑/麻烦），逐条对应内容化解角度；
5. **触达地图**：内容平台偏好（小红书/抖音/B站/知乎/公众号/快手，按人群差异大）+ 搜索词 + 达人类型 + 私域场景；
6. **人群资产映射**：该人群对应 O-5A/AIPS/5R 的哪一层，运营目标（A2→A3 种草 / TI→P 转化 / R4→R5 复购）。

## 分层方法

- 反漏斗三层：核心人群（高痛点高匹配，先打透）→兴趣人群（场景相邻）→泛人群（破圈）；
- 电商可用价格带×人群象限（品质型/性价比型/冲动型/礼品型）；B2B 按角色分（使用者/决策者/采购者，痛点不同）。

## 验证路径

- 小预算内容测试（3–5 个角度×目标人群定向，看互动与搜索信号）；
- 客服/评论区语料核对画像用词（用户原话>内部术语）；
- 平台人群工具回看：触达人群与假设画像的偏差。

## 输出格式

```
## 人群洞察（业务 / 数据来源）
### 人群分层总表（核心/兴趣/泛）
### 每层画像卡（场景/痛点/决策链路/异议/触达地图/资产层）
### 内容角度推导表（人群×痛点×钩子×平台）
### 搜索词与达人类型清单
### 验证计划与待确认假设
```

## 约束

- 无数据支撑的画像标"假设"，给验证方式；不编造调研数据与百分比。
- 不输出刻板印象式结论（如"女性都爱粉色"）；差异用数据或语料证据。
- 涉及个人信息只用聚合画像，不做个体级追踪建议。
