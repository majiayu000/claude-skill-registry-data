# brand-identity-framing

## When to Use

当需要为个人或小型企业建立在线品牌身份，以吸引目标受众并建立共享认知框架时description

## Core Logic

# 执行步骤

1.  **定义核心价值主张**：基于你的知识、经验和技能，明确你能为目标受众提供的核心价值。输入：个人/品牌的核心能力清单。输出：一个清晰的价值主张陈述。
    *   **判断标准**：陈述是否同时包含了你帮助人们实现的“有意义的长期目标”和你帮助他们解决的“紧迫问题”。
2.  **构建品牌信息框架**：将价值主张转化为具体的品牌展示信息。输入：上一步的价值主张陈述。输出：用于网站、社交媒体等渠道的品牌信息元素。
    *   **判断标准**：信息是否隐含（而非直接说明）了“目标-问题-技能/兴趣”这个三元框架，从而在品牌与受众间建立共享认知。
3.  **迭代与形成**：持续通过内容（写作、设计、视频）传递品牌信息，并观察受众反馈。输入：品牌信息框架、发布的内容、受众互动数据。输出：随时间推移而巩固的在线品牌身份。
    *   **判断标准**：品牌身份是否在目标受众的关注和互动中逐渐清晰、一致，并被认可。

# 输出格式要求

提供一个包含以下要素的品牌身份框架文档：
1.  有意义的长期目标（我们帮助您实现...）
2.  紧迫的待解决问题（我们帮助您解决...）
3.  核心教授的技能/兴趣领域（我们通过教授...来连接目标与问题）
4.  品牌口号或个人简介示例（可选，需体现上述框架）
