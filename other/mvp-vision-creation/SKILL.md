# mvp-vision-creation

## When to Use

当需要为某个生活领域或项目确立一个初步的、可迭代的积极方向时description

## Core Logic

# 执行步骤

1.  **设定时间盒**：分配一个固定的、不受干扰的时间段（建议30分钟）用于本练习。
2.  **自由书写理想状态**：在设定的时间内，针对所选领域（如职业生涯、健康、人际关系），尽可能详细地写下你希望实现的理想未来状态。描述具体的情景、感受、拥有的东西、达成的目标。
    *   **判断标准**：产出包含具体细节（如“领导一个10人创新团队”而非“事业成功”）和情感体验（如“感到充实和有影响力”）的描述。
    *   **常见误区**：自我设限（“这不可能”），或写得过于空泛。
3.  **提炼最小可行愿景（MVV）**：从自由书写的内容中，提炼出最核心的、可在接下来一段时间（如3-6个月）内作为决策指引的1-3句话。这应是你愿景的“初稿”。
    *   **判断标准**：MVV简洁、鼓舞人心，且能直接用于过滤日常决策（例如，判断某机会是否与此一致）。
    *   **常见误区**：追求完美或完整，导致无法完成初稿。
4.  **计划回顾与迭代**：为这份MVV设定一个定期回顾的时间点（如每季度），并明确回顾时将根据“新经历和失败”对其进行添加、删除或修改。
    *   **判断标准**：有明确的下一回顾日期和迭代意向。
    *   **常见误区**：将愿景视为固定不变的文件，写完即束之高阁。

输出一份“最小可行愿景（MVV）”文档，包含：
1.  **愿景领域**：
2.  **详细自由书写稿**：
3.  **提炼的最小可行愿景（1-3句）**：
4.  **下一次回顾日期**：
