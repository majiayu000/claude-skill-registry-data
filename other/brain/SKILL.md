# 🧠 brain - 프로젝트별 작업 내역 기억 시스템

**각 프로젝트별로 작업 내용을 기억하고 복원합니다.**

## 핵심 특징

- **프로젝트 분리**: 각 프로젝트마다 별도의 기억 저장
- **자동 감지**: 현재 디렉토리의 프로젝트를 자동으로 인식
- **빠른 조회**: 마지막 작업 내용을 즉시 확인

## 사용법

```bash
/brain              # 현재 프로젝트의 작업 내역 조회
/brain save         # 작업 내용 저장
/brain list         # 모든 프로젝트 목록 조회
```

## 저장 위치

```
~/.claude/brain/
├── PassCloudNative.md       # PassCloudNative 프로젝트
├── monggle-vibe-coding-rules.md  # 이 프로젝트
└── ...
```

## 각 프로젝트별로 저장되는 정보

| 항목 | 내용 |
|-----|------|
| 📅 타임스탬프 | 저장 시간 |
| 🌿 브랜치 | 현재 git 브랜치 |
| ✅ 마지막 커밋 | 최근 커밋 메시지 |
| 📝 수정된 파일 | 변경된 파일 수 |
| 🔄 진행 중 | 작업 중인 내용 |
| ✅ 완료된 작업 | 완료한 항목들 |
| ⏳ 남은 작업 | 앞으로 해야 할 일 |

## 예시

```
🧠 프로젝트 작업 내역: PassCloudNative

🌿 브랜치: refactor/phase1-quick-wins
✅ 마지막 커밋: faab81e - docs: README 수정 (2026-05-14)
📝 수정된 파일: 21개

## 🔄 진행 중인 작업
- WebHard 용량 체크 기능 구현
- "1개 파일 실패" 문구 수정

## ✅ 완료된 작업
- WebHardCapacityCheckTest 작성
- 용량 체크 로직 구현

## ⏳ 남은 작업
- Looper.prepare() 오류 수정
- git-guardian으로 배포
```

## 사용 시점

- `/clear` 후 이전 작업 복원 시
- 프로젝트 간 전환 후 작업 내용 확인 시
- "내가 뭐 하고 있었지?" 할 때

## 관련 명령어

- `/save-point` - 세이브포인트 저장/복구
- `/context-restore` - 컨텍스트 복구
