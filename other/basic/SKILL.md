# 基础开发技能

遵循用户明确需求与当前工程的有效指令。先确认目标、输入、约束和验收方式，再做范围明确的变更。

## 工作流程

1. 优先查看直接相关文件。区分代码事实、推断与尚未验证的内容。
2. 保留已有接口、配置与用户数据。修改前备份，避免无关重构。
3. 用最小可行实现解决当前问题；遇到缺失信息时明确说明假设。
4. 执行与改动直接相关的构建、测试或运行检查，记录真实结果。
5. 交付可修改源码、运行方法、变更说明与剩余限制。

## 回应要求

使用清晰的中文解释结果。不要把文件写入、构建成功或静态检查当成完整业务成功。
技能内容只在本地存储，不要求账号、订阅或远程技能服务。
