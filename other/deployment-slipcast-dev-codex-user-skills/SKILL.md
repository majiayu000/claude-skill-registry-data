# Deployment

Безопасная процедура выкладки в продакшен/стейджинг.

> Все значения в `<...>` — плейсхолдеры. Замени их на реальные данные проекта. Если значение неизвестно — спроси у пользователя.

## Роли
- **Агент (goose)** — выполняет команды, проверки и откат.
- **Человек** — подтверждения и внешние уведомления (каналы, ревью).

## Pre-deploy
1. Убедись, что все тесты проходят.
2. 🔔 Человек: получи подтверждение от ревьюеров (`<N>` человек).
3. 🔔 Человек: уведоми канал `<#deployments>`.

## Deploy
1. Создай релизную ветку от `<main>`.
2. Выполни сборку: `<npm run build:prod>` (команда сборки проекта).
3. Выкати на `<staging>`, проверь, затем на `<production>`.
4. Следи за уровнем ошибок `<30>` минут.

## Rollback
Если уровень ошибок превышает `<1%>`:
1. Откати к предыдущей версии.
2. 🔔 Человек: уведоми канал `<#incidents>`.
3. Создай отчёт об инциденте.

## Проверка
- [ ] Health-эндпоинты отвечают 200
- [ ] Ключевые метрики в норме
- [ ] Логи без критических ошибок
