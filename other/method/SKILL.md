# Method：横向、丰富、精致的学术方法图

将用户参考图中的科学机制组织成清晰的横向方法图。以公开论文的 [GRPO 示例](assets/grpo/method.png) 和 [Transformer 示例](assets/transformer/method.png) 为布局与视觉基准，保留可编辑 Excalidraw 组件，导出 PNG、PDF、SVG 和预览。样例仅说明表现方式，不作为新算法内容模板。用户本次明确要求优先于本 skill 的默认风格。

## 输入与语义

- 查看参考图和风格样例。提取输入/输出、模块、模型状态、数据流、训练反馈、目标函数、条件分支及符号定义。样例只提供风格，不是算法模板；不自动复制样例的阶段数、模型角色、目标函数或反馈机制。
- 已有图先定位并备份当前 `.excalidraw`，保留用户改动和元素 ID；不要运行旧 skeleton 构图脚本覆盖当前源文件。只要求导出时不擅自改内容或布局。
- 参考图文字或公式确实无法辨认且影响科学含义时，询问关键缺失信息，同时推进不依赖它的工作。不能编造方法步骤、实验数值或结论。

## 版式与风格

- **主流程横向排列**，阶段内部可上下分层。起始长宽比约 2.0–2.4:1；可为可读性适当增高，不能硬套 motivation 的纵向结构。
- **默认不使用明显阶段序号或编号徽章，强调一体化流程。** 用连接关系、对齐和简洁标题组织阅读，不将每个阶段包装成独立等高大卡片。只在用户要求编号或确有必要对应正文时保留编号。可以使用统一整体边界及必要的局部容器，不强制整图必须有外框。
- 内容多的核心机制占较宽区域，输入准备/控制判定占较窄区域；不要强行等宽。按内容决定阶段数，用就近注释、短标签和分组降低空白。重点检查模型卡片和公式区：将内容较少的高卡片改成紧凑横向条目，按公式真实边界收紧容器；需要解释的机制可配原生小图，而不是留下大块空白。
- 白底、黑/深灰手绘边框；**模块背景优先采用 Excalidraw 原生 hachure（手绘斜线）填充**，以低饱和浅色区分语义区域，图标保留原色。斜线应可见但不抢过正文与公式；画布和整体外框内部仍可保持白底。少量红/蓝用于真实流向。参数与检查方法见 [背景手绘填充](references/layout-and-content.md#背景手绘填充)。
- **密度以 GRPO / Transformer 示例为基准，优先清楚的主流程。** 不默认把数值验算表、形式化定义和重复说明全部放入主图；复杂细节可保留在附带说明中。用户要求更紧凑时，不应自动增加内容复杂度。
- **通过调整布局或字号减少无效留白。** 根据实际问题选择重排模块、调整列宽和高度、缩短间距、收紧画布，或适当放大正文、标题和标签；也可两者结合，不固定先后顺序。保留可读性和必要连线通道，不靠增加内容或一味缩小文字填空白。具体操作见 [收紧布局](references/layout-and-content.md#收紧布局)。
- **字号与留白一起调整。** 正文、标题和关键标签按层级适当放大，结合精简长句、收紧容器来减少无效空白；不要仅缩小画布或统一缩放全图。约 1500–1600 宽画布的建议字号及复测方法见 [字号与留白](references/layout-and-content.md#字号与留白)。
- 默认 Comic Shanns（fontFamily 8）：可爱而清楚，字号层级稳定；中文可选 Excalifont 及其中文回退字体并检查字形。复杂公式使用渲染图片，普通说明与标签仍用原生文本。
- 模型、任务、书本、环境、奖励、比较、控制等真实实体使用原色彩色卡通图标。主动为关键操作、状态和结果配置足够丰富的语义图标，允许寻找新素材，不局限于已有样例图标；按角色分级定尺寸，避免装饰性重复。先读 [图标选型](references/icons.md)。
- **公式按实际视觉比例逐个定尺寸。** 长公式、分式和大求和式不要压过流程主体；普通公式和策略符号保持与邻近正文协调。用户说“有些公式太大”时，只调整明显偏大的具体公式，保留其余原尺寸，不能统一缩小全部公式。缩放后同时检查上下标可读性和周围留白，详见 [公式比例与局部密度](references/layout-and-content.md#公式比例与局部密度)。

## 充实内容与迭代

先还原科学关系，再优化视觉密度。用户说“内容再丰富一点”时，优先补足参考图已有但仅由箭头隐含的机制：采样来自哪里、反馈更新谁、损失各自学什么、判定未通过时继续什么。将简短解释放在对应子模块附近，不另堆一块长段落。默认同时追求高信息密度与内容完整：说明不同监督信号各自的作用、它们如何配合，以及已有反馈为何改善后续监督；避免把“丰富”理解为增加装饰图标或重复标题。利用已有空隙补充有根据的解释，必要时仅小幅增加高度，保留已经收紧的布局。可将已有机制画成局部可视化，例如同行验证结果、优势向 token 的广播、因果可见性矩阵、多头汇合或注意力计算流程；这些小图须增加可理解的信息，不能引入未经支持的算法步骤或把示意值写成实验结果。添加说明的依据见 [布局与信息密度](references/layout-and-content.md)。

优先合并可逐项对应的内容，例如把轨迹与其评估结果放在同一行，去掉重复编号和重复对象标签，同时保留真实对应关系。针对最大的空白区域调整列宽、短标签排列和子模块结构，随后压缩间距。可适当增高容纳有用解释，不能把所有文字缩到难读。每轮查看整体和最密集局部，修复文字/图标/公式遮挡、箭头穿字、错误绑定、图标比例失衡和无意义重复。尺寸缩到论文通栏后仍须清楚；不承诺期刊录用或无限优化。

## 制作、公式和导出

按 [渲染与导出](references/rendering.md) 操作；本 skill 自带 `scripts/scene_builder.py`、真实 Excalidraw 导出器及依赖清单，无需依赖 motivation skill 或固定临时目录。

- 新建图可先用 scene_builder 创建 skeleton，再由真实 Excalidraw 库规范化和量字。
- 修改已有图直接编辑当前源文件。改文字同步维护 text/originalText 和实际尺寸；移动组时处理其连线与绑定。
- 复杂公式优先在 https://www.latexlive.com/ 输入并取得自包含 SVG，每条保留 `.tex`；确认预览对应当前公式。公式可整体移动缩放，字符修改需重新渲染。不可访问时明确说明替代渲染来源。
- 所有产物从同一最新源文件导出：`.excalidraw`、高清 `.png`（默认 3×、300 dpi）、单页 `.pdf`、`.svg`、`_preview.png`、`_report.json`。保留图标来源说明和公式源码。
- 检查完整文本矩形与图片边界、图标/公式之间的交叠、图标内嵌、字体加载、画布边界、PNG 像素与 DPI、PDF 页数。自动检查后实际看图；警报须结合视觉判断。
- 输出到用户指定目录；未指定时在当前项目中建结果目录，不覆盖 skill 样例。最终简洁提供预览、PNG、PDF、可编辑源文件链接。

调用示例：`使用 /path/to/method/SKILL.md，根据这张参考图绘制横向、内容丰富的学术方法图，保存到 <输出目录>。`
