# Qboard — 대시보드

이 스킬의 목적은 **이 컴퓨터에서 벌어지는 일을 한 화면에 보여 주는 것**이다. 세션과 worktree가
여러 개면 어느 목표가 어디까지 왔는지, 어느 세션이 무엇을 하는지 사람이 머릿속으로 맞추기
어렵다. 그리고 AI가 "다 했다"고 기록한 것과 실제 증거(git, 검수 기록)가 어긋나면 그걸 먼저
봐야 한다. 보드는 그 둘을 나란히 놓는다. 읽기만 하고 아무것도 고치지 않는다.

보여 주는 것:

- `~/.qe/tasks`의 목표마다 상태, `implement-plan.md` 진행률(체크/전체), 관여한 세션, worktree·브랜치, 경고
- 살아 있는 세션 목록 — 공식 명령 `claude agents --json`에서 온다
- 5초마다 새로 읽는다. 사용자가 다른 세션에서 일하는 동안 띄워 두는 화면이다

## 순서

1. **띄운다.** 이 스킬 폴더(스킬을 불러올 때 보이는 "Base directory for this skill" 줄)의
   `board.mjs`를 백그라운드로 실행한다: `node "<이 스킬 폴더>/board.mjs"`.
   포그라운드로 돌리면 서버가 끝나지 않아 대화가 멈춘다.
2. **주소를 준다.** 출력의 `QE Board: http://127.0.0.1:<포트>` 줄을 사용자에게 그대로 준다.
   기본 포트는 4949(`QE_BOARD_PORT`로 바꿀 수 있다)이고, 쓰이고 있으면 빈 포트로 띄운다.
   그래서 주소는 출력에서 읽는다. 짐작하지 않는다. `127.0.0.1`에만 열려 밖에서는 못 본다.
3. **경고가 있으면 짧게 짚는다.** 사용자가 원하면 `/api/state`를 읽어 경고가 있는 목표를
   한두 줄로 알려 준다. 고칠지는 사용자가 정한다. 보드는 진단이지 조치가 아니다.
4. **끝낸다.** 사용자가 그만 보겠다고 하거나 대화를 마무리할 때 띄운 프로세스를 종료한다.
   남겨 두면 포트를 잡고 계속 git을 돌린다.

## 경고의 뜻

| 코드 | 뜻 |
|---|---|
| `invalid-status` | status.json이 깨졌다. 사람이 손으로 고치다 형식이 틀린 경우가 많다 |
| `checked-no-verdict` | 체크박스는 다 찼는데 지금 계획에 대한 검수 기록이 없다. 검증 없이 끝났다고 여기는 중일 수 있다 |
| `done-without-verdict` | 완료로 표시됐지만 그 커밋에 대한 충족 검수 기록이 없다 |
| `changed-after-verdict` | 완료 커밋이 브랜치에서 사라졌거나, 완료 뒤 새 커밋이 쌓였다. 검증한 것과 지금 코드가 다르다(`docs/qe/` 내보내기만 담은 커밋은 세지 않는다) |
| `worktree-missing` | 진행 중인 목표의 worktree가 지워졌다 |
| `branch-missing` | 기록된 브랜치가 없다. 완료 커밋이 기준 브랜치에 들어갔거나(정상 정리) PR·그대로 두기로 마무리했으면(`done.finish`) 경고하지 않는다 |
| `unmerged` | 완료됐는데 기준 브랜치에 없는 커밋이 남아 있다. 끝났지만 합쳐지지 않았다. PR·그대로 두기로 마무리했으면 경고하지 않는다(squash·rebase merge는 커밋이 달라 git으로 확인할 수 없다) |
| `orphaned` | 진행 중인데 그 목표의 세션이 하나도 살아 있지 않고 handoff.md도 없다. 이어받을 단서가 없다 |

기준 브랜치는 원격의 기본 브랜치(`origin/HEAD`, 같은 이름의 로컬 브랜치가 있으면 그것), 없으면 로컬 `main`·`master`다.
원래 checkout이 지금 어느 브랜치에 있든 상관없다.

세션 목록을 못 가져오면(`claude`가 PATH에 없는 등) 화면에 안내가 뜨고 `orphaned`는 판정하지
않는다. 모르는 것을 "버려졌다"고 말하면 안 되기 때문이다.

## 이런 생각이 들면

| 생각 | 실제 |
|---|---|
| "주소는 늘 4949겠지" | 출력에 찍힌 주소를 준다 |
| "경고가 떴으니 내가 고치자" | 보드는 보여 주기만 한다. 고칠지는 사용자가 정한다 |
| "띄워 두고 그냥 끝내자" | 끝낼 때 프로세스를 종료한다 |
