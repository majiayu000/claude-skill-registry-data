# EPV Analysis Skill

## Purpose

Estimate no-growth earnings power value and franchise value.

## Inputs

- Target
- Market
- Industry
- Available data
- User requested depth
- Prior assumptions, if any

## Outputs

- Structured analysis
- Assumptions
- Missing data
- Confidence level
- Next required action

## Rules

- State assumptions explicitly.
- Flag missing or low-confidence data.
- Prefer conservative assumptions.
- Keep output auditable.
