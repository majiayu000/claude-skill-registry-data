# 职位描述分析器（Job Description Analyzer）

## 何时使用此技能

当用户有以下需求时使用此技能：
- 想要分析一个职位发布（JD）
- 问"我该不该投这个岗位？"
- 想知道自己与某个岗位的匹配百分比
- 需要帮助理解职位要求
- 想针对特定岗位定制简历
- 提到："分析这个职位"、"我符合要求吗"、"匹配度分数"、"该不该投"

在定制简历 **之前** 使用此技能，确保投入的时间是值得的。

## 核心能力

- 提取并归类职位要求（必备项 vs 加分项）
- 计算用户经验与职位要求之间的匹配度分数
- 识别技能差距与优势
- 检测职位发布中的警示信号（red flag）
- 确定应重点突出哪些经历
- 生成简历定制策略
- 生成求职信（cover letter）谈话要点
- 评估公司文化契合度指标

## 战略性问题

大多数求职者把时间浪费在：
- 能力不足的岗位（匹配度 <60%）
- 能力过剩的岗位（离职风险高）
- 有警示信号的岗位（高人员流失率、有毒文化）
- 盲目海投 50+ 个岗位，抱着总有一个会中心态

更好的方法：
- 有策略地投递 10-15 个岗位
- 瞄准匹配度 70-90% 的岗位
- 对每一个都深度定制
- 回复率更高，身心消耗更少

## 分析流程

### 步骤 1：提取要求

把职位描述拆分为以下类别：

**必备项（Must-Have）**
- 学历要求
- 工作年限
- 特定的技术技能
- 证书/执照
- 行业经验

**加分项（Nice-to-Have）**
- "加分"技能
- 高级认证
- 领域专长
- 特定工具经验

**软技能/文化**
- 沟通风格
- 工作环境
- 团队结构
- 公司价值观

### 步骤 2：关键词提取

识别三种类型：

**硬技能**（技术能力）
- 工具：Salesforce、Python、AWS、Excel
- 方法论：Agile、Six Sigma（六西格玛）、SDLC
- 认证：PMP、CPA、AWS Certified

**软技能**（人际交往）
- 领导力、协作、沟通
- 解决问题、批判性思维
- 适应力、主动性

**行业/领域知识**
- B2B SaaS、医疗健康、金融科技
- 大型企业 vs 中小企业（SMB）
- 合规知识（HIPAA、SOX、GDPR）

### 步骤 3：计算匹配度分数

```
匹配度计算：

必备技能：
- 用户具备 10 项必备技能中的 8 项 = 80%

加分技能：
- 用户具备 5 项加分技能中的 3 项 = 60%

综合匹配度：
- 必备项权重 70%，加分项权重 30%
- (80% × 0.7) + (60% × 0.3) = 74%

分数解读：
90-100% = 能力过剩（可能有离职风险）
75-89% = 非常契合（立即投递）
60-74% = 较好契合（配上强有力求职信后投递）
50-59% = 有挑战的岗位（如果非常有热情可以投）
<50% = 能力不足（除非是梦想岗位，否则跳过）
```

### 步骤 4：差距分析

针对每一项缺失的要求：
- **关键差距（Critical gap）**：一票否决项（不要投）
- **重大差距（Major gap）**：影响明显但可应对（在求职信中提及）
- **次要差距（Minor gap）**：容易学（弱化处理或强调相关技能）

### 步骤 5：警示信号检测

扫描以下预警信号：

**工作量警示信号：**
- "身兼数职"
- "快节奏环境"
- "快速上手、立即产出"
- "在模糊环境中自主驱动"

**文化警示信号：**
- "明星/忍者/大师型人才"
- "努力工作，尽情玩乐"
- "无限假期"
- "像个大家庭"

**薪酬警示信号：**
- "有竞争力的薪资"（不肯告诉你区间）
- "股权为主"（现金薪酬低）
- "纯提成制"（无底薪）
- "薪资面议"且没有区间

## 要求分类指南

### 如何区分"必备项"与"加分项"

**表明"必备"的措辞：**
- "必须具备……"
- "要求：X 年……经验"
- "你要能……"
- "核心任职资格"
- 列在"任职要求"之下
- 在描述中出现 3 次以上

**表明"加分"的措辞：**
- "最好具备……"
- "有……更佳"
- "优先条件"
- "理想情况下你会有……"
- "如果有……是加分项"
- 仅出现 1-2 次

### 一票否决项检测

**绝对否决项（不要投）：**
- 你不具备的必备执业资格（医疗、法律、CPA）
- 你无法获得的必备安全审查/资质
- 经验年限低于要求 50% 以上
- 你没有的必备学历（且明确标注为"必须"）
- 你无法满足的地点要求

**不构成否决项（照样投）：**
- 经验年限略低于要求（例如对方要 5 年，你有 3 年）
- 你没有的"优先考虑"学历
- 你可以学会的工具/技能
- 你拥有可迁移技能时的行业经验

## 边界情况

### 信息模糊的职位描述
- 标记为潜在警示信号
- 尽可能提取出关键词
- 建议投递前先联系对方澄清
- 以行业标准要求作为基准

### 一个 JD 里包含多个岗位方向
- 识别核心岗位与"其他职责"
- 匹配度分数以主要职责为准
- 标记职责范围蔓延的顾虑

### 内部岗位发布（已在该公司任职）
- 采用不同策略 - 强调内部知识
- 突出跨团队协作关系
- 引用公司具体的项目计划

### 重新发布的岗位
- 可能说明：上一位录用者未通过试用、职责扩大，或首轮招聘失败
- 值得投递，但要调研为什么重新发布
- 对比要求是否与最初发布时发生了变化
