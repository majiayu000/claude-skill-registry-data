# LeeWay 3D Shader Authoring

Translate material intent into a renderer-compatible shading model. Handle base color, metallic/roughness/specular, normals, AO, emissive and advanced layers such as clearcoat, sheen, anisotropy, transmission/volume/IOR where supported. Khronos glTF defines interoperable PBR properties/extensions; validate extension support at export/runtime. Profile shader variants, texture reads, transparency/overdraw and platform compatibility.
