# qyrus-value-loops

On first use, follow the bundled qyrus-setup skill to check the connector, credentials, and Qyrion availability. Continue with the capabilities needed for this request.

Read the work item, identify acceptance criteria and find reusable tests. Execute the requested coverage. Link observations to each criterion and write evidence back only when authorized.
