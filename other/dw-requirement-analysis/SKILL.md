# Step 1: 需求分析

## 执行流程

1. 用 `dw-explorer` subagent 读取上游表结构
2. 分析 PRD/需求文档，提取关键信息
3. 生成结构化需求摘要

## 输出格式

```markdown
## 需求摘要（≤5 行）
[核心需求描述]

## 字段口径草稿
| 字段名 | 口径说明 | 数据来源 |
|--------|---------|---------|
| ...    | ...     | ...     |

## 待确认问题清单
1. [问题 1]
2. [问题 2]
...

## 字段变更单（草稿）
| 变更类型 | 表名 | 字段 | 说明 |
|---------|------|------|------|
| 新增    | ...  | ...  | ...  |
```

## 规则

- 需求摘要不超过 5 行
- 待确认问题必须列出，不能省略
- 字段口径必须标注数据来源
- 写入 CLAUDE.md 的 "本次迭代约束" 节
