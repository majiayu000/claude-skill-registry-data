# 天正绿化种植标注入口

先读当前项目唯一要求和最新纠正，再按实际对象进入专用Skill；不要在本入口另造标注算法。

| 当前对象 | 必读入口 |
|---|---|
| 乔木名称/数量、成员串线、头尾自由引出、树图例中心 | [乔木组标注](../cad-tree-group-annotation/SKILL.md) |
| 灌木、草本、地被、水生、草坪的名称/面积及整体原生引出 | [灌草地被标注](../tianzheng-groundcover-annotation/SKILL.md) |
| 需联动坐标显示或苗木网格定位密度 | [坐标标注](../tianzheng-coordinate-annotation/SKILL.md) |
| 需联动标高符号/文字 | [标高标注](../tianzheng-elevation-annotation/SKILL.md) |

共用控制链及意见沉淀见[标注控制](../cad-check-review/references/annotation-control.md)，源图/隔离副本与后台权限沿[cad-check-review](../cad-check-review/SKILL.md)。首次进入、类型变化或收到对应反例时读完整相关条款；同类型连续工作不逐组重读全历史。

在原机器计划/执行状态记录当前实际读取、规划/生成/自检入口及反例，不另建要求台账。方法来源存在、实际调用、后态合格和整项图面通过是不同证据；记录不得沿用已变化文件的旧指纹冒称当前回执。实际生成和读回均执行同类检查，不能只修一个离线测试函数。

品种、数量、面积、位置和分幅以本项目最后有效来源为准；正式原图提供样式，不能继承不符新稿的旧方案或旧统计。旧注成套替换，保护用户手改与已验底板/地被。乔木和灌草原生表达不同；已验证样例1:200阈值、字号、35°及模板夹点不能自动套不同项目1:500。

当前没有合理位置或来源未知时只挂对应对象；其余授权独立工作继续。同类合批执行、自检和保存，完整大项回项目端统一验收，不逐对象等待放行。新增意见的原话留项目唯一清单，可复用规则回写上述对应类型Skill，旧相冲条款显式替代。
