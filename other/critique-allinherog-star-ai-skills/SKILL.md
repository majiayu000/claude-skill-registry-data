# critique 业务诊断助手

[快速开始](https://github.com/allinherog-star/ai-skills/tree/main#%E5%BF%AB%E9%80%9F%E5%BC%80%E5%A7%8B)

[更多技能](https://ai-skills.ai)

### 概述

业务诊断助手用于回答「这件事该怎么做」、UI设计、UX审查、设计系统，适合产品、运营、technical、software在明确业务目标、内容材料或分析对象后调用。
它会结合作品说明与自评、粘贴设计说明、创意背景、页面文案、作品目标、当前困惑或你希望重点点…等输入，整理关键上下文，并输出摘要、诊断结论、行动建议和可复用交付物，便于继续执行、复盘或交付。

### 什么时候使用

**适用场景**

- 用户提出“这件事该怎么做”这类问题，需要快速拆解目标、判断重点并形成可执行结果
- 产品、运营、technical、software需要围绕业务诊断助手生成摘要、诊断结论、行动建议和可复用交付物
- 用户已经准备了作品目标（说明希望作品达成的传播、理解、转化、信任、审美或展示目标。）、目标观众（说明评审者、客户、用户、购买者或目标观众的背景和期待。）、作品或参考链接（填写公开可访问的作品页面、设计预览、原型、作品集或参考链接。），希望整理成可执行的分析或优化结果
- 用户需要把业务诊断助手相关材料转成清晰结论、优先级和下一步动作

### 调用方式

通过导出的 Python runner 直接调用 AI Skills API：

### 命令示例

**基础调用**

```bash
python3 scripts/run.py --params '{}'
```

**带常用参数调用**

```bash
python3 scripts/run.py --params '{"goal":"作品目标"}'
```

### 参数说明

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `goal` | string | 否 | - | 说明希望作品达成的传播、理解、转化、信任、审美或展示目标 |
| `audience` | string | 否 | - | 说明评审者、客户、用户、购买者或目标观众的背景和期待 |
| `materialUrl` | string | 否 | - | 填写公开可访问的作品页面、设计预览、原型、作品集或参考链接；需要传可访问的完整 URL |
| `reviewDepth` | string | 否 | `标准诊断` | 选择快速点评、标准 critique 或深度作品评审；可选值：`快速体检`、`标准诊断`、`深度改稿` |
| `materialFile` | string | 否 | - | 支持 UI 截图、海报导出图、作品集页面截图、设计文档、PDF 或作品说明 |
| `materialText` | string | 否 | - | 粘贴设计说明、创意背景、页面文案、作品目标、当前困惑或你希望重点点评的问题 |
| `targetPlatform` | string | 否 | - | 选择 Web、移动端、海报、作品集、社媒图、演示页或其它展示载体 |
| `brandRequirements` | string | 否 | - | 补充品牌调性、视觉规范、客户限制、禁用表达和必须保留的信息 |

完整机器可读参数结构见 `references/form-schema.json`。

### 交付内容

- 摘要、诊断结论、行动建议和可复用交付物：围绕用户目标整理可直接阅读、复盘或交付的核心结果。
- 输入材料解读：结合作品目标（说明希望作品达成的传播、理解、转化、信任、审美或展示目标。）、目标观众（说明评审者、客户、用户、购买者或目标观众的背景和期待。）、作品或参考链接（填写公开可访问的作品页面、设计预览、原型、作品集或参考链接。）提炼关键上下文和判断依据。
- 下一步动作：给出优先级、执行建议或可继续加工的内容框架。

### 结果使用建议

- 先判断输出是否回答了用户关于「业务诊断助手」的核心问题。
- 再检查结果是否覆盖摘要、诊断结论、行动建议和可复用交付物，以及是否给出明确下一步动作。
- 如果输入材料较少，建议让用户补充目标、受众、限制条件或原始材料后再运行。
