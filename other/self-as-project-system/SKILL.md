# self-as-project-system

## When to Use

当需要将个人学习、成长与价值创造整合为一个持续发展的系统时description

## Core Logic

# 执行步骤

1.  **设定意图**
    *   **输入**：当前状态、长期愿景、内在驱动力。
    *   **操作**：明确一个具体的、有吸引力的个人发展目标或“为什么”。将其书面化。
    *   **判断标准**：目标清晰、可描述，并能激发行动意愿。
    *   **输出**：一份书面的个人意图声明。
    *   **常见误区**：目标过于模糊（如“变得更好”）、不切实际或缺乏个人情感连接。

2.  **安排创意时段**
    *   **输入**：每日/每周日程、个人意图声明。
    *   **操作**：在日程中固定安排一段不受干扰的时间（如每天30分钟），用于创造性思考、散步或沉浸在与意图相关的信息中。
    *   **判断标准**：该时段被保护，不受其他任务侵占；期间注意力从外部任务转向内部思考。
    *   **输出**：一个受保护的日程时段和期间产生的初步想法或洞察。
    *   **常见误区**：被紧急但不重要的事务打断；用这段时间进行被动消费（如无目的刷手机）。

3.  **创建笔记系统**
    *   **输入**：日常接触的信息（阅读、观察、思考）、个人意图。
    *   **操作**：建立一个笔记系统（数字或纸质），专门记录那些能**推动**你向意图迈进的信息、见解、灵感或待办事项。
    *   **判断标准**：笔记内容与个人意图强相关，并能直接或间接指导后续的“构建”行动。
    *   **输出**：一个按意图组织的、可检索的笔记库。
    *   **常见误区**：记录所有信息，不加筛选；笔记孤立存在，未与行动关联。

4.  **构建生活项目**
    *   **输入**：个人意图、创意时段的产出、笔记系统中的内容。
    *   **操作**：选择笔记库中的一个点子或方向，投入固定时间（如每天30-60分钟）进行具体构建。这可以是学习新技能、创作内容、启动一个小型实验或改善某个生活领域。
    *   **判断标准**：产生了可观察的进展或具体成果（如完成一个原型、写出一篇文章、掌握一个技能点）。
    *   **输出**：一个具体的项目产出或进展状态。
    *   **常见误区**：同时开启过多项目导致精力分散；追求完美而迟迟不开始；将构建视为额外负担而非生活本身。

5.  **教授所知**
    *   **输入**：在“构建”步骤中获得的知识、经验或成果。
    *   **操作**：将你的学习过程、心得或项目成果，通过写作、演讲、演示、辅导等方式分享给他人。旨在解释清楚，而不仅是展示。
    *   **判断标准**：能够清晰地向一个不了解该领域的人阐述核心概念或过程；教学行为引发了新的思考或问题。
    *   **输出**：一份教学材料（文章、视频、谈话）及可能收到的反馈。
    *   **常见误区**：认为必须成为专家后才能教学；教学形式复杂化，阻碍了持续分享。

6.  **评估与产品化**
    *   **输入**：一系列“构建”和“教授”的产出、外部反馈、个人兴趣的持久度。
    *   **操作**：
        *   **IF** 某个兴趣领域持续带来激情，且对应的构建/教学产出能稳定为他人提供价值 **THEN** 考虑将其系统化，发展为可重复提供的“产品”或“服务”（如课程、咨询、订阅内容）。
        *   **ELSE** 回到步骤1或步骤4，调整意图或探索新的构建方向。
    *   **判断标准**：能够明确描述所提供的价值；有初步的受众或市场需求验证。
    *   **输出**：一个关于是否及如何将个人项目发展为个人事业（产品）的决策。
    *   **常见误区**：过早追求商业化而损害了学习与分享的初心；忽视市场反馈，闭门造车。

# 输出格式要求
提供一个清晰的六步循环复盘报告，包含：1) 当前意图状态；2) 创意时段执行情况；3) 笔记系统关键洞察；4) 近期构建项目进展；5) 教学行动与反馈；6) 产品化可能性评估。根据报告，指出下一步应强化或调整哪个环节。
