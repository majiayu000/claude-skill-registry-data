# natural-compass

## When to Use

当个人感到迷茫，不确定自己真正想要什么，或发现当前追求无法带来深层满足时，调用此模型来探索和澄清内在真实欲望。description

## Core Logic

# 执行步骤

1.  **主动追求假设性目标**
    - **输入**：一个当前你认为自己想要达成的目标或状态（例如：获得某份工作、购买某物、达到某个生活状态）。
    - **操作**：投入资源（时间、精力、金钱）去实际追求这个目标。
    - **判断标准**：是否已采取具体行动去接近该目标，并获得了初步的体验或结果。
    - **输出**：对目标追求过程的直接体验和初步结果。

2.  **识别负面体验与排斥点**
    - **输入**：步骤1中获得的体验和结果。
    - **操作**：分析在追求过程中，哪些部分让你感到痛苦、厌倦、空虚或不满足。明确“你不想做的事情”是什么。
    - **判断标准**：是否能清晰列出至少一个在追求过程中发现的、你明确不喜欢或不想重复的环节、感受或结果。
    - **输出**：一个关于“不想做之事”的清晰列表。

3.  **定义核心问题**
    - **输入**：步骤2中得出的“不想做之事”列表。
    - **操作**：将“不想做之事”提炼成一个待解决的“核心问题”。这个问题通常指向你现有思维模式、能力或认知的局限性（例如：“为什么我得到了X却依然不快乐？”，“我无法忍受Y，这暴露了我哪方面的局限？”）。
    - **判断标准**：是否能将具体的负面体验，抽象成一个可以深入探究的、关于自身或目标本质的问题。
    - **输出**：一个明确的、待解决的核心问题陈述。

4.  **沉浸分析与思维拆解**
    - **输入**：步骤3定义的核心问题。
    - **操作**：深入研究该问题。剖析其组成部分：你的假设是什么？外部条件是什么？你的情绪反应模式是什么？使用工具如写作、讨论、研究相关案例来多角度分析。
    - **判断标准**：是否对问题的成因、背景及自身在其中的角色有了更深入、更结构化的理解，超越了最初的表面感受。
    - **输出**：对问题的多层次、结构化分析报告。

5.  **突破思维边界**
    - **输入**：步骤4得出的问题分析报告。
    - **操作**：主动寻求能打破当前分析框架的新视角、新知识或新体验。这可能包括学习新学科、与背景迥异的人交流、尝试完全不同的行为模式。
    - **判断标准**：是否能提出至少一个在原有思维框架内无法产生的新观点或解决方案方向。
    - **输出**：一个或多个超越原问题框架的新思路或可能性。

6.  **解决问题并实现认知进化**
    - **输入**：步骤5产生的新思路。
    - **操作**：基于新思路，制定并执行一个解决方案或实验性行动。这个方案旨在直接应对步骤3定义的核心问题，其目的不仅是解决具体事务，更是为了验证新思维，实现个人认知或能力层级的提升。
    - **判断标准**：是否执行了解决方案，并且通过此过程，对自身或目标的本质有了更深刻的理解（即使外部目标未完全达成）。
    - **输出**：解决方案的执行结果，以及一个更高层级的、关于“自己真正想要什么”的新认知或新假设。

7.  **迭代循环**
    - **输入**：步骤6产生的新认知或新假设。
    - **操作**：将新的认知或假设作为新的“你认为你想要的东西”，从步骤1开始重复整个过程。
    - **判断标准**：是否将本次循环的终点视为下一次探索的起点，持续进行。
    - **输出**：进入下一轮“追求-理解-意识到-研究-扩展-解决”的循环。

# 输出格式要求
以结构化摘要形式呈现当前循环的进展与收获：
1.  **本轮追求目标**：[简述初始目标]
2.  **发现的“不想做之事”**：[列举关键点]
3.  **定义的核心问题**：[陈述问题]
4.  **获得的新认知/进化**：[描述思维或理解上的突破]
5.  **下一轮假设/方向**：[提出基于新认知的下一步探索方向]
