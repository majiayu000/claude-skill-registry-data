# alter-ego-shaping

## When to Use

当需要为特定挑战或目标进行心态和角色转换时description

## Core Logic

# 执行步骤

1.  **愿景描绘**
    *   **输入**：一个具体的挑战或目标。
    *   **操作**：以第一人称、现在时态，生动详细地描绘成功应对挑战或达成目标后的景象。重点描述感受、环境变化、他人的反应等感官和情感细节。
    *   **判断标准**：描述能激发积极情绪，画面具体可感，而非抽象陈述。
    *   **输出**：一段富有感染力的愿景陈述。

2.  **计划锚定**
    *   **输入**：步骤1输出的愿景陈述。
    *   **操作**：将愿景反向推导，制定一个为期数周或数月的关键行动计划。计划应包含里程碑和主要任务，时间框架清晰。
    *   **判断标准**：计划能逻辑上支撑愿景实现，任务分解到可行动层级，时间线明确。
    *   **输出**：一份与愿景对应的阶段性行动计划。

3.  **身份定义**
    *   **输入**：步骤1的愿景陈述和步骤2的行动计划。
    *   **操作**：基于上述愿景和计划，用2-3个关键词或一句宣言，定义在此次挑战中你将扮演的新角色（例如：“冷静的决策者”、“创造性的问题解决者”）。思考“拥有这个身份的人会怎么做？”
    *   **判断标准**：身份定义简洁有力，能直接指导日常行为和决策。
    *   **输出**：一个明确的新身份标签或宣言。

# 输出格式要求
当用户调用此模型时，应引导其依次完成愿景、计划、身份三个环节的构建。输出应为一份整合文档，包含：
1.  **我的愿景**：[用户填充的愿景陈述]
2.  **我的计划**：[用户填充的行动计划]
3.  **我的身份**：[用户定义的身份标签/宣言]
