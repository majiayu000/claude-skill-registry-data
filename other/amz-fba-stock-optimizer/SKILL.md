# 亚马逊FBA库存优化器

## IPI评分说明

**库存绩效指标(IPI)**是亚马逊为FBA卖家提供的健康度指标。
它决定你的月度仓储容量限制。

**IPI阈值：400**

- IPI ≥ 400：无仓储容量限制
- IPI < 400：亚马逊可能施加仓储限制并收取超额费用

**IPI评分构成：**


| 因素 | 权重 | 如何改进 |
| ---------------------- | ------- | ----------------------------------------------------- |
| **过剩库存** | 最高 | 移除或清仓滞销库存 |
| **售出率** | 高 | 通过PPC或促销提高销售速度 |
| **滞留库存** | 中 | 修复导致库存无法销售的listing问题 |
| **库存率** | 中 | 在畅销品断货前补货 |


**查看IPI评分：** 卖家中心 → 库存 → 库存绩效仪表板

## FBA容量管理（2024年后系统）

亚马逊在2024年从每周补货限制转变为**月度容量限制**。
容量按产品类型（标准、超大、服装等）以立方英尺分配。

**容量分配公式因素：**

- 你的IPI评分（主要驱动因素）
- ASIN的历史销售速度
- 亚马逊网络中的可用仓库空间
- 通过Capacity Manager进行的预订

**Capacity Manager（预订系统）：**

- 提前申请额外容量（最多提前3个月）
- 支付预订费（如果使用≥100%的预订容量则退还为积分）
- 最适合：旺季预加载、需要高初始库存的新品发布

## 补货数量计算

**步骤1：计算日销售速度**
日速度 = 过去30天销售数量 ÷ 30

**步骤2：确定补货交期**
交期 = 生产天数 + 货运天数 + FBA入仓天数
（典型：中国到亚马逊美国14-45天）

**步骤3：设置安全库存**
安全库存 = (最大日速度 − 平均日速度) × 交期天数

**步骤4：计算再订货点**
再订货点 = (平均日速度 × 交期) + 安全库存

**步骤5：计算补货数量**
补货数量 = (日速度 × 目标供应天数) − 当前FBA库存 − 在途库存

**目标供应天数指南：**

- 标准产品：45-60天
- 旺季：90-120天
- 滞销产品：最多30-45天

## FBA费用结构（需管理的关键费用）


| 费用类型 | 收费时机 | 如何最小化 |
| ---------------------------- | ------------------------------------------------------------------- | -------------------------------------------------------- |
| **配送费** | 每单位发货时 | 优化包装以减少体积重量 |
| **月度仓储费** | 每立方英尺/月 | 保持精简库存；清仓过剩库存 |
| **库龄附加费** | 181-270天：$0.50/单位；271-365天：$1.00/单位；365+天：$1.50/单位 | 将150天售出目标设为硬性限制 |
| **移除/弃置费** | 每单位移除时 | 对滞销库存使用清仓而非支付长期仓储费 |
| **入库配置费** | 每单位，基于亚马逊分配到多少个运营中心 | 发货到亚马逊优化配置（如果总成本更低） |

## 库龄库存预防协议

**90天时**：标记任何按当前速度剩余供应>60天的ASIN
**120天时**：运行定向促销（降价5-10%）或亚马逊优惠券
**150天时**：为最滞销的单位创建移除订单
**180天时**：在库龄附加费生效前清仓所有剩余库存

**清仓选项（按优先顺序）：**

1. 亚马逊Outlet（亚马逊清仓渠道的折扣listing）
2. 亚马逊清仓计划（亚马逊以~5-10%的回收价值购买）
3. 移除订单到你的仓库 → 在其他渠道销售

## 旺季库存规划


| 旺季活动 | 准备开始 | 库存目标 | 关键行动 |
| --------------------------- | ---------- | --------------- | ----------------------- |
| Prime Day（7月） | 5月1日 | 90天供应 | 4月15日前提交入库 |
| 返校季（8月） | 6月15日 | 60天供应 | 7月15日前完成FBA入仓 |
| 黑五/网一 | 9月 | 120天供应 | 10月1日前完成FBA入仓 |
| 假日季（12月） | 10月 | 90天供应 | 11月1日前完成FBA入仓 |


**旺季FBA收货交期：** 10月至12月期间预留额外2-3周入仓时间。

## 滞留库存修复协议

滞留库存 = 因listing问题导致无法在FBA销售的库存。

**常见原因和解决方案：**


| 原因 | 解决方案 |
| ------------------------------------------------ | --------------------------------------------------- |
| Listing关闭或删除 | 重新上架产品；重新关联FNSKU |
| 价格警报（价格过高/过低） | 在亚马逊允许范围内更新定价 |
| 安全投诉 | 提交测试报告和合规文件进行申诉 |
| Listing抑制（缺少必填属性） | 在管理库存中添加缺失属性 |


**检查滞留库存：** 卖家中心 → 库存 → 修复滞留库存

## 每周监控的库存健康KPI


| KPI | 目标 | 警报阈值 |
| --------------------------- | -------------------- | --------------------- |
| IPI评分 | ≥ 450 | < 400（容量风险） |
| 库存率（畅销品） | > 95% | < 85% |
| 过剩库存占比 | < 总单位数的15% | > 30% |
| 库龄库存（>180天） | 0单位 | 150天时的任何单位 |
| 售出率 | > 7（过去90天） | < 3（标记审核） |
| 滞留库存 | 0单位 | 任何 |
