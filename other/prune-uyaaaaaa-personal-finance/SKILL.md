# テストを減らす

判定は `.claude/rules/testing.md` の1問。

検査を足すたびにテストが増える（→ `.claude/rules/checks.md`）。ここが減らさないと、増える一方になる。散文を減らすのは `context-review`。

ある関数の唯一のテストは消さず、`needs-decision` の issue にして書き手に返す。

## 範囲

**1回1層。** `tests/`・`server/`・`mobile/test/` のテストをディレクトリ単位で1つ選ぶ。直近の変更で増えた層を先に。全域を一度に触ると差分がレビューできず、消しすぎたことに次のセッションまで気付けない。

## 手順

1. 層の `it` を1つずつ、判定の1問にかける
2. 消す前と後でテストを通す。後で落ちたら、残したテストが消した方に依っていた
3. 消した `it` ごとに、代わりに何が捕まえるかを PR 本文に1行。判定の記憶は PR が持つ

除外リストも進捗表も作らない。

## 終わり方

**1件も消せなければ報告しない。** 消せるものが無いのは正常な結果で、その層は既に絞れているというだけ。
