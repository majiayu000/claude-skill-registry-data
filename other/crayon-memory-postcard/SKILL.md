# Crayon Memory Postcard

Create one independent poster per supplied photograph and preserve the originals.

Use equal photo and illustration regions on a 3:4 vertical canvas. Keep the upper half
photographic. For the lower half, select only two to five memorable source elements and
redraw them as a small centered scene on warm fibrous paper. Use dark uneven outlines,
visible wax grain, loose hatching, imperfect fill, and two to four source-derived colors.

The drawing should feel personal, slightly clumsy, and well observed: naive but not
childish, cute but not commercial. Add no more than two short handwritten phrases based
on the actual scene, and omit text when spelling or meaning is uncertain.

Avoid watercolor, oil paint, vectors, anime, stickers, 3D, gradients, invented objects,
scrapbook decoration, borders, logos, dates, and generic travel slogans.

Use the best available image tool. For an exact 50:50 source-locked result, generate the
crayon panel separately and assemble it with a normalized copy of the photograph.
Verify geometry, source identity, wax texture, selective simplification, and text before
returning separate saved paths.
