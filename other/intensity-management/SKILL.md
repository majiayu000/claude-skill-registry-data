# intensity-management

## When to Use

当需要规划或评估一个高强度工作阶段（如冲刺项目、密集训练、创作期）时，调用此模型来设定合理的边界并确保可持续性。description

## Core Logic

# 执行步骤

1.  **定义高强度阶段**
    *   **输入**：明确的目标、需要高强度投入的领域。
    *   **操作**：
        *   设定该“强烈”阶段的**明确时间范围**（例如：3-6个月）。
        *   定义该阶段结束时期望达成的**具体成果**。
        *   规划该阶段内**每日/每周的时间投入上限**（例如：每日专注工作12小时）。
    *   **判断标准**：目标、时限、强度指标均具体、可衡量。
    *   **输出**：高强度阶段的任务书（目标、时限、强度）。

2.  **设定退出与维持条件**
    *   **输入**：步骤1输出的任务书。
    *   **操作**：
        *   **列出“危险信号”**：明确哪些情况表明需要退出或调整强度（如：持续倦怠、健康下滑、核心关系受损、工作质量下降）。
        *   **规划“维持基线”**：预先定义高强度阶段结束后，为了维持成果所必须执行的**最低限度的核心习惯或任务**（例如：每天锻炼30分钟、每周发布1篇文章）。
    *   **判断标准**：危险信号具体可观测；维持基线简单、明确、可持续。
    *   **输出**：预警指标清单和维持基线方案。

3.  **执行与动态监测**
    *   **输入**：任务书、预警指标、维持基线方案。
    *   **操作**：
        *   在设定时间内执行高强度计划。
        *   **定期（如每周）检查预警指标**。
        *   **IF 任何预警指标被触发**：
            *   评估严重程度。
            *   **IF 问题严重**：立即启动向“一致性”周期（见“进步周期框架”）的过渡，执行维持基线方案，停止高强度冲刺。
            *   **IF 问题轻微**：调整高强度计划（如减少每日工时，增加休息），继续监测。
        *   **IF 阶段结束时目标达成且未触发严重预警**：
            *   按计划切换到“一致性”周期，执行维持基线方案，并开始为下一轮周期进行探索。
    *   **判断标准**：能否严格执行计划，并在预警触发时做出合理应对，而非硬撑到底。
    *   **输出**：高强度阶段的执行总结，以及进入下一阶段（通常是“一致性”周期）的指令。

# 输出格式要求
为用户呈现一个结构化的高强度阶段计划，包括目标、时限、强度。必须强调“退出条件”和“维持基线”的设置。在用户执行期间，提醒其监测预警信号，并根据信号提供明确的“继续”、“调整”或“停止”建议。
