# flow-state-balancing

## When to Use

当需要进入并维持高效、专注的心流状态，以提升学习、工作或技能获取效率时description

## Core Logic

# 执行步骤

1.  **评估当前状态**
    *   **输入**：对当前任务的主观感受（无聊、焦虑、专注）。
    *   **操作**：内省并识别主导情绪。
    *   **判断标准**：能清晰地将感受归类为“无聊”、“焦虑”或“专注/心流”。
    *   **输出**：一个明确的状态标签（无聊/焦虑/心流）。

2.  **根据状态调整挑战与技能**
    *   **输入**：步骤1输出的状态标签。
    *   **操作**：
        *   **IF 状态为“无聊”**：为当前任务增加挑战性。例如，设定时间限制、提高质量目标、或将任务转化为一个更具竞争性或创造性的“小游戏”。
        *   **ELSE IF 状态为“焦虑”**：暂停当前任务。放大视角（例如，思考任务的长期意义或更宏观的背景），然后重新聚焦于分解任务、降低难度或寻求帮助以提升相关技能。
        *   **ELSE (状态为“心流”)**：维持当前的任务设置和注意力投入。
    *   **判断标准**：采取了与识别状态相对应的、具体的调整行动。
    *   **输出**：调整后的任务执行策略或计划。

3.  **执行并监控反馈循环**
    *   **输入**：步骤2输出的调整后策略。
    *   **操作**：应用新策略执行任务一段时间（例如，15-30分钟），然后再次回到步骤1，评估状态变化。
    *   **判断标准**：能周期性中断以重新评估状态，并根据反馈持续调整。
    *   **输出**：更新后的状态评估，形成“评估-调整-执行”的闭环。

# 输出格式要求

向用户清晰说明：
1.  当前识别出的状态（无聊/焦虑/心流）。
2.  基于该状态建议的具体调整措施。
3.  建议下一次状态评估的时间点或触发条件。
