# 亚马逊品牌保护

## 品牌保护工具栈

亚马逊提供分层保护工具，组合使用效果更佳：


| 工具 | 准入要求 | 功能说明 |
| ---------------------------- | --------------------------- | ------------------------------------------------------------------- |
| **品牌备案** | 注册商标 | 基础工具；解锁所有其他保护功能 |
| **IP Alert** | 品牌备案 | 当疑似侵权者出现在你的listing上时发出警报 |
| **Transparency** | 品牌备案 | 为商品赋予唯一编码；假冒商品无法销售 |
| **Project Zero** | 品牌备案+邀请制 | AI驱动的主动打假；自助移除功能 |
| **举报侵权(RAV)** | 品牌备案 | 直接提交知识产权侵权投诉 |
| **A+内容和品牌故事** | 品牌备案 | 差异化你的listing；让跟卖者更难复制 |

## 亚马逊品牌备案设置

**要求：**

- 在销售国拥有有效的注册商标（美国USPTO、欧盟EUIPO等）
- 商标必须显示品牌名称，与产品和包装上的名称一致
- 待审商标申请可能符合IP Accelerator计划资格

**注册步骤：**

1. 访问 brandservices.amazon.com
2. 使用商标注册号+发证机构注册
3. 亚马逊与商标局核实（通常2-5个工作日）
4. 获批后：在卖家中心访问品牌备案仪表板

**重要提示：** 美国商标注册需要8-12个月。
尽早申请——没有商标就无法获得品牌备案。

## Listing跟卖检测与应对

**什么是跟卖？**
未经授权的卖家在你的品牌listing上添加自己的报价，
通常以更低价格销售假冒或灰色市场商品。

**检测信号：**

- 购物车被未知卖家抢走
- listing上突然出现新卖家
- 客户投诉产品质量或包装不同
- 评价中提到"与描述不符"

**如何检查：** 卖家中心 → 库存 → 管理库存 → 点击"报价"列中的数字

**应对流程（按顺序）：**

**步骤1：测试购买**（最有效的第一步）
从跟卖者的报价购买一件商品。
收到货后，如果是假冒或不同：你就有了向亚马逊执法团队提交的实物证据。

**步骤2：停止侵权通知**
通过买家-卖家消息发送专业信息："你正在销售[品牌]拥有的listing。这是商标侵权。请在48小时内移除你的报价，否则我们将向亚马逊提交IP投诉并追究法律责任。"
（许多跟卖者在收到此通知后会自行移除。）

**步骤3：举报侵权(RAV)**
品牌备案 → 举报侵权 → 提交ASIN+跟卖者卖家ID+证据
亚马逊通常在3-5个工作日内处理。

**步骤4：Transparency注册**（预防性）
为商品贴上唯一QR码。亚马逊系统和客户可以验证真伪。
没有有效Transparency编码的假冒商品无法在你的listing上销售。

## 防范虚假IP投诉

如果竞争对手对你提交虚假IP投诉，你的listing可能会被下架。

**预防措施：**

- 在扩大规模前注册商标
- 保留所有产品照片、包装和设计文件的时间戳记录
- 记录品牌发展历史（设计文件、发布日期、营销材料）
- 绝不使用可能属于第三方的库存照片

**应对虚假投诉：**

1. 从亚马逊投诉通知中识别投诉人
2. 通过卖家中心 → 绩效 → 账户健康 → 知识产权投诉发送反通知
3. 提供你拥有权利或有权使用内容的证据
4. 如果投诉明显虚假（DMCA滥用），你可以在美国联邦法院起诉投诉人

## 品牌备案的Listing控制功能

注册后，品牌备案为你提供：

**Listing权限：**

- 你的品牌内容优先于第三方卖家编辑
- 只有你能更新品牌listing的标题、图片和描述
- 抑制其他卖家的未授权内容更改

**搜索与举报：**

- 通过图片、关键词或ASIN搜索侵权listing
- 大批量IP侵权举报工具
- 自动保护功能，无需人工审核即可移除明显侵权

**品牌分析：**

- 搜索词表现：查看哪些搜索词引导到你的产品页面
- 购物篮分析：客户同时购买哪些产品
- 复购行为：1年内再次购买的客户百分比
- 人口统计报告：买家的年龄、收入、性别、婚姻状况

## Project Zero（高级保护）

Project Zero是邀请制计划，为品牌提供：

- 自助打假移除（即时移除listing，无需等待亚马逊审核）
- 基于你品牌的机器学习模型，主动扫描和移除假冒商品
- 仅对认证商品集成Transparency编码

**如何获得邀请：**

- 必须拥有品牌备案
- IP投诉准确率高（错误率低）
- 通过品牌备案中的Project Zero候补名单申请

## 每个亚马逊卖家都应了解的关键IP术语


| 术语 | 定义 |
| -------------------- | ------------------------------------------------------------------------ |
| **商标** | 保护品牌名称、logo、标语 |
| **版权** | 保护创意作品（照片、产品描述、包装设计） |
| **专利（实用新型）** | 保护产品的工作原理或制造方式 |
| **专利（外观设计）** | 保护产品的外观 |
| **商业外观** | 保护独特的产品外观（颜色、形状、包装） |
| **ASIN限制** | 限制谁可以在你的listing上销售（需要批准） |

## 品牌保护KPI


| KPI | 检查频率 | 触发行动 |
| ------------------------------------------------- | --------------- | -------------------------------------------------------- |
| 主要ASIN上的卖家数量 | 每日 | >1个未授权卖家 → 启动跟卖应对流程 |
| 购物车赢得率 | 每周 | <90% → 调查是否有跟卖者抢走了购物车 |
| 提及"假货"或"不同"的负面评价 | 每周 | 任何 → 从所有活跃报价测试购买 |
| 收到的IP投诉通知 | 立即 | 7天内回应以避免永久移除listing |
| Transparency扫描失败率 | 每月 | >0.5% → 调查供应链 |
