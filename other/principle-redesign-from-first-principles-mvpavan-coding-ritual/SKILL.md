# Redesign from first principles

A requirement bolted on leaves a design shaped for a world that no longer
exists.

- Work out the design as if the new requirement had been a founding
  assumption. Deliver that redesign only where the request authorizes design
  change; present the rest as a proposal.
- Think the redesign through as a whole before starting, then deliver it in
  increments rather than in one drop.
- Carry the change through every reference to it (types, documents, examples,
  rationale) until no stale trace remains.
