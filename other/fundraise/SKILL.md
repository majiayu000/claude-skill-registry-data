# /fundraise - как делается фандрейзинг

**Канон:** Библия `reglament-kak-delaetsya-fandrayzing` (плейбук: этапы 0-7, ~120 приёмов
с уликами и вердиктами ⚪ берём / 🟨 адаптируем / ⛔ только распознавание) + кейсовая сестра
`reglament-fandrayz-po-tipu-gonki` (Gonka/Либерманы, контуры A-F). Оба в
`$OBSIDIAN_VAULT\03-Insights\Operations\`. Скилл каталог НЕ дублирует - при расхождении
прав регламент.

Логика Антона: учимся у всех, включая полумошенников, как журналисты; исполняем белое
и помеченное серое; чёрное живёт в досье как детектор. Сквозной закон: **правда в цифрах
абсолютна** ([[fake-it-courage-not-fake-numbers]]) - фейк допустим как смелость выйти
недоделанным, никогда как ложь в цифре, имени или факте.

## Шаг 0 - режим и RECALL

Режим по запросу:
- **A «НАШ РЕЙЗ»** - готовим наш раунд / артефакт раунда (дек, письмо, анонс, data room, пайплайн).
- **B «ДЕТЕКТОР»** - разбираем чужой проект: правда / упаковка / ложь, продукт или пирамида.
- **C «УРОК»** - объяснить приём/этап (ответ = таблица приёма + улика + вердикт, без стройки).

RECALL обязателен: оба регламента целиком + [[two-storefronts-raise-and-acquihire]]
(наш текущий рейз: floor, портфель) + для режима A ещё §6 инсайта
`insight-DR-DR26-08-24-HUB-06-2040` (наши активы, честный потолок чека).

## Шаг 0.5 (режим A) - SECURITIES HARD-STOP (наследуется из /gonka-fundraise)

Предмет - токен, поинты, airdrop с ожиданием цены, доля в доходах, нода ради пассивных
токенов или иное публичное инвестпредложение рознице? -> СТОП: юрист + Tier-2 аск Антону.
Белая математика поверх чёрного предмета = чёрное целиком. Розница легальна только через
обвязку (Reg CF/A+, Echo/Legion/Buidlpad, Reg D/S) - см. этапы 2 и 6 плейбука.

## Шаг 1 (режим A) - собрать по этапу

Определи, на каком этапе 0-7 живёт задача, открой его таблицу в регламенте и пройди строки:
1. **Этап 0 Подготовка:** актив вместо выручки; артефакт, переживающий пересказ; data room
   + forward model; цифра без первоисточника в питч не идёт.
2. **Этап 1 Нарратив:** wedge раньше платформы; why-now; категория; метрики только честные
   (ARR ≠ run-rate ≠ CARR - три разных слова в тексте).
3. **Этап 2 Структура:** стандартная обвязка (SAFE+warrant, Reg D/S, foundation/OpCo);
   отсутствие обвязки у себя = красный флаг нам самим.
4. **Этап 3 Пайплайн:** квалификация инвестора (dry powder, 10+ сделок/год, правило 42);
   тиры; параллельный процесс 2-3 недели; term sheet как рычаг (только реальный).
5. **Этап 4 Заголовки:** new/total/commitment ТРЕМЯ раздельными числами; имена только
   с реальной связью с ЭТИМ юрлицом; полный контур A - в /gonka-fundraise.
6. **Этап 5 Медиа:** op-ed, релизная волна, пресс-музей, каскад - каждая цифра в каскаде
   проходит тот же тест правды, что data room.
7. **Этап 6 Розница/крипто:** только белые двери (Echo/Legion/Buidlpad, KOL с раскрытием).
8. **Этап 7 После раунда:** investor updates; у каждого публичного обещания дата ревизии.

Выход: черновики + для каждого блока строка «приём этапа N -> как применён».

## Шаг 2 (режим A) - claim-audit, ворота перед показом

Каждое денежное/метрическое утверждение получает метку: ✅ факт (первоисточник с датой) ·
🟨 упаковка (правда, поданная выгодно - допустима ТОЛЬКО с уточняющим словом прямо в тексте:
commitment, implied, annualized, cumulative) · ⛔ нельзя. Хоть один ⛔ -> переписать.
Затем `/taste-check`; деньги/юр.обязательства/структуры = Tier-2 -> аск Антону.
Исходящее инвестору = класс по [[standing-outbound-mandate]].

## Шаг 1' (режим B) - детектор чужого проекта

1. Прогони через `/gonka-fundraise` режим B (10 вопросов по контурам A-F).
2. Добавь этапные детекторы плейбука:
   - выручка: сверена с банком, не с деком? CFO/аудит есть? (HeadSpin-маркер);
   - рост: источники трафика сырыми данными? (IRL-маркер: 95% ботов);
   - клиенты: крупнейшие клиенты = крупнейшие поставщики? (round-tripping Builder.ai);
   - логотипы: звонок самому «клиенту» (Theranos/11x-маркер);
   - оценка: filing есть? valuation/ARR кратно >50x? SAFE cap ≠ оценка;
   - стадия/раунд: extension под видом нового? секондари внутри? primary сколько?
   - токен: MC/FDV, концентрация топ-кошельков, глубина стакана против «капитализации»,
     MM-контракт (Movement-маркер), wash-trading (DOJ 09.10.2024), subsidy ratio;
   - розница: реферальная награда за ПОКУПКУ токена = пирамидный слой (FTC-тест).
3. Вердикт тремя корзинами: **правда / упаковка / ложь** + строка «продукт или пирамида»
   с уверенностью. Эталон: разбор Gonka 26-27.08.2026.

## Шаг 3 - Connect

Режим A -> артефакты в материалы рейза / контент-воронку (`content_miner.py capture`,
draft-first); режим B -> инсайт в волт (`/obsidian-ingest`) + при лид-потенциале карточка
в CRM; урок C -> при повторе 3+ раз кандидат в регламент. Контентный момент - в воронку.

## Границы (не ослабляются ничем)

- Правда в цифрах - абсолют; ⛔-строки плейбука = детектор, не меню.
- Деньги, юр-структуры, обязательства, публичные анонсы сумм = Tier-2 -> Антон.
- Публичные каналы - матрица площадок §3.2; исходящее - по классам мандата.
- Чёрное описано полно (HeadSpin, IRL, Bitwise, Outcome, Builder.ai, Frank, Ozy, FTX,
  HyperFund, Movement, Mantra, wash-trading) как карта чужого фейка - за любой из этих
  приёмов сажают, и это буквально показано приговорами в уликах регламента.
