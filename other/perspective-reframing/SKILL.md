# perspective-reframing

## When to Use

当需要从现有内容中创造新意，或避免内容同质化时description

## Core Logic

# 执行步骤

1.  **输入**：一个你熟悉且认为有价值的现有想法、概念或内容主题。
2.  **视角定位**：基于你的个人经历、专业背景、价值观或独特观察，确定一个切入该主题的新颖角度。判断标准：该角度能让你对主题产生不同于主流解读的见解。
3.  **深度思考**：在不受干扰的环境中，从你确定的视角出发，对该主题进行重新审视和探索。思考它对你的意义、它如何与你所知的其他事物关联、它被忽略的层面等。判断标准：能产出至少三条从该视角衍生的新论点或新诠释。
4.  **内容阐述**：使用你的语言和逻辑，将重新审视后的想法组织并表达出来。判断标准：最终内容的核心观点源于现有主题，但论述方式和重点明显带有你的个人印记。

# 输出格式要求

输出应包含：
1.  原始主题/想法。
2.  你选择的独特视角。
3.  基于该视角阐述的核心内容要点或论述框架。
