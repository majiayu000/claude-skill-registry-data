# broad-topic-funnel

## When to Use

当需要为专业或小众内容吸引初始流量和广泛关注时description

## Core Logic

# 执行步骤

1.  **定义核心受众与广泛切入点**
    *   **输入**：你想要最终服务和影响的具体目标受众画像。
    *   **操作**：分析该核心受众的底层、普遍性需求或兴趣（如追求效率、渴望成长、关心健康、希望赚钱）。
    *   **判断标准**：找到1-2个与你的专业领域相关，但受众面远大于你核心受众的广泛主题（例如，为“SaaS创业者”写作，但从“生产力”或“商业思维”切入）。
    *   **常见误区**：所有内容都使用只有核心受众才懂的行业黑话或深度话题，无法破圈。

2.  **以广泛主题创作包容性内容**
    *   **输入**：步骤1确定的广泛主题。
    *   **操作**：创作以广泛主题为标题和切入点，但内核融入专业见解的内容。确保内容对广泛人群有直接价值或启发。
    *   **判断标准**：一个对该广泛主题感兴趣的普通读者能完整阅读并从中获益。
    *   **常见误区**：标题和内容脱节，或为了吸引广泛受众而完全稀释了专业价值。

3.  **嵌入专业钩子与转化路径**
    *   **输入**：步骤2创作的广泛主题内容。
    *   **操作**：在内容中自然展示你的专业领域如何为该广泛问题提供更优解，并引导对你的专业内容（如更深入的文章、通讯、服务）感兴趣的读者进行关注或订阅。
    *   **判断标准**：内容能吸引广泛流量，同时能有效筛选并引导部分读者成为你的专业内容追随者。
    *   **常见误区**：生硬地插入广告或转化引导，破坏内容体验；或完全没有引导，无法沉淀精准用户。

4.  **服务与深化核心受众**
    *   **输入**：通过步骤3吸引来的、对专业领域表现出兴趣的读者。
    *   **操作**：为这部分核心受众提供更深度的、专门针对其需求的内容、产品或服务。
    *   **判断标准**：核心受众的互动深度和忠诚度显著高于一般广泛受众。
    *   **常见误区**：获得核心受众后，仍只创作广泛内容，无法满足其深度需求导致流失。

# 输出格式要求
输出一个内容策略框架，包含：
1.  你的核心专业领域/受众。
2.  选定的1-2个广泛切入点主题。
3.  针对每个广泛主题的1个内容创意示例（标题+核心观点）。
4.  在该示例内容中嵌入的、指向专业领域的“钩子”或转化引导设计。
