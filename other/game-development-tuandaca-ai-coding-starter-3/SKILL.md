# Game Development Skill

This skill provides game development guidance.

- Game loop and tick systems
- Entity-component-system (ECS)

- Asset pipeline and loading
- Input handling abstraction

## Gameplay Systems

- State machines and behavior trees
- Physics integration (Box2D, PhysX, Rapier)
- Animation systems (skeletal, vertex, procedural)
- AI (pathfinding, decision making)
- Save/load and serialization

## Rendering

- Sprite batching and atlasing
- Shader basics (GLSL, HLSL, Shader Graph)
- Lighting and post-processing
- Particle systems
- LOD and culling

## Multiplayer

- Network architectures (authoritative, P2P)
- State synchronization
- Lag compensation
- Anti-cheat basics
