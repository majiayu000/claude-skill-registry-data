# Product Strategy

Choose one primary mode and read only its workflow. Add the other mode only when the request explicitly needs both internal product shaping and external evidence.

| Mode | Use when | Workflow |
| --- | --- | --- |
| `product-discovery` | Frame users, problems, assumptions, success, acceptance criteria, or the smallest useful release. | [Product discovery](references/workflows/product-discovery.md) |
| `competitive-research` | Research competitors, categories, pricing, standards, ecosystem norms, or external decision evidence. | [Competitive research](references/workflows/competitive-research.md) |

Do not load sibling workflows or artifacts prospectively. Keep volatile external claims dated and sourced; stop before architecture or implementation unless the selected workflow explicitly calls for a handoff.
