# 供应商分析技能

## 适用场景
用户询问“这家供应商怎么样”“对比几家供应商”“哪些资质快到期”等。

## 数据获取
1. `supplier_page` / `supplier_search` / `supplier_get`：档案与状态；
2. `supplier_scorecard`：年度采购额、订单数、评分、资质最近到期、平均交付天数、取消次数；
3. `alerts_summary`：资质临期、交付临期；
4. `order_page` / `contract_page`：合作记录与合同；
5. `part_price_history`：该供应商历史报价；
6. `generate_chart`：雷达图或柱状图。

## 分析维度
| 维度 | 指标 |
|---|---|
| 合作规模 | 年度采购额、订单数 |
| 质量与交付 | 评分、平均交付天数、取消次数 |
| 合规 | 资质状态、最近到期日 |
| 价格 | 历史均价与最近报价 |

## 输出格式
先给 1 句话结论，再给指标表，最后给 2–3 条可执行建议（续约/观察/淘汰）。

## 边界
- 评分与金额必须来自工具结果；
- 资质到期日为空时说明“未登记”；
- 淘汰/暂停合作属于写操作，必须人工确认。
