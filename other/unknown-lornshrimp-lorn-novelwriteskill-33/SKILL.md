# 通用-作者风格进化

> **题材路由**：跨题材通用能力本体，供各题材外围 Skill 按名称引用（题材包装层只承载题材特有边界；共性进化方法一律回本 Skill）。**与 通用-蒸馏作者文风 的分工**：蒸馏作者文风 = 静态一次性，从已有作品提取文笔 DNA 建**种子画像**；本 Skill = 动态持续，访谈捕获原声做**长期进化**并回填画像。二者相互校准：前者回答"作者过去写成什么样"，后者回答"作者现在想写成什么样、说话是什么味"。

## 适用场景 / 触发词

- 让小说"越来越像自己"、有独有观点与叙述味：`进化我的文风`、`越写越像我`、`挖我的创作观`、`再来一轮风格回访`、`更新我的风格画像`
- 校准剧情冲突的真实判断：`主角该不该原谅他`、`反派要不要写成值得同情`、`这个结局爽还是苦`
- 补主题立场 / 母题 / 叙述原声：`挖我'背叛'的看法`、`给我讲讲你构思的一个小场景`
- 大纲 / 正文 / 润色 / 审阅前画像缺失或过旧：`风格画像多久没更新了`、`先按我的风格写这章`
- **嵌入模式（自动触发，无需作者手动请求）**：选题构思 / 竞品分析 / 大纲设计 / 人物设计 / 背景设计 / 章节创作等环节 Skill 在环节开始前自动调用本 Skill 收集作者反馈

## 核心约束 / 硬规则

1. **挖观点 ≠ 问观点**：直接问观点得到的往往是人云亦云；必须用苏格拉底式追问 / Laddering 阶梯法逐层下钻，直到拿到具体、有立场、可写作的判断。
2. **风格只从自由输入长，不从选项长**：选项是 AI 拟的（代表 AI 表达，不捕获）；作者只要不是单纯点选——追加文字、写一段话、用"其他"——这段文字就是作者最自然的表达，**一律进入原声捕获队列，不得丢弃**。
3. **观点可改写，原声一字不改**：观点沉淀进画像允许归纳转写（但必须引用作者原话、不代作者发明立场）；作者原话进样本库**逐字保留，禁止 AI 改写**。
4. **反向净化（防 AI 自创）**：画像中**找不到 ≥2 条样本支撑**的风格描述 → 降级或删除。画像只从样本库长，不从 AI 想象长。
5. **四段式提问强制（背景→问题→为什么问→选项）**：任何提问不得裸问；选项必须"主句 +（括号解释）"整体成段，作者不依赖任何折叠说明即可读懂。
6. **每次回访 ≤4 问**，下钻有限次数（回合太长作者疲劳），以"回答能写成观点 / 捕获到原声"为够；**每次回访至少 1 个 A 类叙述声口槽位**。
7. **A/B 双类原声分流**：A 类 = 作者**讲故事时的叙述原声**（叙述声口唯一权威来源）；B 类 = 作者**谈创作判断时的原声**（观点与母题来源）。两类都进样本库：A 类核心喂叙述句法层，B 类核心喂情节伦理 / 价值母题层。
8. **禁止把作者的反共识判断"洗平"成主流**：作者真说非主流、反套路时，尊重作者判断，以作者原话为筋骨。
9. **嵌入模式轻量化（被各环节 Skill 调用时）**：低频必采环节（项目初始化 / 题材定位 / 竞品 / 总纲 / 分卷 / 人物 / 设定 / 案件 / 线索 / 章节批创作）每环节前置收集 ≤2 问（默认 1 问）；高频草稿环节（控制卡 / 场景 / 对话 / 强化 / 标题 / 多平台等）**只读消费画像，不提问**；同一主题域 7 天内已有立场 → 不重复提问，直接回喂画像摘要；嵌入样本计入周期蒸馏触发计数。
10. **散落触点捕获（无意识信号 ≥ 提问）**：① 改稿痕迹触点——作者对 AI 改稿 / 去味稿 / 润色稿的修改 diff（恢复了哪句、删了哪句、坚持哪句）= 无意识审美，逐条进样本库；② 审阅回流触点——作者对审阅意见的取舍（哪些接受、哪些坚持反驳）= 创作判断最佳现场；③ 作者窗口触点——作者有话说 / 书评 / 简介 / 读者互动的作者原话 = 读者关系经营层唯一来源；④ 口述转写触点——作者口述场景 / 过往 → 转写逐字入库 = 叙述原声最强来源（A 类）。

## 数据文件自动发现规则

- 数据文件（作者原声样本库 / 作者风格画像）放小说项目根 `蒸馏产物/作者风格进化/`，并在项目根 `Agents.md` 注册为本 Skill 的消费数据源；下游写/审/改 Skill 通过 `Agents.md` 自动发现"作者风格画像增量"。
- 发现顺序：① `Agents.md` 中注册的 作者风格进化 条目路径 → ② 默认路径 `蒸馏产物/作者风格进化/` → ③ 都不存在时：先调用 `通用-蒸馏作者文风` 建种子画像（用已有作品提取文笔 DNA），再开始本 Skill 首轮回访；**不得在无种子画像时凭空生成"作者风格画像"**。
- 种子导入：`通用-蒸馏作者文风` 产出的"作者风格模板"可作画像初值（其统计类结论作为叙述句法层初稿），进化蒸馏后由访谈原声逐条覆写 / 增补。

## 主输出平台（不适用）

本 Skill 不涉及平台输出差异，平台约束交由 `通用-多平台小说适配` 处理。多平台版本改写需要"作者味"时，由平台输出 Skill 读取本画像的叙述句法层与作者语言库。

## 执行流程

### Step 0：读取现状（避免重复提问）
- 读取 `作者原声样本库.md`（滚动样本区最新 N 条）+ `作者风格画像.md`（各层现状）+ 项目根 `Agents.md` 已注册条目
- 产出「已有盘点」：哪些主题已有立场 / 母题（不重复问）、哪些空白（重点挖）、样本累计条数与距上次蒸馏天数（决定本轮是否触发周期蒸馏）
- 若画像为空且项目有 `通用-蒸馏作者文风` 产物：先做种子导入再进 Step 1

### Step 1：设计问题（遵循方法文件，≤4 问）
- 按 `references/访谈挖观点与挖声口方法.md` 的 7 槽位选 ≤4 个，定制到当日主题
- 每个问题按四段式：① 背景（事件/情节/人物上下文，≤80 字）→ ② 问题（有立场指向）→ ③ 为什么问（≤40 字）→ ④ 选项（3–4 个"主句+括号解释"）
- 偏好覆盖：① 当日 / 近段创作校准；② 空白主题；③ 叙述声口挖矿（A 类）——叙述声口是小说风格最高辨识度，**每次回访至少 1 个 A 类槽位**

### Step 2：交互执行 + 原声捕获
- 用 AskUserQuestion 发起，每题顺序 = 背景 → 问题 → 为什么问 → 选项，允许自由输入
- 追问规则：选项背后有更深观点时下钻（先给背景再问）
- 作者疑惑（"不懂问什么"）→ 视为背景不足，补事件时间线或作品原句再重问
- **捕获（强制）**：每题回答逐个检查，凡含自由输入成分（非纯选项文本）→ 加入捕获队列，当场记录原话全文 + 上下文 + 初判风格特征（防遗忘先存临时草稿，Step 3.5 统一归档）

### Step 3：蒸馏（把回答加工成观点底座）
- 产出「作者创作判断图谱」：
  - ① 核心创作判断（人物 / 情节 / 母题立场，标注作者原话出处）
  - ② 母题与价值归位（按画像价值母题层归类；Laddering 跨阶梯反复项 = 核心母题）
  - ③ 可写作姿态（作者偏合哪派、反感哪种写法、敢做哪种反共识情节安排）
  - ④ 文风层候选（A/B 类原声里最像作者的话 1–2 句，逐字保留，供画像回填）
- 禁止：代作者发明立场；把作者反共识判断"洗平"成主流

### Step 3.5：原声归档样本库（观点进画像、原声进样本库，两条线分开走）
- 按 `references/原声样本库归档模板.md` 的 L2 模板逐条归档到样本库「滚动样本区」顶部：原话（逐字）/ 上下文 / 风格初判（按画像六层打标签）/ 可引用金句候选；标注 A 或 B 类
- 无自由输入时标 `N/A（本轮全为选项作答）`，不虚构样本
- 纯选项回答中作者追加的关键句：若含立场，同条同时进样本库（按 A/B 性质）+ 观点沉淀（Step 4）

### Step 4：沉淀回画像（强制）
- **主题制，非日期制**：新增 `作者风格画像.md` 小节（`## {YYYY-MM-DD}：{新增特征}`）或修订既有层；日期是元数据不是文件名
- 修订既有层时，按 `references/作者小说风格画像卡.md` 的六层落位（叙述句法 / 情节伦理显影 / 情绪审美 / 作者语言库 / 价值母题 / 人物声口）
- 若本轮出现作者原声句子 / 新金句 / 口语命名 → 必须回填对应层（语言库 / 句法层 / 人物声口库），只从作者原话长
- 所选主题有对应选题目录 / 大纲文件时，把蒸馏结果同步写回其「作者创作判断底座」供下游创作消费

### Step 5：闭环确认 + 周期蒸馏检查
- 验证新观点 / 新原声可被检索（关键词能在画像 / 样本库命中）
- 产出「本轮蒸馏摘要」：挖到的新判断、强化的母题、叙事声口变化、样本数增量
- **周期蒸馏触发检查**：样本库新增条数 ≥10 或距上次蒸馏 ≥7 天（先到为准）
  - 触发 → 通读新增原声 → 统计重复句式 / 词汇 / 论证 / 情绪 / 金句 / 比喻模式 → 新模式回填画像对应层 → **反向净化**（画像中无 ≥2 条样本支撑的描述降级 / 删除）→ 标注"样本库 N 条蒸馏，{日期}"
  - 未触发 → 摘要记"样本累计 N 条，距上次蒸馏 d 天"，不做蒸馏不标注

## 嵌入模式协议（被各环节 Skill 自动调用）

> 完整回访（上面 Step 0–5）由作者手动或周期触发；**嵌入模式**由选题构思 / 竞品分析 / 大纲 / 人物 / 背景 / 章节创作等环节 Skill 在环节开始前自动调用，是本 Skill 的全流程自动收集通道。环节→槽位→消费层映射见 `references/环节嵌入点映射.md`。

### 触发与输入
- 触发：调用 Skill 执行流程开始前（一律不阻断主流程；未注册数据源时跳过）
- 输入：环节名 + 本环节决策主题（调用 Skill 从映射表取建议槽位传入）

### 执行（轻量回访）
1. **去重**：查样本库 / 画像「蒸馏记录」，同一主题域 7 天内已有立场 → 不再提问，直接回喂画像摘要
2. **提问**：≤2 问，仍用四段式但【背景】可缩短为本环节场景一句话；优先用环节映射表建议槽位
3. **捕获**：自由输入原声照常进捕获队列（A/B 按性质分），当场记录防遗忘
4. **沉淀**：回答即归档（L2 模板，备注 `嵌入模式·{环节名}`）→ 立场直接回填画像对应层小节——不重复完整 Step 3 / Step 4 深加工
5. **回喂**：输出该环节「画像摘要卡」（= 消费层现行摘要，≤1 页），供调用 Skill 执行中作为作者约束

### 约束
- 嵌入模式不替代完整回访：周期蒸馏（≥10 条或 ≥7 天）、深度下钻、反向净化仍由完整回访承担
- 嵌入模式捕获的样本计入周期蒸馏触发计数（与回访样本合并统计）
- 每次嵌入 ≤2 问；去重命中时不硬问，直接回喂

## 像不像审计协议（验证"应用"是否到位）

> 所有"作者味"沉淀最终要落到成品正文上。审计由 `通用-审阅章节正文` 在含 **作者风格进化数据源** 的项目上执行，指标数字必须来自脚本 `scripts/voice_audit_novel.py`（Anti-Cheat：禁止手写达标结论）。

| 指标 | 定义 | 达标线 |
| --- | --- | --- |
| 原声句占比 | 正文中直接引用 / 改编自原声样本库的句子 ÷ 总句数 | ≥15% |
| 作者惯用语命中率 | 画像卡引号短语（毒舌命名 / 惯用语 / 口头禅）在正文命中 ÷ 章节数 | ≥1 次/章 |
| 立场显影溯源率 | 可回溯到价值母题层 / 显影层的立场性情节 ÷ 主张性情节 | ≥80% |
| 风格漂移检测 | 句长 / 对话标签 / 叙事距离与叙述句法基线偏离度 | 偏离 >30% 复审 |

- 不达标 → 定位漂移项，回 `通用-正文润色` / `通用-去AI味重写` 定向修复；全部达标 → 画像本回合实证成立
- 审计结果写入审阅报告「作者像不像审计」子节；无数据源时跳过，不报错

## 强制要求 / 执行安保

| 检查项 | 达标标准 |
| --- | --- |
| 提问有立场指向 | 每个问题逼得出"支持 / 反对 / 这样写 / 那样写"的判断，不是开放闲聊 |
| 背景完整 | 每问含【背景】段；选项为"主句+括号解释"（非裸标签） |
| 有下钻 | ≥1 问用苏格拉底 / Laddering 追到价值 / 母题层 |
| 叙述声口挖矿 | 每次回访 ≥1 个 A 类（叙述原声）槽位 |
| 判断可溯源 | 每条创作判断标注作者原话，不代拟 |
| 原声必归档 | 本轮凡含自由输入的回答已逐字归档（含上下文 + 初判 + A/B 标注）；纯选项轮次标 `N/A` |
| 周期蒸馏 | 触发条件满足已蒸馏回填 + 反向净化；未触发已记录累计数 |
| 嵌入模式合规 | 被环节调用时 ≤2 问、高频草稿环节只读不提问、去重命中不硬问、原声照常归档并备注嵌入环节、回喂画像摘要卡 |
| 散落触点捕获 | 改稿 diff / 审阅取舍 / 作者窗口原话 / 口述转写已按触点标注进样本库（无触点事件时标 N/A） |
| 像不像审计 | 有数据源的项目审阅时已跑 `voice_audit_novel.py` 取数，禁止手写达标结论 |
| 可复用 | 画像层可直接被 `通用-创建小说正文`/`通用-正文润色`/`通用-去AI味重写`/`通用-审阅章节正文` 核销消费 |
