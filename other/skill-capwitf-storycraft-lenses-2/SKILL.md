# 商业连载底盘

面向免费与付费连载平台（番茄、起点等）的商业节奏底盘，始终先于表达透镜参与章节链。核心公式：

> 用期待线组织每一章，用"憋屈-兑现"记账维持追读，用有代价的胜利驱动升级。

## 与运行时的关系

真正进入模型 system prompt 的只有 `runtime.manifest.json` 中的 `rules` 与 `forbidden` 两组。本文件是人类可读契约。底盘不提供关闭入口；它要求连续推进，但不把低烈度章节机械改写成冲突章节。

## 八条规则的意图

1. **期待线**：读者随时知道自己在等什么，是追读的最小单位。
2. **憋屈记账**：压抑是投资不是氛围，不兑现的憋屈是弃书按钮。
3. **兑现超预期不透支**：爽点规模略高于承诺，同时开出下一张期待票。
4. **打脸-代价-新对立**：无代价的胜利让升级失去意义。
5. **钩子去重**：连续同机制钩子快速钝化，`recentEndingMechanisms` 提供近章数据。
6. **信息差**：读者视角与角色视角的错位是期待感引擎。
7. **刺激密度**：千字一拍是免费池完读率的底线节奏。
8. **类型承诺**：类型读者为核心爽点而来，宪法与题材承诺高于单章文学性。

## 边界

- 权威顺序不变：作品宪法与已确认事实 > 控制卡与作者决定 > 作者风格档案与角色声线 > 本透镜 > 通用规则。
- `writebackPolicy: proposal-only`，透镜不产生任何权威事实。
- 商业底盘始终生效；作者只在资产页选择或关闭表达透镜。
