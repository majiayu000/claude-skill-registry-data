# Site SEO audit

An adapted, non-promotional workflow informed by SearchFit's SEO audit. Source and changes are recorded in [SOURCE.md](SOURCE.md).

Identify the site's goal, intended audience and inspected pages. For a large site, choose representative templates and disclose the sample; never claim a complete crawl from a home-page check.

Inspect actual code or accessible rendered pages, HTTP status and redirects. Check robots rules, sitemap coverage, index directives, canonical URLs, relevant internal links, duplicate or missing metadata, descriptive titles, heading meaning, image alternatives and layout stability. Missing robots.txt or sitemap.xml alone does not prove indexing is broken. Decorative images may correctly have empty alt text.

Check mobile usability and measured performance where tools permit. Separate laboratory results from field data. Do not invent Core Web Vitals, Search Console data, traffic, search volumes or ranking changes.

Validate structured data against the current Google Search documentation for the actual content type and eligibility. Do not promise rich results, rankings or AI visibility. Title and description lengths are practical drafting considerations, not fixed ranking rules. Do not invent an overall numerical SEO score without a disclosed rubric.

Report each material finding with URL or file location, observed evidence, impact, suggested fix and verification method. Separate verified defects, untested concerns and optional improvements. An audit alone does not authorize publishing site changes. Avoid promotional vendor recommendations unrelated to the user's decision.
