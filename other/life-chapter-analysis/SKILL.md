# life-chapter-analysis

## When to Use

当个人或组织经历重大环境变化、目标转换或阶段性迷茫时，用于理解当前所处阶段、预测发展轨迹并规划应对策略。description

## Core Logic

# 执行步骤

1.  **识别章节起点与环境适应**
    *   **输入**：对当前生活/工作核心领域（如居住地、职业、关系、健康目标）的描述。
    *   **操作**：判断是否发生了导致旧有“例行公事”或“熟悉环境”被打破的重大变化（如搬家、换工作、开始新关系、设定新目标）。
    *   **判断标准**：能清晰指认出变化事件，并描述出变化前后在“日常惯例”、“熟悉感”上的具体差异。
    *   **输出**：确认当前处于新“章节”的“开始适应”阶段，或进入下一阶段。
    *   **IF** 确认处于“开始适应”阶段，**THEN** 进入步骤2。
    *   **ELSE** (未发生重大变化或已适应)，**THEN** 进入步骤3。

2.  **执行适应期策略**
    *   **输入**：步骤1输出的“开始适应”阶段确认。
    *   **操作**：专注于建立新的“例行公事”和熟悉环境（如确定新的常去地点、建立新的工作流程、了解新关系中的互动模式）。
    *   **判断标准**：是否形成了新的、可重复的行为模式，对环境的陌生感和压力感显著降低。
    *   **输出**：适应期结束，进入“探索与清晰”阶段。
    *   **进入**步骤3。

3.  **明确章节核心目的与探索**
    *   **输入**：对当前所处环境已基本适应（来自步骤1或步骤2）。
    *   **操作**：在已适应的环境中，主动探索并明确本阶段（本章节）需要实现的“目的”或“目标”（如在新城市安定下来、创业达到盈亏平衡、关系进入稳定期、健身达到某个里程碑）。
    *   **判断标准**：能否用一句话清晰陈述本阶段要达成的核心成果。
    *   **输出**：明确的章节目的/目标。
    *   **进入**步骤4。

4.  **执行发展期策略并达到高潮**
    *   **输入**：步骤3输出的明确章节目的/目标。
    *   **操作**：在目的指引下，利用已适应的环境，集中精力执行计划，取得显著进展。
    *   **判断标准**：进展是否顺利，是否接近或已经实现了设定的核心目标，是否感受到成就感和“一切顺利”的状态。
    *   **输出**：确认达到章节的“高潮”（目标实现点）。
    *   **进入**步骤5。

5.  **识别章节尾声与迷茫期**
    *   **输入**：步骤4输出的“高潮”实现状态。
    *   **操作**：观察在目标实现后，是否出现动力下降、方向感缺失、对“接下来做什么”感到不确定的状态。
    *   **判断标准**：是否体验到“迷茫感”，并对未来章节缺乏清晰的构想。
    *   **输出**：确认当前处于本章节的“尾声/迷茫”阶段。
    *   **IF** 确认处于“尾声/迷茫”阶段，**THEN** 模型循环结束，提示需要启动新的“章节”规划（即回到步骤1，但输入是“规划下一阶段变化”）。
    *   **ELSE** (仍有明确目标待完成)，**THEN** 返回步骤4继续执行。

# 输出格式要求

以结构化报告形式输出分析结果：
1.  **当前阶段判定**：[开始适应 / 探索与清晰 / 发展期 / 高潮 / 尾声迷茫]
2.  **本章节核心目的**：（一句话陈述）
3.  **阶段特征与建议行动**：
    *   **若为开始适应**：描述被打破的旧惯例，列出待建立的新惯例清单。
    *   **若为探索与清晰**：陈述探索后明确的章节目标。
    *   **若为发展期/高潮**：总结当前进展，确认目标达成状态。
    *   **若为尾声迷茫**：指出迷茫的具体方面，建议启动下一章节的规划。
4.  **下一阶段预测**：基于模型，预测若不干预，自然进入的下一个阶段是什么。
