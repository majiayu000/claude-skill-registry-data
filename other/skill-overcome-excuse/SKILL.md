# skill-overcome-excuse

## When to Use

当面对新任务或挑战，内心产生“缺乏经验”、“不擅长”等自我否定想法时description

## Core Logic

# 执行步骤

1.  **识别并记录限制性信念**
    *   **输入**：对当前任务/目标的内心感受和想法。
    *   **操作**：将脑海中浮现的“我不能做/我不擅长/因为XX所以不行”等具体理由写下来。
    *   **判断标准**：是否清晰、具体地列出了至少一个自我否定的理由。
    *   **输出**：一份书面化的“借口清单”。

2.  **信念解构与再定义**
    *   **输入**：步骤1产生的“借口清单”。
    *   **操作**：对清单中的每条理由进行审视：
        *   **IF** 理由是关于技能缺乏（如“我不会写作”），**THEN** 将其重新定义为“这是一个需要学习和练习的技能”。
        *   **IF** 理由是关于外部条件（如“只有网红才能成功”），**THEN** 将其重新定义为“这是一个需要验证的市场假设或可选择的路径”。
        *   **IF** 理由是关于恐惧（如“我害怕失败”），**THEN** 明确承认这是情绪反应，而非事实判断。
    *   **判断标准**：是否将每个“静态的否定句”转化为“动态的可行动描述”或“待验证的假设”。
    *   **输出**：一份转化后的“行动视角清单”。

3.  **制定最小启动行动**
    *   **输入**：步骤2产生的“行动视角清单”及原始任务/目标。
    *   **操作**：针对转化后的视角，设计一个可在24小时内执行的、极低成本的启动动作。
        *   **例如**：针对“需要学习写作”，启动动作是“写下关于本主题的100字初稿”或“研究一篇优秀范文的结构”。
        *   **例如**：针对“验证市场假设”，启动动作是“在相关社群提出一个具体问题”或“私信询问3位同行者”。
    *   **判断标准**：启动动作是否足够小、足够具体，以至于“没有理由不去做”。
    *   **输出**：一个明确的、微型的下一步行动指令。

4.  **执行并记录反馈**
    *   **输入**：步骤3制定的“最小启动行动”指令。
    *   **操作**：立即或在计划时间内执行该行动。完成后，简要记录：做了什么、感觉如何、学到了什么、下一个微小的步骤是什么。
    *   **判断标准**：是否完成了启动行动，并产生了无论积极或消极的、具体的个人反馈。
    *   **输出**：已完成的行动记录与新一轮的“行动视角清单”（用于迭代）。

# 输出格式要求
向用户呈现一个清晰的决策路径：
1.  首先，展示您识别出的核心“借口”（来自步骤1）。
2.  然后，展示对该借口的“重新定义”（来自步骤2）。
3.  最后，给出一个“立即可以做的微小下一步建议”（来自步骤3）。
格式为：“您的借口是：[借口]。可以将其视为：[新视角]。现在，请尝试：[具体行动]。”
