## What this skill does

- Reduces brand strategy to one ownable symbol, wordmark, monogram or lockup.
- Checks simplicity, small-size legibility, one-color behavior and distance from famous marks.

## How to use

Provide brand name, offering, audience, positioning, personality, required text and applications.

#### Example

```text
Create one final logo for NORTHLINE COFFEE: a minimal N plus mountain-path symbol, black and cream, scalable and original.
```

## Workflow

1. Extract brand promise, audience, competitors to avoid, applications and exact text.
2. Explore concepts internally, select one architecture and state why it owns the idea.
3. Generate the final logo directly with GPT Image 2 Medium/2K. Keep the brand name and any required copy exact; never treat `ai-logo-generator` as a model.
4. Inspect spelling, geometry, balance, 16px readability, one-color behavior and similarity risk.

## User-facing output

- Media type: One selected logo image
- Default quantity: 1
- Content per image: One final logo architecture on a plain background
- Default layout: User-requested or source-preserving format
- Model policy: GPT Image 2 Medium/2K for final logo geometry and readable brand text
- Downstream use: Brand identity selection and refinement
