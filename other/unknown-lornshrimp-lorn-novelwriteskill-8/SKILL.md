# 通用-正文润色
> **题材路由**：若 .github\题材专用Skills\ 目录存在对应的 <题材>-正文润色 Skill，则：
> - 将题材特性骨架路由到 <题材>-正文润色，该 Skill 位于 .github\题材专用Skills\ 目录。
> - 命中本技能时，必须优先强制加载当前 Skill 与 <题材>-正文润色。


正文润色的目标不是单纯把句子写漂亮，而是把**已有章节**修到“更顺、更准、更抓人、但不失真”。

当题材 Skill 与本 Skill 组合调用时：

- `通用-正文润色` 负责共性流程、默认交付、弱项路由、句级动作与沉浸控制
- 题材 Skill 负责题材边界、项目特例与裁判源补充

## 缓存优化说明

本 Skill 的结构遵循前缀缓存优化原则。润色是高频调用任务（每章可能多次），调用时：

- **缓存层（永久不变）**：frontmatter + 润色总原则 + 句级动作库 + 副总裁判标准 + 弱项路由规则 → 每次调用完全相同，按底价计费
- **项目层（同项目内不变）**：references 清单 + 润色前裁判源复核要求 + 风格/蓝本模板自动发现规则 + 语言风格配置自动发现规则 → 仅在切换项目或新增模板注册时变化
- **可变层（每次变化，不写入本文件）**：本次目标章节文件路径、润色范围（整章/某段）、本次特殊约束 → 由用户每次调用时指定
- 人物传记、故事设定等裁判源通过 references 声明强制加载，其固定部分随本 Skill 一起进入缓存前缀

## 润色前裁判源复核（强制）

- 动手润色前，必须认真仔细阅读与本章实际出场人物对应的人物传记，以及与本章背景、技术、规则、证据、程序链、世界观有关的故事设定文档。
- 不得只凭现成正文、上一轮润色痕迹或审阅摘要直接下刀；凡涉及人物动机、能力边界、关系状态、设定代价、证据机制的句段，都必须回到作者侧裁判源核对后再改。
- 若同一人物传记或故事设定存在多个版本，必须先确认当前可执行的最新版本；若关键裁判源缺失，必须先补齐、定位或明确阻断，不能边猜边润。
- 若本轮润色会触碰人物弧线、规则代价、证据链、关系位置或背景事实，必须在回写前复核一次相关裁判源，确认没有把正文润偏。

3. 若 `Agents.md` 中注册了"作者风格模板"——读取对应路径的模板文件，将其约束（句长基线、段落节奏、感官偏好、对话标签偏好、比喻指纹、禁忌清单）作为润色的文笔侧裁判源
4. 若 `Agents.md` 中注册了"作品蓝本模板"——读取对应路径的模板文件，将其约束（章首模式指纹、钩子轮换规律、中段回报间隔、场景节奏分布、信息释放节拍、情感弧分布）作为润色的结构侧参照
5. 若项目根目录不存在 `Agents.md`，或其中未注册对应模板——回退通用默认模式，不报错，不阻断
6. 若 `Agents.md` 中存在 `## 语言风格配置` 段——读取并解析以下子字段：

   - `叙述者类型` → 映射到叙述距离一致性检查（保持镜头距离不漂移）
   - `表达方式占比` → 映射到段落节奏与信息密度裁判源（确保润色不偏移既定占比）
   - 语言风格配置的优先级：**低于**作者风格模板（精确的统计模板），**高于**通用默认基线

## 共性执行顺序

本 Skill 的各参考文件按以下顺序调度。除非标注"固定先读"，否则按需读取即可。

1. **先读裁判源**：认真仔细阅读本章相关人物传记、故事设定 / 背景设定、控制卡与最新审阅结论，确认不能动的钉子、可增强处与不可越界处。
2. **确认范围与强度**：明确本轮润色的范围（整章/场景/段落）、强度（轻/中/重）与不可改动项。→ 若对阶段归属有疑问，固定先读 `references/Phase0-3创作修订一体化节拍.md` 确认当前处于哪个修订阶段，再按对应阶段门禁执行。
3. **先保信息**：确保事实、因果、视角、结构功能不因润色受损。→ 固定先读 `references/正文润色保真迁移规则.md`（明确必保项、允许优化对象与禁止性操作）；并行读 `references/正文润色数值双轨禁忌与沉浸控制.md`（理解功能线与质感线的分轨原则，确保先稳功能线再优化质感线）。
4. **先修追读链**：先修章首抓力，再修中段回报，再修章末钩子。→ 固定先读 `references/正文润色流程.md`（明确整体执行顺序）。修至每步执行时，若遇具体执行问题需扩展技法，参考 `references/正文润色增强技法与读者机制.md`（章首抓力、中段回报、章末钩子、人物代入、读者机制的专项技法）。
5. **再按弱项路由处理**：对话、动作、心理、肖像、景物、静态或场面。→ 固定先读 `references/正文润色扩展参考路由.md`（症状→修法映射，按弱项类别分流）。短板明确后按需读取对应的写作指导文件（`语言/行动/心理/肖像/景物/静态/场面写作指导与好词好句好段.md`）。若遇到以下问题，再同步读取对应补强文件：
   - 感官描写空泛 → 按需读 `references/感官链与生理反应补强.md`
   - 抽象信息/术语/数据读感发虚 → 按需读 `references/抽象梯与事实转译补强.md`
   - 叙事距离控制偏移（作者视角代替角色视角）→ 按需读 `references/视角与叙述距离修正.md`
   - 段落距感判断不准（贴脸/中距/过桥）→ 按需读 `references/贴脸段中距段过桥段动作卡.md`
   - 需要压缩解释性内容而保信息 → 按需读 `references/删解释保信息的压缩动作卡.md`
   - 功能性句子需保留功能又写活 → 按需读 `references/功能句保真改写示例卡.md`
   - **阅读流畅度问题（新增——吸收自知乎答主好难说故事）**：当润色中感觉"文字没问题但读着就是难受"，优先诊断以下三类流畅度事故再决定修法。
     - **强迫解释**：解释性段落过密/过长，标志"原来/其实是/实际上/也就是说"高频出现。→ 修法：删标志词，把背景信息压缩成1-2句自然融入场景；超过150字的单处解释必须拆分。
     - **分段/标点异常**：①一句话一段（意思未讲完就换行）→ 合并到上一段或下一段直到意思完整；②标点密度异常（2-3字一个标点）→ 删除多余标点，重组为自然语流；③对话与动作描述分离 → 把同一人的对白和动作合并到同一段。
     - **视角跳跃**：同一段落内多感知主体、场景内多视角无序轮换。→ 修法：固定主视角，删除非关键人物的感知展示，增加过渡信号。

## 本轮精修新增关注点（新增）

- **开篇第一段入场测试（新增——吸收自知乎喷神·好难说故事）**：润色章首时，将正文第一段做"闭眼画面测试"——闭上眼，这段文字能不能在脑子里形成场景画面？如果不能，说明第一段使用的语言"没有着力点"，需要优先把抽象形容词改为动词+具体行为。详见 `通用-创建小说正文` 的"写作生动化铁律"。

   - 这句话能不能删？
   - 这个细节有没有必要？
   - 这个情节能不能压缩？
   - 能删就删，能压缩就压缩，把冗余内容去掉后只保留核心信息与核心爽点。

   1. **关键情绪**：主角逆袭瞬间、复仇成功、失去重要的人——用细腻描写放大情绪，让读者共情。
   2. **关键人物**：主角核心特质、反派阴险狡诈——用细腻细节刻画，让人物更立体。
   3. **关键节点**：剧情重大转折、高潮爆发的瞬间——用细腻描写烘托氛围，让情节更有冲击力。

   - 这一段是解释原因？
   - 这一段是举例？
   - 这一段是给出方法？
   - 如果一段话标不出来"这段到底在干什么"，大概率是废段，优先考虑合并或删除。
   - 执行方法：通读全章，在每个段落后用括号简短标注任务类型。标注不出来的段落标记为"无明确任务"，进入删除候选列表。
- **抽象词→动作训练法（新增——吸收自知乎白菜对我笑）**：润色正文时，圈出文中的抽象词（努力、成长、破碎、清醒、痛苦、压迫感等），然后逼自己做三层改写：
   - 这个状态如果变成动作，会是什么？
   - 这个情绪如果变成表情，会是什么？
   - 这个关系如果变成一句对话，会是什么？
   - 不需要每处都改写，但关键位置（章首、人物首次出场、高潮段、情绪爆发点）必须做至少一次抽象→动作转化。
   - 示例："他很愤怒"→"他把杯子放下时，杯底磕在桌上，茶水溅出来一圈。他没擦。"
- **因果链"所以呢"检查法（新增——吸收自知乎白菜对我笑）**：润色段落之间的逻辑衔接时，在每一个段落后追问"所以呢？"。如果这一段回答不了"所以呢"，说明它只是信息堆积而非因果推进。
   - 执行方法：写完/润完一段后，在旁边写"所以呢？"自问。如果自问后的答案与前一段结论重复，则该段需要合并或直接删掉。
   - 理想状态：全章段落之间形成"因为 A→所以 B→因为 B 出现问题→所以需要 C→C 如果做不好→会掉进 D 这个坑→所以最后要用 E 来检查"的因果锁链，而非"先说一个观点→然后说一个例子→然后说一个方法"的松散罗列。
- **细腻写多就是拖节奏——润色时的字数自检（新增——融合知乎多家观点）**：润色中若发现某一处描写/抒情/环境烘托超过 100 字且没有推进剧情或改变角色状态，优先判断：这段对读者"读了之后知道了什么新东西"的贡献是什么？——如果删掉后不影响读者对剧情/人物的理解，说明它属于"拖节奏的细腻"，直接压缩或删除。
- **裁纸刀法——写出爆点前的快速自诊（新增——吸收自知乎"我的世界"）**：当你感觉写了很长铺垫但爆点就是出不来时，用裁纸刀法自诊：
   - 遮住当前正在润色的段落，只看最末一行。
   - 问自己：如果前面那么多铺垫全部删掉，读者直接从这一行读起，会不会更刺激？
   - 如果答案是"会"，说明前面所有铺垫都可以压缩甚至直接删除，保留最末一行即可。
   - 润色时的执行策略：找到那些"最精彩的部分被藏在废话里"的段落，把精彩句提取出来做段首，把铺垫压缩或整段删除。
- **详略得当——非卖点段落的一笔带过检查（新增——吸收自知乎半盏清茶煮春秋）**：润色时扫描全章的篇幅分配，检查"卖点和非卖点是否得到了不成比例的待遇"：
   - 标注本章的核心卖点/亮点/爽点段，确认其篇幅占比 ≥ 全章的 30%。如果卖点段的总字数占比 < 30%，说明本章最吸引人的地方没有获得足够的展开空间。
   - 识别"重要性高但无聊"的情节（主角赶路、买装备、开无聊的会、日常重复操作等），确认这些段落是否被压缩到了 1-3 句内一笔带过。如果此类段落超过 3 句或被当作独立场景展开，压缩到 1-2 句或直接删掉。
   - 执行提示：东市买骏马式的叙述——承认这件事发生了但不需要展示它是怎么发生的。
- **删废词润色法——优先删除的十大废词（新增——吸收自知乎顾里木图的小酒馆）**：润色时的第一刀不是改句子结构，而是扫除以下高频废词。绝大多数情况下，删除这些词后句子反而更有力：
   - **删除优先级**：非常 > 很 > 特别 > 真的 > 其实 > 我觉得 > 突然 > 然后 > 那么 > 就这样
   - **规则**：在正文中搜索以上词汇，除了对话中为了体现角色语气而保留的（需判断是否为角色声口特征），其余一律删除。
   - **例外**：当"突然""很""非常"承担了节奏功能（如"他突然停住了脚步"中的"突然"是为制造停顿感），可以在保留后做测试——删掉后节奏是否受损。不受损则删，受损才留。
   - **原理**：删掉副词、形容词、连接词之后，留下来的名词和动词才是骨肉。不要用修饰词的堆砌来假装文笔好。
- **润色后朗读验收（新增——吸收自知乎顾里木图的小酒馆）**：润色完成后，必须将润色后的正文**大声朗读一遍**（默读无效）。朗读是润色质量的最终验收手段：
   - **朗读检查项**：
     1. **朗读顺不顺**——任何念起来磕绊、换气困难、绕口的地方，标记为句级问题，回到步骤6做句级精修。
     2. **节奏平不平**——如果读起来从头到尾都是一个语调，说明节奏未处理好——应有紧张时的急促感、舒缓时的松弛感。标记节奏问题回到步骤4修追读链。
     3. **听着假不假**——对话如果读出声后像是"念报告"而非"人在说话"，标记对话问题回到弱项路由处理。
   - **验收标准**：朗读一遍后，那些"读出来才意识到不对劲"的位置，就是润色尚未到位的位置。朗读迫使你面对文本的真实节奏——这是默读永远发现不了的问题。

画面感不是"辞藻华丽"，是"读者能在脑子里看到正在发生什么"。正文润色每个动作都服务这个目标。本节提供画面感强化的快速诊断与行动指引，完整技法体系见 `references/画面感强化技法.md`。

### 画面感六步诊断

段落读起来"信息都在但没画面"时，按以下顺序快速排查：

1. **有可见物吗？** → 读者脑中能出现至少一个具体物件/身体部位/场景？否则补一个。
2. **动词都准吗？** → 是否有弱动词可以换成强动词？是否有情绪标签代替了动作？
3. **空间关系清楚吗？** → 角色在哪儿？东西在哪儿？多远？怎么移动？
4. **光线存在吗？** → 白天还是晚上？亮还是暗？光线对角色造成了什么？
5. **有感官切换吗？** → 是否连续3句以上只有视觉？需补充听觉/触觉/嗅觉？
6. **有可被记住的细节吗？** → 100字里有一个读者能记住的细节？否则移冗余修饰换有信息量的细节。

### 画面感快速修复口诀

```
信息太多没画面 → 找一个具体物托住
动作太虚没画面 → 把动词换准
环境太空没画面 → 补一个空间坐标 + 光线
心理太深没画面 → 先把心理变成身体反应
情绪太浓没画面 → 用动作代替形容词
对话太干没画面 → 加停顿 + 小动作 + 空间关系
```

### 镜头意识

润色时建立"文字即摄影机"的镜头意识：

- **特写**（某物/表情/细节）→ 关键证据、关键情绪、关键转折
- **中景**（动作/互动）→ 推进情节的主力镜头
- **全景**（环境/空间关系）→ 建立场景、交代局势

连续三句以上用同一种景别时，考虑切换镜头距离打破单调。

### 感官定向激活

不是平均分配五感，而是根据场景选择1-2种主导感官：

- **恐惧/紧张**：触觉（后颈发凉）+ 听觉（呼吸声/脚步声），忌大量视觉描述
- **悬疑/不安**：听觉（异响/突然安静）+ 嗅觉（怪异气味）
- **愤怒/冲突**：视觉（红/白）+ 触觉（握拳/发抖）
- **压抑/沉重**：触觉（温度/质感）+ 听觉（低频声）

## 润色边界、处理顺序与情感弧保护补强（新增）

- 若本轮同时存在去 AI 味、对话、描写、节奏、措辞多个问题，默认处理优先级为：**去 AI 味 → 对话修正 → 描写精炼 → 节奏微调 → 措辞优化**。
- 润色的判断标准是“怎么写”，不是“写什么”；一旦问题涉及增删场景、重排事件、改人物选择、补悬念、补承重 beat 或重设因果，必须明确退回 `writer / 控制卡 / 正文层`，而不是继续用润色硬扛。
- 对话修正默认只在措辞、标签、声音差和动作配合层动刀，不改对话承担的事实内容；如必须改对话内容才成立，说明已超出润色边界。
- 描写精炼默认遵循“情绪外化 / 焦点控制 / 感官激活 / 隐喻节制”，不把密度和华丽误当质量。
- 节奏微调默认优先通过段长、句长、过渡、短断句与呼吸点处理，不得把原章的中段回报、高潮峰值或章末钩子磨平。
- 润色后必须显式复核情感弧：规划入口 / 出口是否仍成立、是否削弱峰值、是否放大谷值；若入口≈出口且无合理新设计，应标为结构性风险并回退上游。
- 本轮结束时默认产出简短润色回执：处理了哪些问题、情感弧是否保住、哪些问题已超出润色边界应转 `writer`。

## 极其快的节奏与极其强烈的冲突——正文润色规则（新增）

### 快节奏润色的核心方向

**1. "句长与段长的多样化"**
快节奏的正文应该在句长和段长上制造变化，避免齐平带来的单调感：
```
原稿：陈勉走进房间。房间里很暗。他看到了一个人影坐在对面的椅子上。陈勉的心跳加速了。他慢慢走向椅子。那个人影突然站了起来。

润色方向：句长变化 + 短句密集
陈勉推门。房间黑洞洞的。暗处，一个身影站了起来。不对。那不是站，而是突然从黑暗里扑出来。陈勉的脚步一滞。

[短句-短句-中长句-短句的变化制造了加速感]
```

**2. "动词的活跃化"与"时间信号的即刻化"**
快节奏的正文应该尽量用"即刻发生的动词"代替"正在发生的心理"或"可能会发生的推测"：
```
❌ 陈勉想起了上次见到这个人的时候。那次他说过如果再见面就不是朋友。陈勉意识到自己可能要面临一些危险。

✅ 陈勉认出了他。"如果再见面就不是朋友。"上次的话浮现在脑子里。危险已经近在咫尺。
```

快版本用"认出、浮现、近在咫尺"这些即时动词代替了"想起、意识到、可能会"。

**3. "转折点与节奏断层"的有意设置**
快节奏的正文应该有意识地制造几个"断层"或"转折"，让读者心理节奏跟着波动：
```
原稿：陈勉走进去，发现房间里有人，他很惊讶，但他想到了应该怎样应对。

润色：
陈勉推门进去。
房间里有人。
那是——不可能。
他应该在医院里。
```

短断句制造的断层让节奏产生了波动。

### 强冲突润色的核心方向

**1. "对立的具体化"与"立场碰撞的即刻化"**
强冲突的正文应该把所有的"对立"都化成具体的、可看见的、即刻发生的碰撞，而不是抽象的威胁或虚空的紧张：
```
❌ 陈勉和对面的人对立了。他们想要的东西不一样。陈勉很害怕，但他不想退缩。

✅ 陈勉盯着对面的人。"把钱放下。"那个人说。"除非你先把人放了，"陈勉说。两个人的目光在半空中撞在一起。无法妥协的两条线。
```

强版本让"对立"有了身体、有了语言、有了可感知的碰撞。

**2. "代价的物化"与"后果的身体化"**
强冲突的正文应该把所有的代价都改写成"可看、可听、可感"的具体后果：
```
❌ 她意识到自己犯了一个巨大的错误。错误会导致一些可怕的后果。

✅ 她按下的按钮没有回弹。灯灭了。楼下传来了巨大的爆炸声。烟灰透过窗缝吹进来。
```

强版本用具体的动作、声音、视觉来呈现"巨大的错误"。

**3. "权力与位差"的动作化表现**
强冲突的正文应该通过角色的动作、姿态、空间位置来表现权力的不对等，而不是直白地说"他掌握了主动权"：
```
❌ 绑匪掌握了绝对的主动权。他可以决定人质的生死。陈勉感到自己很无力。

✅ 绑匪靠在椅子上，腿搭在桌子上，手里转着一把刀。陈勉站在他五步远的地方，双手垂在身体两侧。"你说。"绑匪说。
```

强版本通过座椅、腿、刀、距离、指令来呈现权力的不对等。

**4. "信息的非对称性"的对话与细节中体现**
强冲突的正文应该充分利用"不同人物掌握不同信息"这一点，在对话和细节中体现这种非对称：
```
陈勉不知道警察已经在楼外围好了。所以他还在和绑匪谈判。而绑匪知道警察在外面，所以他的每一句话都在试探："你告诉我，有多少人在外面？"

[对话中透露出来的：陈勉在猜，绑匪在确认。这就是信息非对称。]
```

### 慢节奏润色的核心方向（补充——吸收自知乎"写作技巧——如何把控小说节奏？"）

快节奏润色规则解决"怎么加速"，以下规则解决"怎么放慢"。慢节奏不是"写得更差"，而是有意识地让读者放慢阅读速度，增加沉浸感与情绪投入。以下规则作用于慢节奏段落（回忆、独处、细腻情感、环境铺陈）：

**1. "感官细节填充法"：增加触感、气味和小动作**
慢节奏的正文应该从"推进信息"模式切换到"创造在场感"模式。润色方向：
```text
原稿：她坐在窗边，想着过去的事情。
润色：她的手指沿着窗台的裂缝慢慢滑动。木屑扎进指腹的触感让她回到了十年前。那天的气味——晒过的棉被、铁锈、还有他身上的肥皂味——像一下子被打翻了。
```
关键手法：把"想"转化为"身体的在场感受"——手指的触感、鼻子的气味。

**2. "拉长镜头时间"：把小动作写细，制造时间膨胀感**
慢节奏的本质是"让读者在一个瞬间停留更久"。润色方向：
```text
原稿：他把照片放进抽屉里。
润色：他的手悬在抽屉上方停了两秒。照片上的人还在笑。他慢慢把照片翻过来扣在抽屉底上，然后关上。锁舌"咔"一声撞进去。
```
关键手法：把一个动作拆成 2–3 个微型动作（悬停→翻扣→关→锁），每个动作附加一个细节（照片的笑脸、锁舌的声音）。

**3. "松紧交替验收"：确保每个慢节奏段落在上下文中成立**
润色完慢节奏段落后，必须检查它在全章节奏中的位置：
- 前一段是快节奏冲突吗？→ 慢节奏段落起到了缓冲作用，成立。
- 前后段落都是慢节奏吗？→ 如果连续 3 段以上慢节奏且主线无推进，标记"节奏过慢"，需在慢节奏中嵌入信息推进（即使是很小的推进：一个回忆中的新线索、一个关系的微妙变化）。

### 快节奏 + 强冲突润色的检查清单

[ ] 句长是否有明确的变化（不是齐平的节奏）？
[ ] 段长是否有意识的起伏（短段制造加速，长段制造沉重）？
[ ] 动词是否都是即时发生的（而不是"想象""推测""可能会"）？
[ ] 时间信号是否明确且推进（什么时刻、多少时间、倒计时）？
[ ] 对立是否具体化了（不只是"对立"，而是具体的行为、语言、空间对抗）？
[ ] 代价是否身体化了（不只是"有后果"，而是可看、可听、可感的具体后果）？
[ ] 权力分布是否通过动作和姿态体现（而不是直白叙述"谁掌权"）？
[ ] 信息非对称性是否在对话和细节中有所体现（让读者能察觉到"这个人知道但那个人不知道"）？
[ ] 是否避免了心理总结、作者旁白和抽象描写？
[ ] 整章是否维持了"快速+冲突"的双重强度，而不是某段掉回原来的节奏？

### 润色中的节奏真伪判定（新增——吸收自知乎丁文韬与流浪的蛤蟆）

> **核心原则**：润色时最容易被误判的是"节奏"。一段文本"读起来快"不等于"节奏好"——它可能只是事件清单式的平推。润色必须先区分**真实节奏**和**假节奏（事件清单）**，再决定怎么动手。

#### 真节奏 vs 假节奏的润色判断

| 对比项 | 真实节奏 | 假节奏（事件清单） | 
| --- | --- | --- |
| 读感 | 读者有"接下来会怎样？""快来了吧？"的心理活动 | 读者被动接收信息，没有期待感 |
| 结构 | 存在蓄力-期待-延迟的区间 | 一路平推，A→B→C线性 |
| 信息释放 | 选择"最吊胃口的时机"释放 | 选择"最方便交代的时机"释放 |
| 文笔特征 | 节奏快时短句密集，节奏慢时长句沉浸 | 句长均匀，无节奏起伏 |
| 概括形式 | "读者在等X→等到X→开始等Y" | "主角做了A→做了B→做了C" |

#### 润色中"保护"节奏的五条规则

**规则一：不要为了"顺畅"洗掉预告-兑现结构**
- 润色时最容易犯的错误：为了让过渡更自然、让行文更流畅，把"读者知道要来了但是还没来"的那个延迟区间给磨短或删掉了
- ❌ 错误润色："他推开门。王主任坐在里面。'你来了。'陈勉走过去坐下。"（把延迟区间的张力洗掉了）
- ✅ 正确润色："他推开门。王主任在——这个时间点，他应该在经侦科。'你来了。'语气太平静了。平静得让陈勉站在门口没动。"（保留了"不对劲"的预告信号和角色反应的延迟）

**规则二：不要用"信息压缩"替代"节奏加速"**
- ❌ 错误润色：认为原文"太啰嗦"，于是把蓄力-期待的段落压缩成一句"他意识到情况比想象的更糟"——信息还在，但节奏没了
- ✅ 正确做法：保持蓄力段的文字量，把精力放在增强每句话的信息密度和感官唤起上，而不是删减字数

**规则三："读者知道要来了但还没来"的区间必须保留**
- 如果在原文中识别到这样的区间（"读者已经猜到了结局，但故事还在四平八稳地推进细节，反复吊胃口"），这是节奏最值钱的地带
- 润色时这个区间**只能强化不能压缩**——删词不删意、段长可微调但不能整段砍掉

**规则四：区分"推进慢"和"节奏好"**
- "推进慢" = 信息密度低，600字没推进什么实质内容 → 需要压缩或重写
- "节奏好" = 信息密度高但在刻意延迟关键揭示 → 绝对不要压缩
- 判断标准：把这段原文的"新信息量"提取出来，如果去掉延迟部分后信息量几乎没变→是节奏好；如果延迟部分是重复之前的内容→是推进慢

**规则五：润色后复核"爽点预告链是否被洗平"**
润色完成后，逐一回答：
1. 本章的爽点预告定位（预告章/蓄力章/兑现章/过渡章）是否清晰？如果定位模糊了 → 预告链被洗平
2. 章首是否仍在预告"有好事/坏事要来了"的信号？如果预告信号被润弱了 → 章首抓力下降
3. 中段是否有明确的"蓄力→期待"区间？如果蓄力段被压缩了 → 节奏变平
4. 章末是否仍在制造"下一章有好戏"的预期？如果章末被润成了总结式收尾 → 翻页驱动力下降

**执行门禁**：如果上述四项中有两项以上的答案是"是（被洗平了）"，润色需要回炉——节奏保护没有做到位。

## 硬规则

- 不新增关键事实，不删减核心信息。
- 未认真仔细阅读本章相关人物传记与故事设定 / 背景设定文档前，不得直接改写人物动机、关系状态、规则表现、证据位置或背景事实。
- 不得把正文润成说明书、散文或空抒情。
- 不得把中段回报和章末钩子润没。
- **留存精修优先**：优先修"读者可能会弃"的问题（开篇太慢/中段平/钩子弱），其次修"写得不够好"的问题（措辞/节奏微调）。润色完成后自检：情绪刺激密度是否仍维持原稿水平？若去味/顺滑后情绪刺激点变少了，必须回退部分修改。
- **动词密度保护**（新增）：润色过程中不得为了"顺滑""流畅""去味"而将核心动作动词替换为形容词/抽象表达。润色完成后抽样检查本章冲突段——动词密度是否仍 ≥ 40%（核心动作动词数/总实词数，排除"是""有""想""知道""觉得""感到"）。若动词密度明显下降，必须回退部分修改。
- 不得保留或新增"这几章 / 前几章 / 前面几章 / 前面这几章 / 后几章 / 后面几章 / 后面这几章 / 整章 / 这整章 / 这一整章 / 上一章 / 下一章 / 本章 / 这章 / 后文会 / 我们会看到 / 读者会发现"这类章节自指 / 导览式话术；若原稿已有，必须改写成场景内表达，而不是原样擦亮。
- 不得为了顺口删掉关键证据、编号、时间点、规则边界。
- 不得在不必要时整章推倒重写。
- 不得用“看起来差不多够长了”代替脚本校验；凡本轮改动影响正文或 `## 作者有话说` 篇幅，都必须显式重跑对应字数脚本。
- 若润色说明、日志或后续审阅报告需要记录字数，必须直接引用脚本字段 `Len / CJK / BodyCJK / MeetsMinCJK / WithinRange / MeetsAll`，不得改写成“去空白统计”。
