# trust-matrix-framework

## When to Use

当需要系统性地构建个人品牌，并希望超越同质化竞争时description

## Core Logic

# 执行步骤

1.  **输入**：个人兴趣/技能领域列表。
    **步骤**：明确个人品牌构建的三大支柱：增长、真诚、权威。将三者视为一个需要协同发展的整体框架。
    **判断标准**：能够清晰阐述“增长”旨在吸引注意力，“真诚”旨在建立情感连接，“权威”旨在提供价值并促成改变。
    **常见误区**：只关注其中一个支柱（如只追求增长技巧），而忽略其他两个，导致品牌发展不均衡或不可持续。

2.  **执行“增长”支柱：训练高表现力内容创作**
    1.  **输入**：希望提升内容表达能力的领域。
    **步骤**：识别并收集5-10位在该领域内表达方式卓越的创作者作为研究对象。
    **判断标准**：能列出具体名单，并说明其表达方式的独特吸引力。
    2.  **输入**：目标创作者名单。
    **步骤**：在固定周期内（如一周），每天花1小时系统性地研究其社交媒体内容，筛选出“异常值”帖子（如互动量是平均值的两倍以上）。
    **判断标准**：收集到20-30篇高质量、高互动的帖子样本。
    3.  **输入**：收集到的“异常值”帖子样本。
    **步骤**：对每篇帖子进行结构化分析，使用分析提示词（如要求AI分析其构思、结构、用词、心理战术等）或手动总结3-5个成功要点。
    **判断标准**：为每篇样本产出具体的、可操作的写作技巧分析报告。
    4.  **输入**：分析得出的高表现力写作技巧。
    **步骤**：在个人内容创作中，有意识地应用这些已验证的技巧，将普通想法转化为具有“爆款”潜力的表达。
    **判断标准**：产出的内容在吸引力、清晰度和互动率上相较之前有可感知的提升。

3.  **执行“真诚”支柱：注入故事与核心信念**
    1.  **输入**：个人经历与当前专注的领域。
    **步骤**：梳理个人故事线，明确写出：过去的处境、引发改变的转折点、现在的状态。
    **判断标准**：形成一段连贯的、能体现个人独特性的叙事草稿。
    2.  **输入**：个人专注的领域或话题列表。
    **步骤**：针对每个领域，列出自己坚信不疑的3-5个核心原则或信念。
    **判断标准**：信念列表具体、明确，且与个人行为有内在一致性。
    3.  **输入**：个人故事草稿与核心信念列表。
    **步骤**：将故事与信念融入内容创作。有两种方式：
        - **作为主题**：直接创作以个人故事或信念为核心的内容。
        - **作为重构方式**：在讲解通用话题时，从个人故事或独特信念切入，提供新视角。
    **判断标准**：内容具有鲜明的个人印记，受众能感知到内容背后的“人”而不仅仅是“信息”。

4.  **执行“权威”支柱：进行有说服力的教育**
    1.  **输入**：计划教学的主题或技能。
    **步骤**：为该主题寻找一个独特的切入视角。这可以源于个人故事、一个新颖的比喻、或对问题的重新定义。
    **判断标准**：能够用一句话概括这个独特视角，并解释它为何比常规教学角度更有吸引力。
    2.  **输入**：教学主题及其独特视角。
    **步骤**：设计内容时，优先考虑如何吸引“非主动学习者”。使用“痛点-欲望-益处”框架构建内容开头：
        - **痛点**：以“如果你讨厌/受困于…”开头，引发共鸣。
        - **欲望**：描绘解决问题后的理想状态。
        - **益处**：清晰列出跟随你学习将获得的具体好处。
    **判断标准**：内容开头能有效抓住随机浏览者的注意力，并激发其进一步了解的兴趣。
    3.  **输入**：吸引人的内容开头。
    **步骤**：在引发兴趣后，交付扎实的教育内容，展示专业能力，旨在改变受众的行为或认知。
    **判断标准**：内容不仅有趣，而且有深度和实用性，能让受众觉得有收获并愿意信任你的专业建议。

# 输出格式要求
输出一个清晰的行动计划，包含：
1.  **增长计划**：列出目标研究对象、研究时间安排、及下一步准备应用的具体写作技巧。
2.  **真诚性注入点**：写出个人故事摘要，并列出2-3个即将创作的内容主题，说明如何融入故事或核心信念。
3.  **权威构建策略**：确定一个教学主题，写出其独特视角，并设计一个基于“痛点-欲望-益处”框架的内容开头草稿。
