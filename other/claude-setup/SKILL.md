# Q Claude Setup

A set of setups that change what Claude is for you over time. Most people write better prompts. These configure Claude so it knows you, audits how you use it, and improves its own setup. Setups run in the background and change every future conversation. Prompts run once.

## When to use this skill
- The user is setting up a new Claude project and wants it tuned to them
- The user keeps re-explaining themselves to Claude every session
- The user wants Claude to get sharper over time, not stay static
- The user wants Claude to maintain and improve its own context

## Techniques

### Version-10 Self
A Claude project configured to be the user 10 years from now. A future-self thinking partner that gives recognition, not advice. Use when the user is stuck on a decision and needs to hear what current them is avoiding.

### Usage Audit
A prompt that makes Claude critique how the user has been using Claude. Surfaces the patterns in their own behavior they cannot see. Use weekly, ideally as part of a review ritual.

### Self-Modifying Instructions
A line in project instructions that makes Claude propose edits to its own setup at the end of each session, based on what it observed. Use to keep a setup improving itself instead of going stale.
