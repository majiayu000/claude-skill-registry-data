# brain-dump-journaling

## When to Use

当感到思绪纷乱、焦虑、有大量待办事项盘旋在脑中，或需要为深度工作/睡眠清理心理空间时。description

## Core Logic

# 执行步骤

1.  **准备与设定意图**
    *   **输入**：书写工具、计时器（可选）。
    *   **操作**：找到一个安静的空间，设定意图：“接下来X分钟（建议10-15分钟），我将不加评判地写下脑中所有内容。”
    *   **判断标准**：准备好工具，明确时间边界和“不加评判”的原则。

2.  **进行无过滤书写（倾倒）**
    *   **输入**：脑海中浮现的任何想法、感受、任务、担忧、灵感、记忆碎片。
    *   **操作**：连续、快速地写下你能意识到的每一个念头。不修改、不评判、不组织语法。格式可以是清单、短句或杂乱的关键词。核心是“清空”大脑。
    *   **判断标准**：笔/键盘不停顿地持续书写了预定时间，或感到“暂时想不出更多”。
    *   **IF** 时间到或感觉写空 → 进入步骤3。
    *   **ELSE** 继续书写直到满足上述条件。

3.  **回顾与初步分类**
    *   **输入**：步骤2产生的原始“大脑倾倒”清单。
    *   **操作**：快速浏览写下的所有项目。使用简单的符号或颜色，对其进行初步分类，例如：
        *   **待办任务** (T)：需要行动的事项。
        *   **未来计划** (P)：稍后考虑的想法或项目。
        *   **担忧/问题** (W)：引发焦虑的事情。
        *   **灵感/想法** (I)：创意或洞察。
        *   **决定** (D)：需要做出的选择。
        *   **其他** (O)：杂项。
    *   **判断标准**：清单中大部分项目都被标记了类别，混乱度降低。

4.  **组织与下一步行动提取**
    *   **输入**：经过步骤3分类的清单。
    *   **操作**：
        *   针对 **待办任务 (T)**：为每个任务确定一个**非常具体**的下一步行动（例如：不是“写报告”，而是“打开文档，列出报告三个核心部分”）。如果可以，立即安排到日历或待办清单中。
        *   针对 **担忧/问题 (W)**：问自己：“关于这件事，我现在能做的**一件**最小、最可控的事是什么？”并转化为一个行动或决定记录下来。
        *   针对 **灵感/想法 (I)**：将其转移到专门的“灵感库”或项目笔记中，以备后用。
        *   针对 **决定 (D)**：设定一个做决定的最后期限，或列出利弊。
    *   **判断标准**：关键的任务和担忧被转化为明确的下一步行动或处理计划；灵感被妥善归档。

5.  **收尾与状态确认**
    *   **输入**：整理后的清单和行动项。
    *   **操作**：合上笔记本或关闭文档。做几次深呼吸，感受思绪被清空和组织后的心理状态。确认最重要的1-3个行动项已记住或置于显眼处。
    *   **判断标准**：感到心理负担减轻，思路清晰，对接下来要做什么有明确感。
    *   **输出**：一份外部化、组织化的思绪清单和明确的下一步行动项。

# 输出格式要求
引导用户完成从“倾倒”到“组织”的全过程。输出应强调过程重于文笔，并展示分类和提取下一步行动的示例。最终反馈应确认用户已完成清空，并已获得可操作的产出。
