# life-game-optimization

## When to Use

当感到生活混乱、压力大、注意力分散，希望系统性地优化心智资源分配以提升创造力和生活体验时description

## Core Logic

# 执行步骤

1.  **心智资源审计**
    *   **输入**：对当前自身状态的感知。
    *   **操作**：列出所有正在消耗你主要专注力（RAM）的“高需求程序”。这些通常是持续占据你思维的后台任务，如对过去的悔恨、对未来的焦虑、未完成的任务、逃避现实的欲望等。
    *   **判断标准**：清单是否覆盖了导致你当前压力和混乱感的主要思维负担。
    *   **输出**：一份“高耗能程序”清单。

2.  **信息摄入校准**
    *   **输入**：上一步的清单，以及对当前情绪状态（焦虑或无聊）的评估。
    *   **操作**：
        *   **IF** 感到焦虑、信息过载 → 执行“信息节食”，主动减少非必要的信息输入（如社交媒体、新闻），并处理清单中的“未完成循环”。
        *   **ELSE IF** 感到无聊、动力不足 → 主动寻求新的、有挑战性的信息或经验（学习新技能、接触新领域）。
        *   **目标**：将状态调整至“心流边缘”，即挑战与能力略微失衡的状态。
    *   **判断标准**：焦虑感减轻或无聊感被适度的兴奋与挑战感取代。
    *   **输出**：一个调整后的、平衡的信息输入计划。

3.  **启动“创造-消化”循环**
    *   **输入**：来自步骤2的新信息或经验。
    *   **操作**：按顺序执行以下子循环：
        *   **3.1 好奇心驱动探索**：主动接触新领域，提出问题，保持开放心态。
        *   **3.2 热情驱动创造**：利用获得的信息或灵感，动手创造一个有形的产出（如写一篇文章、做一个项目、解决一个实际问题）。这是“消化”过程。
        *   **3.3 实践达成精通**：重复练习在创造中学到的技能，将其内化，扩展自己的能力边界。
        *   **3.4 联系实现超越**：将你的创造成果或经验心得分享、传授给他人，完成价值的传递，并为下一轮循环腾出空间。
    *   **判断标准**：是否完成了从获取信息到产出价值，再到能力内化和价值传递的完整闭环。
    *   **输出**：一个创造性的成果、一项得到提升的技能，以及一次有意义的分享。

4.  **设计个人游戏化框架**
    *   **输入**：你对“美好生活”或当前阶段核心目标的定义。
    *   **操作**：
        *   **4.1 定义终极目标**：明确你当前“生活游戏”的获胜条件（例如：掌握某项技能、完成某个项目、达到某种生活状态）。
        *   **4.2 拆解层级目标**：将终极目标分解为可执行的子目标和里程碑（任务关卡）。
        *   **4.3 设定规则与技能**：明确达成目标需要遵循的规则（如每日投入时间）和需要提升的技能（角色属性）。
    *   **判断标准**：目标体系是否清晰、可执行、有激励性，能提供明确的行动指引。
    *   **输出**：一份个人“游戏”设计文档，包含目标层级、规则和所需技能树。

# 输出格式要求
提供一份包含以下部分的个人优化报告：
1.  **识别的高耗能程序**：[清单]
2.  **当前状态与校准方向**：[焦虑/无聊/平衡] → [下一步行动计划]
3.  **本轮“创造-消化”循环目标**：[要探索什么] -> [计划创造什么]
4.  **我的生活游戏设计**：[终极目标] -> [下一个子目标与关卡]
