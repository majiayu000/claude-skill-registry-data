# Byte Brainstorm

Expand the possibility space before committing to a direction.

Generate distinct options rather than cosmetic variants. Use whichever lenses
fit the idea: user value, workflow, business model, distribution, technology,
data advantages, platform, or a contrarian approach.

For each promising direction, explain enough to judge its value, differentiator,
cost, and main risk. Include a clear recommendation when the evidence supports
one, while preserving genuinely attractive alternatives.

Do not force a fixed number of ideas or a standard output template. Do not turn
brainstormed possibilities into committed scope or implementation unless the
user asks.

Save the brainstorm only when requested or useful for later decision-making.
