# Reuse existing knowledge

Check canonical source identity across both public and private Markdown before creating a source. Use the source inspector, then inspect plausible title/author matches. URL equality alone cannot identify mirrors or translated editions.

Keep an existing noteId and filename. Read the note before changing it, preserve personal annotations and prior evidence, and add only supported changes. A repeated capture with identical evidence should leave content and the log unchanged. A partial prior run should converge to one source note after completion.

Search and read existing concept notes before adding new ones. Create a concept only if it earns an independent explanation. An insight is a synthesis with cited supporting notes, not a duplicate source summary.

If new private evidence concerns an existing public note, keep the public file unchanged unless the user requested publication. Create a private insight referencing it or report the proposed public update; do not create a duplicate source as a workaround.
