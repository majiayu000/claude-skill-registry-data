# Content Creator

Professional content creation for WordPress sites with SEO optimization and brand voice consistency.

## When to Use This Skill

- Writing blog posts and articles
- Creating and updating WordPress pages
- Developing SEO-optimized content
- Maintaining consistent brand voice
- Planning content strategy
- Creating product-related content

## Core Capabilities

### Content Creation
- Blog posts with proper structure (headlines, subheadings, paragraphs)
- SEO-optimized articles with keyword integration
- Landing pages with conversion focus
- News articles and press releases
- How-to guides and tutorials

### SEO Integration
- Meta title and description optimization
- Keyword density analysis (1-3% target)
- Proper heading hierarchy (H1 → H6)
- Internal and external linking strategy
- Featured image optimization

### Brand Voice
- Consistent tone across all content
- Audience-appropriate language
- Professional formatting standards
- Call-to-action placement

## Workflow

### Creating a Blog Post

1. **Research Phase**
   - Identify primary keyword (search volume 500-5000/month)
   - Find 3-5 secondary keywords
   - Review existing content using `wp_read_posts`

2. **Structure Phase**
   - Create outline with H2/H3 headings
   - Plan for 1,500-2,500 words for comprehensive coverage
   - Include keyword in title, first paragraph, and 2-3 H2s

3. **Creation Phase**
   - Use `wp_create_post` with proper formatting
   - Add categories and tags via `wp_taxonomy`
   - Upload featured image via `wp_media`

4. **Optimization Phase**
   - Analyze SEO score with `seo_analyze`
   - Update meta tags with `seo_meta`
   - Adjust content based on recommendations

### Content Quality Checklist

- [ ] SEO score above 75/100
- [ ] Readability appropriate for audience
- [ ] Consistent brand voice throughout
- [ ] Clear value proposition
- [ ] Actionable takeaways
- [ ] Proper visual formatting
- [ ] Categories and tags assigned
- [ ] Featured image set

## Content Types

### Blog Posts
- Educational content
- Industry news analysis
- How-to tutorials
- List articles (Top 10, Best of)
- Case studies

### Pages
- About us
- Services/Products
- Contact information
- Landing pages
- Privacy policy

### Product Content
- Product descriptions
- Feature highlights
- Comparison articles
- Buyer guides

## Best Practices

1. **Always start with audience need/pain point**
2. **Research keywords before writing**
3. **Use proper heading hierarchy**
4. **Include internal links to related content**
5. **Optimize meta description (150-160 characters)**
6. **Add alt text to all images**
7. **End with clear call-to-action**

## Performance Metrics

Track these KPIs:
- Organic traffic growth
- Average time on page
- Bounce rate
- Social shares
- Keyword rankings
- Conversion rate
