# reframe-money-as-skill

## When to Use

当意识到自身金钱观念存在限制，并希望采取建设性态度改善财务状况时description

## Core Logic

# 执行步骤

1.  **输入**：来自“money-mindset-stage-assessment”模型的输出，或自我识别的限制性金钱信念（例如：“我总觉得自己不擅长理财”）。
2.  **信念解构**：将输入的限制性信念重新表述为一个“可学习的技能领域”的陈述。
    *   **操作**：将“我不擅长X”或“X很难”的信念，转化为“X是一项我需要学习和掌握的技能”。
    *   **示例转换**：“赚钱很难” → “创造收入是一项我需要学习和掌握的技能”。“我管不好钱” → “财务管理和预算制定是一项我需要学习和掌握的技能”。
    *   **判断标准**：转化后的陈述焦点从固定心态（我做不到）转向成长心态（我可以学习）。
3.  **技能领域定义**：基于转化后的陈述，明确需要发展的具体“技能领域”名称。
    *   **示例**：“创造收入技能”、“投资理财技能”、“税务优化技能”、“慈善规划技能”。
    *   **判断标准**：领域名称具体，指向一个公认的、有知识体系支撑的能力范畴。
4.  **制定学习启动方案**：为定义的技能领域，规划一个最小可行学习行动（MVP Learning Action）。
    *   **操作**：规划一个在未来一周内可以完成的、低成本的初始学习动作。
    *   **示例**：阅读一本该领域的入门书籍第一章；收听一个相关播客节目；预约一次免费的财务咨询；完成一个在线入门课程的第一模块。
    *   **判断标准**：行动极其具体（时间、内容、方式明确），门槛低，无重大执行障碍。
5.  **设定学习型目标**：将原有的、基于结果的财务目标（如“存款增加10万”），转化为一个相关的、基于过程的学习目标。
    *   **操作**：将“达到Y结果”的目标，与“掌握Z技能”联系起来。
    *   **示例**：原目标“明年存款增加10万” → 学习型目标“在本季度内，系统学习并实践三种增加被动收入的方法，并评估其效果”。
    *   **判断标准**：新目标的核心衡量标准是“学到了什么”和“尝试了什么”，而非直接的财务数字。

# 输出格式要求

以行动计划清单形式输出：
*   **旧信念**：[输入的限制性信念]
*   **新视角**：我将 **[对应的技能领域]** 视为一项值得掌握和发展的技能。
*   **启动行动**：为此，我将在 **[具体时间]** 前，完成 **[MVP学习行动]**。
*   **学习目标**：本阶段，我的学习目标是 **[学习型目标]**，这将帮助我逐步接近更广泛的财务愿景。
