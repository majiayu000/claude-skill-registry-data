# flow-state-creation

## When to Use

当需要在日常任务或长期目标中创造高度专注、高效且愉悦的“心流”体验时description

## Core Logic

# 执行步骤

1.  **设定清晰且具挑战性的目标**
    *   **输入**：一个模糊的任务或愿望。
    *   **操作**：将任务分解为具体、可衡量、与当前技能水平相匹配但略有挑战性的子目标。确保目标是“自足的”（autotelic），即其内在价值在于完成过程本身，而非仅为了外部奖励。
    *   **判断标准**：目标是否明确到可以立即开始行动？是否感觉既有挑战性又非遥不可及？
    *   **IF** 目标过于简单或模糊 → 返回步骤1，增加难度或具体化。
    *   **ELSE** → 进入步骤2。

2.  **建立即时反馈循环**
    *   **输入**：步骤1设定的清晰子目标。
    *   **操作**：为每个子目标的进展设计即时、明确的反馈机制。这可以是完成一个复选框、获得一个数据点、看到可视化的进度条，或感受到技能的直接提升。
    *   **判断标准**：能否在行动后立即（或短时间内）知道自己做得好不好、是否在向目标靠近？
    *   **IF** 反馈延迟或模糊 → 返回步骤2，重新设计反馈形式。
    *   **ELSE** → 进入步骤3。

3.  **排除干扰，匹配技能与挑战**
    *   **输入**：待执行的任务环境和自身状态。
    *   **操作**：
        *   **消除外部干扰**：关闭无关通知，创造物理上专注的环境。
        *   **评估挑战-技能平衡**：主观评估任务挑战性与自身技能水平。
            *   **IF** 挑战远高于技能 → 感到焦虑，返回步骤1，将目标拆解得更简单或先提升技能。
            *   **IF** 技能远高于挑战 → 感到无聊，返回步骤1，增加任务难度或寻找新挑战。
            *   **IF** 挑战与技能大致平衡 → 进入“心流通道”，继续执行任务。
    *   **判断标准**：是否能够连续工作而不被轻易打断？对任务的感觉是焦虑、无聊还是适度的兴奋？

4.  **全神贯注于当前行动**
    *   **输入**：进入平衡状态的任务执行过程。
    *   **操作**：将全部注意力集中在当前正在做的具体动作上，屏蔽对过去（后悔）或未来（担忧）的思考。让行动本身成为注意力的唯一焦点。
    *   **判断标准**：是否忘记了时间的流逝？是否感觉自我意识减弱，与任务融为一体？
    *   **IF** 注意力开始漂移到任务之外 → 温和地将注意力拉回当前动作，或检查环境干扰（返回步骤3部分操作）。
    *   **ELSE** → 维持心流状态直至任务阶段完成。

# 输出格式要求
输出应描述当前所处的状态（如：目标清晰度、挑战-技能平衡情况、注意力水平），并给出下一步的具体调整建议（例如：“当前挑战过高，建议将‘完成报告’拆解为‘搜集10条相关数据’”）。
