# search-xianyu

## 目标
在用户需要闲鱼/Goofish 二手商品搜索、监控线索或商品详情时，通过只读工具和浏览器读取整理标题、价格、卖家公开信息、位置、成色和链接。

## 适用请求
- 搜索闲鱼二手商品、关键词、型号、地区或价格区间。
- 读取给定闲鱼商品 URL 的详情、图片线索和卖家公开信息。
- 做只读监控方案说明或人工检查清单，不自动联系卖家。

## 首选通道
- skill-only：默认复用用户当前 Firefox 会话打开闲鱼搜索页或商品页，只读取可见信息。
- 如果本机已有只读 CLI（如 goofish 类 CLI）可作为辅助，但不要新增或依赖 MCP，不触发购买、询价或消息操作。

## 兜底通道
- 使用当前 Firefox 已登录会话只读打开闲鱼页面；如遇验证码或二次确认由用户人工完成，之后仅读取可见内容，不发消息不询价。

## 操作流程
1. 明确关键词、型号、地区、价格范围、成色、发布时间和是否需要只读监控。
2. 优先用当前 Firefox 已登录会话和 WebSearch 只读查询；如已有只读 CLI，可辅助。
3. 如需验证码、扫码或二次确认，必须由用户人工处理。
4. 读取时只记录标题、价格、位置、发布时间、卖家公开信息、描述、图片可见线索和 URL；全程只读搜索/读取，不发起新的登录流程、不下单、不私信、不发帖、不写入平台，也不询价、收藏或关注。
5. 对可疑商品标注风险线索，建议用户人工核验，不替用户交易。

## 只读安全边界
- 只搜索、读取和总结公开或用户授权可见的闲鱼商品信息。
- 不发起新的闲鱼登录流程；如当前 Firefox 已登录则只读复用，不绕过扫码、验证码、风控或 App 限制。
- 不发消息、不询价、不砍价、不下单、不付款、不收藏、不关注、不发布商品、不评价。
- 不保存 Cookie、Token、手机号、地址或支付信息。

## 验证方式
- 后续可运行：`dir C:\Users\Zhang\.config\opencode\skills\search-xianyu\SKILL.md`
- 人工检查：确认兜底明确“需扫码登录、只读、不发消息不询价”。

## 已知限制
- 闲鱼 Web 访问和搜索强依赖登录态、风控和 App 能力。
- 商品价格和状态变化快，卖家可随时下架或修改。
- 自动化监控可能触发平台风控，只能设计只读、低频、用户授权流程。
