# 🌾 Crop Yield Prediction | 经济作物产量预测

> 结合生长阶段、营养状况、环境数据与历史产量数据，预测番茄/玉米/土豆等经济作物的预期产量。
>
> **智能产量预估中枢** · 图片/视频智能分析 · 产量范围与置信度 · 历史报告云端查询

---

## 🎯 任务目标 | Goals

### 1. 🧩 技能用途

通过番茄、玉米、土豆、花生等经济作物植株/田块的图像或视频，结合环境数据与历史产量参考，客观输出预期产量范围与置信度，服务于产量预估、采收计划、市场供需匹配以及农业保险定损等业务场景。

### 2. 🛠️ 能力范围

| 序号 | 具体能力 |
|---:|---|
| 1 | 作物种类识别（番茄 / 玉米 / 土豆 / 花生 等） |
| 2 | 生长阶段识别（苗期 / 花期 / 坐果期 / 成熟期 等） |
| 3 | 营养状况视觉评估（叶色、株型、缺素征兆等） |
| 4 | 开花坐果率与果实发育情况估算 |
| 5 | 单株/单位面积果实数量与大小估算 |
| 6 | 结合环境数据与历史产量的产量范围预测 |
| 7 | 预测置信度与主要影响因子输出 |
| 8 | 产量单位规范化（如 kg/株、kg/亩、吨/公顷） |

### 3. ⚡ 触发条件

| 触发类型 | 触发规则 |
|---|---|
| ✅ 默认触发 | 当用户提供经济作物植株/田块的图像/视频 URL 或文件需要产量预测时，默认触发本技能进行产量预测 |
| 🔎 明确分析意图 | 当用户明确需要预测产量时，提及产量预测、预期产量、亩产、单产、坐果率、番茄产量、玉米产量、土豆产量、花生产量、农业保险定损等关键词，并且上传了图片或视频文件 |
| 📚 历史报告查询 | 当用户提及以下关键词时，**自动触发历史报告查询功能**：查看历史产量预测报告、历史产量报告、产量预测报告清单、查询产量记录、显示所有产量报告 |

|---|---|

## 📷 采集要求 | Capture Requirements

| 序号 | 说明 |
|---:|---|
| 1 | 拍摄距离建议覆盖单株特写（50cm 内）与田块全景（1m 以上）两个尺度，以便同时评估个体与整体产量指标 |
| 2 | 优先在自然散射光下拍摄，避免强逆光、镜头眩光或大面积阴影，保证叶色与果实特征真实 |
| 3 | 拍摄时尽量正对植株或田块中心，避免过度倾斜与遮挡，保留可估算数量与大小的参考物（如叶片、行距） |
| 4 | 支持单张图或短视频（≤10MB），视频建议 5~15 秒平稳环绕拍摄，覆盖不同角度 |
| 5 | 支持格式：jpg/png/jpeg 图片，及 mp4/avi/mov 视频；单文件不超过 10MB |
| 6 | 建议附带作物类型、种植面积、生长阶段、近期环境数据与历史产量等信息，以提升预测精度 |
