# Customize

Use this skill when the user wants to change defaults in a reusable asset instead of only one output.

## Workflow
- Identify the target reusable asset.
- Collect the smallest stable set of preferences.
- Patch the reusable instructions and validate them.

## Deliverables
- An updated skill or template.
- A summary of changed defaults.

## Guardrails
- Do not rewrite unrelated skills.
- Do not store temporary preferences as permanent defaults without approval.
