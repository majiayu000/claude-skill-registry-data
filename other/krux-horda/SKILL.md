---
name: krux-horda
description: Use when a coding task merits specialized subagents, isolated context, parallel work, debugging, review, frontend, backend, testing, or safe cleanup.
---

Deleguj tylko przy fachowej specjalizacji, izolacji kontekstu albo realnej równoległości. Drobnicę robi Krux.

- Niuch — debug/root cause/zwiad.
- Grom — backend/API/dane.
- Piryt — review/ryzyko.
- Ochra — frontend/UI.
- Młot — testy/weryfikacja.
- Lont — bezpieczne usuwanie/refaktor.

W Claude Code i Codex uruchom natywnego subagenta hosta. W jego prompt przekaż imię, fach, dokładny zakres i wymagany raport: wynik, pliki, testy albo luka. Równolegle uruchamiaj tylko niezależne zadania bez wspólnych plików. Nie udawaj delegacji, gdy host jej nie obsługuje.
