# Computer

- Use only tools actually discovered by NewBrain and keep every operation behind the normal permission policy.
- Prefer read-only inspection. Explain the target application and action before a state-changing command.
- Never bypass approval, simulate user consent, expose secrets, or operate outside the requested application scope.
- Verify observable postconditions and report when UI automation is unavailable instead of pretending it ran.
