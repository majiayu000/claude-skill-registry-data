# 直播电商策划

直播 = 货品力 × 内容承接 × 流量节奏。平台差异：抖音（兴趣流量、千川付费撬自然）、快手（信任电商、老铁复购）、视频号（社交推荐+私域联动、微信小店）、淘宝直播（店铺粉丝+搜索）。

## 输入

平台与账号阶段（起号/成长/成熟）、品类与货盘（SKU/价格/库存/毛利）、主播配置、时长与频次、预算（付费流量）、目标（GMV/涨粉/清库存/新品）。

## 排品组货

- 结构（经验比例，按品类调）：引流款 10–20%（低毛利高认知，拉停留与互动）、利润款 50–60%（主推）、形象款 10%（高价锚点）、福利款穿插（整点抽奖/限量秒杀，须真实库存）。
- 排品节奏：开场引流款聚人→每 20–30 分钟一个循环（引流→利润→福利）→黄金时段主推利润款；库存深度决定能不能憋单。
- 价盘：直播价与店铺/达人分销价的关系（破价反噬搜索与其他渠道）；赠品替代直接降价保价盘。

## 脚本与话术结构

- 单品讲解 5–8 分钟循环：钩子（痛点/价格悬念）→卖点演示（眼见为实）→信任（资质/检测/销量，真实）→价格锚点（对比须合规）→逼单（真实库存/限时）→答疑互动。
- 留人话术：整点福利预告、"刚进来的宝宝"周期性重述利益点；互动指令（扣屏/点灯牌/加粉丝团）拉互动指标。
- 合规红线：不得虚构原价/虚假限量、演戏砍价（"我给家人们谋福利"式虚假剧情）、普通食品宣称功效、"最/第一"极限词；憋单可以，骗单不行。

## 流量节奏

- 起号期：短视频引流+小额千川（或视频号加热）测承接，先做 GPM/停留/互动再放量；
- 付费与自然：付费占比逐步降（目标 <50%），靠承接能力撬自然推荐；
- 视频号：开播前私域预约（企微/社群/公众号）→开播转发裂变→直播中社交推荐放大；
- 投放配合：开播前 1–2h 预热素材、开播中按在线人数与 GPM 加减预算（见 ecommerce-ads-cn）。

## 复盘指标

场观、峰值在线、平均停留（抖音 1 分钟+为及格线参考）、互动率、转粉率、GPM、点击-成交转化率、退款率、付费占比；按"流量-承接-转化-货品"四层归因。

## 输出格式

```
## 直播方案（平台 / 阶段 / 目标）
### 货盘表：SKU/角色/价格/库存/毛利/讲解顺序
### 直播脚本：时间轴 × 环节 × 话术要点 × 运营动作（上下架/改价/发券/投流）
### 流量计划：预热/开播/高峰/收尾的投放与私域动作
### 场景与设备最低配置
### 复盘模板与目标值
### 合规自查
```

## 约束

- 话术给要点与示例，不写满屏逐字稿（主播需要即兴空间）；违规话术直接拒绝并给合规替代。
- 起号期不承诺"7 天起号"；给概率性预期与止损线。
