# apag-content-framework

## When to Use

当需要构建有说服力和吸引力的内容（尤其是用于转化或建立影响力）时description

## Core Logic

# 执行步骤

1.  **输入**：需要创作的内容主题及目标读者。
    **步骤**：设计内容的开头，以**吸引注意力 (Attention)**。评估并选择最合适的开篇方式。
        - **IF** 目标是引发好奇：使用一个令人惊讶的事实、一个反直觉的问题或一个强烈的承诺。
        - **ELSE IF** 目标是建立共鸣：描述一个目标读者普遍面临的痛点、场景或挑战。
        - **ELSE**（默认）：使用一个清晰、有力的声明直接点明核心价值。
    **判断标准**：开篇句能在3秒内抓住目标读者的兴趣，使其愿意继续阅读。
    **常见误区**：开篇冗长、与主题关联弱、或使用陈词滥调。

2.  **输入**：已被吸引注意力的读者。
    **步骤**：在吸引注意力后，迅速提供一个独特的**视角 (Perspective)**。这需要清晰界定问题、挑战现状或提供一个新的理解框架。
        - **IF** 内容旨在解决问题：明确且重新定义读者所感知的问题，指出常见解决方案的局限。
        - **ELSE IF** 内容旨在分享观点：提出一个鲜明、可能略有争议但有理有据的立场。
    **判断标准**：读者能清晰感知到你所提供的视角与普通看法有何不同，并觉得这个视角有价值。
    **常见误区**：视角模糊、平庸，或与开篇的注意力吸引点脱节。

3.  **输入**：已接受你独特视角的读者。
    **步骤**：展示你的**优势 (Advantage)**。阐明你的解决方案、方法或观点为何有效，以及它能给读者带来的具体好处。提供逻辑、证据、案例或你的独特资历作为支撑。
        - **IF** 优势是解决方案：详细说明解决方案的步骤、原理及带来的积极结果。
        - **ELSE IF** 优势是独特信息或洞察：提供扎实的论据、数据或推演过程。
    **判断标准**：读者相信你所提供的优势是真实、可信且能解决他们问题或满足其需求的。
    **常见误区**：优势描述空洞、缺乏证据支持、或与前面提出的视角无关。

4.  **输入**：已理解并相信你所提供优势的读者。
    **步骤**：通过**游戏化 (Gamification)** 元素促使读者采取行动或深度参与。将预期的下一步行动（如思考、尝试、购买、分享）设计得更有吸引力、更容易或更有趣味性。
        - **IF** 目标是引导尝试：提供一个极简的入门步骤、一个挑战或一个模板。
        - **ELSE IF** 目标是促进互动：提出一个可参与的问题、发起一个投票或创建一个标签。
        - **ELSE IF** 目标是完成转化：提供一个限时优惠、一个清晰的行动按钮或一个成功案例展示。
    **判断标准**：读者清楚地知道下一步该做什么，并且觉得这样做是值得的、低风险的或有趣的。
    **常见误区**：行动号召模糊、步骤繁琐、或未能给读者一个立即行动的理由。

# 输出格式要求

输出应是一份按照A-P-A-G结构组织的内容大纲或完整文稿，并标注出每个部分分别对应框架中的哪个要素（Attention, Perspective, Advantage, Gamification）。
