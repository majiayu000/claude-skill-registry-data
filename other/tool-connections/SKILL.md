## Wallet Connection Protocol
1. User creates a brand-new throwaway wallet
2. User funds it with ≤ $200 USDC + SOL for fees
3. Bot hands the screen to the human for the connection flow
4. Bot confirms the public address and records it in desk.md
5. Never accept, store, or request a seed phrase or private key
