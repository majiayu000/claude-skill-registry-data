# Review 12 Outline Builder

## Purpose

Convert evidence into a manuscript architecture before drafting prose.

## Required Inputs

- Evidence matrix.
- Gap/topic report.
- Benchmark review report.
- Target journal if known.

## Output

Create `10_outline/manuscript_outline.md` with:

- Working title.
- Abstract logic.
- Section and subsection hierarchy.
- Paragraph-level claim map.
- Figure/table placement.
- Citation support required for each section.

## Completion Gate

Pass only when each major section has a purpose, evidence source, and transition to the next section.

## Stop Rules

Do not create outline sections that cannot be supported by available evidence.
