# 法学论文写作

一个面向法学论文与研究报告的**写作阶段** skill：从构思到成稿，覆盖调研、引注、学术化表述与去 AI 痕迹。

## 一、写作前：充分构思

动笔前必须先完成以下构思，不得直接开始写：

1. **核心问题**：这篇文字要解决的法学真问题是什么（制度漏洞、裁判分歧、规范冲突、学理争议）。
2. **法律载体**：问题落在哪部法律、哪条规范、哪个司法解释、哪类案例上。
3. **中心论题**：全文要证明的一个可争论命题是什么。
4. **论证框架**：分几部分、每部分承担什么论证功能、彼此如何衔接。

构思不清晰时，先停下来，不要用大段文字掩盖未构思。

## 二、调研：规范与案例要及时查证

写作过程中，凡涉及下列内容，**必须及时调研核实，不得凭记忆书写**：

- 法律条文：现行有效版本、施行时间、是否被修正案修改。
- 司法解释、规范性文件：文号、发布机关、现行效力。
- 案例：完整案号、法院、裁判日期、裁判要旨。
- 学术观点：作者、文献、期刊、年份、页码。

调研来源优先级：
1. **本地知识库**（`knowledge_search` / `knowledge_auto_retrieve` / `knowledge_read_file`）。
2. **IMA 知识库**（`research_ima` 自动路由选库，或 `search_ima_catalog` 查看候选库）——用于补充学术文献、内部材料、法规库与案例库。先通过知识库缓存了解 IMA 有哪些库，再主动调用，不要因为不确定有哪些库而跳过。
3. 北大法宝 / 元典等法律数据库（法规与案例的主检索来源）。
4. 国家法律法规数据库（仅当用户指定、商业库无结果或效力冲突时）。

写法律规范与案例相关段落前，先调用检索工具取得依据；拿不到原文时做谨慎表达，标注 `[待补引文位]`。

## 三、引注规范

- **引用采用当页页下脚注（footnote）**，不是文末尾注。生成 Word 时把每条引用作为真正的页下脚注（markdown 用 `[^1]` 脚注语法，`[^1]: 内容` 定义），文末可附"参考文献"清单但不得替代正文脚注。
- 引注格式依据《法学引注手册》（2019）。**详细规则见 `references/citation-format.md`**，写作前必读，涵盖：书籍、期刊文章、网络/公众号、学位论文、法律文件、司法案例、外文文献的完整格式，以及脚注编号位置、引领词（参见/见/转引自/载）、条款序数、案号写法、标点规范。
- 核心速记：
  - 书籍：`作者：《书名》，出版社年份版，页码。`
  - 期刊：`作者：《篇名》，载《期刊名》年份第X期，第X页。`
  - 法条：`《法律名》第X条第X款第X项。`（条款序数用阿拉伯数字）
  - 规范性文件：`《文件名》，文号〔年份〕X号，发布日期发布。`
  - 案例：`原告诉被告案，法院全称（年份）文号判决书。`
  - 每条引用完整、真实、可核验，不得编造页码、期刊、案号。

## 四、表述：学术化 + 去 AI 痕迹

### 学术化
- 用词准确、克制，避免口语化与网络用语。
- 论证有层次：从规范依据到学理分析再到实践适用。
- 观点有出处，判断有依据，不写无对象的抽象议论。

### 去 AI 痕迹
- 少用"首先/其次/再次/最后"等机械连接词。
- 段落结构避免高度雷同（不要每段都"主题句+冒号+内容"），句式允许自然变化。
- 避免宏大叙事、正确的废话、模板化制度建议。
- 每段必须有信息增量，不重复前文。
- 杜绝编造法条、案例、文献、页码。

## 五、写作顺序与自检

### 顺序
1. 点出具体问题 → 2. 说明规范或实践困境 → 3. 提出可争论命题 → 4. 展开规范/案例/学理分析 → 5. 落到有操作性的结论或建议。

### 自检
成稿后逐项检查：
- [ ] 核心论点是否都有引用支撑，引用数量与论题规模匹配
- [ ] 引用是否为当页页下脚注，格式是否统一、真实可核
- [ ] 法条、司法解释是否现行有效版本
- [ ] 案例案号、裁判信息是否准确
- [ ] 是否仍有 AI 味句式、段落结构雷同
- [ ] 是否有未经核验却写成确定结论的表述
