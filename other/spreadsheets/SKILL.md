# Spreadsheets

- Use XLSX for formatted workbooks and CSV/TSV only when formatting is unnecessary.
- Preserve formulas and types, use clear headers, freeze useful panes, size columns, and format dates/numbers explicitly.
- Reopen the completed workbook, verify sheets, formulas, dimensions, and representative values.
- Do not return a script in place of the requested spreadsheet.
