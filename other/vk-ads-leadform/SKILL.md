# VK Ads: четыре шага лид-формы

Используйте [контракт четырёх шагов](references/four-stages.md) и [медиа](references/media.md). Для API-редактирования обязательно прочитайте [API и расхождения](references/api-and-conflicts.md).

1. Установите точную форму, кабинет и связанные кампании. Снимите приватное исходное состояние; запишите существующие значения всех четырёх шагов до переключения вариантов.
2. Заполните [спецификацию](references/specification.md): внутренняя метка формы, сегмент, подтверждённый оффер, тип первого экрана, поля, вопросы, результат, уведомления и правовые реквизиты.
3. Сверьте числовые лимиты с текущим редактором. Не считайте `maxlength=-1` доказательством отсутствия ограничения: UI может применять собственный счётчик и API-валидацию.
4. Для черновика JSON выполните `python scripts/validate_form.py SPEC.json`. Это проверяет нормализованную спецификацию, **не** готовый API payload; ответственный должен отдельно сопоставить API-объекты.
5. Пройдите мобильный/настольный предпросмотр в светлой/тёмной теме. Проверьте кадрирование, читаемость, контакты, награду и ссылку. Не отправляйте реальный лид для проверки вёрстки.
6. Если запись не запрошена, выйдите без сохранения. `Escape` может открыть диалог сохранения всей формы, а не только закрыть меню. Переключение типа первого экрана может сбросить подчинённые значения; вернуться на старую вкладку недостаточно для восстановления.
7. Если сохранение разрешено, сначала проверьте зависимости формы и полный diff, затем сохраните, перечитайте все поля и отделите статус формы от статуса её рекламных кампаний.

[Сценарии приёмки](references/acceptance.md) включают граничные значения, изменение вложенных секций и честную выдачу награды.

## Источники и границы

Проверено 2026-09-09. Числа в справке и интерфейсе могут меняться. Перед записью в кабинет заново откройте нужную официальную страницу и сравните с текущим полем. Метки: **DOC** — официальная документация; **UI** — наблюдение редактора на дату проверки; **RECOMMENDATION** — авторская методика; **UNKNOWN** — не подтверждено. Наблюдение UI не доказывает прохождение серверной валидации или модерации.

Работайте в рамках текущего запроса. Аудит и подготовка текста не разрешают сохранение формы, отправку тестового лида, настройку получателей, запуск кампании или изменение бюджета. Если такая операция уже явно разрешена, не спрашивайте повторно. Не отправляйте заявки ради проверки без разрешённого теста. Форма может использоваться несколькими кампаниями: перед изменением проверяйте связи. Не публикуйте данные кабинета, лиды, скриншоты аккаунта, реальные контакты и секреты в общий пакет.
