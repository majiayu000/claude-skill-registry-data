# ideal-life-mapping

## When to Use

当需要为学习或技能发展设定清晰、有内在动力的目标时description

## Core Logic

# 执行步骤

1.  **输入**：一张白纸或空白文档。
    **操作**：列出你**不想**在生活中拥有的东西。至少写出10个条目，力求具体（例如：“不想每天通勤超过2小时”，而非“不想工作不开心”）。
    **判断标准**：列表条目具体、真实，能引发情感共鸣（厌恶或抗拒感）。
    **常见误区**：条目过于抽象、模糊，或受社会普遍观念影响而非发自内心。

2.  **操作**：列出你**想要**的生活。至少写出10个条目，涵盖健康、关系、事业、财务、个人成长、生活方式等维度，同样要求具体（例如：“想拥有每周远程工作3天的灵活性”，而非“想财务自由”）。
    **判断标准**：列表条目具体、积极，能激发向往和动力。
    **常见误区**：条目是“应该”要的，而非真正“想要”的；或过于宏大，缺乏可关联的具体行动点。

3.  **操作**：将两个列表并置，作为“学习过滤器”和“参考框架”。
    **判断标准**：能清晰看到“趋近”和“避让”的方向，为后续的学习选择提供决策依据。
    **常见误区**：写完即束之高阁，未在后续学习决策中实际使用该地图。

# 输出格式要求

输出一个结构化的“理想生活地图”，包含“避让清单”和“向往清单”两部分，每个部分至少10个具体条目。建议将此地图保存，并在进行任何重要学习投入前回顾。
