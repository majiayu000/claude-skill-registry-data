# failure-stacking

## When to Use

当需要在多个领域积累独特竞争优势，避免单一技能风险时description

## Core Logic

# 执行步骤

1.  **确定核心目标**
    *   **输入**：对当前生活或职业状态的反思。
    *   **操作**：明确一个具体、可衡量的目标（例如：“实现职业转型”、“改善健康状况”、“创作个人作品集”）。
    *   **判断标准**：目标是否清晰、有动力驱动、且不局限于单一技能领域。
    *   **输出**：一个书面化的核心目标陈述。

2.  **启动最小可行行动**
    *   **输入**：上一步确定的核心目标。
    *   **操作**：基于现有知识和资源，立即开始一个与目标相关的最小行动单元（例如：为转型目标更新简历并投递3份；为健康目标开始每周3次15分钟锻炼）。
    *   **判断标准**：行动是否在24-48小时内启动，且无需大量前期学习。
    *   **输出**：一个已启动的具体行动及其初步反馈（障碍或进展）。

3.  **识别障碍并导向学习**
    *   **输入**：上一步行动中遇到的具体障碍或产生的新疑问（例如：简历无回复需优化；锻炼遇到营养问题）。
    *   **操作**：
        *   **IF** 障碍明确（如“简历通过率低”），**THEN** 将该障碍转化为一个具体的学习/技能获取目标（如“学习数据化简历写法”）。
        *   **IF** 产生新疑问或好奇心（如“什么饮食配合锻炼最有效？”），**THEN** 将此好奇心转化为一个探索路径（如“研究基础营养学”）。
    *   **判断标准**：是否将问题/好奇心转化为一个可进入“学习-实践”循环的新技能或知识领域。
    *   **输出**：一个或多个待学习的新技能/知识领域列表。

4.  **实践并追求技能组合**
    *   **输入**：待学习的新技能/知识领域列表。
    *   **操作**：投入时间学习并在实践中应用新技能，旨在达到该领域前25%的水平（即比大多数人懂，但不必是顶尖专家）。记录实践过程中的经验、心得和产生的交叉联想。
    *   **判断标准**：是否能在该领域完成一个实际项目或解决一个具体问题，并能向他人解释核心要点。
    *   **输出**：新增的实践技能、相关成果（作品、解决方案）以及与其他已掌握技能产生联系的洞察。

5.  **整合与模式识别**
    *   **输入**：多次循环步骤2-4后积累的多个技能、项目经验和交叉洞察。
    *   **操作**：定期回顾所有实践路径，寻找技能与知识之间的重叠点和协同效应（例如：写作技能提升了内容创作能力，内容创作又反哺了个人品牌建设）。提炼出自己独特的解决问题的方法论或视角。
    *   **判断标准**：是否能清晰阐述2-3个不同技能如何组合起来解决一个复杂问题，或形成独特的个人价值主张。
    *   **输出**：一个描述个人独特技能组合、经验网络及核心方法论的总结。

# 输出格式要求
向用户呈现一个清晰的“失败/经验堆叠”路径图，包括：
1.  起始目标。
2.  已识别和实践的技能节点。
3.  技能节点之间的连接关系（如何相互促进）。
4.  当前形成的独特优势或方法论摘要。
避免仅罗列技能，必须展示技能间的动态关联和进化路径。
