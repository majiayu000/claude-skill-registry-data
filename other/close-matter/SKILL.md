# Close Matter

## Important
- Manual-only. Check for loose ends before closing.

## Instructions
1. Resolve matter. Confirm closure + reason (settled/unsuccessful/withdrawn).
2. Check loose ends: draft letters, unanalysed docs, open flags, missing costs disclosure. Warn.
3. Set stage (closed_successful/closed_unsuccessful/withdrawn), status "closed".
4. If settled: confirm financials recorded.
5. Suggest final-reporting letter if not sent.
6. Log and commit. Confirm.
