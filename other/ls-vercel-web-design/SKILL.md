# Vercel Web Design Guidelines

Use this skill when working on Vercel web design guidelines tasks.

## Workflow

- Prioritize clear hierarchy, strong defaults, keyboard access, and production-feeling details over decorative spectacle.
- Match the product's domain and workflow density; operational tools need compact clarity, not marketing-page composition.
- Check responsive behavior and text fit in rendered screenshots before considering the UI acceptable.

## Boundaries

- Inspect the target repository before making changes.
- Prefer existing project patterns, declared package managers, and documented validation commands.
- Do not expose secrets, credentials, private user data, or production account identifiers in source, examples, or logs.
- When external APIs or current vendor behavior matter, verify against official docs before implementation.
