# Character Psychology Skill (角色心理学)

`skills/character-psychology.md` 负责为角色建立深层戏剧心理内核与潜意识防御机制，防止角色表现出扁平、脸谱化的 AI 行为。

---

## 1. 核心目标

建立角色的行动源动力，明确：
- **Core Desire (长线超级目标 / 终极渴望)**：角色毕生追求的根源需求（如：获取认可、掌控安全感、寻找被爱、捍卫尊严、渴望自由）。
- **Immediate Desire (当场即时欲望)**：角色在当前具体场次中，此刻立刻想要得到的具体结果（如：让对方留下来、逼问出真相、掩盖罪证、维护面子）。
- **Defense Mechanism (防御机制)**：当内心受到威胁或感到脆弱时，角色习惯性戴上的“社交面具”（如：假装冷漠自大、反讽挑衅、过度讨好客气、机械性沉默）。
- **Contradictions (内在矛盾对立面)**：角色身上同时存在但相互拉扯的特质（例如：渴望亲密，却下意识推开靠近的人）。

---

## 2. 输入与输出规范

### 输入要素
- 角色基础档案：姓名、年龄、社会阶层、职业
- 人格底色：成长创伤、核心信念
- 当前剧本情境：角色处于顺境还是逆境，承受何种外部压力

### 输出结构
符合 [character.schema.json](../../../schemas/character.schema.json) 标准：

```json
{
  "name": "林宛",
  "age": 27,
  "background": "从小在严格挑剔的家庭长大，习惯用优异成绩与坚强外表换取认可",
  "personality": ["自尊极强", "内敛", "敏锐", "控制欲"],
  "core_desire": "获得无条件的尊重与安全感，不愿成为被施舍的一方",
  "immediate_desire": "让男友主动改变决定留下来，但绝不先开口乞求",
  "fear": "一旦低头示弱就会被轻视并失去主动权",
  "secret": "她比对方想象的更害怕一个人面对空荡的房间",
  "values": ["体面高于情绪", "绝不在外人面前崩溃"],
  "emotional_wound": "曾被前任当面指责为'情绪累赘'",
  "defense_mechanism": "通过极度克制、挑剔细节和假装公事公办来掩盖内心动荡",
  "social_mask": "冷静干练、随时能独自搞定一切的独立女性",
  "contradictions": ["内心强烈依恋对方，外部言语却不断向外推搡"]
}
```

## 3. 心理驱动表演转换法则

| 抽象心理状态 | 错误的 AI 提示词指令 | 正确的心理行为转化 (Psychological Action) |
| :--- | :--- | :--- |
| **内心极度脆弱但强撑自尊** | “女孩很悲伤，眼含泪水，很痛苦。” | “女孩故意避开与对方的直接对视，把注意力集中在整理眼前的账单上。手指将纸角反复捏平三次，下颌肌肉收紧，说话前先做一次无声的缓慢呼吸。” |
| **深怀内疚不敢面对** | “男人满脸愧疚地看着女人。” | “男人在女人看向他的一瞬间将目光低垂落向地板，两手插进大衣口袋，身体重心向后微缩，回答问题时语速放慢，避开直视对方眼睛。” |
| **掩饰恐惧与紧张** | “他非常紧张害怕，浑身发抖。” | “他反复检查手表确认时间，喉结轻微滑动一次。当听到背后脚步声时，他握着公文包提手的手指关节发白，但身体强行挺直没有猛烈回头。” |

## 4. 落地检查清单 (Checklist)
- [ ] 该角色的行动是由**欲望驱动**还是仅仅在**反应外界**？
- [ ] 该角色是否有明显的**内在阻碍**（如自尊、秘密、创伤）？
- [ ] 角色的表层行为是否与其内心真实感受存在**戏剧反差**？
