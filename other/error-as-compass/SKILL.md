# error-as-compass

## When to Use

当感到迷茫、焦虑，不清楚人生目标或方向时，用于通过主动试错来探索和澄清个人真实欲望。description

## Core Logic

# 执行步骤

1.  **识别并拒绝预设路径**
    *   **输入**：当前感到迷茫、焦虑的状态；对“唯一正确道路”（如高学历、高薪工作）的固有信念。
    *   **操作**：明确意识到并主动拒绝社会、家庭或教育体系灌输给你的、被视为“唯一成功路径”的预设目标。承认这些目标可能限制了你对可能性的感知。
    *   **判断标准**：能够清晰陈述至少一个你正在质疑或拒绝的“预设路径”，并理解它如何可能限制了你的选择。
    *   **IF** 无法识别或不愿质疑任何预设路径 → **THEN** 模型无法启动，需先进行自我反思或寻求外部视角挑战固有观念。

2.  **基于不满，发起主动探索**
    *   **输入**：步骤1产生的对预设路径的拒绝；内心未被满足的欲望或好奇心。
    *   **操作**：无需他人许可，立即开始尝试你内心渴望但此前因“不合规”而压抑的事情（例如：创业、发展业余爱好、改变社交方式、体验不同生活方式）。行动的核心是满足个人当下的真实欲望。
    *   **判断标准**：启动了至少一项新的、自主选择的探索性行动，该行动源于个人内在驱动而非外部期望。
    *   **常见误区**：等待“完美计划”或“正确时机”；选择行动时仍以社会评价（如“是否体面”）为主要标准。

3.  **将探索中的“失败”视为数据输入**
    *   **输入**：步骤2中探索行动产生的结果（包括负面结果、不适感、未达预期）。
    *   **操作**：将任何不符合预期或带来痛苦的结果（即“错误”或“失败”）视为关键的反馈信息，而非单纯的挫折。分析该结果揭示了你的哪些真实偏好、耐受度或价值观。
    *   **判断标准**：能够从一次“失败”经历中，提炼出关于“我不想要什么”或“什么对我不重要”的明确结论。
    *   **IF** 结果符合预期或带来愉悦 → **THEN** 将其视为“想要什么”的正面数据点，并考虑深化或扩展此探索方向。

4.  **通过排除法迭代澄清目标**
    *   **输入**：步骤3中积累的关于“不想要什么”的数据点；可能有的关于“想要什么”的初步线索。
    *   **操作**：利用“不想要什么”的结论，从反方向划定选择范围。基于缩小后的范围，发起新一轮的探索（回到步骤2），继续通过试错进行精炼。
    *   **判断标准**：个人目标或偏好的描述从模糊的“想要快乐/成功”转变为更具体的、基于排除法的陈述（例如：“我不想要坐班，所以可以尝试远程或项目制工作”）。
    *   **常见误区**：期望一次性找到终极、永恒的人生目标；将迭代过程中的暂时清晰误认为最终答案。

# 输出格式要求

用户应能获得一个动态的、非线性的探索框架。输出需强调：
1.  **核心理念**：明确“错误是自然的指南针”，目标通过排除“不想要的”而非直接找到“想要的”来逐渐清晰。
2.  **行动指令**：鼓励立即开始一项自主的、小规模的探索行动。
3.  **心态调整**：将后续所有结果（尤其是负面结果）都视为有价值的反馈数据，而非对个人的否定。
4.  **迭代预期**：说明这是一个持续循环（探索-反馈-澄清-再探索）的过程，而非一次性任务。
