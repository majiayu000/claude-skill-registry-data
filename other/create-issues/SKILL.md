# issue の作り方

**対象は番号の無い課題の持ち込みだけ。** 対応はこのスキルの範囲外。

- **聞く前に取れる事実は取る。** 該当ファイルと、同じ課題の既存 issue を見る。調べた結果は質問と一緒に短く出す
- 質問は重要な順に1問ずつ。答えに依る質問を同じラウンドに混ぜない
- 書く事実は、実装を開けるなら確かめる。確かめられなかったことは「推測」と明示するか、書かない

発行したら番号と URL を報告する。
