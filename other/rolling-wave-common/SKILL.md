# Rolling-Wave Common

This is a support skill for the rolling-wave skill set. It is not a user-facing workflow entry point.

Use these references when maintaining or executing the phase skills:

- `references/artifacts.md`: project and slice artifact templates.
- `references/lifecycle.md`: status ownership and transition rules.
- `references/pushback.md`: shared evidence-based pushback standard.

Each phase skill still duplicates the short core invariants in its own `SKILL.md` so it can operate in fresh context. Load these shared references only when detailed templates or transition rules are needed.
