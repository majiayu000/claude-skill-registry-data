# 医学结果的临床重要性解释

## 核心原则

1. 统计显著性、效应大小、临床重要性和证据确定性是不同问题，分别报告。
2. 临床重要阈值必须对应具体结局、量表、方向、时间点、人群和效应尺度，并记录来源。
3. 不存在可信阈值时，把临床重要性标为 `indeterminate`；不要要求作者临时发明一个 MCID。
4. 个体层面的 MCID 不自动等于组间平均差的阈值。采用时说明适用性和局限。
5. 以估计值和区间为主，不把 `P ≥ 0.05` 写成“无效”，也不把 `P < 0.05` 写成“临床有效”。
6. 使用方案规定的显著性水平、区间水平和多重性处理，不固定套用 `0.05`。

## 所需输入

为每个结局取得：

- 估计值、置信区间及可选 `P` 值；
- 效应量类型、单位、量表方向、比较组和时间点；
- 主要/次要或探索性地位，以及预设显著性水平；
- 临床重要阈值或重要区间、来源和预设状态；
- 相对效应对应的基线风险，以便在适当时转换为绝对效应。

输入不完整时先列出缺项，不猜测方向、单位、阈值或参考组。

## 工作流

### 1. 校验可比性

- 确认估计值、区间和阈值在同一尺度、同一方向和同一时间点。
- 对“分数越低越好”的量表统一方向后再比较。
- 对比值型指标确认无效值是 `1`；对差值型指标确认无效值是 `0`。
- 相对效应不能单独说明临床影响时，补充同一时间点的绝对风险差或预期绝对效应。
- 发现单位、参考组、区间或方向冲突时停止分类并请求澄清。

### 2. 确认临床重要阈值

按以下优先级选用：

1. 研究方案、注册或样本量设计中预先规定且适用于当前结局的阈值；
2. 同类人群、量表、方向和时间点的高质量锚定法研究或共识；
3. 多个可信来源形成的阈值范围。

记录阈值的数值、方向、单位、适用人群、时间点、来源和是否事后选定。若多个可信阈值不一致，按范围做敏感性
解释并保留差异，不挑选最有利于结论的一个。

### 3. 分开判断统计证据与临床重要性

先按预设分析计划判断统计证据，再把整个置信区间与重要获益/伤害阈值比较：

| 区间与阈值的关系 | 临床解释 |
|---|---|
| 区间全部越过重要获益阈值 | 结果与具有临床重要性的获益相容 |
| 点估计越过阈值，但区间跨过阈值 | 临床重要性不确定 |
| 点估计未越过阈值，但区间包含重要获益 | 不能排除具有临床重要性的获益 |
| 区间全部位于预设“无重要差异”范围内 | 可排除该阈值定义下的重要效应 |
| 区间同时包含重要获益和重要伤害 | 临床解释高度不确定 |
| 无可信阈值或尺度不匹配 | `indeterminate`，只报告大小和精确度 |

表中“区间”指与分析计划一致的区间。边界恰等于阈值时，不写成“已排除”。

### 4. 生成逐结局解释表

使用[对照表模板](templates/significance-vs-clinical-importance.md)，至少包含：

```text
结局 | 时间点 | 效应量/单位 | 区间 | P值（如适用） | 重要阈值及来源
统计判断 | 临床判断 | 不确定性 | 建议措辞 | 是否预设
```

建议措辞使用“与……相容”“不能排除”“未观察到”或“证据不确定”，避免“证实有效”“证明无效”和“趋势性显著”。

### 5. 记录判断限制

明确说明：

- 阈值是否来自不同人群、不同时间点或不同尺度；
- 结果是否为次要、探索性或经过多重比较；
- 区间是否过宽；
- 是否缺少绝对效应、基线风险或患者重要结局；
- 阈值是否在看过结果后才选定。

作者可以提出其他阈值，但要保留原阈值、变更理由和事后性质，并同时展示敏感性解释。

## 输出

建议交付：

- `paper/data/stats/clinical-interpretation.md`：面向作者的逐结局表；
- `paper/data/stats/clinical-interpretation.yaml`：可供后续写作引用的结构化判断；
- 未解决问题清单和阈值来源清单。

本技能只提供解释，不修改统计输出。若需要重新估计、转换尺度或补充绝对效应，交回 `dyz-med-analyze`；若要判断结论
对模型、缺失数据或偏倚假设是否稳健，交给 `dyz-med-sensitivity`。

## 完成标准

- [ ] 每个结局的尺度、方向、时间点和参考组明确
- [ ] 阈值来源、适用性和是否预设已记录
- [ ] 统计判断未固定套用 `P < 0.05`
- [ ] 临床判断考虑了整个区间而非只看点估计
- [ ] 无阈值或尺度不匹配时标为不确定
- [ ] 没有把不显著写成无效或把显著写成临床有效
