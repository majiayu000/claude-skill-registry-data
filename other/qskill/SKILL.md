# Qskill — 스킬을 만들거나 고칠 때

스킬은 글이 아니라 **에이전트의 행동을 바꾸는 코드**다. 그래서 코드처럼 다룬다: 무엇이
실패하는지 먼저 보고, 그 실패를 막는 만큼만 바꾸고, 바뀌었는지 확인한다. 그럴듯해 보이는
문장을 더하는 것은 쉽지만, 실제로 행동을 바꾸는지는 돌려 보기 전에는 모른다. 근거 없이 쌓인
문장은 스킬을 길게 만들고, 긴 스킬은 핵심이 묻히거나 compact 뒤 잘린다.

## 순서

### 1. 스킬 없이 먼저 본다

바꾸려는 상황을 지금 상태(새 스킬이면 스킬 없이, 고치는 거면 고치기 전)로 돌려 본다.
에이전트가 무엇을 하는지, 어떤 핑계로 잘못된 길을 고르는지 **그대로** 적어 둔다.
실패가 보이지 않으면 문장을 넣지 않는다. 넣어도 아무것도 바뀌지 않는다.

### 2. 그 실패만 막는 최소 문장

본 실패에 맞는 형태로 쓴다.

- **판단을 잘못하는 실패**(건너뛰기, 성급한 결론): 왜 그 판단이 비싼지 이유를 쓴다.
  금지만 하면 에이전트는 표현을 바꿔 빠져나간다. 이유를 알면 처음 보는 경우에도 맞게 고른다.
- **모양이 틀리는 실패**(출력 형식, 문서 구조): 금지문보다 예시나 틀을 준다. "이렇게 하지
  마라"보다 "이렇게 생겼다"가 낫다.
- **자주 나오는 핑계**: 본 그대로 "이런 생각이 들면 | 실제" 표로 막는다. 상상한 핑계는 넣지 않는다.

### 3. 다시 돌려 확인한다

같은 상황을 고친 스킬로 다시 돌린다. 한 번 맞은 것은 우연일 수 있으니 여러 번 돌려 본다.
결과는 자동 집계만 믿지 말고 직접 읽는다. 바뀌지 않았으면 문장을 지운다.

### 4. 새로 생긴 핑계를 막는다

고친 스킬에서 새로 나온 빠져나가는 길이 있으면, 그것만 다시 1–3으로.

## 쓰는 법

- **description은 "Use when …" 조건으로.** 언제 이 스킬을 열어야 하는지 상황과 증상을 쓴다.
  스킬이 하는 일을 요약하지 않는다. 요약을 쓰면 에이전트가 스킬을 열지 않고 요약만 따른다.
- **이유로 쓴다.** "항상", "절대" 같은 무조건 문장과 숫자 상한은 판단을 대신한다. 대신 왜
  그래야 하는지, 틀리면 무엇을 잃는지를 쓴다.
- **본문은 짧게.** 자주 불리는 스킬일수록 짧아야 한다. 세부와 참고 자료는 지원 파일로 빼고
  본문에서 링크한다. 지원 파일은 필요할 때만 읽힌다.
- **도구 이름은 정확히.** 실행 환경의 실제 도구·명령 이름을 쓴다.
- **인자 치환 토큰은 이름으로 설명한다.** 달러 기호로 시작하는 위치 인자나 전체 인자 토큰을
  본문에 그대로 쓰면 스킬을 불러올 때 실제 인자로 바뀔 수 있다.
- **스킬 폴더에는 스킬이 쓰는 파일만.** 테스트 시나리오나 실험 기록을 스킬 옆에 두면 에이전트가
  작업 중에 그것을 지시로 읽을 수 있다. 시험 자료는 스킬 폴더 밖에 둔다.

## 확인하는 법

- **불리는지**: 스킬이 불려야 할 요청과 불리면 안 되는 요청을 하나씩 준비해 `claude -p`로
  돌려 본다(플러그인이면 `--plugin-dir <경로>`). 이웃 스킬과 description이 겹치면 엉뚱한 쪽이 불린다.
- **행동이 바뀌는지**: 위 1–3단계. 스킬 없이 돌린 결과와 나란히 비교한다.
- **구조**: 이름과 폴더가 같은지, 링크한 지원 파일이 있는지, 본문이 길어지지 않았는지.
- **반복해서 재려면**: Claude Code의 `claude plugin eval`로 케이스(요청 + 채점 기준)를 만들어 두면,
  플러그인 없이 돌린 결과와 나란히 여러 번 돌려 볼 수 있다. 케이스가 요청 상황을 제대로
  재현하는지(필요한 코드가 요청 안에 있는지 등)부터 확인한다.

## 이런 생각이 들면

| 생각 | 실제 |
|---|---|
| "이 문장이 있으면 더 안전하겠다" | 실패를 보지 않았다면 근거가 없다. 먼저 돌려 본다 |
| "강하게 써야 지킨다" | 이유를 쓰는 편이 새 상황에서도 통한다 |
| "description에 하는 일을 다 적자" | 요약만 따르고 본문을 안 연다. 언제 쓰는지만 적는다 |
| "한 번 돌려 보니 됐다" | 여러 번 돌려 본다. 한 번은 우연일 수 있다 |
