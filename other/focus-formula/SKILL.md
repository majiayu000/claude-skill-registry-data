# focus-formula

## When to Use

当需要系统性地规划个人生活、职业发展或特定项目，以摆脱外部干扰、聚焦核心目标时description

## Core Logic

# 执行步骤

1.  **构建外在潜力金字塔**
    *   **输入**：个人长期愿景或项目终极目标。
    *   **操作**：
        1.  **设定目标（北极星）**：定义一个清晰、长远、能指引方向的核心目标。
        2.  **设计过程（精通之路）**：为目标拆解出可重复执行、能带来渐进式进步的关键日常行动或系统。
        3.  **确定优先级（决策框架）**：建立一个标准（如ROI、与目标的相关性），用于判断和选择当下应执行的具体任务。
    *   **判断标准**：目标具有感召力，过程可执行且与目标强相关，优先级标准能有效区分任务重要性。
    *   **常见误区**：目标过于模糊或宏大；过程与目标脱节；优先级标准主观、多变。

2.  **构建内在进步金字塔**
    *   **输入**：对自身当前状态（情绪、精力、认知）的觉察。
    *   **操作**：
        1.  **提升意识（认知基础）**：通过冥想、记录等方式，定期观察并记录自己的注意力流向、情绪反应和思维模式。
        2.  **引入挑战（成长引擎）**：在能力边缘，主动设置略高于当前水平的任务或学习内容，以驱动成长。
        3.  **保持清晰度（反思校准）**：定期（如每日/每周）回顾，评估行动与目标的匹配度，并根据反馈调整外在金字塔。
    *   **判断标准**：能清晰描述自身状态；挑战任务带来适度压力而非崩溃；反思能产生具体的调整计划。
    *   **常见误区**：忽视内在状态，只关注外在行动；挑战难度过高或过低；反思流于形式，无后续行动。

3.  **对齐与投入注意力**
    *   **输入**：已构建的“外在潜力金字塔”和“内在进步金字塔”。
    *   **操作**：
        1.  **检查对齐**：审视“外在金字塔”的目标、过程、优先级，是否与“内在金字塔”的当前意识状态、挑战承受力、反思结论相协调。
            *   **IF** 发现冲突（如目标引发持续焦虑，过程消耗殆尽精力），**THEN** 返回步骤1或2进行微调。
            *   **ELSE**（两者基本协调），**THEN** 进入步骤2。
        2.  **执行聚焦**：将每日的注意力和时间，有意识地投入到已对齐的“外在金字塔”的优先级任务和“内在金字塔”的挑战与反思中。
    *   **判断标准**：执行任务时感到目标清晰、内心有序，而非被外部杂务驱动；能有效减少无关干扰。
    *   **常见误区**：强行执行未对齐的计划导致内耗；在聚焦时段仍频繁切换任务。

# 输出格式要求
输出一个结构化的总结，包含：
1.  **我的外在潜力金字塔**：列出清晰的北极星目标、核心过程与优先级决策标准。
2.  **我的内在进步金字塔**：描述当前的意识基线、设定的成长挑战及反思校准计划。
3.  **对齐与聚焦计划**：说明下一步将注意力集中投入的具体行动及时间安排。
