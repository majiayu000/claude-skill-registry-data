# skill-tree-progression

## When to Use

当需要系统性地提升在某个领域的能力以建立自信时调用此模型description

## Core Logic

# 执行步骤

1.  **定义当前等级与目标**：明确你目前在目标领域的“技能等级”（初学者、中级等），并清晰定义下一级希望达到的具体能力水平。
    *   **判断标准**：能够列出当前已掌握的技能，并能用具体、可观察的结果描述下一等级的目标（例如：“从能写基础代码到能独立开发一个小功能模块”）。
    *   **常见误区**：目标过于模糊（如“变得更好”）或过于宏大，与当前等级脱节，导致无从下手。

2.  **识别并学习“可解锁技能”**：基于当前等级，识别并专注于学习1-2项直接可用、且能推动你达到下一级目标的“核心技能”。
    *   **判断标准**：选定的技能是具体的、可练习的，并且学习后能立即应用于当前情境以产生微小进步。
    *   **常见误区**：同时学习过多技能，或跳过基础技能去学习高级、当前用不上的“炫技”技能。

3.  **在情境中实践并积累经验**：主动寻找或利用现有情境，应用新学习的技能。完成后进行简短反思，确认技能是否有效应用及效果。
    *   **判断标准**：完成了至少一次有意识的应用实践，并能指出应用过程中的成功点与改进点。
    *   **常见误区**：只学不练，或将实践拖延到“准备好”的完美时刻。

4.  **评估升级与迭代循环**：评估当前技能掌握程度是否已达到下一等级标准。如果达到，返回步骤1，重新定义新的“当前等级”和下一级目标；如果未达到，返回步骤2，继续深化练习或补充相关子技能。
    *   **判断标准**：能根据步骤1定义的标准，客观判断自己是否“升级”。
    *   **常见误区**：长期停留在舒适区，停止学习新技能；或在未扎实掌握当前技能时，急于跳级。

# 输出格式要求
输出一个简短的进度报告，格式为：“当前等级：[等级描述]。正在练习的核心技能：[技能名称]。下次实践计划：[具体情境或任务]。”
