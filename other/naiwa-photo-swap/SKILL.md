# 奶蛙照片替换

以用户照片为底图，把指定人物替换为奶蛙，并让结果看起来像在现场拍摄。默认用中文与用户沟通；用户要求其他语言时遵从用户要求。内置图片只作为奶蛙的造型参考，不能误当成要编辑的风景底图。替换方向不明确时，先确认谁替换谁。

## 角色参考图

只选当前任务需要的参考图。若用户另发奶蛙参考图，优先采用用户新给的版本。

| 图片 | 用途 |
| --- | --- |
| `assets/naiwa-front-crossed-arms.jpg` | 默认造型：梨形体态、浅色肚皮、绿色眼圈、闭嘴微笑、叉手动作 |
| `assets/naiwa-surprised.jpg` | 张口惊讶表情 |
| `assets/naiwa-three-quarter.jpg` | 侧面头部体积和眼睛位置 |
| `assets/naiwa-wave.png` | 叉腿、抬手动作；忽略图中的黑色方块 |

图像工具支持本地文件时，把选中的图片作为参考输入；否则先用看图工具显示参考图，再进行生成。始终明确标注哪张是编辑底图、哪张是角色或动作参考。

## 替换原则

- 按用户指定范围编辑。替换整个人物时，保留奶蛙连贯的柔和黄色梨形轮廓、浅色肚皮、微凸的薄荷绿眼圈、黑色瞳孔、简单嘴型及短圆四肢。仅替换面部时，按要求保留原人物的头发、眼镜、服装、装备和姿态。
- 奶蛙应出现在原人物的位置，尺寸、视角和透视自然。保留背景、其他人物或动物、前景物体及构图；用户要求保留的道具和可读信息也要尽量保留。
- 默认沿用底图人物的动作；只有用户指定时才改用参考图动作。头发、帽子、衣服和表情由本次要求决定，不是固定设定。
- 奶蛙应像真实场景中的哑光立体角色：有细微表面质感、接触阴影，并与现场的光线、清晰度一致。避免贴纸感、塑料高光、普通绿青蛙、巨大的人形黄色面具，以及夸张的大眼和咧嘴笑。

## 胶片质感

默认采用克制的 35mm 彩色负片观感，可参考柯达 Portra 400 和富士 Pro 400H：柔和自然光、微暖褪色、较低对比与饱和度、整张照片一致的细腻颗粒、轻微高光晕染及温和的背景虚化。漏光、灰尘和划痕只能少量点缀，不能遮住人物或重要场景。奶蛙与背景必须具有相同的摄影质感，避免只给背景加滤镜。

## 工作流程

1. 确认底图、需要替换的人物，以及本次表情、动作、衣服、头发、道具的要求。在编辑请求中明确标注每张输入图的作用。
2. 使用图像编辑工具，以底图为第一个输入，再加入需要的奶蛙参考图。[中文提示词模板](references/edit-prompt.md)可用于组织编辑要求。
3. 查看生成图，检查奶蛙辨识度、身体比例、自然融合、场景保留和胶片效果。发现具体问题时做针对性修正。最终结果另存，不能覆盖原图。

本 Skill 不保存 API 密钥或服务商配置。向外部图像服务发送照片时，仍需取得适用于该照片与服务的授权。
