# 医学论文引言撰写

## 入口边界

用户说“写引言”“改引言”“知识缺口不清楚”时使用。用户想先规划全文逻辑时使用
`dyz-med-writing-plan`；只想核查引用是否支持论断时使用 `dyz-med-evidence-audit`。

## 写作前输入

尽量取得：

- 研究问题、研究设计、研究对象与主要结局；
- 论证地图和引言段落计划；
- 已核实的关键文献、文献简报及矛盾证据；
- 目标期刊、研究类型和现有引言草稿。

文献不足以证明疾病负担、已有证据或知识缺口时，不得补写看似可信的数字、作者或引用。可先交付段落骨架和
“待补证据清单”。

## 工作流

### 1. 固定引言要回答的四个问题

1. 具体人群面临什么临床或科学问题？
2. 现有研究已经知道什么？
3. 仍缺什么，为什么现有证据没有解决？
4. 本研究准确要回答什么？

常用漏斗结构为“背景 → 已有证据 → 知识缺口 → 研究目的”，但应服从研究类型、期刊格式和实际论证，
不机械限定为四段。

### 2. 分配证据

- 疾病负担数字必须带可核查来源；
- 每项既有结论应能追溯到具体研究或指南；
- 矛盾或阴性证据应在缺口定义中得到体现；
- “研究很少”“尚无研究”等存在性断言必须经过足够检索才能使用；
- 文献简报只是导航，最终引用仍需核对原始记录或全文可见内容。

### 3. 起草正文

- 背景聚焦目标人群和问题，删除教科书式常识铺陈；
- 已有证据说明人群、设计和关键发现，不堆砌作者名单；
- 缺口具体到人群、比较、结局、方法或证据冲突；
- 目的句与研究问题和主要结局逐字对齐；
- 观察性研究采用关联性目的表述，不提前写成干预效果或因果结论。

### 4. 自检

- 引言未泄露本研究结果；
- 没有把讨论和机制推断提前写入引言；
- 每个数字和关键事实有来源；
- 引用没有超出摘要或全文实际支持范围；
- 研究目的不包含计划外的新结局或新亚组；
- 术语、缩写与全文一致。

## 输出

默认写入 `paper/sections/01-introduction.md`，或按用户指定文件更新。若直接改写现有引言，保留一份变更摘要，
说明删除、合并、补证据或降级措辞的位置。

## 验收标准

- 读者能从背景自然走到具体知识缺口；
- 缺口由已核实证据推出，而非空泛宣称；
- 目的句可直接映射到研究设计和主要结局；
- 不含虚构引用、结果泄露或过度因果表述。
