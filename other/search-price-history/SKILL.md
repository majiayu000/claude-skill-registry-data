# search-price-history

## 目标
在用户需要历史价格、最低价、价格走势、比价或价保判断时，通过只读价格历史工具和公开来源整理可验证的价格时间线。

## 适用请求
- 查询某商品历史最低价、近期价格走势、是否值得买或是否可价保。
- 对比 Amazon、国内电商和跨平台商品价格历史。
- 查找 Keepa、BigGo、什么值得买、慢慢买或平台历史价线索。

## 首选通道
- skill-only：优先查询 Keepa/BigGo/什么值得买/慢慢买/平台历史价网页或用户已授权的只读 API。
- 不新增或依赖 MCP；登录后价格只从当前 Firefox 可见页面、用户复制文本或截图/OCR 取证。

## 兜底通道
- 搜索网页快照、用户爆料、商品页面当前价、促销文章和历史引用。
- 使用平台专项 skill 或当前 Firefox 只读读取当前价和公开历史价线索。

## 操作流程
1. 确认商品 URL、ASIN/SKU、平台、地区、币种、规格、目标时间范围和价保规则。
2. 优先使用 Keepa/BigGo/什么值得买/慢慢买/平台历史价网页或只读 API；不可用时使用 WebSearch、平台页面和公开爆料来源。
3. 只读取和汇总价格数据；全程只读搜索/读取，不发起新的登录流程、不下单、不私信、不发帖、不写入平台，也不领券、加购、申请价保或联系商家。
4. 记录价格、时间、平台、规格、优惠条件、来源 URL 和可信度，区分标价、到手价、券后价、会员价。
5. 给出是否接近历史低价的判断时说明依据和不确定性，不替用户购买或申请价保。

## 只读安全边界
- 只搜索、打开、读取和总结价格历史或当前价公开信息。
- 不发起新的平台登录流程；如当前 Firefox 已登录则只读复用，不绕过验证码、会员、地区或付费限制。
- 不加购、不下单、不付款、不领券、不申请价保、不联系商家、不评论、不发布爆料。
- 不保存密钥、Cookie、Token、地址或支付信息。

## 验证方式
- 后续可运行：`dir C:\Users\Zhang\.config\opencode\skills\search-price-history\SKILL.md`
- 人工检查：确认首选通道为 skill-only 历史价网页/API + 当前 Firefox，不依赖 MCP。

## 已知限制
- 历史价格工具覆盖范围有限，且不同规格、地区、券后价不可直接比较。
- 价格快照和用户爆料可能失真或缺少优惠条件。
- 价保规则由平台实时调整，最终以平台页面和用户账户显示为准。
