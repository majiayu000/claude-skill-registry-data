# Chore System

Use when this capability directly owns the requested outcome.

## Procedure
1. List recurring tasks and realistic frequency.
2. Assign ownership based on age, ability, availability, and fairness.
3. Make completion criteria clear enough that one person is not forced to re-manage every task.
4. Review workload after real use and rebalance when the system is consistently failing.

## Output standard
Give a concrete result, decision aid, or next action. Keep assumptions visible and hand off work outside this skill's domain.
