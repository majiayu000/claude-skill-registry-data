# creator-mindset-shift

## When to Use

当个体在数字环境中困惑于自身角色（消费vs创造），或认为吸引注意力不道德时description

## Core Logic

# 执行步骤

1.  **角色自检**
    - **输入**：个人在数字平台（社交媒体、论坛等）上的行为记录。
    - **操作**：量化分析过去一段时间（如一周）内，在数字平台上的“主动创造行为”（发布原创内容、评论、分享见解）与“被动消费行为”（浏览、点赞、无贡献滚动）的比例。
    - **判断标准**：得出一个明确的“创造/消费”时间或行为占比。
    - **IF** 消费行为占比远高于创造行为 **THEN** 进入步骤2。**ELSE** 可直接进入步骤3。

2.  **心态重构**
    - **输入**：步骤1得出的高消费占比结果、关于“吸引注意力是否道德”的疑虑。
    - **操作**：进行认知重构：a) 将“吸引注意力”重新定义为“为有价值的事物争取被看见的机会”；b) 理解被动消费等同于将塑造环境的影响力让渡给他人；c) 明确道德与否的关键在于所推广的产品/内容是否真实改善他人生活。
    - **判断标准**：能够清晰阐述“为何主动创造并提供价值比被动消费更具积极意义”。
    - **IF** 仍无法接受“吸引注意力”的正当性 **THEN** 模型终止，需更基础的价值观讨论。

3.  **意图设定**
    - **输入**：通过步骤2重构后的心态。
    - **操作**：明确个人作为创造者的核心意图：是希望传播特定知识、解决某一类问题、还是构建某种文化。将此意图作为未来所有创造行为的过滤器。
    - **判断标准**：能够用一句话概括自己的创造意图，并且此意图与提供价值相关。
    - **IF** 意图模糊或仍以自我展示为中心 **THEN** 返回步骤2，重新审视“提供价值”的定义。

# 输出格式要求
输出一份简明的自我诊断与设定报告：
-   当前角色倾向（创造者/消费者/混合）及比例。
-   重构后的核心信念（关于注意力与价值的观点）。
-   作为创造者的首要意图陈述。
