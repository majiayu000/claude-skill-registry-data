# learn-by-teaching

## When to Use

当需要深化对某个主题的理解、检验知识掌握程度或克服“冒名顶替综合征”时description

## Core Logic

# 执行步骤

1.  **确定教学主题与受众**
    *   **输入**：希望巩固的特定知识块或技能点。
    *   **操作**：明确你要教授的具体内容，并设想一个受众（如“初学者朋友”、“未来的自己”或“公开博客的读者”）。
    *   **判断标准**：主题是否足够具体，受众是否明确。
    *   **输出**：清晰的教学主题和假想受众。
    *   **常见误区**：主题过于宽泛；没有设定受众，导致表达不清。

2.  **结构化梳理与内容准备**
    *   **输入**：上一步确定的教学主题。
    *   **操作**：为了向受众解释清楚，你必须将零散的知识点组织成逻辑连贯的结构。可以制作大纲、绘制概念图或整理关键步骤。
    *   **判断标准**：知识是否被组织成易于理解的逻辑流，核心概念和步骤是否清晰。
    *   **输出**：教学内容的结构化大纲或草稿。
    *   **常见误区**：直接堆砌信息，缺乏逻辑梳理；跳过自己似懂非懂的部分。

3.  **选择形式并进行输出**
    *   **输入**：结构化后的教学内容。
    *   **操作**：选择一种输出形式并执行：
        a. **IF** 目标是获得反馈：**THEN** 进行公开写作或录制视频并发布。
        b. **IF** 目标是即时互动和简化：**THEN** 向一位朋友当面或在线讲解。
        c. **IF** 目标是自我内化：**THEN** 以教导“昨天的自己”的口吻撰写学习笔记。
    *   **判断标准**：是否完成了完整的内容输出。
    *   **输出**：最终的教学作品（文章、视频、讲解录音、笔记）。
    *   **常见误区**：因追求完美而拖延输出；在输出时夸大经验或知识水平。

4.  **诚实定位与处理反馈**
    *   **输入**：完成的教学作品及可能收到的反馈。
    *   **操作**：
        a. 在教学中始终保持“学习者/分享者”的诚实定位，不承诺无法交付的内容。
        b. **IF** 收到外部反馈（疑问、纠正）：**THEN** 将其视为发现知识漏洞的机会，进行查证和修正。
        c. **ELSE** (无外部反馈或为自我教学)：**THEN** 在输出过程中，自行标记出讲解时感到不顺畅或不确定的部分，作为后续学习的重点。
    *   **判断标准**：是否通过教学过程发现了自身知识的模糊点或错误。
    *   **输出**：一份知识掌握程度的自我评估清单，以及待深入学习的知识点列表。
    *   **常见误区**：回避或防御性对待负面反馈；教学后不进行反思和查漏补缺。

# 输出格式要求
输出应包含：1) 教学主题与形式；2) 教学作品的核心要点摘要或链接；3) 在教学中发现的知识薄弱环节列表；4) 基于反馈的修正计划或后续学习重点。
