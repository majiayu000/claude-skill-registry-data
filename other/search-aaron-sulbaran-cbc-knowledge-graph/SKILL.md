# Search the wiki

1. Read `wiki/index.md` first. Pick the 3 to 5 pages most likely to answer the question.
2. If the index is not enough, search the wiki folder for the key words, then pick from those hits.
3. Read those pages. Follow a `[[link]]` only if it clearly points somewhere more specific. Open a `raw/` file only when you need an exact quote or number.
4. Answer in plain language and cite every claim with the page or file it came from.
5. If the wiki does not have the answer, say so plainly. Do not fill gaps from general knowledge without labeling it.
6. If your answer pulled together several pages in a new way, offer to save it as a new wiki page so the next search is faster.
