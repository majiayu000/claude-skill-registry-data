# invest-pool：基金池构建与管理

> 基金池是投资者的武器库。产品数量不是越多越好，挑选适合自己的最重要。

---

## 哲学锚点

- **约翰博格「指数优先」**：大多数主动基金长期跑不赢指数，基金池应以指数基金为底仓。
- **巴菲特「能力圈」**：看不懂的策略不纳入池子，无论业绩多亮眼。
- **费雪「长期持有」**：优秀基金不是什么时候都表现好，需要适当的时机和巧妙的投资方法。

## 一、风格分类矩阵

基金池按两个维度分类：**风格** × **类型**。

### 按风格分类

| 风格 | 特征 | 适合人群 | 风险等级 |
|------|------|---------|---------|
| 成长 | 高增长、高估值、高波动 | 年轻、能承受波动 | 高 |
| 稳健 | 中等增长、中等估值 | 均衡型投资者 | 中 |
| 价值 | 低估值、高股息、低波动 | 保守型、临近退休 | 低 |
| 激进 | 行业集中、高弹性 | 有经验、能承受大回撤 | 极高 |
| 主题 | 聚焦特定行业/趋势 | 对某行业有深度认知 | 高 |

### 按类型分类

| 类型 | 特征 | 流动性 |
|------|------|--------|
| 偏股基金 | 股票仓位 > 80% | T+1 |
| 债券基金 | 债券仓位 > 80% | T+1 |
| 固收+ | 债券为主 + 少量股票增强 | T+1 |
| 指数基金 | 跟踪特定指数 | T+1（场内 T+0） |
| QDII | 投资海外市场 | T+2 |

### 基金池结构建议

```
基金池（总量 15-25 只为宜）
├── 底仓层（40-50%）：指数基金 + 稳健风格
│   ├── 宽基指数（沪深300/中证500/标普500）
│   └── 稳健主动基金
├── 核心层（30-40%）：成长 + 价值风格
│   ├── 成长风格主动基金
│   └── 价值风格主动基金
├── 卫星层（10-20%）：主题 + 行业轮动
│   ├── 行业主题基金
│   └── 行业轮动基金
└── 观察池（5-10%）：新发现/待验证
    └── 新发基金/新经理
```

## 二、选基七维度

对每只候选基金，按七个维度评估：

### 维度 1：能力圈

| 问题 | 判断标准 |
|------|---------|
| 主要投哪些行业？ | 有明确行业偏好 |
| 有无明显回避？ | 有清晰的能力圈边界 |
| 策略能向外行说清吗？ | 能说清 → 通过 |

### 维度 2：风格稳定性

| 问题 | 判断标准 |
|------|---------|
| 近三年是否发生风格漂移？ | 无漂移 → 通过 |
| 价值/成长/均衡标签是否稳定？ | 稳定 → 通过 |
| 市场风格变化时是否追热点？ | 不追 → 通过 |

### 维度 3：规模适配

| 规模区间 | 判断 |
|---------|------|
| < 5 亿 | 小盘灵活，但需关注清盘风险 |
| 5-50 亿 | 舒适区 |
| 50-100 亿 | 关注策略容量 |
| > 100 亿 | 警惕策略失效 |
| > 300 亿 | 大概率跑输 |

### 维度 4：平台实力

| 问题 | 判断标准 |
|------|---------|
| 基金公司投研实力如何？ | 以主动权益见长 → 加分 |
| 是否有独立投研团队？ | 不依赖明星经理单打独斗 → 加分 |
| 公司文化鼓励长期还是短期排名？ | 长期主义 → 加分 |

### 维度 5：业绩归因

| 问题 | 判断标准 |
|------|---------|
| 超额收益来自能力还是运气？ | 能力 → 通过 |
| 业绩有多少来自行业/主题风口？ | 风口占比 < 50% → 通过 |
| 跑赢基准的持续性如何？ | 持续 3 年以上 → 通过 |

### 维度 6：职业稳定性

| 问题 | 判断标准 |
|------|---------|
| 是否频繁跳槽？ | 同一家公司 3 年+ → 通过 |
| 任职以来管理基金数量？ | ≤ 5 只为宜 |
| 有无离职/休假等异常？ | 无 → 通过 |

### 维度 7：运气成分

| 问题 | 判断标准 |
|------|---------|
| 近一年业绩是否远超同类？ | 远超 → 警惕均值回归 |
| 业绩是否集中在某几只重仓股？ | 集中 → 警惕运气成分 |
| 基金经理自己是否跟投？ | 跟投 → 加分 |

### 评分方法

每个维度 1-5 分，总分 35 分：

| 总分 | 判断 | 池子归属 |
|------|------|---------|
| 28-35 | 优秀 | 底仓/核心层 |
| 21-27 | 良好 | 核心/卫星层 |
| 14-20 | 一般 | 观察池 |
| < 14 | 较差 | 不纳入 |

## 三、行业轮动基金评估

行业轮动基金是一类特殊品种，需要额外评估：

### 评估维度

| 维度 | 核心问题 | 判断标准 |
|------|---------|---------|
| 轮动跨度 | 在哪些行业间轮动？ | 跨行业 > 单行业内 |
| 左侧/右侧 | 提前布局还是追趋势？ | 左侧更考验能力 |
| 持仓集中度 | 前十大重仓占比？ | < 60% 为宜 |
| 换手率 | 年换手率？ | 过高（> 300%）需警惕 |
| 产业趋势 | 从产业趋势出发还是纯博弈？ | 产业趋势 → 加分 |
| 估值匹配 | 是否结合估值？ | 结合 → 加分 |

### 投资者适配性

| 信号 | 判断 |
|------|------|
| 净值波动大，与基准差异大 | 适合心理承受力强的投资者 |
| 短期业绩爆发力强 | 适合小仓位试水 |
| 长期业绩不稳定 | 不适合底仓，适合卫星仓 |

## 四、更新机制

### 更新频率

| 动作 | 频率 | 内容 |
|------|------|------|
| 快速检查 | 每月 | 基金经理变动、规模异动、业绩大幅偏离 |
| 季度复盘 | 每季度 | 七维度重新评分，淘汰/替换 |
| 全面更新 | 每半年 | 风格分类调整，新基金纳入评估 |

### 淘汰规则

| 信号 | 动作 |
|------|------|
| 基金经理离职 | 立即评估，视情况淘汰 |
| 规模暴涨（半年翻倍） | 减仓或淘汰 |
| 风格漂移 | 观察一季，确认后淘汰 |
| 连续 2 季业绩后 30% | 淘汰 |
| 平台实力下降（投研团队流失） | 评估后淘汰 |

### 纳入规则

| 条件 | 动作 |
|------|------|
| 新发基金 | 进入观察池，不急于买入 |
| 新经理接手 | 重新评估，不自动继承原经理评分 |
| 市场风格变化 | 评估池子风格覆盖是否均衡 |

## 五、组合配置原则

### 数量控制

- 总量 15-25 只为宜
- 太少（< 10）：分散不足
- 太多（> 30）：跟踪不过来，且高度重叠

### 风格均衡

| 原则 | 说明 |
|------|------|
| 成长 + 价值均衡 | 不要全仓单一风格 |
| 主动 + 指数均衡 | 指数基金为底仓，主动基金求超额 |
| 行业分散 | 避免多只基金重仓同一行业 |

### 核心原则

1. **名气大 ≠ 好基金**：大型基金公司也不等于好的基金公司
2. **再辉煌的历史属于过去**：未来需要能够继续沿着正确方向前进的人和公司
3. **产品数量不是越多越好**：挑选适合自己的最重要
4. **优秀基金不是什么时候都表现好**：适当的时机和巧妙的投资方法也很重要
5. **基金的组合和配置是系统性工程**：这里的学问比选基更大，也更能决定最后的投资收益水平

## 核心原则

1. **不替决策**：提供框架，决策交还用户
2. **不预测收益**：只评估基金质量与池子结构
3. **数据时效**：不用过期数据
4. **定期更新**：基金池是活的，需要持续维护
