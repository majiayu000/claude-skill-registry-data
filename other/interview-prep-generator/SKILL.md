# 面试准备生成器（Interview Prep Generator）

## 何时使用此技能

当用户想要以下操作时使用此技能：
- 准备求职面试
- 练习回答面试问题
- 从自身经历中提炼 STAR 故事
- 预判某个特定岗位可能被问到的问题
- 提到：「面试准备」「面试辅导」「STAR 故事」「面试问题」「行为面试题」等

## 核心能力

- 生成针对特定岗位的面试问题
- 从简历经历条目中提炼 STAR 故事
- 基于职位描述预测可能的问题
- 为常见问题准备答案
- 为每段经历准备论述要点
- 识别潜在的疑虑并准备好回应

## 面试准备框架

### 阶段 1：岗位分析
- 从职位描述中提取可能被问到的问题
- 识别将会被考察的技能
- 调研这家公司的面试风格

### 阶段 2：故事库建设
- 将简历经历条目转化为 STAR 故事
- 为常见胜任力准备故事
- 练习简洁的表达

### 阶段 3：模拟准备
- 练习常见问题
- 准备要反问面试官的问题
- 调研这家公司的特定话题

## STAR 方法详解

### 结构
- **S**ituation（情境）：交代背景（1-2 句）
- **T**ask（任务）：说明你的职责（1 句）
- **A**ction（行动）：解释你做了什么（2-3 句）
- **R**esult（结果）：给出带指标的成果（1-2 句）

### STAR 故事模板

```
SITUATION：「在[公司]，我们当时面临[具体挑战/背景]……」

TASK：「我负责[具体的职责范围]……」

ACTION：「我[具体行动 1]、[具体行动 2]，并且[具体行动 3]……」

RESULT：「最终[量化的成果]。这带来了[业务影响]。」
```

### STAR 故事示例

**问题：「请讲一次你带领团队完成困难项目的经历。」**

**回答：**
```
SITUATION：「在智谱科技，我们的主打产品正在被一家刚推出更好移动端体验的竞品抢走客户。我们的月流失率达到 5%，远高于正常的 2%。」

TASK：「作为产品经理，我负责扭转移动端产品的局面，止住流血并赢回客户。」

ACTION：「我首先访谈了 30 位流失客户，弄清他们离开的确切原因。基于调研结果，我筛选出 5 个能追平竞品的关键功能并排定优先级。随后我推动工程团队重构路线图，与高层谈判争取到 2 名外包开发资源，并推行每周迭代评审来保证项目进度。我还在正式发布前，召集 50 位核心客户开展了公测以获取反馈。」

RESULT：「我们在 3 个月内上线了改进后的移动应用，60 天内将流失率从 5% 降回 2%。我们挽回了 35% 的流失客户，移动应用的 NPS 从 32 提升至 58。这个项目在全司大会上被表彰为扭转局面的成功案例。」
```

**时长：** 90 秒到 2 分钟

## 故事库建设流程

### 第 1 步：识别核心胜任力

**需要的领导力故事：**
- 带领团队克服挑战
- 处理冲突
- 做出艰难决策
- 有效授权
- 培养/辅导他人

**需要的解决问题故事：**
- 解决复杂的技术问题
- 修复失灵的流程
- 应对突发障碍
- 在信息不完整时做决策
- 主动改进某项事物

**需要的协作故事：**
- 与难相处的同事共事
- 让跨部门相关方达成一致
- 凝聚共识
- 与其他团队合作
- 在没有职权的情况下施加影响

**需要的成就故事：**
- 超额完成目标/超出预期
- 在压力下交付
- 超越职责范围付出
- 主动担当
- 完成引以为豪的事

**需要的失败/成长故事：**
- 犯错并从中学习
- 接受严厉的反馈
- 失败后重新站起
- 基于经验调整方法

### 第 2 步：将简历映射到故事

对每一条简历经历条目，展开成完整的 STAR 故事：

```
简历经历条目：「带领 12 人跨部门团队交付了 200 万美元的产品发布」

STAR 展开：

SITUATION：公司市场份额正被竞品蚕食，管理层决定我们必须在 6 个月内上线一条新产品线。

TASK：作为产品经理，我负责让产品从概念走向发布，协调工程、设计、市场和销售团队（共 12 人）。

ACTION：
- 我建立了每周跨部门同步会和一个共享的 Notion 工作区
- 制定了包含里程碑和依赖关系的详细项目计划
- 落地了以 2 周为周期的快速原型设计迭代流程
- 亲自化解了工程与市场之间的 3 次重大冲突
- 每月向管理层汇报进展，保持各方一致

RESULT：
- 按时且低于预算完成发布
- 第一年产生 200 万美元收入
- 新增 50 家企业客户
- 团队获得公司创新奖
```

### 第 3 步：创建多个版本

每个故事应具备：
- **完整版：** 2 分钟（用于「讲一次你……的经历」）
- **简短版：** 60 秒（用于追问）
- **一句话版：** 15 秒（用于「举个例子」）

## 按类别划分的常见面试问题

### 行为面试题

**领导力：**
- 「讲一次你带领团队的经历。」
- 「描述一个你必须做出不受欢迎决定的情境。」
- 「你是如何培养团队成员的？」
- 「讲一次你应对难相处的团队成员的经历。」

**解决问题：**
- 「描述你解决过的一个复杂问题。」
- 「讲一次事情没有按计划进行的经历。」
- 「面对信息不完整的问题，你会如何应对？」
- 「举一个你提出的创新方案的例子。」

**协作：**
- 「讲讲与难相处的人合作的经历。」
- 「描述一次你在没有职权的情况下影响他人的经历。」
- 「你如何处理与同事的分歧？」
- 「讲一个成功的跨部门项目。」

**成就：**
- 「你最引以为豪的职业成就是什么？」
- 「讲一次你超出预期的经历。」
- 「描述一个你在逆境中达成的目标。」
- 「你职业生涯中产生过最大影响的一件事是什么？」

**失败/成长：**
- 「讲一次你失败的经历。」
- 「你工作中犯过的最大错误是什么？」
- 「你如何应对批评？」
- 「在你的职业道路中，什么是你会用不同方式去做的？」

### 岗位专属问题

**产品经理（Product Management）：**
- 「你如何确定功能优先级？」
- 「请讲讲你会如何处理[某产品问题]。」
- 「你如何衡量产品成功？」
- 「讲一个你从 0 到 1 做出来的产品。」

**工程（Engineering）：**
- 「描述你在[某项技术]上的经验。」
- 「你如何看待代码评审（code review）？」
- 「讲一个你解决过的技术难题。」
- 「你如何权衡技术债与新功能？」

**市场（Marketing）：**
- 「你如何衡量营销活动的成功？」
- 「讲一场没有达到效果的营销活动。」
- 「你如何在各渠道之间分配预算？」
- 「描述你做品牌建设的方法。」

**销售（Sales）：**
- 「讲讲你的销售流程。」
- 「讲一单你输掉的单子以及原因。」
- 「你如何应对客户的异议？」
- 「描述你成交过的最大一单。」

### 标准问题

**关于你：**
- 「介绍一下你自己。」（2 分钟自我陈述）
- 「请带着我们过一遍你的简历。」
- 「你为什么在看新的机会？」
- 「5 年后你希望自己在做什么？」

**关于岗位：**
- 「为什么选择这个岗位？」
- 「这个职位有什么吸引你的地方？」
- 「你认为这个岗位要做什么？」
- 「入职后的头 90 天你会做什么？」

**关于公司：**
- 「为什么选择这家公司？」
- 「你对我们了解多少？」
- 「你为什么想在这里工作？」
- 「我们的使命有什么让你兴奋的地方？」

## 可以反问面试官的问题

### 问招聘负责人（Hiring Manager）
- 「在这个岗位上，30/60/90 天的成功分别是什么样？」
- 「团队目前面临的最大挑战是什么？」
- 「绩效如何衡量？」
- 「团队结构是怎样的？」

### 问未来团队成员
- 「典型的一天/一周是什么样的？」
- 「在这里工作你最享受的是什么？」
- 「团队之间如何协作？」
- 「你希望新入职的人了解什么？」

### 问高管
- 「公司明年的战略是什么？」
- 「这个团队如何为公司目标做贡献？」
- 「是什么让你对这家公司保持兴奋？」

### 要避免的问题
- ❌ 关于薪资/福利的问题（留到 HR 环节）
- ❌ 一搜（Google 一下）就能知道答案的问题
- ❌ 针对公司负面问题的问题
- ❌ 能用「是/否」回答的问题（要提问开放式问题）

## 应对刁钻问题

### 「你最大的缺点是什么？」

**公式：** 真实的缺点 + 自我认知 + 改进行动

```
「我有时会过度关注细节，这可能会拖慢我的进度。我已经意识到这一点，现在会给任务设定时间限制，并在『足够好』时主动征求反馈。在目前的岗位上，我也学会了在合适的时候把细节工作授权出去。」
```

### 「你为什么想离开现在的公司？」

**保持：**
- 正面（聚焦成长）
- 面向未来（而不是抱怨）
- 简短（不要过度解释）

```
「我在[公司]学到了很多，但我正在寻找[具体机会]，而目前的路径中看不到这样的空间。[公司]的这个岗位恰好提供了这一点——有机会去[具体的事情]。」
```

### 「讲一次你失败的经历」

**必须包含：**
- 真实的失败（不是凡尔赛式谦虚）
- 你学到了什么
- 你如何应用了这次经验

```
「我担任 PM 的第一年，在没有做充分用户调研的情况下上线了一个功能。这个功能在技术上没有问题，但用户觉得很难用，采用率只有 10%。我用惨痛的代价学到：做对的东西比把东西做对更重要。从那以后，我从不省略用户调研——现在在重大功能决策前，我至少会做 10 场用户访谈。」
```

### 薪资问题

**在不得不回答之前先转移话题：**

```
「我对薪资持开放态度，目前更看重找到合适的岗位。方便告诉我这个职位的预算范围吗？」
```

**如果被追问：**
```
「根据我的调研和经验，我的期望范围大致在 X 万到 Y 万之间，但我愿意就整体薪酬包（compensation package）进一步沟通。」
```

## 执行核对清单

完整的面试准备：
1. ✅ 从职位描述中分析出胜任力
2. ✅ 准备 8-10 个覆盖所有胜任力的 STAR 故事
3. ✅ 写好「介绍一下你自己」的自我陈述
4. ✅ 为可能的问题准备好答案
5. ✅ 充分调研公司
6. ✅ 准备好有质量的反问问题
7. ✅ 大声练习（并计时）
8. ✅ 准备好后勤事项（着装、路线、设备调试）
9. ✅ 面试前一天复盘
10. ✅ 面试后发送感谢信
