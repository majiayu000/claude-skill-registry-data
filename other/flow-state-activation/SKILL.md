# flow-state-activation

## When to Use

当需要进入高度专注、高效且愉悦的工作或学习状态时description

## Core Logic

# 执行步骤

1.  **满足心流前提条件**
    *   **输入**：一项待执行的任务。
    *   **操作**：
        a. **目标与规则清晰**：确保任务有明确目标（来自“perspective-framing-game”或独立设定）和清晰的执行步骤/约束。
        b. **挑战与技能平衡**：评估任务难度与自身技能。IF 任务过于简单（无聊），则增加规则复杂度或提高目标；ELSE IF 任务过于困难（焦虑），则拆解任务，从低级别挑战开始练习。
        c. **消除环境干扰**：物理上移除或屏蔽与任务无关的干扰源（如关闭通知、清理桌面）。
    *   **判断标准**：任务是否具有“清晰定义的目标、规则、且难度与能力大致匹配”的特点；工作环境是否简洁、无干扰。
    *   **输出**：一个已准备好的、结构化的任务环境。

2.  **启动专注执行**
    *   **输入**：步骤1输出的已准备任务环境。
    *   **操作**：开始执行任务的第一步。将全部注意力集中于当前步骤的动作和感官反馈上（“此时此地”），同时将最终目标保持在潜意识背景中。
    *   **判断标准**：注意力是否从“担忧结果”转向“体验过程”；是否开始感受到任务本身的细节。
    *   **输出**：注意力成功锚定在任务过程上。

3.  **维持与进入心流**
    *   **输入**：已锚定的注意力。
    *   **操作**：
        a. **持续行动与反馈循环**：执行动作 → 感知即时结果/反馈 → 根据反馈调整下一个动作。保持这个循环快速、顺畅。
        b. **IF 感到分心或停滞**：THEN 回顾步骤1中的目标和规则，检查挑战与技能是否失衡，或环境是否有新干扰，并进行微调。
        c. **ELSE (循环顺畅)**：继续执行，允许自己沉浸于行动-反馈的节奏中。
    *   **判断标准**：是否失去时间感，行动变得自发且高效，并从中获得愉悦感或满足感。
    *   **输出**：进入心流状态，高效完成任务。

# 输出格式要求
报告心流状态准备与进入情况：
1.  **前提检查**：目标/规则清晰度、挑战/技能平衡度、环境清洁度（可评分）。
2.  **启动状态**：注意力是否成功聚焦于过程。
3.  **心流信号**：是否出现时间感扭曲、行动自动化、内在愉悦感等特征。
4.  **中断处理**：如果未进入或中断，记录可能原因（如干扰、难度不适）。
