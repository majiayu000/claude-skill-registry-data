# 商品视频素材、生成与核验

取得已授权的视频素材，制作商品视频分镜、单场景或多场景内容并核验输出。区分素材获取、内容准备和实际模型生成的能力与费用。

## 选择任务模式

从用户目标与已有上下文选择下表中需要的模式，只读取对应能力指南；多步骤任务可组合少数相关模式。

| 模式 | 何时选择 |
|---|---|
| [已授权视频文件获取](references/capabilities/authorized-video-retrieval/workflow.md) | 使用作者提供下载或官方允许的导出途径取得文件，并核对可播放性 |
| [商品视频生成与核验](references/capabilities/product-video-brief/workflow.md) | 先写时间轴脚本，再由可用视频工具生成，检查画面连贯与产品还原 |
| [商品多场景视频制作](references/capabilities/product-multiscene-video/workflow.md) | 逐场景定义镜头、旁白和转场，再检查跨镜头商品身份与时间总和 |

## 执行与交付

1. 确认对象、平台/地区、数据期间和具体任务，优先复用同口径材料。
2. 阅读匹配模式的指南及其工具路由，使用当前真实可用的工具、官方连接或授权导出；没有能力时说明缺口。
3. 按该模式的执行手册处理。授权素材获取、分镜与生成分模式；保留下载权利、模型限制和费用范围。
4. 保留实际来源、时间、范围和 `FACT / ESTIMATE / ASSUMPTION / UNKNOWN`；未知值不填零，不混算不同市场与粒度。
5. 核对会话已有授权，已覆盖的动作继续执行并回读；缺失或扩大范围才补充确认。分析请求本身不授权下单、发布、退款或预算变更。
6. 交付模式要求的结果、证据和实际完成状态；将草稿、提交、最终生效与 `READY / HOLD / STOP` 分开报告。

共同执行约定见 [执行手册](references/playbook.md)，按能力查找工具见 [路由索引](references/tool-routing.md)。模式索引也保存在 `references/capabilities.json`，供本地搜索定位原名称。
