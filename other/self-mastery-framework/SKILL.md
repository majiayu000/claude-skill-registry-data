# self-mastery-framework

## When to Use

当个人希望提升自身在职业或社会中的不可替代性，以应对环境变化和不确定性时description

## Core Logic

# 执行步骤

1.  **特质识别与现状评估**
    *   **输入**：个人当前在职业/生活中的角色、面临的挑战、对未来的担忧。
    *   **操作**：对照“不可替代个体”的七个特质（自我实验、自我反思、自我发展、自力更生、自我教育、自给自足、自我掌控），逐一评估自身现状（例如：强、中、弱）。
    *   **判断标准**：能够清晰、诚实地为每个特质给出一个现状评级。
    *   **输出**：一份包含七个特质的个人现状评估表。

2.  **优先级排序与目标设定**
    *   **输入**：步骤1生成的个人现状评估表。
    *   **操作**：
        *   **IF** 评估表显示多个“弱”项：选择1-2个对当前环境挑战最关键的“弱”项作为优先提升目标。
        *   **ELSE IF** 评估表显示多为“中”项：选择1个对实现长期愿景最重要的“中”项进行强化。
        *   **ELSE** (评估表显示多为“强”项)：选择1个“强”项，设定将其转化为可展示、可交换价值的具体目标。
    *   **判断标准**：选定的目标特质与个人当前环境挑战或长期愿景有明确的逻辑关联。
    *   **输出**：1-2个明确的、待提升的“自我特质”目标。

3.  **行动方案设计**
    *   **输入**：步骤2确定的待提升特质目标。
    *   **操作**：针对每个目标特质，设计具体的、可重复的实践行动。
        *   **自我实验**：设计一个小型试错项目，解决一个具体复杂问题，记录过程与结论。
        *   **自我反思**：定期（如每日/每周）进行动机复盘，分析自身行为背后的驱动力。
        *   **自我发展**：规划学习一项新技能或培养一种新心态，并明确其如何对他人产生价值。
        *   **自力更生**：针对一个不满意的结果，制定一个完全由自己负责的改进计划。
        *   **自我教育**：选择一个未知领域，制定学习路径，并产出理解摘要或应用方案。
        *   **自给自足**：计算维持理想生活方式所需的资源，并制定一个获取计划。
        *   **自我掌控**：在面对逆境或诱惑时，预先制定并执行一个坚守原则的应对策略。
    *   **判断标准**：设计的行动方案具体、可衡量、与目标特质直接相关。
    *   **输出**：针对每个目标特质的详细行动清单。

4.  **价值外化与验证**
    *   **输入**：步骤3的行动方案执行成果（如项目结论、技能作品、改进结果等）。
    *   **操作**：将行动成果以某种形式（如报告、产品、服务、展示）呈现给外部受众（如同事、客户、社区），并寻求反馈。
    *   **判断标准**：外部受众能够理解并认可该成果所体现的价值。
    *   **输出**：外部反馈结果及对个人“价值感知”的验证结论。

# 输出格式要求
请以结构化报告形式呈现，包含以下部分：
1.  **现状评估**：列出七个特质的自我评估结果（强/中/弱）。
2.  **核心目标**：明确本次聚焦提升的1-2个特质及理由。
3.  **行动方案**：详细描述针对每个目标特质的可执行步骤。
4.  **价值验证计划**：说明如何将提升成果转化为外部可感知的价值并进行验证。
