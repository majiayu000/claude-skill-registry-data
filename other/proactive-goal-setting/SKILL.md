# proactive-goal-setting

## When to Use

当个体感到生活缺乏方向、陷入重复性任务或被动接受外部目标，导致焦虑、无聊或停滞时，调用此模型以重新获得对生活的掌控感和成长动力。description

## Core Logic

# 执行步骤

1.  **识别被动状态**
    *   **输入**：对当前生活状态的自我感知（如感到焦虑、无聊、缺乏意义）。
    *   **操作**：审视当前主要活动的目标来源。判断这些目标是**外部分配**（如考试要求、工作任务、社会期望）还是**自我设定**。
    *   **判断标准**：能够清晰列举出至少两项由外部驱动的核心任务或目标。
    *   **输出**：对当前处于“被动接受目标”状态的确认。
    *   **常见误区**：将外部目标合理化或内化为自己的目标，从而无法识别问题的根源。

2.  **确立自主目标**
    *   **输入**：步骤1的输出（确认被动状态）。
    *   **操作**：主动为自己设定一个明确、具体的新目标。该目标应指向未知领域，需要学习新知识、技能或探索新机会才能实现。
    *   **判断标准**：目标表述清晰，且实现路径对当前自我而言是未知的或具有挑战性的。
    *   **输出**：一个清晰的、自我设定的新目标。
    *   **常见误区**：设定的目标仍然是他人期望的变体，或目标过于模糊、缺乏挑战性。

3.  **规划连续目标**
    *   **输入**：步骤2的输出（一个清晰的自主目标）。
    *   **操作**：在开始追求当前目标的同时，开始构思或探索下一个潜在目标。建立“目标队列”的意识。
    *   **判断标准**：能够描述当前目标完成后，可能转向的大致方向或领域。
    *   **输出**：一个初步的、连续的目标设定心智模型。
    *   **常见误区**：只聚焦于单一目标，未建立目标间的连续性，导致当前目标完成后再次陷入方向迷失。

# 输出格式要求

输出应包含：
1.  **状态诊断**：明确指出当前主要目标的外部依赖性。
2.  **新目标陈述**：清晰表述一个自我设定的、具有探索性质的新目标。
3.  **后续方向**：简要说明为实现当前目标需要开始的探索，以及完成后可能衔接的下一个目标领域。
