# search-xiaohongshu

## 目标
在用户需要小红书笔记、真实体验或种草信息时，通过只读搜索和读取整理公开内容、链接、作者、发布时间与关键观点。

## 适用请求
- 查询小红书笔记、商品体验、旅行/美妆/生活方式等真实反馈。
- 对比多个笔记中的优缺点、价格、踩坑点和用户评价。
- 从给定小红书 URL 读取正文、图片文字线索或评论摘要。

## 首选通道
- 本 skill 走 skill-only：不使用 MCP、不新增 MCP 配置；优先 WebSearch/WebFetch、可用 skill、当前 Firefox 可见会话。
- 如果 `last30days-skill-cn` 或 `Agent-Reach` 已安装/可用，则用于只读搜索近期笔记，否则走兜底。
- 登录后可见内容优先复用当前 Firefox 已登录会话只读打开页面和读取可见内容；不可用时转公开搜索兜底。
- 如果 `feedgrab` 或 `url-reader` 已安装/可用，则用于给定 URL 抓取，否则用浏览器人工读取。

## 兜底通道
- 使用 WebSearch 组合关键词、小红书、`site:xiaohongshu.com` 或相关转载页面。
- 使用浏览器打开页面；遇到验证码、风控或登录要求时交给用户人工处理，不自动绕过。

## 操作流程
1. 明确主题、城市/品类、时间范围、是否需要真实体验或避雷信息。
2. 优先用首选通道做只读搜索；不可用时使用 WebSearch 和浏览器读取。
3. 读取笔记时仅记录可见正文、发布时间、作者公开信息、互动量和可见评论；全程只读搜索/读取，不发起新的登录流程、不下单、不私信、不发帖、不写入平台，也不点赞、收藏、关注或评论。
4. 对多个笔记交叉归纳，保留 URL 与原文片段，避免把营销内容当作事实。
5. 如果页面限制访问，说明限制并请求用户提供 URL、截图或人工完成验证码。

## 只读安全边界
- 只允许搜索、打开、读取、摘录和总结公开或用户授权可见内容。
- 不发起新的小红书登录流程；优先复用当前 Firefox 已登录会话，不绕过验证码、风控、App 限制或访问控制。
- 不点赞、收藏、关注、评论、发帖、私信、询价、下单或执行任何写入动作。
- 不保存或输出 Cookie、Token、手机号、二维码登录信息等敏感凭据。

## 已知限制
- 小红书 Web 页面经常要求登录、验证码或 App 打开，自动化读取可能受限。

- 图片内文字、视频内容和深层评论可能需要用户截图或人工辅助。
