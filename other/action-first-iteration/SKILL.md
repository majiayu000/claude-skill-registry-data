# action-first-iteration

## When to Use

当面对新任务或目标，因过度思考“如何开始”或“需要多久”而陷入拖延、焦虑，迟迟无法行动时。description

## Core Logic

# 执行步骤

1.  **识别并重构问题**
    *   **输入**：脑海中浮现的“我如何开始？”或“需要多久？”等疑问。
    *   **操作**：将这些问题识别为“对确定性的过度追求”或“对失败的恐惧”的信号。将核心问题重构为：“我能立即采取的最小、最简单的行动是什么？”
    *   **判断标准**：问题从寻求完美方案转变为寻找一个可立即执行的、微小的具体动作。
    *   **输出**：一个具体的、微小的行动指令（例如：“写下第一行草稿”、“给潜在客户发一封简短的介绍邮件”、“穿上运动鞋出门走5分钟”）。

2.  **执行最小化启动行动**
    *   **输入**：步骤1输出的具体行动指令。
    *   **操作**：不进行任何额外的计划或研究，立即执行该指令。设定一个极短的时间限制（如5分钟），专注于完成这个启动动作本身。
    *   **判断标准**：物理上或数字上完成了该启动动作（如文字已写下、邮件已发送、已走出家门）。
    *   **输出**：一个已完成的初始动作及其产生的初步结果或反馈。

3.  **基于反馈进行迭代**
    *   **输入**：步骤2输出的初步结果或反馈。
    *   **操作**：分析行动后的状态。**IF** 行动带来了新的信息或进展，**THEN** 基于此信息决定下一个最小步骤。**ELSE IF** 行动遇到阻碍或证明无效，**THEN** 将其记录为一条“不可行路径”的数据，并选择另一个不同的最小步骤重新尝试。
    *   **判断标准**：不再回到“如何整体规划”的思考，而是根据上一步的实际结果决定下一步的具体行动。
    *   **输出**：下一个具体的、微小的迭代行动指令，或一份关于“什么不可行”的经验记录。

# 输出格式要求

向用户清晰地呈现：
1.  **识别出的思维陷阱**：指出“总问如何开始”是对确定性的过度追求。
2.  **建议的最小启动行动**：基于用户目标，给出一个具体的、5分钟内可完成的行动建议。
3.  **心态调整提示**：强调“开始即行动”，并将早期尝试视为收集数据的过程，而非对最终成功的评判。
