# focus-matrix-framework

## When to Use

当需要系统性地理解、诊断和提升个人专注力，以优化工作效能和生活体验时description

## Core Logic

# 执行步骤

1.  **定义核心概念与锚点**
    *   **输入**：对当前生活/工作状态的模糊感知。
    *   **操作**：明确并写下你的长期愿景、核心目标、使命以及当前最高优先级的行动项。这些构成了专注的“锚点”。
    *   **判断标准**：锚点清晰、具体、书面化，并能激发内在动力。
    *   **常见误区**：锚点过于宏大或模糊（如“变得成功”），或与内心真实渴望脱节。
    *   **IF** 锚点无法明确或缺乏动力，**THEN** 返回步骤1，进行更深度的自我探索或价值澄清。

2.  **组织能量输入与过滤**
    *   **输入**：步骤1定义的清晰锚点。
    *   **操作**：以锚点为中心，审视并重组所有外部输入（信息、人际关系、饮食、财务等）。评估每一项输入：它是否支持你的锚点（未来）？如果是，则纳入并调整关注度；如果不是，则主动忽略或减少接触。
    *   **判断标准**：日常输入（如阅读内容、社交、饮食选择）与锚点的一致性显著提高，无关干扰减少。
    *   **常见误区**：被动接受所有信息，或仅进行表面时间管理而未触及能量源头的筛选。
    *   **IF** 发现某些输入难以判断或割舍，**THEN** 返回步骤1，检查锚点的优先级是否足够清晰，或该输入是否隐含了未被承认的价值。

3.  **锚定于当下经验并全情投入**
    *   **输入**：经过步骤2筛选后的、支持锚点的清晰环境与能量状态。
    *   **操作**：在执行与锚点相关的具体任务或互动时，将全部注意力从对未来的规划或过去的评判中收回，完全投入到当下的直接经验中。以“毫无保留”的状态行动或沟通。
    *   **判断标准**：进入心流状态，感受到时间扭曲，行动本身带来满足感，产出质量高。
    *   **常见误区**：身体在当下，思绪却飘向结果（焦虑）或过程评判（内耗），导致行动力打折。
    *   **IF** 无法进入当下状态，**THEN** 检查步骤2的能量输入是否存在干扰（如未处理的情绪、环境噪音），或返回步骤1确认当前行动是否与核心锚点真正对齐。

# 输出格式要求
输出一个结构化的专注力诊断与提升方案，包含：
1.  **清晰锚点**：列明愿景、目标、优先行动。
2.  **能量审计**：列出已识别出的支持性输入与待排除的干扰项。
3.  **当下行动计划**：指定一项即将开始的任务，并描述如何以“全情投入”状态执行。
