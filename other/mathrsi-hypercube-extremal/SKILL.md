# Hypercube extremal bounds

本技能处理 `G⊆Q_n` 的禁子图边密度问题。现成资产是无四环Q4旗证书；其它禁图或局部维数可借用研究动作，但须重新证明合法性、取商覆盖和高维平均。它不是一个黑盒“求最优上界”程序，也不负责恢复历史优化作业。

## 入口与返回位置

接收父调用者给定的阶段、原目标、具体义务、可用证明/代码和工作目录。独立调用时先固定这些内容；嵌入调用时直接沿原义务执行，完成scope后返父，阶段衔接由父唯一负责。

| 父阶段 | 此技能实际做什么 | 返回内容与父的下一动作 |
|---|---|---|
| prepare/survey | 对齐边密度、禁图及渐近/有限目标；查原包文献定义与已核基线 | 原文条件、量词与进口；合入同一次survey，不重启重复检索 |
| route-loop | 查共同补全是否缺失、群商是否丢相对朝向；设计工作集/全域区分探针 | 候选模型、失败见证、下一可执行义务；父决定改路线 |
| prove | 实现共同对象、同步取商、精确局部式或高维平均的指定部分 | 可调用引理/候选证书及尚缺输入连接，父接实际原图 |
| verify | 从冻结候选重建整数Gram，重计完整合法域，核解析平均的假设 | 精确有限结论、覆盖及原题连接状态；回原verify，不嵌套整套proof-checker |
| handoff | 给已核证书、常数、命令、进口与不能随包重跑的范围 | 父组织正文/wiki/包；本技能不重复启动交付 |

新题最少要知道：`Q_n`边编码、禁图、密度分母、原始对象量词、目标是有限n还是极限、当前候选的真实文件。若只收到一个小数，先找到其证书和舍入方向；没有证书时保留为探索值并继续可独立完成的理论工作。

先读 [mathematics](references/mathematics.md)。需要优化时再读 [failures-and-search](references/failures-and-search.md)；验证或搬迁时读 [reproduction](references/reproduction.md)。完整推导在 [原理论guide](../../archive/source/guide/02_THEORY_AND_CONSTRAINTS.md)与[refined报告](../../archive/source/certificates/Q4_refined_certificate_20261027/研究报告.md)。这些是现成科学内容，整理层不替代其证明。

## 1. 固定真正的极值问题

`Q_n`有`2^n`顶点和`n·2^(n−1)`边，图边是Hamming距离一。Erdős86目标是每个ε>0、充分大n的C4-free子图密度≤1/2+ε。一般N点C4-free图、顶点诱导密度、固定Q4最大边数都不是这个量词。

对新任务把原图、局部图、旗/根和证书矩阵分开命名，保存各自是否合法、是否取商、是否实际来自原图。不要把PSD当作单个局部图应满足的条件；PSD用于根条件频率的平均，逐图联合矩阵可有负特征值而完全合法。

历史参考Baber 0.60318定位在随包[文献](../../archive/source/literature/)与guide。若用户任务固定该比较即可使用；若声称当前最强或无人做过，交父survey作实时查新，不能以本插件历史快照代替。

## 2. 让局部观察来自同一张图

Q4分层写成`K=(A,B,S)`，A、B是同坐标Q3无四环图，S是层间边的位置集。先证明新跨层四环恰对应A∩B的边及其两个端点处层间边，从而合法性等价于S为A∩B独立集。

然后从同一个K生成所有隐藏方向观察。若原模型只保存分别合法边际，找一组不能共同补全的边际作为区分探针，或直接以完整K逐图约束替换独立边际。共同域建立后检查旧一致性等式是否已逐点冗余，避免重新求解重复约束。

此动作交付的是共同来源定义、合法性等价和从任意原局部图到枚举输入的映射。表里有很多K不等于映射已证明。对其它维数/禁图先重证对应等价，不能照搬独立集式。

## 3. 同步运输共享根

读取根面、两个外方向旗、根稳定子和状态编码。最终Q4五面块状态数240/212/190/187/170，对应根掩码0/1/3/6/7；另有9状态顶点块。

同一根下两旗必须同时受同一个群元素作用。分别规范化两个旗虽得到有效松弛，却会抹掉同角/邻角/对角；需要加强模型时保留标号或使用同步旗对轨道。写出状态置换`P_g`和`Qbar=平均 P_g Q P_g^T`，说明根/边编码同时怎样运输及PSD为何保持。

若宣称包含旧模型，给正向映射`E Q E^T`及群平均，不以维数更大或浮点最优值更好替代包含证明。旧六块与最终六块定义不同，不能按块数认同一模型。最终证书独立逐图核验不依赖旧嵌入的浮点自检。

## 4. 有信息量地搜索候选

冻结当前模型和合法域。工作集只负责生成候选，全域分离负责发现违反行；保存restricted值、当前full值和已接受best，full未改善不能覆盖best。

先用已有搜索源码判断要改什么。原materialize要求已省略的五表；使用[过滤副本物化工具](../../tools/materialize_search.py)恢复deduplicated别名，再按[接续搜索命令](references/reproduction.md)重建表和evaluate.so，不能直接在稀疏archive运行生产者。原 `column_lift.py` 从秩一非负列保持PSD，以LP对偶定价找新增方向，并定期完整评价；这是可借用的具体算法，不要求新题固定3500行/300补行或原seed。若工作集优、全域差，返回最高违反K并补行；若只是定价负特征值，记录它属于对偶定价矩阵，不误判正式Gram不PSD。

score含正负修正，不能只扫描最密或极大图。原最坏mask只有17边，已经给出这种筛选的实际失败理由。候选矩阵变化时可复用合法域与几何覆盖，但所有分数必须重计；整数舍入后再次全域计分。探索资源用尽时交最好已认证证书与未认证候选，不能把求解器stop状态当数学接受。

## 5. 精确接受有限证书

冻结证书重放使用原`verify_final_q4.py`；它刻意固定历史C/M_F/M_v，不能接受新候选。对新候选使用[check_q4_candidate.py](../../tools/check_q4_candidate.py)，传实际JSON与新scratch目录，限定**同一六块状态顺序**、维数240/212/190/187/170/9、根掩码0/1/3/6/7及显式`q5_cuts=[]`；模型变了另证编码并改checker。它以target=-1从完整域求新C，不信输入bound元数据，并由当前矩阵重算M_F/M_v，见[命令及两次真实使用](../../evidence/candidate-inputs/README.md)。不要凭目录的Q5名称判内容。`Q=L L^T/D²`给精确PSD；群平均仍PSD。使用上述工具（冻结证书重放时用原包装器）先计算整数上界，确认C++累加不溢出，再运行完整几何checker。

检查器应核：Q3完整合法域、层对自同构覆盖、所有合法S、最小隐藏方向切片覆盖、每图直接整数计分。读取实际退出码及EXACT_MAX；prepare-only只核因子/元数据，不能关闭全域义务。命令和输出含义见复现reference。

完成有限核验后只报告：所有合法Q4满足该score≤C，及本次实际代表/补全计数。不要把3312331叫作非同构图数，也不要因换一份矩阵仍沿用旧最坏图分数。

## 6. 接回任意原高维图

在原C4-free `G⊆Q_n`上随机取坐标Q4，证明期望边密度等于原ρ。固定根面和外方向频率，应用有放回/无放回关系；顶点两方向对另算相交误差。精确有限证书与这段解析桥梁是两个独立义务，必须同时满足才推出渐近界。

最终历史值有`M_F=1288810336780277/1250000000000000`、`M_v=324664893404033/625000000000000`。由最终矩阵重算这些值，不代入旧证书常数。证明对n≥4有

`ρ(G)≤C+M_F/(n−3)+M_v(4n−6)/((n−2)(n−3))`。

五根型互斥，面误差取最大。没有假设边独立、正则或空面均匀。令n趋于无穷得到π≤C；单个有限n的数值上界则保留修正项。新模型增加块或改变抽样时重新推导误差，不能从历史O(1/n)直接移植常数。

## 7. 返回、失败回流与恢复

返回父的内容是精确命题、真实输入、覆盖/算术/解析桥梁各自结果、证书/日志位置及剩余义务。局部核验成功回当前prove继续连接，完整verify才组织原定理接受。

失败按对象定位：合法域生成错则修覆盖；新矩阵超分则回搜索；PSD精确化失败则保留浮点候选重构因子；原平均不适用则回理论路线，不通过调容差掩盖。未知当前文献进口交定点survey后回原义务，不重新调查整个领域。

断点保存共同对象编码、群作用、冻结模型、已接受best、失败K及完整命令。新研究写自己的wiki，原archive不写。历史证书能支撑本插件工具使用，不能证明MathRSI通用效率或一次新任务已经解决。

## 8. 有限维极值与上下界协同循环（v6 扩展）

除基础六块 `Q4` Gram 证书外，`v6` 新增三类经过实战检验的领域机制（均从各自研究运行提炼，不改动历史 `v3` 归档）：

1. **渐近 COP + 三次型 + 广义超几何度数势（[asymptotic-05912](../../archive/asymptotic-05912/README.md)）：** 在四维旗代数上叠加基于 `Q4` 交集图必无三角形的 35 项完全正（COP）割、29 项三次型（定理 `T3 ≤ 0.5912405943`）及 `m = 1024` 广义顶点度数势（定理 `T4 ≤ 0.5912405942`）。高维传递必须附带 `(v, S, T)` 超几何条件期望五行塔式论证（见 [mathematics](references/mathematics.md)），不可默认固定 `m` 的势对 `n > m` 自动逐点单调。当浮点修补残差已超过单轮增益（如 `0.5907` 拟合的可行性残差 `3.9×10⁻⁴`）时立即停止外层迭代，严禁将未认证 CP 拟合写成已证屏障；任何在采样池上成立的高阶证书（如早期被撤回的 `Q5` `0.5899`）必须通过完整合法域核验与独立重算，谨防二次项系数漏乘组合重数。
2. **有限维多测度同图拉回与解析度下界（[q8-683](../../archive/q8-683/README.md)）：** 对固定维数 `Q_n`（如 `ex(Q8, C4) ≤ 683`，`same-family/provisional`），在同一张候选图 `H ⊆ Q8`（`|E(H)| ≥ 684`）上耦合均匀 `Q4` 补全测度、三度边入射测度与全局顶点度测度，将 83 条活跃不等式精确有理组装后在全部 `13,150,453` 个带标记 `Q4` 补全上逐一整数穷举，并用解析凸包下界与前置 `Q6` 子面导入闭合有限维差值。对于部分轨迹未随包重放的有限维结果（如 [q7-304](../../archive/q7-304/README.md)），严格分开已验证的显式构造（下界 `≥ 304`）与原包报告但本轮未复验轨迹的上界（`≤ 304`）。
3. **上下界协同搜索（[cube_coevolve](../../tools/cube_coevolve/README.md)）：** 对接 Base [primal-dual-coevolution](../../../../base/skills/mathrsi-route-loop/references/primal-dual-coevolution.md)。配置中显式分离 `primary_proof_goal`（如证明 `ex(Q8, C4) ≤ 682`，仍开放）与对抗反例搜索目标 `goal.target`（如寻找 `683` 边合法图）；`quality_band` 只用于聚焦亲本与统计采样，反驳必须在**全部归档图**上执行。未反驳的不等式仅标 `empirical`，经 `proof_obligations.json` 导出后回 `prove` 做全域枚举、SAT/DRAT 或解析证明。
