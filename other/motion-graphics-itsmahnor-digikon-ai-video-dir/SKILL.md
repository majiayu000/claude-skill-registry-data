# motion-graphics

## Inputs
Scene plan with overlay text, retrieved animation recipes, platform specs (verified only), brand rules.

## Procedure
1. Keep each overlay short (the schema limit is 120 characters) and legible for its scene length.
2. Pick an animation recipe for each overlay and fill parameters within range.
3. Place text inside the platform safe area. If no verified safe-area spec exists, keep text away from the top and bottom edges and say that the spec is unverified.
4. Caption **styling and placement** belong to you; caption **timing** belongs to editing-director.
5. Use one dominant motion per scene.

## Never
- Describe motion in free text instead of choosing a recipe.
- Write animation code.
- Put text on a scene that has no overlay entry, or exceed the overlay limit.
- State a claim that is not in the claims register.
