# Inspire Time

## Qualification

Read [references/qualification-criteria.md](references/qualification-criteria.md). Capture only when the insight changes how the user can act or judge in another real situation.

## Workflow

1. State the original problem and trigger evidence.
2. Express the transferable insight without turning it into a universal rule.
3. Record when it applies, its boundary, and a possible counterexample.
4. Design one observable practice using [references/insight-to-practice.md](references/insight-to-practice.md).
5. Ask before writing or activating the practice.
6. Track status and evidence using [references/evidence-and-status.md](references/evidence-and-status.md).
7. Use [assets/inspire-time-template.md](assets/inspire-time-template.md), omitting unsupported fields.

Route personality hypotheses to self-observation and subject-matter learning to its learning note.
