# Prompt Engine

## Instructions
1. Set tipi: TITLES | TEAMS | EXECUTION
2. `PROMPTS/{tip}/{slug}.md` indeks + `P001.md`… alt dosyalar
3. Hedef 122 prompt/set — fazlı üretim
4. 🚩 900M char/prompt imkânsız — dürüst faz planı

**Hibrit:** `/prompt-uret` inline.

## Examples
- `PROMPTS/TITLES/hq-ceo.md` — index skeleton

## Performance Notes
- Structured prompt 4–12 KiB sözleşme (holding red_flag uyumlu)

## Troubleshooting
