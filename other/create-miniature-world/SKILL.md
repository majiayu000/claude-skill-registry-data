# 微缩摄影 Skill · Miniature World

把一件日常物件拍成小人国里的一张照片：巨大的是物件，小的是人；物件的某几个部位从相机这个位置看成了别的东西，那里正在发生一件一眼能读的事。策划和拍摄是同一件事：相机在哪、什么巨大、谁小、哪些部位成了什么、笑点是什么，一段话写完再出图。中文沟通，用户指定语言优先。

入口：一个物件名或一张商品照，例如“把这个做成微缩摄影”。默认两个想法各出一张；说“先看方案”只交图卡等用户选；只要文字就不生图。用户已指定创意直接做，不另凑候选；用户说了机位或景别（特写、整件入画、俯拍）时图卡第 1 条照办并照常过门槛，与看图第二问冲突的机位（只见头顶的正上方）先说明会失去“相机在场景里”再按用户；不主动问景别。

## 模式
- **产品保真**（有商品图或指定商品时默认）：物件可见的形状、部件、材质、颜色、文字原样；不挖空、不改形，用户明确允许才放开。
- **自由创作**（只有普通物件名时默认）：可拆、弯、组合，保留用户锁定的特征。
- **原作复刻**（用户指定原图）：沿用原图的物件、人物、比例、画幅；标明来源与学习性质。

## 流程 Workflow（五步，每步只读对应的参考）
1. **看物件与底图**：实际看图，分清商品图、风格参考、待改成图；只有名字就按名字做，不声称看过图。有实物照时先按[制作路线](references/making-route.md)判它能不能当底图。
2. **写一张图卡**：按[一张图卡](references/picture-card.md)把创意和拍摄写成一段话——相机在哪、看见哪三件东西；什么巨大；谁小、人高约等于哪个部件；物件哪个（或哪几个）部位成了什么、从这个机位凭什么像；正在发生什么事、笑点或发现是什么；不加什么。联想不够时按卡上的方法在[田中案例](references/tanaka-cases.md)里找同类 2–3 张，取想法的机制，不抄人数、配件和标题。
3. **选路线、写提示**：按[制作路线](references/making-route.md)在“直接生成”与“编辑实物照”里选一条，提示照该路线的骨架写。生成器已证实不听的事（人偶精细度、清晰带强度、比例句、朝向）用参考图、底图和路线解决，不堆措辞。
4. **出图**：用当前宿主实际提供的生图能力；传入商品图和一张 Preiser 人偶实物照（[assets/figure-refs/](assets/figure-refs/README.md)；用户自己的参考库优先）；田中原作只用来对照，不传给生成器。每案一张，失败不重试。
5. **看图与交付**：按[看图](references/review.md)先答两问（在发生什么事；像不像小人在巨大物件的世界里），取同类田中原作并排写三处最大差异，记商品保留项保持/变化。交用户时只问一句“这是什么场景”，原话照录。助手自评只作记录，用户第一读是闸门。

## 闸门与授权
- 授权：用户要求做成微缩摄影即按默认张数出图，说“先看方案”“只要提示词”只交文字；编辑只在用户点名那张上做；付费或外部服务、改形、追加张数都要用户明确说。
- 能力诚实：没看图不说看过，没生图不说生成，不能传参考图就说明；不切换付费或外部服务；“保留原样”不等于像素保护，只有编辑路线实际保留并核对过才这样说。
- 预算：每案 1 张首图；编辑只在用户点名的那张上做，至多 1 次；失败不重试、不自动追加；用户已判失败的图保留结论。
- 版权：田中原作图片只在本机对照，不复制、不传入生成器、不发布；案例卡只记想法与拍法。
- 本机执行：实际发送的提示与成图同目录存档，出图后不改；成图写进项目 `outputs/`，不覆盖已有文件；用户私图不入库。

## 状态词
草图（图卡已写，未出图）／候选（已出图，用户未读）／用户认可（用户第一读落在物件之外的世界并说好）／待修（用户点名要改）／阻塞（底图不合格、能力缺失或预算用尽，说明原因停下）。不自造其他标签。

## 完成条件（验收）
图卡已写；路线与底图判定已记；提示已存档；每张成图已实际看过并写了两问、并排三处差异、保留项记录；成图已按宿主支持的方式展示；用户第一读原话已记。这些是交付条件，不代表图已合格。

## 用户反馈
| 反馈 | 处理 |
|---|---|
| 没看懂 / 没故事 | 回图卡：换部位或换事件；不加标题、不堆道具去解释。 |
| 不像小人国 / 人太大 / 拍得不像 | 先查路线与底图（机位、物件在画中大、光），再查图卡“人高≈哪个部件”；不靠改写大小句或缩人。 |
| 不像商品 | 回商品图按保真修具体部件；考虑换编辑实物照路线。 |
| 换个创意 / 更有趣 | 换图卡里的部位或事件，说明与旧案的区别；保留商品依据。 |
| 改这张 / 不要小人 / 再来一张 | 只改点名的部分；后续沿用；逐张生成，不拼格。 |

以成图为主、说明简短；不主动附长提示或评分表。
