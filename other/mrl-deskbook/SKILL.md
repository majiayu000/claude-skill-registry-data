# Manufacturing Readiness Level (MRL) Deskbook (Version 2025)

**Source:** OSD Manufacturing Technology Program with the Joint Service/Industry MRL Working Group. US Government work, public domain under 17 U.S.C. 105; Distribution A, approved public release; DOPSR Case # 25-T-1829. Advisory best practice, not a DoD requirement. See `LICENSE`.

## When to use

Use when a program, project, or supplier question is about manufacturing maturity, producibility risk, MRL targets on an acquisition pathway, running an MRL Assessment, writing a Manufacturing Maturation Plan, putting maturity into contract language, adapting criteria, or screening operational-technology cybersecurity on the shop floor.

**Prerequisites:** none. Plain Markdown. No MCP server, API key, or licence tier needed at runtime.

## How to Use This Skill

- No arguments: read the Chapter Index and open the chapter that matches the question.
- Topic question (thread, environment, MMP, contract language, OT screening): use Topic Index `chNN` tokens.
- Lifecycle question (MSA, TMRR, EMD, LRIP, FRP, MTA, UCA): start with `ch03`, then assessment and MMP chapters.

## Scope and Limits

Manufacturing readiness and producibility risk for defense acquisition practice. This skill is not a technology-readiness (TRL) guide, not a full systems-engineering process model, not a cost-estimating or schedule guide, and not a deep cybersecurity audit method. Appendix A criteria matrix cells are not reproduced. The Excel Users Guide remains an external workbook. DoDI 5000.88, FAR, and DFARS are named only, never quoted.
