# 轮式底盘产品规格

## Purpose

把轮式机器人场景转成可测试的底盘和移动系统要求，连接机械、电气、控制、导航、调度、安全与现场运维，避免只用最高速度和载重描述产品。

## Input

可提供目标场景、路线/地图、载荷、尺寸、地面、坡度、人流、站点、充电方式、现有底盘方案或接口要求。没有数字时先提供指标框架，不编造目标值。

示例：`使用 mobile-base-product-spec，为仓库周转箱搬运机器人定义轮式底盘规格和验收场景。`

## Key Concepts

- **拓扑决定约束**：差速、阿克曼、全向和独立舵轮在转弯空间、侧向移动、地面适应、成本和维护上不同。
- **整机边界优于底盘边界**：载荷重心、上装摆动、传感器遮挡和急停距离会改变移动能力。
- **ODD定义性能**：速度、定位和避障指标必须绑定地面、人流、光照、载荷和网络条件。
- **到站与对接是闭环**：导航到附近不等于完成装卸、充电、电梯或工位交互。
- **恢复能力决定运营效率**：干预率、恢复时间和可诊断性通常比单次演示速度更重要。

## Application

### 1. 定义任务和整机包络

记录整机长宽高、最小通道、载荷范围、重心变化、上装动作、转弯空间、地面接触、工作时间和人机混行。明确空载、额定载荷和最不利载荷状态。

### 2. 比较底盘拓扑

- **差速**：结构简单，可原地转向；关注轮胎打滑、地面磨损和重载转向。
- **阿克曼**：高速和长距离效率较好；关注转弯半径、倒车和狭窄空间。
- **全向/麦克纳姆**：侧向机动强；关注地面要求、越障、效率、振动和轮子磨损。
- **独立舵轮**：机动与承载可兼顾；关注控制复杂度、校准、成本和故障模式。

以任务覆盖、ODD、成本、供应和维护证据选型，不只比较自由度。

### 3. 写移动与通过性规格

至少覆盖速度区间、加减速度、制动距离、转弯半径/横移、定位到站、重复对接、坡度、横坡、门槛、缝隙、地面摩擦、积水/粉尘、振动、噪声和稳定性。使用 [指标字典](references/mobile-base-requirements.md)。

### 4. 写导航与交通交互规格

定义建图/定位设施、静态和动态障碍物、会车、跟随、窄通道、盲区、路口、门禁、电梯、交通规则、地图变更、定位丢失和人工引导。区分底盘控制、导航系统和调度系统责任。

### 5. 写能源、充电与任务连续性

统一续航口径：载荷、速度、地面、上装功耗、待机、环境温度和电池老化。定义低电阈值、任务抢占、自动回充、对接失败重试、充电互锁、换电和电池维护。

### 6. 写安全与恢复

定义速度/区域限制、人员检测、保护停止、急停、掉电制动、防溜坡、碰撞缓冲、牵引/手推、远程接管和现场救援。安全目标和停距需由合格工程与安全负责人确认。

### 7. 建立验收矩阵

| 场景 | 载荷 | ODD条件 | 前置状态 | 期望行为 | 指标 | 样本/时长 | 失败与恢复 |
|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |

覆盖正常、边界、故障、长稳和维护场景。输出规格时标记每项为“必须/应该/可选”，并给出证据来源和责任团队。

## Examples

### 仓储物料搬运机器人

除额定载荷外，还需定义牵引或承载方式、偏载、坡道起停、防溜坡、站点对接、峰值调度、行人/车辆混行、室内外切换和雨水带入后的地面摩擦。

### 室内配送机器人

最高速度不是主指标。更关键的是门槛通过、电梯交互、窄通道会车、到站误差、安静运行、夜间充电和用户挡路时的等待/绕行/求助策略。

## Common Pitfalls

- **底盘与上装分开验收**：整机重心和功耗使指标失效。修正：按整机最不利工况测试。
- **只测空场导航**：真实人流下干预率激增。修正：建立交通密度和动态障碍分级。
- **续航口径模糊**：实验室续航无法支持班次。修正：固定任务循环、载荷、温度和老化条件。
- **没有救援设计**：故障设备阻塞现场。修正：定义手动释放、牵引点、救援时限和权限。
