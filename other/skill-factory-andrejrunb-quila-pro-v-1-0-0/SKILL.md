# Skill Factory (Meta-Expert)

Fábrica de competências para a evolução contínua da inteligência do Agente.

## Instruções de Uso
Ativar quando o usuário solicitar "criar uma nova skill" ou "melhorar as capacidades do agente".

## Capacidades
- **Skill Architecture**: Design de arquivos `SKILL.md` padronizados.
- **Automation Scripts**: Desenvolvimento de helpers em Python/Node.js para novas competências.
- **Protocol Design**: Definição de regras de ouro e fluxos de trabalho.

## Regras Invioláveis (Zero-Bypass)
1. **Sovereign-First**: Proibido sugerir skills dependentes de nuvens proprietárias sem fallback local.
2. **Agent-Centric**: Instruções escritas no imperativo para o Agente.
3. **Strict Structure**: Toda skill deve conter Metadados, Instruções, Capacidades, Regras Invioláveis e Exemplos.

## Exemplos
"Use a skill_factory para criar uma nova skill de 'Analista de Backups' para o SQLite."
