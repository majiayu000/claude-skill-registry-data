# 落地页与转化链路审计

国内落地页的核心矛盾：素材承诺 vs 页面兑现、链路长度 vs 流失、平台规范 vs 转化组件。

## 数据契约

页面载体（基木鱼/橙子建站/微信原生推广页/小程序/自建 H5/电商详情页）、URL 或截图或文案、流量来源（哪个平台什么素材）、转化目标（表单/电话/企微/下单/私信）、当前转化率与行业参照（可选）。有热力图/漏斗数据更好。

## 审计清单

### 1. 一致性（最常被忽视）

- 素材里的价格/优惠/卖点，页面首屏是否立刻兑现？素材说"9.9 体验"页面首屏找不到 → 直接流失。
- 人群语气一致：抖音口语化素材配严肃官网风页面 = 断裂。

### 2. 首屏与加载

- 移动 3 秒原则：加载超 3 秒流失过半；自建 H5 查图片体积/JS 阻塞；平台建站工具（基木鱼/橙子）天然速度达标但组件受限。
- 首屏三要素：这是什么（价值主张）+ 对我有什么用（人群场景）+ 下一步做什么（CTA）。
- 首屏必须有转化组件或锚点，不要让用户滑三屏才看到表单。

### 3. 转化组件

- 表单：字段 ≤3–5 个（每多一个字段流失明显）；验证码/隐私勾选合规但不繁琐；提交后反馈明确。
- 电话：一键拨打 + 客服在线时段匹配；非工作时段的流量给留言/企微兜底。
- 企微加粉：活码分流、欢迎语自动发、加粉后 5 分钟内首次触达（链路见 private-domain-sop-cn）。
- 微信生态：原生推广页→小程序/企微的跳转是否合规（诱导分享/强制关注会违规）；小程序路径参数带渠道（见 tracking-setup-cn）。
- 电商详情页：首图点击率、价格锚点、SKU 结构、评价/问大家、销量展示、客服响应。

### 4. 信任与合规

- 资质展示（行业必需：医疗/金融/教育）、真实案例/评价（不得虚构）、隐私政策。
- 极限词与功效宣称（详见 ad-compliance-cn）；落地页违规会连累账户拒审/处罚。
- 百度移动落地页规范：首屏广告面积、弹窗/悬浮组件限制（冰桶算法相关），违规影响收录与广告审核。

### 5. 漏斗定位

有数据时按"到达→首屏→浏览→组件曝光→提交→有效"逐层算流失，指出最大漏点；无数据时按清单给假设排序，并建议埋点/热力图验证。

## 输出格式

```
## 落地页审计（载体 / 来源 / 目标）
**最大漏点判断**：__（证据或假设）
### 🔴 必改（一致性/加载/合规）
### 🟡 建议改（组件/信任/结构）
### 改版方案：首屏文案示例 + 组件布局 + 验证方式（A/B）
置信度 + 缺数据说明
```

## 约束

- 无法访问 URL 时基于截图/文案分析，并注明未验证加载速度等技术项。
- 不给"加弹窗逼转化"类伤害体验与违规的建议。
- 改版文案遵守广告法；医疗/金融等特殊行业先确认资质再给方案。
