# Next.Js App Router

Use this skill when working on Next.js App Router tasks.

## Workflow

- Inspect Next.js version, router usage, rendering modes, cache strategy, middleware/proxy, and deployment target.
- Keep server-only code out of client components and validate boundaries with typecheck/build.
- Coordinate with `ls-nodejs-nextjs` for current version checks and broader Node/React guidance.

## Boundaries

- Inspect the target repository before making changes.
- Prefer existing project patterns, declared package managers, and documented validation commands.
- Do not expose secrets, credentials, private user data, or production account identifiers in source, examples, or logs.
- When external APIs or current vendor behavior matter, verify against official docs before implementation.
