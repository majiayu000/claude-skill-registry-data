# 竞品深度分析

浅层竞品调研不足以获取真正的市场优势。本框架将情报收集与战略分析结合，从执行流程到底层理论一体覆盖。

---

## 前置：竞品分级

先对竞争者分类，集中精力在最重要的对手上：

- **直接竞争者**：解决相同问题、服务相同客户——重点分析对象
- **间接竞争者**：解决相同问题但方式不同，或服务不同客户
- **标杆竞争者**：行业领导者，定义了客户对体验的基准预期

**建议范围**：3-5 个直接竞争者、2-3 个间接、1-2 个标杆。80% 精力放在前 3 名直接竞争者。

---

## 第一阶段：六层情报框架

针对高优先级竞争者，逐层提取：

### 第一层：战略与定位
- 核心价值主张（品牌口号/首页标题）
- 目标客户画像（ICP）：他们明确服务谁？
- 被忽视的细分群体：他们在忽略谁？
- 品牌语气：权威型 / 活泼型 / 技术导向 / 平易近人

### 第二层：产品与功能
- 核心功能解决的"待完成任务"（JTBD）
- 产品复杂度：轻量工具 vs. 一站式平台
- 技术壁垒：专有技术还是 API 封装？
- 集成生态：兼容哪些主流平台？

### 第三层：定价与商业模式
- 各层级定价（入门 / 专业 / 企业）
- 计价指标：按用户数、席位、用量还是固定费用？
- 转化漏斗：Freemium / 限时试用 / Demo 申请
- 价格心理锚定手法（"最受欢迎"标签、年付折扣等）

### 第四层：营销与流量
- SEO：核心关键词与外链来源
- 付费广告：Meta 广告库 / Google 透明中心查看在投素材
- 内容营销：博客 / YouTube / 社媒的内容聚焦方向
- 合作伙伴：联盟计划、代理商认证体系

### 第五层：用户评价挖掘（信息金矿）
从 G2、Trustpilot、App Store、Reddit 收集每个竞品 20+ 条评价，分类：
- **功能缺口**："我希望它能做 X……"
- **体验摩擦**："操作步骤太繁琐……"
- **定价敏感**："功能这么少价格却这么高……"
- **支持失职**："等了 48 小时没有回复……"
- **上手门槛**："学习曲线太陡……"

> 基准：若 30% 的评价提到同一痛点，即为结构性市场机会。

### 第六层：SEO 与内容情报
- 竞品主导的"商业变现关键词"
- 内容空白：他们忽略了哪类内容？
- 域名权威度：决定你应攻头部词还是长尾词

## 第二阶段：竞争矩阵评分

构建横向对比矩阵，关键维度用 1-5 分评分：

| 维度 | 竞品 A | 竞品 B | 我们 |
| :--- | :--- | :--- | :--- |
| 价格区间 | $$$ | $$ | $ |
| 配置便捷度 | 2/5 | 4/5 | 5/5 |
| 核心功能完备性 | 有 | 无 | 有 |
| 移动端体验 | 3/5 | 5/5 | 4/5 |
| 支持响应速度 | 1/5 | 3/5 | 5/5 |

---

## 第三阶段：识别可利用的市场空白

空白只有同时满足**三重判定标准**才算可利用：
1. **普遍性**：多个竞争者共同存在该弱点
2. **有据可查**：客户正在评价中积极反映
3. **可解决**：你能在现有技术与预算内修复

## 第四阶段：战略分析工具（选用）

根据需要选择以下框架深化分析，详细用法见 `references/frameworks.md`：

- **波特五力**：评估行业吸引力与竞争强度
- **蓝海战略（四项行动框架）**：识别价值创新机会
- **定位图**：可视化竞争空间，找到市场白地
- **差异化路径**：产品 / 服务 / 品牌 / 价格四条路径

---

## 第五阶段：确立差异化切入点

用**独特定位公式**提炼核心 Hook：

> "唯一一款专为 [特定受众] 打造的 [产品品类]，通过 [独特方法论] 解决 [特定痛点]。"

**验证清单：**
- 是否一看即懂？
- 是否能维持至少 6 个月的防御性？
- 是否针对了第一阶段发现的前三大投诉痛点？

**定位声明框架：**
```
针对 [目标客户]
他们面临 [需求或痛点]
我们的产品是 [产品品类]
能够 [核心价值陈述]
与 [主要竞品] 不同的是
我们 [核心差异化陈述]
```

## 第六阶段：持续监测

| 频率 | 动作 |
| :--- | :--- |
| 每周（5 分钟） | Google Alerts 监测竞品新闻与融资动态 |
| 每月（30 分钟） | 审阅 G2/Trustpilot 最新 5-10 条评价 |
| 每季度（2 小时） | 刷新竞争矩阵，根据新功能发布调整路线图 |

## 常见误区

- **功能模仿陷阱**：不要复制他们有的，要构建他们客户渴望却得不到的
- **忽视"维持现状"**：最大竞争对手往往是"什么都不改变"或"继续用表格"
- **确认偏误**：同样要研究竞品的最佳实践，确保满足行业基线标准
