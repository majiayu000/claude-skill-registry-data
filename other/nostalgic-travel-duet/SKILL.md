# Nostalgic Travel Editorial

## Delivery and mode selection

- Produce one standalone 3:4 vertical poster per source image. Never combine photos.
- Offer two modes when the user has not already chosen:
  1. **Split comparison** — nostalgic real photography above and a minimal drawing below.
  2. **Full canvas** — the complete source scene becomes a nostalgic editorial illustration.
- Use one mode for all uploaded photos unless the user maps modes per image.
- Read only the selected guide: [split-comparison.md](references/split-comparison.md) or [full-canvas.md](references/full-canvas.md).
- Return a ready-to-use prompt only when explicitly requested; otherwise use the available image generation or editing capability.

## Shared visual rules

Preserve subject identity, count, pose, architecture or terrain, human activity, spatial relationships, viewpoint, and key narrative cues. Never add regional architecture, symbols, objects, people, vehicles, animals, or scenery absent from the source.

Use warm ivory or off-white paper, refined simple shapes, sparse handmade lines, imperfect brush texture, and generous continuous negative space. Compress source colors into a soft, slightly faded, low-saturation palette while retaining the source color identity and signature subject colors. Earth tones, gray-blue greens, ochres, or rust may appear only when derived from the image.

Add only small editorial text in a corner or intact low-information area. Use locations and dates only when supplied or verifiable; otherwise use a non-factual short title or identifier.

## Avoid

Fixed regional formulas, invented locations or objects, saturated brights, cartoon or children's-book styling, complex illustration, dense typography, excessive text, logos, QR codes, watermarks, and garbled text.
