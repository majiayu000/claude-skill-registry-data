# survival-mode-focus

## When to Use

当因“战术压力”或外部紧急事件而处于高压力状态时，需要将这种压力有效转化为极度专注的心流状态，以最高效率推进任务。description

## Core Logic

# 执行步骤

1.  **接纳并引导压力感知**
    *   **输入**：由外部约束引发的焦虑感、紧迫感等压力情绪。
    *   **操作**：承认压力的存在，并主动将其认知重新框架为“专注的能量源”和“过滤干扰的信号”，而非纯粹的负面情绪。告诉自己，这种不适感是系统进入高效状态的标志。
    *   **判断标准**：对压力的主观感受从“抗拒/逃避”转变为“利用/引导”。
    *   **输出**：被重新定向的压力注意力。

2.  **实施单一任务极端收缩**
    *   **输入**：被重新定向的压力注意力，以及待办任务列表。
    *   **操作**：从所有任务中识别出当前生存危机下最核心、最关键的**单一任务**。清除工作环境中所有与该任务无关的物品、浏览器标签、通知。将视觉和物理接触范围锁定在该任务上。
    *   **判断标准**：工作界面和思维中，除了该核心任务外，无其他可选任务或明显干扰源。
    *   **输出**：一个极度简化的、目标唯一的工作环境与心智状态。

3.  **执行并维持心流状态**
    *   **输入**：目标唯一的工作环境与心智状态。
    *   **操作**：开始执行该核心任务。利用压力带来的天然紧迫感，保持高速、连续的推进。当出现分心思绪时，立即将其关联回任务失败的后果（即压力源），迫使注意力回归。
    *   **判断标准**：进入沉浸状态，时间感知扭曲，工作效率显著高于平常，并能持续一段时间（如25分钟以上）。
    *   **输出**：核心任务的高质量推进或完成。

4.  **压力释放与状态复盘**
    *   **输入**：核心任务取得阶段性成果或完成后，残留的压力感。
    *   **操作**：进行短暂的休息或仪式性活动（如散步、喝水），让身心从高压专注状态中舒缓。复盘此过程：何种压力源最有效？专注状态持续了多久？成果如何？
    *   **判断标准**：身心紧张感得到缓解，并对“压力-专注”转化效率有了更清晰的自我认知。
    *   **输出**：放松的状态，以及关于个人“生存模式”工作特性的经验数据。

# 输出格式要求
向用户解释如何在高压下进入并利用“生存模式专注”。提供清晰的、可操作的心理调整和行动收缩步骤。强调这是“战术压力”策略的后续应用阶段。
