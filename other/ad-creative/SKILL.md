# ad-creative 文案诊断助手

[快速开始](https://github.com/allinherog-star/ai-skills/tree/main#%E5%BF%AB%E9%80%9F%E5%BC%80%E5%A7%8B)

[更多技能](https://ai-skills.ai)

### 概述

文案诊断助手用于回答「这段文案能打动人吗」、转化率、增长营销、文案，适合市场营销、运营、产品、销售在明确业务目标、内容材料或分析对象后调用。
它会结合广告创意脚本、粘贴 Hook、视频脚本、分镜、静态图文案、素材说明、产品卖点或用…等输入，整理关键上下文，并输出摘要、诊断结论、行动建议和可复用交付物，便于继续执行、复盘或交付。

### 什么时候使用

**适用场景**

- 用户提出“这段文案能打动人吗”这类问题，需要快速拆解目标、判断重点并形成可执行结果
- 市场营销、运营、产品、销售需要围绕文案诊断助手生成摘要、诊断结论、行动建议和可复用交付物
- 用户已经准备了创意目标（例如停留、点击、留资、购买、安装、召回、品牌认知或新品解释。）、目标受众情境（补充受众痛点、使用场景、购买阶段、文化语境、创意敏感点和反感表达。）、创意预览链接（填写公开可访问的广告预览、素材说明、落地页、产品页或参考链接。），希望整理成可执行的分析或优化结果
- 用户需要把文案诊断助手相关材料转成清晰结论、优先级和下一步动作

### 参数说明

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `goal` | string | 否 | - | 例如停留、点击、留资、购买、安装、召回、品牌认知或新品解释 |
| `audience` | string | 否 | - | 补充受众痛点、使用场景、购买阶段、文化语境、创意敏感点和反感表达 |
| `materialUrl` | string | 否 | - | 填写公开可访问的广告预览、素材说明、落地页、产品页或参考链接；需要传可访问的完整 URL |
| `reviewDepth` | string | 否 | `标准诊断` | 选择快速体检、标准诊断或深度创意拆解；可选值：`快速体检`、`标准诊断`、`深度改稿` |
| `materialFile` | string | 否 | - | 支持 docx、pdf、md、txt 等创意资料，适合提交脚本、分镜、创意 brief 或素材说明 |
| `materialText` | string | 否 | - | 粘贴 Hook、视频脚本、分镜、静态图文案、素材说明、产品卖点或用户反馈 |
| `targetPlatform` | string | 否 | - | 例如 TikTok、Meta、YouTube、LinkedIn、小红书、信息流、展示广告或线下屏幕 |
| `brandRequirements` | string | 否 | - | 补充品牌语气、视觉/文字限制、禁用表达、声明要求和不能夸大的承诺 |

完整机器可读参数结构见 `references/form-schema.json`。

### 交付内容

- 摘要、诊断结论、行动建议和可复用交付物：围绕用户目标整理可直接阅读、复盘或交付的核心结果。
- 输入材料解读：结合创意目标（例如停留、点击、留资、购买、安装、召回、品牌认知或新品解释。）、目标受众情境（补充受众痛点、使用场景、购买阶段、文化语境、创意敏感点和反感表达。）、创意预览链接（填写公开可访问的广告预览、素材说明、落地页、产品页或参考链接。）提炼关键上下文和判断依据。
- 下一步动作：给出优先级、执行建议或可继续加工的内容框架。

### 结果使用建议

- 先判断输出是否回答了用户关于「文案诊断助手」的核心问题。
- 再检查结果是否覆盖摘要、诊断结论、行动建议和可复用交付物，以及是否给出明确下一步动作。
- 如果输入材料较少，建议让用户补充目标、受众、限制条件或原始材料后再运行。
