# LeeWay 3D Rigging & Animation

## Rig

Define hierarchy, joint placement/orientation, bind pose, controls, constraints, IK/FK and deformation requirements. Validate weights under representative extreme poses.

## Animation

Plan clips/state needs, timing, curves, loops, root motion, events and retargeting. Bake/export only what the target runtime requires.

## Performance

Track bone counts, skinned vertices, influences, blend shapes and animation memory/runtime cost.
