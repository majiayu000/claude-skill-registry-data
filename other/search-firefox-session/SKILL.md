# search-firefox-session

## 目标

复用用户当前已经打开并登录的 Firefox 主会话，对登录态网页进行只读搜索、打开、取证和摘要；不使用 MCP。登录态优先走 Firefox 自身已经加载的 cookies/profile session，但不导出、打印、保存或手工解析 cookie、token、密码或 Firefox profile 数据库。

## 适用请求

- “复用我当前 Firefox / 已打开 Firefox / 已登录淘宝 / 已登录京东 / 当前浏览器会话”。
- 需要访问登录后可见的淘宝、天猫、京东、小红书、知乎、微信公众号、Telegram Web、Grok/X 等页面。
- 需要从可见网页整理商品、帖子、评价、频道消息、搜索结果或截图证据。

## 操作流程

1. 直接信任用户确认的登录态；不要要求重复扫码、验证码或重新登录。
2. 使用系统 Firefox 打开新标签：`firefox.exe -new-tab <url>`，让现有 Firefox 进程接管页面并沿用当前会话。
3. 如页面仍提示未登录，先尝试本机已有登录态路径：让 Firefox 当前会话打开目标页，或在用户明确要求时使用浏览器托管的 Firefox profile/session；cookie 只允许由浏览器引擎自动携带，不允许导出或查看明文。
4. 优先从可见页面取证：页面标题、用户复制的页面文本、截图/OCR、用户确认的可见字段、公开 URL。
5. 如果自动复制页面文本不可用，明确告诉用户需要在当前 Firefox 页面执行：全选/复制页面文本，或截屏/保存可见内容，然后再继续整理。
6. 无法从当前 Firefox 可见页面取证时，先说明限制；未经用户明确允许，不重启 Firefox、不切换 profile、不启用远程调试。

## 安全边界

- 不使用 MCP，不新增 MCP 配置。
- 不读取、导出、打印、保存 cookie、token、密码、验证码、短信、账号数据库或浏览器 profile 敏感文件；Firefox cookies 只能作为浏览器当前会话/托管 profile 内的自动登录态使用。
- 不下单、不加购、不领券、不付款、不发消息、不询价、不点赞、不评论、不关注、不发布、不改设置。
- 只做搜索、打开、读取、摘录、截图/OCR、总结和来源标注。

## 输出证据格式

每条证据尽量包含：页面 URL、平台、页面标题/商品名/帖子标题、可见时间或检索时间、关键可见字段、截图/复制文本来源说明、限制与不确定性。
