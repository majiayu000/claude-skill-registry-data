# lagging-area-focus

## When to Use

当感到生活失控、注意力分散，需要系统性重获专注力时description

## Core Logic

# 执行步骤

1.  **识别落后领域**
    *   **输入**：对生活各领域（如金钱、健康、社交、心理等）的现状感知。
    *   **操作**：通过散步或沉思，评估哪个领域持续带来问题，且其改善能对其他领域产生最大连锁反应。
    *   **判断标准**：明确选定一个具体的生活领域作为当前焦点。
    *   **输出**：一个被选定的“落后领域”。

2.  **解构领域基本原理**
    *   **输入**：一个被选定的“落后领域”。
    *   **操作**：
        *   区分该领域的**基础原则**（驱动结果的杠杆）与**技术细节**（优化结果的技巧）。
        *   识别并列出该领域最核心的1-2个基本原理（例如，在“金钱”领域，核心是“流量”和“价值主张”）。
    *   **判断标准**：能够清晰陈述该领域成功所依赖的、非技术性的普遍原则。
    *   **输出**：该领域的核心基本原理列表。

3.  **设定基于能力的过程目标**
    *   **输入**：该领域的核心基本原理列表。
    *   **操作**：
        *   针对每个基本原理，推导出每日或每周可执行的、具体的杠杆行动（例如，为获得“流量”，可执行“每天写3篇短帖”）。
        *   将这些行动整合，设定一个以“过程”而非“结果”为核心的可衡量目标（例如，“每天写1000字”）。
    *   **判断标准**：目标完全聚焦于个人可直接控制的行为过程，而非外部结果（如粉丝数、收入）。
    *   **输出**：一个基于能力、可每日执行的过程目标。

4.  **在行动中循环学习**
    *   **输入**：一个基于能力的过程目标。
    *   **操作**：
        *   立即开始执行过程目标。
        *   **IF** 遇到失败或障碍：**THEN** 分析具体失败原因，并寻找针对性信息或方法来解决它。
        *   **ELSE** (执行顺利)：**THEN** 继续执行并积累经验。
        *   基于新经验调整行动，进入“执行-失败-学习-调整”的循环。
    *   **判断标准**：学习行为发生在执行目标之后，且学习内容直接针对遇到的真实障碍。
    *   **输出**：迭代改进后的行动方法与累积的直接经验。

5.  **保障每日深度时间**
    *   **输入**：迭代改进后的行动方法。
    *   **操作**：在日程中，为执行过程目标预留固定的、无干扰的30-60分钟“深度时间”。
    *   **判断标准**：该时间段被保护，免受其他任务、通讯或娱乐干扰。
    *   **输出**：受保护的每日专注时间段。

6.  **在深度时间内完全沉浸**
    *   **输入**：受保护的每日专注时间段。
    *   **操作**：在该时间段内，将全部注意力集中于当前任务。运用所有感官，努力进入“心流”或“临在”状态。
    *   **判断标准**：注意力持续集中在目标行动上，没有分心。
    *   **输出**：一次高质量的深度工作会话。

7.  **识别并重置分心时刻**
    *   **输入**：在深度工作或日常执行中出现的注意力分散。
    *   **操作**：
        *   **IF** 意识到自己已经分心或产生抗拒情绪：**THEN** 暂停，识别这个“分心时刻”，接纳“现实与期望不符”的事实，不做评判。
        *   **ELSE** (保持专注)：**THEN** 继续当前任务。
        *   在识别后，温和地将注意力重新引导回目标行动。
    *   **判断标准**：能够从分心状态中跳出，并恢复专注，而非陷入自责或持续分心。
    *   **输出**：恢复的专注状态。

8.  **进行持续的能力锻炼**
    *   **输入**：在特定领域积累的直接经验。
    *   **操作**：
        *   将生活领域视为科学项目：持续识别问题、测试解决方案、复制成功。
        *   像锻炼肌肉一样，通过持续的“关注、能量投入、经验积累”来巩固该领域的能力。
        *   不追求速成，接受长期锻炼的过程。
    *   **判断标准**：形成持续迭代和巩固的习惯，能力随时间稳定提升。
    *   **输出**：在该领域内增长的稳定能力和掌控感。

# 输出格式要求
以清晰的步骤列表形式呈现，用户可对照检查自己处于哪一步，并执行下一步操作。强调每一步的“输入”与“输出”，以及从“过程目标”到“行动中学习”的关键转折。
