# burn-boats-commitment

## When to Use

当需要克服拖延、激发最大行动力以完成一项重大挑战或转型时description

## Core Logic

# 执行步骤

1.  **识别退路与借口**
    *   **输入**：重大目标及当前状态。
    *   **操作**：反思并列出所有允许自己拖延、放弃或不全力以赴的“心理退路”或现实备用选项（如“做不好也没关系”、“还有别的收入来源”、“时间还多”）。
    *   **判断标准**：清晰列出至少2-3个主要的退路或借口。
    *   **输出**：“退路/借口”清单。

2.  **设计不可逆承诺**
    *   **输入**：“退路/借口”清单。
    *   **操作**：为每一条退路，设计一个公开的、经济的或心理上的“切断”行动。行动必须满足：
        *   **公开宣告型**：向关键人群宣布目标和截止日期。
        *   **经济投入型**：投入一笔不可退还的资金（如预付学费、签约对赌）。
        *   **过程绑定型**：启动一个不可中途停止的公开进程（如日更博客、每周汇报）。
    *   **判断标准**：为每个主要退路匹配了具体、可执行、带有代价的“切断”行动方案。
    *   **输出**：“切断退路”行动方案列表。

3.  **执行并锁定承诺**
    *   **输入**：“切断退路”行动方案列表。
    *   **操作**：在设定的时间点，按顺序执行所有“切断”行动。例如：公开发布宣言、完成付款、启动第一个不可逆的交付物。
    *   **判断标准**：所有计划中的“切断”行动均已实际完成，退路在事实上或心理上已被封闭。
    *   **输出**：退路被切断的状态确认，以及随之产生的紧迫感与专注力。

# 输出格式要求
以行动计划表的形式呈现：
1.  重大目标：[目标描述]
2.  **退路识别**：
    *   退路1：[描述] - 对应切断行动：[行动描述，类型]
    *   退路2：[描述] - 对应切断行动：[行动描述，类型]
3.  **承诺执行状态**：
    *   [行动1]：☑ 已完成 / □ 待执行 (于[日期])
    *   [行动2]：☑ 已完成 / □ 待执行 (于[日期])
4.  当前状态：退路已切断，全力前进。
