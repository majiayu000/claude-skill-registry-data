# Architecture Decision Record

Create a new ADR following our standard template.

## Steps

1. Read the [template](./template.md)
2. Determine the next ADR number by listing `docs/adr/`
3. Create `docs/adr/NNNN-<kebab-title>.md` filled out completely
4. Link it from `docs/adr/README.md`

## Arguments

`$ARGUMENTS` — description of the decision being recorded
