# 无效消耗排查

目标：在不明显损失有效转化的前提下，找出可砍掉的消耗。

## 数据契约

近 30 天：计划层汇总（消耗/转化/成本）、素材层汇总、搜索词报告（搜索类平台）、分版位/分流量来源报表（腾讯优量汇、穿山甲、快手联盟）、分时段/分地域报表（可选）、已转化人群包排除配置。

## 排查清单（按金额从大到小输出）

1. **零转化高消耗**：消耗 ≥ 2–3 倍目标成本且 0 转化的计划/素材 → 关停候选。注意区分"还在冷启动"（上线 <3 天或转化数未达学习期门槛）与"确认跑废"。
2. **搜索词漏损**（百度/巨量搜索/聚光搜索/淘宝关键词）：
   - 高消耗零转化词；意图不符词（免费/教程/招聘/图片/加盟竞品词）；
   - 一词泛匹配带出的无关长尾 → 否词清单（精确否定 vs 短语否定分开给）。
3. **联盟/穿山甲/优量汇低质流量**：分版位对比"前端成本 vs 后端质量"（有效线索率/付费率/退款率）。前端便宜后端差 = 隐性浪费，建议拆计划或压版位。
4. **重复触达**：未排除已转化/已留资人群；多计划同定向互抢（重叠度高时合并）。
5. **时段地域漏洞**：非业务时段（如凌晨 B2B）、非服务地域的消耗；客服不在线时段的线索浪费。
6. **僵尸资产**：长期低消耗高成本但没人关的计划；过期活动素材还在跑；预算给到已下架商品/失效落地页。
7. **数据黑洞**：转化回传缺失导致"看起来零转化"的计划——先修回传再决定关停，避免误杀。

## 输出格式

```
## 无效消耗排查（区间 / 总消耗 ¥X）
**预估可节省：¥X/月（占总消耗 X%）**
| # | 类型 | 对象 | 30天消耗 | 转化 | 建议动作 | 风险 |
### 否词清单（如适用）：精确否定 [...] / 短语否定 [...]
### 先修数据再决策的项
### 不建议动的项 + 原因（如冷启动保护期）
置信度 + 缺失数据说明
```

## 约束

- 节省金额按"该对象历史消耗 × 可砍比例"估算，标注假设；不承诺精确数字。
- 关停建议给观察期与回滚条件；品牌词/防御性投放即使 ROI 差也要单独说明战略价值。
- 冷启动期计划、刚上新素材默认保护，不列入立即关停。
