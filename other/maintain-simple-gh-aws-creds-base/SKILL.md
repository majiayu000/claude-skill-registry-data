`simple_gh_aws_creds` gives a GitHub repository its own IAM user and stores the user's access key as GitHub Actions secrets. All AWS (boto3 IAM) and GitHub (PyGithub) work is in `SetupGitHubRepo` in `simple_gh_aws_creds/impl.py`, as numbered step methods (`s1x` set up, `s2x` tear down, `s3x` maintain). The `simple-gh-aws-creds` command (`cli.py`, python-fire) is a thin layer: `cli_config.build_setup()` turns a JSON config file, an optional AWS profile, and a GitHub token read from a named environment variable into a `SetupGitHubRepo`, and each of the four commands calls one method on it.

For template conventions (layout, tests, docs, release), load `pywf-oss-base`.
