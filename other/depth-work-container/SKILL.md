# depth-work-container

## When to Use

当需要在清晰思路的基础上，进行需要高度专注和认知努力的创造性或生产性工作时description

## Core Logic

# 执行步骤

1.  **定义“容器”边界**
    *   **输入**：一个待解决的创造性/生产性任务或项目。
    *   **操作**：明确本次深度工作的具体产出目标（如：完成文章大纲、解决某个技术问题、设计一个方案）以及时间边界（如：接下来的90分钟）。
    *   **判断标准**：目标具体、可衡量，时间边界清晰且合理。
    *   **输出**：一个有时间限制的明确工作目标。

2.  **应用专注力**
    *   **输入**：明确的工作目标与时间边界。
    *   **操作**：在设定的时间内，将所有认知资源集中于定义的目标上，排除外界和内心的干扰。
    *   **判断标准**：在设定时间内，注意力持续指向目标相关任务，中断次数极少或为零。
    *   **输出**：高度专注的工作状态。

3.  **产出与结束**
    *   **输入**：高度专注的工作状态。
    *   **操作**：持续工作直至达成预定目标或时间边界用尽。
        *   **IF** 达成预定目标 → 结束本次深度工作，记录产出。
        *   **ELSE IF** 时间用尽但未完成目标 → 结束本次深度工作，记录进度，并为下次工作定义新的起点目标。
    *   **判断标准**：有明确的产出物或进度记录，工作结束时认知上能够“关闭”该任务。
    *   **输出**：具体的工作成果或明确的进度节点。

# 输出格式要求

强调深度工作作为一个有明确起止边界和目标的“容器”。输出应包含：1) 本次深度工作的具体目标；2) 专注执行的时长或条件；3) 完成后的产出物或状态描述。
