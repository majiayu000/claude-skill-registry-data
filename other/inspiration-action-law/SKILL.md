# inspiration-action-law

## When to Use

当需要建立可持续的创造节奏，将灵感转化为行动时description

## Core Logic

# 执行步骤

1.  **填充（输入灵感）**
    *   **输入**：个人兴趣、好奇心、外部刺激（如书籍、自然、对话）。
    *   **操作**：主动接触与个人目标或兴趣相关的新鲜事物和体验，在屏幕之外寻找新奇。
    *   **判断标准**：是否产生了新的想法、联想或创造的冲动。
    *   **输出**：记录下的灵感、想法或待探索的点。

2.  **清空（整理思维）**
    *   **输入**：步骤1中记录的灵感、想法或待办事项。
    *   **操作**：通过冥想、写作、散步等方式，将大脑中杂乱的想法全部倾倒出来，进行整理和分类。
    *   **判断标准**：大脑是否感觉更清晰、负担减轻；想法是否被组织成可行动的条目。
    *   **输出**：清晰的任务列表、项目计划或思维导图。

3.  **使用（专注执行）**
    *   **输入**：步骤2输出的清晰任务列表。
    *   **操作**：
        a. **规划**：在前一晚，选出2-3项能最大程度推动目标的关键任务。
        b. **安排**：在日历上为深度工作标记出专属时间段（如45分钟至2小时）。
        c. **准备环境**：前往一个与休息区分开的独立空间（如咖啡馆、图书馆）。
        d. **执行**：在设定的时间段内，屏蔽干扰（如使用屏蔽软件），专注执行单一任务。
        e. **休息**：计时结束后，离开工作区域散步10分钟，复盘目标并准备下一时段。
    *   **判断标准**：是否在无干扰环境下，于预定时间内完成了关键任务。
    *   **输出**：完成的工作成果、进展报告及下一阶段计划。

# 输出格式要求
提供以下结构化总结：
1.  **今日填充**：记录的新灵感/想法。
2.  **今日清空**：整理后的核心任务列表（2-3项）。
3.  **今日使用**：已完成的关键任务及成果。
4.  **同步性感悟**：（可选）在执行过程中产生的想法连接或“顿悟”时刻。
