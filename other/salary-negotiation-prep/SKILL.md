# 薪资谈判准备（Salary Negotiation Prep）

## 何时使用此技能

当用户想要：
- 谈判 job offer 或薪资
- 调研自己岗位的市场薪资水平
- 制定反向报价（counteroffer）策略
- 理解整体薪酬包（总包）
- 提到："薪资谈判"、"谈薪资"、"反向报价"、"薪酬"、"该要多少薪资"等

## 核心能力

- 调研并验证市场薪酬水平
- 制定谈判策略和话术脚本
- 计算总薪酬（而不仅仅是基本工资）
- 准备反向报价（counteroffer）回应
- 识别可以借力的谈判筹码
- 应对棘手的薪资对话

## 谈判心态

**关键原则：**
1. 谈判是预期之内的事 - 公司为此预留了预算
2. 84% 的雇主预期候选人会进行谈判
3. 不谈判可能在整个职业生涯中损失数十万至上百万元
4. 目标是双赢，而不是对抗

**你真正在谈判的内容：**
- 基本工资
- 签字费（signing bonus）
- 年度奖金/提成
- 期权/股权（股票期权、RSU）
- 福利（企业年金/公积金匹配、保险）
- 额外待遇（年假、远程办公、职业发展支持）
- 入职日期
- 职级/头衔

## 调研阶段

### 第 1 步：确定市场薪资水平

**可查阅的数据来源：**
- Levels.fyi（最适合技术岗位）
- Glassdoor（通用，数据仅供参考）
- LinkedIn 薪资
- Blind（匿名爆料/报薪）
- PayScale
- Salary.com
- 上市公司财报中的平均薪酬数据（公开可查）

**建立一个薪资区间：**
```
下限（25 分位）：¥XXX, XXX
期望目标（50 分位）：¥XXX, XXX
上限（75 分位）：¥XXX, XXX
冲刺值（90 分位）：¥XXX, XXX
```

### 第 2 步：了解自身价值

**能提升你身价的因素：**
- 相关工作经验年限
- 稀缺/专项技能
- 有据可查的业绩记录
- 受市场认可的高含金量认证（如 PMP）
- 手中的竞争 offer
- 内部员工内推
- 该领域的人才需求旺盛

**可能限制薪资的因素：**
- 初级岗位或转行
- 经验不及理想候选人
- 必备技能存在短板
- 地区差异（所在城市生活成本较低）

### 第 3 步：计算总薪酬

**总薪酬 = 基本工资 + 奖金 + 股权/期权 + 福利**

```
示例：
基本工资：¥900,000/年
目标奖金（15%）：¥135,000
RSU 授予（4 年归属）：¥1,200,000（每年 ¥300,000）
企业年金/公积金匹配（4%）：¥36,000
福利价值：约 ¥90,000

年度总薪酬：¥1,461,000
```

**常见股权术语：**
- **RSU（限制性股票单位）：** 真实股票，归属时按市价计税
- **期权（Options）：** 以行权价购买股票的权利（价值 = 当前股价 - 行权价）
- **归属（Vesting）：** 通常为 4 年归属期，满 1 年后首次归属
- **追加授予（Refresh grants）：** 每年额外授予的股权

## 谈判策略

### 何时谈判

**最佳时机：** 拿到书面 offer 之后、签字之前

**时间线：**
1. 收到口头 offer → 表达热情，请对方提供书面 offer
2. 收到书面 offer → 表达感谢，请求时间审阅
3. 调研并准备 → 24-48 小时
4. 提出反报价 → 通过邮件或电话
5. 往返磋商 → 可能需要多轮沟通
6. 最终达成一致 → 落实到书面

### 反向报价框架

**结构：**
1. 表达热情
2. 强调自身价值
3. 提出明确诉求
4. 给出依据
5. 开启讨论

### 反向报价邮件模板

```
主题：[你的姓名] - offer 沟通

您好，[招聘方/招聘经理]：

非常感谢 [公司名称] 提供的 [职位名称] offer。我对 [岗位中的某个具体亮点] 感到非常振奋。在与团队交流并进一步了解 [某个具体情况] 之后，我确信这是一个非常合适的机会。

我已经仔细审阅了 offer 的详细内容，希望与您讨论一下薪酬部分。基于我对市场行情的调研，以及我的 [X 年相关经验 / 某项稀缺技能 / 手上的竞争 offer]，我希望我们能讨论将基本薪资定为 ¥[你的期望数字]，而不是 ¥[对方报价]。

[可选：补充具体依据，例如："据我了解，[同类公司] 的类似岗位薪资就在这个区间"，或者"考虑到该岗位的职责范围，以及我在 [具体业绩] 方面的记录，我认为这一数字符合我的价值。"]

除此之外，我也愿意灵活讨论薪酬包的其他组成部分。您方便安排一次简短电话沟通吗？

再次感谢这个机会。期待我们能找到让双方都满意的方案。

此致
敬礼
[你的姓名]
```

### 反向报价电话话术

```
"您好，[姓名]，感谢您抽时间。我对这个机会真的非常期待 - [具体且真实的理由]。

我已经审阅了 offer，想和您讨论一下薪酬。基于我做的市场调研，以及 [X 年经验 / 关键业绩 / 手上的竞争 offer]，我希望基本薪资能接近 ¥[金额]。

这方面的数字是否还有可谈的空间？"

[倾听 - 让对方回应]

[如果对方坚持原报价：]
"我理解这里有预算限制。我比较灵活 - 我们能否看看其他部分，比如签字费、期权，或 [其他要素]，来弥合差距？"

[如果对方说需要确认一下：]
"完全可以理解。什么时间方便再次联系？"
```

## 常见谈判场景

### 场景 1：首份报价偏低

**应对方式：**
- 不要立即接受
- 对岗位表达热情
- 提出有调研数据支撑的数字进行反报价
- 准备好给出依据

**话术：**
```
"我对这个机会非常期待。不过根据我的调研，这个基本工资比我的预期要低。结合该岗位和市场行情，我原本期望的数字在 ¥X-¥Y 区间。有没有可能调整到接近日 ¥X？"
```

### 场景 2：对方先询问你的薪资期望

**迂回策略：**
```
"我比较灵活，重点是找到合适的岗位和团队。请问贵司为这个职位预留的薪资预算区间是多少？"
```

**如果被追问：**
```
"根据我对该岗位和市场行情的调研，我的期望在 ¥X-¥Y 区间，但我也愿意讨论整体薪酬的各个组成部分。"
```

### 场景 3：对方不肯上调基本工资

**可以谈判的替代项：**
- 签字费（一次性，更容易获批）
- 额外股权/期权
- 提前绩效考核时间（更早加薪）
- 更多带薪年假
- 远程办公灵活性
- 职业发展/培训预算
- 职级晋升
- 异地调动/安家补助
- 入职日期

**话术：**
```
"我理解基本工资这一项比较固定。我们能否讨论通过签字费来弥补差距？金额在 ¥X 左右的话，这个 offer 我就能接受。"
```

### 场景 4：你手上有竞争 offer

**谨慎使用：**
- 只有在真实存在时才提及
- 不要把它变成威胁
- 定位为共同解决问题

**话术：**
```
"我想坦诚地说明 - 我目前也在与 [另一家公司/几家其他公司] 沟通中。他们的报价是 ¥X。[贵司] 依然是我的首选，因为 [真实原因]，但我也希望薪酬具有竞争力。"
```

### 场景 5：对方询问你当前的薪资

**在很多国家和地区，这个问题属于违规甚至违法的提问**

**如果被问到（且属合法范围）：**
```
"我更想聚焦在我能为这个岗位带来的价值，以及该岗位的市场行情上。请问贵司的预算区间是多少？"
```

**或者转移话题：**
```
"我目前的薪酬其实不具可比性，因为 [所在地区不同/岗位不同/薪酬结构不同]。根据我对该岗位的调研，我的目标是 ¥X-¥Y。"
```

## 谈判技巧

### 应该做的：
- ✅ 一定要谈判（保持尊重）
- ✅ 谈判前先拿到书面 offer
- ✅ 充分调研
- ✅ 报出具体数字
- ✅ 表达真实的热情
- ✅ 给对方一个"可以说yes"的台阶
- ✅ 综合考虑总薪酬
- ✅ 保持耐心 - 流程需要时间
- ✅ 把最终一致落实到书面

### 不应该做的：
- ❌ 当场直接接受
- ❌ 提供过往薪资记录（法律没有强制要求时）
- ❌ 发最后通牒
- ❌ 虚构竞争 offer
- ❌ 态度粗鲁或冒进
- ❌ 为了谈而谈
- ❌ 轻信没有书面承诺的口头保证
- ❌ 谈崩了就撕破脸

## 总薪酬对比

### 逐项对比分析

```markdown
## OFFER 对比

| 组成部分 | 公司 A | 公司 B | 备注 |
|-----------|-----------|-----------|-------|
| 基本工资 | ¥900,000 | ¥840,000 | A 占优 |
| 目标奖金 | 15%（¥135,000） | 20%（¥168,000） | B 占优 |
| 签字费 | ¥120,000 | ¥60,000 | A 占优 |
| 股权/期权（按年计） | ¥300,000 | ¥450,000 | B 占优 |
| 企业年金匹配 | 4%（¥36,000） | 6%（¥50,400） | B 占优 |
| 其他福利 | 标准五险一金 | 补充商业保险 | B 占优 |
| 远程办公 | 混合（每周到岗 3 天） | 全远程 | B 占优 |
| 带薪年假 | 10 天 | 弹性/不限 | 视情况而定 |

**首年总薪酬：**
公司 A：¥1,491,000
公司 B：¥1,568,400

**分析：** 公司 B 的总薪酬更高，但公司 A 的基本工资更高，而基本工资会影响未来加薪基数以及房贷收入证明等资质。
```

## 谈判时间线模板

```
第 1 天：收到 offer
- 表达感谢和热情
- 要求提供书面 offer
- 询问回复截止时间

第 1-3 天：调研
- 核实市场薪资水平
- 计算总薪酬
- 明确自己的优先级
- 准备反向报价

第 3-5 天：反报价
- 发送反向报价邮件或预约电话
- 明确说出你的诉求

第 5-10 天：磋商
- 可能需要多轮沟通
- 保持耐心但及时回应
- 保持专业和积极的态度

第 10 天以后：达成一致
- 确认各项条款
- 所有内容落实到书面
- 签字，庆祝！
```
