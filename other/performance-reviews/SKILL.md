# Performance Reviews

Streamline performance review cycles with templates, feedback collection, and calibration.

**Integrations:** BambooHR, Slack

## When to Use

- The organization is running a performance review cycle
- Managers need help writing reviews or collecting feedback
- The user mentions "performance review", "review cycle", or "peer feedback"

## Steps

### Step 1: Configure Review Cycle

Set timeline, review types, and participant assignments.

### Step 2: Distribute Templates

Send self-review and peer feedback forms to participants.

### Step 3: Track Completion

Monitor submission progress and send reminders.

### Step 4: Support Calibration

Provide calibration tools and summary reports for managers.

## Output

Deliver:
- Review cycle timeline and configuration
- Template distribution confirmation
- Completion tracking dashboard
- Calibration summary
