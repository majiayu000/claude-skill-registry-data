# self-as-ideal-reader

## When to Use

当需要为个人品牌、内容创作或产品开发确定目标受众，但缺乏外部客户数据时description

## Core Logic

# 执行步骤

1.  **自我剖析与画像构建**
    *   **输入**: 对自身性格、兴趣、价值观、当前挑战或目标的初步认知。
    *   **操作**: 使用结构化的工具（如迈尔斯-布里格斯性格测试）或通过深度反思，系统性地梳理并记录自己的核心特质、知识缺口、痛点及渴望。
    *   **判断标准**: 输出一份清晰的、包含多个维度的“自我画像”文档。
    *   **IF** 无法通过工具获得结构化结果 **THEN** 转为通过回答预设问题（如：我最近最大的困扰是什么？我最想学会什么？）来创建画像。

2.  **内容主题生成**
    *   **输入**: 步骤1生成的“自我画像”文档。
    *   **操作**: 基于画像，从以下至少一个角度生成具体的内容创作主题：
        *   **对困境的自我建议**: 针对画像中“当前挑战”，写下你给自己的解决方案或心路历程。
        *   **给过去自己的指南**: 针对画像中“已克服的困难”或“知识/技能”，写下希望更早知道的精简建议。
        *   **给未来自己的鼓励**: 针对画像中“目标或渴望”，写下激励性话语或实现愿景的路径设想。
    *   **判断标准**: 输出一个具体、可立即开始创作的内容主题列表。
    *   **IF** 生成的议题过于宽泛 **THEN** 将议题与一个具体的、微小的场景或案例结合，使其更聚焦。

3.  **内容创作与发布**
    *   **输入**: 步骤2生成的具体内容主题。
    *   **操作**: 选择一个主题，以“与另一个自己对话”的口吻和心态，完成内容创作（如文章、视频脚本、社交媒体帖子），并将其发布在选定的“公开日记”平台（如博客、Newsletter、视频频道）。
    *   **判断标准**: 内容已完成并发布。内容的口吻真诚，如同与朋友交谈，而非面向模糊的“大众”。
    *   **IF** 在创作中感到阻力或完美主义 **THEN** 明确本次创作的核心目的是“完成并交付给（作为读者的）自己”，而非追求外部认可，优先保证完成度。

# 输出格式要求

向用户呈现：
1.  一份简要的“自我画像”摘要（基于用户输入或引导问题生成）。
2.  根据该画像生成的1-3个具体内容创作主题建议。
3.  一个明确的行动号召，例如：“现在，请选择‘[主题A]’，用10分钟写下初稿。”
