# Tweetclaw — X (Twitter) Workflow Suite

Manage the full X content lifecycle.

## Capabilities
1. **Drafting** — posts per best practice: hook line, line breaks, <280 chars per unit, threads with 1 idea per post and clear numbering.
2. **Scheduling plan** — a weekly slot table (topics, formats, best-time hypotheses); outputs ready-to-paste copy per slot.
3. **Monitoring dashboard design** — define tracked metrics (impressions, engagements, profile clicks, follows), keyword/topic monitor plan.
4. **Extraction templates** — structured prompts/specs to pull stats from exported analytics (CSV) into summaries.
5. **Engagement SOP** — daily 20-min reply strategy: who to reply to, what to add (insight > praise), note: quality replies grow reach more than posts.

## Rules
- Align with X policy: no spam patterns, no engagement-bait ("RT if").
- Threads: strong closer with recap + CTA; quote-post your thread's hook.

## Output
Content calendar + drafted posts/threads + metrics tracker template + engagement checklist.
