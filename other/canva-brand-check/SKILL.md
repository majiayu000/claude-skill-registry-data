# Canva Brand Check

## When to use
Export öncesi veya design feedback döngüsünde.

## Checks
- Renk paleti CONTEXT_BRIEF / brand kit ile uyum
- Logo minimum clear space
- Font hierarchy
- Yasaklı ifade/claim (10-brand-guardrails)

## Output
PASS/FAIL + düzeltme listesi → `QA/`
