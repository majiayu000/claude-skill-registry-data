# Onboarding Cycle

Chain: pm-handoff → pm-assess → quality-debt → feature-plan (first task)

## Process

1. Generate handoff documentation (or read existing)
2. Assess current project state
3. Identify low-risk, high-learning first tasks
4. Plan the first feature/fix for the new contributor
5. Provide all context needed to start working
