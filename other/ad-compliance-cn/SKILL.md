# 营销内容合规检查

国内合规是硬约束：罚款（广告法虚假广告可罚广告费用数倍/数十万起）、平台处罚（拒审/限流/封号）、职业打假人索赔。内容发布前过一遍本清单。

## 输入

待审内容（文案/脚本/笔记/落地页/直播话术）、行业与产品资质（特殊化妆品注册证/保健食品批号/医疗广告审查证明/办学许可/金融牌照等）、投放平台与形式（信息流广告/达人软文/直播带货/私域）。

## 检查流程

1. 判定行业→读 `references/prohibited-words.md` 对应行业小节 + 通用极限词表。
2. 逐句扫描：绝对化用语、功效/医疗宣称、虚假或无法证实的表述（数据/销量/专利/获奖无依据）、价格表述（虚构原价/先涨后降）、诱导与导流违规。
3. 形式合规：商业软文是否可识别为广告（《互联网广告管理办法》2023 施行：知识介绍/体验分享/消费测评等形式推销商品须显著标明"广告"）；达人合作是否平台报备；直播带货的广告主/经营者责任。
4. 资质核验：宣称内容是否超出资质范围（普通化妆品不得宣称美白祛斑等特殊功效；普通食品不得宣称保健/治疗功能）。
5. 输出：风险分级 + 逐条改写建议 + 需用户补充的证明材料。

## 风险分级

- 🔴 高危（违法/必罚风险）：极限词用于产品性能、无资质功效宣称、虚假数据、医疗用语用于非药品、软文未标广告（商业推广情形）；
- 🟡 中危（平台处罚/投诉风险）：夸大暗示、无法证实的对比、诱导分享、未报备商业笔记、价格表述瑕疵；
- 🟢 低危（建议优化）：表述模糊可能引发误解、绝对化用语的豁免情形（见参考文件：仅表达时空顺序/自我比较且有依据等，按《广告绝对化用语执法指南》2023 判断，不是一刀切）。

## 输出格式

```
## 合规检查（行业 / 平台 / 形式）
| # | 原文 | 风险级 | 依据（法条/平台规则） | 合规改写 |
### 形式合规：广告标注/报备/资质 结论
### 需补充的证明材料清单
### 总体结论：可发布 / 修改后可发布 / 不建议发布
免责声明：本检查为营销合规辅助，不构成法律意见；重大投放建议法务复核。
```

## 约束

- 每条风险给依据（法条名/规则名），不凭感觉判；拿不准的标"建议法务确认"。
- 改写保留营销力：给"合规且有说服力"的替代（用证据/场景/对比代替绝对化），不是删到干瘪。
- 法规与平台规则更新快，涉及具体罚则/新规时提示以当期官方文本为准。
