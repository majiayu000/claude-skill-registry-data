# 代码走读

以用户指定的业务场景为例，先用一张图串起入口、关键模块和数据落点，再用同一组示例值展示接口请求、响应和数据前后对照。沿实际调用顺序，把这组值代入关键表达式和分支条件，用大白话讲清算出了什么、为什么走这条分支，再指出看哪个变量、日志或字段能验证结果、定位问题。
