# YouTube Transcript Fetcher

Fetches transcripts from YouTube videos. Works from cloud environments (Vercel, Codespaces, AWS, etc.) via residential proxy.

## Key Facts

- YouTube blocks requests from cloud IPs (AWS, Azure, GCP, Vercel) without proxy
- `youtube-transcript-api` uses undocumented YouTube endpoints (same as youtubetotranscript.com)
- DataImpulse proxy rotates IPs automatically per-request — no manual rotation needed
- Requires video to have captions (auto-generated by YouTube counts)

## Usage

### Python (basic)

```python
from youtube_transcript_api import YouTubeTranscriptApi
from youtube_transcript_api.proxies import GenericProxyConfig
import os

proxy_url = f"http://{os.environ['DATAIMPULSE_USER']}:{os.environ['DATAIMPULSE_PASS']}@{os.environ['DATAIMPULSE_HOST']}"

ytt = YouTubeTranscriptApi(
    proxy_config=GenericProxyConfig(
        http_url=proxy_url,
        https_url=proxy_url,
    )
)

transcript = ytt.fetch('VIDEO_ID')  # or full URL — extract ID first
text = ' '.join([s.text for s in transcript])
```

### Extract video ID from URL

```python
import re

def extract_video_id(url: str) -> str:
    patterns = [
        r'youtu\.be/([^?&]+)',
        r'youtube\.com/watch\?v=([^&]+)',
        r'youtube\.com/embed/([^?&]+)',
    ]
    for pattern in patterns:
        match = re.search(pattern, url)
        if match:
            return match.group(1)
    return url  # assume it's already a video ID

video_id = extract_video_id('https://youtu.be/PknH_XtVL_E')
```

### With language selection

```python
# List available transcript languages
transcript_list = ytt.list('VIDEO_ID')

# Fetch specific language (fallback to auto-generated)
transcript = ytt.fetch('VIDEO_ID', languages=['pl', 'en'])
```

## Error Handling

```python
from youtube_transcript_api import (
    TranscriptsDisabled,
    NoTranscriptFound,
    VideoUnavailable,
    RequestBlocked,
)

try:
    transcript = ytt.fetch(video_id)
except TranscriptsDisabled:
    print("No captions available for this video")
except NoTranscriptFound:
    print("No transcript in requested language")
except VideoUnavailable:
    print("Video is private or deleted")
except RequestBlocked:
    print("Still blocked — check proxy credentials")
```

## Channel Bulk Download

When the user says something like "download transcripts for the 20 most recent videos from this channel", use this workflow.

### Step 1 — Install yt-dlp (if not present)

```bash
pip install yt-dlp -q
```

### Step 2 — Get video IDs from channel

```bash
yt-dlp --flat-playlist --print "%(id)s %(title)s" \
  "https://www.youtube.com/@HANDLE/videos" \
  --playlist-end N 2>/dev/null
```

- Replace `@HANDLE` with the channel handle from the URL the user provided
- Replace `N` with the number of videos requested
- Works with any channel URL format: `@handle`, `/channel/UCxxx`, `/c/name`

### Step 3 — Fetch all transcripts

```python
from youtube_transcript_api import YouTubeTranscriptApi
from youtube_transcript_api.proxies import GenericProxyConfig
import json, time

DATAIMPULSE_USER = "12d41802bcf94c896c47"
DATAIMPULSE_PASS = "5c09f4d353af7366"
DATAIMPULSE_HOST = "gw.dataimpulse.com:823"

proxy_url = f"http://{DATAIMPULSE_USER}:{DATAIMPULSE_PASS}@{DATAIMPULSE_HOST}"
ytt = YouTubeTranscriptApi(
    proxy_config=GenericProxyConfig(http_url=proxy_url, https_url=proxy_url)
)

videos = [
    # list of (video_id, title) tuples from Step 2
]

results = []
for vid_id, title in videos:
    try:
        fetched = ytt.fetch(vid_id)
        text = " ".join([t.text for t in fetched])
        results.append({"id": vid_id, "title": title, "url": f"https://youtu.be/{vid_id}", "transcript": text, "words": len(text.split())})
        print(f"✓ {title[:65]} ({len(text.split()):,} words)")
    except Exception as e:
        results.append({"id": vid_id, "title": title, "url": f"https://youtu.be/{vid_id}", "transcript": None, "error": str(e)[:100]})
        print(f"✗ {title[:65]} — {str(e)[:80]}")
    time.sleep(0.5)

output_file = "HANDLE-transcripts.json"  # use channel handle in filename
with open(output_file, "w") as f:
    json.dump(results, f, indent=2)

succeeded = sum(1 for r in results if r["transcript"])
total_words = sum(r.get("words", 0) for r in results)
print(f"\nDone. {succeeded}/{len(results)} succeeded. {total_words:,} total words → {output_file}")
```
