# LeeWay Skill House — 3D Production

## Mission
Provide a complete studio-grade 3D department. Route substantial 3D work through this House rather than equating 3D with Blender.

## Capability floors
REFERENCE/ACQUISITION: research, scene audit, lifecycle, TripoSR, photogrammetry, splats, procedural generation.
MODEL: blueprint/CAD, geometry/topology, sculpting, characters, environments, terrain, vegetation.
SURFACE: UV/material/lookdev, texture baking, shaders, grooming, clothing.
MOTION/VFX: rigging, facial, mocap, animation, physics, VFX.
SCENE/REALTIME: lighting, camera, streaming/virtualized geometry, navigation, spatial audio, game integration.
DELIVERY/QA: game asset production, interchange/export, compositing, automated QA, visual regression, Veritas.

## Provider law
Blender and TripoSR are providers beneath the House. Provider connection is not department qualification. Map providers against config/3d-execution-capability-contract.json.

## Parallel law
Use independent lanes aggressively but serialize conflicting mutation of the same canonical scene/object unless merge ownership is explicit.
