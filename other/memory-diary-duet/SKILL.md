# Memory Diary Duet

## Delivery

- Generate one standalone 4:5 vertical poster per source image. Never combine multiple photos.
- Divide the canvas with a diagonal or near-vertical line into complementary areas: real photography on the left and a hand-drawn interpretation of the same moment on the right. Keep the boundary clear, elegant, and aligned with the subject; no gradients, feathering, or media blending.
- If the user asks only for a prompt, return a ready-to-use generation prompt. Otherwise, use the available image generation or editing capability directly. Ask for an upload only when none is available.

## Left photograph

Preserve subject identity, count, structure, pose, object relationships, environment, materials, natural light, and viewpoint. Apply only subtle lifestyle-editorial grading with warm natural light, soft contrast, faint nostalgia, and fine grain. Do not alter subjects, add or remove objects, replace the setting, invent regional details, or illustrate the photo.

## Right memory drawing

On warm ivory textured paper, extract the left image's most recognizable and narratively useful subjects, objects, actions, or relationships. Recreate the same moment with minimal watercolor and restrained colored pencil. Preserve subject count, contour, proportion, direction, pose, identifying colors, and object relationships. Remove visual clutter and retain only clues needed to communicate the people, place, event, or lifestyle memory.

Use slightly imperfect ink contours, transparent watercolor, soft pencil hatching, visible paper grain, slight overrun, uneven color, and hand-printed imperfections. Keep ivory paper and continuous negative space dominant; avoid filling the page or over-rendering. Derive a soft muted palette from the current source image. Do not impose a fixed palette or add Japanese, café, or food elements absent from the source.

## Archive text

Place a small, readable typewriter-style archive block below the drawing or in intact negative space. Before rendering, lock the exact text and use only: a verifiable location; a MEMORY NO. XX or ITEM NO. XX identifier; 1–3 truthful memory keywords; and a year only when supplied or verifiable. Omit unknown locations, dates, brands, or relationships.

Use small typewriter type, worn letterpress, or a quiet humanist sans with slight ink loss, paper tooth, or handmade misregistration. Never cover the subject. The page should combine real lifestyle photography, a hand-drawn memory archive, restrained Japanese editorial design, a vintage lifestyle magazine, and a private scrapbook. Japanese influence is a design language only and must not change the source geography.

## Avoid

Changing the source, blending photo and drawing, invented locations or years, forced Japanese or café motifs, cartoons, children's-book styling, heavy oil paint, plastic 3D, fixed palettes, dense layout, excessive text, logos, QR codes, watermarks, and garbled text.
