# search-zhihu

## 目标
在用户需要知乎资料时，优先通过只读搜索与页面读取整理公开信息、链接、发布日期、作者和关键结论，不写入知乎平台。

## 适用请求
- 查询知乎问答、回答、专栏、想法或用户公开资料。
- 需要按时间筛选近期知乎讨论，尤其是近 30 天内容。
- 需要从给定 `zhihu.com` URL 提取正文、评论摘要或引用信息。

## 首选通道
- 如果 `last30days-skill-cn` 已安装/可用则主动搜索近期知乎结果，否则走兜底。
- skill-only：公开内容用 WebSearch/WebFetch；登录后可见内容优先复用当前 Firefox 已登录会话只读打开和读取页面。
- 如果 `feedgrab` 或 `url-reader` 已安装/可用，则用于给定 URL 抓取正文，否则使用浏览器只读读取。

## 兜底通道
- 使用普通 WebSearch，查询词优先包含 `site:zhihu.com` 与用户关键词。
- 使用浏览器只读打开搜索结果和知乎页面；遇到登录、验证码或权限限制时请求用户人工处理或提供可访问链接。

## 操作流程
1. 提取触发词、主题、时间范围、内容类型和是否限定 `site:zhihu.com`。
2. 先用首选通道做只读搜索；如果不可用，再使用 WebSearch + 浏览器读取。
3. 打开候选结果时只读取公开或当前 Firefox 已授权可见页面内容；全程只读搜索/读取，不发起新的登录流程、不下单、不私信、不发帖、不写入平台，也不关注、点赞、收藏或评论。
4. 对给定 URL，优先用 `feedgrab` 或 `url-reader` 只读抓取；失败时用当前 Firefox/浏览器读取可见内容。
5. 输出时标注来源 URL、作者/机构、发布时间、是否需要登录可见，并区分原文事实与模型归纳。

## 只读安全边界
- 只能搜索、打开、复制和摘要公开或用户已授权可见内容。
- 不发起新的知乎登录流程；优先复用当前 Firefox 已登录会话，不绕过验证码、付费墙或访问控制。
- 不执行点赞、收藏、关注、评论、发帖、私信、举报、下单或任何写入操作。
- 不写入密钥、Cookie、Token 或账户资料。

## 验证方式
- 后续可运行：`dir C:\Users\Zhang\.config\opencode\skills\search-zhihu\SKILL.md`
- 人工检查：确认 frontmatter `name` 为 `search-zhihu`，章节齐全，流程只包含只读搜索/读取。

## 已知限制
- 知乎部分内容需要登录或 App 环境，浏览器可见内容可能不完整。
- 搜索引擎索引可能滞后，近实时内容需依赖可用的首选通道或用户提供 URL。
- 评论、折叠回答和付费内容可能无法完整读取。
