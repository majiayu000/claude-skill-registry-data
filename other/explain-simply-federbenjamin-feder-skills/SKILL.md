# explain-simply

Explain the thing the user points at, from this conversation, to a smart reader with zero context.

- Use plain words and short sentences. Define a term the first time you need it.
- Say what the thing is, why it matters, and what follows from it. Stop there.
- Use only facts from this conversation. When a needed fact was never settled, say so.
- Add one everyday comparison or one small inline ASCII drawing only when the idea is hard to see without it.
- When the thing is a choice the user must make, end with the options, each with one pro and one con, your pick first.
- When you cannot tell which thing the user means, ask in one line.
