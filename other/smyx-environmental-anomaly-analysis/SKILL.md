# 🌡️ Livestock Barn Environmental Anomaly Correlation | 畜禽舍环境异常联动

> 结合畜禽行为与环境传感器，识别温湿度异常时的群体应激反应。
>
> **环境应激联动预警中枢** · 畜禽舍连续视频智能分析 · 温湿度/氨气等传感器融合 · 群体应激反应识别 · 历史报告云端查询

---

## 🧭 技能概览 | Overview

| 模块 | 内容 |
|---|---|
| 🏷️ 技能名称 | **畜禽舍环境异常联动** |
| 🎯 核心目标 | 基于畜禽舍固定摄像头的连续视频，检测群体行为特征（聚集、分散、喘息、躁动等），并结合环境传感器数据（温度、湿度、氨气浓度等），识别环境异常引起的群体应激反应 |
| 🖼️ 输入类型 | 图片、视频、本地文件、网络 URL，可选传感器时序数据 |
| 📝 输出能力 | 结构化分析报告、行为特征清单、环境指标关联结果、群体应激反应等级、报告链接 |
| 🏢 适用场景 | 畜禽舍环境异常预警与调控前置监控，保障动物福利与生产性能，降低环境应激造成的经济损失 |
| 🧩 场景码 | `SMYX_ENVIRONMENTAL_ANOMALY_ANALYSIS` |

## 🎯 任务目标 | Goals

### 1. 🧩 技能用途

将畜禽舍视频中的群体行为特征与环境传感器数据进行联动分析，识别温度过高/过低、湿度异常、氨气浓度升高等环境异常状态下畜禽的群体应激反应，输出结构化的行为-环境联动异常清单与应激等级，为畜禽舍环境预警与前置巡检提供客观依据。

### 2. 🛠️ 能力范围

| 序号 | 具体能力 |
|---:|---|
| 1 | 畜禽群体行为特征识别（聚集 / 分散 / 喘息 / 躁动 / 静卧异常等） |
| 2 | 群体空间分布与热区变化分析 |
| 3 | 温度/湿度/氨气/二氧化碳等传感器数据接入与时序对齐 |
| 4 | 行为-环境联动相关性分析（异常时段匹配） |
| 5 | 高温应激识别（喘息、张口呼吸、扎堆远离热源等） |
| 6 | 低温应激识别（挤堆、缩身、聚拢取暖等） |
| 7 | 空气质量应激识别（躁动、咳嗽相关行为、避风口聚集等） |
| 8 | 群体应激反应等级输出（正常 / 关注 / 预警 / 高风险） |

### 3. ⚡ 触发条件

| 触发类型 | 触发规则 |
|---|---|
| ✅ 默认触发 | 当用户提供畜禽舍固定摄像头视频 URL 或文件（并可选附带环境传感器数据）需要环境-行为联动分析时，默认触发本技能 |
| 🔎 明确分析意图 | 当用户明确提及畜禽舍环境异常、温湿度异常、高温应激、低温应激、氨气过高、群体应激反应、行为环境联动等关键词，并且上传了图片或视频文件 |
| 📚 历史报告查询 | 当用户提及以下关键词时，**自动触发历史报告查询功能**：查看历史环境异常联动报告、历史畜禽舍应激报告、环境异常联动清单、查询群体应激记录、显示所有环境异常联动报告 |

### 4. 🤖 自动行为

| 自动行为 | 执行要求 |
|---|---|
| 📎 附件处理 | 如果用户上传了附件或者视频/图片/传感器数据文件，则自动保存为本地文件 |
| ☁️ 历史报告查询 | 如果用户触发历史报告查询关键词，必须直接调用云端 API 查询，不得从本地记忆或人工汇总中获取 |

## 📷 采集要求 | Capture Requirements

| 序号 | 说明 |
|---:|---|
| 1 | 固定摄像头俯视/斜俯视覆盖畜禽舍主要活动区，画面稳定，避免频繁抖动或视角切换 |
| 2 | 视频建议 1~30 分钟连续拍摄，帧率不低于 10fps，便于捕捉聚集/分散、喘息、躁动等群体行为 |
| 3 | 光照条件稳定，白天充足自然光或稳定人工光源，避免大面积过暗/过曝 |
| 4 | 传感器数据（温度/湿度/氨气/CO₂ 等）建议按分钟级别采集，并与视频时间戳保持一致或提供时间对齐信息 |
| 5 | 支持格式：jpg/png/jpeg 图片，及 mp4/avi/mov 视频；单文件不超过 10MB；可选附带 csv/json 传感器数据 |
| 6 | 避免在人员操作、清扫等强干扰时段进行行为观察，以免误判为环境应激 |
| 7 | 尽量提供同一时段的视频与传感器数据配对，便于联动相关性分析 |

## 🧪 标准流程 | Standard Flow

| 步骤 | 阶段 | 执行动作 |
|---:|---|---|
| 1 | 📥 准备畜禽舍视频与环境传感器输入 | 提供本地文件路径或网络 URL，尽量提供同一时段的视频与传感器数据 |

| 3 | ⚙️ 执行环境-行为联动分析 | 调用 `-m scripts.smyx_environmental_anomaly_analysis` 处理输入（**必须在技能根目录下运行脚本**） |

| `--detail` | 输出详细程度 | `basic` / `standard` / `json`，默认 `json` |
| `--output` | 结果输出文件路径 | 可选 |
