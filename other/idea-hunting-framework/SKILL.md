# idea-hunting-framework

## When to Use

当需要主动从海量信息中寻找能带来深刻启发、挑战现有认知或激发好奇心的新想法时description

## Core Logic

# 执行步骤

1.  **定义狩猎场**：明确当前“已知领域”的边界。列出你已熟悉的核心概念、观点和信念。
    *   **判断标准**：能清晰描述出至少三个你当前深信不疑或熟练掌握的领域/观点。
    *   **常见误区**：将“已知”定义得过于宽泛或模糊，导致无法有效识别“未知”。
    *   **IF** 无法清晰定义已知边界 **THEN** 返回步骤1，尝试通过写下或向他人解释来明确。

2.  **选择狩猎目标**：根据以下三个筛选标准，从待阅读材料（如书单、文章列表）中选择目标：
    a.  **挑战观念**：材料中的核心论点可能与你步骤1中定义的“已知”观点相冲突。
    b.  **激发好奇**：材料的主题或问题是你长期感兴趣但未曾深入探索的。
    c.  **克服拖延**：材料是你认为重要但一直推迟接触的。
    *   **判断标准**：选定的目标至少符合标准a、b、c中的一项。
    *   **常见误区**：仅选择符合已有观点、易于理解或娱乐性强的材料，这属于在“已知领域”内活动，而非“狩猎”。
    *   **IF** 没有符合条件的材料 **THEN** 扩大信息源搜索范围（如更换平台、咨询该领域专家），然后返回步骤2。

3.  **执行狩猎与识别信号**：阅读选定的材料。在阅读过程中，主动觉察认知反应，寻找“有意义的事件”信号。信号特征包括：感到困惑、产生疑问、内心产生反驳冲动、感到兴奋或看到新的可能性。
    *   **判断标准**：在阅读中至少识别出一个明确的“信号”。
    *   **常见误区**：被动接受信息，忽略或回避内心的不适感（如困惑、反驳），这些往往是想法孕育的关键节点。
    *   **IF** 未识别到任何信号 **THEN** 检查材料是否真的触及“未知”（返回步骤2评估），或调整阅读专注度，尝试主动提问后再继续。

4.  **记录与整合**：当识别到“信号”时，立即记录下相关的原文、你的即时反应（疑问、联想、反对意见）以及它如何与你“已知领域”产生冲突或连接。尝试用自己语言初步描述这个新想法或洞察的雏形。
    *   **判断标准**：记录了包含“外部信息”、“内部反应”和“初步解读”的笔记。
    *   **常见误区**：只摘抄原文，不记录个人化的思考和反应，丢失了想法涌现的关键过程。
    *   **ELSE** 继续阅读，重复步骤3-4，直至完成本次狩猎。

# 输出格式要求
输出应为一个结构化的“想法狩猎记录”，包含：
1.  **狩猎目标**：所阅读材料的名称及选择理由（符合哪个/哪些标准）。
2.  **捕获的想法**：用清晰的语言描述发现的新想法、洞察或认识。
3.  **冲突与涌现过程**：简述该想法如何与你原有的“已知”观点发生冲突或连接，以及你理解它的过程。
4.  **潜在应用**：此想法可能如何影响你的思考或行动。
