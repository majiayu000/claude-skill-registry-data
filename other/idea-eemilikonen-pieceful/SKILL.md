# /idea: capture an idea

1. Append one line under `## Untriaged` in the private `ideas/inbox.md` (notes path in `CLAUDE.local.md`):
   `- YYYY-MM-DD: <idea, one or two sentences in the owner's words> (<source: chat / task id / review>)`
2. If the idea came from the conversation, phrase it faithfully. Don't expand it.
3. Confirm in one line. **Don't** spec, discuss, or start work on it unless asked.
4. Don't commit.
