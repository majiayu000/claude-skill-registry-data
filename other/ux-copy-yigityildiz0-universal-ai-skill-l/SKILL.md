# UX Copy

Use language that helps a person act, recover, and understand consequences.

1. Identify user intent, state, risk, terminology, locale, and available action.
2. Write the shortest clear label or message that preserves necessary context.
3. Make buttons describe the resulting action; distinguish cancel, back, save, submit, delete, and irreversible actions.
4. For errors, explain what happened, what the user can do now, and what information is safe to show.
5. Review reading level, localization expansion, accessibility names, and consistency with the product voice.

Do not blame users, hide destructive consequences, use vague button labels, or promise an action the system cannot perform.
