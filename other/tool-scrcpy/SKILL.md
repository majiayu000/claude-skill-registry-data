# scrcpy Android 屏幕采集与控制 技能卡

## 基本信息

- **中文名称**：scrcpy Android 屏幕采集与控制
- **来源仓库**：[Genymobile/scrcpy](https://github.com/Genymobile/scrcpy)
- **上游参考分支**：`master`
- **参考提交（使用前核对）**：`2926c06c5dc3064ae6d8db706f1a98a37cfcf3f0`
- **许可证线索**：Apache-2.0；文件：`源码\LICENSE`

## 功能概览

1. 低延迟采集 Android 视频/音频并显示/录制
2. 通过 ADB 建立连接、转发和键鼠/触控控制
3. 提供分辨率、码率、裁剪、录制和无界面运行选项

## 适用范围

- 用于后台画面采集、输入通道、录屏证据和 UI 自动化链路的传输层。

## 不能替代的边界

- 不提供 UI 语义识别、内存/IL2CPP、函数 Hook、网络协议或游戏状态判定；画面连接成功不代表应用/对局正常。

## 输入与输出合同

```text
输入：ADB serial、连接模式、视频/音频参数、控制事件和录制路径。
输出：视频/音频帧、录制文件、连接日志、控制回执和退出码。
失败：ADB 失联、服务端启动失败、编码器异常或控制事件丢失时保存日志并要求重新建立会话。
后置：输出必须绑定项目、目标版本、平台/ABI（如适用）、时间戳和证据路径。
```
