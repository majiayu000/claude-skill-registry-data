# morning-walk-habit

## When to Use

当需要启动一天，建立积极基调并获取初始能量时description

## Core Logic

# 执行步骤

1.  **输入**：早晨时段，个人状态。
    **操作**：进行户外散步。地点可以是咖啡馆、公寓周围或任何喜欢的地方。
    **判断标准**：身体得到活动，皮肤直接暴露在阳光下。
    **输出**：完成散步，身体被激活。

2.  **输入**：前一天晚上。
    **操作**：将次日的散步计划明确写下来。
    **判断标准**：计划被清晰记录，避免早晨遗忘。
    **输出**：一份明确的晨间散步行动计划。

# 输出格式要求

告知用户已完成晨间散步，并提醒其已为一天奠定了积极的能量基础。
