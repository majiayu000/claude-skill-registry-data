# life-as-game-framework

## When to Use

当需要将生活或工作中的复杂情境转化为可管理、可执行的系统时，或当感到迷茫、缺乏动力、陷入社会比较时，调用此模型来重新构建认知和行动框架。description

## Core Logic

# 执行步骤

1.  **定义游戏目标**
    *   **输入**：当前情境或生活领域（如职业发展、健康、学习）。
    *   **操作**：为该情境设定一个清晰、具体、可衡量且令人向往的长期目标（宏观游戏），并将其分解为一系列短期、可执行的子目标（微观游戏）。
    *   **判断标准**：目标是否清晰到可以立即开始行动？子目标是否能在短期内（如一周或一个月）完成并带来成就感？
    *   **输出**：一个宏观游戏目标和一系列微观游戏目标。

2.  **建立规则框架**
    *   **输入**：上一步定义的宏观与微观游戏目标。
    *   **操作**：为达成这些目标，设计一套明确的“游戏规则”。规则应包括：
        *   **行动准则**：每天/每周必须执行的具体行动（如“每天写作500字”）。
        *   **边界约束**：禁止或限制的行为（如“工作时不刷社交媒体”）。
        *   **反馈机制**：如何追踪进度（如使用打卡表、数据仪表盘）。
    *   **判断标准**：规则是否足够具体，能框定注意力，减少决策疲劳？是否建立了清晰的反馈回路？
    *   **输出**：一套书面的、可执行的个人规则系统。

3.  **校准挑战与技能**
    *   **输入**：当前游戏目标、规则框架，以及对自我当前技能水平的评估。
    *   **操作**：评估当前任务（挑战）的难度与自身技能的匹配度。
        *   **IF** 挑战远高于技能 → **操作**：将挑战分解为更小的步骤，或先通过训练提升相关技能。
        *   **IF** 挑战远低于技能 → **操作**：增加挑战的难度或复杂性，以引入新的学习点。
        *   **IF** 挑战与技能大致匹配 → **操作**：保持当前路径，专注于进入心流状态。
    *   **判断标准**：任务是否既不会因太简单而无聊，也不会因太困难而焦虑？是否能感受到适度的专注和成长？
    *   **输出**：一个经过调整的、挑战与技能平衡的“游戏关卡”设计。

4.  **塑造玩家角色**
    *   **输入**：游戏目标、规则以及挑战-技能平衡点。
    *   **操作**：有意识地定义并扮演能赢得此游戏的“玩家”角色。思考：
        *   这个角色需要什么样的信念和心态？（如“成长型思维”、“以过程为导向”）
        *   这个角色会如何应对失败和挫折？
        *   这个角色会避免哪些消耗心理能量的行为（如过度社会比较）？
    *   **判断标准**：是否能够从“被动的体验者”视角切换到“主动的玩家”视角？在面对干扰时，是否能调用“玩家角色”的信念来保持专注？
    *   **输出**：一个清晰的“玩家角色”身份认知和行为准则。

# 输出格式要求
以结构化摘要形式呈现游戏化方案：
1.  **游戏名称**：[宏观目标]之战
2.  **当前关卡**：[具体的微观目标]
3.  **核心规则**：列出2-3条最关键的行动准则和边界约束。
4.  **挑战等级**：[高/中/低]，并说明与技能的匹配情况。
5.  **玩家模式**：本次游戏应启动的“角色特质”（如“坚韧的探索者”、“专注的创作者”）。
