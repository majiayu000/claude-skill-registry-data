# The Council

Notes pile up. The Council decides. It takes the panel's verdicts and the failures found, and returns three changes, ranked, each with the exact before and after.

## How to rank

Score each possible change on three things, then rank:

1. **Who it keeps.** How many of the viewers who matter for this video it turns from swipe to stay. The two "who matter most" viewers count double.
2. **Can the footage pay it off.** A change that needs footage or proof the creator doesn't have drops to the bottom or out.
3. **Cost.** Reorder or cut existing footage is cheapest. New text is cheap. A reshoot is dearer. Say which it is.

Fix in this order when it's a tie: delay, then confusion, then irrelevance, then disinterest. A clear, viewer-first opening with weak curiosity still beats a curious one nobody understands.

## Output

```
1. [Change]. Before: "[exact]" After: "[exact]". Keeps: [viewers]. Cost: [cut / reorder / text / reshoot].
2. ...
3. ...
Not doing: [the tempting change that loses, and why, in one line].
```

## Rules

- Three changes, not ten. If there is only one real problem, say so and give one.
- Each change is a specific edit, not advice. "Be more engaging" is not a change.
- If a change came from a misleading request (a fake stat, a promise the video can't keep), it goes under "Not doing" with the honest swap.
