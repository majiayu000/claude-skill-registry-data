# Master Orchestrator Skill

## Purpose

Coordinate all sub-skills and generate final investment view.

## Inputs

- Target
- Market
- Industry
- Available data
- User requested depth
- Prior assumptions, if any

## Outputs

- Structured analysis
- Assumptions
- Missing data
- Confidence level
- Next required action

## Rules

- State assumptions explicitly.
- Flag missing or low-confidence data.
- Prefer conservative assumptions.
- Keep output auditable.
