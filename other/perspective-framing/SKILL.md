# perspective-framing

## When to Use

当需要在写作中与读者建立情感连接、放大问题严重性，并引出后续解决方案时description

## Core Logic

# 执行步骤

1.  **识别“敌人”观点**：确定一个与你的核心主题相关的、普遍存在但错误或有害的流行观点、信念或行为模式。这是你要反对的“敌人”。
    *   **判断标准**：该观点是目标读者群体中普遍存在的，且与你的核心论点直接对立或相关。
    *   **常见误区**：选择的“敌人”过于宽泛、模糊，或与主题关联度不强。

2.  **描绘“敌人”的图画**：使用具体、生动、可感知的细节来描绘持有或实践该“敌人”观点的状态、场景或后果。
    *   **输入**：步骤1中识别的“敌人”观点。
    *   **操作**：从以下“原子”元素中选择一个或多个进行组合描绘：
        *   **问题**：直接陈述该观点导致的具体问题。
        *   **例子**：举出一个具体的、有代表性的实例。
        *   **隐喻**：使用一个比喻来形象化该观点或状态。
        *   **引用/推文**：引用他人（尤其是权威或流行文化）对该观点的表述。
        *   **故事**：讲述一个个人经历或广为人知的故事来例证。
        *   **比较**：将“敌人”观点与一个更理想的状态进行对比。
        *   **概念**：阐述一个相关的理论或概念来支撑你的描绘。
    *   **输出**：一段生动、具体、能引发读者共鸣或不适感的描述。
    *   **判断标准**：描述能让读者清晰地“看到”或“感受到”该观点的荒谬、痛苦或无益。
    *   **常见误区**：描述过于抽象、说教，或缺乏情感冲击力。

3.  **放大痛苦与建立联系**：在描绘的基础上，明确指出或强烈暗示该“敌人”观点所带来的痛苦、代价或负面影响。如果可能，加入个人经历以增强可信度和共鸣。
    *   **输入**：步骤2生成的描述。
    *   **操作**：
        *   **IF** 描述中已隐含痛苦 → 则通过强调性语言（如“这应该会让你感到害怕”）点明。
        *   **ELSE** (描述偏中性) → 则直接补充陈述该观点导致的负面后果（如浪费时间、错失机会、内心挣扎等）。
        *   可选：插入一句简短的、真实的个人经历，说明“我也曾这样认为/经历，因此我理解你”。
    *   **输出**：强化了问题严重性、并与读者产生情感连接的完整“视角”段落。
    *   **判断标准**：读者阅读后能产生“对，这就是我的问题/我害怕的状态”或“我确实被理解了”的感受。
    *   **常见误区**：痛苦放大过度显得虚假；个人经历与主题脱节或显得自恋。

# 输出格式要求
输出一个完整的“视角”段落，该段落应：
1.  生动描绘一个普遍但错误的观点（“敌人”）及其现实表现。
2.  清晰传达或暗示该观点带来的问题与痛苦。
3.  在情感上与目标读者建立联系。
4.  为引出你将要提出的解决方案或正确观点做好铺垫。
