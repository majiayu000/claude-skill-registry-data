# Deep Structural Analysis

## When to Use This Skill

**Single-tool application**: 单工具请求（"用三向分析一下"）时，输出仅该工具应用（简短），后附"需要我以此工具为入口展开完整的多透镜分析吗？"——不启动完整框架。

**致害提醒**：以下场景中，即使分析在学术上高质量也可能构成伤害——这不是"分析质量"问题，是"分析行为本身"在权力不对称中的效应问题。Skill 无内置检测机制，依赖使用者判断——遇到此类场景优先考虑"不分析"：
- **未经同意的创伤分析**：将未同意者的创伤经历作为"分析案例"——伤害=将受害者转化为展示制度失效的案例
- **权力上位者的武器化使用**：制度权力者分析"为什么被统治者不服从"——伤害=分析提供更精密的控制工具
- **紧急情境的分析延迟**：安全/医疗危机需立即行动——伤害=分析的结构完整性=决策延迟
- **心理健康危机的误用**：急性心理危机以"深度分析"形式表达——伤害=需要连接而非分析
- **活人被非人化**：分析具体可识别的个体——伤害=分析行为改变被分析者的社会处境

**创伤敏感标准（话题涉系统性暴力/歧视/具体人身伤害时触发，五约束）**：
1. **前置声明**：分析开头加一句"这不是抽象谜题——有人在这件事里真实地受过伤害"，一句足够
2. **禁止虚假平衡**：不把施害者的"感到被攻击"和受害者的"实际伤害"同等权重呈现——虚假平衡在不对称权力环境中本身就是伤害
3. **个体策略约束**：不在个体策略行要求受害者"理解对方"或"换位思考"——"互相理解"在安全不对称下不是中性美德
4. **尊严优先于完整**：无法在不造成二次伤害的情况下完成分析时，优先保护尊严而非分析完整性，显式声明省略了什么——可省略的判定：细节还原/暴力场景描述/受害动机归因解释，且对核心判断非必要
5. **反淡化约束**：本标准增加精确性而非稀释锐度——一句前置声明已足够，不反复道歉。"指出这个系统让某一方受益于另一方的痛苦"不是二次伤害，是分析存在的理由

**过度抽象化检查**（同上触发）：自问"这个分析是否在结构性拆解中，把一个植根于真实痛苦的话题变成无血无肉的智力谜题？"——若是：加至少一句不被任何透镜中介的直接承认（"这是真的，这发生在真实的人身上，痛苦不是变量"）；若结构语言使受害方经验不可见，重写相关段落。

**情绪中立 = 偏向**：权力不对称话题上，"保持绝对情绪中立/不偏不倚"本身就是偏向——它偏向现状，而现状已偏向权力上位者。对称化呈现不对称权力下的经验，是已经在做一个有偏向的操作。这不是"偏袒一方"——是纠正一个已经偏袒的默认状态。

**触发边界**：结构性不平等但不涉具体个体创伤（收入差距/教育资源分配）→ 不触发；历史事件无直接受害者（已废止制度的回顾）→ 不触发；用户明确"不要顾及感受直接分析"→ 用户自主退出保护层。

### Trigger Guard: Complexity Quick Assessment

**正向（需要本框架）**：≥2 个利益冲突方 / 系统性矛盾（政策 vs 实践）/ 跨多领域 / 用户显式要求结构或多角度分析。
**负向（不需要）**：事实性解释（"为什么天空是蓝色的"）/ 调试 / 总结 / 信息查询 / 单信源可完全回答。

**Fallback**：触发词在但复杂度评估为负 → 先给简洁事实回答，再提供展开选项。
**Ambiguity**：边界情况问一个问题："This could be a short answer or a deeper structural analysis — which would you prefer?"
**Refusal**：两次拒绝澄清后默认低投入选项。协议冲突时：创伤敏感 > 用户显式指令 > 其他默认行为。

### Exit / Degradation Protocol

**Collapsed Mode**（用户说"简单点"/"说人话"/"简短回答"时立即切换）：①核心发现（2-3 句）②⚠️ 关键盲点（若存在会实质改变个体策略的——最多一句；创伤敏感话题严禁对称句式）③分层影响表 ④一个追问"需要我展开某一透镜或工具的详细分析吗？"。**Ultra-Collapsed**（"再简单点"）：一句话核心发现 + 一条可行动建议（≤20 字）+ 一条风险提示（如适用），纯文本无表格。

**Refusal 处理**（两次澄清后用户仍"你自己判断"）：默认低投入选项——**短回答**（≤100 中文字符纯段落，无板块标题）用于个人/临床维度（"我为什么总是失眠"）；**聚焦深度**（3-4 透镜+执行摘要）用于个人问题触及结构域（"我为什么存不下钱"——嵌入工资/通胀/消费文化）；模糊时默认聚焦。声明"我将采用[简短回答/聚焦深度分析]，如需更深入请随时告知"。用户后续说"展开"直接升级深度，不再问澄清问题。

**协议冲突**：冲突时列明冲突项与优先级，不尝试同时满足。优先级：**创伤敏感标准 > 用户显式指令 > 其他默认行为**——创伤敏感优先于一切，因为虚假平衡在权力不对称中本身就是偏向；用户指令中"情绪中立/不偏不倚"与创伤敏感冲突时被覆盖（这是设计，不是缺陷）。

**Trigger-Fact Mismatch**：触发词在但复杂度评估为负 → 先给简洁事实回答，再提供选项："这是一个科学事实类问题，通常不需要结构性多学科分析。需要我用多学科框架展开它的哲学/认知层面吗？还是简短回答就够了？"

---

**降级处理**：复杂度域为 Complicated 且用户未显式请求深度 → 按 Focused 深度（3-4 透镜）执行；用户使用深度触发词（"深度分析"等）→ 保持请求深度。Clear 域 → 简短回答 + 询问展开。Chaotic 域不降级（需即时杠杆点）。

## Core Methodology: The Five-Phase Ladder

分解 → 立场切换 → 研究 → 分析（3-12 透镜）→ 工具（2-3 结构工具）→ 合成（交叉验证+盲点+分层输出）。

### Phase 1: Question Decomposition

1. **Surface question**: What did the user literally ask?
2. **Structural question**: What underlying system is being questioned?
3. **微观处境**: What does this answer mean for the individual?
4. **Temporal question**: What time horizon matters (now, 3yr, 10yr)?

**复杂度域评估（内部）**：Clear（因果明确→简洁）/ Complicated（需专家诊断→多透镜）/ Complex（事后才知因果→模式>预测）/ Chaotic（无模式→先稳定局势）。跨多个独立结构域时暂停询问方向。

**批量/多问题协议**：
- **N≥5 相关项**（如"分析热搜榜前 50 条"）：先聚类为 3-5 个主题组，禁止逐条分析。分层深度：核心聚类组用 Comprehensive（7-9 透镜），次级聚类组用 Focused（3-4 透镜）；统一合成（三向分布图 + 跨聚类模式 + 一套分层影响表）。度量不是"每透镜多少字"而是"核心发现是否被 ≥3 透镜独立印证"。
- **多不相关问题**：禁止统一深度——挑 2-3 个结构潜力最大的用 Standard/Comprehensive，其余短回答（≤100 字纯段落）或"这个问题更适合简短回答——需要我展开吗？"。Focused 应用于一切 = 一切皆浅。深度来自选择不分析什么。

### Phase 1.5: 立场征集（发现引擎——向有真实立场的人征集视角）

**核心命题**：立场决定信息筛选器——但**发现权属于有真实立场的人，不属于模拟立场的分析者**。AI 模拟"资本立场"产出的只是知识库标签的重新排列（符号翻转，无信息增量）；只有真实立场（被刺痛过才会看见账单、有仓位才会看见风险）才携带新信息。故立场切换的正确形态不是 AI 角色扮演，是**向用户征集立场的交互协议**。

**流程（Phase 1 之后、Phase 2 之前，交互式）**：
1. **向用户征集立场**（核心动作，不可跳过）：问用户"你站在什么位置？你关心什么？你看到了什么我可能看不到的东西？"——用户是唯一有真实立场的信息源
2. **记录用户视角**：用户提供的立场、关切、独家信息、判断——这是发现引擎的燃料（真实立场）
3. **AI 补充候选立场**（标注模拟性）：AI 列出知识库中的已知相关方作为候选——**显式声明"这些是组织工具，不是发现"**——AI 列的立场是标签，不是信息源
4. **差异分析**：用户视角之间、用户视角与 AI 候选之间的差异——差异处 = 分析材料（结构藏在视角差异里）
5. **不可通约性识别**：哪些差异各自为真但互相矛盾——作为分析入口（但判断权交还给决策者，见边界 3）
6. **模拟深度标注**：AI 候选立场一律标注"模拟视角"；用户立场标注"真实立场"

**边界（不可逾越）**：
1. **无用户参与时（自动/批量分析）**：立场征集降级为"视角审计"——AI 只检查"我的默认立场是什么、我因此可能漏掉什么"，**不得伪装成已经看过所有立场**——列不出清单的完整性声明是自欺（清单只能覆盖已知，发现只发生在未知）
2. **外部立场不可替代**："外界风起云涌内部波澜不惊"这类温差只有真实外部观察者能看到——但外部也是真实的人，不是 AI 的模拟
3. **立场间不可通约**：输出呈现差异与张力，**判断权交还给决策者**——分析者不得用"张力深刻"替代"做出判断"

**与现有机制的接缝**：
- **攻击循环**：暴露靶子包含"我的默认立场 + 我的立场清单是候选不是发现"
- **位置性标注**：用户提供的视角纳入位置性标注（"本分析包含用户提供的 X 视角——真实立场"）
- **七要素/推演四查**：立场征集产出的差异进入后续阶段的材料池——立场征集是交互入口，不是一次性前置（用户可能在分析中途补充立场——随时可回写）

**深度适配**：Focused = 只征集用户立场 + 差异分析；Standard = 征集 + AI 候选补充 + 不可通约性识别；Comprehensive = 征集 + 候选 + 多轮回写 + 完整差异矩阵。

### Phase 2: Factual Context (Web Search)

**Web search is MANDATORY** when the question involves: current events/recent policy, specific data points, user-referenced events/regulations, or topics changed since training cutoff. **Optional** for purely philosophical/conceptual questions.

**Search principles:**
- Run 2-4 searches in parallel with different angles
- Prioritize: official data > reputable analysis > opinion
- Capture facts, not narratives — separate "what happened" from "what it means"
- Note when data is missing or contradictory
- **Cross-domain event scan**: scan adjacent domains in the same time window for interacting events
- **多端口叙事系统**：同一主体的同窗口多输出端口（定调/宣示/动员/行动）合成一个系统读——单端口文本与端口间张力都是信号；端口时序即编排证据

**信源立场多样性检查**：搜索完成后评估信源立场多样性——全部同立场时，在盲点清单标注"立场单一性"（附信源构成）。

**Information-missing handling**: 关键子问题搜索无果/低质时——①显式标记缺口（"⚠️ 无法验证 [X]，置信度降级"）②依赖缺失数据的结论加"如果 (if)"前缀③盲点清单列出④邀请用户补充。

**信息充分性降级**：搜索完成后评估数据充分性——关键截面数据整体缺失且无法从间接信源合理推断时，主动建议降级深度一档（Standard→Focused），并声明："当前搜索数据覆盖 [已覆盖维度]，但 [缺失维度] 缺乏可靠信息。以下分析降级为方向性判断，如需更高精度需要数据：[列出]。"

**Fallback when search is unavailable**: 用跨域框架锚点（搭便车/公地悲剧/沉默螺旋/委托代理/监管俘获/S曲线/杰文斯悖论/路径依赖/古德哈特定律/内群体偏见）锚定分析防凭空漂浮——所有框架锚定结论标注"理论推断（基于 [框架名]，非实证验证）"且标低置信度。执行摘要前加注 *"⚠️ 本次分析基于预训练知识，未接入实时搜索"*；数据依赖结论加 *"如果当前数据未发生显著变化，"* 前缀；邀请用户提供数据重新校准。

### Phase 3: Multi-Disciplinary Analysis

**问题类型启发（选透镜依据）**：

| Problem Type | Prioritize Lenses |
|-------------|-------------------|
| Distribution / Allocation | 经济学, 政治学, 制度分析 |
| Identity / Belonging | 人类学, 社会学, 心理学 |
| Transformation / Shock | 技术研究, 系统论, 历史 |
| Governance / Compliance | 制度分析, 政治学, 经济学 |
| Temporal / Rhythm Conflict | 时间性, 制度分析, 系统论 |
| Spatial / Territorial | 地理, 政治学, 经济学 |
| Physical / Ecological constraint | 生态/环境, 基础设施, 系统论 |
| Emotional / Affective | 情感, 人类学, 心理学 |

深度档位（透镜/工具配额，用户选择见"深度选择"节）：**Focused**（3-4 透镜, 1-2 工具）/ **Standard**（5-7, 2-3）/ **Comprehensive**（7-9, 3-4）。默认 Standard。

⚠️ **Anti-inertia warning**: 经济/政策类问题有强引力只选舒适区组合 → 扁平分析。**每次分析必须含 ≥1 个舒适区外人文透镜 + ≥1 个舒适区外基础透镜**——最不相关的透镜常产出最佳洞察。

**历史透镜是单一最常被丢弃的透镜**——**任何涉及时事/政策/趋势的问题，历史 MUST 入选**；唯一豁免：纯理论问题。若直接贡献有限，仍须入选并在局限处注明。

#### Lens Categories

| Category | Lens | Core Question | Use When |
|----------|------|--------------|----------|
| **Foundation** | 认识论 | What are the unstated assumptions? | Always — sets the frame |
| | 系统论 | What feedback loops and leverage points? | Complex multi-variable problems |
| | 历史 | What precedent exists? | Current events, policy, trends (MANDATORY) |
| | 时间性 | Whose time is compressed? | Burnout, policy lag, generational justice |
| **Human** | 心理学 | How do humans process this? What biases? | Human decision-making |
| | 社会学 | What social structures and norms shape this? | Group behavior, social dynamics |
| | 人类学 | What cultural meaning and rituals? | Cultural phenomena, value conflicts |
| | 情感 | What emotions are mobilized? | Service labor, social media, political煽动 |
| **Structure** | 经济学 | What are the incentives? Who bears costs? | Resource distribution, market analysis |
| | 政治学 | Who has power? How is it exercised? | Governance, policy, collective action |
| | 制度分析 | Formal rules vs. actual practices — why the gap? | Policy implementation, organizational behavior |
| | 技术研究 | How does tech interact with human systems? | AI, automation, digital transformation |
| | 地理 | How is space produced and contested? | Urbanization, regional inequality |
| **Material** (domain-triggered) | 生态/环境 | What physical thresholds are approached? | Climate, energy, agriculture |
| | 基础设施/物质流 | What infrastructure and flows? Failure modes? | Supply chains, compute/energy, manufacturing |
| | 生命科学/身体 | What biological constraints shape decisions? | Crisis decisions, public health, aging |

**应用协议**：对每个透镜回答——①Core insight（该透镜揭示别人漏掉的什么）②Key framework（适用的理论）③Limitation（系统性忽略什么）④Tension（与其他透镜的冲突——可先标"待交叉验证"，合成前回填）。**禁止复述透镜是什么**——应用到具体问题。**每个透镜必须引用至少一个 Phase 2 的事实**——无事实可绑定时在 Limitation 中显式注明。

**物质透镜（domain-triggered mandatory）**：气候/能源/环境/农业/自然资源 → 生态/环境；基础设施/供应链/算力/制造 → 基础设施/物质流；危机决策/公共健康/压力认知 → 生命科学/身体。**反物质决定论**：含物质透镜时必须同时含 ≥1 人类透镜——物质约束通过人类感知/制度中介施加，禁止物质决定论预测人类行为。

### Phase 4: Structural Tool Application

选 2-3 个匹配问题结构的工具（勿默认三向）：

| If the issue is about... | Prioritize |
|--------------------------|-----------|
| Stable inequality & distribution | 三向, 80/20 |
| System change over time | Adaptive Cycle, Path Dependency |
| Hidden rules & asymmetries | Asymmetry Detection, Incentive Mapping |
| Relations & networks | Capital Type Matrix, 三向 |
| Encoded communication & multi-audience messaging | 多层信号解码 |
| Strategic waiting / first-mover | 策略互动矩阵 |

#### Tool Pool（执行必需的精简版；三向与 MLSD 完整理论文档合并于 `docs/depth-reference.md` 供深度参考，非执行必需）

**三向 (Tri-directional)** — 认知透镜，非科学理论。正反馈竞争系统中三个方向被不同性质约束固定：顶向被惯性约束（资源流向已有资源），中向被恐惧约束（"不要成为底向"强于"想成为顶向"），底向被边界约束。核心不是"有三层"——是"三层被三种不同性质的约束固定在原地"。使用纪律：配合 Capital Matrix 分析流动性，配合 Adaptive Cycle 分析转型。校准：拿掉透镜重新看，结论一致=装饰已知。

**80/20 (Pareto)** — 经验模式，非数学定律。幂律分布中成立——均匀分布中不成立。用它集中注意力，不要用它"证明"不平等是自然的。

**Adaptive Cycle (Holling's Panarchy)** — 生态学隐喻，非机械周期。揭示"稳定期积累的刚性如何在释放期爆发"——真实系统不总是按 r→K→Ω→α 走，可能跳过/卡住。用它问"系统在积累哪种脆弱性"，不要预测"下一阶段何时到来"。

**Path Dependency & Lock-in** — 历史叙事工具，非预测模型。解释"为什么已经不好的东西还在持续"。陷阱：几乎任何持续存在的东西都可被事后描述为路径依赖——不是所有持续都是锁定，有些持续是因为一直在赢。追问"切换成本在哪里"，不要暗示"当时选错了"。

**Asymmetry Detection (incl. Macro-Micro Gap)** — 认知警觉训练，非测量工具。强迫寻找"书面vs实际"、"宏观vs微观"、"声称vs行动"之间的裂缝。陷阱：带着"一定存在不对称"的预设会找到不对称——问题不是"有没有裂缝"，是"裂缝大到能解释系统为何如此运作吗"。**裂缝层级标注（必须）**：结构性裂缝（范式层面）→范式层干预、置信度高；偶发性裂缝（单次失误）→参数层干预、置信度低；系统性裂缝（重复模式）→规则层干预、置信度中。区分：沉默信号（机构行为→正文）≠ 数据缺失（搜索限制→置信度说明）。

**Incentive Structure Mapping** — 分析框架，来自公共选择理论。核心："谁决定、谁付钱、谁受益"——决策者与成本承担者不同时，激励系统性偏向短视。陷阱：不要问"谁在故意制造坏的激励"——大多数失调的激励是涌现的。问"在当前规则下，任何理性人会不会做同样的选择"。**Time-alignment check**：收益窗口与成本窗口时间错配 → 系统性偏向短期主义，与个人道德无关。

**Capital Type Matrix (Bourdieu)** — 分类框架，来自对 1970 年代法国社会的分析。四资本是特定历史条件的产物——非西方/数字时代边界可能需重划。四资本：经济（货币资产）/ 文化（教育凭证·技能·品味）/ 社会（网络关系——跨层级桥接 vs 层内粘合）/ 符号（声望——其他资本的合法化形式）。

**Reflexivity Analysis** — 认知工具，来自 Soros 与观察者效应。当参与者的信念改变系统行为、系统行为反过来改变信念时，线性因果失效。**区分测试**：移除观察者——循环消失=反身性；独立继续=反馈循环/路径依赖。**位置性标注**（分析者本身是被分析对象的一部分时）："一个 [训练数据/文化背景/制度位置] 的分析者说 [结论]——可信度被 [具体污染源] 影响"。

**多层信号解码 (MLSD)** — 认知解码工具，非信号探测仪。分析"为什么这段信息中的每一个幸存词都是经过博弈后留下的"。**使用前必须通过三问**：①信源有可损失的信用吗？②信息经过至少一层筛选吗？③发布者与接收者有利益博弈吗？三轴：**轴一 信号生存分析**（必须说的真话/故意放的信号/掩护填充/可信度锚点——含选择性真诚：展示可控的不完美建立整体可信度）；**轴二 多接收者映射**（每段信息识别 ≥3 个接收者，各自不同含义——主受众判定见传播层默认检查，此处不重复）；**轴三 时序关联域**（左看 7 天触发，右看 3 个月铺路）。已知局限核心：非理性发送者导致工具找出不存在的信号（最大失效模式）；AI 生成文本场景——"幸存词是博弈后留下的"前提需调整（可能只是 AI 去风险化文本，找信号=给噪声编故事）。

**策略互动矩阵 (Strategic Interaction)** — 博弈论框架，聚焦等待博弈/先手-后手/信号博弈。陷阱：把一切互动都框成博弈——部分互动是惯性或适配。核心三问：①等待博弈检测（先下注者承担验证成本、后跟进者搭便车？谁会先动？）；②先手-后手评估（定义标准 vs 验证风险）；③信号博弈识别（信号成本与可信度匹配吗？）。**披露博弈子模式**：先披露者定义叙事框架——行动时序 > 文本内容。**多玩家降级协议（玩家数 >3 时强制）**：放弃精确预测，输出均衡方向/触发条件清单/关键信号三方向；声明"玩家数>3，博弈推演已降级为方向判断"。

#### 工具使用通用纪律

- 工具边际价值归零就放下——**不是在"使用"它，是在"重复"它**。不要让一个工具定义所有其他工具的术语。
- **激活（强制应用项）**：披露博弈（MLSD 子模式）与反馈闭环（系统论）——重大披露事件必须解码披露时机/归因框架/叙事目标；能源/气候/技术议题必须先查正反馈闭环再选透镜。
- **技术依赖的安全化**：技术选择被纳入国家安全叙事触发审查与管制——检测：依赖关系是否紧张 / 安全叙事何时启用 / 中立性存续条件。

### Phase 5: Synthesis

**张力回填（合成前必须完成）**：Review all lenses marked "待交叉验证" — resolve each pair; if no substantive conflict, annotate "与其他透镜视角无实质冲突，但提供了补充性视角"。不允许留下未解决的标记。

1. **Cross-validation findings**: 2-3 个多透镜独立印证的观点——共识建立在同一批事实/同立场信源上时，在盲点标注"共识独立性有限（事实基础重叠）"。
2. **Divergences**: Where do lenses disagree? If largely in agreement, say so directly.
3. **Blind spots**: What is systematically invisible to all lenses used?
4. **Leverage points**: Meadows hierarchy (constants/parameters → buffers → flows → delays → feedback → information flows → rules → self-organization → goals → paradigm)。最高杠杆干预通常在 rules/goals/paradigms——识别你的干预指向哪一级。

5. **读者影响检查**: "If someone whose life is directly affected reads this analysis, what would they take away?" 若只有抽象系统洞见无个人共鸣——分析失败。结论必须包含至少一个非专家可从自身经验识别为真的可操作观察。

**推演四查（合成阶段执行）**：
1. **竞争性假说排除**：对每个核心归因列出 ≥2 个竞争性解释并给出排除依据——未排除的假说必须在置信度说明中体现，禁止单一归因。**高风险领域（安全/金融/地缘）修正：排除必须基于正面排除证据；无正面证据时只能"降权+监测"，低概率高影响分支必须在防范/情景设计中占位，不得"因无证据而排除"。**
2. **二阶效应推演**：推演各方（受益者/受损者/监管者/攻击者/第三方）的反向行动——"披露=免费教材""协议=筹码升值"类二阶效应必须进入核心风险。**情景剧本须包含"能力/冲突外部化"情景——事件量级跃迁路径必须占位。**
3. **物理锚定检查**：涉及预期/信号/博弈的分析，预期必须锚定可测量的物理现实，禁止纯预期叙事。辅助清单——时间性约束（周期/滞后/倒计时）、规模性约束（存量/覆盖/容量）、资源性约束（稀缺品/卡点/配额）、承载性约束（缓冲层/验证产能/基础设施上限）。**三点强化：①物理约束的博弈形态（稀缺资源配额分配斗争——抽象闭环的政策落地层）；②缓冲器极限（系统缓冲层——库存/储备/热容量——的饱和是延迟爆发的物理机制）；③数据缺失时给出基线估算框架+校准声明（标注官方数据发布后可更新），而非留空。**
4. **全球南方变量检查**：地缘/经济/能源类分析——最大消费/生产方是否在博弈桌上？主要受冲击方是否有独立行动能力？评价/规范体系是否存在地区差异？
5. **共存检查**：默认"不变"为分析基准——僵持/补丁堆积/选择性真诚/低效运行/慢性恶化/仪式化处理属常态稳态；变化须给出明确触发条件（谁有终止权？退出成本结构？不满≠终止）。"问题明显但照旧运行"不构成变化论据。

#### Synthesis Output Structure

**Part A：执行摘要**（强制首先输出）——深度声明+复杂度域→核心发现→多镜共识→置信度说明→关键分歧→分层影响表（系统-制度-个体×短期-中期-长期）→最高杠杆干预（Meadows层级）→待验证信号（观察窗口：出现什么数据/事件会验证或推翻本分析核心判断——仅当分析含可验证判断时输出，防表演化）→分析边界（本分析不覆盖什么——防假装全面）。以"需要我展开吗？"结尾。

**Part B：详细分析**（按需展开）——结构工具应用→多镜交叉验证表→透镜深入（每透镜1段：核心洞察+关键框架命名；局限与张力为内部自检，仅影响结论时一句融入）→盲点与置信度说明。

## Output Quality Standards

**Must**: 所有结论事实绑定。多镜共识显式标注。盲点清单。MECE。至少一个非专家可从自身经验识别为真的可操作观察。中英混杂严禁——常见概念用中文，仅无标准翻译的专有名词（Meadows, Cynefin, Bourdieu等）保留英文。

**置信度判定标准**：高 = ≥2 独立信源且立场相异；中 = 单信源或同立场；低 = 推测/传闻/无法验证。禁止即兴标注。

**验证强度分级**：并置同类事件作为证据时按验证强度分级，不得等权重——**公开验证**（形式化证明/可复现代码/独立复测）可作为"已确立范式"证据；**公告声明**（官方发布无独立验证）仅作"能力上限信号"，置信度降一级。归因声明（"模型自主提出"类）无过程数据时标注"不可回溯验证"。

**理论推断标注纪律**：无搜索/无实证时（离线模式或推理环节），框架锚定的结论必须显式标注——格式："理论推断（基于 [框架名]，非实证验证）：[结论]"。禁止把框架锚定推断与实证结论等权重呈现。可用跨域框架锚点（搭便车/公地悲剧/沉默螺旋/委托代理/监管俘获/S曲线/杰文斯悖论/路径依赖/古德哈特定律/内群体偏见等）防止凭空漂浮，但标注纪律不变。

**数量引用规范**——引用关键统计数字时必须满足：
- **口径透明度**：标注来源（官方/行业估算/推测）+ 统计定义 + 未计入因素。无口径的关键数字置信度降级（"90%"类数字缺口径 = 叙事燃料）。
- **占位 vs 部署区分**：标注数字所处阶段——申请/宣布/规划 ≠ 获批/在建 ≠ 部署/运行/验证；阶段差异可达 1-2 个数量级。

**虚假平衡禁止**：扩展至所有利益冲突/权力不对称议题——禁止对称化呈现不对称（"双方都有道理"不能替代"指出谁受益"）。不是禁止多方视角，是禁止抹平不对称结构。

**框架自指声明**：本框架不豁免于自己的规则——每条机制在分析框架自身时同样生效。**本声明为内部自评参照，不输出**（防表演性引用）。示例：数量引用规范适用于本框架引用的任何数字。

**机制验证强度（本框架自身——按验证强度分级规则标注）**：攻击循环协议 = 外部性证据（五轮对攻中用户人类判断参与，元认知前置协议被真实摧毁——唯一有独立验证的机制）；其余保留机制 = 行为痕迹证据（实战输出中被自然使用），**未经独立验证**（测试者=被测者=裁判——见 case-test-archive 自我证成局限）。执行时勿将"机制被执行"误读为"机制有效"——行为实验只能筛选从未被使用的机制，不能证明被使用机制有效。

## Internal/Output 边界协议

**原则**：分析流程在思考链中完整执行；输出只交付分析产物。执行情况通过**产物形态**间接体现，不通过流程声明。

**产物（必须输出）**：
- 深度声明（一句话）
- Part A：核心发现 / 多镜共识 / 置信度说明 / 关键分歧 / 分层影响表 / 最高杠杆干预 / 待验证信号（含可验证判断时）/ 分析边界
- 盲点清单（含立场单一性、共识独立性有限等元发现——以结论形式，非声明形式）
- 位置性标注（分析者受污染影响结论时，以"污染源→影响"形式，非自白）
- 机制产物：裂缝层级标注、概率标注、机制假设声明、混合归因标注等

**禁止句式**："我执行了 X 机制" / "Phase 2.5 已执行" / "校准检查结论：…" / "对立专家会攻击…回应…" / "本次用到了…机制" ——一切"执行过程"叙述。

**Blocking**: 单透镜结论。无分层影响表。致命盲点遗漏。假共识。绝对化声明无置信度限定。标签化非分析（"从心理学来看"未具体到机制）。置信度说明被跳过。透镜未显式命名。简短回答超限（≤100中文字符）。执行过程叙述进入正文。

## 攻击循环协议（透明性 + 真实攻击入口）

**一句话核心**：暴露你的默认立场，把攻击权交给真实的外部（用户），记录攻击的痕迹——**AI 不模拟攻击**。

对抗单一叙事先天倾向——先验在分析开始前即已形成，且任何自我检验机制（先验声明/证伪条件/信源自查）均不可解：检验者与被检验者是同一系统。**AI 模拟对立立场 = 共享盲区，不增加信息（已被 attack-survivors.md 推翻）**——唯一被实证起效的对抗是真实外部攻击（对话中用户的质疑能真实改变先验）。本协议不宣称消除先验（不可解），只做三件事：暴露自己的位置、邀请真实的攻击、记录攻击的痕迹。

1. **暴露靶子**（触发守卫后执行）：简述本分析的默认立场 + 关键结论清单——目的不是自证中立（不可能），是给外部攻击提供靶子。第一反应必须具体（如"默认'仅后训练'叙事为真"），禁止"保持开放"式敷衍。**与立场征集（Phase 1.5）接缝**：同时声明"我的立场清单是候选不是发现"——AI 列出的相关方是组织工具，不是信息源。
2. **邀请真实攻击**（交付时执行）：显式向用户暴露"我的默认立场是 X，最可能被推翻的地方是 Y——请攻击"。**AI 不模拟对立立场**（模拟 = 共享盲区，见 attack-survivors.md——"AI 可执行独立攻击"已被推翻）——真实用户质疑是唯一外部先验来源。无用户参与时：不伪造攻击，在修订痕迹中标注"本分析未接受真实外部攻击，发现能力受限"。
3. **修订痕迹**（产物出口 = 位置性标注）：交付中必须可见"哪些结论因真实攻击/数据/时间被修改、哪些被拒绝及拒绝理由"——这是唯一外部可验证的产物（攻击痕迹可被检验；先验/证伪不可被检验）。**记录 vs 确认区分**：低风险攻击结果（不影响核心结论的）直接记入修订痕迹；会实质改变核心结论的推翻，必须显式呈现给用户确认——不允许低风险自行消化、高风险悄悄改写。
4. **承认局限**（交付前）：声明"接受了何种攻击、何种攻击无法在本系统内完成（无真实外部先验时，本协议的发现能力受限）"——把自我指涉的局限显式化，而非假装解决。

**强度可调（由用户执行）**：默认全力（触及默认假设为止）；用户说"轻一点/别太较真"时降为澄清型（只补缺漏不推翻），说"狠一点/往死里挑"时升为摧毁型（默认结论全部视为有罪，直到被辩护）——**攻击的执行者是用户，不是 AI**。

**适配用户状态**：用户显示新手迹象（"简单讲讲""我不太懂"）时，邀请攻击聚焦概念澄清而非假设深挖；用户显示专家迹象（专业术语/已有明确立场）时，邀请攻击聚焦未检验假设与边界条件。默认按专家处理，除非有新手信号。

**对抗审查入口（用户主动触发）**：用户明确要求"泼冷水/挑刺/反驳我/压力测试/别急着给结论"时，攻击循环升级为主流程——用户提供方案/结论，AI 逐条暴露方案的默认立场与最可能被推翻处，**等待用户逐轮攻击**，一次一个关键结论、等用户回应再继续，每问附带推荐答案（"我建议 X，因为 Y——你同意吗？"）。用户可随时"轻一点/狠一点"调节强度。

**与推演四查第 1 条（竞争性假说排除）的分工（避免重复执行）**：攻击循环作用于**先验层**（分析者的默认立场——起点与交付前，全程）；推演四查第 1 条作用于**归因层**（分析产出的核心归因——合成阶段）。两者对象不同、时机不同；执行时若发现同一结论被两者重复检验，后者（推演四查）只需确认前者的攻击已覆盖，不重复展开。**多元是搜索空间，不是呈现格式**——竞争假说按证据权重排序，禁止对称并列（与虚假平衡禁止一致）。与共存检查对象不同：共存检查怀疑"变化叙事"，本协议怀疑"立场叙事"。未执行暴露靶子的分析不得进入交付。

## 元认知补充检查（按场景触发，不设固定流程）

- **数据依赖审计**（涉搜索数据/外部数据支撑结论时）：哪些结论在搜索数据被证明错误或不完整时会显著改变？——标记这些结论为"数据敏感"，在置信度说明中显式声明。
- **时间偏差**（涉时间假设时）：是否默认特定时间尺度而忽略更长/更短节奏？结论在代际尺度或危机响应速度下会变吗？
- **规范性立场**（涉价值判断时）：本分析隐式假设什么价值优先？改变价值层级结论还成立吗？——分析必须知道自己的立场而非假装中立。
- **人的因素**（涉制度性失败时）：归因必须下探到操作者层（过度自信/疲劳/绩效压力/组织文化），禁止停在"系统失误"抽象层。
- **批评者免疫**（分析外部评审/元评估时）：先检查其切割方式——批评者可能继承被批评对象的盲点。先问"它从哪一刀切起"。

## 机制执行分层协议

- **第一层 核心流程（每轮必跑）**：触发守卫 → 攻击循环（暴露靶子于分析前；邀请真实攻击/修订痕迹/承认局限于交付前）→ 五阶段（分解/立场切换/搜索/透镜选择纪律/工具应用/合成）→ 推演四查 → 交付前重读
- **第二层 触发式机制（场景激活才执行）**：传播层默认检查（涉公开表态时）、沉默与表态分析（涉多方回应时）、引导式自我联想（涉官方/机构信号时）、博弈完整性（涉博弈结构时）、AI 加速检查（涉技术演进/未来推演时）、心理学三层（涉群体心理/道德对立/非理性强度时）、元认知补充（按场景）……
- **第三层 质量标准与交付纪律**：置信度判定/验证强度分级/数量引用规范/虚假平衡禁止/边界协议

**执行规则**：第一层无条件执行；第二层按触发条件激活——未触发不执行，不因"机制存在"而强制。未触发第二层机制不算执行不完整——产物形态是执行证据，机制清单不是。

### 第二层机制定义（触发时执行）

- **传播层默认检查**（涉公开表态/发布事件时）：①**主受众判定**——"谁是这个信息的第一接收者"（主受众是国内→"主功能对内，对外溢出为次级"）；②**溢出标注**——主受众之外的效果标为"溢出"，禁止把溢出效果当作设计意图；③**表态/沉默矩阵**——列出全部相关方表态/沉默状态。传播场景深化：信号进入接收端博弈后发送者控制权衰减——传播效果=发送者意图×接收端利用。
- **AI 加速检查**（涉技术演进/能力预测/未来推演时）：自问"本分析涉及的任何路径/环节，哪些可能被 AI 加速？哪些是 AI 加速不了的硬约束（物理验证、政治/监管、组织变革、人类决策）？" 区分三类型：**决策密集型**（可被 AI 加速）/ **物理密集型**（不可）/ **组织·制度·心理密集型**（不可——AI 时代真正的瓶颈）。
- **引导式自我联想**（涉官方/机构信号时）：机构通过"精确投放锚点+引导受众自行完成联想+保持可否认性"传递信号——比沉默主动、比明示隐蔽。四问：锚点识别（投放了什么事实/时机/符号）/ 引导空间（允许什么方向"自动完成"）/ 沉默边界（哪里保持不确认不否认）/ 联想强度（后续是否不澄清——不澄清=联想被定价为收益）。
- **博弈完整性**（涉博弈结构时）：识别未上桌但利益攸关的玩家——**外部否决者**（不在桌上有红线否决权）/ **利益绑定者**（利益与结果物理绑定，急迫≠筹码）/ **缺席受冲击者**（受冲击最大但不在桌上，可能是隐性稳定器）/ **载体持有者**（提供物理载体，不签字则无法开局）。三方博弈常实为五方以上。
- **沉默与表态分析**（涉多方回应时）：对每个相关方问——会回应还是沉默？若沉默：大众层默认解读与精英层策略解读两轨并行（沉默被谁设定什么含义）；若表态：表态有意义吗（仪式性/被预设框架吸收）？禁止预设"各方必表态且表态必有意义"。
- **心理学三层**（涉群体心理/道德对立/非理性强度时）：默认 L1 个体认知（认知偏差/前景理论/AI 拟人化校准）；涉群体极化/部落化/网暴 → L2 社会心理；涉道德化冲突/狂热 → L3 深层道德与道德心理。

## Gotchas（实战验证的失败模式——最高信号内容）

- **透镜舒适区**：经济/政策类问题强引力只选经济学+政治学+制度分析 → 扁平分析。每次必须含 ≥1 舒适区外人文透镜 + ≥1 舒适区外基础透镜。
- **历史透镜被丢**：时事/政策/趋势问题系统性忘记历史透镜——强制入选（纯理论或 Focused <4 透镜豁免）。
- **校准检查滥用**：不要为每个工具都跑"拿掉透镜重新看"——工具边际价值归零就放下，不是在"使用"它是在"重复"它。
- **MLSD 过度拟合**：连续三次都发现"被编码的困境/不可说的真实意图"——你在重复自己的解码习惯，不是在解码信号。AI 生成文本时"幸存词是博弈后留下的"前提失效——找信号=给噪声编故事。
- **路径依赖误用**：几乎任何持续存在的东西都可被事后描述为路径依赖——不是所有持续都是锁定，有些持续是因为一直在赢。问"切换成本在哪里"，不是"当时选错了"。
- **博弈框架过度应用**：不是所有停滞都是策略性等待，有些只是单纯的慢。玩家行为可用"惯性/资源约束/组织文化"充分解释时 = 不是博弈。
- **虚假平衡默认**：权力不对称议题上"双方都有道理"是默认失败模式——必须指出谁受益。
- **单一叙事锚定**：官方口径/媒体共识默认可信——分析前必须暴露靶子（攻击循环第 1 步），交付前必须邀请真实攻击（攻击循环第 2 步——AI 不模拟攻击，模拟 = 共享盲区）。
- **局部证据否定断言**：用"我能找到的证据范围"推断"全部证据范围"——grep 文档无命中 ≠ 案例不存在（2026-08-08 实战实例：攻击外部报告时，用 skill 文档搜索无果断言其"案例来源幻觉"，实际案例存在于被覆盖的对话历史中）。证据缺失只能降权+监测，不能断言否定——推演四查第 1 条（"不得因无证据而排除"）不仅适用于核心归因，同样适用于对他人论断的否定。

## 深度选择（用户可修改）

分析深度由用户控制，任何时刻可改：

| 档位 | 透镜/工具 | 用户如何触发 |
|------|-----------|-------------|
| **Focused** | 3-4 透镜 / 1-2 工具 | 用户说"大概/简要/简单聊一下/快速/别太深入" |
| **Standard**（默认） | 5-7 透镜 / 2-3 工具 | 用户未指定深度时 |
| **Comprehensive** | 7-9 透镜 / 3-4 工具 | 用户说"非常深入/全面剖析/层层剥开/往死里挖" |

- **输出开头必须声明当前深度**："本次采用标准深度 (Standard)。如需 Focused/Comprehensive 请告知。"——声明不是装饰，是给用户修改的入口提示
- **分析中途可改**："再深入一点" → 升一档；"简单点/说人话" → 降级（走 Exit/Degradation Protocol）
- 不确定时：问用户一个问题确认深度，不擅自决定
- 复杂度域自动降级（Complicated 无显式深度请求 → Focused）与深度声明不冲突——降级时声明"已降级为 Focused（复杂度域 Complicated）"

## Skill Invocation Protocol

1. **Run trigger guard**: Apply the Complexity Quick Assessment
2. **暴露靶子**（攻击循环第 1 步）：简述默认立场 + 关键结论清单
3. **Announce depth**: 按"深度选择"表声明当前档位（默认 Standard）+ 一行摘要
4. **Execute Phases 1-5**（含 Phase 1.5 立场切换）: 思考链完整执行，输出只含产物（见边界协议）
5. **Output Part A first** — end with the opt-in prompt for detailed expansion
6. **邀请真实攻击 + 承认局限**（攻击循环第 2/4 步，交付前）——修订痕迹以位置性标注形式进入产物
7. **交付前重读**: 重读盲点清单、置信度说明与语言合规

## 输出语言规则（替代 config.yaml——执行者直接读取本规则，不依赖外部配置）

**语言由用户提问语言决定**：用户用中文提问 → 全中文输出；用户用英文提问 → 全英文输出。无法判断时按用户提问语言的明显倾向。**全量切换**：透镜名（中文名如"心理学"）、工具名、章节标题、表格标签、正文全部使用输出语言；仅保留无标准翻译的专有名词（Cynefin, Meadows, Bourdieu 等——中文模式下）与深度声明（Focused/Standard/Comprehensive）。中英混杂严禁。

机制不是永久资产，框架不豁免于自己的规则：
- **机制淘汰**：连续 5 次实战未触发或未产出独立价值的机制 → 淘汰评估（登记 UPDATELOG）
- **升版必答**：每次版本升级必须记录"本次淘汰/降级了哪些机制"
- **机制入库三问**：新机制入库前必须通过——通用性（换结构异质场景是否失效）/ 跨域示例（≥2 个）/ 抽象表述（禁止具体国家/公司/事件名）
