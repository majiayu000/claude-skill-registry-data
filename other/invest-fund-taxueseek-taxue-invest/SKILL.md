# invest-fund：基金分析

## 哲学锚点

- **巴菲特「成本意识」**：费率差异 2%，30 年差距 50%+ 收益。
- **约翰博格「指数优先」**：大多数主动基金长期跑不赢指数。
- **能力圈**：基金经理的策略你理解吗？能说清他怎么赚钱吗？

## 场景路由

先按场景进细则，再走三问框架：

| 场景 | 适用 | 细则 |

## 分析框架

### 三问准入

| 问题 | 核心指标 | 判断标准 |
|------|----------|----------|
| 了解策略吗？ | 投资范围、行业集中度、换手率 | 能向外行说清 |
| 能持续跑赢吗？ | 近 1/3/5 年收益 vs 同类排名 | 前 30% 持续 |
| 成本合理吗？ | 管理费+托管费+申购赎回费 | 同类最低 1/3 |

### 深度维度

1. **基金经理七维度分析**（见下方专项）
2. **投资组合**：持仓集中度、行业配置、前十大重仓、换手率
3. **业绩风险**：最大回撤、夏普比率、波动率、下行捕获
4. **业绩持续性**（见下方专项）
5. **申赎行为**：份额变化、持有人结构（机构/个人比例）
6. **费率结构**（见下方专项）
7. **平台与成本优先**：低佣金、申购赎回效率、靠谱渠道（天天基金/数米等）

### 业绩持续性检验

| 指标 | 计算方法 | 判断标准 |
|------|---------|---------|
| 滚动收益率 | 过去 1/3/5 年每年收益率 | 正收益年份 > 70% |
| 排名稳定性 | 同类排名分位波动 | 标准差 < 20% |
| 超额收益持续性 | 每年超额收益的稳定性 | 正超额年份 > 60% |
| 风格稳定性 | 持仓风格漂移检测 | 无显著漂移 |
| 经理稳定性 | 任职期间业绩连续性 | 无频繁跳槽 |

**关键判断**：单年业绩好不代表可持续，需要 3 年以上验证。警惕「流星型」基金（单年爆发，长期平庸）。

### 费率结构细节

| 费率项 | 范围 | 影响 | 优化建议 |
|--------|------|------|---------|
| 管理费 | 0.15%-1.5%/年 | 直接影响净值 | 指数基金选 0.15-0.5%，主动基金选 0.8-1.2% |
| 托管费 | 0.05%-0.25%/年 | 次要影响 | 通常无选择空间 |
| 销售服务费 | 0-0.8%/年 | C 类份额特有 | 短期持有选 C 类，长期持有选 A 类 |
| 申购费 | 0-1.5% | 一次性 | 平台通常有折扣 |
| 赎回费 | 0-1.5% | 持有 < 7 天惩罚性 | 避免频繁申赎 |
| 超额业绩报酬 | 0-20% | 部分基金有 | 关注计提方式（高水位/基准） |

**综合费率计算**：管理费 + 托管费 + 销售服务费 + 申购赎回费摊销。30 年复利下，2% 费率差异 ≈ 50%+ 收益差异。

### 基金经理七维度分析

| 维度 | 核心问题 | 判断标准 |
|------|---------|---------|
| 能力圈 | 主要投哪些行业？有无明显偏好或回避？ | 有清晰能力圈边界 |
| 风格稳定性 | 近三年是否发生风格漂移？ | 无漂移，价值/成长/均衡标签稳定 |
| 规模适配 | 当前规模是否适合其投资策略？ | 5-50 亿为舒适区，>100 亿警惕 |
| 平台实力 | 公司投研实力、团队支持、公司文化 | 以主动权益见长，不依赖明星经理 |
| 业绩归因 | 超额收益来自能力还是运气/风口？ | 风口占比 < 50%，持续 3 年以上 |
| 职业稳定性 | 是否频繁跳槽？ | 同一家公司 3 年+，管理基金 ≤ 5 只 |
| 运气成分 | 近一年业绩是否远超同类？自己是否跟投？ | 远超→警惕均值回归；跟投→加分 |

评分方法：每维度 1-5 分，总分 35 分。28-35 优秀 / 21-27 良好 / 14-20 一般 / <14 较差。

### 行业轮动基金评估

行业轮动基金需额外评估以下维度：

| 维度 | 核心问题 | 判断标准 |
|------|---------|---------|
| 轮动跨度 | 在哪些行业间轮动？ | 跨行业 > 单行业内 |
| 左侧/右侧 | 提前布局还是追趋势？ | 左侧更考验能力 |
| 持仓集中度 | 前十大重仓占比？ | < 60% 为宜 |
| 换手率 | 年换手率？ | > 300% 需警惕 |
| 产业趋势 | 从产业趋势出发还是纯博弈？ | 产业趋势→加分 |
| 估值匹配 | 是否结合估值？ | 结合→加分 |

投资者适配性：净值波动大、与基准差异大→适合心理承受力强的投资者；短期爆发力强→适合小仓位试水；长期业绩不稳定→不适合底仓。
