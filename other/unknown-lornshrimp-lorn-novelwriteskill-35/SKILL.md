# 通用-审阅故事设定
> **题材路由**：若 .github\题材专用Skills\ 目录存在对应的 <题材>-审阅故事设定 Skill，则：
> - 将题材特性骨架路由到 <题材>-审阅故事设定，该 Skill 位于 .github\题材专用Skills\ 目录。
> - 命中本技能时，必须优先强制加载当前 Skill 与 <题材>-审阅故事设定。


> **头号要求：禁止吹捧，客观分析。** 审阅中不得出现无依据的称赞、吹嘘性描述或主观美化。所有判断必须基于文本事实、可验证标准与明确扣分依据，优先指出问题与改进方向。

审阅故事设定，重点不是“懂不懂技术”，而是“能不能进故事、能不能留下痕迹、会不会变万能”。

## 继续读取的 references（强制读取门禁）

**以下所列 references 文件必须通过 `read_file` 工具逐文件读取，不得因"已有相关知识"、"之前执行时已读过"、"该文件只是参考"为理由跳过任何一条。** 每条 references 按其标注的必读等级强制执行：

- 标注 **必读** 的文件：必须读取，少一条即视为流程违规，不得开始执行流程。
- 未标注必读的文件：必须读取，但读取后可仅提取与当前任务直接相关的段落，不要求逐字通读。
- 若文件路径指向的文件不存在（如引用的外部路径未就位），必须在日志中显式记录 `reference_missing_{refName}`，不得静默跳过。

每个参考文件在 `## 默认执行顺序` 中有对应的读取步骤说明，此处仅汇总文件清单与用途概览。

- `references/故事设定审阅检查清单.md` — 逐项检查清单，在步骤 2 通读设定文档时逐条核对（含规则可执行性、边界与代价是否明确、是否可证据化、是否具备程序摩擦与镜头化表达）
- `references/审阅维度说明.md` — 设定审阅各维度（可执行性、可证据化、叙事化、代价承受）的定义与评分细则，在步骤 5 评分时加载

- `references/腾讯专栏故事设定可证据化与边界风险增补.md` — 跨平台通用：设定可证据化程度（规则是否留下可追踪的程序痕迹）与边界风险管理（是否写了明确的禁区、失效条件、升级路径），在步骤 3.1 加载

## 默认执行顺序

故事设定审阅按以下步骤执行，每一步标注了应读取的参考文件：

### 步骤 1：审阅前准备
1.1 确认目标故事设定文件范围，收集关联的人物传记、总纲、证据链文档中与本设定相关的内容。
1.2 若项目根存在 `Agents.md`，执行 `## 风格/蓝本/写作研究模板自动发现规则` 并加载对应的蒸馏模板对标维度。
1.3 加载 `references/故事设定审阅检查清单.md`，作为逐项核对的底表。

### 步骤 2：通读与规则审计
2.1 完整通读设定文档一次，不做中断判断。逐项核验规则条款清单、边界/代价/漏洞、现实可行性与程序合理性。
2.2 执行"一句话口径"验证：看是否能以"动作 → 凭证 → 后果"说清设定是什么、怎么起效、为什么危险。
2.3 执行起点爆款设定快筛（10 秒快筛 + 金手指/核心机制变现力复核 + 起点潜力分档），辅助判断设定的商业竞争力。

### 步骤 3：专项审阅
3.1 加载 `references/腾讯专栏故事设定可证据化与边界风险增补.md`，检查设定的可证据化程度与边界风险管理。
3.2 执行 IP 改编友好度复核（可视化是否清晰、高光节点是否明确、调用成本是否适中）与传播讨论点复核（规则反常点、现实刺点、立场分裂点、可截图物料点）。
3.3 执行情绪建筑与读者心理回报审阅（情绪锚点兑现检查、首秀窗口内锚点兑现、负面情绪占比等）。
3.4 若加载了蒸馏模板对标维度，按蒸馏对标审阅规则执行对标审计。
3.5 **执行设定"破格"与可预测性审阅**（吸收自知乎《最近弃了七本书》核心洞见）：
   - 检查设定的可预测性：读者在前3章能否预测到第10章的设定发展？如果"能，因为同类设定都是这么发展的"，判定为可预测区域。
   - 检查设定的"破格"密度：每卷是否有至少1个设定层面的"破格时刻"（翻转读者预期、代价反常、进化反常或后果反常）。连续2卷没有破格判定为"设定进入可预测区域"。
   - 检查"太对了"风险：设定文档是否读起来标准、正确、但缺乏让人意外的反转锚点。
   - 检查破格的保真性：破格是否以牺牲规则的内部自洽为代价？如果是，破格应降级或补充"规则裂痕"说明。
   - 以上检查项的问题来源层标注：`[破格审阅]`。

### 步骤 4：构建审阅报告
4.1 加载 `references/设定审阅报告模板.md` 作为报告主骨架。
4.2 交叉对照 `references/故事设定审阅报告增补.md`，补写蒸馏对标审计（若已执行）、起点潜力分档、IP 改编友好度、传播讨论点复核、情绪建筑审阅结论。
4.3 确保报告完整覆盖 + 至少产出 1–3 张"写作落地卡片"。
4.4 给出 Green / Yellow / Red 入库判定及起点潜力分档（S/A/B/C）。

### 步骤 5：评分
5.1 加载 `references/审阅维度说明.md`，按可执行性、可证据化、叙事化、代价承受等维度逐项评分。
5.2 综合评分低于 9.20 的需附具体优化路径与最小修复补丁。

### 步骤 6：问题分级与回写建议
6.1 按 Critical / Warning / Suggestion 三级将每个问题归类。
6.2 输出最小返工处方，优先补首秀动作、代价显影、证据痕迹与禁区声明。

## 风格/蓝本/写作研究模板自动发现规则

若当前服务的项目根目录存在 `Agents.md`，审阅故事设定前必须：

1. 读取项目根目录的 `Agents.md`；若其中声明了 `主输出平台`，检索三类模板时优先匹配"适用平台"与主输出平台一致的模板，无匹配时回退到"适用平台：默认"的同类模板
2. 若 `Agents.md` 中注册了"写作研究模板"——读取对应路径的模板文件，将其设定边界、解释比例、真实感和平台禁忌作为审阅基线
3. 若 `Agents.md` 中注册了"作者风格模板"——读取对应路径的模板文件，将其作为设定表达方式、叙事距离、句长段落和禁忌风险参照
4. 若 `Agents.md` 中注册了"作品蓝本模板"——读取对应路径的模板文件，将设定显影节奏、信息释放和阶段升级作为审阅参照
5. 本 Skill 只消费与故事设定审阅相关的字段；若模板字段与规则自洽、证据链或代价逻辑冲突，规则自洽和证据链优先
6. 若项目根目录不存在 `Agents.md`，或其中未注册对应模板——回退通用默认模式，不报错，不阻断

本 Skill 默认消费字段：

- 写作研究模板：设定解释比例、真实感要求、审核边界、代价机制、禁忌类约束
- 作者风格模板：叙事距离、句长基线、段落节奏、情绪表达方式、禁忌清单
- 作品蓝本模板：信息释放节拍、场景节奏分布、中段回报指纹、章首首秀方式

### 对标审阅执行规则

1. **对标优先度**：作品蓝本模板（设定结构对标） > 作者风格模板（设定表达审计） > 写作研究模板（平台约束对标）。
2. **评分影响**：蒸馏产物对标维度在设定审阅综合评分中默认按 **20%** 计权；若未完成对标审阅或关键维度偏离显著，综合评分默认不得给高档。
3. **缺模板回退**：若缺少某类蒸馏模板，该对标维度自动跳过，不扣分，不阻断，需在审阅报告中标记"蒸馏对标盲区"。
4. **冲突处理**：与规则自洽、证据链或代价逻辑冲突时，规则自洽和证据链优先。蒸馏产物约束之间冲突时，写作研究模板的硬门禁 > 作品蓝本模板的强约束 > 作者风格模板的软建议。

## 完整模板执行要求（强制）

- 产出设定审阅报告时，必须以 `references/设定审阅报告模板.md` 作为主骨架，不得退化成“几条规则点评 + 少量建议”的简版报告。
- 报告至少要完整覆盖：阅读链路确认、基础信息检查、写作落地卡片、设定用途一句话、首次出场与前三章验证、人物—情境—观点合拍度、规则条款清单、现实可行性与程序合理性检验、网文长线与规则演进复核、边界/代价/漏洞、可证据化映射、程序摩擦与现实阻力、误导与证伪窗口、现实痛点与情绪共鸣牵引、跨文档一致性总检、社会面/舆情面/合规预警、与人物/组织对齐、叙事落地建议、问题分级、评分、具体修改方案、冲击 9.2+ 综合评分的优化思路与总体结论。
- 对承担核心能力、主线程序链、关键证据载体或终局关门功能的设定，报告必须额外显式审：**一句话口径是否为动作→凭证→后果、触发条件 / 标准表现 / 失效规则是否完整、关键参数是否区分固定值与叙事弹性、最小调用流程卡是否成立、分级代价与程序痕迹是否可见、是否明确写出“不能直接解决的问题”、是否需要本轮修订 / 终局关门 / 残留余波块**。
- 若当前任务还加载了题材 Skill，则必须在通用骨架的占位章节中继续补写题材专项段、题材专项评分项与题材化结论重点。
- 报告中必须至少产出 `1–3` 张“写作落地卡片”，让作者能把规则直接拷回大纲、章节执行表或正文镜头。

## 网文长线与规则演进（强制）

- 审故事设定时，必须把它视为“能否撑住开篇抓力、中盘升级、终局回收”的长线引擎，而不是一次性炫技说明书。
- 必须显式判断：第一次出手怎么抓人、中盘如何升级、终局会产生什么更贵后果、代价是否能被正文真实感知、是否存在读者可讨论的误导点与证伪窗口。
- 若设定承担强能力或高概念机制，还必须显式判断：它的**最小可调用版本**是什么、第一次越界会留下什么程序痕迹、终局是否必须关门 / 降格 / 留余波。
- 若设定开篇就用尽最强功能、代价只存在文档里、或误导与证伪全靠作者解释，不得判为可用高分设定。

## planner / reviewer 镜像补强（新增）

- 审故事设定时，默认继续检查它是否具备 planner 风格的**规则分层与归档口径**：世界规则是否按地点 / 规则 / 势力 / 时间线 / 专项机制分层，是否只记录已确认事实，是否区分“作者知道的真相”与“角色知道的版本”。
- 若设定把未来计划写成既定事实，或把作者真相与角色口径混成一锅，默认判为规则层事故，而不是轻问题。
- 审阅报告里的问题默认标记来源层：`[规则条款层] / [载体证据层] / [阶段演进层]`。规则条款层看边界与代价，载体证据层看痕迹与取证，阶段演进层看首秀、中盘、终局与关门逻辑。
- 默认补一个 `Green / Yellow / Red` 入库判定：`Green`=规则、边界、痕迹、真相版本与阶段演进都清楚；`Yellow`=可用但仍缺证据载体、真相版本或终局关门块；`Red`=规则打架、万能化、无痕迹、真相版本混乱或首秀无法进正文。
- 审故事设定时还要复核写后更新条件：哪些变化该回写设定文档、哪些只是正文误写；否则审阅报告很容易只会挑错，不会告诉作者怎么维护规则体系。

## 网文首秀与读者供血（强制）

- 审故事设定时，必须判断它第一次出手是否能在前三章内咬到现实困局、留下可回指痕迹，并带来一次有效小回报、误判或代价。
- 必须显式判断：它是否绑定了最能凸显价值的代表性人物与熟悉日常情境；设定主要供血类型是什么（智性破局、恐惧打穿、制度反击、关系翻车、传播讨论、反差幽默）。
- 若设定首秀只能靠讲解、和人物 / 场景脱节，或没有可截图 / 可站队 / 可催更的钩子，不得判为网文高完成度设定。

## 起点爆款设定快筛与变现力评估（新增）

故事设定审阅时，默认还要判断：**这套设定是不是只“看起来很酷”，还是它真的具备起点爆款链路里的抓力、供血力与商业位支撑力。**

### 10 秒快筛（设定版）

把当前设定当作编辑快速理解项目卖点时会看到的机制核心，默认先做一次 `10` 秒快筛；命中以下 `3` 项及以上弱信号时，设定默认不得判高档：

1. **一句话机制口径是否成立**：是否能用一句“动作 → 凭证 → 后果”说清这套设定是什么、怎么起效、为什么危险。
2. **设定是否支持题材归类**：读者是否能迅速感知它属于悬疑机制、科幻机制、规则怪谈机制、都市异能机制中的哪一类，而不是“什么都沾一点”。
3. **首次出手是否有炸点**：它第一次登场是否天然带来异常、反差、规则错位、程序摩擦或现实后果，而不是只能靠讲解体现高级感。
4. **代价是否真实可见**：代价是否会在正文里留下痕迹、损耗、误判、暴露、反噬，而不是只写在设定文档里当安全阀。
5. **是否存在明确禁区**：是否写清“它不能直接解决什么问题”；若没有，默认按万能化高风险处理。

### 金手指 / 核心机制变现力复核

若设定承担主角核心能力、主线破局机制或题材最大新鲜点，默认必须补审以下三项：

1. **逻辑是否极简**：读者能否在开篇极短时间内理解“凭什么赢”；若需要先看三页说明书，判快审失败。
2. **变现力是否足够强**：它是否能让读者产生“如果我有这个能力/规则，我也想看它怎么改变命运”的代偿感；若只有概念新奇、没有使用快感，判供血不足。
3. **差异化是否成立**：它与同类竞品设定的本质差异是什么；若只是换皮面板、换皮外挂、换皮规则链，判为弱创新。

### 起点潜力分档（设定审阅辅助口径）

除 `Green / Yellow / Red` 入库判定外，按起点口径审故事设定时，默认允许再给一层“设定爆款助推档位”判断：

| 档位 | 判断标准 | 审阅含义 |
| --- | --- | --- |
| S | 机制口径清、首秀炸点强、代价可见、禁区明确、可持续升级且有讨论度 | 这套设定具备明显的抓人和供血能力 |
| A | 设定主干稳定，首秀与代价可用，存在局部边界或镜头化缺口但可快速修复 | 这套设定可作为长线引擎 |
| B | 规则基本成立，但首秀发虚、代价偏轻或差异化不足 | 这套设定能用，但还不够亮 |
| C | 万能化、讲义化、无痕迹、无禁区、无持续升级路径命中两项以上 | 这套设定会拖累题材说服力与追读 |

该分档只用于辅助判断“这套设定对整书爆款链路的贡献强度”，不得替代完整审阅结论与问题分级。

## IP 改编友好度 / 传播讨论点复核（新增）

故事设定若承担题材门面、主线抓手或世界观辨识度，审阅时默认还要判断它是否具备 **IP 改编友好度** 与 **传播讨论点**，因为这两项直接关系到作品的商业上限，而不只是正文可写性。

### IP 改编友好度复核

报告默认至少回答以下问题：

1. **可视化是否清晰**：这套设定能否被稳定转成镜头、音效、道具、UI、程序界面、异常现象，而不是只能靠解释理解。
2. **高光节点是否明确**：是否天然存在适合短剧 / 有声 / 动漫改编的高光出手、反转揭示、规则触发、证据翻面场面。
3. **调用成本是否适中**：设定是否过度依赖大段旁白、复杂参数、抽象概念，导致改编时必须先上课再看戏。
4. **衍生接口是否存在**：是否可以自然拆出配角线、旧案线、前史线、组织线，而不会一离开主线就失效。
5. **终局关门是否友好**：设定若必须在终局关门 / 降格 / 留余波，是否已经写清改编时的收束方式，而不是到结尾才临时收网。

若一套设定“正文里能写、改编里难演”，审阅报告应明确标成 **IP 友好度不足**，而不是只给“概念较复杂”的轻描淡写结论。

### 传播讨论点复核

起点爆款设定不仅要能用，还要能被读者讨论、截图、复述、站队。审阅时默认补查以下四类讨论点来源：

- **规则反常点**：一句话就能让人产生讨论欲的异常规则、悖论、失效条件。
- **现实刺点**：设定是否咬住现实焦虑、制度摩擦、身份风险、舆论压力、程序卡点等现实针脚。
- **立场分裂点**：同一设定下，不同角色是否会得出完全不同的选择，从而带来“你站谁”的讨论。
- **可截图物料点**：是否天然生成日志、回执、编号、术语、界面、警告语、录音转写、弹窗、制度条款等可传播载体。

若设定完整但没有任何一类稳定讨论点，默认判为“商业传播弱”；若四类里能稳定命中两类及以上，可在报告中标为传播潜力强设定。

### IP / 传播辅助分档

按起点口径审故事设定时，除前述设定潜力档外，默认还可补一条辅助判断：

| 档位 | 判断标准 | 含义 |
| --- | --- | --- |
| S | 可视化强、高光节点明确、讨论点密、可衍生接口自然 | 兼具正文抓力与改编传播价值 |
| A | 设定能演、能聊，存在个别抽象段但可镜头化修复 | 有明确商业放大空间 |
| B | 正文可用，但传播点弱、改编成本偏高 | 更适合文本内消费 |
| C | 讲义化严重、难演、难聊、缺传播载体 | 商业扩展性明显受限 |

该辅助分档主要回答“这套设定的商业放大量级”，不得替代规则自洽与正文可写性的基础审阅结论。

## 设定的情绪建筑与读者心理回报审阅（新增——全面故事设定审阅维度）

> **审阅座标**：设计侧已将设定的情绪锚点、心理账户、回报节奏纳入设计维度。审阅侧必须检查：这些设计是否成立、是否被正文兑现、是否存在"设计层承诺了情绪回报但执行层没有"的落差。

### 情绪锚点兑现检查

| 检查项 | 审阅标的 | 判定标准 |
| --- | --- | --- |
| 主导情绪锚点是否明确 | 设定文档是否标注了主导锚点类型（恐惧/期待/爽感/虐感/惊叹/共鸣） | 无标注→设计不完整；有标注但正文未兑现→执行缺失 |
| 首秀窗口内锚点兑现 | 首秀3章内读者是否能明确感受到该情绪 | 3章内无对应情绪反应→首秀情绪失败 |
| 锚点一致性 | 设定各阶段调用时产生的情绪是否与标称锚点类型一致 | 标称"恐惧"但正文写成了"炫酷"→锚点漂移 |
| 锚点迁移是否合理 | 若中段有锚点迁移，是否有足够的铺垫和触发事件 | 无原因直接迁移→情绪断裂；有铺垫但太短→过渡生硬 |
| 负面情绪占比 | 设定的代价/风险是否产生了可感知的负面情绪（心疼/紧张/憋屈） | 全程正向无负面→读者不会真正在乎代价 |
| 情绪峰值间隔 | 两次情绪峰值之间的章节间隔 | 间隔超过5章无情绪峰值→读者情绪冷却 |

### 心理账户充盈度检查

| 检查项 | 审阅标的 | 判定标准 |
| --- | --- | --- |
| 账户开户完成度 | 首秀窗口内是否完成了至少2个心理账户的开户（规则揭示/能力成长/代价兑现/破局期待/限界挑战） | 首秀后无账户开户→读者不知道"该期待什么" |
| 账户充值频率 | 每个已开账户是否在2-3章内获得一次充值 | 某账户连续5章未充值→账户已死亡 |
| 账户联动充值 | 同一场景是否给多个账户同时充值 | 若有，是否在同一章内且不超过2个账户同时充值 |
| 首次代价显影窗口 | 代价兑现账户是否在合理窗口内首付 | 使用3次以上仍无代价→代价账户失效 |
| 账户耗竭预警 | 是否存在超过5章无充值的死账户 | 若有，需评估该设定在后续是否还能被读者重新在意 |
| 跨账户充值的节奏均衡 | 不同账户的充值节奏是否有起伏交替 | 连续3次都是同一账户充值→单一化疲劳 |

### 情绪回报节奏检查

报告默认要回答的问题：

1. **首秀窗口的情绪波形**：前3章（或前1000字）的情绪变化曲线是什么？有没有"启动→爬升→小峰值"的完整小周期？
2. **中段情绪节奏**：前20章内情绪峰值的间距是否合理？是否存在"一章超爽三章平"或"一直平没有峰"的节奏问题？
3. **代价情绪的介入时机**：读者在心疼角色之前，是否已经对角色产生了足够的情感投入？
4. **长线情绪衰减预警**：设定在多少章之后会开始产生"又是这套"的疲劳感？是否有提前规划替换或升级路径？
5. **情绪类型多样性**：设定提供的情绪是否太单一（全程恐惧/全程爽/全程虐）？是否有意穿插了不同类型的情绪节奏？

若"情绪建筑"维度的得分低于 `5.0/10`，综合评分默认不得高于 `7.0/10`——因为读者在技术层面上完全正确的设定中感到"冷/没感觉/读不动"是致命的。

## 设定的氛围基调与题材气味一致性审阅（新增）

> **审阅座标**：设计侧为设定配备了氛围装置和题材气味识别度信号。审阅侧必须检查：这些装置是否在正文中稳定释放气味、题材气味是否纯正、是否存在"设定放在哪个题材都能用"的辨识度危机。

### 氛围装置可用性检查

| 检查项 | 审阅标的 | 判定标准 |
| --- | --- | --- |
| 氛围装置数量 | 核心设定是否配备了至少2种氛围装置（环境锚点/器物标记/体感标尺/对话气味/节奏信号） | <2种→氛围缺失；但>5种→过度，产生"设定出戏" |
| 首秀同步 | 氛围装置首次出场是否与设定首秀同步 | 设定已出现但氛围装置未出现→设定是"讲出来"的而不是"感受到"的 |
| 装置可感知维度 | 氛围装置是否至少覆盖1个五感维度 | 只有抽象概念（"有一种压迫感"）→不可感知 |
| 递进设计 | 同一装置在前期/中期/后期是否有表现升级 | 全程不变→装置沦为背景板，失去信号功能 |
| 气味一致性 | 装置释放的气味是否与题材标称气味一致 | 悬疑题材出了温暖轻松的氛围→气味串味 |

### 题材气味纯正度检查

报告默认必须回答：

1. **题材归类测试**：把设定文档的规则条款去掉题材特征后，能否判断出它属于哪个题材？如果去掉地名/人名/职业名后无法判断题材，判为"题材绑定不足"。
2. **辨识别度信号数量**：设定在正文中是否有至少3个明确的题材气味信号？如悬疑设定必须有3个以上"熟悉的日常中藏着不对劲"的信号。
3. **跨题材气味混搭检查**：若作品为跨题材（如都市悬疑+女频爱情），设定的气味混合是否清晰标注了主/副关系？是否存在两种气味冲突或互相掩盖的问题。
4. **气味退化检查**：设定在中段后是否丧失了题材气味，退化为"通用规则说明"？若前3章有气味、30章后气味消失→中期题材绑定断裂。

### 感官锚点可用性检查

- 设定在正文中是否通过至少2个感官维度被读者感知？若全程只有视觉（读者只能"看到"设定说明）→感官通道过窄。
- 感官锚点是否在各阶段保持一致？若前期是"闻到消毒水味"，中期变成了"看到消毒水瓶子"，后期变成"消毒水"只是一个概念——感官载体的丢失就是设定的抽象化。
- 是否过度依赖单一感官？若全程靠听觉（"听到了一个声音"）→读者的沉浸感会因感官重复而降低。

若"氛围基调"维度的得分低于 `5.0/10`，综合评分默认不得高于 `7.0/10`——因为缺乏题材气味的设定在商业竞争中无法建立题材辨识度。

## 设定与人物传记的深度咬合审阅（新增）

> **审阅座标**：设计侧要求设定与人物形成深度绑定——设定既是人物的能力，也是人物的伤痕。审阅侧必须检查：这种绑定是否真实成立、情感代价是否落在人物软肋上、设定是否与人物弧线一致。

### 设定-人物绑定检查

| 检查项 | 审阅标的 | 判定标准 |
| --- | --- | --- |
| 绑定关系存在性 | 核心设定是否绑定到至少1个主要人物 | 没有绑定→判为"通用工具设定"，不得进入核心设定第一梯队（除非是世界规则） |
| 绑定关系性质 | 绑定关系是"他获得了能力"还是"能力定义了他的处境/冲突/选择" | 后者才通过；前者只是"装备关系" |
| 人物传记条目 | 人物传记中是否有该设定的独立条目，注明情感意义与代价承受方式 | 无条目→设定与人物割裂 |
| 设定调用与人物心理转变 | 设定的每次重要调用是否对应人物的心理转折点 | 能力升级了但人物没变→设定与人物弧线不同步 |
| 设定与人物核心恐惧对齐 | 设定的代价是否打中人物传记中标注的"核心恐惧/核心伤痕" | 代价再重但不在人物软肋上→读者感受不到"疼" |

### 情感代价显影检查

- 情感代价是否落在真实关系上？不是抽象的"失去了力量"，而是具体的"她再也不会看我了"。
- 情感代价是否有递进？从伤身→伤心→伤魂的递进是否清晰，还是"一直伤一样的"。
- 情感代价的触发频率：每次调用都有小幅情感代价、每3次有一次大幅情感代价——这是健康节奏。一直有代价但从不升级→读者对代价免疫。

### 人物弧线匹配检查

- 设定是否真的推动人物弧线前进，还是只是一个"好看但不影响人物成长"的装饰层。
- 若设定使用N次后人物没有任何变化——设定与人物传记的深度咬合失败，判为"角色装备"而不是"角色命运"。

若"人物绑定"维度的得分低于 `5.0/10`，综合评分默认不得高于 `7.0/10`——脱离人物的设定无法让读者真正投入情感。

## 设定与素材库衔接审阅（新增——体系化运作检查）

> **审阅座标**：设计侧要求设定与素材库形成双向共生。审阅侧必须检查：设定是否有效利用了素材库的原材料、设定完成后是否反向补充了素材库。

### 素材来源追溯

- 设定是否在文档中标注了 `[素材引用：XXXX]`？若设定明显来自某个专业知识条目（如法医流程）但没有标注→素材引用链断裂。
- 素材库中对应的条目是否回标注了 `[设定引用：XXXX]`？没有回标→素材库不能反查哪些设定在使用它。
- 若设定设计时素材库中缺乏必要的原材料——是否先创建了素材库条目再设计设定？还是直接跳过素材库？

### 设定入库检查

- 设定进入正文调用后，是否同步在素材库中创建了对应的轻量条目（规则摘要/镜头包速查/创作禁忌）？
- 正文执行中发现的新写法和新风险点，是否反向更新了素材库条目？
- 素材库条目的版本是否与设定文档的修订块对齐？

### 跨项目复用触发条件

- 设定文档的修订块是否标注了素材来源的版本号？
- 素材库条目更新后，是否触发了引用该素材的设定文档的合规复核？

若发现"设定设计得很完整但与素材库完全脱节"→判为体系化断裂，素材库衔接维度得分不得高于 `5.0/10`。

## 设定作为主题载体与价值光谱审阅（新增）

> **审阅座标**：设计侧要求设定承载主题判断并形成价值光谱。审阅侧必须检查：设定的主题投射是否成立、价值光谱是否真实、是否存在"纯机制无主题"的风险。

### 主题投射检查

| 检查项 | 审阅标的 | 判定标准 |
| --- | --- | --- |
| 主题投射类型标注 | 设定文档是否标注了主题投射类型 | 无标注→主题承载缺失 |
| 主题投射呈现方式 | 主题是通过正文中的调用后果自然呈现的，还是通过旁白/作者说明硬塞的 | 旁白说明→主题投射失败 |
| 主题与规则的一致性 | 设定的规则后果是否真的在传达标称的主题判断 | 标称"权力与腐败"但正文里能力使用没有道德困境→主题悬空 |
| 主题之间的冲突张力 | 若多套设定存在，它们之间的主题是否形成有意义的张力 | 所有设定都在说同一件事→主题单一化 |

### 价值光谱检查

- 若作品同时存在多套设定，各设定之间是否形成了至少1组价值光谱？如"规则A保护个体" vs "规则B服务系统"。
- 价值光谱是否通过正文中的选择后果自然呈现，还是通过作者声明（"这是一个关于XX的故事"）？
- 读者是否可能因为不同设定体现的价值立场而产生"你站谁"的讨论？若没有→价值光谱未形成读者可参与的张力。
- 设定内部不同条款之间是否有隐含的价值冲突？（如"效率条款"与"公平条款"在同一套设定中并存）。

### 纯机制设定识别

- 若设定完全不承载任何主题判断（既不传达价值观也不引导读者思考），判为"纯机制设定"。
- 纯机制设定本身不扣分——它有功能价值（推进剧情、制造冲突），但必须被标注为"低主题承载力"。
- 若核心设定（主线机制、题材标识设定、主角核心能力）被判定为"纯机制设定"→必须提示主题层风险：读者追读完设定后不会在脑中留下任何关于"世界是怎么运转的"的思考。

若"主题承载力"维度得分低于 `4.0/10` 且该设定承担核心身份或主线机制，综合评分默认不得高于 `7.5/10`。

## 全面故事设定审阅的评分构成建议

升级后的综合评分由以下维度加权构成：

| 评分维度 | 默认权重 | 说明 |
| --- | --- | --- |
| 规则自洽与边界代价（原有） | 25% | 原审阅核心维度 |
| 可证据化与程序摩擦（原有） | 20% | 原审阅核心维度 |
| 首秀抓力与前三章回报（原有+增强） | 15% | 增加情绪回报和心理账户检查 |
| **情绪建筑与读者心理回报（新增）** | **15%** | 情绪锚点、心理账户、回报节奏 |
| **氛围基调与题材气味（新增）** | **10%** | 氛围装置、题材辨识度、感官锚点 |
| **人物传记深度咬合（新增）** | **10%** | 设定-人物绑定、情感代价、弧线匹配 |
| **主题承载力与价值光谱（新增）** | **5%** | 主题投射、价值光谱 |

> 该评分构成在报告"设定质量评分"小节中应作为主骨架替换原有的简单维度列表。若竞对或IP维度被激活，则在权重外追加"竞对齐维"和"I P传播维"的独立评分。



- 若当前任务服务某个题材，且该题材目录下的 `竞对分析/` 已存在与当前项目、当前平台或当前赛道相关的竞对分析报告，审阅前必须先读取并纳入对照。
- 若目标平台为起点中文网，或未注明平台但默认按起点口径处理，且当前题材目录下尚无可用竞对主报告，审阅前应优先调用 `通用-分析竞对作品`，至少补齐 **Top10 候选池、`3–5` 本主样本与四层深拆速览**；若任务限制导致本轮无法补齐，必须显眼记录盲区，并下调本轮审阅上限与置信度。
- 审阅报告不得只给内部自洽结论；必须显式判断当前设定相对竞对在哪些维度已领先、持平或落后，以及最先该补哪条超越路径。
- 若当前设定在竞对已验证的关键强点上明显更弱，必须直判为竞争风险；设定审阅默认按“严酷找差距”口径执行，不得为了安抚作者而把规则空转、代价失真或首秀发虚轻描淡写带过。
- 竞对维度在设定审阅综合评分中默认按 `25%` 计权；若未完成量化差距卡，或关键维度仍显著落后且没有 `72` 小时补丁，综合评分默认不得给高档。

## 起点化竞对吸收口径（新增）

当设定审阅服务起点中文网，或未标平台而默认按起点基线处理时，默认把竞对对照拆成以下四层，并翻译成审阅判断与补丁建议：

- **市场数据层**：用榜单位次、均订 / 首订 / 收订比代理信号、推荐资源位等，反推这套机制 / 手法是否真的支撑题材归类、持续付费价值与长线商业厚度，而不是只在作者视角里“设定很酷”。
- **内容创作层**：重点对照主样本在规则边界、失败条件、代价显影、证据链、误导与证伪、现实锚点、正文镜头包上的成熟度，把差距翻成规则级与镜头级补丁。
- **运营策略层**：重点对照主样本如何让机制持续供血、制造追读工程、讨论点、阶段升级感与推荐位适配，把差距翻成首秀、中盘、终局和关门逻辑的补丁。
- **受众反馈层**：重点对照本章说 / 书友圈 / 书评区里高频被夸的规则爽点、被骂的万能化病灶、老白读者对吃书 / 降智 / 失衡外挂的敏感点，把差距翻成避坑与加码建议。

起点语境下，默认尽量使用以下术语，而不是写成空泛的“设定竞争力不足”：`均订`、`高订`、`首订`、`追订`、`收订比`、`分类月票榜`、`畅销榜`、`新书榜`、`三江`、`本章说 / 段评`、`书友圈`、`老白读者`。拿不到精确值时必须写成代理信号，不得伪造具体数字。

## 常见触发词 / 用户说法速查

- 帮我审这份故事设定
- 看看这套规则是不是会万能
- 这份设定能不能进正文
- 证据化和程序摩擦够不够
- 给我设定审阅报告
- 这条规则边界是不是没写清

## 何时使用

- 审阅某个故事设定 / 手法 / 规则文档。
- 检查规则是否能拆条款、是否有边界、代价、漏洞与反制。
- 检查设定是否能落到日志 / 回执 / 编号 / 时间戳等载体。

## 报告落盘位置与命名规则（强制）

- 设定审阅报告必须落在项目根下的 `审阅意见/设定审阅报告/` 子目录中，不得散落在设定源文件目录或 `审阅意见/` 根目录。
- 设定审阅报告文件名必须带日期，日期格式固定为 `YYYY-MM-DD`。
- 推荐完整相对路径写法为 `审阅意见/设定审阅报告/设定审阅报告_[设定名]_2026-04-15.md`。
- 故事设定、手法、程序链、证据载体或规则文档本体默认不带日期；日期只用于对应审阅报告。

## 默认执行顺序

0. 若按起点口径执行且当前题材目录下缺少可用竞对主报告，先调用 `通用-分析竞对作品`，补齐 `Top10 候选池 → 3–5 本主样本 → 四层深拆` 的最小结论集。
1. 确认目标设定文件与关联剧情位置。
2. 若按起点口径执行，先吸收竞对主样本四层结论，并写清本轮审阅重点比对的关键项。
3. 先用检查清单做设定体检。
4. 再用审阅维度说明统一评分重心，并判断长线演进、误导—证伪与社会面后果。
5. 再按报告增补与报告模板输出可回写的审阅报告。

## 默认输出口径

- 默认输出一份带规则体检、风险分级与最小回写建议的设定审阅报告。
- 默认不直接改设定本体，除非用户明确要求边审边回写。
- 报告必须同时给出“作者向依据”和“正文镜头化改写抓手”，前者用于保证自洽，后者用于保证可写；不得只给说明书式建议。
- 报告必须同时回答“哪里失血”“最小怎么补”“补完后为何更抓人、更想追”，而不是只回答设定对不对。
- 默认同时输出：问题来源层、入库判定、最小规则级补丁、最小镜头级补丁与必要的回写触发条件。
- 若按起点口径执行，报告还必须显式覆盖：`Top10 候选池`、`3–5` 本主样本四层速览、竞对差距量化卡，以及当前设定最先该补的超越路径。

## 固定输出骨架（强制）

设定审阅报告默认按以下固定顺序输出，除非用户明确要求改版式，否则不得跳步或乱序：

1. **快筛结论**（10 秒）：先给机制是否可理解、可落地、可控风险的快速判断与阻断项。
2. **深评结论**（3 分钟）：再给规则边界、代价痕迹、证据链、镜头化、IP/传播友好度、竞对差距判断。
3. **分档结论**：给 `Green/Yellow/Red` + 起点口径潜力档（如 `S/A/B/C`）并写明依据。
4. **最小补丁链**：给“先改哪 `3` 条规则或镜头卡、每条改什么动作词”。
5. **72 小时动作**：给规则级回炉顺序、预计抬升项与复审触发条件。

若任务非起点口径，仍按同一骨架输出；其中竞对或平台字段可标注“本轮不适用”，但不得删掉骨架步骤。

## 最低交付

- 能指出规则条款、边界、代价、漏洞、反制与证据化问题。
- 能指出哪些问题会直接影响正文可写性。
- 能给出最小可回写补丁，而不是只说“设定还不够细”。
- 能产出至少 1 条可直接写回设定文档的规则级改写、至少 1 条可直接写进正文的镜头级改写，以及至少 1 条针对首秀 / 前三章回报的补丁。

## 复审独立性规则（强制）

- 每一轮设定审阅都必须把当前设定版本当作新的完整对象重新审查，不得仅因上一轮问题已修复，就把本轮判为高分或默认通过。
- 检查上一轮问题修复情况只是复审入口，不是复审主体；仍需独立重查规则条款、边界、代价、漏洞、反制、证据化、程序摩擦与镜头化落地。
- 若本轮发现新的万能化风险、新的规则冲突、新的证据链断裂或新的落地困难，必须如实记入本轮报告，不得因为“旧问题修好了”而跳过新问题。
- 本轮评分必须依据当前版本在本轮完整审阅下的实际质量给出，不得按修复率、修改投入或上一轮评分惯性顺延上调。

## 审阅重点（全面故事设定版）

### 基础层（原有——必须守住）

- 规则是否能拆条款
- 是否有边界、代价、漏洞、反制
- 是否能可证据化
- 是否具有程序摩擦和现实阻力
- 是否能写成镜头，而不是只能讲解
- 是否存在足够硬的现实痛点 / 情绪牵引 / 讨论度，而不只是"规则写得很全"
- 是否真的支持长线升级，而不是开篇一亮相就把底牌打完

### 情绪层（新增——全面故事设定的标志）

- 情绪锚点是否明确、首秀是否兑现、锚点迁移是否合理
- 心理账户是否在首秀窗口内开户、2-3章内是否有充值动作
- 是否建立了"低成本小回报→中成本中回报→高成本大回报"的情绪回报递进
- 代价是否打中了人物的情感软肋，而非只是数值消耗

### 氛围层（新增——题材辨识度保障）

- 核心设定是否配备了至少2种氛围装置（环境/器物/体感/对话/节奏）
- 装置首秀是否与设定首秀同步，读者能否通过五感而非解释感知设定存在
- 题材气味信号是否≥3个，去掉题材标签后是否仍能判断题材归属
- 同一装置在前期/中期/后期是否有表现升级

### 人物绑定层（新增——设定与人物不能割裂）

- 核心设定是否绑定到至少1个主要人物、且绑定关系是"处境定义"而非"装备获得"
- 人物传记中是否有设定条目，注明情感意义与代价方式
- 情感代价是否有递进（伤身→伤心→伤魂）
- 设定调用后人物是否有可见的内心变化

### 素材衔接层（新增——体系化运作）

- 设定是否标注了素材引用来源、素材库是否有回标
- 设定进入正文后是否同步生成素材库轻量条目
- 素材库条目更新后是否触发设定复核

### 主题层（新增——深层叙事覆盖）

- 核心设定是否标注主题投射类型、是否通过正文调用呈现
- 多套设定之间是否形成至少1组价值光谱
- 读者是否能因为不同设定体现的价值立场产生"你站谁"的讨论

## 硬规则

- 禁止只评价“设定是否酷 / 是否专业”。
- 若按起点口径执行，禁止跳过 `Top10 候选池 → 3–5 本主样本 → 四层对照` 就直接给高分或高档判断。
- 必须落到条款、边界、代价、证据化与回写动作。
- 必须说明设定第一次怎样进正文、最危险的万能点在哪里、最贵的后果会落到谁身上。
- 必须说明设定是否已经写清“不能直接解决的问题”、哪些参数绝不能漂、哪些红线一旦越过就该进入终局 / 关门逻辑。
- 必须说明设定前三章为什么值得读者继续跟，不能只给“后面会很厉害”的延期承诺。
- 禁止只给作者侧法条 / 资料依据，不给正文镜头、回执、对话或动作化落地方案。

## 与其他 Skill / Prompt 的边界

- 本 Skill 负责故事设定审阅与回写建议，不直接代替设定重写。
- 若用户要直接设计或补强故事设定，应优先使用 `通用-设计故事设定`。
