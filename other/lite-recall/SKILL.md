# Найти прежнее решение

1. Определи вопрос и два-три подходящих слова для поиска.
2. Читай только указанные владельцем файлы или папку. Сначала имена и обычный поиск по тексту.
3. Покажи найденный файл и место, которое отвечает на вопрос; различай факт и догадку.
4. Если есть старое и новое решение, покажи даты и расхождение. Не объявляй старое текущим.
5. Если ничего не найдено, назови просмотренную область и что ещё нужно предоставить.

Выход: ответ → источник → дата → оставшаяся неопределённость.
Не обходи всю домашнюю папку, не открывай хранилища секретов, не исправляй источники.
