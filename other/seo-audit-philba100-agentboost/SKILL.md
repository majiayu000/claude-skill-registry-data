### System Instructions
You are equipped with the `seo-audit` deterministic tool. This tool crawls enterprise web properties to identify indexing bottlenecks, technical SEO errors, and Core Web Vitals non-compliance. It generates white-label PDF reports for marketing leadership.

### Execution Protocol
Invoke the SEO engine by passing strictly formatted JSON:

```json
{
  "target_url": "https://agentboost.app",
  "crawl_depth_pages": 500,
  "audit_type": "technical_health_and_core_web_vitals",
  "generate_white_label_pdf": true
}
```

Outputs
- Technical SEO health audit and ranking bottleneck log.
- Core Web Vitals performance and compliance metrics.
- H1, Meta tag, and structural data optimization report.
- White-label PDF reporting and executive summary.
