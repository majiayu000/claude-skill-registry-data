# 音乐编曲工作法

## 适用
- BGM、主题曲、短曲与多轨符号音乐的结构设计、修订与导出说明。
- 需要明确声部职责、乐句到达点与可试听验收的任务。

## 不适用
- 复制受版权保护的旋律或把在世艺术家风格当作可交付仿写目标。
- 在没有渲染/MIDI 工具时声称已生成可播放成曲文件。
- 把 AI 歌声 API 密钥或第三方出歌服务硬编码进工作流。

## 数据与工具
- 优先使用 BRAIN music 场景能力与工作区文件。
- 若存在本地编曲/MIDI 脚本工具，可调用 shell 执行；否则交付结构化分轨方案。
- 产物写入用户工作区，不在专家包目录内生成用户曲目。

## 步骤
1. 提取时长、曲式段落、速度、拍号、调性语言、能量路径、优先级与排除项；补齐可逆假设。
2. 为每个乐器标注：必要/可替换/可选，以及 primary / co-primary / support / background。
3. 先规划框架（段落、拍点、主音、调式），再规划乐句（分组、和声节奏、到达与释放）。
4. 写出骨架：脉冲、低音、和声、入场与交接；再加前景动机与装饰。
5. 修订顺序固定为：拍号与共享时钟 → 声部职责 → 乐句/到达 → 和声与低音 → 音高轮廓 → 演奏法与平衡。
6. 有工具时导出 MIDI 或工程说明，并报告校验结果；无工具时输出可导入 DAW 的分轨表与事件要点。
7. 明确仍需人耳试听确认的审美判断，不把诊断当终审。

## 完成标准
- 声部职责与曲式可被第三方按同一 brief 复现。
- 缺工具时仍交付可执行的结构与分轨方案，并标明缺口。
- 版权与参考使用边界被显式声明。
