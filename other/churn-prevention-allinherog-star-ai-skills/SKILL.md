# churn-prevention 转化实验助手

[快速开始](https://github.com/allinherog-star/ai-skills/tree/main#%E5%BF%AB%E9%80%9F%E5%BC%80%E5%A7%8B)

[更多技能](https://ai-skills.ai)

### 概述

转化实验助手用于回答「这个改动值得测吗」、转化率、增长营销、文案，适合市场营销、运营、产品、销售在明确业务目标、内容材料或分析对象后调用。
它会结合流失与留存内容、粘贴取消原因、客服记录、用户反馈、续费提示、召回邮件、应用内消息或…等输入，整理关键上下文，并输出摘要、诊断结论、行动建议和可复用交付物，便于继续执行、复盘或交付。

### 什么时候使用

**适用场景**

- 用户提出“这个改动值得测吗”这类问题，需要快速拆解目标、判断重点并形成可执行结果
- 市场营销、运营、产品、销售需要围绕转化实验助手生成摘要、诊断结论、行动建议和可复用交付物
- 用户已经准备了留存目标（例如降低取消、解释价值、引导成功设置、召回沉默用户、减少退款或提高续费意愿。）、流失风险人群（补充订阅阶段、使用频率、客户细分、主要异议、历史行为和是否适合人工介入。）、留存触点链接（填写公开可访问的取消页、帮助文档、续费页、产品页、反馈表或消息预览链接。），希望整理成可执行的分析或优化结果
- 用户需要把转化实验助手相关材料转成清晰结论、优先级和下一步动作

### 参数说明

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `goal` | string | 否 | - | 例如降低取消、解释价值、引导成功设置、召回沉默用户、减少退款或提高续费意愿 |
| `audience` | string | 否 | - | 补充订阅阶段、使用频率、客户细分、主要异议、历史行为和是否适合人工介入 |
| `materialUrl` | string | 否 | - | 填写公开可访问的取消页、帮助文档、续费页、产品页、反馈表或消息预览链接；需要传可访问的完整 URL |
| `reviewDepth` | string | 否 | `标准诊断` | 选择快速体检、标准诊断或深度留存策略分析；可选值：`快速体检`、`标准诊断`、`深度改稿` |
| `materialFile` | string | 否 | - | 支持 docx、pdf、md、txt 等留存资料，适合提交反馈汇总、客服摘录、触点文案或研究记录 |
| `materialText` | string | 否 | - | 粘贴取消原因、客服记录、用户反馈、续费提示、召回邮件、应用内消息或取消页文案 |
| `targetPlatform` | string | 否 | - | 例如应用内消息、邮件、客服话术、取消页、续费页、CRM、社群或帮助中心 |
| `brandRequirements` | string | 否 | - | 补充品牌语气、服务承诺边界、隐私提醒、禁用表达和必须保留的信息 |

完整机器可读参数结构见 `references/form-schema.json`。

### 交付内容

- 摘要、诊断结论、行动建议和可复用交付物：围绕用户目标整理可直接阅读、复盘或交付的核心结果。
- 输入材料解读：结合留存目标（例如降低取消、解释价值、引导成功设置、召回沉默用户、减少退款或提高续费意愿。）、流失风险人群（补充订阅阶段、使用频率、客户细分、主要异议、历史行为和是否适合人工介入。）、留存触点链接（填写公开可访问的取消页、帮助文档、续费页、产品页、反馈表或消息预览链接。）提炼关键上下文和判断依据。
- 下一步动作：给出优先级、执行建议或可继续加工的内容框架。

### 结果使用建议

- 先判断输出是否回答了用户关于「转化实验助手」的核心问题。
- 再检查结果是否覆盖摘要、诊断结论、行动建议和可复用交付物，以及是否给出明确下一步动作。
- 如果输入材料较少，建议让用户补充目标、受众、限制条件或原始材料后再运行。
