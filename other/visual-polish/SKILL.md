# Visual Polish

## Entry condition

Use only after macro composition and hierarchy are sound. Polish cannot rescue a weak concept.

## Pass order

1. typography: line breaks, measure, weight contrast, tracking, line-height, optical alignment;
2. spacing: rhythm, section transitions, dense/sparse contrast, edge relationships;
3. imagery: focal point, crop, aspect consistency, treatment, loading state;
4. surfaces: border, radius, shadow, texture and contrast hierarchy;
5. controls: icon alignment, hit area, focus/hover/press, label precision;
6. motion: remove redundant movement, refine amplitude/easing/delay;
7. cross-language and real-content stress test.

## Rule

Prefer subtraction. If two decorations express the same idea, keep the stronger one. The goal is inevitability: each remaining detail should feel intentional.
