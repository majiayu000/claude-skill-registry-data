# 研究资料总结器

> 少读一些，理解更多，引用准确。

把密集资料转化为可行动、可核查的简报。它不是泛泛的“总结一下”，而是一套提炼关键内容、比较来源和规范引用的重复工作流。

## 适用边界

本技能处理用户已经提供或可直接访问的文档，不进行网络检索，也不依赖 MCP。

- 用户要求寻找、发现或调查新来源：改用 `evidence-research`。
- 上市公司完整基本面或财务取证：改用 `stock-analysis`。
- 已有文档的摘要、比较和引用提取：使用本技能。

常见触发语包括：总结论文/文章/报告、关键发现是什么、比较这些来源、提取 PDF 引用、制作研究简报、解读白皮书，以及 summarize、research brief、literature review、citation、source comparison。

## 工作流一：单一来源

### 1. 判断资料类型

- 学术论文：使用 IMRAD（引言、方法、结果、分析、讨论）。
- 网页文章：使用“主张—证据—含义”。
- 技术/行业报告：使用执行摘要结构。
- 文档手册：使用参考摘要结构。

### 2. 生成框架并填写

可运行：

```bash
python scripts/format_summary.py --template academic
```

根据资料类型将 `academic` 换为 `article`、`report` 或 `executive`。脚本只生成空白框架，内容必须由模型从原文提取。

推荐结构：

```markdown
标题：[原始标题]
作者：[原文所列]
日期：[发布日期；未注明则写“未注明”]
资料类型：[论文｜文章｜报告｜文档]

## 核心论点
[1–2 句话]

## 关键发现
1. [发现 + 原文依据]
2. [发现 + 原文依据]

## 方法
[数据来源、样本量、研究设计]

## 局限
- [覆盖不到的内容、偏差或方法缺口]

## 可行动启示
- [可以据此采取什么行动]

## 重要原文
> “直接引文”（第 X 页/章节）
```

### 3. 评价质量

检查来源可信度、证据强度、时效性，以及资金来源、作者关系和方法缺口等偏差迹象。

## 工作流二：多来源比较

1. 收集 2–5 份资料。
2. 分别执行单一来源摘要。
3. 建立比较矩阵：核心论点、方法、关键发现、样本/范围、可信度。
4. 综合一致结论、争议点、共同缺口和每种观点的证据权重。
5. 输出“共识发现—争议点—证据缺口—建议判断”。

示例矩阵：

```markdown
| 维度 | 来源 A | 来源 B | 来源 C |
|---|---|---|---|
| 核心论点 | ... | ... | ... |
| 方法 | ... | ... | ... |
| 关键发现 | ... | ... | ... |
| 样本/范围 | ... | ... | ... |
| 可信度 | 高/中/低 | 高/中/低 | 高/中/低 |
```

不得为了形成“统一结论”而掩盖来源之间的真实冲突。

## 工作流三：引用提取

运行：

```bash
python scripts/extract_citations.py document.txt --output json
```

脚本识别 DOI、URL、作者—年份和编号引用，并进行去重。随后必须人工复核遗漏和误识别：

- 默认 APA 7；也支持 IEEE、Chicago、Harvard 和 MLA 9。
- 区分一手来源、二手来源和三手来源。
- 缺少年份、作者或标题时标为“未注明”，不得补造。

常用命令：

```bash
python scripts/extract_citations.py document.txt
python scripts/extract_citations.py document.txt --format ieee
python scripts/extract_citations.py document.txt --format apa --output json
python scripts/extract_citations.py --stdin
```

## 来源质量评价

| 维度 | 高 | 中 | 低 |
|---|---|---|---|
| 可信度 | 同行评审、一手权威 | 信誉良好的机构/作者 | 未知博客、无审查 |
| 证据 | 大样本、方法严谨 | 数据适中、方法基本可靠 | 轶事、观点、无数据 |
| 时效 | 2 年内 | 2–5 年 | 5 年以上且可能过时 |
| 客观性 | 利益冲突少、论证平衡 | 有轻微关系并已披露 | 相关方资助、明显单边 |

- 四项均高：强来源，可有信心引用。
- 两项以上为中：基本可用，但应附限制。
- 两项以上为低：弱来源，使用前应独立核验。

## 主动提示

- 无日期：明确标注，可信度降级。
- 与其他资料矛盾：直接指出，不抹平分歧。
- 付费墙导致只看到摘要：说明访问限制。
- 用户要求比较但只给一份资料：请求至少再提供一份。
- 引用字段不全：标注缺失，不创造元数据。
- 快速变化领域使用 5 年以上资料：提示可能过时。

## 按需参考

- `references/summary-templates.md`：各类摘要和比较模板。
- `references/citation-formats.md`：APA、IEEE、Chicago、Harvard、MLA 规则。
- `references/SKILL.en.md`：上游英文原文，仅用于核对遗漏或升级差异。

## 交付前验证

1. 每项关键发现都能定位到原文页码、章节或引文。
2. 引用提取脚本成功退出，输出数量与最终参考文献表能够解释性对齐。
3. 每份来源都有四维质量评价，弱来源明确标记。
4. 比较矩阵没有遗漏任何一份输入资料。
5. 所有缺失信息写“未注明”，不得编造。
