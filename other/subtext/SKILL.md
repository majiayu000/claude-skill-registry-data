# Subtext Skill (潜台词生成与对位张力)

`skills/subtext.md` 负责处理“嘴上说的”与“心里想的”之间的戏剧缝隙。没有潜台词的表演是枯燥的说教，有潜台词的表演才是引人入胜的艺术。

---

## 1. 核心定义

> **“台词是浮在水面上的冰山一角，潜台词是隐藏在水下的九成庞然大物。”**

在人类真实的社交语境中，人们极少直白地说出自己最原始的欲望与创伤。人们通过：
- **客套** 表达疏离
- **攻击** 掩盖脆弱
- **冷漠** 试探在乎
- **微笑** 维持自尊

---

## 2. 潜台词对照表与表演映射

| 台词 (表面台词) | 角色内心潜台词 (Subtext) | 演员执行微动作 (Physical Performance) |
| :--- | :--- | :--- |
| “没事，你去忙吧，我一个人挺好的。” | “如果你现在走出这扇门，我永远都不会原谅你。” | 说话时视线落在地面，说完后嘴角扯出一个极勉强的微笑，随后手指无意识地捏紧衣角，留出 0.5 秒停顿观察对方反应。 |
| “这家餐厅味道挺一般的，也就那样。” | “我攒了两个月钱才带你来这里，求你夸我一句有品味。” | 说话时刻意用叉子翻动餐盘里的食物，装作不屑，但眼神余光紧紧盯着对方咀嚼时的微表情。 |
| “你今天穿这身衣服……挺特别的。” | “太难看了，但我怕说真话伤害你的自尊心。” | 视线在对方衣服上停留了不到一秒便迅速移开，端起水杯喝水借此掩饰停顿。 |
| “恭喜你升职，你确实比我更配得上这个位置。” | “凭什么每次都是你踩着我上去？我恨你的虚伪。” | 鼓掌动作机械，掌声沉闷，眼神没有聚焦在对方脸上，而是定定地看着对方胸前的名牌。 |

## 3. 潜台词的“对位表演法则” (Counterpoint Acting)

当台词与情绪发生冲突时，视频提示词的焦点应该放在**泄露潜台词的身体裂痕**上，而不是顺从表层台词：

1. **反向眼神**：嘴上说“没关系”，眼神却坚决避开交流，或死死盯着某一细节。
2. **反向身体语言**：嘴上说“欢迎”，身体重心却向后撤并双臂抱胸。
3. **动作中断 (Broken Action)**：说到关键潜台词词汇时，手头正在进行的日常动作（如倒水、切面包、翻书）产生轻微迟疑或卡顿。
4. **尾音沉降**：表层台词前半句语速正常，后半句语调微沉、音量衰减。
