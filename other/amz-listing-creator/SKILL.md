## TD模板（标题与描述——要点）

- **数量**：最多7个要点。
- **格式**：卖点——描述。
- **内容**：遵循"4+2"公式：
  - **4个卖点要点**：每个要点将卖点与描述结合，自然地融入消费者搜索关键词。示例：`优化的900瓦电机和精制营养提取刀片，将最坚硬的整食搅拌成营养奶昔、冰沙和坚果酱。`
  - **2个补充要点**：1个要点列出"包装内含"内容，1个要点包含保修/保养提醒或注意事项。
  - **1个可选要点**（第7个）：如有需要，添加额外卖点或兼容性信息。

**关键原则：**
- 关注收益，而非仅关注特性
- 将消费者搜索关键词自然地融入描述——避免关键词堆砌
- 每个要点简洁但信息丰富
- 每个要点遵循模式：**卖点**——描述

**示例**（搅拌机）：
```
• 强劲900W电机 — 优化的900瓦电机和精制营养提取刀片，将最坚硬的整食搅拌成营养奶昔、冰沙和坚果酱
• 简易一键操作 — 简单单份设计，一键搅拌和脉冲功能，每次都能获得一致效果
• 不含BPA材料 — 所有杯子和盖子均采用耐用的不含BPA的Tritan塑料制成，日常使用安全
• 紧凑省空间设计 — 轻松放置在任何台面上，非常适合小厨房、宿舍和办公室
• 包装内含 — 1个电机底座、1个24盎司杯子、1个18盎司杯子、2个翻盖、1个唇环、食谱书
• 1年保修 — 完整的制造商保修，提供专属客户支持；如有任何问题请联系我们
```

## 图片模板：X + 1

图片模板使用"X张竖图+1个视频"的组合，以适应移动端优先的浏览习惯。

**竖图内容与顺序：**

| 位置 | 类型 | 内容 | 指南 |
|------|------|---------|------------|
| 1 | **主图**（浅灰/白底） | 产品居中，构图干净 | 保持简洁；四周留白20-30%；展示完整产品 |
| 2-5 | **卖点场景图**（3-4张） | 真实使用场景中的产品，带卖点文字叠加 | 场景必须与卖点匹配；包含简短文字标注 |
| 6 | **配件/套装图** | 所有内含物品的平铺展示 | 清晰展示盒内所有物品；如适用包含收据/说明书 |
| 7 | **尺寸/规格参考** | 产品与熟悉物品并列展示比例 | 帮助买家了解实际尺寸 |

**视频内容指南：**
- 与场景图的风格和调性保持一致
- 重点展示完整的使用/组装过程
- 在演示过程中将卖点作为文字叠加

**图片要求：**
- 最小2000x2000像素（支持缩放）
- 优先竖向（移动端友好）
- 所有图片视觉风格一致
- 高质量灯光，准确色彩

## A+产品描述(EBC)——"1+8+1+8+1"结构

产品描述页面（A+/增强品牌内容）使用"1+8+1+8+1"结构，出现在亚马逊内置推荐组件后的标准listing下方。

| 区块 | 内容 | 目的 |
|---------|---------|---------|
| **第1个"1"** | 产品主标语 | 全宽图片或视频，展示主要价值主张 |
| **第1个"8"** | 特性卖点（8个模块） | 数据驱动的特性描述；基于绩效分析迭代 |
| **第2个"1"** | 场景主标语 | 全宽场景图片或视频 |
| **第2个"8"** | 场景卖点（8个模块） | 使用场景和生活方式描述；主要基于评价分析 |
| **第3个"1"** | 品牌故事 | 客户数量（如众筹支持者）、服务国家、团队介绍、品牌历史、认证 |

**内容指南：**
- 第1组8个模块：聚焦产品特性和技术优势；数据驱动，基于分析迭代
- 第2组8个模块：聚焦使用场景和客户痛点；主要基于评价分析
- 品牌故事区块：通过社交证明建立信任（客户数量、奖项、认证）
- 每个模块：图片+文字组合；文字简洁易读
- 使用竞品分析识别差异化和差异化机会

## 工作流程

### 标准Listing创建流程

1. **调研阶段**
   - 分析3-5个竞品listing
   - 识别关键词差距和内容差异化机会
   - 查看客户反馈以了解痛点和销售角度

2. **TD创建阶段**
   - 从调研中确定前4个卖点
   - 按照"4+2"公式撰写7个要点
   - 确保消费者搜索关键词自然地融入描述

3. **图片规划阶段**
   - 基于TD的卖点规划"X+1"图片组
   - 为每个位置撰写详细的图片简报
   - 确保场景与对应卖点匹配

4. **A+内容阶段**
   - 构建"1+8+1+8+1"页面结构
   - 特性模块基于产品数据；场景模块基于评价分析
   - 包含建立信任元素的品牌故事

5. **审核与优化阶段**
   - 交叉检查所有组件的一致性（卖点应在TD、图片和A+中保持一致）
   - 验证要点和A+内容的关键词覆盖
   - 确保无重复——A+内容应补充而非逐字重复要点

## 常见错误避免

| 错误 | 原因 |
|---------|---------------|
| 撰写超过7个要点 | "4+2"结构确保完整覆盖同时不让读者感到 overwhelm |
| 仅描述特性 | 列出规格而不说明收益；始终以客户获得什么为引导 |
| 低分辨率或不一致的图片 | 低于2000x2000的图片无法缩放；不一致的风格显得不专业 |
| 在A+中重复要点 | A+应扩展和补充，而非逐字重复 |
| 忽视竞品分析 | 错失差异化机会；始终先进行调研 |
| 关键词堆砌 | 降低可读性并损害转化；关键词应自然流畅 |
| 图片与卖点不匹配 | 每个场景图必须对应特定的卖点 |

## 快速参考

**要点**：最多7个，"4+2"公式（4个卖点+包装内含+保修）

**图片**：X张竖图+1个视频；主图白/灰底，场景图带卖点文字

**A+内容**："1+8+1+8+1"=主标语→特性→主标语→场景→品牌故事

**关键原则：**
- 要点中收益优先于特性
- 搜索关键词自然地融入描述
- 移动端优先的图片方向（竖向）
- A+特性模块由数据驱动，场景模块由评价驱动
- 所有素材视觉风格一致
