# 投放数据异常巡检

做"每日体检"：从分天/分时数据里找出偏离基线的信号，分级报警并给排查路径。

## 数据契约

分天（近 14–30 天）+ 可选分时：消耗、展示、点击、转化、成本；预算与撞线时间；操作日志（改价/上新/暂停）；审核状态（拒审/限流通知）。

## 巡检规则（基线=近 7 天同星期均值，经验阈值）

| 级别 | 信号 | 首查方向 |
|---|---|---|
| P0 | 消耗环比掉 ≥50% 或归零 | 余额/预算撞线、计划被暂停、素材拒审、账户处罚、回传断流 |
| P0 | 转化数归零但消耗正常 | 转化回传故障（API/监测链接/事件配置）——先修数据 |
| P1 | 成本单日超基线 +30% | 转 cpa-diagnostics-cn 诊断树 |
| P1 | 消耗单日超基线 +50% | 是否一键起量/自动扩量失控、出价误操作、撞线后放量 |
| P1 | CTR 单日跌 ≥30% | 素材衰退/被限流/外层文案改动 |
| P2 | 连续 3 天温和阴跌（每天 -5~10%） | 素材疲劳、人群衰减、竞争加剧 |
| P2 | 分时结构异常 | 好时段预算耗尽、凌晨低质流量占比升高 |

节点修正：大促（618/双11/年货节）前后、节假日、平台大事件期间基线失真，先标注节点再判断，避免误报。

## 输出格式

```
## 巡检报告（日期 / 账户）
🚨 P0：[信号+证据+立即动作]
⚠️ P1：[...]
👀 P2：[...]
✅ 正常项摘要
### 需要人工确认的操作记录（昨天谁改了什么）
```

## 约束

- 每条报警附数据证据与排查顺序；不确定的标"待确认"而非断言。
- 区分"平台侧问题"（审核/限流/系统故障）与"操作侧问题"，前者给申诉/等待建议，后者给回滚建议。
- 无分时数据时不做分时结论。
