# search-taobao-tmall

## 目标
在用户需要淘宝/天猫商品、淘口令、短链、评价或问大家内容时，通过只读工具和浏览器读取整理详情、价格、规格、评价摘要和链接。

## 适用请求
- 解析或读取淘宝、天猫、`e.tb.cn`、淘口令相关商品信息。
- 查询淘宝评价、问大家、店铺信息或商品规格。
- 搜索淘宝/天猫同款、相似商品或价格线索。

## 首选通道
- skill-only：默认复用用户当前已打开且已登录的 Firefox 会话，用 `firefox.exe -new-tab <淘宝/天猫 URL>` 打开搜索页、商品页、评价页或问大家。
- 公开线索使用 WebSearch/WebFetch；登录后内容只从当前 Firefox 可见页面、用户复制文本或截图/OCR 取证。
- 不新增或依赖 MCP，不默认新建 profile，不要求用户重复登录。

## 兜底通道
- 使用当前 Firefox 已登录会话只读读取页面可见内容；遇到验证码、风控或二次确认时请求用户人工处理。
- 使用 WebSearch 查找商品标题、短链解析结果、店铺页或第三方引用。

## 操作流程
1. 识别输入是关键词、淘口令、短链、商品 URL、店铺还是评价/问大家需求。
2. 用当前 Firefox 新标签页打开淘宝/天猫搜索或详情；若用户已确认登录，直接复用当前会话，不再要求扫码。
3. 浏览器只读读取时，全程只读搜索/读取，不下单、不私信、不发帖、不写入平台，也不扫码、加购、领券、咨询客服或评价。
4. 记录标题、价格、规格、店铺、销量、评价摘要、问大家摘要、URL 和检索时间。
5. 对淘口令或短链，仅解析和读取可见目标，不执行领取、跳转授权或购买动作。

## 只读安全边界
- 只读取商品、评价、问大家和店铺公开或用户授权可见信息。
- 不发起新的淘宝/天猫登录流程；用户确认已登录时直接复用当前 Firefox 会话，不绕过验证码、风控、App 限制或权限限制。
- 不加购、不下单、不付款、不领券、不关注、不咨询客服、不私信、不评价、不发布内容。
- 不保存 Cookie、Token、手机号、收货地址或支付信息。

## 验证方式
- 后续可运行：`dir C:\Users\Zhang\.config\opencode\skills\search-taobao-tmall\SKILL.md`
- 人工检查：确认 `name` 为 `search-taobao-tmall`，且流程为 skill-only + 当前 Firefox 会话复用，不依赖 MCP。

## 已知限制
- 淘宝/天猫详情、评价和问大家经常需要登录或 App 环境。
- 价格、券和库存实时变化，读取结果只代表检索时刻。
- 淘口令和短链可能包含营销参数，需核对最终商品 URL。
