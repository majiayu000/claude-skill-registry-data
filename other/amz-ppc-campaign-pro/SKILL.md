# 亚马逊PPC广告活动管理器

## 亚马逊PPC广告类型


| 广告类型 | 最适合 | 展示位置 |
| ---------------------- | ----------------------------------------- | ------------------------------------- |
| **商品推广** | 单个ASIN，推动销售排名 | 搜索结果+产品详情页 |
| **品牌推广** | 品牌知名度，展示产品系列 | 搜索结果顶部 |
| **展示型推广** | 再营销，竞品抢占 | 亚马逊站内和站外 |


---

## 核心广告活动结构框架

### 三广告活动发布蓝图（用于新品）

**广告活动1：精准匹配——核心词**

- 目标：5-10个最高优先级的精准匹配关键词
- 目标：为已验证的词推动排名，控制花费
- 竞价：从建议竞价开始，根据转化数据调整
- 预算：每日总预算的60%

**广告活动2：广泛匹配——发现**

- 目标：10-20个广泛匹配词
- 目标：发现有转化的长尾变体
- 竞价：比精准匹配竞价低20-30%
- 预算：每日总预算的25%
- 行动：每周搜索词报告审核→将优胜者导入精准广告活动

**广告活动3：自动广告——收割**

- 目标：亚马逊确定的定位（所有匹配类型）
- 目标：发现意外的关键词机会
- 竞价：最低竞价（最小化浪费）
- 预算：每日总预算的15%
- 行动：每周挖掘搜索词报告→将表现好的词添加到手动广告活动，将不相关词添加到否定关键词列表

## 关键指标与基准


| 指标 | 定义 | 健康范围 |
| --------- | ------------------------ | ----------------------------------------------- |
| **ACoS** | 广告花费÷广告收入 | 因类目而异；通常15-35% |
| **TACoS** | 广告花费÷总收入 | 规模化时目标<15%；发布期<25% |
| **CTR** | 点击÷展示 | 商品推广>0.3% |
| **CVR** | 订单÷点击 | >5-10%（因类目和价格点而异） |
| **ROAS** | 广告收入÷广告花费 | ACoS的倒数；大多数类目目标≥3倍 |


**盈亏平衡ACoS公式：**
盈亏平衡ACoS = 利润率%（广告前）
示例：如果你的利润率是30%，盈亏平衡ACoS就是30%。
盈利广告活动的目标ACoS应低于盈亏平衡点。

## 竞价优化规则

**何时提高竞价（+10-20%）：**

- 关键词转化良好（CVR高于类目平均）但展示份额低
- 关键词自然排名在第2-3页，你想加速排名

**何时降低竞价（-10-20%）：**

- ACoS连续14天以上高于盈亏平衡点且排名无改善
- 关键词带来点击但零或极低转化（CVR<2%）

**何时暂停关键词：**

- 50+点击但零订单
- ACoS连续30天持续>2倍盈亏平衡ACoS

---

## 蜜月期策略

新ASIN在前30-90天会获得算法加持。
这个窗口期至关重要——积极利用：

1. **第1-7天**：自动广告+广泛匹配收集初始数据
2. **第8-30天**：为第1周的高转化词启动精准匹配广告活动
3. **第31-90天**：将预算转向表现最好的词，每日优化竞价
4. **90天后**：降低发布期预算，用更低ACoS的广告活动维持排名

---

## 否定关键词策略

否定关键词防止在不相关搜索上浪费花费。

**始终添加为否定：**

- 竞品品牌名（除非是有意抢占策略）
- 30+点击但零订单的词
- 类目外的产品类型（如销售瑜伽垫，否定"瑜伽裤"）

**否定匹配类型：**

- 否定精准：仅屏蔽该精确搜索词
- 否定词组：屏蔽包含该词组的任何搜索

## PPC与自然排名的关联

每个特定关键词的PPC销售都会向亚马逊算法发送排名信号。
关键词X的PPC驱动销售越多，你在关键词X上的自然排名就越高。

**实际意义：**

- 优先在希望提高自然排名的关键词上投入PPC预算
- 使用卖家中心品牌分析每周跟踪关键词排名
- 一旦自然排名达到某词的第1页，可以降低该词的PPC竞价
- 随着自然销售增长，TACoS会自然下降

---

## 广告活动审核清单（每周执行）

- 审核搜索词报告——收割新的精准匹配优胜者
- 为高花费的不相关词添加新的否定关键词
- 基于7天ACoS调整前20个关键词的竞价
- 检查预算——是否有广告活动在下午6点前达到每日预算上限？
- 审核展示份额——核心词是否获得足够曝光？
- 检查跨广告活动的重复关键词（会导致内部竞价竞争）

## 常见错误


| 错误 | 影响 | 解决方案 |
| ------------------------------------------- | ----------------------------- | ---------------------------------------- |
| 设置后不管广告活动 | ACoS攀升，预算浪费 | 每周优化节奏 |
| 仅运行自动广告 | 控制有限，浪费高 | 始终与手动精准匹配配对 |
| 淡季暂停广告活动 | 失去排名信号 | 改为降低30-50%竞价而非暂停 |
| 一个广告活动定位太多关键词 | 预算稀释，数据噪音 | 每个广告组最多10-15个关键词 |
| 忽视搜索词报告 | 错失转化长尾词 | 每周审核，收割到精准匹配 |
