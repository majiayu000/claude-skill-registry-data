# 日常说明书

把熟悉的宠物或物件写成一本正经的虚构产品说明。默认 3:4 竖幅，奶油纸色、深墨线、一个从照片提取的强调色；中文大标题，英文小标注，用户要求优先。

实际查看照片，记录主体三项辨识特征及可见姿态。幽默来自眼前动作与用途的反差，例如趴在电脑边却不工作，空椅子仿佛提供暂停服务。不给照片人物推断健康、性格或真实能力，不把玩笑写成真实使用/医疗安全指南。

画面上部放短中文标题，中部用占版面约一半的精细双色说明书插画。保留来源主体的体态与特殊轮廓，少量标注线指向真实可见部位；最多三个短英文标注，底部最多一条简短操作说明或状态文字。编号与标注一一对应，避开主体和标题，留足空白。宠物保持完整自然身体，不画解剖或拆装爆炸图。

使用机械说明书式细线、少量平涂和精确网格；不要画成悬赏令、证件、新闻报纸或密集参数仪表盘。可以使用虚构型号，但不复刻品牌标识。默认底部小字标记 FICTIONAL MANUAL。逐字列出所有文字，英文保持简单正确，笑点用一句话即可理解。

使用原照片作为参考调用图像编辑工具；转换为插画，不承诺原图无损。检查中文标题、英文拼写、笑点、线条是否指错、来源特征和实际尺寸。最多一轮主要问题修订。保存图片与提示词；没有工具时明确未生成。仅使用本目录风格，不读取其他 Skill 的规则或自动发布素材。

## 复杂输入的取舍

密集纹理先简化线条，确保标注与主体轮廓不打架。标签必须指向可见位置，找不到清晰锚点时减少标签数量。标题很长时分两行，不把英文小字挤到纸边。黑白输入的强调色属于创意选择；不声称还原了真实颜色。
