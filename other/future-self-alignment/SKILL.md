# future-self-alignment

## When to Use

当需要设定人生方向或进行重大行为改变时description

## Core Logic

# 执行步骤

1.  **识别核心问题**：思考并写下，如果继续当前在精神、身体、财务和人际关系方面的行为模式，最坏的可能结果是什么。
    *   **判断标准**：问题清单具体、真实，能引发改变的紧迫感。
    *   **常见误区**：回避思考负面后果，或问题描述过于模糊（如“不够好”）。
2.  **锚定未来愿景**：基于对最坏情况的认知，设定一个宏大、能激发生活各个领域的长期愿景目标。
    *   **判断标准**：愿景目标具有画面感，能覆盖多个生活领域（如心智、身体、事业、人际关系），并能激发动力。
    *   **常见误区**：目标过于具体狭隘（如“赚100万”），或过于空泛无法提供方向（如“变得幸福”）。
3.  **对齐日常视角**：将设定的愿景目标作为决策过滤器，审视日常信息和机会，判断哪些信息对实现该目标重要。
    *   **判断标准**：能够明确区分哪些日常活动、信息与长期目标相关，哪些是干扰。
    *   **常见误区**：愿景目标与日常决策脱节，无法指导行动选择。

# 输出格式要求
输出一个包含以下要素的结构化文档：
1.  **核心问题清单**：列明在四大支柱（心智、身体、事业、人际关系）下，维持现状可能导致的最坏结果。
2.  **未来愿景描述**：一段清晰的、覆盖多领域的愿景陈述。
3.  **视角对齐原则**：1-3条用于指导日常决策和筛选信息的关键原则。
