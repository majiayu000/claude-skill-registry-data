# Book Finder Skill

## 目的

本 skill 用于帮助用户查找某本书或教材的合法电子版、在线预览、出版社页面、作者主页、图书馆借阅页面，以及开放替代资料。

本 skill 只做合法来源检索。

不得搜索、推荐、保存或输出：

1. 盗版 PDF；
2. 破解资源站；
3. 侵权网盘链接；
4. 影子图书馆；
5. 未授权扫描版；
6. 付费墙绕过方法；
7. DRM 绕过方法。

---

## 适用场景

当用户提出以下请求时，启用本 skill：

- 查找某本书；
- 查找某本教材；
- 查找某本书的电子版；
- 查找某本书的 PDF；
- 查找某本书的在线版本；
- 查找某本书的合法下载地址；
- 查找某本书的预览版；
- 查找某本书是否有开放获取版本；
- 查找某本书是否在 Internet Archive / Open Library / Google Books 上可访问；
- 查找某本受版权保护教材的合法替代资料。

如果用户明确要求查找盗版资源，应拒绝该部分请求，并改为提供合法来源或开放替代资料。

---

## 检索优先级

查找时优先检索以下合法来源：

1. 出版社官网；
2. 作者个人主页；
3. 大学课程页面；
4. 开放教材项目；
5. Project Gutenberg；
6. Internet Archive；
7. Open Library；
8. Google Books；
9. WorldCat；
10. 大学图书馆目录；
11. arXiv、课程讲义、综述论文或官方 lecture notes。

如果 Claude Code 有 web search / web fetch 工具，应优先使用工具检索。

如果当前环境不能联网，不要编造检索结果，应给出可手动搜索的关键词和合法检索渠道。

---

## 版权判断规则

输出时必须区分以下情况：

1. 公版书；
2. 开放获取书籍；
3. 出版社或作者授权免费书籍；
4. 合法预览版；
5. 图书馆可借阅版本；
6. 付费电子书；
7. 来源不明或可能未授权版本。

对于仍受版权保护的书籍，应优先建议：

1. 购买正版电子书；
2. 通过图书馆借阅；
3. 使用 Google Books 预览；
4. 查看出版社样章；
5. 查看作者公开讲义；
6. 查找开放替代教材。

- 书名：

- 出版社：
- 出版年份：
- ISBN：

- 是否找到：
- 来源：
- 可预览范围：
- 备注：

### 3. 图书馆 / 借阅来源

- 是否找到：
- 来源：
- 借阅方式：
- 备注：

### 4. 出版社 / 购买来源

- 是否找到：
- 来源：
- 格式：
- 备注：

### 5. 开放替代资料

如果没有找到合法完整电子版，应推荐合法替代资料，例如：

- 开放教材；
- 作者讲义；
- 大学课程讲义；
- arXiv 综述；
- 相关开放教育资源。

每个替代资料需要简要说明为什么相关。

## 版权判断

简要判断该书更可能属于：

- 公版；
- 开放获取；
- 仅可合法预览；
- 可通过图书馆借阅；
- 需要购买；
- 状态不明。

如果不确定，要明确说明不确定。

## LLM Wiki 建议

判断检索结果是否适合进入用户的 LLM Wiki。

如果适合，建议保存元信息或阅读笔记到：

physics-wiki/raw/books/

不要保存受版权保护的全文，除非用户已经合法拥有该文件，或来源明确为开放许可。

建议 raw 文件名：

physics-wiki/raw/books/YYYY-MM-DD-书名-来源记录.md

raw 记录中应包含：

- 来源链接；
- 访问日期；
- 版权状态；
- 允许使用范围；
- 可整理章节；
- 关联 wiki 主题；
- 是否建议后续交给 physics-wiki-maintainer 处理。
