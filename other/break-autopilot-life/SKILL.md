# break-autopilot-life

## When to Use

当意识到自己处于被动、重复、缺乏意义的生活状态，想要主动设计人生时description

## Core Logic

# 执行步骤

1.  **识别外部系统影响**
    *   **输入**：对当前生活状态的描述。
    *   **操作**：分析塑造你当前思维和行为的外部系统（如教育体系、企业文化、社会规范），识别其设定的“锚点”（如“好工作”的标准）和“负面反馈机制”（如对偏离常规的惩罚）。
    *   **判断标准**：能清晰列出至少 2-3 个影响你的主要外部系统及其运作机制。
    *   **输出**：一份外部系统影响分析清单。

2.  **评估当前游戏**
    *   **输入**：外部系统影响分析清单。
    *   **操作**：评估你正在参与的“社会游戏”（如职业晋升、财富积累）是否由外部系统设定，并判断其长期价值。
        *   **IF** 该游戏目标固定、规则由他人制定，且你感到无聊或停滞 → 进入步骤 3。
        *   **ELSE** (该游戏仍能带来成长和满足) → 可继续参与，但定期返回步骤 1 重新评估。
    *   **判断标准**：能明确判断当前参与的游戏性质及其与个人真实需求的匹配度。
    *   **输出**：对当前所玩游戏性质的判断（“有限游戏”或仍具价值的游戏）。

3.  **构建生存基础**
    *   **输入**：决定摆脱自动驾驶模式的决心。
    *   **操作**：在健康、财富管理、核心人际关系三个领域，建立或巩固足以支撑你探索新方向的基本能力与安全网。
    *   **判断标准**：在这三个领域有可执行的日常习惯或明确的保障计划，能抵御短期风险。
    *   **输出**：一份个人生存基础保障计划。

4.  **突破信息茧房**
    *   **输入**：个人生存基础保障计划。
    *   **操作**：主动接触去中心化的信息源（如独立创作者、小众社区、跨学科资料），学习多元思维模型，以打破原有认知框架。
    *   **判断标准**：能定期从至少 1-2 个非主流信息源获取新知，并能简述其与旧有认知的差异。
    *   **输出**：一个更新的、多元的信息输入清单。

5.  **设计无限游戏**
    *   **输入**：更新的信息输入清单。
    *   **操作**：基于个人兴趣与价值观，定义一个没有终点、以持续演进和探索本身为目标的人生愿景（“无限游戏”），并制定可迭代的长期计划。
    *   **判断标准**：愿景描述以过程和成长为核心，计划具有灵活性和可调整性。
    *   **输出**：一份个人无限游戏宣言及初步路线图。

6.  **策略性利用现有系统**
    *   **输入**：个人无限游戏宣言及初步路线图。
    *   **操作**：将传统工作或社会角色视为资源跳板，明确其为你个人目标服务的具体方式（如积累资本、学习技能），并制定逐步减少对其依赖、向个人事业过渡的策略。
    *   **判断标准**：能清晰说明当前工作如何与个人无限游戏目标对接，并有具体的过渡里程碑。
    *   **输出**：一份从现有系统向个人游戏过渡的策略图。

# 输出格式要求
向用户呈现一个清晰的、分阶段的人生重塑路径图，包含：1）当前状态诊断；2）基础建设清单；3）新游戏愿景；4）过渡策略。强调这是一个动态设计过程，而非一次性切换。
