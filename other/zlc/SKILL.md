# zlc 体 / Four-Beat Comment

一种四拍固定的中文点评句式，语料来自同学 zlc 的说话方式。

## 语料 / Corpus

这四句是原始样本，所有规则都从它们里面拆出来：

> 很欣赏这份大胆发问。不囿于既定的认知，敢于畅想中国人能不能飞上蓝天。少年最珍贵的就是这份敢想敢梦的想象力，多一些这样大胆的追问，才能让畅想真正生根发芽。

> 很欣赏这份大胆的思辨。不盲从固有看法，认真思考是否该封禁胡巴。少年最珍贵的就是这份独立审慎的判断力，多一些这样理性的权衡，才能让思考真正生根落地。

> 很欣赏这份向往与认同。不困于原生身份的局限，由衷努力想要成为中国人。人最珍贵的便是这份发自内心的归属感，多一些这样真诚的奔赴，才能让文化认同真正生根落地。

> 很反感这种人机式的表达。不输出真实独立的思考，只会机械复制套用现成话术。交流最珍贵的就是真诚鲜活的观点，少一些这样机械的内容，才能让真实的表达真正生根落地。

## 何时使用 / When to use

- 使用者说"用 zlc 体"、"用他那个语气"、"来一段四拍点评"
- 要给某句话、某个提问、某个行为配一段点评
- 要把一段普通评价改写成这个句式

**不适用于** / Not for：

- 正经写作 → 这套本身就是套话体，跟 `writing-rules` 完全对立，两个不能同时开
- 真心要给人建议 → 这个句式是形式游戏，说不出实质意见

## 四拍结构 / The four beats

| 拍 | 骨架 | 褒用 | 贬用 |
|---|---|---|---|
| 一 · 表态 | 很＋态度＋**这份/这种**＋品质 | 很欣赏这份大胆发问 | 很反感**这种**人机式的表达 |
| 二 · 否定＋事实 | 不＋X，＋具体行为 | 不囿于既定的认知，敢于畅想中国人能不能飞上蓝天 | 不输出真实独立的思考，**只会**机械复制套用现成话术 |
| 三 · 价值 | ＋主体＋最珍贵的就是/便是＋这份＋抽象品质 | 少年最珍贵的就是这份敢想敢梦的想象力 | 交流最珍贵的就是真诚鲜活的观点 |
| 四 · 呼吁 | **多一些/少一些**这样＋修饰＋的＋名词，才能让＋X＋真正＋生根发芽/生根落地 | 多一些这样大胆的追问 | **少一些**这样机械的内容 |

拍一到拍二之间是句号，拍三到拍四之间是逗号。四拍一段，不换行。

### 褒贬开关

三个地方一起翻，翻一半会串味：

| | 褒 | 贬 |
|---|---|---|
| 拍一量词 | 这份 | **这种** |
| 拍二后半 | 敢于/认真/由衷＋褒义行为 | **只会**＋负面行为 |
| 拍四 | **多**一些 | **少**一些 |

## 第二拍决定这段话好不好笑

前后三拍都是空的，撑起整段的是第二拍那件**具体的小事**。

「畅想中国人能不能飞上蓝天」「是否该封禁胡巴」这类东西之所以有效果，是因为
拍三拍四那种表彰大会的口气，被扣在了一件很小很具体的事情上。落差就是笑点。

所以第二拍的写法：

- **照抄对方原话里的关键词**，越具体越好
- 不要概括成「勇于探索未知」这种话，一概括落差就没了，整段变成真的官腔
- 长度控制在 10 到 18 字，比其他三拍长一点，因为它承载全部信息

拍二写空了，这段就只是四句套话，没有任何意思。

## 词库 / Word bank

**拍一态度**：欣赏、佩服、认可、赞许 ／ 反感、警惕、不适

**拍三主体**：少年、青年、人、同学、创作、交流、讨论、学习、写作

**拍三品质**：想象力、判断力、归属感、观察力、共情力、分寸感、好奇心

**拍四收尾**：生根发芽、生根落地、开花结果、落到实处

收尾主要就「生根发芽」和「生根落地」两个，别的用一次就够，用多了不像。

## 变体规则 / Variation

连续生成多条时，骨架保留，下面几处轮换，否则一眼看穿：

- 第三拍的「就是」和「便是」交替
- 主体词跟着内容走（讲想象力用「少年」，讲交流用「交流」，讲归属用「人」）
- 第一拍的品质可以是四字（大胆发问）、可以是「形容词的名词」（大胆的思辨），
  也可以是并列名词（向往与认同）
- 第二拍前半句的动词换：囿于、盲从、困于、拘泥于、满足于

## 常见写坏的方式 / Failure modes

| 症状 | 问题 |
|---|---|
| 第二拍写成万能评语 | 落差没了，就是普通官腔 |
| 褒用写了「这种」 | 量词一错，赞许听起来像阴阳怪气 |
| 四拍写成四行 | 必须一段连写，断行就散了 |
| 加了第五拍 | 四拍是闭合的，再补一句就拖沓 |
| 收尾不用「生根」系 | 这是这个句式的签名，换掉就不是它了 |
| 写不下于是缩成两拍 | 缩了就没有那个铺陈感，宁可换词也要凑够四拍 |

## 流程 / Process

1. 拿到被点评的对象，先找出**那件具体的事**，这是拍二的材料
2. 判断褒还是贬，三个开关一起定
3. 按四拍填，拍三的主体词跟着内容走（讲思考就用「少年」，讲说话方式就用「交流」）
4. 通读一遍：拍二够不够具体、四拍长度是不是差不多、收尾套语有没有跟上一条重复

一次给两到三个版本，褒贬各一个更好玩。

## 输出格式 / Output

直接给成段的话，不要拆成四行，不要标注哪拍是哪拍。使用者要的是能直接发出去的一段。

需要解释的时候另起一行说，不要混在正文里。

## 边界 / Boundaries

- **不冒充 zlc 本人发言**。这是模仿一种句式，不是替他说话。生成的内容不得署他的名，
  不得放进聊天记录截图里伪装成他说的。
- **只对事不对人**。贬用模式针对的是某种说法、某段内容、某个现象。
  不要拿它去点评某个具体的真人，尤其不要在群里对着某个人发。
- **不编造对方说过的话**。拍二的材料必须是真发生过的，没有就问，别自己编一个荒谬的事情安上去。
- **不批量刷屏**。一次两三条，不生成二十条让人复制粘贴去洗版。
- **不跟 `writing-rules` 同时开**。那套禁强行升华、禁套话，这套全是强行升华和套话。
  同时开只会两边都做不好。使用者同时要求两者时，先请他选一种，不自行混用。
