# 医学论文讨论部分撰写

## 输入

尽量读取：

- 研究问题、设计与论证边界；
- 已核实的结果正文、统计输出和敏感性分析；
- 方法部分与偏倚控制说明；
- 关键文献、矛盾证据、证据审计结果；
- 目标期刊与适用报告规范。

缺少关键文献或结果来源时，可先搭讨论骨架，但把未核实位置明确留在内部问题清单中。

## 核心原则

1. 不新增、改写或重新解释不在结果来源中的数字。
2. 观察性关联、预测性能和探索性发现不得写成因果、疗效或临床可用性证明。
3. 文献比较依据研究设计、适用人群、效应量和偏倚风险；引用量或期刊名不能替代质量判断。
4. 机制解释必须区分本研究直接证据、外部证据、合理推断和纯假设。
5. 局限性与方法实际做法一致，不套用通用清单。

## 工作流

### 1. 概括主要发现

用一小段回答研究问题，引用必要的主要效应量，不重复整段结果，也不加入新分析。

### 2. 与既有证据比较

对最相关证据做逐点比较：

- 研究人群、设计、暴露或干预和结局是否可比；
- 方向、效应量与不确定性是否一致；
- 差异可能来自哪些可证实的方法学或临床因素；
- 是否存在阴性、矛盾或更新的证据。

需要补充当前文献时，使用可用的权威检索工具并记录检索日期与来源。只看摘要时，明确“摘要级核实”，
不写摘要未支持的细节。

### 3. 写解释与机制

逐条标注证据层级：

- `direct`：本研究直接测量并支持；
- `external`：由已核实外部研究支持；
- `plausible`：间接证据下的合理推断；
- `speculative`：待验证假设。

机制链缺失时直接承认缺口。可参考
[机制论断分级骨架](data/mechanism-rubric.yaml)，但不得把内部评分当成正式证据等级。

### 4. 写稳健性、局限性与适用性

- 说明敏感性分析对主结论的支持或削弱；
- 每项局限性连接到可能影响的结论；
- 偏倚方向只有在本研究实际方法、数据或已核实的方法学来源支持时才写，保留支持依据与定位；
- 无法判断方向时明确写“方向未知/无法判断”，只说明已知局限影响的结论，不补造机制或默认“向零偏倚”；
- 不能仅凭“非差异误分类”“缺失数据”或局限性名称判定方向，须核对支持该方向的条件是否适用于本研究；
- 讨论外部适用性时限定到实际人群、场所和数据范围；
- 不把已经处理的问题重复列为未处理局限。

### 5. 写临床意义与未来研究

临床意义必须与效应量、不确定性、研究设计和预设阈值相符。沿用 `dyz-med-interpret` 的分类前，按已有论断或输出定位
回查效应量、置信区间、结局角色、研究设计及阈值来源与适用性，不仅凭点估计或上游标签下结论。
置信区间跨越或触及可信且适用的临床重要阈值时保留 `uncertain`；阈值缺失或与结局、尺度、方向、时间点不匹配时
保留 `indeterminate`，不自行补阈值。未来研究建议具体到需要验证的问题、设计或人群；
没有正式把握度计算时，不编造样本量。

### 6. 收束结论

结论直接回答研究问题，强度不超过研究设计和证据。不得把“需要进一步验证”前面的过度结论当作已被修正。

## 输出

默认写入 `paper/sections/04-discussion.md`。如补充了新文献，同步更新引用记录或待核查清单，不在章节末尾
单独生成参考文献块。

## 验收标准

- 主要发现与结果完全一致；
- 相关证据和矛盾证据均被公平处理；
- 机制与临床应用表述有清晰证据边界；
- 局限性与方法相符；
- 结论无因果泄漏、夸大或新数字。
