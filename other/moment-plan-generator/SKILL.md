# 朋友圈文案可视化生成器（moment-plan-generator）

## 核心功能

本技能将用户提供的 Markdown 文案、聊天记录或朋友圈内容文档，转换为**可交互的 HTML 页面**。生成的 HTML 具备以下功能：

1. **多风格模板**：支持不同视觉风格，用户可根据品牌调性选择
2. **自动日期跳转**：根据当前日期自动定位到当天应发的文案
3. **一键复制 + 防折叠混淆**：复制时自动插入零宽字符，避免微信朋友圈折叠
4. **文案优化**：清理多余换行和句号，重新排版

## 使用场景

当用户需要：
- 把朋友圈文案变成可浏览的 HTML 页面
- 让团队成员能快速找到并复制当天该发的文案
- 避免朋友圈文案被微信折叠
- 需要不同视觉风格来匹配品牌调性

**触发词**：朋友圈文案、文案可视化、防折叠、moment、朋友圈 HTML、文案模板

## 工作流程

### 第 1 步：确认输入文件

询问用户文案来源：
- Markdown 文件（.md）
- 聊天记录（微信/飞书导出）
- 已确认的朋友圈内容文档
- 或直接粘贴文案内容

### 第 2 步：选择风格模板

向用户展示可用风格，并说明每种风格的含义和适用场景：

| 风格 | 适用场景 | 视觉特点 |
|------|---------|---------|
| **default（默认）** | 通用、温暖、有质感 | 暖金色调，柔和排版 |
| **traditional（中国传统文化风）** | 国学、文化、历史类内容 | 朱红/墨黑，书法字体，宣纸纹理 |
| **geek（极客科技风）** | 科技、互联网、产品类内容 | 深蓝/荧光绿，等宽字体，代码感 |
| **cyberpunk（赛博朋克风）** | 潮流、年轻、创意类内容 | 霓虹紫/品红，高对比，未来感 |
| **consulting（咨询公司风）** | 商务、专业、企业类内容 | 深蓝/灰色，简洁严谨，埃森哲风格 |

**选择后**：读取对应的 `templates/{style}.html` 模板。

### 第 3 步：处理文案内容

1. **解析文案**：提取每条文案的内容、日期、阶段标签、配图建议
2. **清理排版**：
   - 删除每句末尾多余的句号（如连续多个"。"）
   - 合并过度换行（超过 2 个换行符合并为 2 个）
   - 统一标点符号（全角/半角）
3. **日期映射**：根据文案中的日期信息，生成日期→内容锚点的映射

### 第 4 步：生成 HTML

使用选定的模板，将处理后的文案注入，生成完整的 HTML 文件。

**HTML 包含**：
- 所有文案内容（按阶段分组）
- 日期自动跳转 JS
- 一键复制按钮（每条文案）
- 防折叠混淆算法（内嵌 JS）
- 目录导航（快速跳转）
- 响应式样式（PC + 移动端）

### 第 5 步：输出和部署

生成的 HTML 文件：
- **本地使用**：直接双击打开，所有功能正常
- **部署到服务器**：上传 HTML 文件，分享给团队
- **WorkBuddy 兼容**：纯静态文件，无需后端

## 防折叠混淆说明

### 核心原理

微信朋友圈折叠的多维度检测：
1. **哈希值检测**：同一账号短时间发布相同文案 → 折叠
2. **语义相似度**：多人转发相同内容 → 折叠
3. **发布频率**：同账号 3 分钟内多次发布 → 自动折叠
4. **字数+行数**：>100 字且>6 行 → 格式化折叠
5. **营销识别**：含敏感词汇 → 人工/算法审核

本技能采用**双重混淆策略**：

#### 方法 1：Unicode 排版方向控制（RLO/PDF）🌟
```
原文：我见过很多企业家
防折：我‮过见‬很多企业家

实际字符顺序：我 + RLO + 过 + 见 + PDF + 很多企业家
显示效果：完全正确（RLO 使部分文字反向显示）
微信检测：字符序列被打乱，哈希值完全不同
特点：视觉零差异，最难被识别
```

#### 方法 2：零宽字符插入
- 在文本中随机插入不可见字符（`​`, `‌`, `‍`, `﻿`）
- 不改变视觉效果，改变哈希值
- 作为 RLO 的补充

### 关键优化：每次复制都不同 ✨

**问题**：如果多个人同时复制同一条文案，结果相同 → 微信仍识别为重复

**解决方案**（已实现）：
1. **随机混淆位置**：不是固定间隔插入，而是完全随机选择
2. **随机混淆方式**：随机决定先用 RLO 还是零宽字符
3. **随机混淆强度**：每次的密度和范围都有变化
4. **每次复制都生成新方案**：即使同一条文案复制两次，结果也不同

**结果**：
- 用户 A 复制：`我‮过见‬很多…` 
- 用户 B 复制同一条：`我‬见过‮很‍多…`
- 用户 C 复制同一条：`我…见‌过很多‮…`
- 微信看到三个不同的文案 → 各自独立，不被折叠 ✅

### 混淆强度

- **轻度**：RLO 密度 15%，零宽字符密度 10%
- **中度**（默认）：RLO 密度 25%，零宽字符密度 15%
- **重度**：RLO 密度 35%，零宽字符密度 25%

### 最佳实践

虽然防折叠已大幅优化，但微信算法持续演进。建议配合：
- ✅ 分多次粘贴，每次不超过 100 字
- ✅ 在微信中先手动输入 2-3 个字，再粘贴其余部分
- ✅ 将核心/敏感内容放在配图上
- ✅ 避免连续发布（间隔 5 分钟+）
- ✅ 混合使用不同的措辞表达同一意思

## 可选：大模型文案优化

如果用户希望文案内容可以有变化（不要求与原文案一模一样），可以在生成 HTML 之前，调用大模型对文案进行优化：
- 保持原有情感和原意
- 调整句式、修辞，增加差异化
- 避免与其他团队成员的文案高度重复

**此功能默认关闭**，需要用户主动提出。

## 示例

**用户输入**：
```
我有一批朋友圈文案，在 `.claude/明理之光发售全案/朋友圈文案.md` 里。帮我生成 HTML，用默认风格。
```

**技能执行**：
1. 读取 `.claude/明理之光发售全案/朋友圈文案.md`
2. 解析文案内容（29 条，分 5 个阶段）
3. 使用 `templates/default.html` 模板
4. 生成 `moment-plan.html`
5. 用户打开 HTML，自动定位到今天，点击复制即可

## 注意事项

- 生成的 HTML 是**自包含的**，所有 CSS 和 JS 内嵌，无需外部依赖
- 防折叠混淆在复制时执行，不影响页面显示
- 日期自动跳转基于用户本地系统时间
- 模板可以扩展，后续可添加更多风格
