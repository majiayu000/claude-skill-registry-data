# meme-virus-analysis

## When to Use

当需要分析一个观念、文化现象或行为模式为何能广泛传播并被人接受时description

## Core Logic

# 执行步骤

1.  **定义待分析的模因**
    *   **输入**：一个具体的观念、口号、行为模式、价值观或文化符号。
    *   **操作**：清晰、简洁地描述该模因的核心内容及其表现形式。
    *   **判断标准**：描述准确，能将其与其他模因区分开来。
    *   **输出**：模因的明确界定。

2.  **识别模因寄主的价值观阶段**
    *   **输入**：模因的明确界定。
    *   **操作**：分析该模因主要吸引或产生于哪类人群。使用“螺旋动力学阶段评估”模型，推断该人群主导的价值观阶段（如蓝色、橙色、绿色等）。
    *   **判断标准**：能建立模因内容与特定价值观阶段核心诉求之间的逻辑关联。
    *   **输出**：模因主要寄主的螺旋动力学阶段标签。

3.  **分析模因的“适应性”功能**
    *   **输入**：模因界定及其寄主阶段标签。
    *   **操作**：从寄主价值观的角度，分析该模因如何满足其心理或社会需求。
        *   **IF** 寄主阶段为蓝色 → 分析模因是否提供了**秩序、意义、归属感**或**明确的善恶标准**。
        *   **IF** 寄主阶段为橙色 → 分析模因是否承诺了**成功、效率、竞争优势**或**个人提升**。
        *   **IF** 寄主阶段为绿色 → 分析模因是否强调了**平等、包容、社区联结**或**批判不公**。
        *   **IF** 寄主阶段为黄色/天蓝色 → 分析模因是否体现了**系统整合、灵活性**或**整体视角**。
    *   **判断标准**：分析能解释“为什么这个模因对这个群体有吸引力”。
    *   **输出**：关于模因如何满足特定阶段价值观需求的分析陈述。

4.  **评估模因的传播与复制机制**
    *   **输入**：模因适应性分析。
    *   **操作**：识别该模因通过何种渠道（如社交媒体、教育体系、权威人物）和形式（如故事、图像、简洁规则）进行传播。分析其是否易于被记忆、理解和再次传递。
    *   **判断标准**：能指出至少一种有效的传播途径或复制特征。
    *   **输出**：对模因传播机制的描述。

5.  **推断模因的影响与演变**
    *   **输入**：前述所有分析结果。
    *   **操作**：综合判断该模因可能产生的长期影响。
        *   **IF** 模因强化其寄主阶段的固有局限（如蓝色僵化、橙色短视、绿色相对主义）→ 预测其可能导致思维封闭或群体极化。
        *   **IF** 模因有助于整合不同阶段视角或促进向更复杂阶段发展 → 预测其可能促进认知升级或社会创新。
        *   预测该模因在环境变化下可能发生的演变或被新模因取代的条件。
    *   **判断标准**：推断基于螺旋动力学的发展逻辑，而非主观臆断。
    *   **输出**：关于模因潜在社会心理影响及演变方向的推论。

# 输出格式要求
输出一份分析简报，包含：
1.  **模因定义**：清晰描述所分析的观念或文化单元。
2.  **核心寄主**：指出其主要吸引的价值观发展阶段及原因。
3.  **适应性分析**：阐明该模因如何满足寄主的核心心理需求。
4.  **传播机制**：简述其如何被复制和扩散。
5.  **影响与展望**：总结其可能带来的影响及未来演变趋势。
