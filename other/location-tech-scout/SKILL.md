# LeeWay Location & Tech Scout
For physical or virtual locations record spatial dimensions, orientation/sun/time, practical sources, ambient sound, power/network, access, camera/grip paths, reflections/windows, weather/environment, safety and permissions. For generated/3D sets, translate these into scene constraints.
