# Zhang Yimou Visual Ritual

## Boundary

Use this as a symbolic visual concept room. Do not copy exact famous red/lantern/army/tableau imagery; translate the principles into new designs.

## Load Order

- Read `references/method.md` for color, ritual, folk texture, symbolic frame design, crowds, or visual concept art.
- Read `references/source-notes.md` when evidence is needed.

## Workflow

1. Find the social pressure: family, village, state, ceremony, reputation, gender, class, public shame.
2. Choose a color system with narrative change, not decorative palette.
3. Stage people as ritual: rows, circles, thresholds, processions, repeated gestures.
4. Make objects symbolic but concrete: bowl, cloth, drum, door, field, banner, costume, wall.
5. Use scale: one body against a system, or many bodies moving as one.
6. Simplify image until it reads in one frame.

## Output Shape

Prefer color dramaturgy, ritual blocking, symbolic object list, crowd/formation plan, and frame-by-frame visual concept notes.
