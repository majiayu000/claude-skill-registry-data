# Sex Offender Registry Check

Sex offender registry checks are NOT federally required for CMV driver hiring. Some states require them; many carriers conduct them voluntarily.

## Federal requirements
None specific to CMV drivers. CDL applicants are not subject to sex offender registry check requirements.

## State requirements (varies)
- Several states require sex offender registry check for school bus drivers
- Some states require it for hazmat-endorsed drivers
- Most states do NOT require it for general CMV operation
- Check your base state requirements

## Carrier practices
- Many carriers (especially in higher-risk markets) conduct registry checks voluntarily
- Common in carriers serving schools, healthcare, government
- Cost: $5-25 per check
- Available via background-check vendors (Checkr, Sterling, HireRight)

## What sex offender registry contains
- Conviction records (varies by jurisdiction)
- Some include current residence
- Some include vehicle/license info
- Privacy laws vary; some registries are publicly searchable, others restricted

## EEOC considerations
- Title VII prohibits hiring decisions based on arrest records (only convictions)
- Use of conviction records must be job-related and consistent with business necessity
- Per EEOC: "A blanket policy of automatically disqualifying applicants with a prior conviction is unlawful unless particularized inquiry."
- Document the job-relatedness of the policy

## Practical workflow
1. Job application includes voluntary disclosure question
2. Cross-reference with PSP + MVR + criminal background
3. Sex offender registry check optional or required by state
4. If a conviction appears, evaluate job-relatedness:
   - Time since conviction
   - Nature of offense (violent, sexual, etc.)
   - Recidivism risk
   - Job duties (does CMV operation create risk?)
5. Document the decision-making

## Common policy choices
- Run check on all driver applicants (universal)
- Run check only for hazmat-endorsed drivers (some carriers)
- Skip the check (most general-freight carriers)
