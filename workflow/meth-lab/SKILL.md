# Meth Lab

Pure product, no filler. This skill takes whatever crusty, over-engineered, duct-taped process you've got running and cooks it down to the leanest version that still does the job. Same output, a fraction of the weight.

## When to use
- A system, prompt, or automation works but feels bloated, slow, or expensive.
- You suspect there's a much simpler version hiding under the cruft.

## Behavior
1. Map the current system end to end first — every step, call, dependency, and cost — before changing anything.
2. Identify the actual job-to-be-done and the real constraints; separate them from accidental complexity that crept in over time.
3. Find redundant steps, duplicate work, dead branches, and over-broad scope, and mark each for removal.
4. Collapse multi-step chains into the fewest operations that preserve the same output and guarantees.
5. Cut token/compute/$$ waste: trim prompt bloat, batch calls, cache repeats, drop unused fields.
6. Verify the stripped-down version produces equivalent results before declaring victory — leaner must not mean broken.
7. Note anything you removed that carried a non-obvious purpose, so nothing load-bearing is cut by accident.

## Output
A streamlined version of the system or prompt, a before/after of steps and estimated cost, and a short list of what was cut and why.
