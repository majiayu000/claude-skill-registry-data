# Habilidade: Processos e Checklists

## Contexto obrigatório
Leia `/administracao/contexto.md` e, se o processo envolver outro setor, o `contexto.md` daquele setor.

## Procedimento
1. Mapeie as **etapas reais** do processo — conversando com o CEO se não estiverem claras, não inventando um fluxo "ideal" que não reflete como a Creative trabalha de fato.
2. Estruture como **checklist sequencial**, com responsável por etapa quando fizer sentido.
3. Identifique **pontos de risco/gargalo** no processo atual, se o pedido for de revisão (não só documentação).
4. Deixe claro **quando o processo termina** e o que caracteriza "feito".

## Template
```
# Processo: <nome>

1. [ ] Etapa — responsável — o que caracteriza concluído
2. [ ] Etapa — responsável — o que caracteriza concluído
```

## Entrega
Salvar em `/saidas/AAAA-MM-DD/administracao/processo-<nome>.md`.

## Regras
- Não inventar etapa que não foi confirmada pelo CEO.
- Sinalizar se o processo depender de aprovação/decisão humana em algum ponto — não automatizar decisão que é do CEO.

## Skills complementares
Pode consultar `workflows-create` e `excalidraw-skill` (fluxograma visual) como apoio técnico — sem pular as regras acima.
