# Cyber Terminal Schematic（赛博终端示意图）

把一个概念编译成**一条**可直接交给图像模型的提示词，风格锁死为「技术示意图海报」：一族终端原生图面当主视觉，套一层按预设装配的 HUD 仪表框（角落数据面板、图例、标尺、系统状态行）。

核心原则：**风格锁死，图即内容。** 这套风格不是加科技感滤镜，是把文章的逻辑结构本身画成一张仪表图——流程画成拓扑，排序画成条形，变化画成折线，构成画成堆叠。结构越清楚，图越好看。

风格是常量，图面不是。**锁死的是载体**（黑底、单绿、等宽、辉光、扫描线），**自由的是画什么**（图面族、HUD 配置、标签语言）。改图面不算破风格，改载体才算。

## 两种输出模式

| | 封面 Cover | 插图 Inline |
|---|---|---|
| 目标 | 首屏砸眼、可点击 | 讲清一个段落的结构 |
| 画幅（锁死） | **5:2 横板** | **16:9** |
| 主标题 | 巨型渲染进画面 | 极少量小标，或无 |
| 图面复杂度 | 主结构完整 + 具名节点/条目 | 单一概念图，结构更简 |
| HUD | 篇内同一预设 | 篇内同一预设（不单张降档） |

## 单一寄存器

纯黑底 + 单一霓虹绿荧光 + 等宽字，赛博终端 / 系统监控 HUD 感。整套只有这一个配色，没有备选。

> 蓝底白线的工程图纸已经拆成独立 skill：`engineering-blueprint-sheet`。那边是**印出来的纸**（线型分级、尺寸标注、标题栏、纸纹折痕），这边是**发光的屏**（等粗细线条、辉光、扫描线）。两边元素不互相借用——终端上不许有折痕，蓝图上不许有辉光。用户要蓝图就转过去，不要在这里调色。

## 屏幕质感强度

这套风格最容易翻车的地方是出成一张干净矢量流程图——干净、正确、没味道。质感层不是可选滤镜，是**必带的一段**，独立于内容存在：内容是平面线稿，质感是承载它的那块屏。

三档，一次选一档，**整篇统一**（封面和所有插图必须同档，否则并排看一眼就假）：

| 档位 | 给什么 | 加了什么 |
|---|---|---|
| CRT-01 CLEAN | 信息密度高的插图、超长标题封面 | 横向扫描线 + 辉光溢出 + 四角压暗 |
| **CRT-02 STANDARD（默认）** | 封面和大多数插图 | 上一档 + 荧光竖向颗粒 + 屏幕弧度 + 边缘虚焦 + 玻璃雾感 + 逐行明暗浮动 |
| CRT-03 DEGRADED | 只用于封面/单张大图，讲旧、遗留、故障、归档 | 上一档 + 横向刷新亮带 + 右向拖影 + 烧屏残影 + 雪花噪点 + 老化玻璃 |

用户没指定用 CRT-02。

铁律一条：**质感盖在内容之上，永远不吃内容**——扫描线压过标题和节点标签，但缩略图状态下所有字仍然认得出来。

## 图面族（八族，一张图只用一族）

主视觉不是只有拓扑图。终端这块屏原生就能画下面八族，每族都不破任何一条铁律——它们共用同一套线稿语法（等粗细、细描、发光点），只是几何不同。完整几何描述和各族的坑在 `references/compile-contract.md`。

| 族 | 对应的段落逻辑 |
|---|---|
| **TOPOLOGY 节点拓扑**（默认招牌） | 流程、分工、依赖、循环、分诊 |
| **BAR RANK 条形排行** | 排序、占比、谁多谁少、前后对比 |
| **TIME SERIES 时序折线** | 趋势、增长、波动、拐点 |
| **MATRIX GRID 矩阵网格** | 二维分类、覆盖度、密度、有无 |
| **STACK 层级堆叠** | 上下游、抽象层、技术栈、构成 |
| **TIMELINE 时间轴** | 阶段、里程碑、演进顺序 |
| **BIG METRIC 巨型指标** | 单一数字砸脸，配一条趋势小线 |
| **SPLIT COMPARE 左右对照** | A vs B、旧法 vs 新法、错 vs 对 |

三条硬规矩：

1. **一张图一族，绝不混族。** 拓扑 + 条形塞进同一张必乱，要两族就出两张图。
2. **表是常见解，不是全集。** 表外结构可以自造，但必须满足：一个主结构、一句话能说清几何、缩略图状态下结构不糊。三条缺一就退回最近的一族。
3. **自带轴的族不叠边缘标尺**（见下节 HUD 预设）。

## HUD 预设（开篇选一次，篇内锁死）

HUD 不是固定一套。开篇选一个预设，**同一篇的封面和所有插图用同一个**，跨篇随意换——这样篇内成系列，篇与篇之间不会十篇长一个样。

| 预设 | 元素 | 给什么 |
|---|---|---|
| **HUD-FULL** | 角落面板 + 图例 + 边缘标尺 + 状态行 + 角标 | 流程/工程题材，拓扑族封面 |
| **HUD-LEAN（默认）** | 角落面板 + 状态行 + 角标 | 大多数情况；信息密度高或标题很长时 |
| **HUD-EDGE** | 只角标 + 一条边标尺 | 自带坐标轴的族，避免双重刻度 |

**双重刻度是扩容后最容易出的脏**：BAR RANK / TIME SERIES / MATRIX GRID / TIMELINE 这四族图面自己带轴和刻度，再套 HUD-FULL 的边缘标尺，画面四周会出现两套读不通的尺子。这四族默认走 HUD-EDGE 或 HUD-LEAN。

也可以自定义组合，但整篇锁死同一套。

## 标签语言（中文可用，受控）

图里的文字分两层，规矩不同：

- **HUD 层全拉丁**：面板、图例、状态行、角标一律短拉丁字段（PROJECT / TYPE / SYS READY / [ok]）。中英混在同一个部件里显脏，这层不开口子。
- **图面层可中文**：节点标签、条目名、轴标、行标可以用短中文，**2-6 字、粗黑体、全图上限 8 个**。超过 8 个说明这张图该拆成两张。

中文标签必须逐个列进 TEXT 段并要求 verbatim 渲染，不然模型会造假字。仍然禁止：长中文句子、中文段落、中文写进 HUD 部件。

## Read

- 编译提示词：读 `references/compile-contract.md`（消歧义铁律 + 锁死内核 + 八族图面几何 + HUD 预设 + 固定骨架 + 三档质感层原文）。三档 SCREEN TEXTURE 的英文段落在那里，整段复制，不要自己重写。
- 要成品参考或批量做整篇：读 `references/examples.md`（封面 + 系列插图的已决策成品 prompt）。

## Input

从用户输入推断，不要求填表：

1. **模式**：封面（5:2）还是插图（16:9）。做整篇时先出封面再出插图系列。
2. **图面族**：八族选一，按段落逻辑判；判不准就问一句这段到底在说什么关系，不要默认套拓扑。
3. **HUD 预设**：HUD-FULL / HUD-LEAN（默认）/ HUD-EDGE。整篇一套到底。
4. **质感强度**：CRT-01 / CRT-02（默认）/ CRT-03。用户说「旧一点」「故障感」「年代感」就上 CRT-03，说「干净点」「太脏了」就退 CRT-01。
5. **主标题**：用户原文照抄，不翻译不润色；中文主标建议 2-8 字，最多一行小副标。只有封面渲染大标题。
6. **图面内容**：把段落逻辑转译成选中那一族的具体几何（节点/条目/轴/层各是什么），以及要出现的中文标签。

## Workflow

1. **判模式**：封面锁 5:2、插图锁 16:9。用户要的是图纸不是屏幕，转 `engineering-blueprint-sheet`。
2. **选图面族**：一张图一个主结构，对应段落的核心逻辑。抽象概念要落到具体几何（分工→拓扑菱形；谁多谁少→条形排行；这两年怎么变的→时序折线；旧法 vs 新法→左右对照）。表外结构按元规则自造。
3. **定 HUD 预设 + 质感档**：默认 HUD-LEAN + CRT-02；两者都整篇一套到底。自带轴的族退到 HUD-EDGE。
4. **定标签**：先定中文标签（≤8 个、2-6 字），再补拉丁 HUD 字段。中文标签逐个写进 TEXT 段并要求 verbatim。
5. **锁招牌装置**：整篇封面 + 所有插图共享同一个 HUD 预设 + 同一档质感层。只有中间的图面和标题变，边框和质感一字不变——这是整篇成系列的关键。交付成图时，再配一张已出好的基准图当参考一起喂，比只靠文字稳；后续每张都锚回那张基准图，不要拿上一轮输出继续改。
6. **编译提示词**：按 `compile-contract.md` 的固定骨架输出成品，无占位符、无菜单、正文零中文（要渲染进画面的标题和标签除外）；SCREEN TEXTURE 段整段照抄不改写。
7. **输出**：模式 + 图面族 + HUD 预设 + 质感档 + 一条完整提示词 +（可选）一句选型理由。用户只要 prompt 时省略解释。

## Quality Gates

- 图面是主视觉，HUD 是配角；不要让面板和日志抢过中央的图。
- 一张图只有一族图面，不混族；HUD 预设和质感档整篇统一，跨篇可换。
- 自带坐标轴的族（条形 / 时序 / 矩阵 / 时间轴）不叠 HUD 边缘标尺——两套刻度同框即废图。
- 单一色相铁律：只有一种绿，出现第二种彩色即偏移。**CRT 质感不是破例口子**——RGB 子像素三联点、色散分离、彩虹边一律不要，老屏幕在这里是单色荧光屏。
- 不许出现纸的元素：折痕、水渍、纸纹、图钉孔、线型分级、尺寸标注箭头、标题栏表格——那些属于 `engineering-blueprint-sheet`，出现即串味。这边**示意图线稿**全部一样粗，这是屏幕的语法；**这条只管线不管字**，标题该粗就粗，AVOID 要写成 `varying stroke weights inside the linework`。
- 质感层必带，且必须是独立一段；只在 LOCKED 里写一句 scanline 会被模型无视，出来还是干净矢量图。
- 质感不吃字：缩略图状态下主标题和所有节点标签仍然清晰。扫描线咬碎笔画、辉光把标题糊成一团光斑，都算废图。
- 图面关系必须读得出来，缩略图状态下结构不糊：拓扑要看清入口/分支/汇合/出口/回环，条形要看清谁长谁短，折线要看清趋势方向，堆叠要看清上下顺序。
- 主标题精确渲染，放引号里并补 `render verbatim, no extra words or characters`；中文标题用用户原文，不出现假中文字。
- **所有中文文字都走粗黑体，不写 monospace**（那对中文无效）——这条对主标题和中文标签一视同仁。
- 中文标签受控：只出现在图面层（节点/条目/轴/行），2-6 字，全图 ≤8 个，逐个列进 TEXT 段并要求 verbatim。HUD 部件里不出现中文。
- 不生成看起来像真实可读代码的大段文字；状态行和字段是短标签，不是真代码。**时钟时间可用**（`[10:14:23]` 这类 HH:MM:SS，日志感全靠它），**日期不可用**（年份、YYYY-MM-DD、月份名一律禁）——两者不是一回事，别一起禁掉。
- 封面永远 5:2，插图永远 16:9，除非用户明确改画幅。合法分辨率：5:2 → `2560×1024`，16:9 → `2560×1440`。画面有小字，quality 拉到 high。
- 本 skill 只产出提示词，不编造已生成的图片结果。
