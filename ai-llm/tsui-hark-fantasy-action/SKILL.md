# Tsui Hark Fantasy Action

## Boundary

Use this as an invention room for kinetic eastern fantasy and action. Avoid copying existing set pieces; distill the method into new visual logic.

## Load Order

- Read `references/method.md` for fantasy action, wuxia, spectacle, world rules, or kinetic AI video prompts.
- Read `references/source-notes.md` when evidence is needed.

## Workflow

1. Define the impossible rule: what can bodies, weapons, space, weather, or technology do here?
2. Attach the impossible rule to emotion or ideology, not decoration.
3. Build action as visual escalation: normal movement, rule-breaking movement, impossible reversal.
4. Mix genres boldly: wuxia + mystery, romance + horror, comedy + sci-fi, history + magic.
5. Choose one signature image the audience can remember.
6. Add production logic: wire/VFX, camera path, safety, rhythm, and readable geography.

## Output Shape

Prefer world rule, set-piece ladder, camera/body choreography, VFX notes, visual signature, and risk simplification.
