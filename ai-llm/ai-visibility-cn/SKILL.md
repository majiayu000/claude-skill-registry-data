# 国内 AI 搜索可见性（GEO）

用户决策入口正在迁移到 AI 问答。国内信源生态与海外完全不同：知乎/公众号/百家号/百科/官网是主要引用源，且各引擎信源偏好不同。

## 国内引擎与信源特点（以实测为准，生态变化快）

| 引擎 | 信源特点 |
|---|---|
| 夸克 AI 搜索 | 阿里系，全网+夸克内容生态；用户规模大，年轻/学习场景多 |
| DeepSeek（联网） | 全网检索，引用标注清晰；技术/专业人群渗透高 |
| 豆包 | 字节系，抖音/头条生态内容权重高；大众用户多 |
| 腾讯元宝 | 混元+DeepSeek 双模型；**可检索微信公众号内容（独家信源）**，公众号资产直接影响元宝答案 |
| Kimi | 长文本与联网检索；办公/研究场景 |
| 秘塔 AI 搜索 | 结构化检索+学术/全网模式，引用来源列表清晰，适合审计信源 |
| 百度 AI 搜索 | 文心+百度生态（百家号/知道/百科）权重高 |

## 工作流程

### 1. 品牌答案审计

- 构造问题集（20–50 个）：品类推荐（"XX 哪个牌子好"）、对比（"A 和 B 怎么选"）、品牌事实（"XX 是哪家的/怎么样"）、场景决策（"预算 X 买什么 XX"）；
- 逐引擎实测（用户手动测或提供截图/结果），记录：是否提及品牌、排序位置、表述正负面、引用信源 URL；
- 输出"可见性矩阵"：问题×引擎×提及/排序/情感/信源。

### 2. 信源缺口分析

- 汇总被引用信源类型：知乎回答/公众号文章/百家号/百科/官网/垂直媒体/小红书（部分引擎）；
- 找出竞品被引而我方缺席的信源位（如某知乎高赞问题、某百科词条、某测评文章）；
- 检查品牌事实错误（AI 幻觉/过时信息）：错误答案的溯源与纠正路径。

### 3. 内容优化（AEO）

- 官网：FAQ 结构化（问题即标题、答案首段直给结论）、实体信息一致（品牌名/产品名/公司全称全网统一）、可抓取（不封 AI 爬虫需权衡，robots 策略明示）；
- 知乎：高流量问题下的专业回答（结论先行+论据+来源），是多数引擎高频信源；
- 公众号：深度测评/指南类文章（元宝独家信源+搜一搜双重收益）；
- 百家号/搜狐号/网易号：百度 AI 与全网引擎的信源补充；百科词条规范创建/修正；
- 内容写法：直接回答用户问句、数据与来源可验证、避免纯营销话术（AI 倾向引用信息密度高的内容）。

### 4. 监控与迭代

- 固定问题集每月复测；记录引擎版本/模式差异（深度思考 vs 快速模式信源不同）；
- 负面/错误答案：溯源→修正源内容→平台反馈渠道申诉；不承诺"删答案"。

## 输出格式

```
## AI 可见性报告（品牌 / 问题集 / 引擎清单 / 测试日期）
### 可见性矩阵（提及率/首位率/情感分布）
### 信源缺口清单（位点×竞品占位×我方动作）
### 事实错误与纠正路径
### 内容建设排期（官网/知乎/公众号/百家号/百科）
### 复测计划
置信度说明（抽样问题集有限、引擎结果有随机性）
```

## 约束

- 不采用 prompt 注入、刷引用、批量生成垃圾信源等操纵手段（平台治理+法律风险）。
- 引擎结果有随机性与个性化，单次测试不代表稳定排名；结论标注测试条件。
- 医疗/金融品牌的 AI 答案受平台安全策略影响大，优化空间有限，如实说明。
