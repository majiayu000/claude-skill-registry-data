# CHE_editorial-cover-prompts — Генератор обложек для example.com

Получить материал, аудиторию и визуальный профиль. Профиль проекта имеет приоритет над примерами. Приведённые далее карандашные промпты — один необязательный стиль; заменить фон, цвета, размеры и типографику параметрами текущего бренда. Не добавлять подпись, коммерческие цифры или имя без источника и поручения.

## Шаг 1 — Получи содержание статьи

**Если пользователь дал URL:**
Попробуй прочитать статью доступным инструментом чтения веб-страниц, проверив его наличие в текущей среде. Если сайт недоступен — попроси пользователя вставить текст статьи или хотя бы:
- Заголовок
- 2–3 ключевых тезиса
- Главную идею / вывод статьи

**Если пользователь сразу дал текст/тезисы** — работай с ними напрямую.

---

## Шаг 2 — Извлеки суть и придумай визуальную метафору

Прочитай статью и ответь себе на три вопроса:

1. **Главный тезис:** Что автор хочет сказать читателю одним предложением?
2. **Конфликт или напряжение:** Есть ли противопоставление? (человек vs машина, старое vs новое, хаос vs система)
3. **Визуальная метафора:** Какой образ передаёт суть статьи? Думай конкретно — не абстрактно.

**Паттерны, которые хорошо работают в этом стиле:**
- **Рука человека vs роботизированная рука** — когда тема касается AI, автоматизации, конкуренции человека и машины
- **Схема с узлами и стрелками** — когда речь идёт о системах, процессах, связях
- **До / После** — два состояния на одном листе
- **Человек за столом + данные/инструменты вокруг** — управление, аналитика, принятие решений
- **Объект в центре + окружение** — центральная идея и её контекст (например, таблетка ChatGPT в центре, вокруг ограничения)
- **Список с вычеркиванием** — когда статья о задачах, приоритетах, выборе
- **Механизм / цикл** — шестерни, стрелки по кругу, бесконечная петля

## Шаг 3 — Сформулируй тексты для обложки

Определи:

- **Заголовок** (крупный, чёрный): берётся из статьи или перефразируется. Максимум 5–7 слов. Должен цеплять — парадокс, вопрос, сильное утверждение.
- **Подзаголовок** (меньше, красный): расшифровывает или усиливает. Максимум 8–10 слов.
- **Акцентный элемент** (опционально): число в красной рамке, плашка-тег, короткая фраза как стикер (например: «Источник → результат», «2026», «ВАЖНО»).
- **Подпись** (опционально): «example.com» — мелко, внизу.

## Шаг 4 — Составь промпты для генерации

Выдай три варианта промптов — для разных инструментов.

### 4а. Универсальный мастер-промпт (русский)

```
Создай горизонтальную обложку для блога, 1400×900 px.
Фон — белая бумага. Стиль — карандашный скетч с перекрёстной штриховкой, как у профессионального иллюстратора.
Палитра: чёрный и серый карандаш + красный как единственный акцентный цвет (стрелки, рамки, ключевые детали, подчёркивания). Никакого другого цвета.

Иллюстрация: [ВИЗУАЛЬНАЯ КОНЦЕПЦИЯ]. Рисунок передаёт суть статьи через конкретный образ — схему, метафору, объекты. Стиль: скетч от руки, штриховка, динамичные стрелки.

Текст на обложке:
- Заголовок: «[ЗАГОЛОВОК]» — крупный жирный шрифт, чёрный
- Подзаголовок: «[ПОДЗАГОЛОВОК]» — меньше, красным
[ОПЦИОНАЛЬНЫЙ АКЦЕНТ: число/тег в красной рамке]

Без фотореализма. Без градиентов. Без лишних цветов. Концептуально и динамично.
```

### 4б. Промпт для Midjourney (английский)

```
Blog cover illustration, horizontal 1400x900px. White paper background. Professional pencil sketch style with cross-hatching. Black and grey pencil + red as the ONLY accent color (arrows, frames, key elements). No other colors.

Illustration concept: [ENGLISH VISUAL CONCEPT]. Hand-drawn arrows, diagrams, sketch-style objects. Dynamic composition.

Bold black headline text: "[HEADLINE]"
Smaller red subheadline: "[SUBHEADLINE]"
[OPTIONAL: red-framed badge/tag]

Sketch illustration style, no photorealism, no gradients, no color fills. Clean white paper, conceptual, dynamic. --ar 14:9 --style raw 
```

### 4в. Промпт для Ideogram (английский, оптимизирован под рендер текста)

```
Pencil sketch blog cover, white paper background, 1400x900. Cross-hatching illustration style, black/grey/red only. Red is the only accent color.

Scene: [ENGLISH VISUAL CONCEPT]

Typography on image:
LARGE BOLD BLACK: "[HEADLINE]"
SMALLER RED: "[SUBHEADLINE]"
[OPTIONAL TAG in red box]

Style: hand-drawn sketch, professional illustrator, dynamic arrows, no photorealism, no gradients. Editorial illustration for Russian marketing blog.
```

## Шаг 5 — Визуальный бриф (итог)

После промптов выдай компактный бриф в таком формате:

```
📐 ВИЗУАЛЬНЫЙ БРИФ

Статья: [название/URL]
Главный тезис: [одно предложение]

Иллюстрация:
— Что изображено: [описание]
— Ключевой конфликт/напряжение: [если есть]
— Эмоция/ощущение: [что должен почувствовать читатель]

Текст:
— Заголовок: [текст]
— Подзаголовок: [текст] (красный)
— Акцент: [если есть]

Лучший инструмент для этой концепции: [Midjourney / Ideogram / ChatGPT image + почему]
```

## Если пользователь просит несколько вариантов

Предложи 2–3 разные визуальные метафоры с кратким обоснованием — пусть выберет, какая концепция резонирует больше. Потом генерируй полные промпты только для выбранного варианта.

## Quality gate

Перед передачей результата прочитай `evals/shared.csv`, `evals/skill-specific.csv` и `evals/judge_prompt.md`. Оцени каждый критерий независимо; не заменяй проверки общим баллом.

Если результат ограничен визуальным брифом и промптами, не утверждай, что обложка создана или визуально проверена. Если создан фактический файл изображения, обязательно открой его, проверь композицию и артефакты, а размер и формат сверь по метаданным. Указание требований в промпте не считается доказательством их выполнения на изображении. После исправлений повторно проверь все проваленные критерии; условные критерии к фактическому изображению помечай `not_applicable`, когда файл не создавался.
## Среда и входы

Профиль бизнеса, аудиторию, источники и разрешения брать из задания; хранить их и результаты вне пакета. Методолог навыка не становится автором материала автоматически. Использовать только объявленные инструменты. Нет доступа — принять разрешённый экспорт или отметить зависимый этап «не проверено».

Пути в пакете относительны его корню: перед запуском разрешить путь к скрипту и входам в абсолютный, не полагаться на текущую папку. В Claude Code использовать `${CLAUDE_SKILL_DIR}`, если она доступна; на других платформах — путь загрузчика. Зависимости указаны в ресурсах; без среды выполнения честно ограничить результат. Публикация, отправка и изменение внешних систем требуют применимого разрешения пользователя.
