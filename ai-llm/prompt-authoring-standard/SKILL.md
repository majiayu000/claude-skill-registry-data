# Prompt Specification — стандарт разработки промптов

При составлении или переделке промпта следуй этой структуре.

## Роль модели
- [ ] Явно задай роль (например «Senior Python Developer», «Technical Writer»)

## Назначение, цель, область применения
- [ ] Опиши задачу одним предложением
- [ ] Укажи конечный результат для пользователя
- [ ] Укажи область применения: программирование, анализ данных, документация и др.

## Контекст и входные данные
- [ ] Перечисли, что модели известно и что неизвестно
- [ ] Задай ограничения
- [ ] Опиши вход пользователя: код, текст, ссылки, требования, изображения, таблицы

## Предварительный анализ (обязателен)
Перед выполнением модель обязана:
1. Определить цель пользователя
2. Найти неоднозначности
3. Обнаружить конфликты требований
4. Проверить полноту данных
5. Определить недостающую информацию

Если информации недостаточно — сначала задать вопросы.

## Основная задача и алгоритм
Опиши задачу подробно и задай алгоритм:
1. Проанализировать запрос
2. Проверить входные данные
3. Построить решение
4. Проверить результат
5. Выдать итог

## Требования
- Сохранять смысл, не изменять факты
- Использовать Markdown, писать структурированно
- Избегать повторений, профессиональная терминология
- Результат пригоден для дальнейшего использования

## Ограничения
Запрещается: выдумывать факты, изменять смысл, пропускать требования, использовать неподтверждённые сведения, писать лишний текст.

## Формат ответа
```
Анализ
Замечания
Решение
Итог
```

## Критерии качества
Успешно, если: нет противоречий, нет неоднозначностей, соблюдены все требования, информация структурирована, ответ легко читать, решение можно использовать сразу.

## Контроль качества
Перед выводом проверь: все ли требования выполнены, нет ли противоречий, не потерян ли смысл, нет ли повторов, нет ли лишнего текста, соблюдены ли ограничения.

## Форматирование и стиль
Markdown, таблицы, списки, кодовые блоки, заголовки — если улучшают читаемость. Стиль — профессиональный, лаконичный, без воды, без эмоциональных оценок, с чёткой структурой.
