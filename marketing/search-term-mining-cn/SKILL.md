# 搜索词挖掘与否词

两个方向：从搜索词报告里**淘金**（高意图词转精确/加预算）与**排雷**（无关词入否词库）；另从业务与竞品**拓词**。

## 数据契约

搜索词报告（搜索词、匹配到的关键词、展示/点击/消耗/转化）；业务信息（产品/服务/地域/客单价/目标人群）；可选：平台下拉词、百度指数/巨量算数/小红书搜索联想、竞品标题。

## 流程

1. **分类打标**：把搜索词按意图分层——
   - 品牌词（自家/竞品）、品类词、场景/需求词（"XX 怎么选""XX 多少钱"）、人群词、长尾问题词、无关词（免费/招聘/教程/图片/下载/加盟骗局等）。
2. **淘金**：有转化且成本达标的词 → 提为精确/单独单元；高点击零转化但意图对的词 → 查落地页匹配而非直接否。
3. **排雷**：高消耗无关词 → 否词；给出**精确否定**（整词无关）与**短语否定**（词根无关，如"免费""招聘"）两份清单，提醒短语否定可能误伤（如"免费"会否掉"免费试用"这类想要的词）。
4. **拓词**：按"人群×场景×痛点×价格×地域"矩阵生成候选词；电商场景叠加属性词（材质/规格/风格/适用人群）；内容搜索场景（小红书/抖音）用口语化问句而非书面关键词。
5. **结构建议**：词性分组（一单元一主题）、匹配方式分层（核心精确+长尾短语+拓量智能匹配但配否词）、品牌词防御。

## 平台差异要点

- 百度：智能匹配必须配否词库；问句词多，落地页要对应解答型内容。
- 巨量搜索：搜索词更口语/短视频化（"XX 推荐""XX 测评"），与信息流素材协同（搜后推）。
- 小红书：搜索词=生活决策问句（"油皮 粉底 平价"），买词之外更要让笔记标题/正文/标签覆盖这些词（见 social-search-seo-cn）。
- 淘宝/拼多多：关键词=购买意图，属性词+人群词组合；避开与商品属性不符的词（转化差还拉低权重）。

## 输出格式

```
## 搜索词分析（平台 / 区间）
### 淘金清单：词 / 数据 / 建议（提精确/加价/建单元）
### 否词清单：精确否定 [...] 短语否定 [...]（附误伤提示）
### 拓词矩阵：N 个候选词分组 + 优先级
### 结构建议
```

## 约束

- 否词前检查该词历史是否有转化；有转化的词不进否词库，先查匹配问题。
- 拓词不堆量：给优先级与理由，标注哪些是假设需验证。
- 竞品词投放提示法律与平台风险（商标侵权投诉可能），由用户决策。
