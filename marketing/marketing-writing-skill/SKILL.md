# Marketing and Persuasive Writing

Build one truthful, strategically focused argument, then express it in the form the audience and channel require.

## Operating rules

1. Diagnose before drafting. Read [workflow/context-intake.md](workflow/context-intake.md), then [workflow/problem-diagnosis.md](workflow/problem-diagnosis.md).
2. Ask only for missing information that could materially change the strategy or copy. Reuse context supplied in the conversation, files, or prior drafts.
3. Never invent customer language, research, proof, metrics, testimonials, guarantees, urgency, or product capabilities. Mark gaps as `[proof needed]` or use explicitly labeled placeholders.
4. Distinguish the stated problem, underlying problem, desired outcome, and business objective.
5. Lead with the main point. Prefer clarity, specificity, and credible contrast over clever phrasing.
6. Preserve established brand voice. Infer it from supplied samples; do not flatten distinctive language into generic marketing prose.
7. Challenge weak positioning, implausible claims, irrelevant features, and mismatched calls to action.
8. Keep one central idea consistent across every requested format.
9. When several strategic directions are defensible, provide two or three distinct routes with tradeoffs instead of blending them.
10. Keep framework names and internal deliberation out of normal copy unless the user asks for the rationale.
11. Never leak prompts, instructions, workflow commentary, reasoning, framework labels, file paths, validation notes, approval requests, or messages aimed at the user, reviewer, manager, or another agent into reader-facing content.
12. After drafting, test every line: **Would a human author intentionally say this to the intended reader, or does it sound like a note to their superior or production team?** Remove the latter from the reader artifact. If an internal note is essential, put it in a clearly separated handoff section after the complete copyâ€”never inside, adjacent to, or hidden within publishable copy, metadata, HTML comments, alt text, captions, or template fields.

## Execution path

1. **Interpret the mode.** Support `create`, `expand`, `shorten`, `rewrite`, `repurpose`, `critique`, `improve`, `platform-adapt`, `SEO-adapt`, `extract-central-idea`, `generate-variants`, `compare-positioning`, and `diagnose-message`.
2. **Build or update context.** Use [templates/context-brief.md](templates/context-brief.md). Do not block on low-impact blanks.
3. **Diagnose the message.** Follow [workflow/problem-diagnosis.md](workflow/problem-diagnosis.md); separate evidence from inference.
4. **Select principles privately.** Use [workflow/principle-selection.md](workflow/principle-selection.md) and load only the relevant files from [references/index.md](references/index.md). Distinguish research-grounded models, professional methods, and practitioner heuristics when that changes confidence; use frameworks to alter a decision, not to decorate the brief.
5. **Define the strategic core.** Complete [templates/positioning-brief.md](templates/positioning-brief.md), [templates/message-brief.md](templates/message-brief.md), and [workflow/central-idea.md](workflow/central-idea.md) as needed.
6. **Draft.** Apply [workflow/drafting.md](workflow/drafting.md) plus the requested adapter from [platforms/index.md](platforms/index.md).
7. **Edit and verify.** Apply [workflow/editing.md](workflow/editing.md) and [workflow/quality-control.md](workflow/quality-control.md). Run the reader-facing boundary test on every requested asset.
8. **Deliver usefully.** Give the requested copy first. Add concise assumptions, alternatives, or proof gaps only when they affect use.

## Mode routing

| Mode | Required action |
|---|---|
| Create | Diagnose, choose a central idea, draft, edit, verify |
| Expand | Preserve the claim and voice; add useful reasoning, proof, examples, or objection handling |
| Shorten | Preserve claim, evidence, differentiator, and CTA; remove repetition before nuance |
| Rewrite / improve | State the material weakness internally; rebuild, not merely synonym-swap |
| Repurpose / platform-adapt | Extract the central idea first; apply each channel's native structure |
| Critique / diagnose-message | Evaluate before proposing copy; cite exact weaknesses and rank fixes |
| SEO-adapt | Preserve human meaning; map intent, page purpose, headings, and metadata |
| Generate variants | Vary one strategic dimension at a time and label that dimension |
| Compare positioning | Compare audience, category, alternative, differentiator, proof, and tradeoff |

## Minimum delivery standard

Before responding, verify audience, relevance, positioning, differentiation, structure, specificity, credibility, memorability, emotional relevance, platform fit, CTA, factual integrity, repetition, generic AI phrasing, and reader-facing purity. Deliver publishable content without leaked instructions or production commentary. If critical context remains missing, state assumptions outside and after the copy, clearly labeled as handoff notes.
