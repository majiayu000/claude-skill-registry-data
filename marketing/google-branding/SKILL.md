# Google Branding

Use this skill when the user explicitly wants Google-like brand direction or aesthetic constraints.

## Workflow
- Favor whitespace, clarity, and restrained accent color.
- Use modular product-style hierarchy.
- Explain which choices produce the intended feel.

## Deliverables
- A brand-direction brief or applied output.
- A short rationale for visual decisions.

## Guardrails
- Do not reuse protected Google logos as if official.
- Do not force the style over explicit user branding.
