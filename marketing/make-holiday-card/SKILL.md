# Make Holiday Card

## What this skill does

- Combines a selected holiday, supplied subjects, exact message and intentional card layout.
- Keeps faces recognizable, copy accurate and important content inside print or digital safe areas.

## How to use

Provide holiday, supplied photos, exact greeting, names, format, channel and visual tone.

#### Example

```text
Create one 5×7 vertical Lunar New Year card from this family photo; exact text 新春快乐 · 林家; elegant red and gold.
```

## Workflow

1. Confirm holiday, audience, exact copy, names, size and photo roles.
2. Lock identity, crop safety, typography hierarchy, bleed and decoration boundaries.
3. Use GPT Image 2 Medium with supplied references and one result.
4. Check every character, all faces and hands, safe areas, contrast, dimensions and extra-person errors.

When this Skill selects GPT Image 2, use `quality: "medium"` and `imageSize: "2K"` by default; change either only when the user explicitly requests another tier.

Every GPT Image 2 call in this Skill defaults to Medium at 2K; use another tier only when the user explicitly requests it.

## User-facing output

- Media type: One holiday card image
- Default quantity: 1
- Content per image: One personalized card with exact approved greeting
- Default layout: User-requested or print-defined format
- Model policy: GPT Image 2 exact-copy card design
- Downstream use: Digital greetings and print cards
