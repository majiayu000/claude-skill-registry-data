# 渠道追踪与归因（国内现实版）

国内追踪的三大坑：微信内打开丢参数、APP/小程序与 H5 割裂、平台转化回传与业务口径不一致。先画链路再配参数。

## 输入

转化链路图（流量源→落地载体→转化事件→业务系统）、各平台投放情况、技术能力（可否埋点/接 API/开发小程序）、现有追踪手段。

## 分场景方案

### 1. H5/官网（浏览器环境）

- UTM 五参数规范：utm_source（平台：douyin/wechat/baidu/xhs）、utm_medium（paid/organic/social/private）、utm_campaign（活动_日期）、utm_content（素材ID）、utm_term（关键词）；
- 命名规则表 + 批量生成（给模板表格）；落地页统一接收并写入表单隐藏字段/CRM；
- 失效场景明示：微信内置浏览器打开外链常丢参/被拦截；APP 内 webview 部分丢参；抖音跳转微信链路基本不可追踪——这些场景用下面的替代方案。

### 2. 平台广告转化回传（投放优化依赖）

- 巨量：监测链接/转化 API 回传（线索/表单/付费事件），clickid 透传；回传延迟与丢失直接影响 oCPM 模型；
- 腾讯：click_id + 转化回传（API/SDK），微信生态内转化（加企微/小程序）用官方归因能力；
- 百度：oCPC 回传（API/基木鱼组件）；快手/小红书类似；
- 原则：回传事件与优化目标一致、去重、延迟监控；回传数与业务数定期对账（差异 >10% 先修数据）。

### 3. 微信生态

- 企微渠道活码：一渠道一码（广告/包裹卡/门店/直播），自动打标签+分渠道欢迎语；
- 小程序：路径参数（scene/query）带渠道，小程序数据助手+自定义埋点；公众号带参二维码；
- 视频号/微信小店：订单来源分析+达人/团长渠道标识。

### 4. 电商

- 站内：生意参谋/罗盘/商智的流量来源口径；站外引流用平台联盟/UD 等官方链路（可归因）；
- 包裹卡/短信/私域→店铺：渠道券/专属 SKU/客服报暗号等土办法兜底（标注精度有限）。

### 5. 归因口径

- 平台归因（点击/展示窗口各异）vs 业务归因（CRM 首触/末触）必然对不上；给"对账表"：各平台报表转化×折算系数≈业务成交；
- 多触点：国内缺乏跨平台统一归因，建议"平台内归因+业务端首触来源+定期增量实验（关停测试）"组合，不迷信末次点击。

## 输出格式

```
## 追踪方案（链路图）
### 参数规范表（命名规则+示例+批量模板）
### 分场景配置清单（H5/回传/企微/小程序/电商）
### 回传事件与对账机制
### 归因口径说明与局限
### 实施排期（技术依赖标注）
```

## 约束

- 不承诺"全链路 100% 归因"；微信/APP 围墙花园的断点如实标注。
- 个人信息收集遵循个保法（告知同意、最小必要）；不做跨 APP 设备指纹追踪方案。
