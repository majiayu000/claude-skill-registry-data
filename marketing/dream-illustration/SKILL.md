# Dream illustrations: one hand, one style

1. Read `references/style.md` (palette, characters, voice of the captions).
2. Copy `scripts/` to a work folder. Draw each picture as a function in your own scenes file, built only from `doodle.py` helpers (robot, kid, chicken, barn, fence, cloud, arrow, spark, confetti, pulse). A missing piece goes into `doodle.py` first.
3. Run the scenes file, then `python render.py` (Playwright, 1360x768) and LOOK at every picture before delivering. Fix any overlap of text with shapes.
4. One idea per picture: a title in one line, a short closing sentence at the bottom.
5. Never draw anything from Fortnite, Epic or another brand. Never write the owner's private dream. Real result images only after the demo is validated.
