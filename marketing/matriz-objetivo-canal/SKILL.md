# Matriz Objetivo x Canal Movistar

Cargada por el Planner/Planner y el Campaign Manager. Referencia estructurada para decidir que canales activar según el objetivo de la campaña.

Estas matrices son punto de partida. El Planner puede ajustarlas si el briefing lo justifica, pero debe documentar la desviación.

---

## 1. Objetivo: Notoriedad

| Canal | Recomendación | Rol |
|---|---|---|
| Medios masivos | Principal | Construir memoria, superioridad y territorio |
| Digital video / social reach | Principal | Amplificar cobertura y códigos de campaña |
| Programatica premium | Apoyo | Cobertura cualificada y contexto |
| Movistar+ lineal | Apoyo | Refuerzo audiovisual en entorno propio |
| CRM | No principal | Solo si hay mensaje de valor específico para clientes |
| Tienda | Apoyo | Presencia visual coherente, no presión comercial |
| Performance | No recomendado como protagonista | Puede capturar demanda derivada |

**Corrección tipica:** no se recomienda activar CRM masivo para un objetivo puro de notoriedad salvo que exista un valor concreto para clientes. En caso contrario, se convierte una campaña de marca en presión comercial.

---

## 2. Objetivo: Consideración

| Canal | Recomendación | Rol |
|---|---|---|
| Digital social / Meta | Principal | Explicar beneficios y razones para elegir |
| Display secuencial | Apoyo | Ordenar mensajes por fases |
| Programatica contextual | Apoyo | Asociar producto a contexto relevante |
| Movistar+ banner / lineal | Apoyo fuerte | Refuerzo contextual en clientes |
| CRM | Principal si es base cliente | Personalizar razon de valor |
| Tienda | Principal si hay decisión asistida | Explicar y reducir dudas |
| Performance | Apoyo | Capturar señales de intención |

**Corrección tipica:** se recomienda usar Meta no solo como performance, sino como consideración visual. Si solo se activa con precio, se pierde construcción de valor.

---

## 3. Objetivo: Performance / conversión

| Canal | Recomendación | Rol |
|---|---|---|
| Meta performance | Principal | Capturar demanda con creatividad directa |
| Search / SEM | Principal | Capturar intención activa |
| Retargeting | Principal con limites | Recordar, resolver objeción y cerrar |
| CRM | Principal si cliente identificable | Activación personalizada |
| Tienda | Principal si hay cierre asistido | Conversion con explicación humana |
| Movistar+ banner | Apoyo | Recordatorio contextual |
| Movistar+ preroll | Condicionado | Solo si la relevancia justifica interrupción |
| First Impression | Normalmente no recomendado | Reservado para mensajes estrategicos |
| Medios masivos | Apoyo indirecto | Generar demanda, no optimizar conversión directa |

**Corrección tipica:** no se recomienda usar First Impression para una campaña puramente tactica de conversión. El formato es demasiado valioso e intrusivo para un mensaje de bajo valor estratégico.

---

## 4. Objetivo: Fidelización / valor cliente

| Canal | Recomendación | Rol |
|---|---|---|
| CRM | Principal | Reconocer, personalizar y activar valor |
| Movistar+ banner | Principal / apoyo fuerte | Recordatorio contextual de valor |
| Tienda | Apoyo | Explicar ventajas y resolver dudas |
| Digital customer match | Apoyo | Refuerzo segmentado |
| Movistar+ preroll | Condicionado | Solo para beneficios de alto valor |
| Medios masivos | Apoyo | Construir orgullo de pertenencia |
| Performance abierto | No recomendado | Puede parecer captación genérica |

**Corrección tipica:** no conviene tratar una campaña de fidelización como una campaña de descuento. El beneficio debe sentirse como reconocimiento, no como liquidación.

---

## 5. Objetivo: Educación / explicación

| Canal | Recomendación | Rol |
|---|---|---|
| Tienda | Principal | Explicar con ayuda humana |
| CRM | Principal | Ordenar información de forma clara |
| Digital video corto | Apoyo | Demostración simple |
| Landing / web | Principal | Profundizar y resolver dudas |
| Movistar+ banner | Apoyo | Recordatorio sencillo |
| Movistar+ preroll | Condicionado | Solo si es breve y contextual |
| Performance | Apoyo bajo | Llevar a landing explicativa |
| Medios masivos | No recomendado como explicativo | Puede abrir territorio, no explicar detalle |

**Corrección tipica:** no se recomienda resolver una explicación compleja en un banner o preroll. Estos canales deben abrir la puerta; la explicación debe vivir en CRM, tienda, landing o contenido específico.

---

## 6. Objetivo: Retención

| Canal | Recomendación | Rol |
|---|---|---|
| CRM | Principal | Mensaje personalizado y reconocimiento |
| Call center | Principal si hay riesgo alto | Resolución, escucha y cierre |
| App / web privada | Apoyo | Autogestion y consulta |
| Tienda | Apoyo si hay visita | Explicación y recuperación |
| Movistar+ banner | Condicionado | Refuerzo suave de valor |
| Digital retargeting | Muy condicionado | Evitar sensación de persecución |
| Masivos | Apoyo indirecto | Reforzar confianza de marca |

**Corrección tipica:** en retención, la presión comercial debe sentirse como cuidado, no como desesperación. No se recomienda usar retargeting agresivo si el cliente ya esta recibiendo CRM o contacto de servicio.

---

## Como usar estas matrices

1. **Planner/B**: identifica el objetivo principal del briefing, consulta la matriz correspondiente. Si el briefing pide canales que la matriz marca como "no recomendado", flaggea la discrepancia.
2. **Campaign Manager**: en Cierre, verifica que la arquitectura de canales es coherente con el objetivo. Si una campaña de notoriedad tiene CRM como canal principal sin justificación, es un flag.
