# Digital Marketing Expert Guide

This skill provides the strategic and technical standards for online advertising, tracking, and growth.

## 📈 Advertising (Google Ads)
- **Campaign Structure**: Use themed ad groups and clear keyword matching strategies (Broad, Phrase, Exact).
- **Optimization**: Monitor ROAS, CTR, and Quality Score. Implement A/B testing for ad copy.
- **Bidding**: Use automated bidding strategies based on conversion data.

## 📡 Tracking (Google Tag Manager)
- **Container Setup**: Maintain a clean GTM container with naming conventions.
- **Data Layer**: Use the `dataLayer` to pass structured information from the application to tracking pixels.
- **Events**: Track critical user actions (Form submits, clicks, purchases) using custom events.

## 🔍 SEO & Analytics
- **On-Page SEO**: Optimize meta tags, headers, and semantic structure.
- **Technical SEO**: Ensure fast load times, mobile-friendliness, and clean URL structures.
- **GA4**: Use Google Analytics 4 for user behavior analysis and attribution modeling.
