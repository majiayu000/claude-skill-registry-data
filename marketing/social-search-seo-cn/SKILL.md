# 社交搜索优化（小红书/抖音/微信搜一搜）

国内搜索行为已迁移：生活决策搜小红书、教程测评搜抖音、品牌服务搜微信。社交搜索排序 = 关键词匹配 × 内容质量 × 互动信号 × 账号权重 × 时效。

## 输入

平台、业务与目标词（品类/场景/品牌/竞品）、现有内容资产（笔记/视频/公众号/小程序）、账号矩阵情况、预算（是否配搜索广告）。

## 分平台打法

### 小红书搜索

- 选词：搜索联想词+千瓜/新红热词+评论区用户原话；分层：品类大词（竞争高）/场景词/人群词/长尾问句（冷启动先打长尾）；
- 卡位：标题含核心词、正文自然出现 2–4 次、标签带词、封面文字含词；一词多笔记矩阵（不同账号/角度覆盖同一词）；
- 排序信号：点击率（标题封面）、互动率（赞藏评）、搜索后点击与停留；发布后 24–48h 互动冲刺（社群/薯条小额）；
- 广告配合：聚光搜索广告买核心词，自然+广告双卡位；
- 红线：堆词/买互动/代发铺量属虚假营销治理对象，矩阵要真实账号真实内容。

### 抖音搜索

- 选词：巨量算数/搜索联想/下拉词；抖音搜索偏"视频化问句"（XX 怎么做/XX 测评/XX 推荐）；
- 卡位：标题+口播台词+字幕+话题标签四处埋词（语音会被识别）；合集归类同主题视频；
- 排序信号：完播/互动/搜索点击率/账号垂直度；蓝 V 与小程序/POI 有搜索直达组件；
- 广告配合：巨量搜索广告（搜索快投单独建计划看词）；
- 本地生活：POI+团购+地域词（"城市+品类"）。

### 微信搜一搜

- 流量入口：公众号文章/视频号/小程序/服务直达/百科；
- 卡位：公众号标题与正文埋词（搜一搜长尾流量可观）、小程序名称与简介含品类词、视频号标题话题；
- 品牌区：微信指数看热度；服务号菜单与小程序服务直达配置；
- 联动：元宝可检索公众号内容（AI 搜索信源，见 ai-visibility-cn），公众号内容质量同时服务搜一搜与 AI 引用。

## 流程

1. 词库：按"品类/场景/人群/品牌/竞品"分层，标注搜索量级（工具数据或联想词热度推断）与竞争度；
2. 现状审计：目标词搜索结果前 20 条的内容类型/账号/互动量，找可打的缝隙（长尾/新角度/视频化）；
3. 内容排期：一词一内容（或多账号矩阵），标题/正文/标签按平台规则埋词；
4. 冷启动互动与广告配合；
5. 度量：目标词排名（定期人工/工具查）、搜索来源流量占比、搜索-转化链路（见 tracking-setup-cn）。

## 输出格式

```
## 社交搜索方案（平台 / 业务）
### 词库分层表（词/量级/竞争/优先级）
### 现状审计与缝隙判断
### 内容卡位排期（词×内容×账号×时间）
### 广告配合与预算
### 度量与复查节奏
### 合规提示（不刷量/不堆词/商业内容报备）
```
