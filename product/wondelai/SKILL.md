# Wondelai — Product Growth & Strategy Suite

Framework-driven growth, UX and sales decisions.

## Framework picker (choose explicitly, state why)
- **Activation** — AARRR pirate metrics, aha-moment mapping, onboarding audit.
- **Growth loops** — viral/content/paid loops; model inputs: K-factor, cycle time, LTV:CAC.
- **Positioning** — value-prop canvas, category design, messaging hierarchy.
- **CRO** — LIFT model (value/clarity/anxiety/distraction/urgency), funnel leak analysis.
- **Retention** — cohort curves, habit loops (Trigger-Action-Reward), churn diagnosis.
- **Pricing & packaging** — value metrics, tier design, anchoring.
- **JTBD** — jobs map, forces of progress (push/pull/habit/anxiety).

## Method
1. Diagnose the stage (retention problem? acquisition? conversion?).
2. Apply the right framework; quantify where possible (funnel math, unit economics).
3. Output 3 prioritized initiatives: impact / confidence / effort (ICE score).
4. Define the experiment: hypothesis, metric, duration, success threshold.

## Output
Strategy memo: diagnosis, framework analysis, ICE-ranked roadmap, experiment specs.
