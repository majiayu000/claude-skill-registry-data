# 机器人成本与量产分析

## Purpose

把技术方案转成可审查的整机成本、制造风险、运维负担和单位经济性，帮助产品经理判断项目在样机、试点、小批和规模部署阶段是否成立。

## Input

可提供BOM、报价、产量、整机配置、研发投入、寿命、班次、任务量、故障维修、售价/租赁方式或客户人工基线。缺失数据时使用区间与敏感性分析，不伪造精确成本。

示例：`使用 robotics-cost-production，比较轮式机械臂和人形机器人完成工厂搬运的五年TCO。`

## Key Concepts

- **BOM不等于整机成本**：还包括制造、测试、校准、报废、保修、物流、部署和支持。
- **NRE与单位成本分开**：研发、模具、认证和产线投入按阶段与销量摊销，不能隐藏。
- **成功任务是经济单位**：便宜但高干预、低可用的机器人可能更贵。
- **量产是能力而非数量**：设计可制造、供应稳定、测试覆盖、良率和维修性共同决定爬坡。
- **区间优于假精确**：对销量、良率、故障和利用率做基准/乐观/悲观情景。

## Application

### 1. 明确比较对象与口径

定义产品配置、形态、ODD、任务、年产量、部署数量、经济寿命、币种/税口径和价格时间点。确认比较的是样机、小批还是稳定量产成本。

### 2. 建立成本树

至少覆盖：

- 结构件、外壳、连接件和加工
- 电机/执行器、减速器、驱动器、制动和关节
- 相机、激光、IMU、力矩/触觉及其他传感器
- CPU/GPU/NPU、控制器、网络、存储和线束
- 电池、BMS、充电/换电和热管理
- 机械臂、末端工具、脚/轮和安全部件
- 装配、标定、老化、终检、包装、物流和报废
- 软件许可、云服务、通信和第三方模块

使用 [成本模型模板](references/cost-production-model.md)。

### 3. 计算NRE和量产摊销

列出研发人力、样机、工装、模具、测试设备、认证、数据采集/训练、产线和供应商开发。按预期可售数量摊销，并单独展示销量不达预期的风险。

### 4. 建立良率与供应模型

记录关键件供应商、交期、最小起订、单一来源、替代料、停产风险、来料良率、装配良率、返工、校准时间和终检覆盖。对高成本执行器、减速器、传感器和算力模块做专项敏感性分析。

### 5. 计算部署与运维TCO

包含场地改造、地图/标定、安装培训、远程运营、现场救援、备件、保养、维修、软件/云、能源、网络、保险/合规和退役。用可用率、干预率和MTTR连接运维成本。

### 6. 计算单位成功任务经济性

推荐指标：

- 单个成功任务成本 = 生命周期总成本 / 生命周期成功任务数
- 每有效工时成本 = 生命周期总成本 / 满足任务定义的有效运行小时
- 人工干预成本 = 干预次数 x 单次平均人工时间 x 人工全成本率
- 产能利用率 = 实际有效任务量 / 可用设计产能

与现有流程比较时，纳入人员、设备、错误、事故、等待、空间和峰值成本，不只比较工资。

### 7. 设计量产与降本路线

按样机 -> 工程样机 -> 设计验证 -> 生产验证 -> 小批 -> 爬坡分阶段。每阶段定义成本、良率、节拍、质量、供应、可靠性和设计冻结门槛。优先降低高占比且不损伤安全/可靠性的成本。

### 8. 输出投资结论

交付：成本树、假设表、三情景模型、关键件敏感性、供应/良率风险、TCO、单位任务经济性、降本路线和继续/转向/停止建议。

## Examples

### 轮式搬运机器人

底盘BOM较低不代表项目便宜。若每个点位需要大量场地改造、地图维护和现场救援，部署与运维可能主导TCO。应以每千次成功转运成本比较人工或固定输送方案。

### 人形机器人

执行器、减速器、传感器、算力和电池占比高，跌倒维修和遥操作也可能显著。用“假设未来大幅降价”支撑立项时，必须展示当前可行方案和价格未下降的情景。

## Common Pitfalls

- **只看BOM**：漏掉测试、校准、售后和报废。修正：用完整成本树和TCO。
- **用目标销量倒推低成本**：需求未证实时摊销失真。修正：做销量与良率敏感性。
- **忽略干预与停机**：账面自动化，实际靠人工维持。修正：按成功任务和有效工时核算。
- **过早降规格**：降低传感或安全冗余导致返工和事故风险。修正：先做功能价值工程和证据评审。
