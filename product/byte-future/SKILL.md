Use the project's existing backlog or `.byte-os/FUTURE.md`. Capture a short title,
the idea, why it is deferred when known, and a useful revisit trigger when one
exists. Do not invent priority, deadlines, ownership, or success metrics.

existence must not block current completion. If the user later promotes it,
handle it like a normal active request using the most appropriate Byte capability.
